# 音乐

播放器从 `playlist.json` 读取曲目，构建时会把本目录复制到 `site/assets/music/`。

## 添加本地音乐

1. 把 `.mp3` / `.m4a` / `.ogg` 和同名 `.lrc` 放进本目录。
2. 在 `playlist.json` 里增加一项：

```json
{
  "title": "歌曲名",
  "artist": "歌手",
  "src": "song.mp3",
  "lyrics": "song.lrc"
}
```

- `src` 是相对本目录的文件名，也可以直接写 `https://...` 远程地址。
- `lyrics` 可留空；有 `.lrc` 时会显示悬浮歌词。
- 默认是两首 SoundHelix 测试曲，没有歌词文件；换成自己的音乐和 LRC 即可。

## 说明

- 播放器按钮全部使用符号：`⏮` / `▶` / `⏭` 控制播放，`→` / `⇄` / `↻` 切换顺序、随机、单曲循环，`≡` 打开歌单，`♪` 打开悬浮歌词。
- 进度条可以拖动定位。
- 播放器只在用户点击播放后发声，避免浏览器自动播放限制。
- 音乐版权由上传者自行确认；不要把未授权的商业音乐放进公开仓库。
