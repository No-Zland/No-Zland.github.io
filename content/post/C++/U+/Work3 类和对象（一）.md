```

```

B、在创建对象时，系统自动调用构造函数

```

# （选择题）第19题

题目：

```

假定MyClass为一个类，则该类的拷贝构造函数的声明语句为下列哪项？（）

```

选项：

```

A、MyClass(MyClass x)

B、MyClass&(MyClass x)

C、MyClass(MyClass &x)

D、MyClass(MyClass *x)

```

参考答案：

```

C

```

答案解析：

```

拷贝构造函数的核心规则是参数必须是当前类的引用（通常是const引用），原因是：

1. 若参数为普通对象（如选项A），会触发拷贝构造函数的递归调用（传递实参时需要拷贝对象，又会调用拷贝构造函数），导致编译错误；

2. 选项B的语法错误（引用符号&应写在参数类型后）；

3. 选项D的参数是指针，不符合拷贝构造函数的参数要求（拷贝构造函数的参数是对象的引用，而非指针）；

4. 选项C符合语法：MyClass(MyClass &x)是正确的拷贝构造函数声明（完整写法通常会加const，即MyClass(const MyClass &x)）。

```

# （判断题）第24题

题目：

```

已知：类A中一个成员函数说明如下：void Set(A &a); 其中A &a的含意是将a的地址赋值给变量Set。（）

```

选项：

```

A、正确

B、错误

```

参考答案：

```

错误

```

答案解析：

```

A &a的含义是声明一个类 A 类型的引用变量 a，而非 “将 a 的地址赋值给变量 Set”。

- 题目中 “将 a 的地址赋值给变量 Set” 的描述完全错误：Set是函数名，并非变量；&在此处是引用符号，不是取地址操作。

```

# （判断题）第25题

题目：

```

C++中定义类的成员函数为内联函数时，可以直接在类体内定义函数而不用inline关键字声明。（）

```

选项：

```

A、正确

```

参考答案：

```

正确

```

```

C++中“类内定义成员函数”的语法，默认会将该函数视为内联函数，无需额外加inline关键字：

};

```

此时add函数会被编译器当作内联函数处理，不需要手动加inline声明。

# （判断题）第31题

题目：

```

对于常量类型和引用类型的数据成员，不能在构造函数中用赋值语句直接赋值，C++提供初始化表进行赋值。（）

```

选项：

```

A、正确

B、错误

```

参考答案：

```

正确

```

答案解析：

```

初始化表是C++中构造函数的语法特性，用于在对象成员创建时直接完成初始化，而非在构造函数体中赋值。

- 语法形式：在构造函数参数列表后，用:开头，以逗号分隔成员的初始化项，格式为构造函数名(参数) : 成员1(值1), 成员2(值2) { /* 函数体 */ }。

- 适用场景：必须用于常量成员、引用成员的初始化；也常用于类类型成员（避免默认构造+赋值的额外开销）。

- 示例：

```cpp

class A {

private:

const int num; // 常量成员

int &ref; // 引用成员

public:

// 用初始化表初始化常量和引用

A(int n, int &r) : num(n), ref(r) {}

};

```

```
