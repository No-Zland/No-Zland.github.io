# 途眸智谏 · Android 移动应用开发项目书

> 项目名称：途眸智谏驾驶员监护 Android 移动应用
> 所属系统：途眸智谏离线化多模态驾驶员监控系统（DMS）
> 开发工具：Android Studio
> 目标平台：Android 8.0（API 26）及以上

---

## 1. 项目概述

### 1.1 项目背景

途眸智谏离线化多模态驾驶员监控系统是一套基于 ESP32-S3 + K230 + RK3568 异构硬件架构、融合边缘 AI 与云端大模型的驾驶员安全监护系统。系统通过端侧 AI 推理实时检测驾驶员的疲劳、分心、跌倒等异常状态，并形成"异常检测 → 分级报警 → 休息引导 → 远程提醒"的完整安全闭环。

当前系统已完成端侧（K230 视觉）、物联网主控（ESP32-S3）、车载交互（RK3568）的开发，但**亲属端远程监护能力尚未落地**。驾驶员在长途驾驶中一旦出现重度疲劳、医学急救等危险事件，亲属无法第一时间获知，也无法实时掌握驾驶员的行驶位置与安全状态。

本项目即为填补这一闭环空缺，基于 Android Studio 开发一款**亲属端移动监护应用（途眸智谏 App）**，通过 MQTT 云端订阅设备实时数据，实现驾驶员状态远程监测、实时定位、分级告警推送与大模型建议展示。

### 1.2 项目目标

1. 实现亲属/监护人对驾驶员状态的**实时远程监控**；
2. 实现驾驶员**实时位置**的地图可视化展示；
3. 实现**分级告警与医学急救**的即时推送通知；
4. 展示云端大模型生成的**个性化安全建议**；
5. 支持**设备绑定**与**历史事件**追溯；
6. 完成 App 与现有 MQTT 云端、大模型平台的对接。

### 1.3 项目范围

| 范围 | 内容 |
|------|------|
| 包含 | 用户登录/注册、设备绑定、实时状态监控、地图定位、告警推送、LLM 建议展示、历史记录、个人中心 |
| 不包含 | 端侧 AI 推理、车载交互界面（RK3568）、传感器采集（ESP32-S3/K230） |

## 2. 需求分析

### 2.1 用户角色

| 角色 | 描述 | 核心诉求 |
|------|------|----------|
| 亲属/监护人（主用户） | 驾驶员的家人、车队管理员 | 实时掌握驾驶员安全状态与位置，接收告警 |
| 驾驶员（间接用户） | 被监护对象 | 无感运行，紧急时获得家人关注 |

### 2.2 功能需求

#### F1 用户账号
- 支持手机号/账号密码注册、登录；
- 支持 Token 会话保持与自动登录。

#### F2 设备绑定
- 通过设备 ID（`esp32s3_toughmind_01`）绑定一台 DMS 设备；
- 支持多设备管理、设备在线状态显示。

#### F3 实时状态监控
- 实时展示疲劳等级（正常/轻度/中度/重度/医学异常）；
- 展示疲劳分数、PERCLOS、眨眼/哈欠次数、分心状态；
- 展示车内温度、GPS 卫星数、设备网络状态。

#### F4 实时定位
- 地图展示驾驶员实时位置与车速；
- 支持历史轨迹回放。

#### F5 告警推送
- 分级告警：轻度/中度/重度/医学急救四级，差异化通知样式与铃声；
- 医学急救事件最高优先级，强制提醒并显示跌倒/抽搐/意识丧失类型。

#### F6 大模型建议
- 展示云端大模型生成的个性化休息建议、路线引导；
- 支持建议的历史查看。

#### F7 历史记录
- 按时间查询历史疲劳/告警事件；
- 事件详情页展示完整指标（7 项以上）。

#### F8 个人中心
- 账号信息、设备管理、消息通知设置、关于。

### 2.3 非功能需求

| 类别 | 指标 |
|------|------|
| 实时性 | 状态数据推送延迟 < 3s |
| 可靠性 | MQTT 断线自动重连，消息 QoS 1（至少一次） |
| 兼容性 | Android 8.0+，适配主流分辨率 |
| 安全性 | 登录鉴权、HMAC-SHA256 载荷签名校验 |
| 性能 | 内存占用可控，前台运行无卡顿 |

## 3. 系统总体设计

### 3.1 系统架构

本 App 处于整个 DMS 系统的**北向云端消费端**，通过 MQTT 公共 Broker 订阅设备上报数据，形成端—云—App 三层链路：

```
┌──────────────┐   UART    ┌───────────────┐   WiFi+MQTT   ┌───────────────┐
│  K230 视觉    │ ────────► │  ESP32-S3     │ ────────────► │  MQTT Broker  │
│  (疲劳/跌倒)  │  $DMS帧   │  (物联主控)    │  上报/订阅      │ broker.emqx.io│
└──────────────┘            └───────────────┘               └───────┬───────┘
                                                                    │ 订阅
                                                          ┌─────────▼─────────┐
                                                          │  途眸智谏 Android │
                                                          │  App（本项目）     │
                                                          └─────────┬─────────┘
                                                                    │ HTTPS
                                                          ┌─────────▼─────────┐
                                                          │ 云端大模型 / 后端  │
                                                          │ (讯飞星火/自建)    │
                                                          └───────────────────┘
```

### 3.2 技术选型

| 模块 | 选型 | 说明 |
|------|------|------|
| 开发语言 | Kotlin | Google 官方首选语言 |
| UI 框架 | Jetpack Compose | 声明式 UI，开发效率高 |
| 架构模式 | MVVM + Repository | 分层清晰，便于测试 |
| MQTT 客户端 | Eclipse Paho Android Service | MQTT 3.1.1 标准库 |
| 地图 SDK | 高德地图 SDK（AMap） | 与 ESP32 端高德 API 一致 |
| 网络请求 | Retrofit + OkHttp + kotlinx.serialization | REST 对接大模型/后端 |
| 本地存储 | Room + DataStore | 事件持久化、偏好存储 |
| 依赖注入 | Hilt | 解耦、易维护 |
| 通知 | NotificationManager + FCM | 分级告警推送 |
| 异步 | Kotlin Coroutines + Flow | 响应式数据流 |

### 3.3 通信协议

#### 3.3.1 MQTT 主题（与现有 config.py 对齐）

| 主题 | 方向 | 载荷 | 用途 |
|------|------|------|------|
| `dms/driver/state` | 设备→云 | 驾驶状态 | 实时状态监控 |
| `dms/gps/position` | 设备→云 | GPS 位置 | 实时定位 |
| `dms/alarm/urgent` | 设备→云 | 紧急告警 | 分级/医学告警 |
| `dms/llm/advice` | 云→App | LLM 建议 | 个性化建议展示 |
| `dms/cmd/downlink` | App→设备 | 下行指令 | 远程唤醒（规划） |

#### 3.3.2 载荷字段

驾驶状态（`dms/driver/state`）：

```json
{
  "device_id": "esp32s3_toughmind_01",
  "fatigue_level": 2,
  "fatigue_score": 55.0,
  "perclos": 0.35,
  "yawn_total": 8,
  "head_distracted": false,
  "lat": 30.1234,
  "lon": 120.1234,
  "speed_kmh": 80,
  "temperature": 32.5,
  "wifi_rssi": -60,
  "satellites": 10,
  "ts": 1717200000,
  "hmac": "签名"
}
```

#### 3.3.3 安全校验

- 设备上报载荷携带 HMAC-SHA256 签名，密钥 `toughmind_dms_hmac_key_2025`；
- App 端校验签名，防止伪造/篡改数据。

## 4. 功能详细设计

### 4.1 登录/注册

- 输入校验、密码加密存储（Token 保存于 DataStore）；
- 登录成功后建立 MQTT 连接并订阅主题。

### 4.2 设备管理

- 输入设备 ID 绑定；展示设备在线/离线、最后上报时间；
- 支持绑定多台设备，切换查看。

### 4.3 实时监控主界面

- 顶部状态卡片：疲劳等级（颜色区分）、疲劳分数、PERCLOS；
- 中部地图：驾驶员位置、车速；
- 底部信息栏：温度、卫星数、网络状态、哈欠/分心统计。

### 4.4 告警推送

| 等级 | 触发 | 通知样式 |
|------|------|----------|
| 轻度 | fatigue_level=1 | 普通通知 |
| 中度 | fatigue_level=2 | 声音 + 振动 |
| 重度 | fatigue_level=3 | 高优先级 + 强提醒 |
| 医学急救 | medical_level≥1 | 最高优先级 + 持续强提醒 + 显示医学类型 |

### 4.5 大模型建议展示

- 订阅 `dms/llm/advice`，展示休息建议、路线引导；
- 建议与历史事件关联，可回溯查看。

### 4.6 历史记录

- 本地 Room 存储每次状态/告警事件；
- 按日期分组列表，详情页展示完整指标。

## 5. 数据库设计

### 5.1 Room 实体

**Device**（设备表）
- deviceId（主键）、deviceName、bindTime、lastOnlineTime、isOnline

**Event**（事件表）
- id（主键，自增）、deviceId、type（state/alarm/medical）、level、fatigueScore、perclos、yawnTotal、headDistracted、lat、lon、speed、temperature、timestamp

**Advice**（建议表）
- id（主键）、deviceId、content、timestamp

### 5.2 DataStore 偏好

- 登录 Token、当前设备 ID、通知开关、告警铃声设置。

## 6. 界面设计

采用 Jetpack Compose，遵循 Material 3 设计规范：

| 页面 | 主要内容 |
|------|----------|
| 登录/注册页 | 表单、校验提示 |
| 首页（监控） | 状态卡片 + 地图 + 信息栏 |
| 设备管理页 | 设备列表、绑定入口 |

| 事件详情页 | 完整指标、位置快照 |

## 9. 风险分析

| 风险 | 影响 | 应对措施 |
|------|------|----------|
| 公共 Broker 不稳定 | 推送延迟/丢失 | 部署私有 Broker 或使用 TLS 8883 端口 |
| 公网明文传输 | 数据泄露 | 接入 TLS，载荷签名校验 |
| MQTT 断线 | 数据中断 | 自动重连 + 离线缓存 |
| 地图 SDK Key 限制 | 定位异常 | 申请企业级 Key，做好配额监控 |
