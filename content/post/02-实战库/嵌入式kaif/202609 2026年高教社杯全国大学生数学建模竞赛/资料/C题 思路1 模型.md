根据这篇思路，C题“微电网购电优化”本质上是一个**离散时间下的能量管理优化问题**。由于时间按每10分钟离散、目标与约束基本线性，核心模型是**线性规划（LP）**；若考虑储能充放电互斥等逻辑约束，则升级为**混合整数线性规划（MILP）**。不同问题在此基础上叠加滚动优化和不确定性方法。

---

## 一、总体模型框架

### 1. 决策变量
- 每个时段购电量 \(x_t\)
- 储能充电功率 \(P_t^{ch}\)、放电功率 \(P_t^{dis}\)
- 储能荷电状态 \(SOC_t\)
- 紧急购电量（问题二）
- 计划购电量与调整购电量（问题三）

### 2. 目标函数
- 问题一：最小化购电总成本  
  \[
  \min \sum_t c_t \cdot x_t \cdot \Delta t
  \]
  其中 \(\Delta t = 1/6\) 小时，\(c_t\) 为电价。
- 问题二：正常购电成本 + 紧急购电成本（5倍价）
- 问题三：计划购电成本 + 调整购电成本 + 偏差惩罚（违约或1.5倍补充）
- 问题四：在电价不确定性下，最小化期望成本或最坏情况成本。

### 3. 约束条件
- 功率平衡：光伏 + 购电 + 储能放电 ≥ 小区负载
- 储能容量：\(0 \le SOC_t \le 4500\)（实际可用4500）
- 充放电功率限制：\(0 \le P_t^{ch}, P_t^{dis} \le 5000\)
- SOC动态：\(SOC_{t+1} = SOC_t + \eta_{ch} P_t^{ch} \Delta t - P_t^{dis} \Delta t / \eta_{dis}\)
- 买电瞬时假设：购电无延迟，缺电即可买。
- 初始/终端SOC约束。

## 二、分问题模型与算法

### 问题一：静态购电计划
- **模型**：线性规划（LP）或混合整数线性规划（MILP）。  
  若允许储能同时充放电但优化会自然避免，则LP即可；若严格禁止同时充放电，需引入0-1变量，成为MILP。
- **离散化**：每10分钟一个时段，一天144个时段，不插值，避免失真。
- **算法**：单纯形法、内点法（LP）；分支定界/分支切割（MILP）。  
- **求解器**：Gurobi、CPLEX、MATLAB `linprog`/`intlinprog`、Python PuLP/Pyomo。

### 问题二：全年紧急购电
- **模型**：带分段线性惩罚的LP/MILP。  
  紧急购电价格是正常5倍，可设为两个购电变量：正常购电 \(x_t\)、紧急购电 \(y_t\)，目标中 \(c_t x_t + 5c_t y_t\)。优化会自动优先用正常购电，不足时用紧急购电。
- **规模**：全年52560个时段，可按天分解优化（若每天初始SOC固定为6000），降低计算量。
- **算法**：同问题一，按天独立求解LP/MILP，再汇总全年成本。

### 问题三：滚动预测与调整
- **模型**：滚动时域优化（Rolling Horizon Optimization），即模型预测控制（MPC）思想。
- **流程**：每天0点、6点、12点根据最新预测更新未来24小时的光伏和负载，重新求解购电计划。  
  计划购电与调整购电的偏差产生惩罚：计划 > 调整 → 违约；调整 > 计划 → 1.5倍补充费。
- **模型**：每个决策点求解一个LP/MILP，目标含计划成本、调整成本、偏差惩罚。
- **算法**：MPC框架 + LP/MILP求解器。每次优化未来时段，只执行当前时段决策，下一时刻再滚动。

### 问题四：不确定性量化
- **模型**：随机规划（Stochastic Programming）或鲁棒优化（Robust Optimization）。
- **不确定性来源**：电价变化（可量化）。
- **方法**：
  - 蒙特卡洛模拟生成电价场景；
  - 两阶段随机规划：第一阶段制定购电计划，第二阶段根据实际电价调整；
  - 机会约束规划：满足一定置信水平下的成本约束；
  - 鲁棒优化：考虑电价最坏情况，最小化最大成本。
- **算法**：场景生成 + 随机规划求解（LP/MILP），或鲁棒对等模型转化后求解。

---

## 三、总结：采用的模型算法

| 问题 | 核心模型 | 算法 |
|------|----------|------|
| 问题一 | LP / MILP | 单纯形法、内点法、分支定界 |
| 问题二 | LP / MILP（带紧急购电惩罚） | 按天分解 + LP/MILP |
| 问题三 | 滚动时域优化（MPC） | MPC + LP/MILP |
| 问题四 | 随机规划 / 鲁棒优化 | 蒙特卡洛 + 场景法 / 鲁棒对等 |

**总体一句话**：  
这是一道典型的**离散时间线性优化**问题，主体用**线性规划/混合整数线性规划**，问题三用**滚动时域优化（MPC）**，问题四用**随机规划或鲁棒优化**处理电价不确定性。求解器推荐 Gurobi/CPLEX，编程可用 Python + Pyomo/PuLP 或 MATLAB。
