你的判断是对的：**四问不应各自重建一套储能与能量平衡约束，而应共享同一个“物理可行域”，差别只放在信息集、购电变量的生成方式和费用结算层。** 题面给出的储能参数为 12000 kWh、5000 kW、运行范围 1200–10800 kWh、初始电量 6000 kWh、效率 90%，而结果均按 10 分钟购电量输出。 你前面统一的“144 个决策区间 + 145 个储能状态节点”也是正确方向。

下面这版可以直接作为论文的“公共基础物理模型”。

## 5 C题四问共用的基础物理模型

为保证问题1—问题4在物理约束层面保持完全一致，本文首先建立统一的微网基础物理模型。四个问题均采用相同的能量平衡关系、储能状态转移关系、储能容量与功率约束、外网购电边界以及光伏弃电约束。不同问题仅在可利用的信息、计划购电量的形成方式、紧急购电及购电费用结算方式等上层决策机制上有所区别。

### 5.1 时间离散与单位统一

全天划分为144个长度为10 min的决策时段，定义

[  
\Delta t=10\text{ min}=\frac{1}{6}\text{ h},  
]

[  
k=0,1,\ldots,143.  
]

其中，第 (k) 个时段表示

[  
[\tau_k,\tau_{k+1}),  
\qquad  
\tau_k=k\Delta t.  
]

因此全天共有144个决策区间，但储能状态需要在所有区间边界上定义，即

[  
j=0,1,\ldots,144.  
]

于是 (E_{d,0}) 表示日期 (d) 当天0:00的储电量，而 (E_{d,144}) 表示当天24:00的储电量。

需要特别说明的是，附件中的时间数据以区间末时刻标记。例如“00:10”对应 (0{:}00-0{:}10) 时段，“0:00+1”对应 (23{:}50-24{:}00) 时段。因此附件中虽然存在“0:00+1”这一时刻标签，但一天仍然只有144个10分钟决策区间，而不是145个。

为避免功率与电量混用，将负荷功率和光伏功率统一转换成10分钟电量：

[  
L_{d,k}=P^L_{d,k}\Delta t,  
]

[  
G_{d,k}=P^{pv}_{d,k}\Delta t.  
]

其中 (L_{d,k}) 和 (G_{d,k}) 的单位均为 kWh。

这里 (G_{d,k}) 表示当前决策阶段能够使用的光伏电量输入。在计划优化阶段可对应当时已经获得的预测光伏，在实际运行阶段可对应实际光伏数据，但二者进入物理模型后的能量守恒形式完全相同。

---

### 5.2 基础决策变量

定义：

[  
q^{grid}_{d,k}\ge0  
]

为第 (k) 个10分钟时段实际由外部电网进入微网的电量，单位为 kWh；

[  
C_{d,k}\ge0  
]

为微网母线向储能输入的充电电量，单位为 kWh；

[  
D_{d,k}\ge0  
]

为储能向微网母线释放的放电电量，单位为 kWh；

[  
S_{d,k}\ge0  
]

为由于负荷及储能无法消纳而舍弃的光伏电量，单位为 kWh；

[  
E_{d,j}  
]

为储能在第 (j) 个边界时刻的内部实际储电量，单位为 kWh。

这里 (q^{grid}_{d,k}) 是物理层面的“总外网输入电量”。在不同问题中，它可以由计划购电、调整后的购电以及紧急购电等变量进一步组成，因此无需在公共物理模型中改变能量平衡方程。

---

### 5.3 10分钟微网能量平衡约束

对于任意日期 (d) 和时段 (k)，满足

# [  
\boxed{  
q^{grid}_{d,k}  
+G_{d,k}  
+D_{d,k}

L_{d,k}  
+C_{d,k}  
+S_{d,k}  
}  
]

该式表示：

# [  
\text{外网购电}  
+\text{光伏发电}  
+\text{储能放电}

\text{负荷需求}  
+\text{储能充电}  
+\text{弃光}.  
]

虽然题目表述为“微网提供的电能不可低于小区负载”，但从严格的能量守恒角度，不建议简单写成

[  
q^{grid}+G+D\ge L+C,  
]

因为不等式会允许多余电量在模型中无物理解释地消失。

引入弃光变量后，应采用上述等式形式，使全部输入电能均具有明确去向。

---

### 5.4 外网只能购电、不能售电

题目只规定了外网购电，没有给出向外网售电的机制和售电价格，因此规定

[  
\boxed{  
q^{grid}_{d,k}\ge0.  
}  
]

不得通过令

[  
q^{grid}_{d,k}<0  
]

将其解释为向外网售电。

题目也没有给出外网最大供电功率，因此公共模型中不人为增加外网购电上限。

---

### 5.5 光伏弃电约束

为处理光伏发电超过负荷需求且储能无法完全吸收的情况，引入弃光变量：

[  
\boxed{  
0\le S_{d,k}\le G_{d,k}.  
}  
]

于是实际被微网利用的光伏电量为

[  
G^{use}_{d,k}=G_{d,k}-S_{d,k},  
]

并满足

[  
0\le G^{use}_{d,k}\le G_{d,k}.  
]

该约束仅允许舍弃光伏电量，不能使用 (S_{d,k}) 去抵消过量的外网购电。

因此能量平衡也可等价写为

# [  
q^{grid}_{d,k}  
+G^{use}_{d,k}  
+D_{d,k}

L_{d,k}  
+C_{d,k}.  
]

引入弃光变量后，即使光伏功率超过负荷与储能最大吸收能力，模型仍能够保持物理可行。

---

### 5.6 储能状态转移约束

本文统一规定 (C_{d,k}) 和 (D_{d,k}) 均为储能外部母线侧的电量。

充、放电效率均取

[  
\eta_c=\eta_d=0.9.  
]

则储能内部电量按照

# [  
\boxed{  
E_{d,k+1}

E_{d,k}  
+\eta_c C_{d,k}  
-\frac{D_{d,k}}{\eta_d},  
\qquad k=0,\ldots,143  
}  
]

进行更新。

其中，储能充入 (C_{d,k}) kWh 电量后，真正存入电池的能量为

[  
\eta_c C_{d,k};  
]

若需要向微网母线输出 (D_{d,k}) kWh，则储能内部需要减少

[  
\frac{D_{d,k}}{\eta_d}.  
]

由于 (C_{d,k}) 和 (D_{d,k}) 已经定义为一个10分钟时段内的电量，因此上述状态方程中不能再次乘以 (\Delta t)。否则会造成重复的时间尺度换算。

---

### 5.7 储能容量约束

题目规定储能额定容量为12000 kWh，同时要求运行过程中储电量始终保持在1200–10800 kWh，因此对所有状态节点规定

[  
\boxed{  
1200\le E_{d,j}\le10800,  
\qquad j=0,\ldots,144.  
}  
]

相应的荷电状态范围为

[  
0.1\le SOC_{d,j}\le0.9,  
]

其中

[  
SOC_{d,j}=\frac{E_{d,j}}{12000}.  
]

由于

[  
E_{d,j}\le10800  
]

已经比额定容量限制

[  
E_{d,j}\le12000  
]

更加严格，因此无需再次写 (E_{d,j}\le12000)，否则只是一个冗余约束。

---

### 5.8 最大充放电量约束

题目给出的最大充放电功率为

[  
P^{\max}_{bat}=5000\text{ kW}.  
]

由于每个优化时段长度为

[  
\Delta t=\frac16\text{ h},  
]

故一个10分钟时段内允许的最大充、放电量为

# [  
q^{\max}_{bat}

# P^{\max}_{bat}\Delta t

# 5000\times\frac16

833.3333\text{ kWh}.  
]

因此应满足

[  
\boxed{  
0\le C_{d,k}\le833.3333,  
}  
]

[  
\boxed{  
0\le D_{d,k}\le833.3333.  
}  
]

这里不能错误地写为

[  
C_{d,k}\le5000,\qquad D_{d,k}\le5000,  
]

因为5000的单位是 kW，而 (C_{d,k},D_{d,k}) 的单位是 kWh。

### 5.9 储能充放电互斥约束

从物理上看，同一储能设备在同一调度时段不应同时进行充电和放电。

若要求严格保证充放电互斥，可增加二进制变量

[  
z_{d,k}\in{0,1},  
]

并规定

[  
\boxed{  
C_{d,k}\le833.3333z_{d,k},  
}  
]

[  
\boxed{  
D_{d,k}\le833.3333(1-z_{d,k}).  
}  
]

其中：

当

[  
z_{d,k}=1  
]

时，只允许充电；

当

[  
z_{d,k}=0  
]

时，只允许放电。

两者均可取0，因此储能也允许既不充电也不放电。

这里实际上不需要任意选取一个很大的 (M)，因为储能单时段最大电量已知，可以直接取

[  
\boxed{M=833.3333\text{ kWh}}.  
]

这样既避免了“大 (M)”过大引起的数值稳定性问题，又能够精确表达互斥关系。

如果为了提高求解速度暂时采用连续线性规划模型，则可以先删除二进制变量并求解LP，然后检查

# [  
N_{\mathrm{sim}}

\sum_{d,k}  
\mathbf 1  
\left(  
C_{d,k}>\varepsilon,,  
D_{d,k}>\varepsilon  
\right),  
]

以及

# [  
\delta_{\max}

\max_{d,k}  
\min(C_{d,k},D_{d,k}),  
]

其中可取

[  
\varepsilon=10^{-6}\text{ kWh}.  
]

如果

[  
N_{\mathrm{sim}}=0  
]

且

[  
\delta_{\max}\le\varepsilon,  
]

说明在当前目标函数和数据下，连续LP自然形成了充放电互斥，可不必增加二进制变量。

但是，这种“自然互斥”只是一种求解结果，不能从理论上保证。尤其在存在光伏过剩和免费弃光时，LP可能存在同时充放电的退化最优解。因此如果论文希望严格保证物理真实性，最终模型应采用上述二进制互斥约束。

[  
\boxed{  
E_{2025/1/1,0}=6000.  
}  
]

6000 kWh 位于允许范围

[  
1200\le6000\le10800  
]

之内，因此初始状态满足储能安全要求。

### 5.11 日内储能状态衔接

对于同一天的144个决策区间，储能状态依次按照

[  
E_{d,0}  
\rightarrow  
E_{d,1}  
\rightarrow  
\cdots  
\rightarrow  
E_{d,143}  
\rightarrow  
E_{d,144}  
]

连续演化。

严格来说，状态递推只能对

[  
k=0,\ldots,143  
]

建立，即最后一个状态转移为

[  
E_{d,143}\rightarrow E_{d,144}.  
]

不能再建立

[  
E_{d,144}\rightarrow E_{d,145},  
]

否则就产生了典型的“144/145索引错误”。

因此：

[  
\boxed{  
\text{144个调度区间}  
\Longleftrightarrow  
\text{144次状态转移}  
\Longleftrightarrow  
\text{145个储能状态节点}.  
}  
]

---

### 5.12 跨日储能状态衔接

对于问题2—问题4等连续多日运行情况，相邻两日必须满足

[  
\boxed{  
E_{d+1,0}=E_{d,144}.  
}  
]

即前一天24:00的储电量等于后一天0:00的储电量。

因此整个研究期内的储能状态实际上形成一条连续状态链：

# [  
E_{1,0}  
\rightarrow\cdots\rightarrow  
E_{1,144}

E_{2,0}  
\rightarrow\cdots.  
]

不能每天人为重新将储能恢复为6000 kWh。

需要特别区分的是，题目只在问题1中明确规定0:00和24:00储电量相同，因此

[  
E_{d,144}=E_{d,0}  
]

属于问题1额外增加的周期边界条件，而不是四个问题都必须共同采用的基础约束。

问题2—问题4若采用跨日连续运行，则只需保持

[  
E_{d+1,0}=E_{d,144}.  
]

### 5.13 四问统一的基础物理可行域

综上，四问共同的核心物理约束可统一写成

# [  
q^{grid}_{d,k}  
+G_{d,k}  
+D_{d,k}

L_{d,k}  
+C_{d,k}  
+S_{d,k},  
]

[  
q^{grid}_{d,k}\ge0,  
]

[  
0\le S_{d,k}\le G_{d,k},  
]

# [  
E_{d,k+1}

E_{d,k}  
+0.9C_{d,k}  
-\frac{D_{d,k}}{0.9},  
]

[  
1200\le E_{d,j}\le10800,  
]

[  
0\le C_{d,k}\le833.3333,  
]

[  
0\le D_{d,k}\le833.3333,  
]

以及在采用严格充放电互斥时

[  
C_{d,k}\le833.3333z_{d,k},  
]

[  
D_{d,k}\le833.3333(1-z_{d,k}),  
]

[  
z_{d,k}\in{0,1}.  
]

初始条件为

[  
E_{2025/1/1,0}=6000,  
]

多日运行满足

[  
E_{d+1,0}=E_{d,144}.  
]

由此，问题1—问题4可以完全共享上述基础物理可行域，而各问题之间的区别仅通过计划购电、紧急购电、购电调整、预测信息以及波动电价等上层决策规则体现，无需重复改变底层储能与微网物理模型。

这里再给你几个**审查后的关键结论**。

第一，**弃光变量必须保留**。我实际核对了你上传的附件2：全年数据中有 **241 个10分钟时段**满足“光伏电量－负荷电量 (>833.333) kWh”，最大光伏净过剩约 **1100.33 kWh/10 min**。这意味着即使储能尚未充满，仅受5000 kW充电功率上限影响，也存在光伏无法全部吸收的时段。如果既禁止售电、又不允许弃光，模型会直接不可行。题意本身也没有规定售电机制，因此允许弃光是最稳妥的物理处理。题目对“只购电、无售电”和光伏过剩处理确实留下了需要建模说明的空间。

第二，**二进制变量不是为了让模型“有解”，而是为了严格保证物理互斥**。连续LP在购电价格为正、需要从外网买电时，效率损失通常会使同时充放电不经济；但在光伏过剩、外网购电为0且弃光免费的时段，可能出现等价退化解，所以不能理论保证 (C_tD_t=0)。因此最推荐的做法正是你写的思路：**先跑LP并检查同时充放电；若确实出现，再切换MILP。**

第三，最容易出现的程序错误是：**把附件里的“0:00+1”误当成第145个决策变量。** 正确关系始终是：

[  
\boxed{144\text{个能量数据/决策变量}\quad+\quad145\text{个储能状态}}  
]

其中 (E_{144}) 就是24:00储电量。你之前统一变量体系中对此的定义是正确的。

第四，**问题1的 (E_{144}=E_0) 不要错误继承到问题2—4。** 题面只在问题1明确要求日初日末储电量相同；问题2以后更合理的是跨日连续 (E_{d+1,0}=E_{d,144})。

这套公共约束现在已经足够稳定，可以直接作为后面**问题1、2、3、4所有优化程序的同一个底层函数**，上层只替换“当时已知的 (L,G,p)”和购电结算规则。
