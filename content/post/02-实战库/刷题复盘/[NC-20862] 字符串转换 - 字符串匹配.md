### 题目描述：

给一个文本串 S ，再给两个串A、B，将文本串中的 A 都转换成 B ，转换后的字符不再参与转换，输出最终的文本串。

**输入描述:**

> 第一行输入一个文本串 S 。  
> 第二行输入字符串 A 。  
> 第三行输入字符串 B 。  
> $|S|$ 为 $S$ 的长度，$|A|$为A的长度，$|B|$为B的长度，所有字符都是小写字母，保证 $|A| <= |S|$ 。  
> 对于50%的数据：$1<= |A|、|B|、|S| <=1000$
> 对于100%的数据：$1<= |A|、|B|、|S| <=1000000$

**输出描述：**
> 只有一行，输出转换后的文本串。
### 示例1
**输入**
```
abababcd 
ab
cd
```
**输出**
```text
cdcdcdcd
```
---
### 最终代码：
```python
print(input().replace(input(), input()))
```

### 解题思路：

#### 1. 解决python的输入输出
由于是为了学习python，所以首先考虑用
```python
S, A, B = map(input().split())
```
，结果出现：
```python
执行出错
程序异常退出，请检查是否存在语法错误或者数组越界非法访问等情况
Traceback (most recent call last):
File "/tmp/a.py3", line 4, in <module>
s = S.replace(A, B)
AttributeError: 'list' object has no attribute 'replace'
```
  可以得知input()默认是字符串，但split()使用后返回的是列表，而列表中没有replace()这个方法。这个只有字符串才有，所以改为：
```python
S = input()
A = input()
B = input()
```
#### 2. 学习python的字符串替换方法
接下来要进行字符操作，之前用的是c/cpp，已经不太记得对应的字符串操作函数了，在搜索了python的字符串函数的时候，在想到cpp用while+strstr()。在使用replace()函数也遇到了一些问题:
```python
S = input()
A = input()
B = input()
S.replace(A, B)
print(S)
```
##### 3. python字符串的不变性
示例输出结果为：
`abababcd`
查询AI原因可以得知python的一个特性：
```
所有字符串的方法都不会改变原字符，必须用变量接住返回值
```
增加变量接住返回值，第一次AC代码如下：
```python
S = input()
A = input()
B = input()
s = S.replace(A, B)
print(s)
```

#### 4. 简化代码
后来咨询AI得到输入简化可为：
1. 逗号表达式，多元赋值
```python 
S, A, B = input(), input(), input()
```
2. 列表推导式，嵌套调用
```python
print(input().replace(input(), input()))
```
3. 海象运算符，python 3.8+使用
```python
print((S := input()).replace(input(), input()))
```
4. ACM极限压缩流（大量数据）
```python
import sys
S, A, B = sys.stdin.read().splitline()[:3]
print(S.replace())
```
原理：sys.stdin.read()可以将所有输入读进去，splitlines()按行分割，`[:3]`取前三个赋值
