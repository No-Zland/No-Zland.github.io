## 核心知识点：

斐波那契数列其实属于初等数论。本质上呢，是引入**递归**的典型例题之一：从斐波那契数列的前五项（1，1，2，3，5）可以发现规律，从第三项开始，该项为前两项之和，因此可以得到两个条件：
$$
\begin{cases}
f(n) = 1, & n <= 2 \\
f(n) = f(n - 1) + f(n - 2), & n > 2 
\end{cases}
$$
将这个公式抽象为代码，可以这么看。从3开始（注意，这里下标从1开始），那么需要两个变量$a = 1，b = 1$，最简单新建一个中间变量c来作为新的项，有
```cpp
for(int i = 3; i <= n; i ++){                                                           
	int tem = a + b;
	a = b;
	b = tem;
}
```
但是可以用更省空间、更简约的方法
```cpp
for(int i = 3; i <= n; i ++){
	b += a;
	a = b - a;
}
```

## 题目描述

定义一个数列：

$f(1) = 1$，
$f(2) = 1$，
$f(n) = f(n - 1) + f(n - 2) \quad (n \ge 3)$

现在给你一个整数 $n$，求出 $f(n)$。

## 输入描述:

> 输入一个整数n。
## 输出描述:

> 输出一个整数f(n)。

---
### 最终代码：

```python
n = int(input())
if n <= 2:
    print('1')
else:
    a = 0 
    b = 1
    for _ in range(1, n):
        a, b = b, a + b
    print(b) 
```
