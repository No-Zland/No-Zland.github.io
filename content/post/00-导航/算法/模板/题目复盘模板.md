#### 同类题（自动，按共同考点反查）

```dataview
TABLE WITHOUT ID
  file.link AS "题目",
  map(filter(file.tags, (t) => contains(this.file.tags, t) AND startswith(t, "#算法/")), (t) => replace(t, "#算法/", "")) AS "共同考点"
FROM "02-实战库/刷题"
WHERE file.path != this.file.path
  AND length(filter(file.tags, (t) => contains(this.file.tags, t) AND startswith(t, "#算法/"))) > 0
LIMIT 12
```
