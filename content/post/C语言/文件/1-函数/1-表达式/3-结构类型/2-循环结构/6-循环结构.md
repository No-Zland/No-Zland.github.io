# 1. 固定次数循环：for (初始化表达式; 条件表达式; 更新表达式) {循环体;}

执行流程：①执行初始化表达式 → ②判断条件表达式（为真则执行循环体，否则退出） → ③执行更新表达式 → 重复步骤②-③。

```c
for (初始化表达式; 条件表达式; 更新表达式) {
    循环体;
}
```

示例：输出 1 到 10 的整数

```c
#include <stdio.h>

int main() {
	
    for (int i = 1; i <= 10; i++) {
	    
        printf("%d ", i);
        
    }
    
    return 0;
    
}
```

# 2. 先判断后执行：while (条件表达式) {循环体;}

执行流程：先判断条件表达式，**为真**则执行循环体，重复此过程；若条件一开始为假，循环体一次都不执行。

```c
while (条件表达式) {
    循环体;
}
```

示例：

```c
#include <stdio.h>

int main() {

    int i = 1, sum = 0;
    
    while (i <= 100) {
    
        sum += i;
        
        i++;
        
    }
    
    printf("1到100的和为：%d\n", sum);
    
    return 0;
    
}
```

# 3. 先执行后判断do-while：do {循环体;} while (条件表达式);

执行流程：先执行循环体，再判断条件表达式；若条件为真，继续循环；否则退出。循环体至少执行一次。

```c
do {
    循环体;
} while (条件表达式);
```

示例：输入一个正整数（确保输入有效）

```c
#include <stdio.h>

int main() {

    int num;
    
    do {
    
        printf("请输入一个正整数：");
        
        scanf("%d", &num);
        
    } while (num <= 0);
    
    printf("你输入的正整数是：%d\n", num);
    
    return 0;
}
```

# 4. 循环控制符

## 4.1 跳出当前所在的循环：break 语句

作用：立即跳出当前所在的循环或 switch 结构，执行后续代码。

示例：当找到目标值时跳出循环

```c
#include <stdio.h>

int main() {
	
    int arr[] = {2, 4, 6, 8, 10};
    
    int target = 6, i;
    
    for (i = 0; i < 5; i++) {
	    
        if (arr[i] == target) {
	        
            printf("找到目标值，索引为：%d\n", i);
            
            break;  // 找到后跳出for循环
            
        }
        
    }
    
    return 0;
    
}
```

## 4.2 跳过本次循环：continue 语句

作用：跳过本次循环的剩余代码，直接进入下一次循环的条件判断。

示例：输出 1 到 10 中的奇数

```c
#include <stdio.h>

int main() {
	
    for (int i = 1; i <= 10; i++) {
	    
        if (i % 2 == 0) {
	        
            continue;  // 偶数时跳过本次循环
            
        }
        
        printf("%d ", i);
        
    }
    
    return 0;
    
}
```
