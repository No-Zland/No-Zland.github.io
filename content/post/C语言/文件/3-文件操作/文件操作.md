# 一、文件操作

### 1. 定义

C 语言文件操作是通过标准库函数（核心头文件 <stdio.h>）与外部存储文件（文本文件 .txt/.csv、二进制文件 .jpg/.mp4/.bin 等）进行数据交互的过程。

核心目的是实现**数据持久化存储**（写入文件）和**外部数据读取**（从文件加载），是底层开发、日志记录、数据处理等场景的核心技能。

### 2. 核心流程（必遵循）

所有文件操作严格遵循 “三步曲”，缺一不可，否则会导致资源泄漏或数据丢失：

1. **打开文件**：通过 fopen() 建立程序与文件的连接，获取文件指针（FILE*），这是后续操作的基础；

2. **操作文件**：通过读写函数（如 fread()、fwrite()）实现数据交互；

3. **关闭文件**：通过 fclose() 释放文件资源，确保数据同步到磁盘（避免缓冲区数据丢失）。

### 3. 关键概念

- **文件指针（****FILE*****）**：系统维护的文件描述符结构体指针，记录文件位置、打开模式、缓冲区状态等信息，是所有文件操作的 “桥梁”；

- **文本文件 vs 二进制文件**：文本文件以字符 ASCII 码存储（可直接读取），二进制文件以字节流存储（需按特定格式解析，如图片、视频）；

- **缓冲区**：系统为文件操作分配的临时内存，用于减少磁盘 I/O 次数，fflush() 可手动刷新缓冲区（将数据写入磁盘）。

# 二、核心函数：文件打开与关闭

## 1.  文件打开：FILE *fopen(const char *filename, const char *mode);

### 函数原型

```c
FILE *fopen(const char *filename, const char *mode);
```

- **参数说明**：

- filename：文件路径（相对路径：如 test.txt；绝对路径：如 C:/data/test.txt）；

- mode：打开模式（核心参数，决定操作权限和文件类型）。

- **返回值**：成功返回文件指针（FILE*），失败返回 NULL（需检查错误，如文件不存在、权限不足）。

### 典型示例

```c
#include <stdio.h>

int main() {    // 以“只读”模式打开文本文件（文件必须存在）

    FILE *fp = fopen("test.txt", "r");   
     
    if (fp == NULL) { // 必须检查打开结果  
          
	    perror("fopen error"); 
	    // 打印错误原因（如“No such file or directory”） 
           
	    return 1; // 异常退出    
	    
	}    // 后续文件操作...  
	  
	fclose(fp); // 关闭文件（不可遗漏）    return 0;}
```

## 2.  文件关闭：int fclose(FILE *stream);

#### 函数原型

```c
int fclose(FILE *stream);
```

- **参数说明**：stream 为 fopen() 返回的文件指针；

- **返回值**：成功返回 0，失败返回 EOF（-1，如文件已关闭或指针无效）。

#### 关键注意

- 关闭文件后，文件指针会变为 “野指针”，不可再使用；

- 程序退出前必须关闭所有打开的文件，否则缓冲区数据可能未写入磁盘，导致数据丢失；

- 若多个指针指向同一文件，关闭一次即可。

# 三、文件打开模式（核心重点）

## 1. 模式分类与说明

mode 参数决定文件操作权限和类型，支持文本模式（默认）和二进制模式（加 b），组合使用时需遵循 “权限 + 类型” 规则，以下是常用模式的详细对比：

| 模式  | 类型       | 核心功能                           | 文件不存在时     | 注意事项                             |
| --- | -------- | ------------------------------ | ---------- | -------------------------------- |
| r   | 文本       | 只读（文本模式），指针初始在文件开头             | 报错（ENOENT） | 若文件不存在，fopen() 返回 NULL           |
| w   | 文本       | 只写（文本模式），**覆盖原有内容**，无文件则创建     | 创建新文件      | 慎用！会清空原文件数据，不可逆                  |
| a   | 文本       | 追加（文本模式），指针初始在文件末尾，写入内容追加到尾部   | 创建新文件      | 无法覆盖原有内容，仅能在末尾添加                 |
| r+  | 文本       | 读写（文本模式），指针初始在文件开头，可读取和覆盖写入    | 报错         | 写操作会从当前指针位置覆盖，需用 fseek() 调整指针    |
| w+  | 文本       | 读写（文本模式），先清空原文件，无文件则创建         | 创建新文件      | 适合 “重新写入 + 读取” 场景，如生成临时文件        |
| a+  | 文本       | 读写（文本模式），追加模式（写仅在末尾），读需移动指针到开头 | 创建新文件      | 读前需用 fseek(fp, 0, SEEK_SET) 移动指针 |
| rb  | 二进制      | 只读（二进制模式），用于处理图片、视频等非文本文件      | 报错         | 无需转换换行符，直接操作字节流                  |
| wb  | 二进制      | 只写（二进制模式），覆盖原有字节流，无文件则创建       | 创建新文件      | 常用于文件复制、保存二进制数据（如结构体）            |
| ab  | 二进制      | 追加（二进制模式），在文件末尾添加字节流           | 创建新文件      | 适合日志追加二进制数据（如传感器数据）              |
| x   | 文本 / 二进制 | 独占创建（如 wx/xb），仅当文件不存在时创建并写入    | 创建新文件      | 文件已存在则报错（EEXIST），避免覆盖            |

### 模式使用示例

```c
// 1. 二进制模式复制图片（推荐，避免文本模式转换换行符导致文件损坏）
FILE *src = fopen("source.jpg", "rb"); // 读二进制

FILE *dst = fopen("copy.jpg", "wb");   // 写二进制

if (src == NULL || dst == NULL) {    

	perror("open error");   
	 
	return 1;
	
}// 后续复制操作...

// 2. 追加模式写日志（文本模式）
FILE *log_fp = fopen("app.log", "a");

fprintf(log_fp, "程序启动成功\n"); // 内容追加到文件末尾fclose(log_fp);
```

# 四、文件读写方法（按类型分类）

## 1. 字符读写（单个字符操作）

适合逐字符处理文本文件（如解析配置文件、统计字符数），函数简洁，无格式符依赖。

### （1）fgetc()：读取单个字符

- 函数原型：int fgetc(FILE *stream);

- 功能：从文件指针 stream 指向的文件中读取一个字符（返回 ASCII 码，类型为 int）；

- 返回值：成功返回字符 ASCII 码，失败或读到文件末尾返回 EOF（-1）；

- 典型示例：统计文本文件字符数

```c
#include <stdio.h>

int count_chars(const char *filename) {  
	  
	FILE *fp = fopen(filename, "r");
		
	if (fp == NULL) {
		
	    perror("fopen error");   
		    
	    return -1;   
		     
	}
	
	int count = 0;
	
	int ch; // 必须用int接收（避免EOF与char混淆）    
	
	while ((ch = fgetc(fp)) != EOF) { // 逐字符读取        
	
		count++;    
		
	}    
	
	fclose(fp);    
	
	return count;
	
}

int main() {
	 
	printf("字符数：%d\n", count_chars("test.txt"));  
	  
	return 0;
	
}
```

### （2）fputc()：写入单个字符

- 函数原型：

```c
int fputc(int c, FILE *stream);
```

- 功能：将字符 c（ASCII 码）写入文件指针 stream 指向的文件；

- 返回值：成功返回写入的字符，失败返回 EOF；

- 典型示例：将字符串逐字符写入文件

```c
#include <stdio.h>

void write_str(const char *filename, const char *str) {
	
    FILE *fp = fopen(filename, "w");
	    
        if (fp == NULL) {   
	          
            perror("fopen error");  
                  
            return; 
               
        }    
        
        int i = 0;    
        
        while (str[i] != '\0') {    
	        
            fputc(str[i], fp); // 逐字符写入
                    
            i++;   
             
        }   
         
        fclose(fp);
        
}

int main() {    
	
	write_str("output.txt", "Hello C File!");    
	
	return 0;
	
}
```

## 2. 格式化读写（通用数据类型）

支持整数、浮点数、字符串等多种数据类型，需配合格式符（如 %d、%f、%s），与 printf()/scanf() 用法类似，是最常用的文件读写方式。

### （1）fprintf()：格式化写入

- 函数原型：

```
int fprintf(FILE *stream, const char *format, ...);
```

- 功能：按格式字符串 format 将数据写入文件；

- 返回值：成功返回写入的字符数，失败返回 EOF；

- 典型示例：写入学生信息（结构体）到文本文件

```c
#include <stdio.h>

typedef struct {
	
    char name[20];
	    
    int age;
	        
    float score;
        
} Student;

int main() {

    Student stu = {"Zhang San", 20, 95.5};
    
    FILE *fp = fopen("students.txt", "w");   
     
    if (fp == NULL) {    
    
        perror("fopen error");  
              
        return 1;   
         
    }    // 格式化写入（与printf类似，多了文件指针参数）
     
    fprintf(fp, "姓名：%s 年龄：%d 成绩：%.1f\n", stu.name, stu.age, stu.score);
    
    fclose(fp);
    
	return 0;
	
}
```

### （2）fscanf()：格式化读取

- 函数原型：

```c
int fscanf(FILE *stream, const char *format, ...);
```

- 功能：按格式字符串 format 从文件读取数据，需传递变量地址；

- 返回值：成功返回读取的变量个数，失败返回 EOF，读取不匹配返回小于预期的个数；

- 典型示例：从文件读取学生信息

```c
#include <stdio.h>

typedef struct {    

	char name[20];  
	  
	int age;    
	
	float score;
	
} Student;

int main() {   
 
	Student stu; 
	   
	FILE *fp = fopen("students.txt", "r");    
	
	if (fp == NULL) {    
	
	    perror("fopen error"); 
	           
	    return 1; 
  
	}    // 格式化读取（跳过“姓名：”等前缀，只取数据）
	    
	fscanf(fp, "姓名：%s 年龄：%d 成绩：%.1f", stu.name, &stu.age, &stu.score);
	
	printf("读取结果：%s %d %.1f\n", stu.name, stu.age, stu.score);  
	  
	fclose(fp);    
	
	return 0;
	
}
```

## 3. 字符串读写（专门处理字符串）

针对字符串批量操作，避免逐字符读写的繁琐，fgets() 支持读取含空格字符串，安全性高于已废弃的 gets()。

### （1）fgets()：读取字符串（安全）

- 函数原型：
```c
char *fgets(char *str, int num, FILE *stream);
```

- 功能：从文件读取最多 num-1 个字符（留 1 位存字符串结束符 \0），遇换行符 \n 或文件末尾停止；

- 返回值：成功返回 str 指针，失败或读到文件末尾返回 NULL；

- 典型示例：读取含空格的文本行

```c
#include <stdio.h>

int main() {    

	FILE *fp = fopen("test.txt", "r");   
	 
	if (fp == NULL) {    
	
	    perror("fopen error");  
	          
	    return 1;    
	    
	}    
	
	char buf[1024]; // 缓冲区，存储读取的字符串    // 逐行读取（fgets会保留换行符\n）
	    
	while (fgets(buf, sizeof(buf), fp) != NULL) {  
	  
	    printf("读取行：%s", buf); // 直接输出（含换行符） 
	       
	}    
	
	fclose(fp);  
	  
	return 0;
	
}
```

### （2）fputs()：写入字符串

- 函数原型：

```c
int fputs(const char *str, FILE *stream);
```

- 功能：将字符串 str 写入文件（不自动添加换行符 \n，需手动添加）；

- 返回值：成功返回非负值，失败返回 EOF；

- 典型示例：批量写入多行字符串

```c
#include <stdio.h>

int main() {    

	FILE *fp = fopen("output.txt", "w");    
	
	if (fp == NULL) {    
		
	    perror("fopen error");        
		
	    return 1;    
	
	}    
	
	fputs("第一行文本\n", fp); // 手动加\n换行    fputs("第二行文本（含空格）", fp); 
	   
	fclose(fp);    
	
	return 0;
	
	}
```

## 4. 二进制读写（处理非文本文件）

直接操作字节流，不转换数据格式，适合处理图片、视频、结构体等二进制数据（避免文本模式的换行符转换导致数据损坏）。

### （1）二进制读取：size_t fread(void *ptr, size_t size, size_t nmemb, FILE *stream);

- 函数原型：
```c
size_t fread(void *ptr, size_t size, size_t nmemb, FILE *stream);
```

- 功能：从文件读取 nmemb 个大小为 size 的数据块，存入 ptr 指向的缓冲区；

- 参数说明：

- ptr：缓冲区指针（存储读取的数据）；

- size：单个数据块的字节数（如 sizeof(int)）；

- nmemb：数据块个数；

- stream：文件指针；

- 返回值：成功返回实际读取的 data 块个数（非字节数），失败或读到末尾返回小于 nmemb 的值；

- 典型示例：读取结构体数组（二进制文件）

```c
#include <stdio.h>

typedef struct { 
   
	int id;    
	
	char name[20];    
	
	float score;
	
} Student;

int main() {
	
    Student stus[3];  
      
    FILE *fp = fopen("students.bin", "rb");  
      
    if (fp == NULL) {    
	    
        perror("fopen error");  
          
        return 1;    
    }    
    
    // 读取3个Student类型数据块（每个大小为sizeof(Student)）    
    size_t read_num = fread(stus, sizeof(Student), 3, fp);  
      
    printf("实际读取：%zu 个学生\n", read_num);  
      
    for (int i = 0; i < read_num; i++) {  
	     
        printf("ID：%d 姓名：%s 成绩：%.1f\n", stus[i].id, stus[i].name, stus[i].score);  
          
    }    
    
    fclose(fp);  
      
    return 0;
}
```

### （2）二进制写入：size_t fwrite(const void *ptr, size_t size, size_t nmemb, FILE *stream);

- 函数原型：size_t fwrite(const void *ptr, size_t size, size_t nmemb, FILE *stream);

- 功能：将 ptr 指向的 nmemb 个大小为 size 的数据块，写入文件；

- 返回值：成功返回实际写入的 data 块个数，失败返回小于 nmemb 的值；

- 典型示例：写入结构体数组到二进制文件

```c
#include <stdio.h>

typedef struct {

    int id;    
    
    char name[20]; 
       
    float score;
    
} Student;

int main() {   
 
	Student stus[3] = {  
	  
	    {1, "Zhang San", 95.5},  
	          
	    {2, "Li Si", 88.0},  
	          
	    {3, "Wang Wu", 92.3}  
	      
	};    
	
	FILE *fp = fopen("students.bin", "wb");    
	
	if (fp == NULL) { 
	   
	    perror("fopen error");   
	         
	    return 1;  
	      
	}    // 写入3个Student数据块    
	
	size_t write_num = fwrite(stus, sizeof(Student), 3, fp);    
	
	if (write_num == 3) {   
	 
	    printf("写入成功\n");   
	     
	} else {    
	
	    printf("写入失败，仅写入 %zu 个\n", write_num);  
	     
	}    
	
	fclose(fp);    
	
	return 0;
	
}
```

# 五、特殊操作

## 1. 文件指针定位（随机读写）

文件指针默认按顺序移动，通过以下函数可手动控制指针位置，实现随机读写（如修改文件中间内容）。

### （1）fseek()：移动文件指针：int fseek(FILE *stream, long offset, int whence);

- 函数原型：
```c
int fseek(FILE *stream, long offset, int whence);
```

- 功能：将文件指针移动到指定位置；

- 参数说明：

- offset：偏移量（正数向右移，负数向左移）；

- whence：基准位置（SEEK_SET：文件开头；SEEK_CUR：当前位置；SEEK_END：文件末尾）；

- 返回值：成功返回 0，失败返回 -1；

- 典型示例：修改文件中间的内容

```c
#include <stdio.h>

int main() {  
  
	FILE *fp = fopen("test.txt", "r+"); // 读写模式  
	  
	if (fp == NULL) {    
	
	    perror("fopen error");  
	          
	    return 1;   
	     
	}    // 1. 移动指针到文件第10个字符位置（从开头算，偏移量9，因下标从0开始） 
	   
	fseek(fp, 9, SEEK_SET);    // 2. 写入内容（覆盖当前位置及后续字符） 
	   
	fputs("MODIFY", fp);   
	 
	fclose(fp); 
	   
	return 0;
	
}
```

### （2）获取当前指针位置：long ftell(FILE *stream);

- 函数原型：
```c
long ftell(FILE *stream);
```

- 功能：返回当前文件指针相对于文件开头的偏移量（字节数）；

- 返回值：成功返回偏移量，失败返回 -1；

- 典型示例：计算文件大小

```c
#include <stdio.h>

long get_file_size(const char *filename) {
	
    FILE *fp = fopen(filename, "r");   
     
    if (fp == NULL) {   
	    
        perror("fopen error");    
            
        return -1;   
         
    }    
    
    fseek(fp, 0, SEEK_END); // 移动指针到文件末尾 
       
    long size = ftell(fp); // 末尾偏移量即文件大小 
       
    fclose(fp); 
	  
    return size;
    
}
    
int main() { 
   
	printf("文件大小：%ld 字节\n", get_file_size("test.txt"));  
	  
	return 0;
	
}
```

### （3）重置指针到文件开头：void rewind(FILE *stream);

- 函数原型：

```c
void rewind(FILE *stream);
```

- 功能：等价于 fseek(stream, 0, SEEK_SET)，无返回值；

- 典型示例：先读文件末尾，再重置到开头重读

```c
#include <stdio.h>

int main() {    

	FILE *fp = fopen("test.txt", "r");  
	  
	if (fp == NULL) {    
	    
		perror("fopen error"); 
		   
	    return 1;   
	     
	}    // 移动到末尾    
	
	fseek(fp, 0, SEEK_END);    // 重置到开头  
	  
	rewind(fp);    // 重读文件   
	 
	char buf[1024];    
	
	fgets(buf, sizeof(buf), fp);   
	 
	printf("文件开头：%s", buf);
	    
	fclose(fp);    
	
	return 0;
	
}
```

### 2. 文件复制（二进制模式，通用所有文件）

利用 fread() 和 fwrite() 实现文件复制，支持文本、图片、视频等任意类型文件（推荐二进制模式，避免格式转换错误）。

#### 典型示例：文件复制函数

```c
#include <stdio.h>
#include <stdlib.h> // 包含EXIT_FAILURE#define BUF_SIZE 1024 * 1024 // 1MB缓冲区（平衡速度和内存占用）

int copy_file(const char *src_path, const char *dst_path) {    // 打开源文件（只读二进制）和目标文件（只写二进制）
	
    FILE *src = fopen(src_path, "rb");  
      
    FILE *dst = fopen(dst_path, "wb");   
     
    if (src == NULL || dst == NULL) {   
	    
        perror("open error");        // 关闭已打开的文件（避免资源泄漏）        
        
        if (src != NULL) fclose(src);        
        
        if (dst != NULL) fclose(dst);        
        
        return -1;    
    }    
    
    char buf[BUF_SIZE];    
    
    size_t read_num, write_num;    // 分块读取并写入（大文件不占满内存）    
    
    while ((read_num = fread(buf, 1, BUF_SIZE, src)) > 0) {    
        
        write_num = fwrite(buf, 1, read_num, dst);        
        
        if (write_num != read_num) { // 写入字节数不匹配，复制失败            
	        
	        perror("write error");            
	        
	        fclose(src);            
	        
	        fclose(dst);            
	        
	        return -1;        
	    
	    }    
	
	}    // 检查读取是否出错    
	
	if (ferror(src)) {    
	    
	    perror("read error");        
	    
	    fclose(src);        
	    
	    fclose(dst);        
	    
	    return -1;    
	
	}    
	
	printf("文件复制成功！\n");    
	
	fclose(src);    
	
	fclose(dst);    
	
	return 0;
	
}

int main() {
	
    if (copy_file("source.mp4", "copy.mp4") != 0) {    
	    
        return EXIT_FAILURE;    
        
    }    
        
    return 0;
    
}
```

### 3. 文件加密 / 解密（简单异或加密）

通过二进制读写修改文件字节流，实现简单加密（异或同一个密钥，加密和解密逻辑相同）。

#### 典型示例：文件异或加密 / 解密

```c
#include <stdio.h>
#define KEY 0x99 // 加密密钥（0-255任意值）

int encrypt_file(const char *in_path, const char *out_path) {

    FILE *in = fopen(in_path, "rb");
    
    FILE *out = fopen(out_path, "wb");  
      
    if (in == NULL || out == NULL) {   
     
        perror("open error");    
            
        if (in != NULL) fclose(in); 
               
        if (out != NULL) fclose(out);  
              
        return -1;    
    }    
    
    int ch; 
       
    while ((ch = fgetc(in)) != EOF) {  
      
        fputc(ch ^ KEY, out); // 异或密钥加密  
          
    }    
    
    fclose(in); 
       
    fclose(out);  
      
    printf("加密/解密完成！\n");   
     
    return 0;
    
}

int main() {    // 加密：source.txt → encrypted.txt

    encrypt_file("source.txt", "encrypted.txt");   
     
    // 解密：encrypted.txt → decrypted.txt（与加密用同一函数） 
       
    encrypt_file("encrypted.txt", "decrypted.txt");   
     
    return 0;
    
}
```

### 4. 批量处理文件（遍历目录下文件）

结合 <dirent.h> 头文件（Linux/macOS）或 Windows API，遍历目录下所有文件并批量操作（如批量转换格式、批量加密）。

#### 典型示例（Linux/macOS）：遍历目录下所有.txt 文件并统计字符数

```c
#include <stdio.h>
#include <dirent.h>
#include <string.h>
// 统计单个文本文件字符数（复用之前的函数）

int count_chars(const char *filename) {
	
	FILE *fp = fopen(filename, "r");
	
	if (fp == NULL) {
		
		perror("fopen error");
		
		return -1;
		
	}
	
	int count = 0;
	
	int ch;
	
	while ((ch = fgetc(fp)) != EOF) count++;
	
	fclose(fp);
	
	return count;
	
}

int main() {
	
	const char *dir_path = "."; // 当前目录
	
	DIR *dir = opendir(dir_path);
	
	if (dir == NULL) {
		
		perror("opendir error");
		
		return 1;
		
	}
	
	struct dirent *entry;
	
	// 遍历目录下所有文件
	while ((entry = readdir(dir)) != NULL) {
		
		// 筛选.txt后缀的文件
		char *suffix = strrchr(entry->d_name, '.');
		
		if (suffix != NULL && strcmp(suffix, ".txt") == 0) {
			
			// 拼接文件路径（当前目录+文件名）
			char file_path[256];
			
			snprintf(file_path, sizeof(file_path), 
			"%s/%s", dir_path, entry->d_name);
			
			int chars = count_chars(file_path);
			
			if (chars != -1) {
				
				printf("文件：%s 字符数：%d\n", entry->d_name, chars);
				
			}
			
		}
		
	}
	
	closedir(dir);
	
	return 0;
	
}
```

# 六、异常处理与错误排查

C 语言无异常捕获机制，需通过检查函数返回值和使用错误处理函数排查问题：

## 1. 核心错误处理函数

- perror(const char *s)：打印系统错误信息（如 “No such file or directory”），前缀为 s；

- ferror(FILE *stream)：检查文件操作是否出错，返回非 0 表示出错；

- clearerr(FILE *stream)：清除文件错误标志和 EOF 标志，恢复文件操作；

#### 示例：错误处理完善的文件读取

```c
#include <stdio.h>

int main() {
	
    FILE *fp = fopen("test.txt", "r");
    
    if (fp == NULL) {   
		
        perror("fopen failed"); // 打印打开错误   
	    
        return 1;    
	    
    }    
    
    char buf[1024];   
     
    if (fgets(buf, sizeof(buf), fp) == NULL) { 
	       
        if (ferror(fp)) { // 检查是否是读取错误  
              
            perror("fgets failed");    
            
        } else { // 是文件末尾，正常情况 
            
            printf("文件为空\n");  
             
        }      
          
        fclose(fp);  
        
        return 1;    
    }    
    
    fclose(fp);
    
    return 0;
}
```

## 2. 常见错误及解决方案

| 错误现象            | 可能原因                  | 解决方案                            |
| --------------- | --------------------- | ------------------------------- |
| fopen() 返回 NULL | 文件不存在、路径错误、权限不足       | 检查路径是否正确、文件是否存在、权限是否足够          |
| 文本文件换行符混乱       | 用文本模式打开二进制文件（自动转换换行符） | 处理非文本文件时强制用二进制模式（rb/wb）         |
| 二进制文件损坏         | 用文本模式读写二进制文件          | 统一使用二进制模式，避免格式转换                |
| 数据写入不生效         | 未关闭文件且未刷新缓冲区          | 用 fclose() 关闭文件或 fflush() 刷新缓冲区 |
| fscanf() 读取不完整  | 格式符与文件内容不匹配           | 确保格式符与文件数据格式一致（如跳过前缀）           |

# 七、实践注意（避坑指南）

1. **始终检查函数返回值**：fopen()、fread()、fwrite() 等函数必须检查返回值，避免使用无效指针或未成功读写的数据；

2. **优先使用二进制模式处理非文本文件**：图片、视频、结构体等数据，用 rb/wb 模式，避免文本模式的换行符转换导致数据损坏；

3. **及时关闭文件**：文件操作完成后立即用 fclose() 关闭，避免资源泄漏和缓冲区数据丢失；

4. **合理设置缓冲区大小**：批量读写时（如文件复制），用 1MB-10MB 缓冲区（平衡速度和内存占用），避免频繁磁盘 I/O；

5. **跨平台路径处理**：Linux/macOS 用 / 分隔路径，Windows 用 \，推荐用 snprintf() 拼接路径（如 snprintf(path, sizeof(path), "%s/%s", dir, file)）；

6. **避免使用已废弃函数**：gets()、fscanf(fp, "%[^\n]")（易缓冲区溢出），替换为 fgets()；

7. **加密 / 敏感操作前备份**：修改、加密文件前，先备份原始文件，避免不可逆损失。
