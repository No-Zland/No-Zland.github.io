```cpp
#include <iostream>
using namespace std;
using ll = long long;

int main() {
    int T;
    cin >> T;
    while (T--) {
        ll x;
        cin >> x;
        
        // 统计位数
        int k = 0;
        ll t = x;
        while (t > 0) {
            k++;
            t /= 10;
        }
        
        // 计算 10^k
        ll power = 1;
        for (int i = 0; i < k; i++) {
            power *= 10;
        }
        
        // 输出 10^k + 1
        cout << power + 1 << endl;
    }
    return 0;
}
```
### 二、考察的知识点

#### 1. **数位统计（Digit Counting）**

- **算法思想**：通过不断除以10来统计一个数的十进制位数
    
- **时间复杂度**：O(log₁₀ n)
    
- **关键操作**：`t /= 10` 每次去掉最后一位
    

#### 2. **幂运算的整数实现**

- **避免浮点误差**：用循环乘法代替 `pow()` 函数
    
- **算法思想**：累乘10 k次，得到10^k
    
- **时间复杂度**：O(k) = O(log₁₀ n)
    

#### 3. **循环结构的使用**

- 外层循环：处理多组测试数据
    
- 内层循环：统计位数和计算幂
    

#### 4. **数据类型的选择**

- `long long`：处理可能的大数（10^18级别）
    
- 注意乘法溢出问题
    

### 三、解题思路详解

#### 步骤1：理解题目要求

题目要求：对于每个输入的数x，输出一个形如 **10^k + 1** 的数，其中k是x的十进制位数。

#### 步骤2：统计位数

cpp

int k = 0;
ll t = x;
while (t > 0) {
    k++;
    t /= 10;
}

- 每次除以10，相当于去掉最后一位
    
- 直到t变为0，此时循环次数就是位数
    
- **例如**：x = 12345
    
    - 第1次：12345 → 1234 (k=1)
        
    - 第2次：1234 → 123 (k=2)
        
    - 第3次：123 → 12 (k=3)
        
    - 第4次：12 → 1 (k=4)
        
    - 第5次：1 → 0 (k=5)
        
    - 结果：k=5
        

#### 步骤3：计算10^k

cpp

ll power = 1;
for (int i = 0; i < k; i++) {
    power *= 10;
}

- 从1开始，连续乘以10 k次
    
- **为什么不用pow()**：pow返回double，可能精度丢失
    
- **例如**：k=5
    
    - i=0: power=1×10=10
        
    - i=1: power=10×10=100
        
    - i=2: power=100×10=1000
        
    - i=3: power=1000×10=10000
        
    - i=4: power=10000×10=100000
        
    - 结果：10^5 = 100000
        

#### 步骤4：加1输出

cpp

cout << power + 1 << endl;

- 在10^k的基础上加1
    
- **例如**：
    
    - 输入123（3位）→ 10³ + 1 = 1001
        
    - 输入9（1位）→ 10¹ + 1 = 11
        
    - 输入1000（4位）→ 10⁴ + 1 = 10001
        

### 四、算法复杂度分析

- **时间复杂度**：O(T × log₁₀ x)
    
    - T：测试数据组数
        
    - log₁₀ x：统计位数和计算幂的循环次数
        
- **空间复杂度**：O(1)
    
    - 只使用了常数个变量
        

### 五、边界情况处理

1. **x = 0 的情况**
    
    - 原代码中 `while(t > 0)` 会直接跳过，k=0
        
    - 10⁰ + 1 = 1 + 1 = 2（合理）
        
2. **大数情况**
    
    - long long 最大约 9.2×10¹⁸
        
    - 10¹⁸ + 1 在范围内
        
3. **多组测试数据**
    
    - 使用 while(T--) 正确处理
