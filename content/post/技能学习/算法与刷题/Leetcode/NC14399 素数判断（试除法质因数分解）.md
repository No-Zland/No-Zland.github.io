# 题目描述
给出一个数x，判断它是否为素数，并输出所有它的素因子。
## 输入描述：
第1行输入组数T，代表有T组数据。
第2-T+1行每行输入一个数x表示对应询问。
数据保证：2≤x≤10⁹
## 输出描述：
对于每组询问输出两行表示结果。
第1行，如果x是素数，输出“isprime”（不含双引号），否则输出“noprime”（不含双引号）。
第2行，输出x的素因子。
## 示例1
### 输入
```text
3
2
9
10
```
### 输出
```text
isprime
2
noprime
3
noprime
2 5
```
---
```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int T;
    cin >> T;
    while (T--) {
        int x;
        cin >> x;
        int temp = x;
        vector<int> factors;      // 存储不重复的素因子
        // 处理因子 2
        if (temp % 2 == 0) {
            factors.push_back(2);
            while (temp % 2 == 0) temp /= 2;   // 除尽所有 2
        }
        // 处理奇数因子
        for (int i = 3; i <= temp / i; i += 2) {
            if (temp % i == 0) {
                factors.push_back(i);           // 记录第一次出现的 i
                while (temp % i == 0) temp /= i; // 除尽所有 i
            }
        }
        // 如果剩余 temp > 1，它本身是一个素因子
        if (temp > 1) {
            factors.push_back(temp);
        }
        // 判断素数：如果 factors 只有 x 本身，则是素数
        if (factors.size() == 1 && factors[0] == x) {
            cout << "isprime\n" << x << "\n";
        } else {
            cout << "noprime\n";
            for (size_t i = 0; i < factors.size(); i++) {
                if (i > 0) cout << " ";
                cout << factors[i];
            }
            cout << "\n";
        }
    }
    return 0;
}
```

本题的核心是**质因数分解**：将一个正整数 xx 分解为若干素数的乘积，并输出所有不同的素因子。同时需要判断 xx 本身是否为素数。
## 1. 基本方法：试除法
对于任意合数 nn，其最小的素因子一定不超过 nn​。因此，我们只需枚举 22 到 nn​ 的所有整数，尝试是否能整除 nn。一旦找到一个因子，就说明 nn 不是素数。
## 2. 高效分解并去重
- **处理因子 2**：先单独处理因子 2，因为 2 是唯一的偶素数。如果 xx 能被 2 整除，则将 2 加入答案，并用 `while` 循环将 xx 中所有的因子 2 除尽。
- **处理奇数因子**：从 3 开始，以步长 2 枚举奇数 ii，直到 i×i≤当前剩余的 xi×i≤当前剩余的 x。如果当前 xx 能被 ii 整除，则：
    
    - 将 ii 加入答案（只加一次）。
        
    - 用 `while` 循环将 xx 中所有的因子 ii 除尽（即反复除以 ii，直到不能整除为止）。
        
- **处理剩余部分**：当上述循环结束后，如果剩余的 x>1x>1，则说明它本身是一个大于 原数原数​ 的素数因子，将其加入答案。
#### 3. 判断素数
- 如果答案中只有一个因子，且该因子等于原始输入的 xx，则 xx 是素数，输出 `"isprime"`，并输出 xx。
- 否则，输出 `"noprime"`，并按顺序输出答案中的所有素因子（空格分隔）。
#### 4. 复杂度分析
- 时间复杂度：O(x)O(x​)。对于 x≤109x≤109，最多枚举约 3162331623 次，完全满足题目时间要求。
- 空间复杂度：O(log⁡x)O(logx)，只需存储少量素因子。
#### 5. 注意事项
- 循环条件使用 `i <= x / i` 而不是 `i * i <= x`，可以有效防止乘法溢出（虽然本题 x≤109x≤109 不易溢出，但这是良好编程习惯）。
- 输入输出优化：使用 `ios::sync_with_stdio(false); cin.tie(nullptr);` 加速 C++ 标准 IO，避免因大量数据导致超时。
- 输出格式：每组结果占两行，第二行末尾无多余空格，且每个素因子之间用空格隔开。
