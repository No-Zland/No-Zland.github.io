# 题目背景
IEEE 二进制浮点数算术标准（IEEE 754）是20世纪80年代以来最广泛使用的浮点数运算标准，为许多 CPU 与浮点运算器所采用。银行家舍入法（Banker's Rounding），又称“向偶数舍入”（round half to even），是 IEEE 754 推荐的默认舍入方式。
# 题目描述
小 P 的实验表格里有 \(n\) 个形如 `xxx.x` 的、保留一位小数的非负实数，其中：
* 小数点前的 `xxx` 表示整数部分 \(a\)，为任意非负整数；
* 小数点后的 `x` 表示小数部分 \(b\)，为一位数字，取值 0-9；
* \(a\) 可以是任意位数（如 `2026`、`531` 或 `0`）；\(b\) 必为一位，且当 \(b=0\) 时不会省略（如 `13.0`）。
为方便统计分析，小 P 想将它们都近似为整数，具体定义两种计算方式。
1. 四舍五入法
* 当 \(0 \le b \le 4\) 时，向下舍去，结果为 \(a\)；
* 当 \(5 \le b \le 9\) 时，向上进位，结果为 \(a + 1\)。
2. 银行家舍入法（向偶数舍入）
* 当 \(b \neq 5\) 时，处理与四舍五入法一致（\(b \le 4\) 向下、\(b \ge 6\) 向上）。
* 当 \(b = 5\) 时，由于 \(a + 0.5\) 与相邻整数 \(a\) 和 \(a + 1\) 的距离相同，为避免系统性偏差，向偶数舍入：若 \(a\) 为偶数，则结果为 \(a\)；否则结果为 \(a + 1\)。
现给出小 P 表格中的 \(n\) 个实数（格式如上）。对每个实数，分别计算上述两种方法的取整结果。
# 输入格式
从标准输入读入数据。
* 第一行包含一个正整数 \(n\)，表示实数个数。
* 接下来输入 \(n\) 行，每行一个实数，格式与题目描述相符。建议按字符串读取并按规则解析（以避免浮点解析误差），也可采用其他合理方式处理。
# 输出格式
输出到标准输出。
输出共两行：
* 第一行输出空格分隔的 \(n\) 个整数，表示采用四舍五入法得到的结果；
* 第二行输出空格分隔的 \(n\) 个整数，表示采用银行家舍入法得到的结果。
# 样例输入
```text
4
7.5
0.0
13.9
2026.5
```
# 样例输出
```
8 0 14 2027
8 0 14 2026
```
# 样例解释
对于最后一个实数 2026.5，采用四舍五入法进位到 2027，而采用银行家舍入法则取相邻的偶数 2026。
# 子任务
50% 的测试数据满足：不存在小数部分 $(b=5)$ 的情况，即两种舍入方法结果相同；
全部的测试数据满足：$n \le 100$ 且每个实数的整数部分 $a \le 10^5$。
# 提示
不同编程语言的内置函数（如 `round()`）可能采用不同的舍入策略，建议按照题目描述自行实现上述两种舍入算法。
## 两种舍入规则整理
1. **四舍五入**
- 小数部分 $(<(0.5))$：舍去小数，保留整数部分
- 小数部分 $\ge(0.5)$：整数部分 $(+1)$
1. **银行家舍入（四舍六入五成双）**
- 小数 $(<(0.5))$：舍去
- 小数 $(>(0.5))$：进1
- 小数恰好等于 $(0.5)$：看整数部分，**奇数进1，偶数不变**，结果为偶数
```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    cin >> n;
    vector<long long> a(n);
    vector<int> b(n);
    for (int i = 0; i < n; ++i) {
        string s;
        cin >> s;
        size_t pos = s.find('.');
        string intPart = s.substr(0, pos);
        long long x = 0;
        for (char c : intPart) {
            x = x * 10 + (c - '0');
        }
        a[i] = x;
        b[i] = s[pos + 1] - '0';
    }
    // 四舍五入
    for (int i = 0; i < n; ++i) {
        long long ans = a[i] + (b[i] >= 5 ? 1 : 0);
        cout << ans << (i + 1 == n ? '\n' : ' ');
    }
    // 银行家舍入
    for (int i = 0; i < n; ++i) {
        long long ans;
        if (b[i] < 5) {
            ans = a[i];
        } else if (b[i] > 5) {
            ans = a[i] + 1;
        } else {
            // b[i] == 5，向偶数舍入
            ans = a[i] + (a[i] % 2);
        }
        cout << ans << (i + 1 == n ? '\n' : ' ');
    }
    return 0;
}
```
