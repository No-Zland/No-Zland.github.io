# 题目背景
众所周知，西西艾弗岛上的机器人喜欢吃苹果。
# 题目描述
管理员小P会定期向机器人宿舍投放苹果。已知初始（第0天）有 $n$ 个苹果。从第1天起，每天按如下流程进行：
- 根据经验，每天约有 $k$ 的苹果会变质。若前一天剩余 $t$ 个苹果，则可近似认为有 $\left\lceil \frac{t\cdot k}{100} \right\rceil$ 个会变坏（其中 $\lceil\cdots\rceil$ 表示向上取整）。
丢弃所有坏苹果后，每个机器人会食用一个苹果。
显然，宿舍中如果入住过多机器人，每次投放的 $n$ 个苹果可能很快就被吃光了。小P希望这些苹果至少够机器人们吃 $m$ 天，试计算宿舍中最多可以入住多少机器人。
注：“至少够吃 $m$ 天”意味着当第 $m$ 天每个机器人都食用一个苹果后，剩余苹果数量大于或等于零；剩余苹果是否还够第 $(m+1)$ 天食用则与本题无关。
# 输入格式
从标准输入读入数据。
输入仅一行，包含空格分隔的三个正整数 $n(n、k)k$ 和 $m$，分别表示初始苹果数量(n、k)每日损耗比例和食用天数。
# 输出格式
输出到标准输出。
输出一个正整数，表示宿舍中最多可入住机器人数量。
# 样例1输入
```
1000 1 5
```
# 样例1输出

```
194
```
# 样例1解释
当宿舍中入住194个机器人时，每日消耗苹果数量如下表所示：

| 苹果数量 | 第0天  | 第1天 | 第2天 | 第3天 | 第4天 | 第5天 |
| ---- | ---- | --- | --- | --- | --- | --- |
| 变质   |      | 10  | 8   | 6   | 4   | 2   |
| 食用   |      | 194 | 194 | 194 | 194 | 194 |
| 剩余   | 1000 | 796 | 594 | 394 | 196 | 0   |

```cpp
#include <bits/stdc++.h>
using namespace std;
typedef long long ll;
ll n, k, m;
// 判断 x 个机器人是否能吃满 m 天
bool check(ll x) {
    ll t = n;                 // 当前苹果数
    for (int day = 0; day < m; ++day) {
        ll bad = (t * k + 99) / 100;  // 向上取整的变质数
        t -= bad;
        if (t < x) return false;      // 不够吃
        t -= x;                       // 每个机器人吃一个
    }
    return true;
}
int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    cin >> n >> k >> m;
    ll l = 1, r = min(n, (ll)1000000000), ans = 0;
    while (l <= r) {
        ll mid = (l + r) / 2;
        if (check(mid)) {
            ans = mid;
            l = mid + 1;
        } else {
            r = mid - 1;
        }
    }
    cout << ans << '\n';
    return 0;
}
```
