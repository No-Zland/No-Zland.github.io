- 核心定位：微软出品的全功能集成开发套件，支持多语言开发的 "专业级工具"。
- 核心特性：
    - 主打 Windows 平台开发，支持 C/C++、C#、Python 等数十种语言，内置 MSVC 编译器（可额外配置 GCC）；
    - 提供智能代码提示、实时调试、性能分析、团队协作等企业级功能，调试能力远超轻量级 IDE；
    - 社区版（Community）免费开放，专业版 / 企业版需付费订阅。
- 适配场景：Windows 平台大型应用开发、游戏引擎开发、多语言混合编程，适合进阶学习与职业开发。

- 官方下载：Visual Studio 2022 社区版
- 安装要点：
    - 下载后运行安装器，必须勾选 "使用 C++ 的桌面开发" 工作负载（含 MSVC 编译器）；
    - 可选勾选 "MinGW 工具集" 以兼容 GCC 编译环境；
    - 安装路径建议保留默认，占用磁盘空间约 20-30GB，需耐心等待。
