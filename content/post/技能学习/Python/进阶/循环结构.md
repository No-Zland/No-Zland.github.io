循环用于重复执行代码块，Python 提供for循环（适合遍历序列）和while循环（适合条件循环）。
## 1. for 循环

for循环通过遍历序列（列表、元组、字符串、字典等）或迭代器执行循环。

### 1.1 基本语法

```python

for 变量 in 序列:

	循环块
```
#### 1.1.1 else子句

`for`循环可搭配`else`，当循环**正常结束**（未被`break`中断）时执行`else`代码块

```python

for i in range(3): 
   
	print(i)else:  
	  
print("循环正常结束") 
 
# 输出顺序：0 1 2 循环正常结束
```

#### 1.1.2 range (start, stop, step) 函数

生成整数序列（start默认 0，step默认 1，**不包含 stop**），常用于固定次数循环。
生成 1-5 的整数（步长 1）

```python

for i in range(1, 6):

	print(i, end=" ")
```

生成1-10的奇数（步长2）

```python

pythonfor i in range(1, 11, 2):   
 
print(i, end=" ")1 3 5 7 9 |
```

### 1.2 遍历

可直接遍历列表、元组、字符串、集合等，变量依次取序列中的元素。

#### 1.2.1 遍历列表
```python
fruits = ["apple", "banana", "cherry"]

for fruit in fruits:    
	
	print(fruit)  

# 依次输出：apple banana cherry
```

#### 1.2.2 遍历字符串（按字符）
```python
s = "hello"

for char in s:    

	print(char)  

# 依次输出：h e l l oelse:    

print("循环正常结束")  

# 循环正常结束
```


#### 1.2.3 遍历字典

以字典person = {"name": "Alice", "age": 20, "gender": "female"}为例：

##### keys () 遍历键.

```python
for key in person.keys():

	print(key, end = " ")

# 输出：
# name age gender
```

##### .values() 遍历值

```python
for value in person.values():    

	print(value, end=" ")
	
# 输出：
# Alice 20 female
```

##### .items()（遍历键值对） 

```python
for k, v in person.items():  
  
	print(f"{k}: {v}")
	
# 输出：
# input name: Alice 等
```

## 2. while 循环

### 2.1 基本语法

`while`循环通过判断条件是否为`True`决定是否执行循环体。

```python
while 条件表达式:  
	  
	循环体
```
### 2.2 条件判断

每次循环**开始前**判断条件：条件为`True`则执行循环体，条件为`False`则退出循环。

### 2.3 避免死循环

循环体内必须包含**修改条件的语句**（如计数器递增/递减），否则条件始终为`True`，导致无限循环。

### 2.4 else子句

与`for`循环类似：`while`循环**正常结束**（条件变为`False`）时执行`else`代码块；
若被`break`中断，则不执行`else`。

示例：
```python
# 1. 基本用法：计数到5
count = 1

while count <= 5:  
	
	print(count)  
	 
	count += 1  # 关键：更新条件，避免死循环
	
# 输出：1 2 3 4 5
```

```python
# 2. while-else：条件不满足时执行else 
num = 3

while num > 0:    
	
	print(num)    
	
	num -= 1
	
else:   
	
	print("num变为0，循环结束")  
	
# 输出顺序：3 2 1 num变为0，循环结束
```
### 2.5 无限循环（需手动中断，如用break）

示例：输入 "quit" 退出循环

```python
while True:    
	
	s = input("输入内容（输入'quit'退出）：")    
	
	if s == "quit":        
	
	break  # 中断循环（见下文循环控制）    

print(f"你输入了：{s}")
```

## 3. break 与 continue（循环控制）

用于改变循环的执行流程，仅作用于**当前所在层级的循环**。

### 3.1 break

- **作用**：立即终止当前所在的循环（跳出循环体），后续循环不再执行。

- **特性**：嵌套循环中，仅终止当前层级的循环，不影响外层循环。

### 3.2 continue

- **作用**：跳过当前轮次循环的剩余代码，直接进入下一次循环的条件判断。

- **特性**：不终止循环，仅跳过当前轮次的后续逻辑。

#### 示例代码

```python
# 1. break：找到目标元素后终止循环
nums = [1, 3, 5, 7, 9]

target = 5

for num in nums:
    
    if num == target:    
		
        print(f"找到目标：{num}")    
		
    break  # 找到后立即跳出循环    
	
	print(f"当前元素：{num}") # 输出：
	# 当前元素：1
	# 当前元素：3
	# 找到目标：5

# 2. continue：跳过偶数，只打印奇数
for i in range(1, 10):    
	
	if i % 2 == 0:        
	
	continue  # 偶数时跳过后续打印逻辑    
	
	print(i, end=" ")  # 输出：1 3 5 7 9
	
# 3. 嵌套循环中的break（仅终止内层循环）
for i in range(2):
    
    for j in range(3):    
        
        if j == 1:    
            
            break  # 只终止内层循环（j的循环）        
			
            print(f"i={i}, j={j}")
			
# 输出：
# i=0, j=0
# i=1, j=0
```
