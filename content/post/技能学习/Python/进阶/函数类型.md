在 Python 中，函数本身可以作为一种数据类型，这意味着可以将一个函数作为参数传递给另一个函数。
# 一、def（函数定义）

函数是封装可复用逻辑的代码块，通过 def 关键字定义，核心是 “输入参数→处理逻辑→返回结果” 的封装。

## 1. 基本形式

```python
def 函数名(参数列表):
	
	函数体
```

### 1.1 函数名

遵循标识符规则（字母、数字、下划线，不能以数字开头）。

```python
# 定义一个简单的加法函数
def add(a, b):

    result = a + b
    
	return result  # 返回结果（见“返回值”部分）
```

### 1.2 函数参数

参数是函数的输入，Python 支持多种参数类型，灵活适应不同调用场景。

1. **正确调用**：`foo(hello)`
    把 `hello` 函数作为参数传给 `foo`，`foo` 内部调用 `hello()`，会打印 “hello”，这是正确的。
    
2. **错误调用 1**：`foo(hello())`
    这里先调用 `hello()`，但 `hello` 无返回值，相当于把 `None` 传给 `foo`。`foo` 内部尝试调用 `None()`，但 `None` 不是可调用对象，会报 `'NoneType' object is not callable` 错误。
    
3. **错误调用 2**：foo(add)
    把 `add` 函数传给 `foo`，`foo` 内部调用 `sum()`，但 `add` 需要两个参数 `a` 和 `b`，
    此处未传，会报 `add() missing 2 required positional argument` 错误。

#### 1.2.1 位置参数

* 要点：必须按参数定义的顺序传递，数量需与形参一致。

* 特性：最基础的参数类型，调用时 “位置对应”。

```python
def greet(name, age):

    print(f"Hello, {name}! You are {age} years old.")

greet("Alice", 20)  

# 位置对应：name="Alice"，age=20 → 输出：Hello, Alice! You are 20 years old.
```

#### 1.2.2 关键字参数

* 要点：调用时通过 参数名 = 值 指定，可忽略顺序。
* 特性：提高代码可读性，适合参数较多的场景。
示例：

```python
greet(age=20, name="Bob")  # 输出：Hello, Bob! You are 20 years old.
```

#### 1.2.3 默认参数

* 要点：定义时指定参数名 = 默认值，调用时可省略该参数（使用默认值）。

* 特性：默认参数必须放在位置参数之后；默认值建议为不可变对象（如 int、str，避免 list 等可变对象的陷阱）。

示例：带默认参数的函数（country 默认值为 "China"）

```python
def introduce(name, country="China"):
	
    print(f"I'm {name}, from {country}.")
	
introduce("Li Hua")  # 省略country，使用默认值 → 输出：I'm Li Hua, from China.

introduce("Anna", "USA")  # 覆盖默认值 → 输出：I'm Anna, from USA.
```

#### 1.2.4 不定长参数

用于处理参数数量不确定的场景，分两种：

##### \*args（打包为元组）

* 要点：收集多余的位置参数，打包为元组（tuple）。

* 特性：\* 是关键，args 约定俗成的变量名（可换其他名称）。

```python
# 计算任意个数字的和

def sum_all(*args):
	
    print("参数元组：", args)  # args是元组
	
    return sum(args)
	
print(sum_all(1, 2, 3))  # 输出：参数元组：(1, 2, 3) → 6

print(sum_all(10, 20))   # 输出：参数元组：(10, 20) → 30
```

##### \*\*kwargs（打包为字典）

* 要点：收集多余的关键字参数，打包为字典（dict）。

* 特性：\*\* 是关键，kwargs 是约定俗成的变量名。

```python
# 打印任意个关键字参数

def print_info(**kwargs):
	
	print("参数字典：", kwargs)  # kwargs是字典
	
	for k, v in kwargs.items():
		
	    print(f"{k}: {v}")
		
print_info(name="Alice", age=20, gender="female")

# 输出：
# 参数字典： {'name': 'Alice', 'age': 20, 'gender': 'female'}
# name: Alice
# age: 20
# gender: female
```

##### 混合使用

参数顺序需遵循：位置参数 → 默认参数 → \*args → \*\*kwargs。



```python
def func(a, b=0, *args, **kwargs):

    print(f"a={a}, b={b}, args={args}, kwargs={kwargs}")

func(1, 2, 3, 4, x=5, y=6)

# 输出：a=1, b=2, args=(3, 4), kwargs={'x': 5, 'y': 6}
```

### 1.3 lambda 参数：表达式（匿名函数）

为了解决上述需要频繁定义新函数的麻烦，引入 lambda 表达式（匿名函数）。

lambda 表达式的格式为 `lambda [参数]: 函数体`，它可以快速定义一个临时的匿名函数。

在案例中，可用 `foo(lambda: sum(3, 4))` 来替代额外定义 `md` 函数的方式，直接在调用时通过 lambda 表达式指定函数逻辑，简洁高效。

简言之，匿名函数是无需定义名称的简洁函数，用 lambda 关键字创建，适合简单逻辑。

参数可多个（用逗号分隔），表达式结果即返回值。

#### 1.3.1 限制

仅能包含一个表达式（不能有循环、if-else（但可嵌套表达式）等复杂逻辑）。

#### 1.3.2 用途

通常作为参数传递给高阶函数（如 map、sorted），避免定义单独函数。

#### 1.3.3 示例代码



```python
# 等价于def add(a,b): return a+b

add = lambda a, b: a + b

print(add(3, 5))  # 输出：8

# 带条件的lambda（表达式内嵌套条件）

max_num = lambda x, y: x if x > y else y

print(max_num(10, 20))  # 输出：20

# 作为参数传递（见下文高阶函数）
```

# 二、函数调用

通过函数名 (实参列表) 调用，实参与形参需匹配（数量、类型兼容）。



```
\# 定义一个简单的加法函数

def add(a, b):

&#x20;   result = a + b

&#x20;   return result  # 返回结果（见“返回值”部分）

\# 调用函数

print(add(3, 5))  # 输出：8
```

## 1. return 表达式（返回值）

函数通过 return 语句将结果返回给调用者。

### 1.1 基本形式



```python
return 表达式
```

执行到 return 时函数立即结束。



```python
# 单值返回

def square(x):
	
    return x **2
	
print(square(3))  # 输出：9
```

### 1.2 特性

#### 1.2.1 多值返回

可返回多个值（用逗号分隔），实际会被打包为元组，调用时可解包。

```python
# 多值返回（打包为元组）

def get_info():
	
    name = "Alice"
	
    age = 20
	
    return name, age  # 等价于 return (name, age)
	
info = get_info()

print(info)  # 输出：('Alice', 20)（元组）

name, age = get_info()  # 解包

print(name, age)  # 输出：Alice 20
```

#### 1.2.2 无返回值

若未写 return 或仅写 return，默认返回 None。



```python
# 无返回值（默认返回None）

def say_hello():
	
    print("Hello")
	
result = say_hello()

print(result)  # 输出：None
```

## 2. 函数嵌套

函数内部可定义另一个函数（内层函数），形成嵌套结构。

### 2.1 要点与特性

#### 作用域（单向性）

内层函数可访问外层函数的变量，但外层函数不能访问内层函数的变量。

#### 封装性

内层函数对外层不可见，仅在外部函数内部可用，实现 “局部功能封装”。

#### 示例代码

```python
def outer():
	
    x = 10  # 外层函数变量
	
    def inner():
		
        y = 20  # 内层函数变量
		
        print(f"内层访问外层变量：x={x}")  # 合法：内层可访问外层
		
        print(f"内层变量：y={y}")
        
    inner()  # 外层函数内部调用内层函数
    
    # print(y)  # 错误：外层不能访问内层变量
	
outer()

# 输出：
# 内层访问外层变量：x=10
# 内层变量：y=20
```

# 三、高阶函数

高阶函数指接受函数作为参数或返回函数的函数，Python 内置的 map、filter、sorted 是典型例子。

## 1. map(func, iterable)

### 1.1 作用

将 func 应用于 iterable（可迭代对象，如列表、元组）的每个元素，返回迭代器（需转换为列表查看结果）。



```python
# 用lambda作为func，计算列表中每个元素的平方

nums = [1, 2, 3, 4]

result = map(lambda x: x** 2, nums)

print(list(result))  

# 输出：[1, 4, 9, 16]
```



***

## 2. filter(func, iterable)

### 2.1 作用

通过 func 判断 iterable 的元素，保留 func 返回 True 的元素，返回迭代器。

```python
# 筛选列表中的偶数

nums = [1, 2, 3, 4, 5, 6]

result = filter(lambda x: x % 2 == 0, nums)

print(list(result))  

# 输出：[2, 4, 6]
```



***

## 3. sorted(iterable, key=func, reverse=False)

### 3.1 作用

对 iterable（字典）升序排序，key 参数接受函数（用于提取排序依据），reverse = True 为降序。

```python
# 按字符串长度排序

words = ["apple", "banana", "cherry", "date"]

sorted_words = sorted(words, key=lambda s: len(s))  # key=len也可

print(sorted_words)  

# 输出：['date', 'apple', 'banana', 'cherry']（按长度从小到大）


# 按字典值排序

person = [{"name": "Alice", "age": 20}, {"name": "Bob", "age": 18}]

sorted_person = sorted(person, key=lambda x: x["age"])  # 按age升序

print(sorted_person)  

# 输出：[{'name': 'Bob', 'age': 18}, {'name': 'Alice', 'age': 20}]
```
