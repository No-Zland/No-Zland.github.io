# Python笔记

## 缩进规则

Python 通过缩进来区分代码块（通常4个空格），同一分支的代码必须保持相同缩进。

## 作用域（局部变量、全局变量）

作用域指变量的可访问范围，分为局部和全局两种，另有global和nonlocal关键字控制变量访问。

### 局部变量

要点：函数内部定义的变量，仅在函数内有效（函数调用结束后销毁）。

| def func1():     # 局部变量（仅在func1内有效）     local_var = 200     print(f"访问全局变量：{global_var}")  # 合法：函数内可访问全局变量     print(f"访问局部变量：{local_var}") func1() # print(local_var)  # 错误：局部变量在函数外不可访问 |

|---|

### 全局变量

要点：函数外部定义的变量，在整个模块（文件）内有效，函数内可访问（但默认不能修改）。

| # 全局变量 global_var = 100 |

|---|

#### global 关键字

作用：在函数内声明变量为全局变量，允许修改全局变量的值。

| def func2():     # 尝试直接修改全局变量（默认不允许，会创建局部变量）     global_var = 200  # 这里实际是创建了一个同名局部变量     print(f"函数内的局部global_var：{global_var}") func2() print(f"全局变量未被修改：{global_var}")  # 输出：100（全局变量仍为100） def func3():     global global_var  # 声明为全局变量     global_var = 300  # 现在可以修改全局变量     print(f"函数内修改全局变量：{global_var}") func3() print(f"全局变量已被修改：{global_var}")  # 输出：300 |

|---|

#### nonlocal 关键字

作用：在嵌套函数的内层函数中，声明变量为外层函数的局部变量（非全局），允许修改外层变量的值。

| # nonlocal示例（嵌套函数） def outer():     outer_var = 10          def inner():         nonlocal outer_var  # 声明为外层函数的变量         outer_var = 20  # 修改外层变量          inner()     print(f"外层变量被修改：{outer_var}")  # 输出：20 outer() |

|---|

# 进阶知识：Python 核心特性与工具

## 高级数据结构与技巧

列表推导式、字典推导式、集合推导式（简化代码）；

生成器（yield）、迭代器（iter、next）；

深拷贝与浅拷贝（copy模块）。

## 面向对象编程（OOP） 类（class）与对象（实例化）；

类的属性（类属性、实例属性）、方法（实例方法、类方法@classmethod、静态方法@staticmethod）；

封装、继承（单继承、多继承）、多态；

魔术方法（__init__、__str__、__len__等）。

## 模块与包

模块导入（import、from...import、as别名）；

自定义模块与包（__init__.py作用）；

常用标准库：os（系统操作）、sys（解释器交互）、datetime（时间处理）、json（JSON 数据）、re（正则表达式）等。

## 高级特性

装饰器（@decorator，用于函数增强，如日志、缓存）；

上下文管理器（自定义__enter__、__exit__，用于资源管理）；

正则表达式（匹配、替换字符串，re模块）。

## 并发编程基础

多线程（threading模块）、多进程（multiprocessing模块）；

协程（asyncio库，异步编程）。
