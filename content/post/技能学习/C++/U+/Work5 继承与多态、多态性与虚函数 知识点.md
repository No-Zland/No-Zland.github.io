# 知识点总结与对应题目

## 一、继承的基本概念

### 知识点总结

1. **派生类的主要作用**：提高代码可重用性。派生类通过继承基类成员，减少重复代码编写。

2. **派生类的实质**：基于继承机制扩展基类功能，继承是建造派生类的核心机制。

3. **继承的基本特性**：

- 一个派生类可以作为另一个派生类的基类。

- 派生类至少有一个基类。

- 派生类包含自身成员和基类成员。

- 派生类继承的基类成员访问权限会因继承方式改变。

### 对应题目

## 二、成员访问权限

### 知识点总结

1. **基类成员在派生类中的访问规则**：

- **私有成员（private）**：无论哪种继承方式，派生类都无法直接访问。

- **公有成员（public）**：

- 公有继承：仍为公有，派生类对象可访问。

- 保护继承：变为保护成员，派生类对象不可访问。

- 私有继承：变为私有成员。

- **保护成员（protected）**：

- 可被本类、派生类成员及友元访问。

- 公有继承下仍为保护成员，派生类对象不可访问。

2. **访问权限变化**：派生类继承的基类成员访问权限会因继承方式改变。

### 对应题目


## 三、继承中的构造与析构

### 知识点总结

1. **构造函数执行顺序**：

- 单继承：基类构造函数 → 派生类对象成员构造函数 → 派生类构造函数。

- 多继承：虚基类构造函数 → 非虚基类构造函数 → 对象成员构造函数 → 派生类构造函数。

2. **派生类构造函数特点**：

- 必须在初始化列表中调用基类构造函数（尤其基类有参数时）。

- 不能初始化基类的对象成员。

3. **析构函数执行顺序**：与构造函数相反，先派生类析构 → 基类析构。

- 析构函数建议声明为虚函数。

## 四、多继承与虚基类

### 知识点总结

1. **多继承的二义性**：多个基类有同名成员时，直接访问会产生二义性，需用`基类名::成员名`指定。

2. **虚基类**：

- 作用：消除多继承中的二义性。

- 特性：只被初始化一次，由最远派生类调用构造函数。

- 构造顺序：优先于非虚基类。

## 五、多态性

### 知识点总结

1. **编译时多态**：通过函数重载实现。

2. **运行时多态**：

- 基础：虚函数。

- 条件：基类指针/引用指向派生类对象 + 调用虚函数。

- 特性：根据对象类型确定调用的函数。

3. **虚函数规则**：

- 不能是静态成员函数或友元函数。

- 派生类重写时需保持函数名、参数、返回值一致。

- 基类声明后，派生类同名函数自动为虚函数。

- 构造函数不能是虚函数，析构函数可以是虚函数。

## 六、抽象类与纯虚函数

### 知识点总结

1. **纯虚函数**：声明格式为`virtual 返回值类型 函数名(参数)=0;`，无函数体。

2. **抽象类**：

- 定义：包含纯虚函数的类。

- 特性：不能实例化对象，只能作为基类。

- 派生类：需重写所有纯虚函数才能成为非抽象类。

# （判断题）第60题

题目：

```

C++ 允许从抽象类派生具体类，也允许从具体类派生出抽象类。（）

```

选项：

```

A、正确

B、错误

```

参考答案：

```

A

```

答案解析：

```

1. 从抽象类派生：若派生类重写了所有纯虚函数，则成为具体类；

```
