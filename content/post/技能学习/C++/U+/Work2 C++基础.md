# （选择题）第9题
题目：
```
下列的调用方式中引用调用的是？（）
```
选项：
```
A、形参和对应的实参都是变量名
B、形参是指针，对应的实参是地址值
C、形参是引用，对应的实参是变量名
D、形参是变量名，对应的实参是地址值
```
参考答案：
```
C
```
答案解析：
```
**引用调用（Call by Reference）** 是 C++ 特有的函数调用方式，核心规则是：
- 函数的**形参声明为 “引用类型”**（语法上带`&`，比如`int &x`）；
- 调用函数时，**实参直接传递变量名**（而非地址 / 值）；
- 函数内部对形参的所有操作，都会直接作用于实参变量（因为形参是实参的 “别名”，二者共享同一块内存）。
简单说：引用调用相当于给实参变量起了个 “外号”（形参），操作 “外号” 就是操作原变量。
```


```
A、正确
B、错误
```
参考答案：
```
错误
```
答案解析：
```
“存储单元” 就是计算机内存中划分出的一块空间（可以理解为 “内存格子”），用来存放数据。
“常量占用存储单元” 的字面意思是：用`const`定义的常量，会像普通变量一样，在内存中占据一块专属的存储空间。

| ------------------------- | -------- | ----------------- |
| C 语言`#define PI 3.14`     | 不占用      | 预处理时的 “文本替换”（无内存） |
| C++`const double PI=3.14` | 通常占用     | 有类型的常量（存在内存中）     |
```

# （填空题）第37题
题目：
```
变量的____就是变量的别名，对其进行声明时必须立即初始化，不能声明完成后再赋值。
```
填空：
```
1、
```
参考答案：
```
引用
```
答案解析：
```
引用（ &）
引用的核心特性是 “终身绑定”—— 一旦引用绑定到某个变量，就**永远不能再绑定到其他变量**（比如`b`绑定`a`后，这辈子只能是`a`的别名，不能改成`c`的别名）。

如果允许 “先声明、后初始化”，会导致编译器无法确定引用的绑定对象，违背 “引用是别名” 的本质（比如`int &b;` 这句代码，编译器不知道`b`是谁的别名，就无法为它分配逻辑）。

- **初始化**：在创建引用的那一刻，指定它绑定的原变量（`int &b = a;`）；
- **赋值**：给引用对应的内存空间赋值（`b = 20;`），本质是修改原变量的值，不是重新绑定。
```

```cpp
#include <iostream>
using namespace std;
void sortArray(int* arr, int size);
int main() {
    int size;
    int* arr;
    cout << "Enter the size of the array: ";
    cin >> size;
    // 动态分配内存
    arr = new int[size];
    if (!arr) {
        cerr << "Invalid input. Please enter a valid number." << endl;
        return 1;
    }
    // 填充数组
    cout << "Enter " << size << " integers:" << endl;
    for (int i = 0; i < size; ++i) {
        cin >> arr[i];
    }
    // 排序数组
    sortArray(arr, size);
    // 打印数组
    cout << "The sorted array contains:" << endl;
    for (int i = 0; i < size; ++i) {
        cout << arr[i] << " ";
    }
    cout << endl;
    // 释放内存
    delete[] arr;
    return 0;
}
void sortArray(int* arr, int size) {
    for (int i = 0; i < size - 1; ++i) {
        for (int j = 0; j < size - i - 1; ++j) {
            if (arr[j] > arr[j + 1]) {
                int temp = arr[j];
                arr[j] = arr[j + 1];
                arr[j + 1] = temp;
            }
        }
    }
}
```
