# 一、this指针

## 知识点总结

1. **核心特性**

- 是类非静态成员函数中隐含的指针参数，会自动传递当前调用成员函数的对象地址。

- 仅在非静态成员函数内部可用，指向当前调用该函数的对象。

- 类型为对应类类型的指针（例如，类`Person`的this指针类型为`Person*`）。

- 主要用途包括区分成员变量与局部变量、返回当前对象等，且不会破坏类的封装性。

# 二、对象数组

## 知识点总结

1. **定义与特性**

- 由同一类的多个对象组成，定义语法为`类名 数组名[元素个数]`（例如`Person stu[3]`）。

- 下标从0开始，数组名是指向首元素的常量指针。

- 每个元素都是该类的对象，创建对象数组时，每个元素都会调用构造函数进行初始化；元素既可以被赋值，也可以被取值。

# 三、动态内存（new/delete）

## 知识点总结

1. **new的功能**

- 可用于动态创建单个对象和对象数组，创建对象时会自动调用相应的构造函数。

- 动态创建的对象或对象数组，需使用`delete`运算符进行释放（释放对象数组时需用`delete[]`）。

- 创建对象数组时，允许指定初始值对数组元素进行初始化。

# 四、类的成员方法

## 知识点总结

1. **构造函数**

- 与类同名，无返回值，可进行重载，主要用于初始化对象。

- 拷贝构造函数的参数为类的const引用（格式如`类名(const 类名 &obj)`），用于用已有对象初始化新对象。

2. **析构函数**

- 语法格式为`~类名()`，无参数、无返回值，且不能重载；在对象销毁时自动调用，用于释放对象所占用的资源。

3. **赋值运算符重载**

- 语法格式为`类名& operator=(const 类名 &obj)`，返回值为自身引用，用于给已有对象赋值，需注意防止自赋值问题。

4. **静态成员函数**

- 用`static`关键字修饰，没有this指针，属于类本身，而非某个对象；仅能访问类的静态成员，可在创建对象前操作静态数据成员。

5. **常成员函数**

- 语法格式为`返回值 方法名(参数) const`，承诺不修改对象的任何成员；常对象只能调用常成员函数。

# 五、静态数据成员

## 知识点总结

1. **特性**

- 用`static`关键字修饰，为类的所有对象所共享，不属于某个具体对象。

- 生存期与整个程序相同，从程序启动到程序结束。

- 必须在类外进行初始化，初始化格式为`数据类型 类名::成员名 = 初始值`（例如`int Person::count = 0`）。

- 引用时可以通过`类名::成员名`的方式，也可以通过对象（`对象名.成员名`）访问。

# 六、友元（函数/类）

## 知识点总结

1. **特性**

- 友元函数或友元类可以访问类的私有、保护和公有成员，但其本身并非类的成员函数，需在类中用`friend`关键字声明。

- 友元关系不具有交换性（A是B的友元，不代表B是A的友元）、传递性（A是B的友元，B是C的友元，不代表A是C的友元）和继承性（父类的友元不一定是子类的友元）。

- 友元可能破坏类的封装性，但在某些场景下可提高程序运行效率。

# 七、对象成员与初始化

## 知识点总结

1. **对象成员**

- 一个类中可以包含另一个类的对象作为成员（即对象成员）。

- 包含对象成员的类（包含类）的构造函数，需通过初始化表调用对象成员的构造函数进行初始化，不能在构造函数体内初始化对象成员。

- 对象成员的析构函数调用顺序与它们在包含类中的声明顺序相反。

2. **初始化**

- 对象成员必须在包含类的构造函数初始化表中进行初始化，格式为`包含类构造函数(参数) : 对象成员1(参数), 对象成员2(参数) { ... }`。

# 八、其他

## 知识点总结

1. **string类**：使用C++标准库中的string类时，必须包含头文件`#include<string>`。

2. **常对象**：声明为`const`的对象（常对象），只能调用类的常成员函数，不能调用普通成员函数。

3. **函数参数**：当函数形参为对象的引用时，实参应传递对象本身，不能传递对象的地址（否则会导致类型不匹配）。

4. **const指针**：声明为`const 类名 *指针名`（如`const Time *p`）的指针，不能通过该指针修改所指向对象的成员。

```
2、实现成员函数display()用于显示点的坐标。

3、定义友元函数dist(const Point& p1, const Point& p2)计算并返回两个点之间的欧几里得距离。

4、编写主函数测试上述功能。

```


参考答案：

```cpp

#include <iostream>

#include <cmath>

using namespace std;

class Point {

private:

double x, y;

public:

// 构造函数

Point(double x_val, double y_val) : x(x_val), y(y_val) {}

// 成员函数 display()

void display() const {

cout << "(" << x << ", " << y << ")" << endl;

}

// 声明友元函数 distance()

friend double dist(const Point& p1, const Point& p2);

};

// 友元函数 distance() 的定义

double dist(const Point& p1, const Point& p2) {

double dx = p1.x - p2.x;

double dy = p1.y - p2.y;

return sqrt(dx * dx + dy * dy);

}

int main() {

// 创建两个点对象

Point p1(3.0, 4.0);

Point p2(6.0, 8.0);

// 显示点的坐标

p1.display();

p2.display();

// 计算并显示两点之间的距离

cout << "Distance between points: " << dist(p1, p2) << endl;

return 0;

}

```

答案解析：

```

Point类包含x和y私有成员，构造函数初始化这两个成员，display函数显示坐标。友元函数dist利用欧几里得距离公式计算两点距离，可直接访问Point类的私有成员。主函数创建点对象，测试显示和距离计算功能，符合题目要求。
```
