# C 语法（0）：知识点索引

> 这是《C 语法（1）：快速入门》的“回忆版”：只留下容易忘、容易写错的结论，不重复完整讲解和示例。
> 用法：先扫加粗的关键词，能回忆起结论就跳过；卡住了再回笔记对应章节看例子。
> ⚠️ = 高频坑；⭐ = 容易忘的细节。快速复习时只看 ⚠️ 行。

## 一、基本数据类型

- **`sizeof`**：结果类型是 `size_t`，`printf` 用 `%zu`；类型宽度不要背，现场 `sizeof` 验证。
- **宽度不是承诺**：`int` 不保证 4 字节，指针不保证 8 字节；跨平台代码不要假设。
- **`char` 的符号**：是否有符号由实现决定；要可移植就显式写 `signed char` / `unsigned char`。
- **有符号 vs 无符号**：`int` 与 `unsigned int` 混比时，`int` 会转成 `unsigned int`，`-1 < 1u` 为假。⚠️
- **整型提升**：`char`、`short` 参与运算先提升为 `int`；`sizeof('a')` 等于 `sizeof(int)`（C++ 不同）。⭐
- **浮点比较**：不要用 `==`；用 `fabs(a - b) < eps`。
- **`long double`**：格式符是 `%Lf`，各平台实现差异大，跨平台少用。

## 二、表达式与运算符

- **优先级速记**：后缀 > 一元 > 乘除 > 加减 > 移位 > 关系 > 相等 > 位与 > 异或 > 位或 > 逻辑与 > 逻辑或 > 条件 > 赋值 > 逗号。
- **`*p++`**：等价于 `*(p++)`，先取 `*p` 再让 `p` 后移；要自增所指内容写 `(*p)++`。⚠️
- **`&` / `*` 的双重身份**：`&` 既取地址也按位与，`*` 既解引用也乘法；先看它是一元还是二元。
- **赋值右结合**：`a = b = 0` 即 `a = (b = 0)`；赋值表达式本身有值。
- **逗号最低**：`a = 1, b = 2` 是 `(a = 1), (b = 2)`，整个表达式值为 `2`。
- **短路**：`&&`、`||` 左侧能决定结果就不算右侧；常写 `p != NULL && p->x > 0`。
- **`==` 写成 `=`**：`if (x = 1)` 恒真；把常量放左边（`1 == x`）让编译器帮你报错。⚠️
- **位运算低于关系**：`x & 1 == 0` 实际是 `x & (1 == 0)`；写 `(x & 1) == 0`。⚠️
- **移位**：`1 << 31` 对有符号 `int` 可能溢出/未定义；需要最高位用 `1u << 31`。

## 三、类型转换

- **隐式提升**：大致 `char/short → int → long → long long → float → double`；有符号/无符号混合时可能转成无符号。⚠️
- **浮点转整数**：截断，不是四舍五入；`int(-3.9) == -3`。
- **强制转换**：`(类型)表达式` 只影响表达式的值/赋值结果，不改变原变量。
- **指针转换**：要保证对齐和实际对象类型兼容；`void *` 可以和任意对象指针互转。
- **窄化转换**：赋值/传参时可能只给警告；开 `-Wall -Wextra`，别忽略。
- **`size_t` 与 `int`**：`for (int i = 0; i < strlen(s); i++)` 会出现有符号/无符号比较警告。

## 四、变量、作用域与生命周期

- **局部变量不初始化**：值不确定，不是 0；只有全局/静态变量默认 0。⚠️
- **`static` 局部变量**：作用域仍在函数内，生命周期是整个程序，只初始化一次。⭐
- **全局变量**：从定义处到文件末尾可见；跨文件用 `extern` 声明。
- **同名遮蔽**：内层变量遮外层；`{ int x; { int x; } }` 合法但易混。
- **C 没有嵌套函数**：函数里不能再定义函数；文件内私有函数用 `static`。
- **`const` 不是“编译期常量”**：`const int n = 5;` 不能做 `case` 标签；块作用域的 `int a[n];` 在 C99 下是 VLA。⚠️
- **`volatile`**：告诉编译器每次都要真读内存，别优化掉；用于硬件寄存器、信号处理等场景。

## 五、常量与宏

- **宏是文本替换**：没有类型检查、没有作用域；`const` 有类型、有作用域。⭐
- **带参宏加括号**：参数和整体都加，`#define SQ(x) ((x)*(x))`；否则 `SQ(1+2)` 展开成 `1+2*1+2`。⚠️
- **宏参数副作用**：`MAX(i++, j++)` 可能自增多次；需要函数，或先把值算好。
- **多语句宏**：用 `do { ... } while (0)` 包起来，避免 `if/else` 悬挂。⭐
- **宏末尾不加分号**：`#define X 1;` 会把分号也替换进去。
- **枚举**：本质是整型，默认从 0 递增；可指定值，后面的值继续递增。
- **`#undef`**：取消宏；宏名通常大写，和变量/函数区分。

## 六、分支结构

- **`else` 配对**：与最近的未匹配 `if` 配对；嵌套 `if` 一定加花括号。⚠️
- **`else if` 顺序**：从特殊到一般；`score >= 90` 必须放在 `>= 80` 前面。
- **`switch` 表达式**：必须是整型/枚举，不能是浮点或字符串。
- **`case` 标签**：必须是编译期整型常量表达式，不能是变量。
- **漏 `break`**：会贯穿到下一个 `case`；故意利用时要写注释。⚠️
- **`default`**：可放任意位置；没有匹配且无 `default` 时什么都不做。
- **`case` 里定义变量**：加花括号限制作用域，避免跨标签初始化问题。
- **三元 `?:`**：右结合；两个分支的类型会统一，注意隐式转换。

## 七、循环结构

- **`for` 三段**：初始化、条件、更新都可省略；`for (;;)` 是死循环，靠 `break` 退出。
- **`while` vs `do-while`**：`while` 可能一次都不执行；`do-while` 至少一次，末尾有分号。⭐
- **`continue` 的位置**：`for` 会执行更新表达式，`while` 不会；更新语句在 `continue` 后面会死循环。⚠️
- **`break` 的层数**：只跳出最内层循环/`switch`；多层退出用标志变量或 `goto`。
- **`goto` 的合理用法**：多层嵌套跳到统一清理标签；不要用它写普通流程。
- **循环变量**：C99 可写在 `for` 内；C89 要在外面定义。

## 八、函数

- **只有传值**：所谓“传址”是把地址值传给指针形参。⭐
- **数组退化为指针**：函数内 `sizeof(arr)` 是指针大小；必须额外传长度。⚠️
- **二维数组参数**：列数不能省，`void f(int a[][3], int rows)`。
- **函数声明**：放在调用前；声明里参数名可省，类型不能省。
- **不要返回局部变量地址**：函数返回后栈帧失效；返回字符串字面量/静态数组可以。
- **递归**：必须有终止条件且向终止条件靠近；深度大用迭代，重复计算用记忆化。
- **函数指针声明**：`int (*p)(int, int)`；`int *p(int, int)` 是返回指针的函数。⚠️
- **函数名退化**：`p = add` 与 `p = &add` 等价；调用前确保指针非空。
- **`return` vs `exit`**：子函数 `return` 只返回调用者；`exit` 终止整个进程并刷新 stdio 缓冲。

## 九、数组与字符串

- **初始化**：局部数组不初始化是垃圾值；`int a[5] = {0}` 才全 0；`= {1}` 只首元素 1，其余 0。⭐
- **越界**：C 不检查；越界是未定义行为，可能不报错。
- **数组名**：不是指针，但大多数表达式退化为首元素指针；`sizeof(a)` 是整块大小。⭐
- **字符串**：`char s[] = "abc"` 占用 4 字节（含 `'\0'`），但 `strlen(s) == 3`；`char s[] = {'a','b','c'}` 不是字符串。⚠️
- **字面量只读**：`char *p = "abc"` 不能改；要改就写 `char p[] = "abc"`。
- **`strlen`**：不含 `'\0'`，返回 `size_t`；`strcpy`/`strcat` 不检查目标大小。⚠️
- **`strncpy`**：`src` 长度 ≥ `n` 时不补 `'\0'`，要手动 `dst[n-1] = '\0'`。
- **`strcmp`**：相等返回 0，不是 1；比较字典序，不是长度。
- **查找函数**：`strchr`/`strstr` 找不到返回 `NULL`；找到了可用 `pos - s` 求下标。
- **二维数组**：按行连续存放；`matrix[i][j]` 等价 `*(*(matrix + i) + j)`。

## 十、标准 I/O 与文件操作

- **`scanf` 的 `&`**：普通变量必须加；数组名/指针本身是地址，不加。⚠️
- **`%c` 不跳过空白**：前面有残留换行时用 `" %c"`。
- **`%s` 遇空白停止**：读整行用 `fgets`；注意它保留 `\n`。⭐
- **浮点格式符**：`printf` 输出 `double` 用 `%f`；`scanf` 读 `double` 必须 `%lf`。⚠️
- **`getchar`/`fgetc` 返回 `int`**：为了区分 `EOF`；不要用 `char` 接收。
- **`fgets`**：最多读 `n-1` 个字符，自动补 `'\0'`，保留换行；返回 `NULL` 表示 EOF/错误。
- **`fopen`/`fclose`**：`fopen` 必须判 `NULL`；`fclose` 必须调用，否则缓冲区可能没落盘。⭐
- **打开模式**：`"w"` 截断，`"a"` 追加，`"r+"` 要求文件存在；二进制加 `b`。⚠️
- **`fread`/`fwrite`**：返回“块数”，不是字节数；参数顺序 `(ptr, size, nmemb, stream)`。
- **求文件大小**：`fseek(fp, 0, SEEK_END); ftell(fp)`；二进制模式最稳。
- **错误处理**：`perror` 打印系统错误；`ferror` 判断流错误；`clearerr` 清标志。
- **不要用**：`gets()`（C11 已删）、`fflush(stdin)`（未定义）。

## 十一、预处理指令

- **时机**：编译前做文本替换/文件包含/条件筛选；指令不以分号结尾。
- **`#include` 查找**：`<...>` 查系统路径；`"..."` 先查当前文件目录。⭐
- **头文件保护**：`#ifndef/#define/#endif` 或 `#pragma once`；不要混用。
- **条件编译**：条件只能是整型常量表达式；不能用变量、函数调用、`sizeof`、浮点数。
- **`#ifdef`**：等价 `#if defined(X)`；`#ifndef` 用于“未定义时”。
- **`#error`**：主动触发编译错误，适合提示不支持的环境。
- **`-DDEBUG`**：编译时定义宏，等价源码里 `#define DEBUG`；发布版不用改源码。

## 十二、`main` 与程序入口

- **标准形式**：`int main(void)` 或 `int main(int argc, char *argv[])`；不要 `void main()`。
- **`argc`/`argv`**：`argc` 是参数个数；`argv[0]` 是程序名，`argv[1]` 才是第一个参数；`argv[argc] == NULL`。
- **退出状态**：返回 0/`EXIT_SUCCESS` 成功；非 0/`EXIT_FAILURE` 失败。
- **`main` 的 `return`**：等价于 `exit(n)`；子函数里的 `return` 只返回调用者。
- **`exit` vs `_Exit`**：`exit` 刷新 stdio、调用 `atexit`；`_Exit` 不刷新、不调用。
- **不要主动调用 `main`**：它不是普通函数。
