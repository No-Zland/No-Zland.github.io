# C++ 算法竞赛快速上手

这篇只讲**最短时间内能写出可提交代码**所需的语法和习惯。指针、Class、复杂 STL（`set`/`map`/`priority_queue`）、`string` 的高级操作一律跳过，留给你后续单独学。

## 1. 最小可提交模板

竞赛代码不需要“优雅”，需要**稳定、可复现、不丢分**。先记住这个骨架，每道题都从这里开始：

```cpp
#include <bits/stdc++.h>
using namespace std;

typedef long long ll;
const int N = 1e5 + 5;
const int INF = 0x3f3f3f3f;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    // 你的代码

    return 0;
}
```

`bits/stdc++.h` 是 GCC 专用但竞赛环境（洛谷、Codeforces、NOI Linux）都支持，不确定时换成 `<iostream>`、`<algorithm>`、`<vector>` 等具体头文件。`ios::sync_with_stdio(false); cin.tie(nullptr);` 关闭 `cin/cout` 与 C 标准库的同步，是竞赛中直接用 `cin/cout` 的前提。

## 2. 输入输出：先把数据读对

### 2.1 单组与多组数据

单组数据直接 `cin >>` / `cout <<`。多组数据有两种常见形式：

**给定测试用例数 `T`**：

```cpp
int T;
cin >> T;
while (T--) {
    int n;
    cin >> n;
    // 处理
}
```

**读到文件末尾（EOF）**：

```cpp
int x;
while (cin >> x) {
    // 处理 x
}
```

`while (cin >> x)` 在读到 EOF 时自动停止，适用于“不知道有多少组”的题目。

### 2.2 输出格式：不要多印一个字

竞赛评测是逐字节比对。**不要输出“请输入”“答案是”之类的提示语**，严格按题目要求输出。

### 2.3 换行用 `'\n'`，不要用 `endl`

`std::endl` 除了换行还会**刷新缓冲区**，在输出量大的题目中会显著拖慢程序，是 TLE 的常见原因之一：

```cpp
cout << ans << '\n';   // 快
// cout << ans << endl; // 慢，大量输出时可能 TLE
```

这一点在 Codeforces 上被反复提醒。

## 3. 数据类型：`int` 的边界比你想的窄

### 3.1 核心范围

| 类型 | 大致范围 | 竞赛用法 |
|---|---|---|
| `int` | \(-2.1 \times 10^9\) 到 \(2.1 \times 10^9\) | 单个输入值通常够用 |
| `long long` | \(-9.2 \times 10^{18}\) 到 \(9.2 \times 10^{18}\) | **求和、乘积、DP 答案默认用它** |
| `double` | 约 15 位有效数字 | 浮点题使用，不要用于精确整数比较 |

`int` 上限约 21 亿。题目给 \(n \le 10^5\)、每个数 \(\le 10^9\)，总和就是 \(10^{14}\)，远远超出 `int`，必须用 `long long`。

### 3.2 最隐蔽的坑：中间结果先溢出

即使你把答案声明成了 `long long`，如果两个操作数都是 `int`，**乘法仍然按 `int` 计算**，溢出之后才赋值：

```cpp
int width = 1e6, height = 1e6;
long long area = width * height;          // 错：先按 int 算，已溢出
long long area = 1LL * width * height;    // 对：1LL 把整个表达式提升为 long long
```

`1LL *` 是竞赛中最常用的防溢出写法，看到乘法就习惯性加上。

### 3.3 浮点比较不要用 `==`

浮点数有精度误差，`0.1 + 0.2` 不一定等于 `0.3`。判断两个浮点数是否“相等”用差值：

```cpp
const double EPS = 1e-9;
if (fabs(a - b) < EPS) {
    // 认为相等
}
```

**能不用浮点就不用**。很多题目表面是小数，但可以通过乘以 \(10^k\) 转成整数运算，从根本上避开精度问题。

## 4. 数组与 `vector`：存数据的两种方式

### 4.1 静态数组

大小已知且不大时，直接用全局静态数组：

```cpp
const int N = 1e5 + 5;
int a[N];
```

全局数组自动初始化为 0，避免局部大数组导致的栈溢出。`memset(a, 0, sizeof(a))` 可以把整型数组置 0 或 -1，但**不要用于浮点数组**，也不要指望它能置其他整数值。

### 4.2 `vector` 基础用法（只学这些就够起步）

`vector` 是变长数组，竞赛中最常用的容器。先掌握最核心的接口：

```cpp
vector<int> v;

v.push_back(x);        // 尾部插入
v.pop_back();          // 尾部删除（不返回被删的值）
v.size();              // 元素个数
v.empty();             // 是否为空
v.clear();             // 清空
v[i];                  // 下标访问（不检查越界）
v.back();              // 最后一个元素
```

**遍历**优先用范围 `for`：

```cpp
for (const auto& x : v) {
    cout << x << ' ';
}
```

需要修改元素时用 `auto&`：

```cpp
for (auto& x : v) {
    x *= 2;
}
```

`vector` 支持随机访问，因此可以直接用 `sort` 排序：

```cpp
sort(v.begin(), v.end());          // 升序
sort(v.begin(), v.end(), greater<int>()); // 降序
```



### 4.3 排序与查找

数组和 `vector` 的排序都用 `sort`：

```cpp
sort(a, a + n);              // 数组升序
sort(a, a + n, greater<int>()); // 数组降序
```

在**有序**数组中查找位置：

```cpp
int pos = lower_bound(a, a + n, x) - a; // 第一个 >= x 的下标
int pos = upper_bound(a, a + n, x) - a; // 第一个 > x 的下标
```

`lower_bound` / `upper_bound` 要求区间**已经有序**，返回的是迭代器，减 `a` 或 `v.begin()` 得到下标。

## 5. 结构体与多关键字排序

竞赛中经常需要“先按 A 排，A 相同再按 B 排”。标准写法是写一个 `cmp` 函数：

```cpp
struct Node {
    int id, score;
};

bool cmp(const Node& a, const Node& b) {
    if (a.score != b.score) return a.score > b.score; // 分数高的在前
    return a.id < b.id;                                // 分数相同，id 小的在前
}

sort(v.begin(), v.end(), cmp);
```

`cmp` 返回 `true` 表示 `a` 应该排在 `b` 前面。多关键字排序就是**逐字段写比较，第一个能分出胜负的条件直接返回**。

## 6. 数据范围决定算法：一条最实用的对应关系

竞赛中**先看数据范围，再选算法**，不是反过来。现代评测机 1 秒大约能处理 \(10^8\) 次简单运算。

| \(n\) 的范围 | 可接受的复杂度 | 典型做法 |
|---|---|---|
| \(\le 20\) | \(O(2^n)\)、\(O(n!)\) | 暴力枚举、全排列 |
| \(\le 100\) | \(O(n^3)\) | 三重循环、Floyd |
| \(\le 1000\) | \(O(n^2)\) | 朴素 DP、冒泡 |
| \(\le 10^5 \sim 10^6\) | \(O(n \log n)\) | 排序、二分 |
| \(\le 10^7 \sim 10^8\) | \(O(n)\) | 前缀和、线性扫描 |
| \(\le 10^{18}\) | \(O(\log n)\) | 快速幂、二分 |

看到 \(n \le 10^5\) 就想 \(O(n \log n)\)，看到 \(n \le 10^3\) 才允许 \(O(n^2)\)。**如果写出的复杂度比表格高，先优化，不要急着提交**。

## 7. 新手高频 WA / TLE 速查

| 现象 | 最常见原因 | 修正 |
|---|---|---|
| 大数据 WA，小数据对 | `int` 乘法/求和中间溢出 | `1LL *` 或全程 `long long` |
| 浮点题 WA | 用 `==` 比较浮点数 | `fabs(a-b) < EPS` |
| 输出量大时 TLE | 用了 `endl` | 改用 `'\n'` |
| 输入量大时 TLE | 用了 `cin/cout` 但没关同步 | `ios::sync_with_stdio(false); cin.tie(nullptr);` |
| 取模题出负数 | C++ 的 `%` 对负数结果仍可能为负 | `(a % MOD + MOD) % MOD` |
| 多组数据读到死循环 | 该用 `while (cin >> x)` 却用了 `cin >> x` 一次 | 按题目输入模式选择读取方式 |
| 数组越界 | 下标从 0 开始，长度为 \(n\) 时合法下标是 \(0 \sim n-1\) | 循环条件写 `i < n` |
| `memset` 后浮点数组不对 | `memset` 按字节填充，不适用于浮点 | 浮点数组用 `fill` 或循环赋值 |

**负数取模**是一个容易被忽略的点：`-5 % 3` 在 C++ 中结果是 `-2`，而题目通常要求非负余数 `1`。涉及减法的取模，统一写成 `(a - b % MOD + MOD) % MOD`。

## 8. 起步练习路径

语法只需要上述内容就可以开始做题。建议按以下顺序，**边做边补**，不要等“学完”再动手：

1. 顺序与输入输出：A+B 类题目，练熟 `cin/cout` 和多组读取。
2. 分支与循环：条件判断、`for`/`while`，练熟边界。
3. 数组与排序：读入数组、`sort`、`lower_bound`。
4. 结构体排序：多关键字 `cmp`。
5. 枚举与模拟：用循环直接模拟题意，先把“暴力分”拿到。

洛谷入门题单（P1001、P1046、P1909、P5707 等）和 Codeforces Div.4 的 A、B 题都是合适的起点。**每道题提交前先自己造一组边界数据**（\(n=0\)、\(n=1\)、最大值），这是竞赛习惯中最值得尽早养成的一条。
