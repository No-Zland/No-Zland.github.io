# Python 语法（0）：知识点索引

## 一、基础语法（笔记 1）

### 1. 缩进与代码块

- 缩进是语法，不是风格；同一代码块必须一致，Tab 和空格不要混用。⚠️
- `if`、`for`、`while`、`def`、`class`、`try` 等行尾都要冒号 `:`。

### 2. 基本类型

- **`int` 任意精度**：不会溢出；`bool` 是 `int` 的子类，`True == 1`。⭐
- **浮点误差**：`0.1 + 0.2 != 0.3`；比较用 `math.isclose`。⚠️
- **`round()` 是银行家舍入**：`round(2.5) == 2`、`round(3.5) == 4`；二进制浮点还会让 `round(2.675, 2)` 得 `2.67`。⭐
- **字符串不可变**：`s[0] = "x"` 报错，“修改”字符串的方法都返回新字符串。
- **真值判定**：`0`、`0.0`、`""`、`[]`、`{}`、`set()`、`None`、`False` 为假；`"0"`、`[0]` 为真。⚠️
- **`None` 不是 0/空串**：判断用 `is None`，不要 `== None`。⭐
- **`0` 是合法值时**：用 `if x is not None:`，不要用 `if x:`。⚠️

### 3. 运算符

- **`is` vs `==`**：`is` 比身份，`==` 比值；小整数/字符串驻留会让 `is` 偶尔为真，不能依赖。⚠️
- **`and`/`or` 返回操作数本身**：`0 or "x"` → `"x"`，`1 and 0` → `0`。⭐
- **幂运算 `**`**：右结合且优先于一元负号；`-2 ** 2 == -4`，`2 ** 3 ** 2 == 512`。⚠️
- **`//` 向下取整**：`-7 // 2 == -4`；`%` 符号跟除数：`-7 % 3 == 2`。⚠️
- **链式比较**：`1 < x < 10` 等价于 `1 < x and x < 10`，且 `x` 只求值一次。
- **`not a == b`**：是 `not (a == b)`，不是 `(not a) == b`。

### 4. 类型转换

- **`int()` 向零截断**：`int(-3.9) == -3`；`round()` 是舍入，但采用银行家舍入。
- **`int("3.14")`**：报 `ValueError`；先 `float()` 再 `int()`。
- **隐式转换**：`int + float` 结果是 `float`；`bool` 参与算术会变成 `0/1`。

### 5. 变量与作用域

- **函数内的赋值**：只要对变量赋值，它就是局部变量；赋值前读取会 `UnboundLocalError`。⚠️
- **修改外层变量**：全局用 `global`；外层函数变量用 `nonlocal`；`nonlocal` 不能指向模块全局。⭐
- **`a = b` 只是引用**：两个名字指向同一对象；可变对象会互相影响。⚠️
- **浅拷贝**：`copy.copy` / `list.copy()` 只复制一层；嵌套可变对象仍共享，深拷贝用 `copy.deepcopy`。⭐
- **`del` 删的是名字/引用**：不一定立刻释放对象。

### 6. 常量

- **没有 `const`**：全大写只是约定，运行时仍可改。⭐
- **更强约束**：用 `enum.Enum`；`typing.Final` 主要给类型检查器看。

### 7. 分支与循环

- **`elif`**：是 else if；条件顺序从特殊到一般。
- **条件表达式**：`a if cond else b`；嵌套多了就加括号或改回 `if`。
- **`for` 不是三段式**：遍历可迭代对象；`range(stop)` 不含 `stop`。⭐
- **`range(start, stop, step)`**：惰性序列，不是列表；负 step 倒序。
- **`for/while ... else`**：循环没被 `break` 中断才执行 `else`；`break` 后不执行。⚠️
- **遍历时删列表元素**：会跳元素；遍历副本 `lst[:]` 或新建列表。⚠️
- **遍历时改字典**：增删键会 `RuntimeError`；先 `list(d)` 或 `d.copy()`。
- **`break`/`continue`**：只作用于当前层；Python 没有 `goto`。

### 8. 异常处理

- **四段顺序**：`try/except/else/finally`；`else` 是“没异常时”，`finally` 是“无论如何”。⭐
- **裸 `except:`**：会吞掉 `KeyboardInterrupt`/`SystemExit`；至少写 `except Exception`。
- **捕获具体异常**：不要用一个 `except` 处理所有情况；异常变量在块结束后会被删除。⭐
- **`raise` 重抛**：`raise X from e` 保留因果链。
- **不要用异常做正常流程控制**：可预期的情况用 `if`。

### 9. 函数

- **默认参数只求值一次**：`def f(a=[])` 会跨调用共享；用 `None` 哨兵。⚠️
- **参数顺序**：位置 → 默认 → `*args` → 仅关键字 → `**kwargs`；`*args` 是元组，`**kwargs` 是字典。⭐
- **调用时解包**：`f(*lst)`、`f(**dct)`。
- **返回值**：无 `return` 返回 `None`；`return a, b` 返回元组，可解包。
- **函数是一等对象**：传函数写 `foo(bar)`，不要写 `foo(bar())`。⚠️
- **`lambda` 只能一个表达式**；闭包晚绑定：`[lambda: i for i in range(3)]` 调用时全返回 2，用 `lambda i=i: i` 固定。⭐
- **`map`/`filter`/`zip`**：返回惰性迭代器，只能消费一次；需要列表用 `list(...)`。⚠️

### 10. 程序入口

- **`if __name__ == "__main__":`**：直接运行才执行；被 `import` 时不执行。⭐
- **`__name__`**：直接运行时是 `"__main__"`，导入时是模块名。
- **不是强制**：但能让模块既可运行又可被安全导入。

## 二、容器类型（笔记 2）

### 1. 列表（list）

- **有序、可变、可重复**；切片 `lst[start:stop:step]` 左闭右开，负索引从 -1 开始。
- **切片赋值可改变长度**：`lst[1:3] = [10]`；步长不为 1 时，赋值长度必须匹配。⚠️
- **`lst.sort()` 原地、返回 `None`**；`sorted(lst)` 返回新列表。⚠️
- **`lst.reverse()` 原地、返回 `None`**；`reversed(lst)` 返回迭代器。
- **`append(x)` 返回 `None`**：`lst = lst.append(x)` 会把 `lst` 变成 `None`。⚠️
- **`extend(iterable)`** 展开加入；`lst + other` 生成新列表。
- **`lst * 3` 重复**：`[[0] * 3] * 3` 的三行是同一个列表对象。⚠️
- **`remove(x)`** 删第一个值，不存在报 `ValueError`；`pop(i)` 按下标删除并返回，默认末尾。
- **`in` 是线性查找**：大列表频繁查找用 `set`/`dict`。

### 2. 元组（tuple）

- **单元素元组**必须写 `(5,)`；`(5)` 是 `int`。⚠️
- **不可变是“浅”的**：元组里的 list 仍可改。⭐
- **可哈希**：元素都可哈希时，元组可作 dict 键/set 元素。
- **解包**：`a, b = b, a`；`*rest` 收集剩余；`_` 常作丢弃。
- **不需要修改时优先元组**：更省内存，遍历略快。

### 3. 字典（dict）

- **3.7+ 保留插入顺序**；键必须可哈希（list/dict/set 不行，tuple/frozenset 可以）。⭐
- **`d[key]` vs `d.get`**：键不存在时前者抛 `KeyError`，后者返回默认值。⚠️
- **`setdefault(k, default)`**：键不存在才插入并返回；适合分组。
- **合并**：`d1 | d2`（3.9+）或 `{**d1, **d2}`；后者也创建新字典。
- **视图**：`.items()` 同时拿键值；`.keys()`/`.values()` 是视图，随字典变化。
- **删除**：`del d[k]`、`d.pop(k, default)`、`d.popitem()`；`clear()` 清空。
- **字典推导式**：`{k: v for ...}`；键重复时后者覆盖前者。

### 4. 集合（set）

- **空集合是 `set()`**：`{}` 是空字典。⚠️
- **无序、不重复、元素可哈希**；不支持下标/切片。⭐
- **运算**：`|` 并、`&` 交、`-` 差、`^` 对称差。
- **`frozenset`**：不可变、可哈希，可作 dict 键。
- **`add`/`update`**：加一个/加多个；`remove` 不存在报 `KeyError`，`discard` 不报。⭐
- **去重不保序**：要保序去重：`dict.fromkeys(seq)`。

### 5. 可变性总结

- **可变**：`list`、`dict`、`set`；**不可变**：`int`、`float`、`str`、`bool`、`tuple`、`frozenset`。
- **不可变对象可作 dict 键**；可变对象不能。
- **函数传参是“对象引用”**：函数内修改可变对象会影响外部；重新赋值不会。⚠️
- **不要用 `is` 判断值相等**：不可变对象的驻留会让结果不可预测。

## 三、文件操作（笔记 3）

### 1. 打开与关闭

- **`open(path, mode, encoding="utf-8")`**：文本模式显式指定编码，Windows 默认可能是 GBK。⭐
- **模式**：`r` 必须存在；`w` 截断；`a` 追加；`x` 独占创建；`+` 读写；`b` 二进制。⚠️
- **二进制模式**不能指定 `encoding`；读写的是 `bytes`。
- **永远用 `with open(...) as f:`**：异常时也能关闭。⭐

### 2. 读写

- **文本读取**：`read(size)` 读字符，`readline()` 读一行（含 `\n`），`readlines()` 返回列表（含 `\n`）。⭐
- **大文件**用 `for line in f:` 逐行迭代；不要 `read()`/`readlines()` 全量加载。
- **`write(s)`** 返回写入字符数；`writelines(lines)` 不自动加换行。⚠️
- **二进制**：`read(size)` 读字节，返回 `bytes`；`write(b)` 返回字节数。
- **读到末尾**后再读返回 `""`/`b""`；要重读先 `seek(0)`。
- **迭代文件对象和 `readline()` 混用**会互相影响位置。

### 3. 指针与大文件

- **`tell()`** 返回当前位置；文本模式是“不透明 cookie”，不一定是字符数。⭐
- **`seek(offset, whence)`**：0 开头、1 当前、2 末尾；文本模式只保证 `seek(0)`、`seek(0, 2)` 等有限操作。⚠️
- **二进制大文件分块**：`while chunk := f.read(1 << 20):`。
- **文本大文件逐行迭代**：`for line in f` 内存友好。

### 4. 路径与配置

- **`os.path.join`** 跨平台拼接；`pathlib.Path` 更现代：`Path.cwd() / "data" / "x.txt"`。⭐
- **`Path.read_text(encoding="utf-8")` / `write_text`** 简化读写。
- **判断**：`os.path.exists` / `Path.exists()`；`is_file()`/`is_dir()`。
- **`shutil.copy`** 复制内容+权限；`copy2` 还复制元数据；`copytree` 目标必须不存在。⚠️
- **删除**：`Path.unlink()` 删文件，`shutil.rmtree()` 递归删目录；没有回收站。
- **JSON**：`json.dump(obj, f, ensure_ascii=False, indent=2)`；`json.load(f)`。
- **YAML**：`yaml.safe_load`；不要用无 `Loader` 的 `yaml.load`。⭐
