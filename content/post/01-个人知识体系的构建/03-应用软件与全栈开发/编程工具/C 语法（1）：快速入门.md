## 一、基本数据类型

不同平台字节长度可能不同，**用 `sizeof` 验证**，下表为常见值，不是跨平台保证。

| 类型 | 常见字节 | 常见格式说明符 | 说明 |
|---|---:|---|---|
| `char` | 1 | `%c` / `%hhd` | 字符或小整数 |
| `short` | 2 | `%hd` | 短整型 |
| `int` | 4 | `%d` / `%i` | 常用整型 |
| `long` | 4 或 8 | `%ld` | 平台相关 |
| `long long` | 8 | `%lld` | 大整数 |
| `unsigned char` | 1 | `%hhu` | 无符号字符 |
| `unsigned short` | 2 | `%hu` | 无符号短整型 |
| `unsigned int` | 4 | `%u` | 无符号整型 |
| `unsigned long` | 4 或 8 | `%lu` | 无符号长整型 |
| `unsigned long long` | 8 | `%llu` | 无符号大整数 |
| `float` | 4 | 输出 `%f`，输入 `%f` | 单精度浮点 |
| `double` | 8 | 输出 `%f`，输入 `%lf` | 双精度浮点 |
| `long double` | 平台相关 | `%Lf` | 长双精度，跨平台差异大 |
| 指针 | 4 或 8 | `%p` | 输出地址 |
| 数组 | 元素大小 × 个数 | 无统一格式符 | 连续内存块 |
| 结构体 | 成员大小加对齐 | 无统一格式符 | 复合类型 |

### 1. 用 `sizeof` 验证长度

```c
#include <stdio.h>

int main(void) {
    printf("char: %zu\n", sizeof(char));
    printf("int: %zu\n", sizeof(int));
    printf("long: %zu\n", sizeof(long));
    printf("long long: %zu\n", sizeof(long long));
    printf("float: %zu\n", sizeof(float));
    printf("double: %zu\n", sizeof(double));
    printf("pointer: %zu\n", sizeof(void *));
    return 0;
}
```

`sizeof` 返回 `size_t`，输出用 `%zu`。不要假设 `int` 一定是 4 字节，也不要假设指针一定是 8 字节。

### 2. 有符号与无符号

`char`、`short`、`int`、`long` 默认是否带符号由实现决定，通常 `char` 是否有符号取决于平台。需要明确时用 `signed char` 或 `unsigned char`。

无符号类型不表示负数，混合比较容易出问题：

```c
unsigned int u = 1;
int i = -1;

if (i < u) {
    printf("直觉上 i 更小\n");
} else {
    printf("实际可能走到这里\n");
}
```

不要把有符号和无符号混在一起比较，必要时先统一类型。

## 二、表达式与运算符

表达式由 **操作数** 和 **运算符** 组成。C 语言中每个表达式 **都有值，也有类型**。

### 1. 优先级与结合性

**数字越小，优先级越高**；同优先级按结合性决定执行顺序。

![[C语言优先级与结合性总表.jpg]]

**容易出错的点：**

- `*` 在优先级 2 是 **解引用**，在优先级 3 是 **乘法**。
- `&` 在优先级 2 是 **取地址**，在优先级 8 是 **按位与**。
- `+ -` 在优先级 2 是 **一元正负号**，在优先级 4 是 **二元加减**。
- 赋值运算符优先级很低，且右结合，`a = b = 0` 等价于 `a = (b = 0)`。
- 逗号运算符优先级最低，`a = 1, b = 2` 先执行 `a = 1`，再执行 `b = 2`，整个表达式结果为 `2`。

### 2. 短路求值

`&&` 和 `||` 具有 **短路求值**：左侧结果已能决定整体结果时，右侧不再计算。

```c
int a = 0;
int b = 10;

if (a != 0 && b / a > 1) {  // a != 0 为假，右侧 b / a 不执行
    printf("不会到这里\n");
}

if (a == 0 || b / a > 1) {  // a == 0 为真，右侧 b / a 不执行
    printf("会到这里\n");
}
```

常用于 **“先判空、再使用”**，例如 `if (p != NULL && p->value > 0)`。

**注意：** 短路只保证右侧不被求值，不改变运算符优先级；复杂条件仍建议加括号。

## 三、类型转换

不同类型混合运算时会发生转换，分为 **隐式转换** 和 **强制转换**。

### 1. 隐式转换

编译器自动完成，通常遵循 **“低精度 → 高精度”**，尽量避免数据丢失：

```c
int a = 10;
float b = 3.14f;
float c = a + b;  // a 先隐式转为 float，再与 b 相加
```

常见提升顺序（粗略理解）：

$$
char / short → int → long → long long → float → double
$$

### 2. 强制转换

由程序员 **显式指定** 目标类型，格式 `(目标类型)表达式`：

```c
double d = 5.99;
int e = (int)d;              // e = 5
float f = 10.5f;
int g = (int)(f + 2.5);      // 先算 f + 2.5 = 13.0，再转为 int，g = 13
```

不改变原变量的值，只影响表达式的值或赋值结果。指针类型之间的强制转换要谨慎。

### 3. 注意事项

1. **对齐兼容**：强制转换指针类型时，要确保对齐和实际对象类型兼容。
2. **精度丢失**：高精度转低精度可能丢数据；浮点转整数是 **截断**，不是四舍五入。
3. **未知性**：赋值时的隐式转换不一定报错，编译器可能只给警告，需要自己检查。
4. **有符号与无符号混合运算**：有符号数可能被转换为无符号数，导致意外结果。

```c
double d = 3.99;
int n = d;        // n = 3，小数被截断
unsigned int u = 10;
int i = -1;
if (i < u) {      // i 可能被转换为无符号数，比较结果与直觉不同
    printf("可能出乎意料\n");
}
```

## 四、变量与作用域

变量是程序中用于存储数据的内存空间：

1. **定义**：申请空间，例如 `int age;`
2. **初始化**：定义时赋初值，例如 `int age = 18;`
3. **赋值**：定义后修改值，例如 `age = 20;`

```c
int age;              // 定义，未初始化
float score = 95.5f;  // 定义并初始化
char gender = 'M';

age = 18;             // 赋值
age = 20;             // 重新赋值，覆盖旧值
```

**未定义行为：** 局部变量未初始化时值不确定，不要假设局部变量默认是 0。

### 1. 作用域与生命周期

| 类别 | 定义位置 | 作用域 | 生命周期 |
|---|---|---|---|
| 局部变量 | 函数或代码块内 | 当前函数/代码块 | 进入块创建，离开块销毁 |
| 全局变量 | 所有函数外 | 从定义处到文件结束 | 程序启动到程序结束 |
| 静态局部变量 | 函数/代码块内，用 `static` 修饰 | 当前函数/代码块 | 整个程序运行期，仅初始化一次 |

```c
#include <stdio.h>

int global = 100;  // 全局变量

void count(void) {
    static int cnt = 0;  // 静态局部变量，仅初始化一次
    cnt++;
    printf("cnt = %d\n", cnt);
}

int main(void) {
    count();  // cnt = 1
    count();  // cnt = 2
    printf("global = %d\n", global);
    return 0;
}
```

**静态局部变量** 作用域仍在函数内，但生命周期是整个程序：函数多次调用时保留上一次的值。

### 2. 同名变量

若局部变量与全局变量 **同名**，作用域内 **优先访问局部变量**：

```c
#include <stdio.h>

int x = 10;

void func(void) {
    int x = 20;
    printf("func: x = %d\n", x);  // 20，访问局部变量
}

int main(void) {
    func();
    printf("main: x = %d\n", x);  // 10，访问全局变量
    return 0;
}
```

同名变量容易造成阅读混淆，实际项目中应尽量避免。

## 五、常量

常量是值不可修改的量。C 语言常见形式有四种：

| 形式 | 写法 | 特点 |
|---|---|---|
| 字面常量 | `123`、`3.14f`、`'A'`、`"hello"` | 直接写出的值 |
| `const` 常量 | `const int MAX = 100;` | 编译期检查，不可修改 |
| 宏常量 | `#define PI 3.14159` | 预处理文本替换，无类型检查 |
| 枚举常量 | `enum Week { MON, TUE, WED };` | 本质为整型，默认从 0 递增 |

```c
#define PI 3.14159
const int MAX = 100;
enum Week { MON, TUE, WED };  // MON=0, TUE=1, WED=2
```

### 1. 宏常量与 `const` 常量的区别

**宏** 是 **预处理阶段** 的 **文本替换**，不参与类型检查，也没有作用域概念：

```c
#define SQUARE(x) ((x) * (x))

int a = SQUARE(1 + 2);  // 展开为 ((1 + 2) * (1 + 2))，结果为 9
```

宏参数不加括号很容易出错：

```c
#define BAD_SQUARE(x) x * x

int b = BAD_SQUARE(1 + 2);  // 展开为 1 + 2 * 1 + 2，结果为 5
```

**`const` 常量** 有类型、有作用域，调试时也能看到符号，通常更安全。整型常量和错误码用 `enum` 或 `const` 往往比宏更利于调试和类型检查。

### 2. 枚举常量

```c
enum Week {
    MON,  // 0
    TUE,  // 1
    WED   // 2
};

enum Status {
    OK = 0,
    ERR_PARAM = 1,
    ERR_FILE = 2
};
```

枚举本质是 **整型**，适合表示离散状态集合，能提高可读性。

## 六、分支结构

### 1. `if` 单分支

条件表达式为真（非 0）时执行语句块，否则跳过：

```c
if (条件表达式) {
    语句块;
}
```

```c
#include <stdio.h>

int main(void) {
    int num = 10;

    if (num > 0) {
        printf("%d 是正数\n", num);
    }

    return 0;
}
```

### 2. `if-else` 双分支

条件为真执行语句块 1，否则执行语句块 2：

```c
if (条件表达式) {
    语句块1;
} else {
    语句块2;
}
```

```c
#include <stdio.h>

int main(void) {
    int num = 7;

    if (num % 2 == 0) {
        printf("%d 是偶数\n", num);
    } else {
        printf("%d 是奇数\n", num);
    }

    return 0;
}
```

### 3. `if-else if-else` 多分支

依次判断条件，执行第一个为真的分支；都不满足执行 `else`：

```c
if (条件表达式1) {
    语句块1;
} else if (条件表达式2) {
    语句块2;
} else {
    语句块n;
}
```

```c
#include <stdio.h>

int main(void) {
    int score = 85;

    if (score >= 90) {
        printf("等级：A\n");
    } else if (score >= 80) {
        printf("等级：B\n");
    } else if (score >= 60) {
        printf("等级：C\n");
    } else {
        printf("等级：D\n");
    }

    return 0;
}
```

**注意：**

- 条件从上到下判断，第一个为真的分支执行后，后续分支不再判断。
- 多分支条件顺序很重要。上例中 `score >= 90` 必须放在 `score >= 80` 之前，否则 95 分也会先命中 `>= 80`。
- `else` 与最近的未匹配 `if` 配对，嵌套 `if` 建议加花括号避免歧义。

### 4. `switch` 多条件匹配

`switch` 根据表达式的值匹配 `case` 常量，适合离散整型或枚举值：

```c
switch (表达式) {
    case 常量1:
        语句块1;
        break;
    case 常量2:
        语句块2;
        break;
    default:
        语句块n;
}
```

```c
#include <stdio.h>

int main(void) {
    int day = 3;

    switch (day) {
        case 1: printf("星期一\n"); break;
        case 2: printf("星期二\n"); break;
        case 3: printf("星期三\n"); break;
        case 4: printf("星期四\n"); break;
        case 5: printf("星期五\n"); break;
        case 6: printf("星期六\n"); break;
        case 7: printf("星期日\n"); break;
        default: printf("输入无效\n");
    }

    return 0;
}
```

**`switch` 要点：**

- 表达式必须是整型或枚举类型，不能是浮点数、字符串。
- `case` 后必须是编译期整型常量表达式，不能是变量。
- `break` 用于跳出 `switch`；缺少 `break` 会发生“贯穿”，继续执行下一个 `case`。
- `default` 可选，处理所有未匹配情况。
- 多个 `case` 可共享同一段代码：

```c
switch (ch) {
    case 'a':
    case 'e':
    case 'i':
    case 'o':
    case 'u':
        printf("元音\n");
        break;
    default:
        printf("辅音或其他\n");
}
```

### 5. 三元条件运算符

简单二选一可用 `?:` 简化：

```c
int max = (a > b) ? a : b;
```

等价于：

```c
int max;
if (a > b) {
    max = a;
} else {
    max = b;
}
```

三元运算符适合简单赋值，嵌套过多会降低可读性，复杂逻辑仍应使用 `if-else`。

## 七、循环结构

C 语言提供 `for`、`while`、`do-while` 三种循环。

### 1. `for` 循环：固定次数循环

```c
for (初始化表达式; 条件表达式; 更新表达式) {
    循环体;
}
```

执行流程：

1. 执行初始化表达式（只执行一次）。
2. 判断条件表达式，为真则执行循环体，为假则退出。
3. 执行更新表达式。
4. 重复步骤 2–3。

```c
#include <stdio.h>

int main(void) {
    for (int i = 1; i <= 10; i++) {
        printf("%d ", i);
    }
    printf("\n");
    return 0;
}
```

`for` 适合循环次数已知的场景。三部分都可以省略，但省略条件时等价于永真，需要配合 `break` 退出：

```c
for (;;) {
    // 无限循环，需要 break 退出
}
```

### 2. `while` 循环：先判断后执行

```c
while (条件表达式) {
    循环体;
}
```

先判断条件，为真则执行循环体，重复此过程；条件一开始为假时，循环体一次都不执行。

```c
#include <stdio.h>

int main(void) {
    int i = 1;
    int sum = 0;

    while (i <= 100) {
        sum += i;
        i++;
    }

    printf("1 到 100 的和为：%d\n", sum);
    return 0;
}
```

`while` 适合循环次数未知、依赖条件退出的场景。循环体内必须有改变条件的语句，否则可能死循环。

### 3. `do-while` 循环：先执行后判断

```c
do {
    循环体;
} while (条件表达式);
```

先执行循环体，再判断条件；条件为真则继续循环，否则退出。循环体至少执行一次。

```c
#include <stdio.h>

int main(void) {
    int num;

    do {
        printf("请输入一个正整数：");
        scanf("%d", &num);
    } while (num <= 0);

    printf("你输入的正整数是：%d\n", num);
    return 0;
}
```

`do-while` 适合 **“至少执行一次”** 的场景，例如输入校验。

### 4. 三种循环的选择

| 循环 | 特点 | 适用场景 |
|---|---|---|
| `for` | 初始化、条件、更新集中在一行 | 循环次数已知或可计算 |
| `while` | 先判断后执行 | 循环次数未知，依赖条件退出 |
| `do-while` | 先执行后判断，至少执行一次 | 输入校验、菜单循环 |

三种循环可以互相转换，选择可读性最好的即可。

### 5. `break`：跳出当前循环或 `switch`

`break` 立即跳出当前所在的循环或 `switch`，执行后续代码：

```c
#include <stdio.h>

int main(void) {
    int arr[] = {2, 4, 6, 8, 10};
    int target = 6;
    int found = -1;

    for (int i = 0; i < 5; i++) {
        if (arr[i] == target) {
            found = i;
            break;
        }
    }

    if (found != -1) {
        printf("找到目标值，索引为：%d\n", found);
    } else {
        printf("未找到\n");
    }

    return 0;
}
```

`break` 只跳出 **最内层** 循环或 `switch`，不会跳出多层嵌套。

### 6. `continue`：跳过本次循环剩余部分

`continue` 跳过本次循环的剩余代码，直接进入下一次循环的条件判断：

```c
#include <stdio.h>

int main(void) {
    for (int i = 1; i <= 10; i++) {
        if (i % 2 == 0) {
            continue;  // 偶数跳过，不执行 printf
        }
        printf("%d ", i);
    }
    printf("\n");
    return 0;
}
```

**注意：**

- `continue` 不跳出循环，只跳过当前这一轮。
- `for` 循环中 `continue` 会执行更新表达式；`while` 循环中如果更新语句在 `continue` 之后，可能造成死循环。
- `break` 和 `continue` 都只作用于最内层循环。

### 7. 多层循环的退出

常用两种方式：

1. `break` 只能跳出最内层循环。
2. `goto` 通常不推荐，但 **“从多层嵌套中统一跳转到清理代码”** 是其少数合理用法之一。

```c
// 方式一：使用标志变量
int found = 0;
for (int i = 0; i < 3 && !found; i++) {
    for (int j = 0; j < 3; j++) {
        if (matrix[i][j] == target) {
            found = 1;
            break;
        }
    }
}

// 方式二：使用 goto（谨慎使用，但跳出多层循环是合理场景）
for (int i = 0; i < 3; i++) {
    for (int j = 0; j < 3; j++) {
        if (matrix[i][j] == target) {
            goto found_label;
        }
    }
}
found_label:
printf("找到目标\n");
```

## 八、函数

### 1. 函数定义

```c
返回值类型 函数名(参数类型1 参数名1, 参数类型2 参数名2, ...) {
    函数体;
    return 返回值;
}
```

```c
int sum(int a, int b) {
    return a + b;
}
```

- 返回值类型为 `void` 时，函数不返回值，可省略 `return` 或只写 `return;`。
- 无参数时参数列表写 `void`，例如 `int func(void)`。
- 函数名遵循标识符命名规则。

### 2. 函数声明

函数声明用于提前告知编译器函数的存在。函数定义在调用位置之后时，必须先声明：

```c
#include <stdio.h>

int sum(int a, int b);  // 函数声明，以分号结尾

int main(void) {
    printf("%d\n", sum(3, 5));
    return 0;
}

int sum(int a, int b) {  // 函数定义
    return a + b;
}
```

声明中的参数名可以省略，例如 `int sum(int, int);`。

### 3. 函数调用

格式 `函数名(实参列表)`：

```c
int result = sum(3, 5);
```

调用时，实参的值或地址传递给形参。C 语言参数传递只有一种方式：**传值**。所谓“传址调用”本质是把地址值传给指针形参。

### 4. 传值调用

形参是实参的副本，函数内修改形参不影响实参：

```c
#include <stdio.h>

void change(int x) {
    x = 100;  // 只修改形参 x
}

int main(void) {
    int num = 10;
    change(num);
    printf("num = %d\n", num);  // 仍为 10
    return 0;
}
```

### 5. 传址调用

传入实参的地址，函数通过指针修改实参指向的数据：

```c
#include <stdio.h>

void swap(int *p1, int *p2) {
    int temp = *p1;
    *p1 = *p2;
    *p2 = temp;
}

int main(void) {
    int a = 5, b = 10;
    swap(&a, &b);
    printf("a = %d, b = %d\n", a, b);  // a = 10, b = 5
    return 0;
}
```

**要点：**

- 传值调用适合只读参数或不需要修改实参的场景。
- 传址调用适合需要修改实参、传递大结构体避免复制、或需要返回多个值的场景。
- 传入指针后，函数内要先检查指针是否为 `NULL`，再解引用。

### 6. 数组作为函数参数

数组作为参数时退化为指向首元素的指针，函数内无法通过 `sizeof` 得到数组长度，需额外传入长度：

```c
#include <stdio.h>

void print_arr(int arr[], int n) {
    for (int i = 0; i < n; i++) {
        printf("%d ", arr[i]);
    }
    printf("\n");
}

int main(void) {
    int a[5] = {1, 2, 3, 4, 5};
    print_arr(a, 5);
    return 0;
}
```

`int arr[]` 与 `int *arr` 在参数位置上等价。数组参数本质是传址，函数内修改 `arr[i]` 会影响原数组。

### 7. 递归

递归函数是直接或间接调用自身的函数，必须满足两个条件：

- **终止条件**：递归必须有出口，否则会无限递归导致栈溢出。
- **递归关系**：将原问题分解为更小的同类子问题。

#### 7.1 阶乘

```c
#include <stdio.h>

int factorial(int n) {
    if (n <= 1) {          // 终止条件
        return 1;
    }
    return n * factorial(n - 1);  // 递归关系
}

int main(void) {
    printf("5! = %d\n", factorial(5));  // 120
    return 0;
}
```

#### 7.2 斐波那契数列

```c
int fibonacci(int n) {
    if (n == 1 || n == 2) {  // 终止条件
        return 1;
    }
    return fibonacci(n - 1) + fibonacci(n - 2);  // 递归关系
}
```

递归写法直观，但朴素递归会重复计算大量子问题，`n` 较大时效率极低。实际可用迭代或记忆化：

```c
int fibonacci_iter(int n) {
    if (n == 1 || n == 2) {
        return 1;
    }

    int a = 1, b = 1, c = 0;
    for (int i = 3; i <= n; i++) {
        c = a + b;
        a = b;
        b = c;
    }
    return c;
}
```

#### 7.3 递归避坑

1. 必须有终止条件，且终止条件必须能在有限步内到达。
2. 递归深度过大会导致栈溢出，深度较大时应改用迭代。
3. 递归可能有大量重复计算，必要时用记忆化或迭代优化。
4. 递归函数的参数应逐步向终止条件靠近，否则可能无限递归。

### 8. 函数指针

函数指针是保存函数地址的指针变量，可用于实现回调。

#### 8.1 定义与调用

```c
返回值类型 (*指针名)(参数类型1, 参数类型2, ...);
```

```c
#include <stdio.h>

int add(int a, int b) {
    return a + b;
}

int main(void) {
    int (*p)(int, int) = add;  // p 指向 add 函数
    printf("%d\n", p(3, 5));   // 通过函数指针调用，输出 8
    printf("%d\n", (*p)(3, 5)); // 等价写法
    return 0;
}
```

#### 8.2 回调函数

函数指针常用于把函数作为参数传递，实现回调：

```c
#include <stdio.h>

int add(int a, int b) { return a + b; }
int mul(int a, int b) { return a * b; }

int calculate(int (*func)(int, int), int a, int b) {
    return func(a, b);
}

int main(void) {
    int (*p)(int, int) = add;
    printf("3 + 5 = %d\n", calculate(p, 3, 5));  // 8

    p = mul;
    printf("3 * 5 = %d\n", calculate(p, 3, 5));  // 15

    return 0;
}
```

#### 8.3 函数指针避坑

1. 函数指针的类型必须与目标函数匹配：返回值类型和参数类型都要一致。
2. `int (*p)(int, int)` 中括号不能省，`int *p(int, int)` 是返回指针的函数声明。
3. 函数名在表达式中通常退化为函数指针，`p = add` 和 `p = &add` 等价。
4. 调用函数指针前应确保它已指向有效函数，未初始化的函数指针解引用属于未定义行为。

### 9. 综合示例：菜单循环 + 函数回调

```c
#include <stdio.h>

int add(int a, int b) { return a + b; }
int sub(int a, int b) { return a - b; }
int mul(int a, int b) { return a * b; }

int main(void) {
    int choice;
    int a, b;

    do {
        printf("\n1. 加法  2. 减法  3. 乘法  0. 退出\n");
        printf("请选择：");
        scanf("%d", &choice);

        if (choice == 0) {
            break;
        }

        printf("请输入两个整数：");
        scanf("%d %d", &a, &b);

        switch (choice) {
            case 1: printf("结果：%d\n", add(a, b)); break;
            case 2: printf("结果：%d\n", sub(a, b)); break;
            case 3: printf("结果：%d\n", mul(a, b)); break;
            default: printf("无效选择\n");
        }
    } while (1);

    return 0;
}
```

- `do-while` 保证菜单至少显示一次。
- `switch` 根据选择分派到不同函数。
- `break` 用于跳出 `switch` 和退出菜单循环。
- 三个运算函数通过函数名直接调用；需要运行时切换算法时，可改成函数指针数组。

## 九、数组与字符串

### 1. 一维数组

数组是 **同类型元素的连续内存块**：

```c
int arr[5];                    // 仅定义，元素未初始化
int a[5] = {1, 2, 3, 4, 5};    // 完全初始化
int b[5] = {1, 2};             // 部分初始化，其余元素为 0
int c[] = {1, 2, 3};           // 长度由初始化元素个数决定，长度为 3
int d[5] = {0};                // 全部元素初始化为 0
```

**要点：**

- 下标从 `0` 开始，合法范围 `0 ~ 长度-1`。
- C 不检查数组越界，越界访问属于未定义行为。
- 局部数组未初始化时元素值不确定；全局数组和静态数组默认初始化为 0。
- 数组长度必须是编译期常量（C99 起支持变长数组，但实践中应谨慎使用）。
- 数组名在大多数表达式中退化为指向首元素的指针，但数组本身不是指针。`sizeof(数组名)` 得到整个数组的字节数。

输入输出：

```c
#include <stdio.h>

int main(void) {
    int arr[5];

    printf("请输入 5 个整数：\n");
    for (int i = 0; i < 5; i++) {
        scanf("%d", &arr[i]);
    }

    printf("数组元素：");
    for (int i = 0; i < 5; i++) {
        printf("%d ", arr[i]);
    }
    printf("\n");

    return 0;
}
```

注意 `scanf("%d", &arr[i])` 中的 `&`：`arr[i]` 是普通 `int` 变量，需要取地址。

### 2. 二维数组

二维数组可以理解为“多个一维数组的数组”：

```c
数据类型 数组名[行数][列数];
```

```c
int matrix[2][3];  // 2 行 3 列，共 6 个 int

int m1[2][3] = {{1, 2, 3}, {4, 5, 6}};  // 按行初始化
int m2[2][3] = {1, 2, 3, 4, 5, 6};      // 按顺序初始化，效果同上
int m3[2][3] = {{1}, {4, 5}};            // 部分初始化，其余为 0
```

访问格式 `数组名[行下标][列下标]`，行列下标均从 0 开始：

```c
matrix[0][1] = 10;            // 第 1 行第 2 列
printf("%d\n", matrix[1][2]); // 第 2 行第 3 列
```

输入输出通常需要双重循环：

```c
#include <stdio.h>

int main(void) {
    int matrix[2][3];

    printf("请输入 2 行 3 列整数：\n");
    for (int i = 0; i < 2; i++) {
        for (int j = 0; j < 3; j++) {
            scanf("%d", &matrix[i][j]);
        }
    }

    printf("二维数组元素：\n");
    for (int i = 0; i < 2; i++) {
        for (int j = 0; j < 3; j++) {
            printf("%d ", matrix[i][j]);
        }
        printf("\n");
    }

    return 0;
}
```

对于 `int matrix[2][3]`，`matrix[0]` 是第一个包含 3 个 `int` 的一维数组，`matrix[1]` 是第二个。二维数组在内存中按行连续存放。

### 3. 二维与一维转换

二维转一维（按行展开）：

```c
int matrix[2][3] = {{1, 2, 3}, {4, 5, 6}};
int arr[6];
int index = 0;

for (int i = 0; i < 2; i++) {
    for (int j = 0; j < 3; j++) {
        arr[index++] = matrix[i][j];
    }
}
// arr = {1, 2, 3, 4, 5, 6}
```

一维转二维：

```c
int arr[6] = {7, 8, 9, 10, 11, 12};
int matrix[2][3];
int index = 0;

for (int i = 0; i < 2; i++) {
    for (int j = 0; j < 3; j++) {
        matrix[i][j] = arr[index++];
    }
}
```

### 4. 数组作为函数参数

数组作为函数参数时会退化为指向首元素的指针，函数内无法通过 `sizeof` 得到数组长度，通常需要额外传入长度：

```c
#include <stdio.h>

void print_arr(int arr[], int n) {
    for (int i = 0; i < n; i++) {
        printf("%d ", arr[i]);
    }
    printf("\n");
}

int main(void) {
    int a[5] = {1, 2, 3, 4, 5};
    print_arr(a, 5);
    return 0;
}
```

`void print_arr(int arr[], int n)` 与 `void print_arr(int *arr, int n)` 在参数位置上等价。二维数组作为参数时，**列数不能省略**：

```c
void print_matrix(int matrix[][3], int rows) {
    for (int i = 0; i < rows; i++) {
        for (int j = 0; j < 3; j++) {
            printf("%d ", matrix[i][j]);
        }
        printf("\n");
    }
}
```

### 5. 字符串

C 语言没有独立的字符串类型。字符串本质是 **以 `'\0'` 结尾的字符数组**。`'\0'` 是 ASCII 值为 0 的空字符，用作字符串结束标志。

```c
char s1[] = "Hello";  // 等价于 {'H','e','l','l','o','\0'}，长度为 6
char s2[10] = "Hello"; // 数组长度 10，前 6 个元素为 Hello\0，其余为 0
char s3[] = {'H', 'e', 'l', 'l', 'o'}; // 不是字符串，没有 '\0'
```

**区别：**

- `char s1[] = "Hello";` 是字符串，末尾自动补 `'\0'`。
- `char s3[] = {'H', 'e', 'l', 'l', 'o'};` 是字符数组，不是字符串，不能直接传给 `printf("%s")` 或 `strlen`。
- `char *p = "Hello";` 指向字符串字面量，内容通常不可修改，不要通过 `p[0] = 'h'` 修改。

### 6. 常用字符串函数

需包含 `<string.h>`：

| 函数 | 功能 | 注意事项 |
|---|---|---|
| `strlen(s)` | 求字符串长度，不含 `'\0'` | 返回 `size_t`，输出用 `%zu` |
| `strcpy(dest, src)` | 复制字符串，包含 `'\0'` | `dest` 必须足够大 |
| `strncpy(dest, src, n)` | 最多复制 n 个字符 | 不保证补 `'\0'`，需手动处理 |
| `strcmp(s1, s2)` | 比较字符串 | 相等返回 0；按字典序返回正/负 |
| `strncmp(s1, s2, n)` | 比较前 n 个字符 | 常用于前缀比较 |
| `strcat(dest, src)` | 拼接字符串 | `dest` 必须足够大，且以 `'\0'` 结尾 |
| `strchr(s, c)` | 查找字符 | 返回首次出现位置指针，找不到返回 `NULL` |
| `strstr(s1, s2)` | 查找子串 | 返回首次出现位置指针，找不到返回 `NULL` |

```c
#include <stdio.h>
#include <string.h>

int main(void) {
    char s1[20] = "Hello";
    char s2[20] = "World";
    char s3[40];

    printf("strlen(s1) = %zu\n", strlen(s1));  // 5

    strcpy(s3, s1);
    printf("strcpy 后 s3 = %s\n", s3);          // Hello

    strcat(s3, " ");
    strcat(s3, s2);
    printf("strcat 后 s3 = %s\n", s3);          // Hello World

    int cmp = strcmp(s1, s2);
    if (cmp == 0) {
        printf("s1 == s2\n");
    } else if (cmp < 0) {
        printf("s1 < s2\n");                    // 按字典序 Hello < World
    } else {
        printf("s1 > s2\n");
    }

    char *pos = strchr(s3, 'W');
    if (pos != NULL) {
        printf("找到 W，位置偏移 = %ld\n", pos - s3);
    }

    return 0;
}
```

### 7. 字符串避坑

1. 字符串必须以 `'\0'` 结尾，否则 `strlen`、`printf("%s")`、`strcpy` 等可能越界读取。
2. `strcpy`、`strcat` 不检查目标缓冲区大小，目标空间不足会导致缓冲区溢出。
3. `strncpy(dest, src, n)` 在 `src` 长度大于等于 `n` 时不会自动补 `'\0'`，需要手动设置 `dest[n-1] = '\0'`。
4. `strcmp` 比较的是字典序，不是长度。
5. 字符串字面量通常存放在只读区域，不要通过指针修改。

## 十、标准 I/O 与文件操作

C 语言通过 `<stdio.h>` 提供输入输出函数。按操作对象分为：

- **标准 I/O**：键盘（`stdin`）、屏幕（`stdout`、`stderr`）。
- **文件 I/O**：磁盘文件，通过 `FILE *` 文件指针操作。

**文件操作三步流程：**

1. **打开文件**：用 `fopen()` 建立程序与文件的连接，获取文件指针 `FILE *`。
2. **操作文件**：用读写函数（`fread()`、`fwrite()`、`fprintf()` 等）进行数据交互。
3. **关闭文件**：用 `fclose()` 释放资源，确保缓冲区数据同步到磁盘。

**关键概念：**

| 概念 | 说明 |
|---|---|
| 文件指针 `FILE *` | 系统维护的结构体指针，记录文件位置、打开模式、缓冲区状态等信息 |
| 文本文件 | 以字符编码存储，可直接阅读，如 `.txt`、`.csv` |
| 二进制文件 | 以字节流存储，需按格式解析，如图片、视频、结构体数据 |
| 缓冲区 | 系统为文件 I/O 分配的临时内存，减少磁盘读写次数；`fflush()` 可手动刷新输出缓冲区 |

### 1. 常用 I/O 函数速查

| 函数 | 方向 | 说明 |
|---|---|---|
| `putchar(c)` | 输出到屏幕 | 输出一个字符，等价于 `fputc(c, stdout)` |
| `fputc(c, stream)` | 输出到文件/屏幕 | 输出一个字符，`stream` 可为 `stdout` |
| `puts(s)` | 输出到屏幕 | 输出字符串并自动换行 |
| `fputs(s, stream)` | 输出到文件/屏幕 | 输出字符串，不自动换行 |
| `printf(fmt, ...)` | 格式化输出到屏幕 | 最常用输出 |
| `fprintf(stream, fmt, ...)` | 格式化输出到文件 | 用法类似 `printf` |
| `getchar()` | 从键盘读字符 | 返回 `int`，便于判断 `EOF` |
| `fgetc(stream)` | 从文件/键盘读字符 | `stream` 可为 `stdin` |
| `fgets(s, n, stream)` | 安全读取字符串 | 最多读 `n-1` 个字符，保留换行符 |
| `scanf(fmt, ...)` | 格式化从键盘读取 | 普通变量需加 `&` |
| `fscanf(stream, fmt, ...)` | 格式化从文件读取 | 格式需与文件内容匹配 |
| `fopen(path, mode)` | 打开文件 | 返回 `FILE *`，失败返回 `NULL` |
| `fclose(fp)` | 关闭文件 | 使用后必须关闭 |
| `fread(ptr, size, nmemb, stream)` | 二进制读 | 返回实际读取的块数 |
| `fwrite(ptr, size, nmemb, stream)` | 二进制写 | 返回实际写入的块数 |
| `fseek(fp, offset, whence)` | 移动文件指针 | 随机读写 |
| `ftell(fp)` | 返回当前偏移量 | 配合 `fseek` 使用 |
| `rewind(fp)` | 重置指针到文件开头 | 等价于 `fseek(fp, 0, SEEK_SET)` |

> **不推荐 `gets()`**：无长度限制，存在缓冲区溢出风险，C11 已废弃。  
> **不推荐 `fflush(stdin)`**：该用法非标准，行为未定义。需要清空输入缓冲区时，可循环读取字符直到 `'\n'` 或 `EOF`。

### 2. 字符输入输出

```c
#include <stdio.h>

int main(void) {
    printf("请输入一个字符：");
    int ch = getchar();  // 用 int 接收，便于判断 EOF

    if (ch != EOF) {
        printf("你输入的是：");
        putchar(ch);
        printf("\nASCII = %d\n", ch);
    }

    return 0;
}
```

`getchar()` 返回 `int`，因为 `EOF` 通常是 `-1`，用 `char` 接收可能无法正确区分普通字符和 `EOF`。

### 3. 读取含空格的字符串

`scanf("%s", buf)` 遇空白就停止，不能读取含空格的整行。安全读取整行的常用方法是 `fgets`：

```c
#include <stdio.h>
#include <string.h>

int main(void) {
    char buf[50];

    printf("请输入一行文本（可含空格）：");
    if (fgets(buf, sizeof(buf), stdin) != NULL) {
        buf[strcspn(buf, "\n")] = '\0';  // 去掉可能存在的换行符
        printf("你输入的是：%s\n", buf);
    }

    return 0;
}
```

**`fgets` 要点：**

- 最多读取 `n-1` 个字符，最后自动补 `'\0'`。
- 如果读到换行符，会保留在缓冲区中。
- 输入超过 `n-1` 个字符时，只读取前 `n-1` 个，剩余字符留在输入缓冲区。
- 读到文件末尾或出错时返回 `NULL`。

也可以用扫描集 `%[^\n]`，但它不限制宽度时仍有溢出风险，且会留下换行符：

```c
char buf[50];
scanf("%49[^\n]", buf);  // 最多读 49 个字符，遇换行停止
```

### 4. 格式化输入输出

```c
#include <stdio.h>

int main(void) {
    int num;
    double score;
    char name[20];

    printf("请输入整数和浮点数：");
    if (scanf("%d %lf", &num, &score) != 2) {
        printf("输入格式错误\n");
        return 1;
    }

    printf("请输入姓名（无空格）：");
    scanf("%19s", name);  // 限制宽度，给 '\0' 留位置

    printf("num = %d, score = %.2f, name = %s\n", num, score, name);
    return 0;
}
```

**要点：**

- `scanf` 返回成功读取的数据个数，可用于判断输入是否匹配。
- 读取普通变量必须加 `&`；字符数组名本身是地址，通常不加 `&`。
- `%c` 不跳过空白字符，前面有残留换行时可用 `" %c"`。
- `%s` 遇空白停止，不能读取含空格字符串。
- 用 `%19s` 这类宽度限制防止缓冲区溢出。

### 5. 打开与关闭文件

#### 5.1 `fopen()`：打开文件

```c
FILE *fopen(const char *filename, const char *mode);
```

- `filename`：文件路径，可以是相对路径（如 `test.txt`）或绝对路径。
- `mode`：打开模式，决定操作权限和文件类型。
- 返回值：成功返回文件指针，失败返回 `NULL`。必须检查返回值。

```c
#include <stdio.h>

int main(void) {
    FILE *fp = fopen("test.txt", "r");
    if (fp == NULL) {
        perror("fopen");
        return 1;
    }

    // 文件操作...

    fclose(fp);
    return 0;
}
```

#### 5.2 `fclose()`：关闭文件

```c
int fclose(FILE *stream);
```

- 成功返回 `0`，失败返回 `EOF`。
- 关闭后文件指针不应再使用。
- 程序退出前应关闭所有打开的文件，否则缓冲区数据可能未写入磁盘。

#### 5.3 文件打开模式

| 模式 | 类型 | 功能 | 文件不存在时 | 注意事项 |
|---|---|---|---|---|
| `"r"` | 文本 | 只读，指针在开头 | 打开失败 | 文件必须存在 |
| `"w"` | 文本 | 只写，清空或创建 | 创建新文件 | 会覆盖原内容，慎用 |
| `"a"` | 文本 | 追加写，指针在末尾 | 创建新文件 | 只能末尾追加 |
| `"r+"` | 文本 | 读写，指针在开头 | 打开失败 | 写入从当前位置覆盖 |
| `"w+"` | 文本 | 读写，清空或创建 | 创建新文件 | 适合重新写入并读取 |
| `"a+"` | 文本 | 读写，追加写 | 创建新文件 | 读之前需移动指针到开头 |
| `"rb"` | 二进制 | 只读 | 打开失败 | 用于图片、视频等 |
| `"wb"` | 二进制 | 只写，清空或创建 | 创建新文件 | 用于保存二进制数据 |
| `"ab"` | 二进制 | 追加写 | 创建新文件 | 适合追加二进制日志 |
| `"wx"` / `"xb"` | 文本/二进制 | 独占创建，文件已存在则失败 | 创建新文件 | C11 可选，避免覆盖已有文件 |

> 文本模式在部分平台会转换换行符，处理非文本文件时应使用二进制模式 `b`。

### 6. 文件读写方法

#### 6.1 字符读写：`fgetc()` / `fputc()`

适合逐字符处理文本，例如统计字符数、逐字节加密。

```c
int fgetc(FILE *stream);          // 读取一个字符，返回 int，读到末尾或出错返回 EOF
int fputc(int c, FILE *stream);   // 写入一个字符
```

```c
#include <stdio.h>

int count_chars(const char *filename) {
    FILE *fp = fopen(filename, "r");
    if (fp == NULL) {
        perror("fopen");
        return -1;
    }

    int count = 0;
    int ch;
    while ((ch = fgetc(fp)) != EOF) {
        count++;
    }

    fclose(fp);
    return count;
}

int main(void) {
    printf("字符数：%d\n", count_chars("test.txt"));
    return 0;
}
```

#### 6.2 格式化读写：`fprintf()` / `fscanf()`

用法类似 `printf` / `scanf`，多一个文件指针参数。

```c
int fprintf(FILE *stream, const char *format, ...);
int fscanf(FILE *stream, const char *format, ...);
```

```c
#include <stdio.h>

typedef struct {
    char name[20];
    int age;
    float score;
} Student;

int main(void) {
    Student stu = {"ZhangSan", 20, 95.5f};

    FILE *fp = fopen("students.txt", "w");
    if (fp == NULL) {
        perror("fopen");
        return 1;
    }
    fprintf(fp, "%s %d %.1f\n", stu.name, stu.age, stu.score);
    fclose(fp);

    fp = fopen("students.txt", "r");
    if (fp == NULL) {
        perror("fopen");
        return 1;
    }
    if (fscanf(fp, "%19s %d %f", stu.name, &stu.age, &stu.score) == 3) {
        printf("读取结果：%s %d %.1f\n", stu.name, stu.age, stu.score);
    }
    fclose(fp);

    return 0;
}
```

> `fscanf` 的 `%s` 遇空白停止，不能读取含空格的字符串。若字段含空格，建议用 `fgets` 读整行，再用 `sscanf` 解析，或改用明确分隔符的格式。

#### 6.3 字符串读写：`fgets()` / `fputs()`

```c
char *fgets(char *str, int num, FILE *stream);
int fputs(const char *str, FILE *stream);
```

```c
#include <stdio.h>

int main(void) {
    FILE *fp = fopen("output.txt", "w");
    if (fp == NULL) {
        perror("fopen");
        return 1;
    }
    fputs("第一行文本\n", fp);
    fputs("第二行文本（含空格）\n", fp);
    fclose(fp);

    fp = fopen("output.txt", "r");
    if (fp == NULL) {
        perror("fopen");
        return 1;
    }

    char buf[1024];
    while (fgets(buf, sizeof(buf), fp) != NULL) {
        printf("%s", buf);  // fgets 保留换行符
    }
    fclose(fp);

    return 0;
}
```

- `fgets` 最多读取 `num - 1` 个字符，自动补 `'\0'`，遇换行或文件末尾停止。
- `fputs` 不自动添加换行符，需要手动写 `\n`。
- 不要使用 `gets()`，它没有长度限制，C11 已废弃。

#### 6.4 二进制读写：`fread()` / `fwrite()`

直接操作字节流，适合图片、视频、结构体数组等。

```c
size_t fread(void *ptr, size_t size, size_t nmemb, FILE *stream);
size_t fwrite(const void *ptr, size_t size, size_t nmemb, FILE *stream);
```

返回值是**实际读写的块数**，不是字节数。

```c
#include <stdio.h>

typedef struct {
    int id;
    char name[20];
    float score;
} Student;

int main(void) {
    Student stus[3] = {
        {1, "Zhang San", 95.5f},
        {2, "Li Si", 88.0f},
        {3, "Wang Wu", 92.3f}
    };

    FILE *fp = fopen("students.bin", "wb");
    if (fp == NULL) {
        perror("fopen");
        return 1;
    }
    size_t written = fwrite(stus, sizeof(Student), 3, fp);
    printf("写入 %zu 个学生\n", written);
    fclose(fp);

    Student read_stus[3];
    fp = fopen("students.bin", "rb");
    if (fp == NULL) {
        perror("fopen");
        return 1;
    }
    size_t read_num = fread(read_stus, sizeof(Student), 3, fp);
    printf("读取 %zu 个学生\n", read_num);
    for (size_t i = 0; i < read_num; i++) {
        printf("%d %s %.1f\n", read_stus[i].id, read_stus[i].name, read_stus[i].score);
    }
    fclose(fp);

    return 0;
}
```

#### 7.2 逐字符读取

```c
#include <stdio.h>

int main(void) {
    FILE *fp = fopen("data.txt", "r");
```

`fgetc` 返回 `int`，便于区分普通字符和 `EOF`。

### 8. 文件指针定位

文件指针默认按顺序移动。需要随机读写时，可用以下函数调整位置。

| 函数 | 作用 |
|---|---|
| `fseek(fp, offset, whence)` | 移动文件指针 |
| `ftell(fp)` | 返回当前指针相对于文件开头的偏移量 |
| `rewind(fp)` | 重置指针到文件开头，等价于 `fseek(fp, 0, SEEK_SET)` |

`whence` 可取：

| 常量 | 含义 |
|---|---|
| `SEEK_SET` | 文件开头 |
| `SEEK_CUR` | 当前位置 |
| `SEEK_END` | 文件末尾 |

```c
#include <stdio.h>

long get_file_size(const char *filename) {
    FILE *fp = fopen(filename, "rb");
    if (fp == NULL) {
        perror("fopen");
        return -1;
    }

    fseek(fp, 0, SEEK_END);
    long size = ftell(fp);
    fclose(fp);
    return size;
}

int main(void) {
    printf("文件大小：%ld 字节\n", get_file_size("test.txt"));
    return 0;
}
```

### 9. 常见实战

#### 9.1 文件复制

用 `fread` / `fwrite` 分块复制，适合任意类型文件。缓冲区不要放在栈上过大，可用 `static` 或动态分配。

```c
#include <stdio.h>
#include <stdlib.h>

#define BUF_SIZE (1024 * 1024)  // 1MB

int copy_file(const char *src_path, const char *dst_path) {
    FILE *src = fopen(src_path, "rb");
    FILE *dst = fopen(dst_path, "wb");

    if (src == NULL || dst == NULL) {
        perror("open");
        if (src != NULL) fclose(src);
        if (dst != NULL) fclose(dst);
        return -1;
    }

    static char buf[BUF_SIZE];
    size_t read_num;
    while ((read_num = fread(buf, 1, BUF_SIZE, src)) > 0) {
        size_t write_num = fwrite(buf, 1, read_num, dst);
        if (write_num != read_num) {
            perror("write");
            fclose(src);
            fclose(dst);
            return -1;
        }
    }

    if (ferror(src)) {
        perror("read");
        fclose(src);
        fclose(dst);
        return -1;
    }

    fclose(src);
    fclose(dst);
    return 0;
}

int main(void) {
    if (copy_file("source.mp4", "copy.mp4") != 0) {
        return EXIT_FAILURE;
    }
    printf("复制成功\n");
    return 0;
}
```

#### 9.2 简单异或加密 / 解密

异或同一个密钥，加密和解密使用同一函数。

```c
#include <stdio.h>

#define KEY 0x99

int xor_file(const char *in_path, const char *out_path) {
    FILE *in = fopen(in_path, "rb");
    FILE *out = fopen(out_path, "wb");
    if (in == NULL || out == NULL) {
        perror("open");
        if (in != NULL) fclose(in);
        if (out != NULL) fclose(out);
        return -1;
    }

    int ch;
    while ((ch = fgetc(in)) != EOF) {
        fputc(ch ^ KEY, out);
    }

    fclose(in);
    fclose(out);
    return 0;
}

int main(void) {
    xor_file("source.txt", "encrypted.txt");
    xor_file("encrypted.txt", "decrypted.txt");
    return 0;
}
```

> 这只是演示用简单异或，不具备实际安全强度。

#### 9.3 批量处理文件（POSIX 示例）

`<dirent.h>` 是 POSIX 接口，Linux/macOS 可用；Windows 需使用其他 API。

```c
#include <stdio.h>
#include <dirent.h>
#include <string.h>

int count_chars(const char *filename) {
    FILE *fp = fopen(filename, "r");
    if (fp == NULL) {
        perror("fopen");
        return -1;
    }

    int count = 0;
    while (fgetc(fp) != EOF) {
        count++;
    }
    fclose(fp);
    return count;
}

int main(void) {
    DIR *dir = opendir(".");
    if (dir == NULL) {
        perror("opendir");
        return 1;
    }

    struct dirent *entry;
    while ((entry = readdir(dir)) != NULL) {
        char *suffix = strrchr(entry->d_name, '.');
        if (suffix != NULL && strcmp(suffix, ".txt") == 0) {
            char path[256];
            snprintf(path, sizeof(path), "./%s", entry->d_name);
            int chars = count_chars(path);
            if (chars >= 0) {
                printf("%s: %d 字符\n", entry->d_name, chars);
            }
        }
    }

    closedir(dir);
    return 0;
}
```

### 10. 错误处理与排查

C 语言没有异常捕获机制，需要检查函数返回值，并配合错误处理函数。

| 函数 | 作用 |
|---|---|
| `perror(s)` | 打印系统错误信息，前缀为 `s` |
| `ferror(fp)` | 检查文件操作是否出错，非 0 表示出错 |
| `clearerr(fp)` | 清除错误标志和 EOF 标志 |

```c
#include <stdio.h>

int main(void) {
    FILE *fp = fopen("test.txt", "r");
    if (fp == NULL) {
        perror("fopen");
        return 1;
    }

    char buf[1024];
    if (fgets(buf, sizeof(buf), fp) == NULL) {
        if (ferror(fp)) {
            perror("fgets");
        } else {
            printf("文件为空或已到末尾\n");
        }
        fclose(fp);
        return 1;
    }

    fclose(fp);
    return 0;
}
```

**常见错误与解决：**

| 现象 | 可能原因 | 解决 |
|---|---|---|
| `fopen` 返回 `NULL` | 路径错误、文件不存在、权限不足 | 检查路径、文件、权限 |
| 文本文件换行混乱 | 用文本模式打开二进制文件 | 非文本文件使用 `rb` / `wb` |
| 二进制文件损坏 | 用文本模式读写二进制 | 统一使用二进制模式 |
| 写入不生效 | 未关闭文件或未刷新缓冲区 | `fclose` 或 `fflush` |
| `fscanf` 读取不完整 | 格式与文件内容不匹配 | 确保格式符与数据一致，必要时用 `fgets` + `sscanf` |

### 11. I/O 避坑清单

1. `scanf` 读取普通变量必须加 `&`；字符数组名通常不加 `&`。
2. `%c` 不跳过空白；前面有残留换行时可用 `" %c"`。
3. `%s` 遇空白停止，不能读取含空格字符串；需要读整行时用 `fgets`。
4. `fgets` 会保留换行符，必要时用 `strcspn(buf, "\n")` 去除。
5. 文件打开后必须检查 `NULL`，使用后必须 `fclose`。
6. 格式说明符必须与数据类型匹配；`scanf` 读 `double` 用 `%lf`，`printf` 输出 `double` 常用 `%f`。
7. 不要使用 `gets()`；不要依赖 `fflush(stdin)`。
8. 字符串必须以 `'\0'` 结尾，否则字符串函数可能越界读取。
9. `strcpy`、`strcat` 不检查目标缓冲区大小，必要时用带长度限制的版本或 `snprintf`。
10. 数组下标从 0 开始，C 不自动检查越界。
11. 数组作为函数参数会退化为指针，函数内无法用 `sizeof` 得到数组长度，需额外传入长度。
12. 二维数组作为函数参数时，列数不能省略。
13. `getchar`、`fgetc` 返回 `int`，不要用 `char` 接收，以免无法正确判断 `EOF`。
14. 文件读写后关闭文件，确保缓冲区数据同步到磁盘。
15. `fread` / `fwrite` 返回值是块数，不是字节数；应检查是否与预期一致。
16. 关闭文件后不要继续使用该 `FILE *` 指针。
17. 跨平台路径拼接推荐用 `snprintf`，不要手写死路径分隔符。
18. 加密、覆盖写等不可逆操作前先备份原文件。
19. 批量遍历目录的 `<dirent.h>` 是 POSIX 接口，Windows 下需换用其他 API。

### 12. 格式说明符

格式说明符用于 `printf`、`scanf`、`fprintf`、`fscanf` 等格式化 I/O 函数。格式符必须与数据类型匹配，否则可能导致乱码、读取错误或未定义行为。

#### 12.1 常用格式说明符

| 格式符 | 对应类型 | 说明 |
|---|---|---|
| `%d` | `int` | 十进制整数 |
| `%i` | `int` | 十进制整数，`scanf` 中可自动识别进制 |
| `%u` | `unsigned int` | 无符号十进制 |
| `%x / %X` | 整型 | 十六进制小写/大写 |
| `%o` | 整型 | 八进制 |
| `%c` | `char` | 单个字符；`scanf` 中不跳过空白 |
| `%s` | `char[] / char*` | 字符串；遇空白停止 |
| `%[^\n]` | `char[] / char*` | 扫描集，读取到换行符为止，保留空格；仅用于输入 |
| `%f` | `float` / `double` 输出 | 默认保留 6 位小数 |
| `%.2f` | 浮点 | 保留 2 位小数 |
| `%e / %E` | 浮点 | 科学计数法 |
| `%lf` | `double` 输入 | `scanf` 读取 `double` 必须用 `%lf` |
| `%Lf` | `long double` | 长双精度 |
| `%p` | 指针 | 输出地址 |
| `%%` | 无 | 输出百分号 |

#### 12.2 `printf` 与 `scanf` 的差异

`printf` 和 `scanf` 的格式符并不完全对称，最容易出错的是浮点数：

```c
double d = 3.14;

printf("%f\n", d);    // 输出 double 可以用 %f
scanf("%lf", &d);     // 输入 double 必须用 %lf
```

`float` 输入用 `%f`，`double` 输入用 `%lf`；输出时 `float` 和 `double` 都可以用 `%f`。`long double` 输入输出都用 `%Lf`。

#### 12.3 宽度、精度与对齐

```c
printf("%5d\n", 42);      // 右对齐，占 5 位：   42
printf("%-5d|\n", 42);    // 左对齐，占 5 位：42   |
printf("%.2f\n", 3.14159); // 保留 2 位小数：3.14
printf("%8.2f\n", 3.14159); // 总宽 8，保留 2 位：    3.14
```

`scanf` 中也可以限制读取宽度，例如 `%19s` 最多读取 19 个字符，给 `'\0'` 留位置：

```c
char name[20];
scanf("%19s", name);
```

#### 12.4 格式说明符避坑

1. 格式符必须与类型匹配，`%d` 不要对应 `double`。
2. `scanf` 读取普通变量必须加 `&`；字符数组名本身是地址，通常不加 `&`。
3. `%c` 不跳过空白字符；前面有残留换行时，可用 `" %c"` 跳过空白。
4. `%s` 遇空白停止，不能读取含空格的字符串；需要读整行时用 `fgets` 或扫描集。
5. `size_t` 用 `%zu`，不要用 `%d`。
6. 指针用 `%p`，不要用 `%d` 或 `%x` 强行输出。

## 十一、预处理指令

预处理指令是 C 语言编译前的“文本操作指令”，由编译器的预处理阶段执行。它们以 `#` 开头，不需要分号结尾，核心作用是文本替换、文件引入和代码条件筛选。

### 1. 预处理指令概览

**作用：** 在编译之前处理源代码文本。

C 语言常见的预处理指令包括：

| 指令 | 作用 |
|---|---|
| `#define` | 定义宏 |
| `#undef` | 取消宏定义 |
| `#include` | 包含文件 |
| `#if` / `#elif` / `#else` / `#endif` | 条件编译 |
| `#ifdef` / `#ifndef` | 判断宏是否定义 |
| `#error` | 触发编译错误 |
| `#pragma` | 编译器相关指令，如 `#pragma once` |

**注意：**

它们不是 C 语句，不受普通语法规则约束，但会影响后续编译的内容。

- **文本替换特性**：宏替换是 **纯文本替换**，没有类型检查，也不执行语法验证。例如 `#define PI 3.14a` 在定义时不一定报错，真正使用 `PI` 时才可能暴露问题。
- **括号要加足**：带参数宏的参数和整体表达式都应加括号，否则容易因运算符优先级导致逻辑错误。
- **宏与常量不同**：`#define PI 3.14` 是文本替换；`const float pi = 3.14f;` 是有类型常量，编译时检查类型，通常占内存。按需选择。

### 2. 宏定义

宏定义通过 `#define` 将标识符与文本或表达式绑定。

**作用：** 预处理阶段会把代码中所有宏名 **替换** 为对应文本，实现“一处定义、多处复用”。

**分类：** 无参数宏 和 带参数宏。

#### 2.1 无参数宏

格式：

```c
#define 宏名 替换文本
```

替换文本可以省略，此时宏名仅作为“标识”，例如 `#define DEBUG`。

```c
#include <stdio.h>

#define PI 3.14159
#define MAX_SIZE 100
#define GREET "Hello C Preprocessor"

int main(void) {
    float radius = 5.0f;
    float area = PI * radius * radius;
    int arr[MAX_SIZE];

    printf("圆面积：%.2f\n", area);
    printf("%s\n", GREET);

    return 0;
}
```

预处理后，`PI` 被替换为 `3.14159`，`MAX_SIZE` 被替换为 `100`，`GREET` 被替换为字符串字面量。`arr[MAX_SIZE]` 在编译前等价于 `arr[100]`。

#### 2.2 带参数宏

格式：

```c
#define 宏名(参数列表) 替换表达式
```

参数列表没有类型，替换表达式应加括号避免优先级问题。

```c
#include <stdio.h>

#define MAX(a, b) ((a) > (b) ? (a) : (b))
#define SQUARE(x) ((x) * (x))

int main(void) {
    int x = 3, y = 5;

    printf("最大值：%d\n", MAX(x, y));
    printf("(x+2) 的平方：%d\n", SQUARE(x + 2));

    return 0;
}
```

`MAX(x, y)` 展开为 `((x) > (y) ? (x) : (y))`，结果为 `5`。  
`SQUARE(x + 2)` 展开为 `((x + 2) * (x + 2))`，结果为 `25`。

如果 `SQUARE` 写成 `#define SQUARE(x) x * x`，那么 `SQUARE(3 + 2)` 会展开为 `3 + 2 * 3 + 2`，结果是 `11`，而不是 `25`。所以带参数宏的参数和整体表达式都要加括号。

#### 2.3 取消宏定义

格式：

```c
#undef 宏名
```

**作用：** 取消已定义的宏，后续代码中该宏名不再生效：

```c
#include <stdio.h>

#define NUM 100

int main(void) {
    printf("%d\n", NUM);  // 输出 100

#undef NUM
    // printf("%d\n", NUM);  // 错误：NUM 未定义

    return 0;
}
```

#### 2.4 宏的注意事项

1. **宏不是函数**：宏在预处理阶段展开，没有函数调用开销，但也没有类型检查和调试符号。
2. **参数和整体都要加括号**：例如 `#define SQUARE(x) ((x) * (x))`，不要写成 `x * x`。
3. **避免副作用**：如果宏参数在展开后出现多次，可能被求值多次。例如 `MAX(i++, j++)` 可能导致自增多次，应避免这种用法。
4. **宏名通常用大写**：这是约定俗成，便于区分宏和普通变量/函数。
5. **多行宏用反斜杠续行**：

```c
#define CHECK(cond, msg) \
    do { \
        if (!(cond)) { \
            printf("%s\n", msg); \
        } \
    } while (0)
```

这种 `do { ... } while (0)` 写法可以让宏在语法上表现得像一条语句，避免在 `if-else` 中展开后出错，这种表达在 Linux 内核中很常见。

### 3. 文件包含

`#include` 指令将指定文件的全部内容嵌入当前文件，实现头文件复用。

#### 3.1 标准库头文件

格式：

```c
#include <头文件名>
```

编译器从系统头文件路径查找，例如 `/usr/include`、`C:\MinGW\include`。

```c
#include <stdio.h>

int main(void) {
    printf("Hello from stdio.h\n");
    return 0;
}
```

**注意：** `<stdio.h>` 中的函数声明被引入后，才能使用 `printf`、`scanf` 等函数。

#### 3.2 自定义头文件

格式：

```c
#include "头文件名"
```

编译器先 **从当前源文件所在路径查找，找不到再去系统路径查找**。适合包含项目内自定义头文件。

示例：`myfunc.h` 声明函数，`main.c` 包含并调用。

**myfunc.h：**

```c
#ifndef MYFUNC_H
#define MYFUNC_H

int add(int a, int b);

#endif
```

**main.c：**

```c
#include <stdio.h>
#include "myfunc.h"

int add(int a, int b) {
    return a + b;
}

int main(void) {
    int sum = add(3, 5);
    printf("3 + 5 = %d\n", sum);
    return 0;
}
```

实际项目中，函数实现通常放在单独的 `.c` 文件中，头文件只放声明。这样多个源文件可以共享同一份声明，链接时再找到实现。

#### 3.3 路径写法

**相对路径：**

```c
#include "./include/myfunc.h"       // 当前目录下的 include 子目录
#include "../../include/myfunc.h"    // 上两级目录下的 include 子目录
```

跨平台项目 **推荐使用相对路径**，避免写死绝对路径。

**绝对路径** 也可以写，但可移植性差：

```c
#include "C:/project/include/myfunc.h"
```

#### 3.4 头文件保护

头文件可能被多个源文件包含，也可能出现 A 包含 B、C 同时包含 A 和 B 的情况。如果没有保护，B 的内容可能被重复嵌入，导致结构体、函数声明等重复定义。

常用两种方式：

**方式一：`#ifndef` / `#define` / `#endif`**

```c
#ifndef MYFUNC_H
#define MYFUNC_H

/* 函数声明、结构体定义等 */

#endif
```

**方式二：`#pragma once`**

```c
#pragma once

/* 函数声明、结构体定义等 */
```

`#pragma once` 写法更简洁，但属于编译器扩展，并非所有编译器都保证支持；`#ifndef` 方式更通用。实际项目中二者选其一即可，不要混用。

> 注意：`#include` 主要用于包含头文件（`.h`），不建议包含源文件（`.c`），否则容易导致代码重复编译和链接错误。

### 4. 条件编译

**作用：** 通过条件判断控制“哪些代码参与编译”。预处理阶段会删除不满足条件的代码，常用于跨平台适配、调试开关和代码版本控制。

#### 4.1 `#if` / `#elif` / `#else` / `#endif`

```c
#if 条件表达式
    满足条件的代码
#elif 另一个条件表达式
    满足此条件的代码
#else
    所有条件都不满足的代码
#endif
```

**条件表达式的要求：**

`#if` 的条件表达式在预处理阶段求值，必须由整型常量表达式组成，可以包含：

- 整型字面常量、字符常量
- 已定义的宏（会被展开）
- `defined` 运算符
- 算术、关系、逻辑、位运算

不能包含变量、函数调用、类型转换、`sizeof`、浮点数等。

```c
#define MAX_SIZE 100

#if MAX_SIZE > 50
    /* 合法：MAX_SIZE 展开为 100，条件为真 */
#endif

#if 1
    /* 合法：常量条件 */
#endif

// #if variable > 50
// 错误：variable 不是预处理阶段的常量
```

**嵌套条件编译：**

```c
#define OS_WIN 1
#define DEBUG 1

#if OS_WIN
    #ifdef DEBUG
        printf("Windows 调试模式\n");
    #else
        printf("Windows 发布模式\n");
    #endif
#endif
```

每个 `#if`、`#ifdef`、`#ifndef` 都必须有对应的 `#endif`。嵌套时要注意配对，避免遗漏。

#### 4.2 `#ifdef` 与 `#ifndef`

`#ifdef 宏名` 等价于 `#if defined(宏名)`，**宏已定义** 时编译代码：

```c
#ifdef DEBUG
    printf("调试信息\n");
#endif
```

`#ifndef 宏名` 等价于 `#if !defined(宏名)`，**宏未定义** 时编译代码：

```c
#ifndef MY_HEADER_H
#define MY_HEADER_H

/* 头文件内容 */

#endif
```

`#ifndef` 最常见于 **头文件保护**：第一次包含时宏未定义，进入保护块并定义宏；后续再次包含时宏已定义，整个块被跳过。

#### 4.3 `#error` 编译错误指令

`#error` 用于在条件不满足时触发编译错误，常用来 **提示不支持的环境**：

```c
#if !defined(_WIN32) && !defined(__linux__)
    #error "不支持当前操作系统"
#endif
```

#### 4.4 典型应用1：跨平台适配

不同系统的头文件和函数不同，可以用条件编译适配。编译器会自动定义平台宏，例如 GCC 在 Linux 下定义 `__linux__`，MSVC 在 Windows 下定义 `_WIN32`。

```c
#include <stdio.h>

#ifdef _WIN32
    #include <windows.h>
    #define SLEEP_MS(x) Sleep(x)
#elif defined(__linux__)
    #include <unistd.h>
    #define SLEEP_MS(x) sleep((x) / 1000)
#else
    #error "不支持当前操作系统"
#endif

int main(void) {
    printf("休眠 3 秒...\n");
    SLEEP_MS(3000);
    printf("休眠结束\n");
    return 0;
}
```

预处理后，Windows 下 `SLEEP_MS(3000)` 展开为 `Sleep(3000)`，Linux 下展开为 `sleep(3)`。

#### 4.5 典型应用2：调试开关

用宏 `DEBUG` 控制调试日志是否参与编译，发布版本关闭调试代码：

```c
#include <stdio.h>

#define DEBUG

int main(void) {
    int num = 10;

#ifdef DEBUG
    printf("调试：num 的初始值为 %d\n", num);
#endif

    num *= 2;
    printf("最终结果：%d\n", num);

    return 0;
}
```

开发阶段保留 `#define DEBUG`，发布阶段注释掉这一行，调试日志代码就不会被编译进最终程序。

### 5. 实践建议

#### 5.1 调试日志与发布版本

除了用 `#ifdef DEBUG` 包裹调试代码，也可以在编译时通过命令行定义宏，而不修改源码：

```bash
gcc -DDEBUG main.c -o main
```

`-DDEBUG` 等价于在源码开头写 `#define DEBUG`。这样同一份源码可以编译出调试版和发布版。

#### 5.2 用宏或枚举简化 `main` 逻辑

宏可以定义数组长度、错误码等常量，减少硬编码：

```c
#include <stdio.h>

#define ARR_SIZE 10
#define ERR_PARAM 1

int main(void) {
    int arr[ARR_SIZE];

    if (ARR_SIZE <= 0) {
        return ERR_PARAM;
    }

    (void)arr;
    return 0;
}
```

对于整型常量和错误码，`enum` 或 `const` 往往比宏更利于调试和类型检查。宏不是唯一选择，按场景选用即可。

#### 5.3 头文件保护

所有自定义头文件都建议加包含保护，而不仅是可能被多次包含的头文件：

```c
#ifndef MY_HEADER_H
#define MY_HEADER_H

/* 函数声明、结构体定义等 */

#endif
```

#### 5.4 编译选项建议

初学阶段建议开启常见警告，有助于发现宏参数缺少括号、未使用变量等问题：

```bash
gcc -std=c11 -Wall -Wextra -pedantic main.c -o main
```

如需更严格检查，可加 `-Werror` 将警告视为错误。

### 6. 预处理小结

预处理指令在编译之前完成文本替换、文件引入和条件筛选。记住三条主线：

- **宏定义**：`#define` / `#undef`，本质是文本替换，带参数宏要加足括号，避免副作用。
- **文件包含**：`#include <>` 查系统路径，`#include ""` 先查当前路径；头文件要加保护，不要包含 `.c` 文件。
- **条件编译**：`#if` / `#ifdef` / `#ifndef` / `#error`，用于跨平台适配、调试开关和头文件保护；条件表达式只能使用预处理阶段可求值的整型常量表达式。

预处理指令不参与类型检查，也不生成运行时代码，但它们决定了编译器“看到什么”。理解这一点，就能更安全地使用宏、组织头文件，并用条件编译适配不同环境。

## 十二、`main` 函数与程序入口

### 1. 标准形式

`main` 函数是 C 程序的唯一入口。标准形式优先使用：

| 形式 | 适用场景 |
|---|---|
| `int main(void)` | 无命令行参数 |
| `int main(int argc, char *argv[])` | 需要访问命令行参数 |

`void main()` 不是标准形式，部分编译器可能接受，但不推荐跨平台使用。

```c
#include <stdio.h>

int main(void) {
    printf("Hello, C\n");
    return 0;
}
```

### 2. 命令行参数

`argc` 是参数个数；`argv[0]` 通常是程序名或执行路径，`argv[1]` 才是第一个用户参数；标准保证 `argv[argc] == NULL`。

```c
#include <stdio.h>

int main(int argc, char *argv[]) {
    printf("argc = %d\n", argc);

    for (int i = 0; i < argc; i++) {
        printf("argv[%d] = %s\n", i, argv[i]);
    }

    return 0;
}
```

假设编译为 `program`，执行 `./program hello world`，输出类似：

```text
argc = 3
argv[0] = ./program
argv[1] = hello
argv[2] = world
```

`argv[0]` 的具体值取决于启动方式，可能是 `./program`、绝对路径或空字符串，不应写死。

### 3. 返回值与退出状态

`main` 的返回值表示程序退出状态：

- 返回 `0` 或 `EXIT_SUCCESS`：程序正常退出。
- 返回非 0 或 `EXIT_FAILURE`：程序异常退出。

```c
#include <stdio.h>
#include <stdlib.h>

int main(void) {
    FILE *fp = fopen("data.txt", "r");
    if (fp == NULL) {
        perror("fopen");
        return EXIT_FAILURE;
    }

    fclose(fp);
    return EXIT_SUCCESS;
}
```

Linux/macOS 中可用 `echo $?` 查看上一个程序的退出状态；Windows 命令行用 `%ERRORLEVEL%`。POSIX 环境通常只能看到状态码的低 8 位。

### 4. `return` 与 `exit`

| 写法 | 行为 |
|---|---|
| `main` 中 `return n;` | 以状态码 `n` 结束程序 |
| 子函数中 `return n;` | 仅返回给调用者，不终止程序 |
| `exit(n)` | 终止整个进程，刷新 stdio 缓冲区，调用 `atexit` 注册函数 |
| `_Exit(n)` | 终止进程，但不刷新 stdio 缓冲区，不调用 `atexit` 函数 |

`exit` 需要包含 `<stdlib.h>`：

```c
#include <stdio.h>
#include <stdlib.h>

void check_num(int num) {
    if (num < 0) {
        printf("错误：数字不能为负\n");
        exit(EXIT_FAILURE);
    }
}

int main(void) {
    check_num(-5);
    printf("这行不会执行\n");
    return 0;
}
```

`main` 是程序入口，不应由用户代码主动调用。C++ 标准明确禁止；C 标准虽未以同样方式绝对禁止，但也不应依赖调用 `main`，否则可能导致重入或递归调用风险。

## 全文小结

- **数据类型**：用 `sizeof` 验证长度，有符号/无符号不要混比。
- **表达式**：注意优先级、结合性、短路求值。
- **类型转换**：隐式提升、强制转换，警惕精度丢失和无符号陷阱。
- **变量与作用域**：局部、全局、静态局部，生命周期各不相同。
- **常量**：字面量、`const`、宏、枚举，按场景选用。
- **分支与循环**：`if` / `switch` / `for` / `while` / `do-while`，`break` / `continue` 只作用于最内层。
- **函数**：传值调用、传址调用、递归、函数指针与回调。
- **数组与字符串**：连续内存块，字符串以 `'\0'` 结尾，数组参数退化为指针。
- **I/O 与文件操作**：打开 → 读写 → 定位 → 关闭 → 错误处理；文本用 `r/w/a`，二进制加 `b`。
- **预处理指令**：宏定义、文件包含、条件编译；宏是文本替换，头文件要加保护。
- **程序入口**：`int main(void)` 或 `int main(int argc, char *argv[])`，返回 0 表示正常退出。
