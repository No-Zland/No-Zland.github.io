# 二分：从有序查找到答案二分

> 一句话本质：二分不是「在数组里找数」，而是「在单调谓词上找翻转点」——只要能判定，就能把线性搜索压成对数次判定。

## 一、是什么

二分是在**单调**的候选集上反复折半，每次判定丢掉一半，最终缩成一点。它要求的不是「有序」，而是一个单调谓词 $P$：$P(x)$ 为真则对所有 $y > x$ 都有 $P(y)$ 为真。二分求的是翻转点 $x^* = \min\{x : P(x)\}$。

它解决两类问题：

- **定位**：有序结构里找「第一个 $\ge x$ 的位置」，即 `lower_bound`；
- **最优化**：把「求最小/最大的可行值」降级成「$x$ 可行吗」，即二分答案。

识别信号：

- 出现「有序」「第一个 / 最后一个满足」「插入位置」「出现次数」；
- 问「最小的最大值」「最大的最小值」「最少要多少」；
- 能写出 `check(x)`，且 $x$ 可行能推出更大的 $x$ 也可行（或反之）；
- 答案值域到 $10^{18}$ 而 $n$ 只有 $10^5$：$O(n\log V)$ 能过，$O(nV)$ 必死；
- 单次判定便宜（扫描、BFS、并查集），直接求最优却很贵；实数问题里函数单调，要求 $10^{-6}$ 精度。

不该用它的时候：

- 谓词不单调。「恰好分成 $k$ 段」的可行域是离散点集，二分失效，只能 DP；
- 答案一次扫描就能求出（如最大子段和的 Kadane），二分只是把 $O(n)$ 变成 $O(n\log V)$；
- 要的是**所有**解而不是一个点（如求全部根，得先分段再逐段二分）；

## 二、形式

**数学形式.** 设答案区间 $[L,R]$，循环不变量为

$$P(l-1) = \text{false}, \qquad P(r) = \text{true}.$$

每轮取 $m = \lfloor (l+r)/2 \rfloor$，$P(m)$ 为真则 $r \leftarrow m$，否则 $l \leftarrow m+1$。每次至少扔掉一半，长度满足

$$r - l \le \left\lceil \frac{R-L+1}{2^k} \right\rceil,$$

故 $k=\lceil\log_2(R-L+1)\rceil$ 轮后 $l=r$，即最小可行点。二分答案的代价是

$$O(\log V \cdot T_{\text{check}}),$$

$V$ 是答案值域，$\log_2 10^9 \approx 30$。

**代码形式.**

```cpp
#include <vector>
#include <algorithm>
using namespace std;

int lowerBound(const vector<int>& a, int x);   // 第一个 >= x 的下标
bool check(long long x);                       // 单调谓词
template <class F>
long long minFeasible(long long lo, long long hi, F ok);  // 最小可行值
```

**数据形式.** 只要两个端点：`l` 是「最后一个已知不满足的位置 $+1$」，`r` 是「一个已知满足的位置」（可为哨兵 $n$）。

## 三、怎么理解

**直觉.** 猜数字：1~1000 里想一个数，每次只告诉你「大了 / 小了」。猜 500，无论答案在哪边，剩下的候选都只剩一半，10 次必中，因为 $2^{10} > 1000$。二分的威力来自「一次判定淘汰一半」，与「数组有序」无关。

**为什么正确.** 两点：

1. **不丢解**：若 $P(m)$ 真，答案 $\le m$，保留 $[l,m]$；若 $P(m)$ 假，由单调性所有 $x \le m$ 都不可行，答案在 $[m+1,r]$。两种收缩都没有丢掉 $x^*$。
2. **终止即答案**：退出时 $l=r$，不变量给出 $P(l-1)$ 假、$P(l)$ 真，故 $l$ 是最小可行点。

这两条只用到「单调」；数组有序只是让 $P(i) = (a_i \ge x)$ 成为单调谓词的特例。

**手推.** $a = \{1,3,3,5,7,9\}$，查第一个 $\ge 4$ 的位置。

| 轮 | $l$ | $r$ | $m$ | $a_m$ | 判定 | 动作 |
|---|---|---|---|---|---|---|
| 1 | 0 | 6 | 3 | 5 | 真 | $r=3$ |
| 2 | 0 | 3 | 1 | 3 | 假 | $l=2$ |
| 3 | 2 | 3 | 2 | 3 | 假 | $l=3$ |
| 4 | 3 | 3 | — | — | 退出 | 答案 3 |

下标 3 正是 5。4 不在数组里也无妨——答案可以是「插入点」。

## 四、怎么变成代码

从形式到代码的映射：

- `l`：第一个**可能**是答案的位置，初值 $0$（数组二分）或下界（二分答案）；`r`：第一个**确定**满足的位置，初值 $n$——「$x$ 比所有元素都大」时答案就是 $n$，这个哨兵最容易漏。
- `mid`：写 `l + (r - l) / 2`，不写 `(l + r) / 2`——后者在 $l+r$ 超过 `int` 上限时溢出成负数。
- 循环：`while (l < r)`，左闭右开 $[l,r)$，退出时天然 $l=r$。
- 收缩：判定真时 `r = mid`（`mid` 可能是答案，必须留在区间内），假时 `l = mid + 1`（`mid` 一定不是答案，可排除）。
- 反向：求「最后一个满足」时换成 `l = mid`、`r = mid - 1`，此时 `mid` 必须写 `l + (r - l + 1) / 2` 向上取整，否则 $l=3,r=4$ 时 `mid=3`，判定真则 `l=3`，区间一步没缩，死循环。记法：**收缩式带 `+1` 的，mid 向下取整；不带 `+1` 的，mid 向上取整**。
- 实数二分：不用 `eps` 判停，迭代 100 次后区间长 $2^{-100}\approx8\times10^{-31}$，远超 double 精度。

完整模板：

```cpp
#include <vector>
#include <algorithm>
using namespace std;

// 第一个 >= x 的下标；不存在返回 n
int lowerBound(const vector<int>& a, int x) {
    int l = 0, r = (int)a.size();          // r = n 接住「比所有元素都大」
    while (l < r) {
        int mid = l + (r - l) / 2;         // 向下取整，mid < r 恒成立
        if (a[mid] >= x) r = mid;          // mid 可能是答案，留着
        else l = mid + 1;                  // mid 一定不是答案，排除
    }
    return l;
}

// 最后一个 <= x 的下标；不存在返回 -1
int lastLeq(const vector<int>& a, int x) {
    int l = -1, r = (int)a.size() - 1;     // -1 是「无解」哨兵
    while (l < r) {
        int mid = l + (r - l + 1) / 2;     // 向上取整，保证 mid > l
        if (a[mid] <= x) l = mid;
        else r = mid - 1;
    }
    return l;
}

// 在 [lo, hi] 上找最小可行值，调用者保证 ok(hi) 为真
template <class F>
long long minFeasible(long long lo, long long hi, F ok) {
    while (lo < hi) {
        long long mid = lo + (hi - lo) / 2;
        if (ok(mid)) hi = mid; else lo = mid + 1;
    }
    return lo;
}

// 实数二分：固定 100 次迭代，不用 eps
template <class F>
double bisectReal(double lo, double hi, F ok) {
    for (int it = 0; it < 100; ++it) {
        double mid = (lo + hi) / 2;
        if (ok(mid)) hi = mid; else lo = mid;
    }
    return lo;
}
```

## 五、具体例子

### 例 1：手写 `lower_bound`（靠循环不变量写对）

问题：给有序数组 $a$ 与 $x$，求第一个 $\ge x$ 的下标。

套哪个形式：定位型二分，不变量 $a_{l-1} < x \le a_r$（把 $a_{-1}$ 看作 $-\infty$、$a_n$ 看作 $+\infty$）。

关键不是背模板，而是写之前先把不变量说清楚：初值 $l=0,r=n$ 成立；每轮 $a_m \ge x$ 时 $m$ 可当新 $r$，否则 $l$ 至少是 $m+1$；退出时 $l=r$ 即答案。

```cpp
#include <vector>
using namespace std;

// 不变量：a[l-1] < x <= a[r]；区间是 [l, r)
int lowerBound(const vector<int>& a, int x) {
    int l = 0, r = (int)a.size();
    while (l < r) {
        int mid = l + (r - l) / 2;     // mid < r 恒成立
        if (a[mid] >= x) r = mid;      // 保持 a[r] >= x
        else l = mid + 1;              // 保持 a[l-1] < x
    }
    return l;                          // l == r，第一个 >= x 的位置
}
```

复杂度：$O(\log n)$ 时间，$O(1)$ 空间。

### 例 2：二分答案——跳石头（P2678）

问题：长 $L$ 的河里有 $N$ 块石头，最多移走 $M$ 块，让「相邻落脚点最小距离」尽量大，求最大值。

套哪个形式：最优化 + 单调谓词。二分最短距离 $x$，`check(x)` 回答「能否只移走 $\le M$ 块，使所有间距 $\ge x$」。$x$ 变大要求更严、需要的移除数不减，所以可行域是 $[0, ans]$，求最大可行点。

贪心 check 为何最优：从左往右扫，维护「上一块保留的石头」，当前石头距它 $< x$ 就移走当前这块——移走它会同时增大与前后两块的间距，不会比移走前一块更差，故贪心移除数最小。

```cpp
#include <cstdio>
#include <vector>
using namespace std;

int L, N, M;
vector<int> d;                       // d[0]=0, d[1..N]=石头, d[N+1]=L

bool check(int x) {
    int removed = 0, last = 0;       // last = 上一块保留石头的下标
    for (int i = 1; i <= N + 1; ++i) {
        if (d[i] - d[last] < x) ++removed;   // 间距不足，移走这块
        else last = i;                        // 够了，保留
    }
    return removed <= M;
}

int main() {
    scanf("%d %d %d", &L, &N, &M);
    d.assign(N + 2, 0);
    for (int i = 1; i <= N; ++i) scanf("%d", &d[i]);
    d[N + 1] = L;
    int lo = 1, hi = L;                       // 答案至少 1，至多 L
    while (lo < hi) {
        int mid = lo + (hi - lo + 1) / 2;      // 求最大可行，向上取整
        if (check(mid)) lo = mid; else hi = mid - 1;
    }
    printf("%d\n", lo);
    return 0;
}
```

注意 `i = N+1` 是终点、不能移走：此时间距不足应移走 `last`，代价仍为 1，且合并后 $L - d_{prev} \ge x$（`last` 当初被保留，故 $d_{last} - d_{prev} \ge x$），计数成立。

复杂度：`check` 为 $O(N)$，共 $O(\log L)$ 轮，总 $O(N\log L)$。

### 例 3：实数二分——一元三次方程（P1024）

问题：$ax^3+bx^2+cx+d=0$ 在 $[-100,100]$ 内有三个不同实根，精确到 $0.01$。

套哪个形式：实数二分。$f$ 连续，$f(i)\cdot f(i+1)<0$ 则 $[i,i+1]$ 内必有根；以 1 为步长枚举 200 段，每段二分 100 次；端点恰为根直接输出。

```cpp
#include <cstdio>
#include <cmath>

double a, b, c, d;
double f(double x) { return ((a * x + b) * x + c) * x + d; }   // 秦九韶

int main() {
    scanf("%lf %lf %lf %lf", &a, &b, &c, &d);
    int cnt = 0;
    for (int i = -100; i < 100 && cnt < 3; ++i) {
        double fl = f(i), fr = f(i + 1);
        if (fabs(fl) < 1e-9) { printf("%.2f ", (double)i); ++cnt; continue; }
        if (fl * fr < 0) {
            double lo = i, hi = i + 1;
            for (int it = 0; it < 100; ++it) {       // 固定 100 次，区间长 2^-100
                double mid = (lo + hi) / 2;
                if (f(mid) * fl > 0) lo = mid; else hi = mid;
            }
            printf("%.2f ", lo);
            ++cnt;
        }
    }
    return 0;
}
```

`f(mid) * fl > 0` 说明 `mid` 与左端点同号，根在右侧，故 `lo = mid`；否则根在左半，`hi = mid`。

复杂度：$O(200 \times 100) = O(1)$。

## 六、复杂度与易错点

| 场景 | 时间复杂度 | 空间复杂度 |
|---|---|---|
| 有序数组定位 | $O(\log n)$ | $O(1)$ |
| 二分答案 | $O(\log V \cdot T_{\text{check}})$，$\log V \approx 30$ | $O(1)$ 额外 |
| 实数二分（固定 100 次） | $O(100 \cdot T_f)$ | $O(1)$ |
| 跳石头 | $O(N \log L)$ | $O(N)$ |

1. `r` 写成 `n-1`，$x$ 比所有元素大时返回 $n-1$ 而非 $n$。
2. 用 `l = mid` 却仍向下取整，$l=r-1$ 时区间不缩，死循环。
3. `check` 忘判单个元素已超限（`a[i] > x`），段数算成 0 或越界。
4. 二分答案上界随手写 `1e18`，`check` 内加法溢出成负数，判定全部翻转。
5. 实数二分用 `while (r-l > 1e-12)` 判停：double 只有 15~16 位有效数字，eps 再小就永远停不下来。
6. 没验证单调性就二分，「恰好 $k$ 段」这类判定不单调。
