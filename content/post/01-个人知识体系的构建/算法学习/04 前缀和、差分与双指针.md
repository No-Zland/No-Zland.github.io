# 前缀和、差分与双指针

> 一句话本质：前缀和把区间求和变成两个前缀相减，差分把区间加变成两个端点修改，双指针靠单调性把 $O(n^2)$ 压成 $O(n)$。

## 一、是什么

**前缀和**：先花 $O(n)$ 预处理 $P[i]=\sum_{k\le i}a_k$，此后任意区间和 $O(1)$——用空间换查询。**差分**：反过来只存相邻差 $d[i]=a_i-a_{i-1}$，一次区间加变成两次单点修改——用「最后统一还原」换「修改 $O(1)$」。**双指针**：左右两个下标只朝一个方向走，共享同一趟扫描。

识别信号：

1. 大量「求区间 $[l,r]$ 的和」，$m$ 也是 $10^5$——逐段累加是 $10^{10}$。
2. 矩阵题问「以 $(x_1,y_1)$、$(x_2,y_2)$ 为对角的子矩阵和」——二维前缀和 + 容斥。
3. 「把 $[l,r]$ 全部加 $v$」，最后一次性问每个位置——差分。
4. 元素非负，问「最短 / 最长的满足条件的连续子段」——双指针。
5. 统计「和为 $k$ 的子数组个数」而元素可负——前缀和 + 哈希。
6. 「$T$ 次操作能否做到」而 `check` 要扫区间——差分 + 二分。

不该用它：区间改完还要频繁区间查询（差分只擅长「多次改、一次查」，混合要树状数组 / 线段树）；元素含负数却用双指针求「和 $\ge S$ 的最短段」（左端不再单调，结论直接失效）；要维护不可减的信息（区间最大值、最大子段和），前缀和只能相减，$\max$ 减不了。

## 二、形式

$$P[0]=0,\qquad P[i]=P[i-1]+a_i,\qquad \sum_{l}^{r}a_i=P[r]-P[l-1]$$

二维靠容斥，加两次减一次，查询同理：

$$S[i][j]=a[i][j]+S[i-1][j]+S[i][j-1]-S[i-1][j-1]$$

差分与前缀和互逆：

$$d[i]=a_i-a_{i-1},\qquad a_i=\sum_{k\le i}d[k],\qquad \text{区间加}\ v:\ d[l]\mathrel{+}=v,\ d[r+1]\mathrel{-}=v$$

双指针的全部合法性压在这一条不变量上：

$$l(r)=\min\{l:\mathrm{valid}(l,r)\},\qquad r_1<r_2\ \Longrightarrow\ l(r_1)\le l(r_2)$$

代码形式：`ll sum(int l, int r)`、`void add(int l, int r, ll v)`。数据形式：`vector<long long> P(n+1)` 且下标从 1 起（$P[0]=0$ 消掉所有 $l=1$ 的特判）；差分数组开 `n+2`，多出的一格专门吃 $r+1$。

## 三、怎么理解

直觉：前缀和像记「出生到今天一共花了多少」，任意两天相减就是这段花销；差分像只记「今天比昨天多花多少」，整段涨薪只需在第一天记 $+v$、最后一天之后记 $-v$。

为什么正确：$P$ 的差分等于 $a$，$d$ 的前缀和也等于 $a$，所以那两次单点修改恰好只改变 $[l,r]$ 内的前缀和。双指针靠反证：若 $r$ 右移后最小合法左端左移了，则旧的最小左端在新 $r$ 下依然合法，与「最小」矛盾。

手推：$a=(3,1,2)$，差分 $d=(3,-2,1)$，前缀和还原得 $3,1,2$；正部之和 $3+1=4$。$P=(0,3,4,6)$，$\sum_{2}^{3}=P[3]-P[1]=6-3=3$。二维 2×2 全 1：$S[2][2]=4$，查整块 $4-0-0+0=4$。

## 四、怎么变成代码

映射：`P` 长度 $n+1$、`P[0]=0`、下标 1 起，这样 `l-1` 永不越界；二维容斥四个符号别记错成「减两次不加」；差分开 `n+2`，`r+1` 最大到 $n+1$；滑动窗口动作固定三步——右端进、`while` 不合法就左端出、合法时更新答案。循环顺序：前缀和必须从左到右（依赖前一项）；差分先做完全部修改再统一求前缀和。边界：`l > r` 返回 0；`r+1 > n` 时直接改 `d[r+1]` 也不会越界，因为留了位。

```cpp
#include <iostream>
#include <vector>
#include <unordered_map>
using namespace std;
typedef long long ll;

// 一维前缀和：P[0]=0，区间和 O(1)
struct Prefix {
    vector<ll> P;
    explicit Prefix(const vector<ll>& a) : P(a.size() + 1, 0) {
        for (size_t i = 1; i < P.size(); ++i) P[i] = P[i - 1] + a[i - 1];
    }
    ll sum(int l, int r) const { return l > r ? 0 : P[r] - P[l - 1]; }  // 1-based
};

// 差分：区间 [l,r] 加 v，d 必须开 n+2
void rangeAdd(vector<ll>& d, int l, int r, ll v) {
    d[l] += v;
    d[r + 1] -= v;
}

// 前缀和 + 哈希：统计和恰为 k 的子数组个数（元素可正可负）
ll countK(const vector<int>& a, ll k) {
    unordered_map<ll, int> cnt;
    cnt[0] = 1;                        // 空前缀，漏了就从第一个元素起全丢
    ll s = 0, ans = 0;
    for (int x : a) {
        s += x;
        auto it = cnt.find(s - k);     // 等价于 P[l-1] = P[r] - k
        if (it != cnt.end()) ans += it->second;
        ++cnt[s];
    }
    return ans;
}

int main() {
    Prefix p({3, 1, 2});
    cout << p.sum(2, 3) << "\n";                       // 3
    vector<ll> d(6, 0);
    rangeAdd(d, 1, 3, 2);
    cout << countK({1, 2, 3, -1, 2}, 3) << "\n";       // 2：[1,2] 与 [3]
    return 0;
}
```

## 五、具体例子

### 1. 最大子段和

问题：$n\le2\times10^5$，求连续子段的最大和（至少取一个）。套形式：$\sum_{l}^{r}=P[r]-P[l-1]$，固定 $r$ 时想让 $P[l-1]$ 最小，于是维护前缀最小值：

$$ans=\max_{r}\Big(P[r]-\min_{0\le l-1<r}P[l-1]\Big)$$

```cpp
#include <iostream>
#include <vector>
#include <climits>
using namespace std;
typedef long long ll;

ll maxSub(const vector<int>& a) {
    ll best = LLONG_MIN, minP = 0, P = 0;   // minP 含 P[0]=0
    for (int x : a) {
        P += x;
        best = max(best, P - minP);         // 以当前位置结尾的最优
        minP = min(minP, P);                // 更新留给后面
    }
    return best;
}

int main() {
    cout << maxSub({-2, 11, -4, 13, -5, -2}) << "\n";   // 20
    return 0;
}
```

复杂度 $O(n)$ 时间、$O(1)$ 空间。`best` 初值必须是 $-\infty$ 而不是 0，否则全负数数组会错答 0。

### 2. 差分区间加：铺设道路

问题：每次把一段区间的值同时减 1（只能减到 0 为止），求最小操作次数。套形式：区间操作对应差分端点，答案就是差分正部之和

$$\text{ans}=\sum_{i=1}^{n}\max(0,\ a_i-a_{i-1}),\qquad a_0=0$$

```cpp
#include <iostream>
#include <vector>
using namespace std;
typedef long long ll;

int main() {
    int n;
    cin >> n;
    vector<ll> a(n + 1, 0);                 // a[0] = 0 当作地面
    for (int i = 1; i <= n; ++i) cin >> a[i];
    ll ans = 0;
    for (int i = 1; i <= n; ++i)
        if (a[i] > a[i - 1]) ans += a[i] - a[i - 1];   // 只累正部
    cout << ans << "\n";
    return 0;
}
```

手算 $a=(3,1,2)$：$3+0+1=4$。为什么对：记 $D=\sum\max(0,a_i-a_{i-1})$。一次区间减 1 至多让 $D$ 少 1（在 $l$ 处减、在 $r+1$ 处加，正部最多消掉一个），而填平意味着 $D=0$，故操作数 $\ge D$；从左往右依次压平每段抬起的部分，每次恰好减 1，正好达到 $D$。复杂度 $O(n)$。

### 3. 滑动窗口：逛画展

问题：$n$ 幅画、$m$ 位画家，求包含全部 $m$ 位作品的最短区间。套形式：连续子段 + 条件只增不减（种类数），双指针合法。

```cpp
#include <iostream>
#include <vector>
using namespace std;

int main() {
    int n, m;
    cin >> n >> m;
    vector<int> c(n + 1), cnt(m + 1, 0);
    for (int i = 1; i <= n; ++i) cin >> c[i];
    int distinct = 0, l = 1, bl = 1, br = n;
    for (int r = 1; r <= n; ++r) {
        if (cnt[c[r]]++ == 0) ++distinct;        // 新种类进窗
        while (distinct == m) {                  // 合法就尽量缩
            if (r - l < br - bl) bl = l, br = r;
            if (--cnt[c[l]] == 0) --distinct;    // 左端出窗
            ++l;
        }
    }
    cout << bl << " " << br << "\n";
    return 0;
}
```

复杂度 $O(n)$：每个下标进窗、出窗各一次。若把条件换成「窗口内无重复」，只需把 `distinct == m` 改成 `cnt[c[r]] > 1`，其余不动。

## 六、复杂度与易错点

| 项 | 值 |
|---|---|
| 时间复杂度 | 前缀和预处理 $O(n)$、查询 $O(1)$；差分修改 $O(1)$、还原 $O(n)$；双指针与滑窗 $O(n)$ |
| 空间复杂度 | 前缀和 $O(n)$（二维 $O(nm)$）；差分 $O(n)$；哈希 $O(n)$ |

- 区间和写成 `P[r] - P[l]`，少减一位，所有 $l>1$ 的查询整体偏移。
- 二维容斥漏掉 `+ S[x1-1][y1-1]`，左上角被减两次，答案偏小。
- 差分只开 $n$ 格，`d[r+1] -= v` 越界，$n=1$ 时当场 RE。
- 含负数仍用双指针求「和 $\ge S$ 的最短段」，左端不单调，答案偏大。
- 滑窗收缩忘 `--cnt[c[l]]` 或忘维护 `distinct`，窗口永不合法，答案停在初始值。
- 哈希法忘 `cnt[0] = 1`，从第一个元素开始的子数组全部漏算。
