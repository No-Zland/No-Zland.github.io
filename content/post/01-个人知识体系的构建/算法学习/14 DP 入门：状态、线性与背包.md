# DP 入门：状态、线性与背包

> 一句话本质：DP 是把重复出现的子问题存下来、按依赖顺序各算一次；动手只做三件事——定义状态、写转移、定顺序。

## 一、是什么

**动态规划**把原问题拆成彼此重叠的子问题，用一张表存下答案，再按拓扑序递推。前提两条：**最优子结构**（全局最优由子问题最优拼成）、**无后效性**（状态确定后，未来决策与"怎么走到这里"无关）。

它解决三类问题：最值、计数、可行性。共同点不是"难"，而是"决策有阶段、阶段间的依赖单向"。

识别信号：

- 问"最多 / 最少 / 有多少种方案"，且每一步的选择只影响后面：DP，而不是搜索。
- 数据范围呈 $n\cdot V\approx10^7$ 的形状（$n\le10^3,V\le10^4$）：这是 $O(nV)$ 的邀请函。
- 每件物品"选或不选"、有容量上限、每件只能用一次：01 背包。
- 同一件物品能无限次取，或者"当天买、隔天卖、可以反复交易"：完全背包。
- 序列上问"以 $i$ 结尾的最长上升子序列"，两个序列做配对：LIS / LCS。
- 题面强调"恰好装满""不超过""至少"：先看清这几个字，它决定初始化。

不该用它的场景：

- 状态记不下"选过哪些"：改搜索或状压。
- 决策之间有环、没有拓扑序：那是最短路径或解方程。
- 必须输出方案本身：加"来源"数组，或直接 DFS。

## 二、形式

**数学形式。** 统一写成"枚举最后一步决策"：

$$f[i]=\max_{k\in D(i)}\bigl\{f[k]+c(i,k)\bigr\}$$

01 背包是它最标准的一例，$f[i][j]$ 表示前 $i$ 件、容量 $j$ 的最大价值：

$$f[i][j]=\max\bigl(f[i-1][j],\;f[i-1][j-w_i]+v_i\bigr),\quad f[0][j]=0$$

LIS 的递推是 $f[i]=1+\max\{f[j]\mid j<i,\ a_j<a_i\}$，答案是 $\max_i f[i]$ 而**不是** $f[n]$。

**代码形式。** 骨架永远是三层，从外到内：`for 阶段 → for 状态 → for 决策 → 转移`。背包把"决策"折进了 `max` 的两项里，所以只剩两层循环——但顺序从此变成语义。

**数据形式。** 二维表 `f[n+1][V+1]` 最直观；转移只依赖上一阶段，可以压成一维 `f[V+1]`，空间 $O(nV)\to O(V)$。这个压缩不是优化技巧，而是"顺序问题"的根源：一维数组同时扮演"上一行"和"本行"。

## 三、怎么理解

**直觉。** 暴力枚举所有选择组合（$2^n$ 条路），DP 发现"走到同一状态的不同路径后续完全一样"，于是每格只留最好的一条——一次合并。

**为什么正确（归纳）。** 设阶段 $1..n$ 递增，且 $<i$ 的阶段都已最优。阶段 $i$ 的最优解最后一步必属于 $D(i)$，之前的部分是 $<i$ 的子问题，由无后效性换成最优解不会更差，故枚举 $D(i)$ 取最大即得 $f[i]$。无后效性一旦不成立（LIS 只记"前 $i$ 个的长度"就用到了被丢掉的历史），归纳断裂——这就是"状态没切干净"。

**手推 01 背包。** $V=10$，物品 $(w,v)=(5,10),(4,7),(3,5)$，一维数组倒序更新，初值全 0。

- 物品 1（$w=5$）：得 $f[5..10]=10$。
- 物品 2（$w=4$）：$j=10$ 时 `f[6]` 仍是物品 1 时代的 10，故 $f[10]=\max(10,10+7)=17$；$j=8$ 时 $f[4]=0$，仍是 10。
- 物品 3（$w=3$）：$f[10]=\max(17,f[7]+5=15)=17$，$f[8]=\max(10,f[5]+5=15)=15$。

最终 $f[10]=17$，方案是 $4+3$ 两件。倒序保证 `f[j-w]` 读到的都是上一轮的值。

**为什么倒序。** 一维数组里 `f[j-w]` 既可能是上一行、也可能是本行。倒序时 $j$ 从大到小、$j-w<j$，那一格**本轮还没被改过**，读到的是 $i-1$ 的值，等价于每件最多用一次；正序则刚被刷新，会把同一件塞进去无数次。

## 四、怎么变成代码

**映射。**

- 阶段：物品下标 $i$（或序列位置、时间）；状态：容量 $j$、结尾位置 $i$；决策：选或不选、接到哪个 $j$。
- 循环顺序：外层物品、内层容量；01 用 `j = V → w`，完全用 `j = w → V`。LIS 二分版没有容量，靠 `lower_bound` 找插入点。
- 边界：最值型 `f` 全 0（表示"不超过"），恰好装满用 $-\infty$；计数型 `f[0]=1`、其余 0。
- 答案：`f[V]`（背包）、`max f[i]`（LIS、最大子段和）、`f[1]`（数字三角形）。

```cpp
#include <iostream>
#include <vector>
#include <algorithm>

// 01 背包：每件最多一次 → 容量倒序
long long knapsack01(int V, const std::vector<int>& w, const std::vector<long long>& v) {
    std::vector<long long> f(V + 1, 0);
    for (size_t i = 0; i < w.size(); ++i)
        for (int j = V; j >= w[i]; --j)                 // 倒序：f[j-w] 仍是上一行的值
            f[j] = std::max(f[j], f[j - w[i]] + v[i]);
    return f[V];
}

// 完全背包：每件无限次 → 容量正序
long long knapsackFull(int V, const std::vector<int>& w, const std::vector<long long>& v) {
    std::vector<long long> f(V + 1, 0);
    for (size_t i = 0; i < w.size(); ++i)
        for (int j = w[i]; j <= V; ++j)                 // 正序：f[j-w] 已含本件，可重复选
            f[j] = std::max(f[j], f[j - w[i]] + v[i]);
    return f[V];
}

// LIS（严格上升）O(n log n)：tails[len-1] 是长度 len 的上升子序列的最小结尾
int lis(const std::vector<int>& a) {
    std::vector<int> tails;
    for (int x : a) {
        auto it = std::lower_bound(tails.begin(), tails.end(), x);  // 非降换成 upper_bound
        if (it == tails.end()) tails.push_back(x);
        else *it = x;
    }
    return (int)tails.size();
}

int main() {
    int n, V;
    std::cin >> n >> V;
    std::vector<int> w(n);
    std::vector<long long> v(n);
    for (int i = 0; i < n; ++i) std::cin >> w[i] >> v[i];
    std::cout << knapsack01(V, w, v) << ' ' << knapsackFull(V, w, v) << '\n';
    return 0;
}
```

## 五、具体例子

**1. 01 背包：为什么必须倒序。**

问题：$n$ 件物品，第 $i$ 件重 $w_i$ 值 $v_i$，容量 $V$，每件至多选一次，求最大价值。

形式：$f[j]=\max(f[j],f[j-w_i]+v_i)$，$j$ 从 $V$ 递减到 $w_i$。

```cpp
#include <iostream>
#include <vector>
#include <algorithm>
using namespace std;

int main() {
    const int V = 10;
    vector<int> w = {5, 4, 3};
    vector<long long> v = {10, 7, 5};
    vector<long long> back(V + 1, 0), fwd(V + 1, 0);

    for (size_t i = 0; i < w.size(); ++i) {
        for (int j = V; j >= w[i]; --j)                       // 正确：倒序
            back[j] = max(back[j], back[j - w[i]] + v[i]);
        for (int j = w[i]; j <= V; ++j)                       // 错误示范：正序
            fwd[j] = max(fwd[j], fwd[j - w[i]] + v[i]);
    }
    cout << "倒序 " << back[V] << "（应为 17）\n";
    cout << "正序 " << fwd[V] << "（退化成完全背包，20）\n";
    return 0;
}
```

复杂度：$O(nV)$ 时间，$O(V)$ 空间。正序版把重 5 的物品选了两次，恰好证明"顺序即语义"。

**2. 完全背包：正序 + 纪念品逐日。**

问题（P5662 纪念品）：$T$ 天、$N$ 种纪念品，第 $i$ 天第 $j$ 种价格 $p_{i,j}$，初始 $M$ 元。每天可以任意买卖（当天买当天也能卖），求 $T$ 天后的最大现金。

形式：第 $d$ 天以现金为容量、第 $j$ 种为"重 $p_{d,j}$、值 $p_{d+1,j}-p_{d,j}$"的物品做完全背包，收益落袋后滚到次日——当天能反复买卖同一件，正是"正序"的语义。

```cpp
#include <iostream>
#include <vector>
#include <algorithm>
using namespace std;

int main() {
    int T, N;
    long long M;
    cin >> T >> N >> M;
    vector<vector<int>> p(T, vector<int>(N));
    for (int i = 0; i < T; ++i)
        for (int j = 0; j < N; ++j) cin >> p[i][j];

    for (int d = 0; d + 1 < T; ++d) {
        int cap = (int)M;
        vector<long long> f(cap + 1, 0);
        for (int j = 0; j < N; ++j) {
            int cost = p[d][j], gain = p[d + 1][j] - p[d][j];
            if (gain <= 0) continue;                       // 明天不涨就不买
            for (int c = cost; c <= cap; ++c)              // 正序：同一天可反复买卖
                f[c] = max(f[c], f[c - cost] + gain);
        }
        M += f[cap];                                       // 今天的收益落袋
    }
    cout << M << '\n';
    return 0;
}
```

复杂度：$O(T\cdot N\cdot M)$ 时间，$O(M)$ 空间。

**3. LIS：$O(n^2)$ 与 $O(n\log n)$。**

问题：求最长严格上升子序列长度。

形式：朴素版 $f[i]=1+\max\{f[j]\mid j<i,a_j<a_i\}$；优化版维护 `tails`，`tails[len-1]` 是"长度为 len 的上升子序列可能的最小结尾"，来一个 $x$ 就二分替换第一个 $\ge x$ 的位置。

```cpp
#include <iostream>
#include <vector>
#include <algorithm>
using namespace std;

int lisSlow(const vector<int>& a) {
    int n = (int)a.size(), best = 0;
    vector<int> f(n, 1);
    for (int i = 0; i < n; ++i) {
        for (int j = 0; j < i; ++j)
            if (a[j] < a[i]) f[i] = max(f[i], f[j] + 1);
        best = max(best, f[i]);                 // 答案是所有 f 的最大值
    }
    return best;
}

int lisFast(const vector<int>& a) {
    vector<int> tails;
    for (int x : a) {
        auto it = lower_bound(tails.begin(), tails.end(), x);  // 第一个 >= x
        if (it == tails.end()) tails.push_back(x);
        else *it = x;                           // 用更小的结尾换掉，后续更容易接
    }
    return (int)tails.size();
}

int main() {
    vector<int> a = {3, 1, 4, 2};
    cout << lisSlow(a) << ' ' << lisFast(a) << '\n';   // 2 2
    return 0;
}
```

复杂度：$O(n^2)$ / $O(n\log n)$，空间 $O(n)$。手算 $[3,1,4,2]$：`[3] → [1] → [1,4] → [1,2]`，长度 2。`tails` 存的**不是**某个真实子序列，只保证长度信息正确。

**4. 数字三角形：自底向上。**

问题（P1216）：$n$ 层三角形，从顶到底走，每步只能到左下或右下，求路径最大和。

形式：$f[i][j]=\max(f[i+1][j],f[i+1][j+1])+a[i][j]$，自底向上推，答案 $f[1][1]$，不必判越界。

```cpp
#include <iostream>
#include <vector>
#include <algorithm>
using namespace std;

int main() {
    int n;
    cin >> n;
    vector<vector<int>> a(n + 1, vector<int>(n + 2, 0));
    for (int i = 1; i <= n; ++i)
        for (int j = 1; j <= i; ++j) cin >> a[i][j];
    vector<int> f(n + 2, 0);
    for (int i = n; i >= 1; --i)
        for (int j = 1; j <= i; ++j)
            f[j] = max(f[j], f[j + 1]) + a[i][j];   // f[j+1] 还是下一行的旧值
    cout << f[1] << '\n';
    return 0;
}
```

复杂度：$O(n^2)$ 时间，$O(n)$ 空间（滚动成一维，$j$ 升序保证 $f[j+1]$ 未被覆盖）。

## 六、复杂度与易错点

| 项 | 时间 | 空间 |
|---|---|---|
| 01 / 完全背包 | $O(nV)$ | $O(V)$ |
| 多重背包（二进制拆分） | $O(nV\log c)$ | $O(V)$ |
| LIS | $O(n^2)$ / $O(n\log n)$ | $O(n)$ |
| LCS | $O(nm)$ | $O(nm)$，可滚动到 $O(m)$ |
| 数字三角形 | $O(n^2)$ | $O(n)$ |

- 01 背包写成正序：一件被选多次，大样例偏大；完全背包写成倒序则退化成 01，答案偏小。
- 计数型 `f[0]` 留成 0：答案全是 0；忘了取模则溢出 `int`。
- "恰好装满"用全 0 初始化：把"装不满"也当成合法方案；应初始化 $-\infty$，最后判 `f[V] < 0`。
- LIS 严格上升用 `lower_bound`，非降用 `upper_bound`，混用会把相等元素算进上升。
- LIS 的 $O(n^2)$ 版答案取 `f[n]`：错，应取 $\max_i f[i]$。
