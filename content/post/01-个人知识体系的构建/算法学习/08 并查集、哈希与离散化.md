# 并查集、哈希与离散化

> 一句话本质：并查集维护「谁和谁是一伙的」，哈希把「值」变成「下标」，离散化是保序的哈希——三者都在解决同一对矛盾：**信息量小，值域大**。

## 一、是什么

并查集（DSU）维护**等价关系**：把 $n$ 个元素划成若干不相交的集合，只支持 `find(x)`（返回代表元）与 `unite(x,y)`（合并）。它不存集合里的元素，只存「谁属于谁」——问题只问「是不是一伙」，不问「都有谁」，这才可能做到近似 $O(1)$。

哈希表把键 $k$ 经 $h(k)$ 映射到 $[0,M)$ 的桶，冲突用拉链或开放寻址处理，期望 $O(1)$。离散化把「值域大、取值稀疏」的序列换成排名，只保留相对大小，于是能拿数组当桶。

识别信号：

- 「连通」「合并」「是否同一组」「朋友的朋友还是朋友」；
- 「敌人的敌人是朋友」「A 吃 B、B 吃 C」这类两类以上的关系；
- 「两者差值恰为 $d$」「倍数关系」——带权并查集；
- 值域到 $10^9$，但真正出现的数只有 $10^5$ 个；
- 统计「多少种不同的数」、查「某个值出现几次」；

不该用它的时候：

- 需要**拆分集合**或**删除元素**：并查集只支持合并，删边要离线倒序；
- 需要**有序遍历 / 前驱后继 / 第 $k$ 小**：用 `set`，代表元没有顺序；
- 值域小且连续（如 26 个字母）：直接开数组，哈希是负优化；
- `unordered_map` 被卡成 $O(n)$ 还硬用：换排序或自己写哈希。

## 二、形式

**数学形式.** 等价关系（自反、对称、传递）把 $S$ 划成等价类，`find` 是代表元映射 $\pi$：

$$\pi(\pi(x))=\pi(x), \qquad x\sim y \iff \pi(x)=\pi(y).$$

`unite` 是划分的**粗化**：把两类并成一类，类数减一。按秩合并保证树高 $O(\log n)$，路径压缩把均摊代价压到 $O(\alpha(n))$——$\alpha$ 是反阿克曼函数，$n\le10^9$ 时 $\alpha\le4$。

种类并查集：把每个元素复制 $k$ 份，第 $t$ 份编号 $x+tn$，表示「$x$ 属于第 $t$ 类」这个**命题**；合并副本即令两个命题同真同假。

离散化：对去重排序后的 $b$，

$$\text{id}(x)=|\{i:b_i<x\}|+1=\text{lower\_bound}(b,x)-b+1.$$

哈希：$h(k)=k\bmod M$，装填因子 $\alpha=n/M$。拉链法一次成功查找的期望比较约 $1+\alpha/2$；线性探测约 $\frac12\left(1+\frac{1}{1-\alpha}\right)$，$\alpha\to1$ 时爆炸，所以要把 $\alpha$ 压在 0.7 以下。

**代码形式.**

```cpp
#include <vector>
using namespace std;

struct DSU { int find(int x); bool unite(int x, int y); bool same(int x, int y); };
vector<int> compress(const vector<int>& v);   // 1-based 排名
```

**数据形式.** `fa[x]` 存父亲（根的父亲是自己），`sz[x]` 存集合大小；种类并查集开 $kn$ 个点；哈希表是桶数组 + 冲突结构；离散化另存一份去重后的值表用于反查。

## 三、怎么理解

**直觉.** 并查集像认大哥：每人只记得直接上级，问「你俩是不是一伙」就各自往上问到最终的大哥。路径压缩让路径上每人直接记住大哥，按秩合并是「小帮派并入大帮派」，避免层级越叠越深。哈希像按首字母分书架；离散化像按身高排名，不关心多高，只关心第几。

**为什么路径压缩不改变等价类.** `find` 只把 `fa[x]` 改成根，而根本来就在 $x$ 的同一棵树里，所以「谁和谁连通」不变，只是树变浅。按秩合并让高度只在等高时增 1，故树高 $O(\log n)$；压缩再把这个对数摊掉。

**为什么种类并查集能判矛盾.** 以两类关系（敌人）为例：$x$ 与 $x+n$ 分别表示「$x$ 在 A 组」「$x$ 在 B 组」。说「$x$ 与 $y$ 是敌人」就合并 $(x,y+n)$ 与 $(x+n,y)$——恰是「$x$ 在 A $\Rightarrow$ $y$ 在 B」与「$x$ 在 B $\Rightarrow$ $y$ 在 A」。于是副本同集合就代表一条已推出的断言；新说法与它冲突（如 `find(x)==find(y)` 又说 $x,y$ 是敌人）即矛盾。

**手推.** $n=5$，依次 `unite(1,2)`、`unite(3,4)`、`unite(2,3)`，再 `find(4)`：

| 操作 | 说明 | `fa[1..5]` |
|---|---|---|
| 初始 | 各自为根 | 1 2 3 4 5 |
| unite(1,2) | 等大，2 挂 1 | 1 1 3 4 5 |
| unite(3,4) | 等大，4 挂 3 | 1 1 3 3 5 |
| unite(2,3) | 根 1、3 等大，3 挂 1 | 1 1 1 3 5 |
| find(4) | 4→3→1，压缩 | 1 1 1 1 5 |

## 四、怎么变成代码

映射：

- `fa[x]`：父亲下标，根满足 `fa[x]==x`。初始化 `fa[i]=i`、`sz[i]=1`——忘掉 `sz` 会让按秩退化成随机挂。
- `find` 两趟迭代：第一趟走到根，第二趟把路径上每个点直接连到根。递归版在 $10^6$ 的链上会爆栈。
- `unite`：先各自 `find`，相同返回 `false`（已连通，别重复加边）；否则小挂大，`sz` 相加。
- 种类并查集：`id(x,t)=x+t*n`，$k$ 类开 $kn$ 个点；合并时**所有类一起平移**，漏一类就会判错。
- 离散化：排序 → `unique` → 对每个原值 `lower_bound`；返回 0-based，按需 +1。查存在的值要验 `b[id-1]==x`，否则会把「插入位置」当成「存在」。
- 哈希：模数取质数、远离 2 的幂；`unordered_map` 要防卡（随机盐或换 `map`）。

完整模板：

```cpp
#include <vector>
#include <numeric>
#include <algorithm>
using namespace std;

struct DSU {
    vector<int> fa, sz;
    explicit DSU(int n) : fa(n + 1), sz(n + 1, 1) { iota(fa.begin(), fa.end(), 0); }
    int find(int x) {
        int r = x;
        while (fa[r] != r) r = fa[r];                             // 1 找根
        while (fa[x] != r) { int p = fa[x]; fa[x] = r; x = p; }   // 2 压平路径
        return r;
    }
    bool unite(int x, int y) {
        x = find(x); y = find(y);
        if (x == y) return false;
        if (sz[x] < sz[y]) swap(x, y);                            // 小挂大
        fa[y] = x; sz[x] += sz[y];
        return true;
    }
    bool same(int x, int y) { return find(x) == find(y); }
    int roots(int n) {                                            // 连通块个数
        int c = 0;
        for (int i = 1; i <= n; ++i) c += (find(i) == i);
        return c;
    }
};

vector<int> compress(const vector<int>& v) {                      // 1-based 排名
    vector<int> b = v;
    sort(b.begin(), b.end());                                     // 1 排序
    b.erase(unique(b.begin(), b.end()), b.end());                 // 2 去重
    vector<int> id(v.size());
    for (size_t i = 0; i < v.size(); ++i)
        id[i] = int(lower_bound(b.begin(), b.end(), v[i]) - b.begin()) + 1;
    return id;
}
```

## 五、具体例子

### 例 1：并查集——亲戚 / 连通块（P1551）

问题：$n$ 个人、$m$ 对亲戚关系、$q$ 次询问两人是否亲戚（关系可传递）。

套哪个形式：等价类。每条关系一次 `unite`，每次询问一次 `same`。亲戚关系自反、对称、传递，正是等价关系——这是能套它的唯一理由。

```cpp
#include <cstdio>
#include <vector>
#include <numeric>
using namespace std;

vector<int> fa, sz;
int find(int x) {
    int r = x;
    while (fa[r] != r) r = fa[r];
    while (fa[x] != r) { int p = fa[x]; fa[x] = r; x = p; }
    return r;
}
void unite(int x, int y) {
    x = find(x); y = find(y);
    if (x == y) return;
    if (sz[x] < sz[y]) { int t = x; x = y; y = t; }
    fa[y] = x; sz[x] += sz[y];
}

int main() {
    int n, m, q;
    scanf("%d %d %d", &n, &m, &q);
    fa.resize(n + 1); sz.assign(n + 1, 1);
    iota(fa.begin(), fa.end(), 0);
    for (int i = 0; i < m; ++i) { int a, b; scanf("%d %d", &a, &b); unite(a, b); }
    while (q--) {
        int a, b; scanf("%d %d", &a, &b);
        puts(find(a) == find(b) ? "Yes" : "No");
    }
    return 0;
}
```

复杂度：$O((n+m+q)\,\alpha(n))$，近似线性；空间 $O(n)$。

### 例 2：种类并查集——食物链（P2024）

问题：$n$ 只动物，每句说「$x$ 与 $y$ 同类」或「$x$ 吃 $y$」，三类循环：A 吃 B、B 吃 C、C 吃 A。按顺序判假话条数。

套哪个形式：$k=3$ 类的等价类。两类关系（敌人）只需 `x` 与 `x+n` 两倍空间；食物链有三类，把这套「复制副本」的做法再做一份，就是 $x$、$x+n$、$x+2n$。

- 同类：`unite(x,y)`、`unite(x+n,y+n)`、`unite(x+2n,y+2n)`；
- $x$ 吃 $y$：整体平移一类——`unite(x,y+n)`、`unite(x+n,y+2n)`、`unite(x+2n,y)`；
- 判假：说同类前若已推出任一方吃另一方；说吃前若已同类或已推出 $y$ 吃 $x$；编号越界也算假。

```cpp
#include <cstdio>
#include <vector>
#include <numeric>
using namespace std;

int n, k;
vector<int> fa, sz;

int find(int x) {
    int r = x;
    while (fa[r] != r) r = fa[r];
    while (fa[x] != r) { int p = fa[x]; fa[x] = r; x = p; }
    return r;
}
void unite(int x, int y) {
    x = find(x); y = find(y);
    if (x == y) return;
    if (sz[x] < sz[y]) { int t = x; x = y; y = t; }
    fa[y] = x; sz[x] += sz[y];
}
int id(int x, int t) { return x + t * n; }        // t = 0 / 1 / 2

int main() {
    scanf("%d %d", &n, &k);
    fa.resize(3 * n + 1); sz.assign(3 * n + 1, 1);
    iota(fa.begin(), fa.end(), 0);
    int bad = 0;
    while (k--) {
        int op, x, y;
        scanf("%d %d %d", &op, &x, &y);
        if (x > n || y > n) { ++bad; continue; }
        if (op == 1) {
            if (find(id(x,0)) == find(id(y,1)) || find(id(x,0)) == find(id(y,2))) { ++bad; continue; }
            for (int t = 0; t < 3; ++t) unite(id(x, t), id(y, t));
        } else {
            if (find(id(x,0)) == find(id(y,0)) || find(id(x,0)) == find(id(y,2))) { ++bad; continue; }
            unite(id(x,0), id(y,1));
            unite(id(x,1), id(y,2));
            unite(id(x,2), id(y,0));
        }
    }
    printf("%d\n", bad);
    return 0;
}
```

复杂度：$O(k\,\alpha(n))$，空间 $O(3n)$。

### 例 3：哈希表——两数之和

问题：给 $n$ 个数与 $t$，找 $i<j$ 使 $a_i+a_j=t$。

套哪个形式：把「找配对」变成「查表」。扫到 $a_i$ 时只需知道 $t-a_i$ 是否出现过，一次哈希查询把 $O(n^2)$ 降到 $O(n)$。

```cpp
#include <cstdio>
#include <vector>
#include <unordered_map>
using namespace std;

int main() {
    int n; long long t;
    scanf("%d %lld", &n, &t);
    unordered_map<long long, int> pos;      // 值 -> 最早出现的下标
    for (int i = 1; i <= n; ++i) {
        long long x; scanf("%lld", &x);
        auto it = pos.find(t - x);
        if (it != pos.end()) { printf("%d %d\n", it->second, i); return 0; }
        if (!pos.count(x)) pos[x] = i;      // 只留最早的下标，保证 i < j
    }
    puts("-1");
    return 0;
}
```

拉链法：每个桶挂一条链表，冲突就在链表里找。开放寻址：冲突时按 $(h(k)+i)\bmod M$ 往后试空桶，装填因子压在 0.7 以下。计数场景直接把 `pos` 换成 `cnt[x]++`。

复杂度：期望 $O(n)$，最坏 $O(n^2)$。

### 例 4：离散化——统计数字（NOIP2007）

问题：$n\le2\times10^5$ 个不超过 $1.5\times10^9$ 的数，按升序输出「数值 出现次数」。

套哪个形式：排序 + 扫描；若要接树状数组（以值为下标），就用离散化把值域压到 $1..m$。

```cpp
#include <cstdio>
#include <vector>
#include <algorithm>
using namespace std;

int main() {
    int n; scanf("%d", &n);
    vector<int> a(n);
    for (int& x : a) scanf("%d", &x);
    vector<int> b = a;
    sort(b.begin(), b.end());                                 // 1 排序
    b.erase(unique(b.begin(), b.end()), b.end());             // 2 去重
    vector<int> cnt(b.size() + 1, 0);
    for (int x : a)                                            // 3 lower_bound 映射
        ++cnt[lower_bound(b.begin(), b.end(), x) - b.begin() + 1];
    for (size_t i = 1; i <= b.size(); ++i)
        if (cnt[i]) printf("%d %d\n", b[i - 1], cnt[i]);
    return 0;
}
```

复杂度：$O(n\log n)$，空间 $O(n)$。

## 六、复杂度与易错点

| 结构 | 单次时间 | 空间 |
|---|---|---|
| 并查集（压缩 + 按秩） | $O(\alpha(n))\approx O(1)$ | $O(n)$ |
| 种类并查集 | $O(\alpha(n))$ | $O(kn)$ |
| 哈希表 | 期望 $O(1)$，最坏 $O(n)$ | $O(n)$ |
| 离散化 | 建表 $O(n\log n)$，查询 $O(\log n)$ | $O(n)$ |

1. 初始化只写 `fa[i]=i`，忘了 `sz[i]=1`，小挂大失效。
2. `find` 写成递归，$10^6$ 的链直接爆栈。
3. 种类并查集只并了一类，另外两类没同步，判矛盾结果随机。
4. 离散化后忘了 `lower_bound` 是 0-based，当 1-based 下标用，树状数组越界或死循环。
5. 查离散化里不存在的值，不验 `b[id-1]==x` 就当成存在。
