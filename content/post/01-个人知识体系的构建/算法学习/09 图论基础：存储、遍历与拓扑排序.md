# 图论基础：存储、遍历与拓扑排序

> 一句话本质：图论先决定「关系怎么存」，再用一次遍历把「可达」摊平成一个顺序；拓扑序就是 DAG 上做 DP 的许可证。

## 一、是什么

图 $G=(V,E)$ 由点集和边集组成：点是被讨论的对象，边是对象之间的二元关系。有向边表示单向依赖，无向边表示双向对等，边权表示走这条边的代价。图论算法反复回答的只有两个问题——**可达性**（能不能到、几步到、有几条路）和**顺序性**（谁必须先发生）。

它专门解决：连通块划分、无权最短路、依赖排序、二部划分、环检测，以及「在图上做 DP」。

识别信号：

- 输入是「$n$ 个点 $m$ 条边」加 $m$ 行 $u\ v\ (w)$，或一张 $n\times m$ 的字符网格——先建图，别写暴力。
- $n\le 10^5,\ m\le 2\times 10^5$：邻接矩阵开不下，只能邻接表；$n\le 500$ 且要反复查边，才轮到矩阵。
- 问「几个连通块」「能否全部到达」「两人是否互相可达」。
- 出现「上下左右移动」「只能走 `.`」「传送门」——网格图是隐式图，用 BFS/DFS。
- 出现「A 必须在 B 之前」「先修课」「任务依赖」——拓扑排序。
- 边权全是 1 却问「最少几步」——只能 BFS，DFS 求最短路一定错。
- 「分成两组，组内无边」——二分图染色。

不该用它的场景：只关心连通、不关心路径与顺序时，并查集更轻；点数上百万且只要连通性，DFS 递归会爆栈，应改迭代或并查集；边权带负时本篇的 BFS 全部失效，连 Dijkstra 也不行（交给 10）。

## 二、形式

数学形式。邻接表把存储压到 $\Theta(n+m)$。BFS 的核心不变量是队列中距离单调不减：

$$d[v]=d[u]+1,\qquad (u,v)\in E$$

拓扑排序（Kahn）的不变量：队列里永远是当前入度为 0 的点，已输出序列恒为某个合法拓扑序的前缀。DAG 上的 DP 形如

$$f[v]=\max_{(u,v)\in E}\{f[u]+w(u,v)\}$$

按拓扑序求值，算 $v$ 时所有前驱都已是终值——这就是「无后效性」在图上最直白的样子。

代码形式是一副骨架：先 `build` 建图，再 `bfs(s)` 或 `dfs(u,p)`，最后 `topo(order)`。

数据形式三种：`vector<int> g[N]` 存出边终点（无向图两个方向各存一次）；`indeg[]` 随加边自增；`d[]`、`color[]` 初始化为 $-1$、$0$，顺带充当访问标记。

## 三、怎么理解

直觉：BFS 是往水里扔石头，波纹一圈圈扩散，先到的一定圈数少；DFS 是一条路走到黑，撞墙再回头；拓扑排序是剥洋葱，入度为 0 的点没有任何前置，可以立刻剥掉，剥完一层又露出新的 0 入度点。

为什么正确：

- **BFS 首次到达即最短**：队列中 $d$ 非降，所以出队点的层号是当前最小值。任取一条 $s\to v$ 的路径，其倒数第二个点 $x$ 满足 $d[x]\ge d[u]$，于是 $d[v]\le d[x]+1$，若已有更短路径访问过 $v$ 就与「出队顺序」矛盾。归纳即得。
- **Kahn 正确**：若输出 $n$ 个点，则每条边 $(u,v)$ 在 $u$ 出队时让 $indeg[v]$ 减 1，$v$ 只可能更晚出队，所有约束都满足；若有环，环上点的入度被环内前驱撑着，永远减不到 0，输出必少于 $n$ 个。
- **DAG 上 DP 正确**：拓扑序保证前驱先于后继，$f[v]$ 用到的每个 $f[u]$ 都已是终值，不会被后来的更新改写。

手推一个 5 点图：边 $1\to2,1\to3,2\to4,3\to4,4\to5$。初始入度 $[0,1,1,2,1]$，队列 $[1]$。弹出 1，2、3 入度归零入队；弹 2，4 的入度 $2\to1$；弹 3，4 变 0 入队；再弹 4、5，得拓扑序 $1,2,3,4,5$。最长路 $f_1=0,\ f_2=f_3=1,\ f_4=2,\ f_5=3$，答案 3，对应链 $1\to2\to4\to5$。

## 四、怎么变成代码

映射关系：`g[u]` 是 $u$ 的出边终点表；每次 `g[u].push_back(v)` 就 `++indeg[v]`；BFS 的 `d[]` 初始 $-1$，既是距离又是 `vis`；染色用 $0/1/2$ 三态，$0$ 表示未染。

循环顺序只有一条铁律：**先出队，再松弛**。拓扑 DP 同样，必须在弹出 $u$ 之后才用它更新 $v$；若在入队时更新，前驱还可能被后来的点改大，答案就错了。

边界：多组数据要清空 `g`、`indeg`、`d`、`color`；Kahn 结束必须核对 `order.size() == n`；网格图统一判 `0 <= nx && nx < n`，`nx` 与 `x` 不要混用。

```cpp
// 显式标准头，不用 <bits/stdc++.h>
#include <cstdio>
#include <vector>
#include <queue>
#include <algorithm>
using namespace std;

const int N = 100005;
vector<int> g[N];
int indeg[N], d[N], color[N];

// 1) 无权 BFS：返回 s 所在连通块点数，d[v] 为最少边数
int bfs(int s) {
    queue<int> q;
    d[s] = 0; q.push(s);
    int cnt = 0;
    while (!q.empty()) {
        int u = q.front(); q.pop();
        ++cnt;
        for (int v : g[u])
            if (d[v] == -1) {          // -1 兼作未访问标记
                d[v] = d[u] + 1;       // 边权为 1，首次到达即最短
                q.push(v);
            }
    }
    return cnt;
}

// 2) Kahn：order 得到拓扑序；返回 false 表示有环
bool topo(int n, vector<int>& order) {
    queue<int> q;
    for (int i = 1; i <= n; ++i)
        if (indeg[i] == 0) q.push(i);
    while (!q.empty()) {
        int u = q.front(); q.pop();
        order.push_back(u);
        for (int v : g[u])
            if (--indeg[v] == 0) q.push(v);   // 减到 0 才有资格
    }
    return (int)order.size() == n;            // 少于 n 个点 = 有环
}

// 3) 二分图染色：相邻染相反色，撞同色即有奇环
bool paint(int u, int c) {
    color[u] = c;
    for (int v : g[u]) {
        if (color[v] == 0) {
            if (!paint(v, 3 - c)) return false;
        } else if (color[v] == c) {
            return false;
        }
    }
    return true;
}

int main() {
    const int n = 5;
    int es[5][2] = {{1,2},{1,3},{2,4},{3,4},{4,5}};
    for (auto& e : es) { g[e[0]].push_back(e[1]); ++indeg[e[1]]; }

    for (int i = 1; i <= n; ++i) d[i] = -1;
    printf("block = %d, d[5] = %d\n", bfs(1), d[5]);

    vector<int> order;
    printf("topo = %d, size = %d\n", (int)topo(n, order), (int)order.size());

    for (int i = 1; i <= 3; ++i) g[i].clear();   // 换成三角形，必冲突
    g[1].push_back(2); g[2].push_back(1);
    g[2].push_back(3); g[3].push_back(2);
    g[3].push_back(1); g[1].push_back(3);
    printf("bipartite = %d\n", (int)paint(1, 1));
    return 0;
}
```

## 五、具体例子

### 1. 邻接表 BFS：连通块与无权最短路

**问题**：给 $n$ 点 $m$ 边无向图，求 1 号点所在连通块大小，以及 1 到每个点的最少边数。

**形式**：`d[v] = d[u] + 1`，队列保证按 $d$ 非降处理，所以一个点第一次被赋值就是最短距离。

```cpp
#include <cstdio>
#include <vector>
#include <queue>
using namespace std;
const int N = 100005;
vector<int> g[N];
int d[N];

// 返回 s 所在连通块大小；d[v] = s 到 v 的最少边数，-1 表示不可达
int bfs(int s, int n) {
    for (int i = 1; i <= n; ++i) d[i] = -1;
    queue<int> q;
    d[s] = 0; q.push(s);
    int cnt = 0;
    while (!q.empty()) {
        int u = q.front(); q.pop();
        ++cnt;
        for (int v : g[u])
            if (d[v] == -1) {          // 第一次被访问
                d[v] = d[u] + 1;       // 按层推进
                q.push(v);
            }
    }
    return cnt;
}
```

**复杂度**：每个点入队一次、每条边被看两次，$O(n+m)$；空间 $O(n+m)$。

### 2. 拓扑排序：杂务与最大食物链计数

**问题**：P1113 每项杂务有耗时，必须等所有前置完成，求全部完成的最早时刻；P4017 求 DAG 上从入度 0 到出度 0 的路径条数。

**形式**：两者共用 Kahn，只是转移一个取 $\max$、一个求和：

$$fin[v]=\max(fin[v],\,fin[u]+t[v]),\qquad cnt[v]=\sum_{(u,v)} cnt[u]$$

```cpp
#include <cstdio>
#include <vector>
#include <queue>
#include <algorithm>
using namespace std;
const int N = 5005, MOD = 80112002;
vector<int> g[N];
int indeg[N], t[N], fin[N], cnt[N];

// P1113：f[v] = max(f[u]) + t[v]，即「等最慢的前置做完」
long long finishMax(int n) {
    vector<int> deg(indeg, indeg + n + 1);
    queue<int> q;
    for (int i = 1; i <= n; ++i)
        if (!deg[i]) { q.push(i); fin[i] = t[i]; }
    long long ans = 0;
    while (!q.empty()) {
        int u = q.front(); q.pop();
        ans = max(ans, (long long)fin[u]);
        for (int v : g[u]) {
            fin[v] = max(fin[v], fin[u] + t[v]);  // 前驱已全部算完
            if (--deg[v] == 0) q.push(v);
        }
    }
    return ans;
}

// P4017：cnt[v] += cnt[u]，链尾（出度 0）才结算
int foodChains(int n) {
    vector<int> deg(indeg, indeg + n + 1);
    queue<int> q;
    for (int i = 1; i <= n; ++i)
        if (!deg[i]) { q.push(i); cnt[i] = 1; }
    int ans = 0;
    while (!q.empty()) {
        int u = q.front(); q.pop();
        if (g[u].empty()) ans = (ans + cnt[u]) % MOD;
        for (int v : g[u]) {
            cnt[v] = (cnt[v] + cnt[u]) % MOD;
            if (--deg[v] == 0) q.push(v);
        }
    }
    return ans;
}
```

**复杂度**：每个点、每条边各处理一次，$O(n+m)$。

### 3. 二分图染色：奇数环为什么冲突

**问题**：能否把点染成两色，使每条边两端异色。

**形式**：`color[v] = 3 - color[u]`；冲突条件是遇到已染色且同色的邻居。沿一个环走 $k$ 步，颜色翻转 $k$ 次，回到起点要同色必须 $k$ 为偶数——**奇环必冲突，偶环不冲突**，所以「二分图」$\iff$「无奇环」。

```cpp
#include <cstdio>
#include <vector>
using namespace std;
const int N = 100005;
vector<int> g[N];
int col[N];

bool dfs(int u, int c) {
    col[u] = c;
    for (int v : g[u]) {
        if (!col[v]) {
            if (!dfs(v, 3 - c)) return false;
        } else if (col[v] == c) {
            return false;              // 同色相邻：出现奇环
        }
    }
    return true;
}

// 图可以不连通，每个未染色点起一次 DFS
bool isBipartite(int n) {
    for (int i = 1; i <= n; ++i)
        if (!col[i] && !dfs(i, 1)) return false;
    return true;
}
```

**复杂度**：$O(n+m)$，空间 $O(n+m)$。

## 六、复杂度与易错点

| 项 | 值 |
|---|---|
| 时间复杂度 | 建图 $O(n+m)$；单次 BFS/DFS $O(n+m)$；Kahn 普通队列 $O(n+m)$，求字典序最小换成小根堆 $O((n+m)\log n)$ |
| 空间复杂度 | 邻接表 $O(n+m)$；链式前向星 $2m$ 条边、每条 3 个 int；邻接矩阵 $O(n^2)$ |

- 有向图判环只用一个 `vis`，把指向「已完成」点的横叉边当成环；要 0/1/2 三色。
- 无向图 DFS 判环不判父亲，每条边都自成一环，重边还要单独处理。
- 链式前向星反边是 `i ^ 1`，要求边从 2 开始编号，从 1 开始会整体错位。
- 多组数据只清 `g` 不清 `indeg`，第二组开始一个点都入不了队。
- 拓扑排序不核 `order.size()`，有环时输出残序还当答案。
- 网格 BFS 把 `nx` 写成 `x` 去比边界，两套坐标混用。
