# 【数论】最小公倍数
## 最小公倍数

### 定义：

几个数 **共同的倍数** 叫做这几个数的公倍数，其中 **除0以外最小**的一个公倍数，叫做这几个数的最小公倍数。

### 性质：

1. 对于一系列整数 $a_1, a_2, \dots, a_n$，其中任意一个数 $a_i$ 都能被 $\text{lcm}(a_1, a_2, \dots, a_n)$ 整除。
如果其中任意一个数 $a_i$ 都能被 $b$ 整除，那么 $\text{lcm}(a_1, a_2, \dots, a_n)$ 也能被 $b$ 整除。

2. 对于任意的整数 $a，b，c$，有 $\text{lcm}(a, b, c) = \text{lcm}(a, b) \times \text{lcm}(b, c)$。
这告诉我们，**计算多个数字的最小公倍数** 可以拆分成计算**多组**数字（每组两个）的最小公倍数。最后计算它们的**乘积**。

3. 对于任意的整数 $a$，$b$，$\text{lcm}(a, b) = \text{lcm}(b, a)$。
即最小公倍数的数值不依赖数字的顺序。

4. 对于任意的整数 $a，b$，他们的最小公倍数 $\text{lcm}(a, b)$ 与最大公约数 $\text{gcd}(a, b)$ 之间有关系
$$
 \text{lcm}(a, b) \cdot \text{gcd}(a, b) = a \cdot b 
$$


据此我们还可以推出两条特殊性质：
* 如果 $a$ 与 $b$ 互质，那么它们的最小公倍数就是两者乘积 $a·b$。
* 如果 $a$ 是 $b$ 的因数，那么它们的最小公倍数就是 $b$。

## 代码1：直接调用lcm函数

```cpp
#include <numeric>
using namespace std;
using ull = unsigned long long;

int main(){
    ull a, b;
    cin >> a >> b;
    cout << lcm(a, b);
}
```

## 代码2：借助辗转相除法与性质4实现

```cpp
#include <iostream>
using namespace std;
using ull = unsigned long long;
// 辗转相除法
ull gcd(ull a, ull b){
	while(b){
		ull t = a % b;
		a = b;
		b = t;
	}
	return a;
}
// 性质4
ull lcm(ull a, ull b){
	return a / gcd(a, b) * b; // 先乘后除容易溢出
}

int main(){
	ull a, b;
	cin >> a >> b;
	cout << lcm(a, b);
}
```
