# 贪心与构造：先猜后证

> 一句话本质：贪心是每步取局部最优、再用交换论证担保全局最优；构造是先手玩小数据猜出通项，再验证它满足全部约束。

## 一、是什么

**贪心**：把最优解拆成有先后顺序的选择，每步只按一个局部指标取最优，且永不回头修改。**构造**：不优化任何目标，只回答「存不存在」，从 $n=1,2,3$ 的答案里看出模式，给出通项并验证约束。

识别信号：

1. 问「最多选几个」「最少花多少」，且每步选择只依赖已做过的选择。
2. 题面出现「互不重叠」「同一时刻只能处理一个」——冲突 + 最大相容子集。
3. 代价与处理顺序有关（排队、合并、装载），在暗示你排序。
4. 带「截止时间 / 有效期」，每个单位时间做一件。
5. $n\le10^5$ 要求 $O(n\log n)$，却看不出 DP 的阶段在哪。
6. 给定 $n$，要你「输出任意一个满足……的序列」，样例只给小 $n$——那是请你手玩。

不该用它：局部最优会挤占后续资源、且挤占无法用统一尺度比较时（0/1 背包按性价比贪心就是反例）；写不出「换掉不劣」的论证时；构造题的约束互相牵制到必须先搜索才知道有没有解时。

## 二、形式

贪心是一个选择序列 $g_1,\dots,g_k$，$g_i=\arg\min_{c\in C_i}w(c)$，$C_i$ 是第 $i$ 步的可行集。最优性由交换引理担保：

$$\text{若}\ \exists\,\text{最优解}\ O,\ \text{在首个分歧位}\ i\ \text{把}\ O_i\ \text{换成}\ G_i\ \text{后仍最优},\ \text{则}\ G\ \text{最优}$$

区间调度：$\max|S|$，约束 $\forall a,b\in S:\ r_a\le l_b\ \lor\ r_b\le l_a$。合并果子的代价是哈夫曼带权路径长：

$$\min\sum_i w_i\cdot depth_i\ =\ \min\sum_k\big(w(a_k)+w(b_k)\big)$$

代码形式：`sort(cmp)` + 一趟扫描；`priority_queue<int,vector<int>,greater<int>>`。数据形式：按右端点排好序的 `vector<pair<int,int>>` 就是候选序列，堆是「当前已选集合」——贪心需要存的状态往往只有一个标量（`last`、当前总和）。

## 三、怎么理解

直觉：区间调度像订会议室，先结束的会议留下的空档最多；合并果子像捆绳子，越早被合进去的堆，会被后面每一次合并重复计费，所以让它最轻。

为什么正确：交换论证三步——取首个分歧位、把最优解的选项换成贪心的、证明不劣，再对剩余部分归纳。合并果子用「最轻的两堆必是兄弟」：设权最小的 $a$ 不在最深，把最深叶子 $x$ 与它交换，$\sum w\cdot depth$ 只会变小，故存在最优解让 $a$ 在最深。

手推区间：$[1,4],[2,3],[3,5],[4,6]$ 按右端点为 $[2,3],[1,4],[3,5],[4,6]$。选 $[2,3]$，$last=3$；$[1,4]$ 判 $1<3$ 跳过；$[3,5]$ 判 $3\ge3$ 选上，$last=5$；$[4,6]$ 跳过，答案 2。这正是按右端点排序的理由：两条冲突时，先结束的那条留给后面的余地更大。

手推合并果子 $1,2,3$：合 $1+2=3$（代价 3），再合 $3+3=6$，总 9；若先合 $2+3=5$ 再合 $1+5=6$，总 11，更差。

## 四、怎么变成代码

映射：比较器只比 `second`（右端点），`first` 是左端点，别搞混；`last` 存「上一个选中区间的右端点」，初值 $-\infty$；判据写 `l >= last`，端点相接算相容；堆必须显式给 `greater`，默认大根堆恰好是错的那一半；代价与答案用 `long long`（$10^4$ 堆、每堆 $10^9$ 就会超 `int`）。

循环顺序：先排序再单趟扫描——交换论证要求候选按右端点不降，扫描只是把这个不变量往前推一格。边界：空集返回 0；堆只剩一堆时不再合并；构造题先特判 $n=1$。

```cpp
#include <iostream>
#include <vector>
#include <queue>
#include <algorithm>
using namespace std;

// 区间调度：按右端点升序，能接就接（交换论证见正文）
int maxSeg(vector<pair<int, int>> seg) {
    sort(seg.begin(), seg.end(),
         [](const pair<int, int>& a, const pair<int, int>& b) { return a.second < b.second; });
    int cnt = 0;
    long long last = -(1LL << 60);
    for (auto& s : seg)
        if (s.first >= last) { ++cnt; last = s.second; }   // 端点相接也相容
    return cnt;
}

// 合并果子 / 哈夫曼：每次合最小的两堆
long long mergeFruit(vector<long long> w) {
    priority_queue<long long, vector<long long>, greater<long long>> pq(w.begin(), w.end());
    long long cost = 0;
    while (pq.size() > 1) {
        long long a = pq.top(); pq.pop();
        long long b = pq.top(); pq.pop();
        cost += a + b;                                         // 本次代价
        pq.push(a + b);                                        // 新堆回到候选集
    }
    return cost;
}

int main() {
    cout << maxSeg({{1, 4}, {2, 3}, {3, 5}, {4, 6}}) << "\n";  // 2
    cout << mergeFruit({1, 2, 3}) << "\n";                    // 9
    return 0;
}
```

## 五、具体例子

### 1. 区间调度（线段覆盖）

问题：$n$ 条线段 $[l_i,r_i]$，选最多条互不重叠。套形式：最大相容子集，按右端点排序后能接就接。代码 `maxSeg`，复杂度 $O(n\log n)$ 排序 + $O(n)$ 扫描，空间 $O(n)$。为什么对：最优解若首条为 $b$，则 $r_b\ge r_a$，把 $b$ 换成 $a$ 后 $last$ 更小、后面能接的只多不少。

### 2. 合并果子

问题：$n$ 堆果子，每次合并两堆、代价为两堆之和，求最小总代价。套形式：$\min\sum w_i\cdot depth_i$ 等价于「每次合最小的两堆」，堆取两次最小值再 push 回去。代码 `mergeFruit`，复杂度 $O(n\log n)$，空间 $O(n)$。

### 3. 构造：锯齿排列

问题：给定 $n$，输出 $1..n$ 的一个排列，满足 $p_1<p_2>p_3<p_4>\cdots$。先手玩：$n=4$ 写 $1,3,2,4$ 成立；$n=5$ 写 $1,4,2,5,3$ 成立——模式是「小数占奇数位、大数占偶数位」。于是取 $m=\lceil n/2\rceil$，奇数位依次填 $1..m$，偶数位依次填 $m+1..n$。

```cpp
#include <iostream>
#include <vector>
using namespace std;

int main() {
    int n;
    cin >> n;
    int m = (n + 1) / 2;                 // 小数的个数
    vector<int> p(n + 1);
    int lo = 1, hi = m + 1;
    for (int i = 1; i <= n; ++i)
        p[i] = (i % 2 == 1) ? lo++ : hi++;   // 奇位小数、偶位大数
    for (int i = 1; i <= n; ++i) cout << p[i] << " \n"[i == n];
    return 0;
}
```

为什么对：偶数位 $2i$ 的值是 $m+i>m$，而两侧奇数位的值都 $\le m$，故 $p_{2i-1}<p_{2i}>p_{2i+1}$ 恒成立。复杂度 $O(n)$。$n=1$ 时直接输出 1，不用特判也不会崩，但要自己验一遍。

## 六、复杂度与易错点

| 项 | 值 |
|---|---|
| 时间复杂度 | 排序 $O(n\log n)$；堆 $O(n\log n)$；构造 $O(n)$ |
| 空间复杂度 | 排序 $O(n)$；堆 $O(n)$；构造 $O(n)$（可优化到 $O(1)$） |

- 区间调度按左端点排序：$[1,10],[2,3],[3,4]$ 只选出 1，正解是后两条。
- 判据写成 `l > last`，端点相接被误判冲突，答案偏小。
- 合并果子用大根堆，那是代价最大的方案；和忘记 `long long` 直接溢出。
- 偷懒把区间存成 `int`，端点乘 $10^5$ 再相加溢出。
- 构造题只验了 $n$ 是偶数就交，$n=1$ 的输出缺空格或多换行。
- 交换论证只在脑子里过一遍没写成注释，换个题才发现自己一直在猜。
