# 【数论】汉诺塔问题
## 汉诺塔

### 内容：

汉诺塔是一个经典问题，相传在古印度圣庙中，有一种被称为汉诺塔(Hanoi)的游戏。该游戏是在一块铜板装置上，有三根杆(编号A、B、C)，在A杆自下而上、由大到小按顺序放置n个金盘。游戏的目标：把A杆上的金盘全部移到C杆上，并仍保持原有顺序叠好。

操作规则：每次只能移动一个盘子，并且在移动过程中三根杆上都始终保持大盘在下，小盘在上，操作过程中盘子可以置于A、B、C任一杆上。

## 代码1：汉诺塔移动过程

```cpp
Function Hanoi(n,a,b,c)
    if n==1 then
        print(a+'->'+c)
    else
        Hanoi(n-1,a,c,b)
        print(a+'->'+c)
        Hanoi(n-1,b,a,c)
    end if
end Function
```

```cpp
#include <iostream>
using namespace std;
int hanoi( int n, char A, char B, char C){
    if(n == 1){
         cout << A <<"-->" << C << '\n';
    }
    else{
        hanoi( n - 1, A, C, B);
        cout << A <<"-->" << C << '\n';
        hanoi( n - 1, B, A, C);
    }
    return 0;
}

int main(){
    int n;
    char A = 'A',B = 'B',C = 'C';
    
    cin >> n;
    hanoi( n, A, B, C);
}
```
