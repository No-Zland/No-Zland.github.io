# DP 进阶：区间、树形、状压与数位

> 一句话本质：四种进阶 DP 的差别只在"状态长什么样"——区间是端点，树形是子树，状压是集合，数位是前缀。

## 一、是什么

线性 DP 的状态是一条下标；当一条下标记不住全部信息时，就把**一个结构整体**当状态：区间 $[l,r]$、子树 $u$、集合 $mask$、数位前缀。

四类模型做的是同一件事——**状态的形状升级**：不换算法，只换一个能切断历史的坐标轴。

识别信号：

- 合并相邻两堆、消去相邻一段，问最后的最小代价，$n\le500$；首尾相接（围成圈）就复制一倍数组：区间 DP。
- 树上选点或选边，父子之间有互斥关系：树形 DP，$f[u][0/1]$。
- 树上选 $k$ 个点且带容量：树形背包，后序合并子树。
- $n\le20$，且"已选过哪些"会改变后续可选集合：状压 DP。
- 网格 $n,m\le12$ 按行种草、铺砖、放国王：状压逐行转移。
- 问 $[L,R]$ 内满足数位条件的数有几个：数位 DP，`solve(R)-solve(L-1)`。

不该用它的场景：

- 区间 DP 的 $n$ 到 $10^4$：$O(n^3)$ 过不去，$O(n^2)$ 只对特定代价成立。
- 状压的 $n$ 到 $25$ 以上：$2^n\cdot n$ 已经超时，考虑 meet-in-the-middle。
- 树形 DP 在深度 $10^5$ 的链上递归：不是算法错，是栈错，要么手工栈要么改迭代。
- 数位条件依赖整数的值（如整除大质数）：状态会爆炸，得换同余手段。

## 二、形式

**数学形式。** 四行状态定义，四行转移：

$$f[l][r]=\min_{l\le k<r}\bigl(f[l][k]+f[k+1][r]\bigr)+w(l,r)$$

$$f[u][0]=\sum_{v\in son(u)}\max(f[v][0],f[v][1]),\qquad f[u][1]=val_u+\sum_{v\in son(u)}f[v][0]$$

$$f[i][s]=\sum_{t\ \text{合法}} f[i-1][t],\quad s,t\ \text{为行内选择的二进制掩码}$$

$$dfs(pos,pre,limit,lead)=\sum_{d} dfs(pos-1,d,limit\wedge d=up,lead\wedge d=0)$$

**代码形式。** 骨架仍是"阶段 → 状态 → 决策"，只是阶段换了含义：区间是**长度**，树形是**后序**，状压是**行号**，数位是**位数**。

**数据形式。** 区间 $O(n^2)$ 的二维表；树形每个点两个值；状压是 $f[行数][2^m]$；数位是 `memo[位数][状态]`。注意树形与状压的值常需 `long long`，$10^{12}$ 级别不是 `int` 能装的。

## 三、怎么理解

**直觉。** 区间 DP 在"最后一次合并"上分治：任何一段最终都由两段拼成，枚举拼接点就够。树形 DP 靠"子树互不干扰"，儿子只通过父亲互相影响。状压"把集合当数字"，第 $i$ 位为 1 表示已用。数位"高位决定低位"：某一位一旦小于上界，后面就自由了。

**为什么正确。** 四种都对"规模"归纳：区间按长度，子区间都更短，先算短的；树形按子树大小，DFS 后序保证儿子先算完；状压按 `popcount`，转移只加位，规模严格增；数位按剩余位数，`limit` 为真时答案依赖"上界具体是什么"，这段分支**不能写进记忆数组**，否则不同询问互相污染；`limit` 为假时后面完全自由，只与 `(pos, pre, lead)` 有关，才能复用。

**手推 1：环形石子合并。** 数组 $[4,5,9,4]$，代价是区间和。

- 链式最优：先并 $4+5=9$（代价 9），再并 $9+4=13$（代价 13），最后 $9+13=22$（代价 22），总 $44$。若先并 $5+9=14$ 再并 $4+14=18$，总共 $54$。
- 断环成链后有了新选择：把首尾两个 $4$ 先并（代价 $8$），再并 $8+5=13$、$13+9=22$，总代价降到 $43$。

所以"复制一倍 + 取所有长度 $n$ 的区间的最小值"不是技巧，是让 $[4,5,9,4]$ 的尾部 $4$ 能与头部 $4$ 相邻。

**手推 2：windy 数。** 要求相邻两位差的绝对值 $\ge2$，求 $[1,10]$ 内个数。$1\ldots9$ 都是单个数字，无相邻位可比，全算，共 9 个；$10$ 有 $|1-0|=1<2$，不算。故 `solve(10)=9`。

## 四、怎么变成代码

**映射。**

- 区间：`f[l][r]`，外层 `len` 从 2 到 $n$，内层 `l`，决策 `k` 取 `l..r-1`（`k` 取到 `r` 会让 `f[k+1][r]` 变成空区间）。
- 树形：建双向边，DFS 判父亲；先递归儿子，再合并。
- 状压：先把"行内合法 mask"筛出来（`s & (s << 1)` 为 0），再把"本行不能种的位置"压成 `barren[i]`。
- 数位：`dig` 低位在前、从 `len` 往下搜；`memo` 只在 `!limit && !lead` 时写。

```cpp
#include <iostream>
#include <vector>
#include <algorithm>

const long long INF = 1e18;

// 石子合并（链式）：f[l][r] 为把 a[l..r] 并成一堆的最小代价，代价为区间和
long long intervalDP(const std::vector<long long>& a) {
    int n = (int)a.size() - 1;                       // a 从下标 1 开始
    std::vector<long long> pre(n + 1, 0);
    for (int i = 1; i <= n; ++i) pre[i] = pre[i - 1] + a[i];
    std::vector<std::vector<long long>> f(n + 1, std::vector<long long>(n + 1, INF));
    for (int i = 1; i <= n; ++i) f[i][i] = 0;        // 单堆无需合并
    for (int len = 2; len <= n; ++len)               // 阶段：长度，必须由小到大
        for (int l = 1; l + len - 1 <= n; ++l) {
            int r = l + len - 1;
            for (int k = l; k < r; ++k)              // 决策：断点，k < r
                f[l][r] = std::min(f[l][r], f[l][k] + f[k + 1][r]);
            f[l][r] += pre[r] - pre[l - 1];          // 本次合并的代价
        }
    return f[1][n];
}

int main() {
    int n;
    std::cin >> n;
    std::vector<long long> a(n + 1);
    for (int i = 1; i <= n; ++i) std::cin >> a[i];
    std::cout << intervalDP(a) << '\n';
    return 0;
}
```

## 五、具体例子

**1. 区间 DP：环形石子合并（P1880）。**

问题：$n$ 堆石子围成圈，每次只能合并相邻两堆，代价为两堆之和，求合并成一堆的最小总代价。

形式：$f[l][r]=\min_k(f[l][k]+f[k+1][r])+\text{sum}(l,r)$，数组复制一倍，答案 $=\min_{1\le i\le n} f[i][i+n-1]$。

```cpp
#include <iostream>
#include <vector>
#include <algorithm>
using namespace std;

const long long INF = 1e18;

int main() {
    int n;
    cin >> n;
    vector<long long> a(2 * n + 1), pre(2 * n + 1, 0);
    for (int i = 1; i <= n; ++i) { cin >> a[i]; a[i + n] = a[i]; }  // 断环成链
    for (int i = 1; i <= 2 * n; ++i) pre[i] = pre[i - 1] + a[i];

    vector<vector<long long>> f(2 * n + 1, vector<long long>(2 * n + 1, INF));
    for (int i = 1; i <= 2 * n; ++i) f[i][i] = 0;

    for (int len = 2; len <= n; ++len)                 // 只算到长度 n
        for (int l = 1; l + len - 1 <= 2 * n; ++l) {
            int r = l + len - 1;
            for (int k = l; k < r; ++k)
                f[l][r] = min(f[l][r], f[l][k] + f[k + 1][r] + pre[r] - pre[l - 1]);
        }

    long long ans = INF;
    for (int i = 1; i <= n; ++i) ans = min(ans, f[i][i + n - 1]);
    cout << ans << '\n';                                // [4,5,9,4] → 43
    return 0;
}
```

复杂度：$O(n^3)$ 时间、$O(n^2)$ 空间（复制后规模 $2n$，常数乘 4）。

**2. 树形 DP：没有上司的舞会（P1352）。**

问题：$n$ 个点的树，每个点有权值，父子不能同时选，求最大权值和。

形式：$f[u][0]$ 表示 $u$ 不选、$f[u][1]$ 表示 $u$ 选；转移如上式，后序 DFS。

```cpp
#include <iostream>
#include <vector>
#include <algorithm>

int n;
std::vector<long long> val;
std::vector<std::vector<int>> g;
std::vector<std::vector<long long>> f;   // f[u][0] 不来，f[u][1] 来

void dfs(int u, int fa) {
    f[u][0] = 0;
    f[u][1] = val[u];                              // u 来，先拿自己的快乐值
    for (int v : g[u]) {
        if (v == fa) continue;                     // 双向边，跳过父亲
        dfs(v, u);
        f[u][0] += std::max(f[v][0], f[v][1]);     // u 不来，下属随意
        f[u][1] += f[v][0];                        // u 来，下属都不能来
    }
}

int main() {
    std::cin >> n;
    val.assign(n + 1, 0);
    g.assign(n + 1, std::vector<int>());
    f.assign(n + 1, std::vector<long long>(2, 0));
    for (int i = 1; i <= n; ++i) std::cin >> val[i];
    std::vector<int> indeg(n + 1, 0);
    for (int i = 1; i < n; ++i) {
        int u, v;
        std::cin >> u >> v;                        // u 是 v 的上司
        g[u].push_back(v);
        g[v].push_back(u);
        ++indeg[v];
    }
    int root = 1;
    for (int i = 1; i <= n; ++i)
        if (indeg[i] == 0) { root = i; break; }    // 入度为 0 的是根
    dfs(root, 0);
    std::cout << std::max(f[root][0], f[root][1]) << '\n';
    return 0;
}
```

复杂度：$O(n)$ 时间、$O(n)$ 空间；加一维容量即树形背包，$O(nV)$。

**3. 状压 DP：玉米田（P1879）。**

问题：$n\times m$ 网格，1 可种、0 贫瘠，相邻格子不能同时种，求方案数 $\bmod 10^8$。

形式：$f[i][s]$ 表示第 $i$ 行种成掩码 $s$ 的方案数，转移要求 $s$ 行内无相邻 1、$s$ 与 `barren[i]` 不交、$s$ 与上一行掩码不交。

```cpp
#include <iostream>
#include <vector>

const long long MOD = 100000000;                 // P1879 要求的模数

int main() {
    int n, m;
    std::cin >> n >> m;
    std::vector<int> barren(n, 0);                // 贫瘠位置为 1
    for (int i = 0; i < n; ++i)
        for (int j = 0; j < m; ++j) {
            int x; std::cin >> x;
            if (x == 0) barren[i] |= 1 << j;
        }

    int S = 1 << m;
    std::vector<std::vector<long long>> f(n, std::vector<long long>(S, 0));
    for (int s = 0; s < S; ++s)                   // 第一行
        if ((s & (s << 1)) == 0 && (s & barren[0]) == 0) f[0][s] = 1;

    for (int i = 1; i < n; ++i)
        for (int s = 0; s < S; ++s) {
            if (s & (s << 1)) continue;           // 行内相邻两格都种了
            if (s & barren[i]) continue;          // 种在贫瘠土地上
            for (int t = 0; t < S; ++t) {
                if (t & (t << 1)) continue;
                if (t & barren[i - 1]) continue;
                if (s & t) continue;              // 上下同列冲突
                f[i][s] = (f[i][s] + f[i - 1][t]) % MOD;
            }
        }

    long long ans = 0;
    for (int s = 0; s < S; ++s) ans = (ans + f[n - 1][s]) % MOD;
    std::cout << ans << '\n';
    return 0;
}
```

复杂度：$O(n\cdot 4^m)$ 朴素，筛掉不合法 mask 后远小于上界；空间 $O(n\cdot 2^m)$。$m\le12$ 才可行。

**4. 数位 DP：windy 数（P2657）。**

问题：求 $[L,R]$ 中相邻两位差的绝对值 $\ge2$ 的数的个数（不含前导 0）。

形式：`dfs(pos, pre, limit, lead)`，`pos` 是剩余位数，`pre` 是上一位数字，`limit` 是是否顶住上界，`lead` 是是否仍在前导 0 中。

```cpp
#include <iostream>
#include <cstring>
#include <cstdlib>

int dig[20];
long long memo[20][10];      // memo[pos][pre]：剩 pos 位、上一位是 pre 的答案

long long dfs(int pos, int pre, bool limit, bool lead) {
    if (pos == 0) return lead ? 0 : 1;                    // 全 0 不算一个数
    if (!limit && !lead && memo[pos][pre] != -1) return memo[pos][pre];
    int up = limit ? dig[pos] : 9;                        // 顶住上界就只能填到这一位
    long long res = 0;
    for (int d = 0; d <= up; ++d) {
        if (!lead && std::abs(d - pre) < 2) continue;      // 相邻两位差不足 2
        res += dfs(pos - 1, d, limit && d == up, lead && d == 0);
    }
    if (!limit && !lead) memo[pos][pre] = res;            // 顶住上界的分支不能复用
    return res;
}

long long solve(long long x) {
    if (x <= 0) return 0;
    int len = 0;
    while (x > 0) { dig[++len] = (int)(x % 10); x /= 10; }  // 低位在前
    std::memset(memo, -1, sizeof memo);
    return dfs(len, 0, true, true);
}

int main() {
    long long l, r;
    std::cin >> l >> r;
    std::cout << solve(r) - solve(l - 1) << '\n';
    return 0;
}
```

复杂度：$O(\text{位数}\times 10\times 10)$ 每询问，空间 $O(\text{位数}\times 10)$。

## 六、复杂度与易错点

| 模型 | 时间 | 空间 |
|---|---|---|
| 区间 DP | $O(n^3)$，可优化到 $O(n^2)$ | $O(n^2)$ |
| 树形 DP | $O(n)$；带容量 $O(nV)$ | $O(nV)$ |
| 状压 DP | $O(n\cdot 2^m\cdot 2^m)$ | $O(n\cdot 2^m)$ |
| 数位 DP | $O(\text{位数}\times S\times 10)$ | $O(\text{位数}\times S)$ |

- 区间 DP 按左端点递增枚举：子区间还没算，读到 INF，答案随数据随机偏大。
- 区间 DP 初值全 0 求最小值：所有区间都变 0；应只置 `f[i][i]=0`，其余 INF。
- 断点写成 `k <= r`：`f[r+1][r]` 越界。
- 树形 DP 只建单向边，或建了双向边却忘判父亲：直接死循环。
- 状压数组开 `1 << n` 少一位，$n=20$ 时下标 $2^{20}$ 恰好越界。
- 数位 DP 在 `limit` 为真时也写 `memo`：多组询问互相污染，答案偏小。
