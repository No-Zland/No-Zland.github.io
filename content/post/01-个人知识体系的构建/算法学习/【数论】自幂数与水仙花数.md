# 【数论】自幂数之水仙花数

## 自幂数

### 定义： 

一个 **n位数**，每个数位上的数字的 **n次幂之和**。

每个位数的自幂数有自己的名字。最大的自幂数有39位，十进制自然数中共有88个。编程中通常使用 **遍历** 来实现。

## 水仙花数（Narcissistic number）

水仙花数，又称超完全数字不变数（PPDI）、自恋数、自幂数、阿姆斯特朗数（Armstrong number）。

**定义：** 是**三位数**的自幂数。共有四个：153、370、371、407。

## 代码
```cpp
#include <bits/stdc++.h>
using namespace std;
bool is_flw(int flw){
	int n = 0;
	int tem = flw;
	// 计算数位
	while(tem){
		n ++;
		tem /= 10;
	}
	
	tem = flw;
	long long sum = 0;
	// 计算各个数位之和
	while(tem){
		sum += pow(tem % 10, n); 
		tem /= 10;
	}
	
	// 判断是否自幂数
	if(sum == flw){
		return true;
	}
	return false;
}

int main(){
    int n;
    cin >> n;
    // 输入n次
    while(n --){
       int flw;
	   cin >> flw;
	   printf(is_flw(flw) ? "yes\n" : "no\n");
    }
}
```

## 优化
下面这些优化本质上是 **拿空间换时间**。
### 1. 查表法

计算数位可以使用查表法，缩减复杂度
```cpp
int digit(int x){
	// 快速求位数（分支预测友好）
    if(x < 10) return 1;
    if(x < 100) return 2;
    if(x < 1000) return 3;
    if(x < 10000) return 4;
    if(x < 100000) return 5;
    if(x < 1000000) return 6;
    if(x < 10000000) return 7;
    if(x < 100000000) return 8;
    if(x < 1000000000) return 9;
    return 10;
}
```


### 2. 用整数幂代替pow函数

pow 返回 double 有精度误差，可以使用整数幂。
pow(5, 3) 等可能在浮点里返回 124.99999...，被截断成 124，导致误判。虽然对常见自幂数恰好没事，但属于埋雷。
```cpp
long long pw[10][11];          // pw[d][k] = d^k
void init(){
    for(int d = 0; d < 10; d++){
        pw[d][0] = 1;
        for(int k = 1; k <= 10; k++)
            pw[d][k] = pw[d][k-1] * d;
    }
}
```

// 快速读入（手写 getchar_unlocked 或 fread 缓冲）
inline int readInt(){
    int x = 0, c;
    do c = getchar_unlocked(); while(c < '0' || c > '9');
    while(c >= '0' && c <= '9'){ x = x*10 + (c-'0'); c = getchar_unlocked(); }

}
