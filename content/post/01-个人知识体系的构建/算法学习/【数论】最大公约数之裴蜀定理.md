# 【数论】最大公约数之裴蜀定理

## 裴蜀定理（Bézout's Lemma）

裴蜀定理，又称贝祖定理，是数论中关于 **最大公约数** 的重要定理，由法国数学家艾蒂安·裴蜀提出。

### 内容： 

若**整数 $a、b$** 的最大公约数为 $d$，则存在整数 $x、y$ 使得 **线性不定方程 $ax+by=d$** 成立，特别地，**a 与 b互质**当且仅当存在 $x、y$ 满足 $ax + by = 1$。

### 推广： 

多个整数的情形，即对 **n个整数a₁,a₂,…,aₙ**，存在整数 **x₁,x₂,…,xₙ** 使得 **x₁a₁ + x₂a₂ + … + xₙaₙ** 等于它们的最大公约数。该定理还可扩展至主理想环上的情形.

## 代码1：小红走网格，直接调用gcd函数

```cpp
#include <numeric>
using namespace std;
using ll = long long;
 
int main() {
    int T;
    cin >> T;
    while (T --) {
        ll x, y, a, b, c, d; // x，y要到达的坐标；abcd四个方向移动一次的步数
        cin >> x >> y >> a >> b >> c >> d;
        // 利用裴蜀定理判定是否是倍数关系
        bool y_psb = (y % gcd(a, b) == 0);
        bool x_psb = (x % gcd(c, d) == 0);
        // 
        cout << (x_psb && y_psb ? "YES" : "NO") << endl;
    }
}
```
