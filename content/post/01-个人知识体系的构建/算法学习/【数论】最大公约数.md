# 【数论】最大公约数（GCD）
## 最大公约数（Greatest Common Divisor, GCD）

### 严谨定义：

设 $a$ 和 $b$ 为两个**不全为零**的整数（即 $a^2 + b^2 \neq 0$）。

若存在一个**正整数 d**，能够**同时满足**以下两个严格的数理逻辑条件，则称 $d$ 为 $a$ 和 $b$ 的最大公约数：

1. 公因子条件 (Common Divisor Condition)

$d$ 必须是 $a$ 和 $b$ 的**公共因子**。即 $d$ 能够整除 $a$，同时也能够整除 $b$。

*   **数学符号表示**：记作 $d|a$ 且 $d|b$。
*   **等价含义**：这意味着存在整数 $k_1, k_2$，使得 $a = k_1d$ 且 $b = k_2d$。

2. 最大性条件 (Maximality Condition)

$d$ 必须是所有公因子中**数值最大**的一个。

*   **具体表述为**：对于任何其他的正整数 $c$，如果 $c$ 也能同时整除 $a$ 和 $b$（即 $c|a$ 且 $c|b$），那么必然有 **$c \le d$**。
*   **意义**：这一条件确立了最大公约数的**唯一性**。

---
*注：通常将其记作 $d = \gcd(a, b)$。*

### 影响：

最大公约数，不仅是 **初等数论** 中描述 **整数因子关系** 的核心概念，更是连接算术基本定理与现代代数结构的桥梁。

在理论层面，最大公约数是**理解同余理论、模运算以及环论中理想性质**的关键；在应用层面，它构成了现代**非对称加密技术（如 RSA 算法）**、编码理论以及数字信号处理的数学基石 。

古希腊欧几里得在《几何原本》中提出的 **辗转相除法**，到中国古代《九章算术》中记载的**更相减损术**。

## 代码1：辗转相除法求最大公约数

基于数学定理：$$gcd(a, b) = gcd(b, a \space mod \space b)$$即：两个数的最大公约数，等于其中较小的数和两数相除余数的最大公约数。通过不断用除数替换被除数，用余数替换除数，数值会迅速减小，直到余数为0。此时的除数即为所求结果。
### 1. 迭代

```cpp
ll gcd(ll a, ll b) {
	// 辗转相除法
    while (b) { 
	    ll t = a % b; 
	    a = b; 
	    b = t; 
    }
    return a;
}
```
### 复杂度分析

• 时间复杂度：$O(log \space min(a, b))$。因为余数至少减半（拉梅定理），所以递归深度是对数级。
• 空间复杂度：$O(log \space 1)$。
递归版在 `-O2` 下通常会被**编译器优化**成尾递归/循环，性能差不多，但迭代版更保险（不用担心极端情况栈溢出，虽然对数级基本不会）。

### 2. 递归

```cpp
ll gcd(ll a, ll b) {
    return b == 0 ? a : gcd(b, a % b);
}
```

### 复杂度分析
• 时间复杂度：$O(log \space min(a, b))$。因为余数至少减半（拉梅定理），所以递归深度是对数级。
• 空间复杂度：$O(log \space min(a, b))$（递归栈）。
最坏情况是斐波那契数列相邻两项，例如 $gcd(F(n), F(n-1))$，需要递归 n 层。

### 代码2：二进制 GCD（Stein 算法）

当 `a, b` 是**大整数**时，`a % b` 代价高；Stein 算法只用移位和减法，常数更低：

```cpp
ll gcd(ll a, ll b) {
    if (!a) return b;
    if (!b) return a;
    int sh = __builtin_ctzll(a | b);  // 公共因子 2 的个数
    a >>= __builtin_ctzll(a);
    do {
        b >>= __builtin_ctzll(b);
        if (a > b) swap(a, b);
        b -= a;
    } while (b);
    return a << sh;
}
```
