# 组合计数与博弈论

> 一句话本质：计数是"建立一一对应"，博弈是"给必败态一个可算的刻画"；两者都先把问题压缩成一个数，再证明这个数够用。

## 一、是什么

**组合计数**统计满足约束的离散对象有多少个，输出一个整数（常对质数取模）。**组合博弈**研究这样一类游戏：双方可用操作完全相同、无随机、轮流行动、不能行动者负，判定在最优策略下谁赢、第一步怎么走。

它们解决同一类问题的两端：前者数"有多少种"，后者判"哪种局面必输"。

识别信号：

- 题面出现"有多少种方案""对 $10^9+7$ 取模"，且答案只与 $n,k$ 有关：阶乘 + 逆元预处理，别写 DP。
- 出现"至少一个""不存在""两两不同"这类否定式限定：容斥，总数减不合法。
- 方程 $x_1+x_2+\cdots+x_k=n$，或"$n$ 个相同的球放进 $k$ 个盒子"：隔板法。
- 轮流从若干堆里取、各堆互不影响、不能取者输：Nim，看异或和。
- 棋子在 DAG 上走、问先手胜负：SG 函数做 mex。
- $n\ge 10^9$ 而模数 $p\le 10^5$：Lucas 定理。

不该用它的场景：

- 约束带**位置依赖**（相邻不能相等、每个位置有各自上限），组合数公式写不出来——那是 DP。
- 要输出方案本身或按字典序枚举，计数的封闭形式帮不上，转搜索与构造。
- 游戏存在平局、可循环、或双方操作集不同，Nim 与 SG 的结论直接失效。
- 对象连续（实数区间上取值），"个数"没有意义。

## 二、形式

**数学形式。** 计数只有两条公理：互斥则相加，分步则相乘。由此派生出两个常用式：

- 容斥：$|A\cup B|=|A|+|B|-|A\cap B|$，三项以上"加奇减偶"。
- 隔板法：$x_1+\cdots+x_k=n$ 的非负整数解有 $\binom{n+k-1}{k-1}$ 个，正整数解有 $\binom{n-1}{k-1}$ 个。

取模下的组合数必须把除法换成乘逆元（$p$ 为质数）：

$$\binom{n}{m}\equiv fact[n]\cdot invfact[m]\cdot invfact[n-m]\pmod p,\qquad invfact[i-1]=invfact[i]\cdot i$$

博弈的结论是一行：设 $s=a_1\oplus a_2\oplus\cdots\oplus a_n$，则 $s\ne 0$ 先手必胜，$s=0$ 先手必败。

**代码形式。** 预处理一次、查询 $O(1)$，骨架就三步：顺着填 $fact$、用费马小定理求 $invfact[n]$、倒着推回 $invfact[0]$。博弈更省：一次遍历累异或，连局面都不用存。

**数据形式。** 组合数只要两个长度 $n+1$ 的数组，下标就是参数；Nim 只要一个 `int`。这里值得记一笔——博弈的状态空间可以大到 $10^{18}$，但胜负被压缩成一个整数，这就是"找到不变量"的收益。

## 三、怎么理解

**直觉。** 计数不是"一个一个数"，是"换一批好数的对象"。方程解换成插板方案，合法括号换成不越界路径，都是把一个难数的集合搬到另一个等势、易数的集合上。

**为什么正确。** 隔板法靠双射：$d$ 个 1 排成一行，把 $k-1$ 块板插进 $d+1$ 个空档（允许同档，对应变量取 0），第 $i$ 段 1 的个数就是 $x_i$；反过来任一组解也唯一确定插法，双向可逆，故个数相等。组合数取逆元则依赖：$p$ 是质数且 $n<p$ 时 $m!$ 与 $(n-m)!$ 都不含因子 $p$，故与 $p$ 互质，费马小定理保证逆元存在，除法才合法。

Nim 的证明是两个引理。① 若 $s\ne0$，取 $s$ 的最高位 $k$，必有一堆 $a_i$ 的第 $k$ 位是 1，令 $a_i'=a_i\oplus s$，则 $a_i'<a_i$（高位被消掉），是合法取法，且新异或和为 $s\oplus a_i\oplus a_i'=0$。② 若 $s=0$，任何操作只改一堆且必然变小，新的异或和必不为 0。终局全 0 属于 $s=0$，于是"非 0 能一步到 0、0 只能到非 0"，归纳即得胜负。

**手推。** 先算 $a+b+c=3$：$d=3$ 个 1 加 2 块板共 5 个位置，选 2 个放板，$\binom{5}{2}=10$。枚举核对：$(3,0,0)$ 三种排列，$(2,1,0)$ 六种，$(1,1,1)$ 一种，共 $3+6+1=10$。✓

再算 Nim 三堆 $3,4,5$：$3\oplus4=7$，$7\oplus5=2\ne0$，先手胜。第一步取第 1 堆：$3\oplus2=1<3$，取走 $3-1=2$ 个，局面变 $1,4,5$，而 $1\oplus4\oplus5=0$——把必败态交给对手。

## 四、怎么变成代码

**映射。**

- 变量：`n` 是参数上界，`fact[i]=i!`，`invfact[i]=(i!)^{-1}`，模数 `MOD` 必须是**质数**。
- 循环顺序：`fact` 正序；`invfact` 必须先算顶端再倒序，因为 $invfact[i-1]$ 依赖 $invfact[i]$，顺序反了全是 0。
- 边界：`fact[0]=1`；`C(n,m)` 里 $m<0$ 或 $m>n$ 返回 0；数组按最大 $n$ 再留 5 位余量。

```cpp
#include <iostream>
#include <vector>

const long long MOD = 1000000007LL;   // 必须为质数
const int MAXN = 1000006;

long long fact[MAXN], invfact[MAXN];

long long qpow(long long a, long long b) {          // 快速幂，用来求逆元
    long long r = 1 % MOD;
    for (a %= MOD; b > 0; b >>= 1, a = a * a % MOD)
        if (b & 1) r = r * a % MOD;
    return r;
}

void initComb(int n) {
    fact[0] = 1;
    for (int i = 1; i <= n; ++i) fact[i] = fact[i - 1] * i % MOD;
    invfact[n] = qpow(fact[n], MOD - 2);            // 费马小定理求 (n!)^-1
    for (int i = n; i >= 1; --i)                     // 倒推：invfact[i-1] 依赖 invfact[i]
        invfact[i - 1] = invfact[i] * i % MOD;
}

long long C(int n, int m) {                          // 要求 0 <= m <= n < MOD
    if (m < 0 || m > n) return 0;
    return fact[n] * invfact[m] % MOD * invfact[n - m] % MOD;
}

int main() {
    initComb(MAXN - 1);
    long long d;
    std::cin >> d;
    std::cout << C((int)(d + 2), 2) << '\n';         // a+b+c=d 的非负解数
    return 0;
}
```

## 五、具体例子

**1. 隔板法：$a+b+c=d$ 的非负解数。**

问题：给定 $d$，数三元组 $(a,b,c)$ 满足 $a,b,c\ge0$ 且 $a+b+c=d$。

形式：$d$ 个 1 与 2 块隔板排成一排，共 $d+2$ 个位置，选出 2 个位置放板，两个板把 1 分成三段，段长即 $(a,b,c)$。故答案为 $\binom{d+2}{2}=\frac{(d+1)(d+2)}{2}$。

```cpp
#include <iostream>
using namespace std;

long long starsBars(long long d) {              // C(d+2, 2)，这里 d 不大，直接算
    return (d + 1) * (d + 2) / 2;
}

int main() {
    for (long long d = 0; d <= 20; ++d) {
        long long brute = 0;                     // 暴力：枚举 a、b，c 被唯一确定
        for (long long a = 0; a <= d; ++a)
            for (long long b = 0; a + b <= d; ++b) ++brute;
        cout << d << " 公式 " << starsBars(d) << " 暴力 " << brute << '\n';
    }
    return 0;
}
```

复杂度：$O(1)$ 出答案，暴力对拍 $O(d^2)$。注意区分：若要求**正整数**解，是 $\binom{d-1}{2}$；"盒子可空"与"不可空"混用是最常见的错。

**2. 组合数预处理：$O(n)$ 建表、$O(1)$ 查询。**

问题：$q$ 次询问 $\binom{n}{m}\bmod p$，$n\le 10^6$。

形式：$\binom{n}{m}=fact[n]\cdot invfact[m]\cdot invfact[n-m]$，查询时三次乘法。

```cpp
#include <iostream>
#include <vector>
using namespace std;

const long long MOD = 1000000007LL;

long long qpow(long long a, long long b) {
    long long r = 1;
    for (a %= MOD; b > 0; b >>= 1, a = a * a % MOD)
        if (b & 1) r = r * a % MOD;
    return r;
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int nmax, q;
    cin >> nmax >> q;
    vector<long long> fact(nmax + 1, 1), invfact(nmax + 1, 1);
    for (int i = 1; i <= nmax; ++i) fact[i] = fact[i - 1] * i % MOD;
    invfact[nmax] = qpow(fact[nmax], MOD - 2);
    for (int i = nmax; i >= 1; --i) invfact[i - 1] = invfact[i] * i % MOD;

    while (q--) {
        int n, m;
        cin >> n >> m;
        if (m < 0 || m > n) { cout << 0 << '\n'; continue; }
        cout << fact[n] * invfact[m] % MOD * invfact[n - m] % MOD << '\n';
    }
    return 0;
}
```

复杂度：建表 $O(n)$，每次查询 $O(1)$，空间 $O(n)$。$n\ge p$ 时 $fact[n]\equiv0$，必须改用 Lucas 逐位拆。

**3. Nim：异或和为 0 必败。**

问题：$n$ 堆石子，每次从一堆取任意正数，取完者胜，判先手胜负并给第一步。

形式：$s=\bigoplus a_i$；$s=0$ 输出必败，否则找最小的 $i$ 使 $a_i\oplus s<a_i$，取走 $a_i-(a_i\oplus s)$ 个。

```cpp
#include <iostream>
#include <vector>
using namespace std;

int main() {
    int n;
    cin >> n;
    vector<int> a(n);
    int s = 0;
    for (int i = 0; i < n; ++i) { cin >> a[i]; s ^= a[i]; }
    if (s == 0) { cout << "lose\n"; return 0; }     // 异或和为 0：先手必败
    cout << "win\n";
    for (int i = 0; i < n; ++i) {
        int t = a[i] ^ s;                            // 目标堆大小
        if (t < a[i]) {                              // 必须变小才是合法取法
            cout << "pile " << i + 1 << " take " << a[i] - t << '\n';
            break;
        }
    }
    return 0;
}
```

复杂度：$O(n)$，空间 $O(n)$（其实可以边读边异或，$O(1)$）。

## 六、复杂度与易错点

| 项 | 值 |
|---|---|
| 组合数预处理 | $O(n)$ 建表，$O(1)$/次查询 |
| Lucas 单次 | $O(\log_p n)$ |
| 隔板法 / 卡特兰数 | $O(1)$ 或 $O(n)$ 递推 |
| Nim 判定 | $O(n)$ 时间，$O(1)$ 空间 |
| 空间 | 组合数 $O(n)$；博弈 $O(1)$ |

- 隔板法混淆"可空 / 不可空"：$\binom{n+k-1}{k-1}$ 与 $\binom{n-1}{k-1}$ 用反，样例能过、边界全错。
- `invfact` 正序推：$invfact[i-1]$ 必须在 $invfact[i]$ 之后算，顺序反了只剩 0 和 1。
- $n\ge p$ 仍用阶乘查表：结果恒为 0，必须走 Lucas；$p$ 不是质数时费马小定理也不成立。
- 卡特兰数 $\frac{1}{n+1}\binom{2n}{n}$ 先整除再取模：模意义下整除不成立，要乘 $n+1$ 的逆元。
- Nim 判的是异或和是否为 0，不是"最大值是否为 0"；输出方案时把条件写成 `t <= a[i]` 会给出"取 0 个"的非法操作。
- SG 的 mex 从 0 开始枚举；多个子游戏是**异或**不是相加。
