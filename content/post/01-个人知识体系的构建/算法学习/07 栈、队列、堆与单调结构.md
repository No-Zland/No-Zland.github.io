# 栈、队列、堆与单调结构

> 一句话本质：栈记住「最近未解决的事」，队列记住「按时间到期的事」，堆只维护「谁最该先出场」；单调结构把「谁还有资格留在场上」写成了容器的不变量。

## 一、是什么

栈只能一端进出（LIFO），队列两端进出（FIFO），堆是满足偏序的完全二叉树：只保证堆顶是极值，增删 $O(\log n)$，其余无序。

单调栈、单调队列**不是新容器**，而是给栈 / 队列加一条不变量：容器内元素保持单调，入队时顺手弹掉「永远不会再成为答案」的元素，用 $O(n)$ 扫描代替 $O(n^2)$ 枚举。

解决的问题：嵌套配对、左右第一个更大 / 更小、定长窗口最值、动态最值 / 中位数。

识别信号：

- 出现「括号」「合法序列」「嵌套」「能否配对」「消去」；
- 中缀 / 后缀表达式求值，或按优先级结合；
- 「左右第一个比它大（小）的数」「柱状图最大矩形」「接雨水」；
- 「长度 $k$ 的窗口最大值」「数据流中位数」「随时取最大」；
- $n\ge10^5$ 必须 $O(n)$ 或 $O(n\log n)$，暴力 $O(n^2)$ 会 T；只要维护极值又要支持插入，就是堆。

不该用它的时候：

- 要任意位置删除、查前驱后继：用 `multiset`，堆只能靠懒惰删除近似；
- 要区间任意查询或带修改：线段树、树状数组、ST 表；
- 「第一个满足与大小无关的谓词 $P$」：单调剪枝不成立，栈会弹错；要第 $k$ 小且 $k$ 很大，堆得弹 $k$ 次。

## 二、形式

**数学形式.** 栈的不变量是「抵消后的规范形」：扫描到 $i$ 时栈里是前缀中尚未抵消的元素；括号匹配中只剩左括号，且前缀可补全为合法串。

单调栈（右侧第一个严格更大）：栈内下标 $i_1<i_2<\dots<i_k$ 满足

$$a_{i_1} > a_{i_2} > \dots > a_{i_k},$$

且 $i_t$ 是 $i_{t+1}$ 左边第一个更大者，故 $i_{t+1}$ 被弹出时答案就是 $i_t$。

单调队列：下标递增、值递减，队头即窗口最大值；右端到 $i$ 时队头过期的条件是 $\text{front}\le i-k$。

堆：小根堆满足 $h_i\le h_{2i},h_{2i+1}$，故 $h_1=\min$，但兄弟无序——这正是堆不能二分的原因。

**代码形式.**

```cpp
#include <vector>
#include <queue>
using namespace std;

vector<int> nextGreater(const vector<int>& a);       // 右侧第一个更大
vector<int> windowMax(const vector<int>& a, int k);  // 窗口最大值
struct Median { void add(int); double get() const; };// 对顶堆
```

**数据形式.** 单调栈 / 队列**存下标不存值**：答案要的是位置（距离、宽度、过期），值用 `a[idx]` 取。单调队列常写成数组 + `head/tail`，比 `deque` 快近一倍。

## 三、怎么理解

**直觉.** 栈像叠盘子；括号匹配里栈顶就是「最近一个还没配对的左括号」。单调栈像排队看身高：后面来了更高的人，前面那些矮的永远不可能是答案，可以请出场——**被弹出的一刻答案就确定了**。

**为什么单调栈正确.** 设 $i$ 把 $j$ 弹出：$a_i>a_j$，且 $j$ 与 $i$ 之间仍在栈中的元素都 $\le a_j$（否则 $j$ 早被弹走）。故 $i$ 就是答案。每个下标进出各一次，总代价 $O(n)$。

**为什么单调队列三步不能换序.** 顺序是：队头过期 → 队尾弹劣 → 入队。若先弹劣，「已过期但值很大」的队头不会因「劣」被弹掉，会继续被当成窗口最大值输出。

**手推.** $a=\{2,1,4,3\}$，求每个位置右侧第一个更大：

| $i$ | $a_i$ | 弹栈并记答案 | 栈（底→顶） |
|---|---|---|---|
| 0 | 2 | — | [0] |
| 1 | 1 | — | [0,1] |
| 2 | 4 | 弹 1、0，`res[1]=res[0]=2` | [2] |
| 3 | 3 | — | [2,3] |

收尾时栈内下标无解：`res[2]=res[3]=-1`；核对无误。

## 四、怎么变成代码

映射：

- 栈存**下标**，答案数组初值 `-1`。
- 单调栈（从左往右）：先 `while` 弹掉「比当前小」的栈顶，**每弹一次就填一次答案**，再 `push(i)`。
- 比较符：`<` 是「严格更大」，`<=` 是「大于等于」；差一个等号答案就不同。
- 单调队列四步固定顺序：① 队头过期 `front <= i-k` 就 `++head`；② 队尾弹劣 `a[back] <= a[i]` 就 `--tail`；③ 入队；④ `i >= k-1` 才输出 `a[head]`。
- 堆：`priority_queue` 默认大根，小根写 `greater<int>`；对顶堆只维持两堆 size 差 $\le1$。

完整模板：

```cpp
#include <vector>
#include <deque>
#include <queue>
#include <functional>
using namespace std;

// 右侧第一个严格更大的下标，没有则 -1
vector<int> nextGreater(const vector<int>& a) {
    int n = (int)a.size();
    vector<int> res(n, -1);
    vector<int> st;                              // 存下标，值递减
    for (int i = 0; i < n; ++i) {
        while (!st.empty() && a[st.back()] < a[i]) {
            res[st.back()] = i;                  // 弹出即定答案
            st.pop_back();
        }
        st.push_back(i);
    }
    return res;
}

// 窗口大小 k 的滑动最大值
vector<int> windowMax(const vector<int>& a, int k) {
    int n = (int)a.size();
    vector<int> res;
    deque<int> q;                                // 存下标，值递减
    for (int i = 0; i < n; ++i) {
        while (!q.empty() && q.front() <= i - k) q.pop_front();   // 1 队头过期
        while (!q.empty() && a[q.back()] <= a[i]) q.pop_back();   // 2 队尾弹劣
        q.push_back(i);                                           // 3 入队
        if (i >= k - 1) res.push_back(a[q.front()]);              // 4 取答案
    }
    return res;
}

// 对顶堆：动态插入，O(log n) 取中位数
struct Median {
    priority_queue<int> lo;                                  // 大根，存较小一半
    priority_queue<int, vector<int>, greater<int>> hi;       // 小根，存较大一半
    void add(int x) {
        if (lo.empty() || x <= lo.top()) lo.push(x); else hi.push(x);
        if (lo.size() > hi.size() + 1) { hi.push(lo.top()); lo.pop(); }
        if (hi.size() > lo.size())     { lo.push(hi.top()); hi.pop(); }
    }
    double get() const {
        return lo.size() == hi.size()
             ? (static_cast<double>(lo.top()) + hi.top()) / 2.0 : (double)lo.top();
    }
};
```

## 五、具体例子

### 例 1：括号匹配（栈）

问题：给只含 `()[]{}` 的串，判是否合法。

套哪个形式：栈的抵消不变量。左括号入栈，右括号只能和栈顶配；类型不符或栈空即非法；扫完栈必须为空——`(()` 就靠这句判掉。

```cpp
#include <cstdio>
#include <vector>
#include <string>
using namespace std;

bool valid(const string& s) {
    vector<char> st;
    for (char c : s) {
        if (c == '(' || c == '[' || c == '{') { st.push_back(c); continue; }
        if (st.empty()) return false;                    // 右括号多余
        char t = st.back();
        if ((c == ')' && t != '(') || (c == ']' && t != '[') || (c == '}' && t != '{'))
            return false;                                // 类型不匹配
        st.pop_back();
    }
    return st.empty();                                   // 漏这句，(() 会被判合法
}

int main() {
    char buf[100005];
    scanf("%100000s", buf);
    puts(valid(buf) ? "Yes" : "No");
    return 0;
}
```

复杂度：$O(n)$ 时间，$O(n)$ 空间。求最长合法子串时栈改存**下标**、栈底垫 `-1`：遇 `)` 弹栈，弹空则把当前下标压入当哨兵，否则长度为 `i - st.back()`。

### 例 2：单调栈——下一个更大元素（存下标）

问题：对每个 $a_i$，输出右侧第一个 $>a_i$ 的下标（1-based），没有则 0。

套哪个形式：单调栈。栈内值递减，当前元素弹掉所有比它小的栈顶，被弹者当场得到答案。

```cpp
#include <cstdio>
#include <vector>
using namespace std;

int main() {
    int n; scanf("%d", &n);
    vector<int> a(n);
    for (int& x : a) scanf("%d", &x);
    vector<int> res(n, -1), st;                 // st 存下标，值递减
    for (int i = 0; i < n; ++i) {
        while (!st.empty() && a[st.back()] < a[i]) {
            res[st.back()] = i;                 // 这里存下标而非值
            st.pop_back();
        }
        st.push_back(i);
    }
    for (int i = 0; i < n; ++i) printf("%d%c", res[i] + 1, i + 1 == n ? '\n' : ' ');
    return 0;
}
```

存下标是为了能算距离：柱状图最大矩形对每根柱子求左右第一个更矮，宽为 $r-l-1$。

复杂度：$O(n)$。

### 例 3：单调队列——滑动窗口最大值

问题：$n$ 个数，窗口长 $k$，输出每个窗口的最大值。

套哪个形式：单调队列。队内值递减，队头即最大值；「队头过期」与「队尾弹劣」是两个独立条件。

```cpp
#include <cstdio>
#include <vector>
using namespace std;

int main() {
    int n, k; scanf("%d %d", &n, &k);
    vector<int> a(n), q(n);
    for (int& x : a) scanf("%d", &x);
    int head = 0, tail = 0;                      // 手写队列，区间 [head, tail)
    for (int i = 0; i < n; ++i) {
        while (head < tail && q[head] <= i - k) ++head;             // 1 队头过期
        while (head < tail && a[q[tail - 1]] <= a[i]) --tail;       // 2 队尾弹劣
        q[tail++] = i;                                              // 3 入队
        if (i >= k - 1) printf("%d ", a[q[head]]);                   // 4 取答案
    }
    return 0;
}
```

复杂度：$O(n)$。每个下标进出各一次，`deque` 换成数组后常数减半。

### 例 4：对顶堆——动态中位数

问题：依次插入 $n$ 个数，输出第 $1,3,5,\dots$ 个插入后的中位数。

套哪个形式：对顶堆。`lo` 存较小一半、`hi` 存较大一半，插入后把 size 差调回 $\le1$；中位数是 `lo` 顶或两堆顶平均。

```cpp
#include <cstdio>
#include <queue>
#include <vector>
#include <functional>
using namespace std;

int main() {
    int n; scanf("%d", &n);
    priority_queue<int> lo;                                // 大根
    priority_queue<int, vector<int>, greater<int>> hi;     // 小根
    for (int i = 1; i <= n; ++i) {
        int x; scanf("%d", &x);
        if (lo.empty() || x <= lo.top()) lo.push(x); else hi.push(x);
        if (lo.size() > hi.size() + 1) { hi.push(lo.top()); lo.pop(); }
        if (hi.size() > lo.size())     { lo.push(hi.top()); hi.pop(); }
        if (i % 2 == 1) printf("%d\n", lo.top());          // 奇数个时中位数在 lo 顶
    }
    return 0;
}
```

复杂度：每次插入 $O(\log n)$，取中位数 $O(1)$，总 $O(n\log n)$。

## 六、复杂度与易错点

| 结构 | 时间 | 空间 |
|---|---|---|
| 单调栈 | $O(n)$，每个下标进出各一次 | $O(n)$ |
| 单调队列 | $O(n)$ | $O(n)$ |
| 堆 / 对顶堆 | 单次 $O(\log n)$ | $O(n)$ |

1. 括号匹配忘了「扫完栈为空」，`(()` 这种漏判。
2. 单调栈比较符写错（`<` 与 `<=`），「严格更大」与「大于等于」差一位。
3. 单调队列先弹劣后判过期，队头留着一个已过期的最大值。
4. 对顶堆调整后两堆 size 差超过 1，取中位数越界。
5. 存值不存下标算不出距离；存下标却拿值去比较，逻辑反掉。
