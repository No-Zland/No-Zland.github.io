# 模拟与枚举：把题意逐字翻译成代码

> 一句话本质：模拟是照着题面改状态，枚举是把候选解挨个试；两者不靠公式，靠「状态写全、边界写对」。

## 一、是什么

**模拟**：把题面的规则逐条翻译成对状态变量的修改，执行顺序与叙述顺序一一对应——没有模型，只有流程。**枚举**：把候选解组成集合 $\Omega$ 逐个判定，再用剪枝把实际枚举量压下去。规则题（图形、日期、网格行走、多组数据格式化）和答案空间小且可判定的搜索题，都归它管。

识别信号：

1. 「依次执行」「重复直到」「若……则……」「每次取最左的」——这是状态机，照抄即可。
2. 答案与位置强绑定：螺旋填数、第 $i$ 行第 $j$ 列、上下左右走一格。
3. 数据范围小得可疑（$n\le100$）——这是在提示 $O(n^2)$ 就是正解。
4. 问「有多少对 $(i,j)$ 满足……」，判定是 $O(1)$，又没有单调性可用。
5. 输入是「第一行 $T$」或读到文件末尾，输出要补前导零、保留 $k$ 位小数。
6. 规则含周期实体（星期、方向、循环队列），答案只依赖取模。

不该用它：操作到 $10^5$ 次、每步还要扫一遍数组，总代价 $10^{10}$ 必 TLE，先想 04 的双指针；金额用 `double` 累加误差会滚雪球，先换整数单位。

## 二、形式

$$s_k=(t_k,x_k,y_k,d_k),\qquad s_{k+1}=\delta(s_k),\qquad \delta:\ \text{前进一格；越界或已访问则}\ d\leftarrow(d+1)\bmod 4$$

枚举是判定问题 $\exists x\in\Omega:P(x)$，代价 $|\Omega|\cdot\mathrm{cost}(P)$；日期题压成序数日：

$$D=\mathrm{toDays}(y,m,d),\qquad \Delta D=D_1-D_0,\qquad w=D\bmod 7$$

代码形式：`void step(State&)` 描述一步，`bool ok(i,j)` 描述判定。数据形式：网格用 `vector<vector<int>>`，非 $0$ 兼作访问标记；四方向用平行数组，此后没有 if-else 嵌套：

```cpp
const int dx[4] = {0, 1, 0, -1}, dy[4] = {1, 0, -1, 0};  // 右、下、左、上
```

## 三、怎么理解

直觉：模拟像照菜谱做菜，不必懂化学，只要按顺序执行；方向数组把「右转」外置成一张查表。

为什么正确：模拟靠不变量归纳——「每轮结束，已填格数等于最后写入的值，访问标记与实际写入一致」；枚举靠「$\Omega$ 覆盖全部解 + 判定与题意等价」，剪枝额外要求「被跳过的分支已证明无解」，说不出这句就不许剪。

手推 $n=3$ 的螺旋：$(0,0)$ 写 1、向右 2、3；$(0,3)$ 越界，$0\to1$，向下 4、5；$(3,2)$ 越界，$1\to2$，向左 6、7；$(2,-1)$ 越界，$2\to3$，$(1,0)$ 写 8；$(0,0)$ 已填，$3\to0$，$(1,1)$ 写 9，得

$$\begin{matrix}1&2&3\\8&9&4\\7&6&5\end{matrix}$$

## 四、怎么变成代码

映射：`d` 只做 `(d+1)%4` 且从不回退，所以方向就是数组下标；`a[nx][ny]` 非零兼作「墙」，省掉 `vis`；`v` 从 1 到 $n^2$ 恰等于格子数，不必另设计数器。循环顺序必须**先写当前格、再试走**，反过来最后一格会多转一次向。边界五项缺一必 RE：`nx<0||nx>=n||ny<0||ny>=n||a[nx][ny]`。日期题同理：年月日压成一个整数再运算，闰年规则只写一次。

```cpp
#include <iostream>
#include <vector>
using namespace std;

const int dx[4] = {0, 1, 0, -1};
const int dy[4] = {1, 0, -1, 0};

int main() {
    int n;
    if (!(cin >> n)) return 0;                 // 空输入直接退出
    vector<vector<int>> a(n, vector<int>(n, 0));
    int x = 0, y = 0, d = 0;
    for (int v = 1; v <= n * n; ++v) {
        a[x][y] = v;                           // 先落笔
        if (v == n * n) break;                 // 最后一格不再转向
        int nx = x + dx[d], ny = y + dy[d];
        if (nx < 0 || nx >= n || ny < 0 || ny >= n || a[nx][ny]) {
            d = (d + 1) % 4;                   // 撞界或撞已填，右转一次
            nx = x + dx[d], ny = y + dy[d];
        }
        x = nx, y = ny;
    }
    for (int i = 0; i < n; ++i)
        for (int j = 0; j < n; ++j)
            cout << a[i][j] << " \n"[j + 1 == n];
    return 0;
}
```

## 五、具体例子

### 1. 螺旋矩阵：方向数组 + 撞墙转向

问题：$n\times n$ 按顺时针从 1 填到 $n^2$。套 $(x,y,d)$ 与 $\delta$，代码即上面那段。复杂度：时间 $O(n^2)$、空间 $O(n^2)$。正确性靠不重不漏：`v` 严格递增，撞墙必转向，转向后剩余空间必够走完当前边。

### 2. 日期推算：天数、取模与进位

问题：给定日期与整数 $k$，求 $k$ 天后是几月几日、星期几，$k$ 可负。套序数日：加减变成整数加减，再反解。

```cpp
#include <iostream>
using namespace std;

bool leap(int y) { return y % 4 == 0 && (y % 100 != 0 || y % 400 == 0); }

int mdays(int y, int m) {
    static const int t[13] = {0, 31, 28, 31, 30, 31, 30, 31, 31, 30, 31, 30, 31};
    return (m == 2 && leap(y)) ? 29 : t[m];
}

long long toDays(int y, int m, int d) {           // 0001-01-01 记为第 0 天
    long long s = 0;
    for (int i = 1; i < y; ++i) s += 365 + leap(i);
    for (int i = 1; i < m; ++i) s += mdays(y, i);
    return s + d - 1;
}

void fromDays(long long s, int& y, int& m, int& d) {
    y = 1;
    while (s >= 365 + leap(y)) s -= 365 + leap(y), ++y;   // 整年地减
    m = 1;
    while (s >= mdays(y, m)) s -= mdays(y, m), ++m;       // 整月地减
    d = int(s) + 1;
}

int main() {
    int y, m, d;
    long long k;
    cin >> y >> m >> d >> k;
    long long D = toDays(y, m, d) + k;            // 负数照加，不必特判
    int yy, mm, dd;
    fromDays(D, yy, mm, dd);
    int w = int((D % 7 + 7) % 7);                 // 0001-01-01 是周一，记为 0
    cout << yy << "-" << mm << "-" << dd << " " << w + 1 << "\n";
    return 0;
}
```

复杂度：时间 $O(y)$，$y\le10^6$ 够用；空间 $O(1)$。错都错在 `d-1` 与 `fromDays` 的 `>=`，两处各差一天。

### 3. 枚举 + 剪枝：3、5、7 的倍数

问题：$[1,n]$ 中能被 3 或 5 或 7 整除的个数，$n\le10^{18}$，逐个枚举不可能。套容斥：$\Omega$ 是 3 个集合的 7 个非空交集，

$$\Big|\bigcup A_i\Big|=\sum_{\varnothing\ne S}(-1)^{|S|+1}\Big\lfloor\frac{n}{\mathrm{lcm}(S)}\Big\rfloor$$

```cpp
#include <iostream>
using namespace std;
typedef long long ll;

ll gcd(ll a, ll b) { return b ? gcd(b, a % b) : a; }

int main() {
    ll n, ans = 0;
    cin >> n;
    const ll p[3] = {3, 5, 7};
    for (int mask = 1; mask < 8; ++mask) {        // 枚举 7 个非空子集
        ll l = 1;
        int bits = 0;
        for (int i = 0; i < 3; ++i)
            if (mask >> i & 1) {
                ++bits;
                l = l / gcd(l, p[i]) * p[i];      // 先除后乘防溢出
                if (l > n) break;                 // 剪枝：贡献必为 0
            }
        if (l > n) continue;
        ans += (bits % 2 ? 1 : -1) * (n / l);     // 奇加偶减
    }
    cout << ans << "\n";
    return 0;
}
```

复杂度 $O(2^3)$，与 $n$ 无关。剪枝合法只需一句：$l>n$ 时 $\lfloor n/l\rfloor=0$，这一支对答案贡献恒为 0。

## 六、复杂度与易错点

| 项 | 值 |
|---|---|
| 时间复杂度 | 模拟 $O(\text{操作数})$；螺旋 $O(n^2)$；枚举 $O(\lvert\Omega\rvert)$，剪枝后远小于上界 |
| 空间复杂度 | 网格 $O(n^2)$；线性模拟、日期、容斥均为 $O(1)$ |

- 多组数据忘清空数组与计数器，第二组读到上一组的脏数据。
- 撞墙只判了 `nx >= n`，漏 `nx < 0`，本地不崩、评测 RE。
- 最后一格不 `break`，方向多推一格，下一轮起点错位。
- `toDays` 的 `d-1`、`fromDays` 的 `>=` 任一写错，结果整体差一天。
- $k<0$ 时 `D % 7` 得负，忘了 `(x % 7 + 7) % 7`。
- 金额用 `double` 累加，$99.995$ 输出成 $99.99$，一律换「分」。
