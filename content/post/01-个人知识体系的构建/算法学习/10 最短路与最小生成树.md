# 最短路与最小生成树

> 一句话本质：最短路固定起点、逐点松弛到不再变短；最小生成树按边权从小到大加边到连通——两者都靠一条单调性把贪心锁死。

## 一、是什么

最短路：给定带权图与源点 $s$，求 $s$ 到每个点的最小路径权。最小生成树（MST）：在连通带权无向图中选 $n-1$ 条边，使所有点连通且边权和最小。前者是「点对点」的路径优化，后者是「全局」的连接优化。

识别信号：

- 「从 A 到 B 最少花多少」时间、费用，边权非负——单源最短路。
- 边权有负数——Dijkstra 直接排除（下面给反例），只能按拓扑序做（DAG）或上 Bellman-Ford / SPFA。
- 边权只有 0 和 1，「走空地 0 步、破墙 1 步」——0-1 BFS，双端队列，别开堆。
- $n\le 400$ 且要任意两点距离——Floyd；$n\le 10^5$ 还要任意两点——$n$ 次 Dijkstra。
- 「用最少的花费把所有点连起来」「修路使全省连通」——最小生成树。
- 「让最长的那段尽量短」「最大边最小」——瓶颈生成树，答案就是 MST 上的最大边。

不该用它的场景：只判断连通性，并查集或一次 BFS 就够；图本身是一棵树时两点路径唯一，直接 DFS，不必跑最短路；有负环时「最短路」根本不存在，Dijkstra 与 Floyd 都会给出看着合理的错值。

## 二、形式

松弛是唯一的原子操作：

$$dis[v]=\min\bigl(dis[v],\ dis[u]+w(u,v)\bigr)$$

收敛后所有边满足三角不等式 $dis[v]\le dis[u]+w(u,v)$，此时 $dis$ 就是最短路——否则还能再松弛一次。

Dijkstra 的不变量是：堆顶取出的最小 $dis[u]$ 已是终值，前提是 $w\ge 0$。Floyd 把「允许的中转点」当成阶段：

$$f_k[i][j]=\min\bigl(f_{k-1}[i][j],\ f_{k-1}[i][k]+f_{k-1}[k][j]\bigr)$$

MST 靠切割性质：把点集分成 $S$ 与 $V\setminus S$，跨切割的最小边必属于某棵 MST。

代码骨架三条：`dijkstra(s)` 配邻接表和堆；`floyd()` 配二维距离数组；`kruskal()` 配边表和并查集。数据形式：无向边在邻接表里存两次、在边表里存一次；`dis` 用 `long long`，`INF` 取 `4e18`。

## 三、怎么理解

直觉：Dijkstra 像从源点长出一片「已确定区域」，每次把离这片区域最近的外部点吞进来；Floyd 像逐个开放中转站，第 $k$ 轮只允许经过前 $k$ 个点；Kruskal 像按价格从便宜到贵买边，会成环就不买。

为什么正确：

- **Dijkstra**：设 $u$ 是第一个出堆时 $dis[u]$ 不等于真实最短距离的点，取真实最短路 $s\to\cdots\to x\to y\to\cdots\to u$，其中 $x$ 是路径上最后一个已确定点。$dis[x]$ 已正确，且 $dis[y]\le dis[x]+w(x,y)<dis[u]$（非负权），所以 $y$ 会先于 $u$ 出堆，矛盾。
- **Floyd**：第 $k$ 轮开始前 $f[i][j]$ 表示「只允许 $1..k-1$ 中转」的最短距离。只允许 $1..k$ 的路径要么不经过 $k$，要么在 $k$ 处断成两段，取小即完成归纳。
- **Kruskal**：当前边 $e$ 是跨两个连通块的最小边。若某棵 MST 不含 $e$，加入 $e$ 会成环，环上必有另一条跨该切割的边 $e'$，且 $w(e')\ge w(e)$，用 $e$ 换掉 $e'$ 仍是生成树且不更差。

手推：5 点图边 $1-2(2),1-3(5),2-3(1),2-4(4),3-4(1),4-5(3)$。Dijkstra 从 1 出发：2 得 2，3 经 2 得 3，4 经 3 得 4，5 得 7。Kruskal 按边权 $1,1,2,3$ 依次取 $2-3,3-4,1-2,4-5$，和为 7。

## 四、怎么变成代码

映射：邻接表存 `{to, w}`；堆里存 `pair<ll,int>`，`greater` 造小根堆；`d > dis[u]` 说明是过期元素，直接丢；Floyd 的 `f[i][i]=0`，其余初始化为 INF；Kruskal 排序后并查集判环，选够 $n-1$ 条立即停。

循环顺序：Dijkstra 先弹堆再松弛；Floyd 三层固定为 `k, i, j`；Kruskal 只扫一遍排好序的边。

边界：`INF=4e18` 时 Floyd 里 `INF+INF` 会溢出成负数，必须判 `f[i][k] < INF && f[k][j] < INF`；无向图两个方向都要加边；Kruskal 结束要核对边数，否则不连通时会返回假权值。

```cpp
// 显式标准头，不用 <bits/stdc++.h>
#include <cstdio>
#include <vector>
#include <queue>
#include <algorithm>
#include <numeric>
#include <functional>
using namespace std;
typedef long long ll;

const int N = 1005;
const ll INF = (ll)4e18;
struct Edge { int to; ll w; };
vector<Edge> g[N];
ll dis[N], f[N][N];

// 1) Dijkstra 堆优化：要求所有边权 >= 0
void dijkstra(int n, int s) {
    fill(dis, dis + n + 1, INF);
    priority_queue<pair<ll, int>, vector<pair<ll, int>>, greater<pair<ll, int>>> pq;
    dis[s] = 0; pq.push({0, s});
    while (!pq.empty()) {
        auto [d, u] = pq.top(); pq.pop();
        if (d > dis[u]) continue;             // 惰性删除：跳过过期元素
        for (const auto& e : g[u])
            if (dis[e.to] > d + e.w) {        // 松弛
                dis[e.to] = d + e.w;
                pq.push({dis[e.to], e.to});
            }
    }
}

// 2) Floyd：调用前 f 已初始化为 INF、对角 0，并写入边
void floyd(int n) {
    for (int k = 1; k <= n; ++k)              // k 是阶段，必须在最外层
        for (int i = 1; i <= n; ++i)
            for (int j = 1; j <= n; ++j)
                if (f[i][k] < INF && f[k][j] < INF)
                    f[i][j] = min(f[i][j], f[i][k] + f[k][j]);
}

// 3) Kruskal：排序 + 并查集
struct KEdge { int u, v; ll w; };
int fa[N];
int find(int x) { return fa[x] == x ? x : fa[x] = find(fa[x]); }

ll kruskal(int n, vector<KEdge>& es) {
    iota(fa, fa + n + 1, 0);
    sort(es.begin(), es.end(),
         [](const KEdge& a, const KEdge& b) { return a.w < b.w; });
    ll sum = 0; int cnt = 0;
    for (const auto& e : es) {
        int ru = find(e.u), rv = find(e.v);
        if (ru == rv) continue;               // 已连通，加了会成环
        fa[ru] = rv; sum += e.w; ++cnt;
        if (cnt == n - 1) break;              // 已够 n-1 条
    }
    return cnt == n - 1 ? sum : -1;           // -1 表示图不连通
}

int main() {
    const int n = 5;
    int raw[6][3] = {{1,2,2},{1,3,5},{2,3,1},{2,4,4},{3,4,1},{4,5,3}};
    vector<KEdge> es;
    for (int i = 1; i <= n; ++i) { fill(f[i], f[i] + n + 1, INF); f[i][i] = 0; }
    for (auto& r : raw) {
        g[r[0]].push_back({r[1], r[2]});
        g[r[1]].push_back({r[0], r[2]});      // 无向边存两次
        es.push_back({r[0], r[1], r[2]});
        f[r[0]][r[1]] = f[r[1]][r[0]] = min(f[r[0]][r[1]], (ll)r[2]);
    }
    dijkstra(n, 1);
    floyd(n);
    printf("dis[5] = %lld, f[1][5] = %lld\n", dis[5], f[1][5]);
    printf("mst = %lld\n", kruskal(n, es));   // 1+1+2+3 = 7
    return 0;
}
```

## 五、具体例子

### 1. Dijkstra 堆优化：热浪与负权反例

**问题**：P1339 给无向带权图，求 $s$ 到 $t$ 的最短路。

**形式**：`dis[t]` 一旦从堆中弹出即可返回，因为此后不会有更小的值。

```cpp
#include <cstdio>
#include <vector>
#include <queue>
#include <functional>
#include <algorithm>
using namespace std;
typedef long long ll;
const int N = 2600;
const ll INF = (ll)4e18;
struct Edge { int to; ll w; };
vector<Edge> g[N];
ll dis[N];

ll dijkstra(int n, int s, int t) {
    fill(dis, dis + n + 1, INF);
    priority_queue<pair<ll, int>, vector<pair<ll, int>>, greater<pair<ll, int>>> pq;
    dis[s] = 0; pq.push({0, s});
    while (!pq.empty()) {
        auto [d, u] = pq.top(); pq.pop();
        if (d > dis[u]) continue;
        if (u == t) return d;                  // 终点定型，提前退出
        for (const auto& e : g[u])
            if (dis[e.to] > d + e.w) {
                dis[e.to] = d + e.w;
                pq.push({dis[e.to], e.to});
            }
    }
    return INF;
}
```

**为什么不能负权**：边 $1\to2$ 权 2、$1\to3$ 权 5、$3\to2$ 权 $-10$。堆先弹出 $dis[2]=2$ 并把它定死，可真实最短路是 $5-10=-5$。负权让「先弹出即最小」失效，这就是算法前提而非实现细节。

**复杂度**：$O((n+m)\log n)$，空间 $O(n+m)$。

### 2. Floyd：灾后重建与 k 必须在最外层

**问题**：P1119 每条边、每个点都有重建时间，询问时刻 $T$ 时 $x$ 到 $y$ 的最短路，未重建的点不能走。

**形式**：把点按重建时间排序，时间到了就把它当作新开放的中转点，跑一轮以它为 $k$ 的 Floyd——$k$ 的语义正好是「已开放的点集」。

```cpp
#include <cstdio>
#include <vector>
#include <algorithm>
using namespace std;
const int N = 205;
const int INF = 0x3f3f3f3f;
int f[N][N], t[N];

// 第 k 个点刚重建完，作为新中转点
void openK(int k, int n) {
    for (int i = 0; i < n; ++i)
        for (int j = 0; j < n; ++j)
            if (f[i][k] < INF && f[k][j] < INF)
                f[i][j] = min(f[i][j], f[i][k] + f[k][j]);
}

// 查询按 T 升序离线处理，ptr 指向下一个待开放的点
int solve(int x, int y, int T, int& ptr, const vector<int>& ord, int n) {
    while (ptr < n && t[ord[ptr]] <= T) openK(ord[ptr++], n);
    if (t[x] > T || t[y] > T || f[x][y] >= INF) return -1;
    return f[x][y];
}
```

**为什么 k 不能进内层**：取四点，边 $1\to3,3\to4,4\to2$ 权都是 1。写成 $i$ 外、$j$ 中、$k$ 内时，算 $(i=1,j=2)$ 需要 $f[1][4]+f[4][2]$，而 $f[1][4]$ 要等 $j=4$ 那一轮才被算出；$j=2$ 过去不再回头，$f[1][2]$ 永远停在 INF。正确值 3 只在 $k=4$ 那一层出现。

**复杂度**：$O(n^3)$ 预处理，每次开放一个点 $O(n^2)$，询问 $O(1)$；空间 $O(n^2)$。

### 3. Kruskal：排序 + 并查集

**问题**：P3366 求 $n$ 点 $m$ 边无向图的最小生成树权值。

**形式**：按边权升序扫描，两端不在同一集合就选它并合并。

```cpp
#include <cstdio>
#include <vector>
#include <algorithm>
#include <numeric>
using namespace std;
typedef long long ll;
const int N = 200005;
struct KEdge { int u, v; ll w; };
int fa[N];
int find(int x) { return fa[x] == x ? x : fa[x] = find(fa[x]); }

ll kruskal(int n, vector<KEdge>& es) {
    iota(fa + 1, fa + n + 1, 1);              // 下标从 1 开始
    sort(es.begin(), es.end(),
         [](const KEdge& a, const KEdge& b) { return a.w < b.w; });
    ll sum = 0; int cnt = 0;
    for (const auto& e : es) {
        int ru = find(e.u), rv = find(e.v);
        if (ru == rv) continue;               // 成环，跳过
        fa[ru] = rv;
        sum += e.w; ++cnt;
        if (cnt == n - 1) break;
    }
    return cnt == n - 1 ? sum : -1;
}
```

**复杂度**：排序 $O(m\log m)$ 主导，并查集近似 $O(m\alpha(n))$；空间 $O(n+m)$。

## 六、复杂度与易错点

| 算法 | 时间 | 空间 | 适用 |
|---|---|---|---|
| Dijkstra（堆） | $O((n+m)\log n)$ | $O(n+m)$ | 非负权、单源 |
| Floyd | $O(n^3)$ | $O(n^2)$ | 任意两点、$n\le 400$ |
| Bellman-Ford | $O(nm)$ | $O(n)$ | 有负权、判负环 |
| Kruskal | $O(m\log m)$ | $O(n+m)$ | 稀疏图 MST |
| Prim（朴素） | $O(n^2)$ | $O(n)$ | 稠密图 MST |

- 堆里不判 `d > dis[u]`，过期元素反复扩展，常数和复杂度一起坏。
- Floyd 的 INF 取 `1e18`，两个 INF 相加溢出成负数，凭空造出更短路。
- 无向图只加一个方向，跑出一片 INF 还以为是图不连通。
- Kruskal 不检查边数，图不连通时返回一个假的生成树权值。
- 负权图硬跑 Dijkstra，答案偏大；有负环时先判环，别直接求最短路。
- 0-1 BFS 忘记出队判重，一个点被反复扩展，复杂度退化。
