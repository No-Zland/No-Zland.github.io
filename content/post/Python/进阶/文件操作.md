# 一、文件操作核心定义与流程

## 1. 定义

Python 文件操作是通过内置函数或模块（如 open()、os、pathlib）与外部文件（文本文件 .txt/.csv、二进制文件 .jpg/.mp4 等）进行交互的过程，
核心目的是实现**数据的持久化存储**（写入）和**外部数据读取**，是开发中处理配置、日志、数据集等场景的基础技能。

## 2. 核心流程

所有文件操作遵循 “三步曲”，需严格保证资源释放：

1. **打开文件**：建立程序与文件的连接，返回文件对象；

2. **操作文件**：通过文件对象的方法（如 read()、write()）实现读写；

3. **关闭文件**：释放文件资源（避免锁定、数据丢失或资源泄露）。

# 二、核心函数：open()（文件打开与创建）

## 1. 函数原型

```python
open(    
	
	file: str | bytes | PathLike[str] | PathLike[bytes],  # 文件路径（相对/绝对）    
	
	mode: str = 'r',  # 打开模式（核心参数）    
	
	buffering: int = -1,  # 缓冲策略（默认系统决定）    
	
	encoding: str | None = None,  # 文本模式编码（如 utf-8，二进制模式无需指定）    errors: str | None = None,  # 编码错误处理（如 'ignore'/'replace'）    
	
	newline: str | None = None,  # 换行符处理（如 '\n'/'\r\n'）    
	
	closefd: bool = True,  # 是否关闭文件描述符    
	
	opener: Callable[[str, int], int] | None = None  # 自定义打开器（高级）
	
) -> TextIOWrapper | BinaryIOWrapper  # 返回文本/二进制文件对象
```

## 2. 关键参数解析

| 参数       | 作用说明                                          | 注意事项                              |
| -------- | --------------------------------------------- | --------------------------------- |
| file     | 指定文件路径（相对路径：基于当前工作目录；绝对路径：如 C:/data/test.txt） | 跨平台路径推荐用 os.path.join() 或 pathlib |
| mode     | 控制文件操作权限（读 / 写 / 追加）和数据类型（文本 / 二进制）           | 必须正确选择，否则导致报错或数据覆盖                |
| encoding | 文本模式下指定字符编码（推荐 utf-8）                         | 二进制模式（带 b）无需指定，否则报错               |

# 三、文件打开模式（核心重点）

## 1. 模式分类与说明

按 “操作权限” 和 “数据类型” 分为两类，支持**组合使用**（如 r+、wb），用表格清晰对比：

| 模式  | 类型       | 核心功能                   | 文件不存在时                | 注意事项                           |
| --- | -------- | ---------------------- | --------------------- | ------------------------------ |
| r   | 文本（默认）   | 只读                     | 报错（FileNotFoundError） | 指针初始在文件开头                      |
| w   | 文本       | 只写，**覆盖原有内容**          | 创建新文件                 | 慎用！会清空原文件数据                    |
| a   | 文本       | 只写，在文件末尾追加内容           | 创建新文件                 | 指针初始在文件末尾，无法覆盖前内容              |
| r+  | 文本       | 读写（先读后写，或移动指针后写）       | 报错                    | 写操作会从当前指针位置覆盖，需用 seek() 调整     |
| w+  | 文本       | 读写，先清空原文件              | 创建新文件                 | 适合 “重新写入 + 读取” 场景              |
| a+  | 文本       | 读写，追加模式（写只能在末尾，读需移动指针） | 创建新文件                 | 读前需用 seek(0) 移动指针到开头           |
| rb  | 二进制      | 二进制只读（处理图片、视频等非文本文件）   | 报错                    | 无需指定 encoding，读取内容为字节流 bytes   |
| wb  | 二进制      | 二进制只写，覆盖原有字节流          | 创建新文件                 | 常用于文件复制、保存二进制数据                |
| ab  | 二进制      | 二进制追加，在末尾添加字节流         | 创建新文件                 | 适合日志追加二进制数据（如图片碎片）             |
| x   | 文本 / 二进制 | 独占创建（仅当文件不存在时创建并写入）    | 创建新文件                 | 文件已存在时报错（FileExistsError），避免覆盖 |

## 2. 模式使用示例

```python
# 1. 文本模式：r（只读，文件必须存在）
with open("test.txt", "r", encoding="utf-8") as f:
    
    content = f.read()
	
	print("文本内容：", content)
```

```python
# 2. 文本模式：w（覆盖写，文件不存在则创建）
with open("test.txt", "w", encoding="utf-8") as f:    
	
	f.write("第一次写入\n")  # 文件内容：第一次写入
	
with open("test.txt", "w", encoding="utf-8") as f:    

	f.write("第二次写入\n")  # 覆盖原内容，文件内容：第二次写入
```

```python
# 3. 二进制模式：rb+wb（复制图片）
with open("source.jpg", "rb") as src:  # 读二进制文件（无encoding）
    
    binary_data = src.read()  # 读取字节流
	
with open("copy.jpg", "wb") as dst:  # 写二进制文件    
    
    dst.write(binary_data)  # 写入字节流，完成复制print("图片复制完成")
```

# 四、文件读写方法（按类型分类）

## 1. 文本文件读写（返回 / 操作 str 类型）

### 1.1 读取方法​

#### （1）read() 方法​

- 函数原型：read(size=-1)​

- 核心功能：读取 size 个字符（size=-1 时读取全部内容）。适用于小文件，一次性加载所有内容到内存。​

- 典型示例：​

​
```python
with open("test.txt", "r", encoding="utf-8") as f:​

	full_content = f.read() # 读取全部内容​

	f.seek(0) # 将指针移回文件开头（否则后续读取从末尾开始）​

	part_content = f.read(5) # 读取前5个字符​

print("全部内容：", full_content)​

print("前5个字符：", part_content)​
```

#### （2）readline() 方法​

- 函数原型：readline(size=-1)​

- 核心功能：逐行读取，返回单行字符串（含换行符 \n），size 限制该行读取的字符数。适用于需要逐行处理且中途可能终止的场景。​

- 典型示例：​

```python
​with open("test.txt", "r", encoding="utf-8") as f:​

	line1 = f.readline() # 读取第1行​

	line2 = f.readline() # 读取第2行​

print("第1行（含换行符）：", repr(line1)) # repr() 显示换行符​

print("第1行（去除换行符）：", line1.strip())​
```


#### （3）readlines() 方法​

- 函数原型：readlines(hint=-1)​

- 核心功能：读取所有行，返回列表（每行作为列表元素，含 \n），hint 限制读取的行数（约等于 hint 个字符的行数）。适用于需要一次性获取所有行并批量处理的场景（注意：大文件会占用大量内存）。​

- 典型示例：​

```python
​with open("test.txt", "r", encoding="utf-8") as f:​
	
	lines = f.readlines() # 所有行存入列表​
	
print("行列表（含换行符）：", lines)

# 遍历处理每行​

for line in lines:​
	
	print("处理后行内容：", line.strip())​​
```

#### （4）直接迭代文件对象​

- 核心功能：通过 for line in file_obj 逐行迭代文件对象。内存友好，无需一次性加载全部内容，适合处理大文件（如 1GB 日志文件）。​

- 典型示例：​

```python
​# 处理1GB大文件，内存占用极低​

with open("large_file.txt", "r", encoding="utf-8") as f:​
	
	for line in f: # 逐行读取，每行加载到内存​
		
		if "关键词" in line: # 示例：筛选含关键词的行​
			
			print("匹配行：", line.strip())​
```

### 1.2 写入方法​

#### （1）write() 方法​

- 函数原型：write(s: str) -> int​

- 核心功能：写入字符串 s，返回写入的字符数（需手动添加换行符 \n 实现换行）。​

- 典型示例：​

```python
​with open("output.txt", "w", encoding="utf-8") as f:​

	count1 = f.write("Hello World!\n") # 写第一行（加\n换行）​
	
	count2 = f.write("这是第二行") # 写第二行（无\n则与上一行连在一起）​

print(f"第一次写入{count1}个字符，第二次写入{count2}个字符")​
```

#### （2）writelines() 方法​

- 函数原型：writelines(lines: Iterable[str])​

- 核心功能：写入字符串可迭代对象（如列表、元组），不自动添加换行符，需手动在元素中加入 \n。​

- 典型示例：​

```python
lines = ["第一行\n", "第二行\n", "第三行"] # 元素需手动加\n实现换行​

with open("output.txt", "w", encoding="utf-8") as f:​

	f.writelines(lines) # 批量写入​
```

## 2. 二进制文件读写（返回 / 操作 bytes 类型）​

二进制文件（图片、音频、视频等）**仅支持 read() 和 write() 方法**，无需指定 encoding，核心处理字节流 bytes。​

#### 2.1 读取方法（read()）​

- 函数原型：read(size=-1)​

- 核心功能：读取 size 个字节（size=-1 时读取全部字节），返回 bytes 类型。大文件需分块读取（避免内存溢出）。​

- 典型示例：​

```python
​# 读取二进制文件（如MP3）​

with open("music.mp3", "rb") as f:​
	
	chunk_size = 1024 * 1024 # 1MB分块（根据内存调整）​
	
	while True:​
		
		chunk = f.read(chunk_size) # 分块读取字节流​
			
		if not chunk: # 读取到末尾（chunk为空）​
			
			break​
			
		# 处理字节流（如传输、解码）​
			
		print(f"处理{len(chunk)}字节数据")​
```

#### 2.2 写入方法（write()）​

- 函数原型：write(b: bytes) -> int​

- 核心功能：写入字节流 b，返回写入的字节数。​

- 典型示例：​

```python
​# 写入二进制文件（如保存网络图片）​

binary_data = b"\xff\xd8\xff\xe0\x00\x10JFIF" # 示例：JPG文件头字节流​

with open("download.jpg", "wb") as f:​

	bytes_written = f.write(binary_data) # 写入字节流​

print(f"写入{bytes_written}字节")​
```

# 五、特殊操作（指针控制、大文件、路径处理）

### 1. 文件指针操作（定位读写位置）​

文件对象内置指针记录当前读写位置（文本模式按 “字符” 计数，二进制模式按 “字节” 计数），核心方法：​

#### （1）tell() 方法​

- 函数原型：tell() -> int​

- 核心功能：返回当前指针位置（文本模式：字符数；二进制模式：字节数）。​

- 典型示例：​

```python
# 取消自动换行复制

with open("test.txt", "r", encoding="utf-8") as f:​

	f.read(3) # 读取3个字符​
	
	print("当前指针位置（字符数）：", f.tell()) # 输出：3​
```
​

#### （2）seek() 方法​

- 函数原型：seek(offset: int, whence: int = 0) -> int​

- 核心功能：移动指针到指定位置：​

- whence=0：从文件开头计算（默认）；​

- whence=1：从当前位置计算；​

- whence=2：从文件末尾计算。​

- 典型示例：​

```python
# 取消自动换行复制

with open("test.txt", "r+", encoding="utf-8") as f:​
	
	f.seek(5) # 从开头移动5个字符​
	
	f.write("插入") # 从指针位置覆盖写入​
	
	f.seek(0, 2) # 移动到文件末尾​
	
	print("文件末尾位置（字符数）：", f.tell())​
```

​
### 2. 大文件处理（避免内存溢出）​

当文件体积超过内存（如 10GB 日志）时，需采用 “流式处理”：​

#### （1）文本大文件：逐行迭代​

```python
# 取消自动换行复制​

def process_large_text(file_path: str):​

	"""逐行处理大文本文件，内存占用<1MB"""​
	
	with open(file_path, "r", encoding="utf-8") as f:​
		
		for line in f: # 逐行读取，每行加载到内存​
			
			if "ERROR" in line: # 示例：提取错误日志​
				
				print("错误日志：", line.strip())​
				
process_large_text("10GB_log.txt")​
```

#### （2）二进制大文件：分块读取​

```python
def copy_large_binary(src_path: str, dst_path: str):​

	"""分块复制大二进制文件（如视频）"""​
	
	chunk_size = 1024 * 1024 * 10 # 10MB/块（可根据内存调整）​
	
	with open(src_path, "rb") as src, open(dst_path, "wb") as dst:​
		
		while chunk := src.read(chunk_size): # 海象运算符：读取块并判断非空​
			
			dst.write(chunk)​
			
copy_large_binary("large_video.mp4", "video_copy.mp4")​
```

# 六、高级操作（文件管理、异常处理、配置读写）

### 1. 文件管理（复制、移动、删除）

依赖 shutil 模块（高级文件操作），支持跨目录操作：

```python
import shutil from pathlib 

import Path

# 1. 文件复制（src→dst，支持跨磁盘）
shutil.copy("source.txt", "dest_dir/source_copy.txt")  # 复制文件内容+权限

shutil.copy2("source.txt", "dest_dir/source_copy2.txt")  # 复制文件内容+权限+元数据（创建时间）

# 2. 文件移动/重命名
shutil.move("old.txt", "new.txt")  # 同一目录：重命名

shutil.move("old.txt", "dest_dir/new.txt")  # 跨目录：移动+重命名

# 3. 目录复制（递归复制所有子文件/目录）
shutil.copytree("src_dir", "dst_dir")  # dst_dir必须不存在

# 4. 文件删除（谨慎使用！无回收站）
Path("delete_me.txt").unlink()  # pathlib方式# 

os.remove("delete_me.txt")  # os方式

# 5. 目录删除（递归删除，谨慎！）
shutil.rmtree("delete_dir")  # 删除目录及所有内容
```

### 2. 异常处理（避免程序崩溃）

文件操作易触发异常（如文件不存在、无权限），需用 try-except 捕获：
​

```python
​def safe_read_file(file_path: str) -> str | None:​
	
	try:​
		
		with open(file_path, "r", encoding="utf-8") as f:​
			
			return f.read()​
			
		except FileNotFoundError:​
			
			print(f"错误：文件 {file_path} 不存在")​
			
			return None​
			
		except PermissionError:​
			
			print(f"错误：无权限读取 {file_path}")​
			
			return None​
```

# 七、最佳实践（避坑指南）

1. **始终用** **with** **语句**：自动关闭文件，即使发生异常也能释放资源，避免手动 close() 遗忘；

2. **明确指定** **encoding**：文本模式强制指定 encoding="utf-8"，避免不同环境下的编码乱码（如 Windows 默认 gbk）；

3. **慎用** **w** **模式**：w 会覆盖原文件，写入前确认文件是否需要备份，推荐先判断文件是否存在；

4. **二进制模式无** **encoding**：处理图片、视频等时，必须用 rb/wb，且不指定 encoding，否则报错；

5. **大文件流式处理**：避免用 read()/readlines() 一次性加载大文件，优先用 for line in file 或分块读取；

6. **路径用** **pathlib**：Python 3.4+ 推荐 pathlib 替代 os.path，代码更简洁、跨平台兼容性更好；

7. **敏感操作前备份**：删除、覆盖文件前，对重要数据进行备份（如 shutil.copy2()），避免不可逆损失。
