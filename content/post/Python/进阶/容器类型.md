## 1. 列表（list）

### 1.1 基本形式

```
lst = \[1, 2, 3, 4]
```

### 1.2 列表推导式

简洁生成列表的语法。

```
# 生成1-10的偶数

even\_lst = \[x for x in range(1, 11) if x % 2 == 0]

print(even\_lst)  # 输出：\[2, 4, 6, 8, 10]
```

### 1.3 切片赋值

可通过切片批量修改元素。

```
lst\[1:3] = \[10, 20]  # lst变为\[1, 10, 20, 4]
```

### 1.4 .sort ()（原地排序）

```
lst.sort(reverse=True)  # 原地降序：\[20, 10, 4, 1]
```

### 1.5 .sorted ()（返回新列表）

生成排序后的新列表，原列表保持不变。

### 1.6 .reverse ()（原地反转）

```
lst.reverse()  # 原地反转：\[1, 4, 10, 20]
```

## 2. 元组（tuple）

有序、不可变的容器类型，用于存储一系列元素。与列表（list）类似，核心区别在于不可变性。

### 2.1 基本形式

```
t1 = (1, 2, 3)  # 包含3个整数的元组

t2 = ("a", 10, True)  # 混合类型元素

t3 = ()  # 空元组
```

#### 2.1.1 括号可省略性（不推荐，可读性差）

```
t4 = 10, 20, 30  # 等价于(10, 20, 30)
```

#### 2.1.2 单元素元组逗号性

单元素元组需加逗号（否则被视为括号表达式）。

```
t4 = (5,)  # 正确：元组类型

print(type(t4))  # \<class 'tuple'>

t5 = (5)   # 错误：实际是整数类型（非元组）

print(type(t5))  # \<class 'int'>
```

#### 2.1.3 可嵌套性

元组内部可以包含其他元组，形成多维结构。

### 2.2 性质

#### 2.2.1 不可变性

元组创建后，其元素不能被修改、添加或删除。尝试修改会直接报错。

```
t = (1, 2, 3)

# t\[0] = 10  # 报错：'tuple' object does not support item assignment（元组不支持修改元素）

# del t\[0]  # 报错：'tuple' object doesn't support item deletion（元组不支持删除元素）
```

#### 2.2.2 有序性

元素按插入顺序排列，支持索引（从 0 开始）访问和切片（获取子序列）。

```
# 索引访问（获取单个元素）

t = ("apple", "banana", "cherry", "date")

print(t\[0])   # 输出：apple（第1个元素）

print(t\[-1])  # 输出：date（最后1个元素）
```

```
# 切片（获取子元组，左闭右开）

print(t\[1:3])  # 输出：('banana', 'cherry')（索引1到2的元素）

print(t\[:2])   # 输出：('apple', 'banana')（从开头到索引1）
```

#### 2.2.3 元素多样性

可包含不同类型的元素，且允许重复元素。元组因不可变特性，可作为字典的键。

```
# 作为字典的键

dct = {(1, 2): "value"}  # 合法（元组不可变）
```

### 2.3 解包（多个赋值）（unpacking）

快速为多个变量赋值。

```
tup = (10, 20, 30)

a, b, c = tup  # a=10, b=20, c=30
```

## 3. 字典（dict）

### 3.1 基本形式

```
dct = {'a': 1, 'b': 2}
```

### 3.2 有序性

Python 3.7+ 字典保留插入顺序。

### 3.3 字典推导式

简洁生成字典，支持键值互换等操作。

```
reverse\_dct = {v: k for k, v in dct.items()}

print(reverse\_dct)  # 输出：{1: 'a', 2: 'b'}
```

### 3.4 .setdefault () 设置默认值

键不存在时设置默认值（比 get () 多一步赋值操作）。

```
dct.setdefault('c', 3)  # 键'c'不存在，设置为3，dct变为{'a':1,'b':2,'c':3}
```

### 3.5 合并字典

使用 \*\* 操作符或 |（Python 3.9+ 支持）。

```
d1 = {'a': 1}

d2 = {'b': 2}

merged = {\*\*d1, \*\*d2}  # 输出：{'a':1, 'b':2}

# 或 Python 3.9+：d1 | d2
```

## 4. 集合（set）

### 4.1 集合推导式

简洁生成集合，自动去重并支持筛选。

```
nums = \[1, 2, 2, 3, 4, 4]

unique\_even = {x for x in nums if x % 2 == 0}

print(unique\_even)  # 输出：{2, 4}
```

### 4.2 frozenset ()（冻结集合）

不可变集合，可作为字典的键或其他集合的元素。

```
fset = frozenset({1, 2, 3})

dct = {fset: "frozen"}  # 合法（frozenset可作为键）
```

### 4.3 无序性

不支持索引，无法通过下标访问元素。

## 5. 类型可变性总结

| 类型        | 可变性 | 说明（是否可原地修改）              |
| --------- | --- | ------------------------ |
| int/float | 不可变 | 赋值会创建新对象（如 a=1; a=2）     |
| str       | 不可变 | 修改会创建新字符串（如 s = s + "a"） |
| bool      | 不可变 | 仅 True/False，无法修改        |
| frozenset | 不可变 | 冻结集合，无法修改                |
| tuple     | 不可变 | 无法原地修改，拼接会生成新元组          |
| dict      | 可变  | 可增删改键值对（如 d \['k']=v）    |
| set       | 可变  | 可增删元素（如 add），但元素需不可变     |
| list      | 可变  | 可通过索引、方法原地修改（如 append）   |
