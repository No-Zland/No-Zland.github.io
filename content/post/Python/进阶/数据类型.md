# 1. 整数（int）

支持二进制（0b 前缀）、八进制（0o 前缀）、十六进制（0x 前缀）表示，且支持无长度限制的大整数。

## 1.1 基本形式

```python
a = 0b1010  # 二进制，对应10

b = 0o12    # 八进制，对应10

c = 0xa     # 十六进制，对应10

d = 123456789012345678901234567890  # 大整数，Python自动支持

print(a, b, c, d)  # 输出：10 10 10 123456789012345678901234567890
```

# 2. 浮点数（float）

## 2.1 is\_integer () 函数

判断浮点数是否为整数（无小数部分）。

```python
x = 5.0

y = 3.14159

print(x.is_integer())  # 输出：True（5.0是整数）
```

## 2.2 round () 函数

四舍五入控制精度。

```python
print(round(y, 2))  # 输出：3.14（保留2位小数）
```

# 3. 字符串（str）

## 3.1 转义字符

常用转义字符：\n（换行）、\t（制表符）、\（反斜杠）等。

## 3.2 strip ()（去首尾空格）

```python
s = "  Hello\tWorld\n  "

print(s.strip())  # 输出：Hello        World（去首尾空格）
```

## 3.3 upper () / lower ()（大小写转换）

```python
print(s.upper())  # 输出：  HELLO        WORLD\n  （转大写）
```

## 3.4 split ()（分割）

```python
print("a,b,c".split(','))  # 输出：\['a', 'b', 'c']（分割）
```

## 3.5 join ()（拼接）

```python
print('-'.join(\['a', 'b']))  # 输出：a-b（拼接）
```

## 3.6 三引号字符串（支持多行文本）

```python
multi\_line = """第一行

第二行

第三行"""

print(multi\_line)  # 输出多行文本
```

# 4. 布尔值（bool）

## 4.1 短路特性（逻辑运算符）

逻辑运算符的短路特性常用于条件判断和逻辑运算组合。

### and 关键词（第一个 False 则返回）

```python
# 3>2为True，继续判断后续值，返回最后一个True值

print(3 > 2 and 5)  # 输出：5

# 3>4为False，直接返回False，不执行后续判断

print(3>4 and 5)  # 输出：False
```

### or 关键词（第一个 True 则返回）

```python
print(3>4 or 5)  # 输出：5（or第一个True则返回）

print(not 0)     # 输出：True（0为False，not取反）
```
