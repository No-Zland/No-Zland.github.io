实验三 分支程序、循环程序设计

1.实验目的：

（1）掌握分支、循环程序的设计方法。

（2）进一步熟悉利用DEBUG程序修改参数的方法，并检查和验证结果的正确性。

（3）学习针对不同的问题，选用不同的程序设计方法。

2.实验内容：

（1）学习分支、循环程序的设计方法并编写汇编程序。

（2）使用DEBUG调试程序，并在MS-DOS运行成功。

3.实验步骤：

（1）分析所要解决的问题，确定适当的算法，设计整个程序的逻辑结构，画出程序框图。

（2）用EDIT或其它编辑软件，编写.ASM源程序。

（3）对其进行汇编及连接，产生.EXE文件。

（4）对.EXE文件进行调试运行。

4.实验项目：

（1）在数据段的ARRAY存储区中存放有100个字数据，计算这100个数据的和，并将其和放入SUM单元。参考源代码：

DATA   SEGMENT

ARRAY  DW 100 DUP(?)

SUM    DW 0

DATA   ENDS

CODE   SEGMENT

       ASSUME   CS:CODE，DS:DATA

START:   MOV  AX，DATA

           MOV  DS，AX

           MOV  CX，100              ；循环次数送CX寄存器

           MOV  SI，OFFSET ARRAY     ；置地址指针初值

           MOV  AX，0                ；累加器初始化

LOOP1:   ADD  AX，[SI]             ；累加

           ADD  SI，2                ；修改地址指针

           LOOP LOOP1                ；修改计数器，判断循环是否结束

           MOV  SUM，AX

           MOV  AH，4CH

           INT  21H

CODE   ENDS

       END  START  

将该程序变成简化段定义并运行调试，查看寄存器和存储单元的值，验证结果是否正确。

（2）编程实现 S=1＋2×3＋3×4＋…＋N×(N＋1)＋…直到N×(N＋1)项大于200为止。

（3）编写程序：从键盘接收一个小写字母，然后找出它的前导字符和后续字符，并按顺序输出这三个字符。

（4）编写一个程序，判别键盘上输入的字符；若是1-9字符，则显示之；若为A-Z或a-z字符，均显示“c”；若是回车字符<CR>(其ASCII码为0DH)，则结束程序，若为其它字符则不显示，继续等待新的字符输入。

5.实验报告主要内容：

（1）记录项目1的结果和调试说明。包括上机调试的情况、调试步骤、调试所遇到的问题是如何解决的，并对调试过程中的问题进行分析，对执行结果进行分析。

（2）写出项目2、3、4的源程序清单、程序说明、执行结果，画出相应的程序流程图。
