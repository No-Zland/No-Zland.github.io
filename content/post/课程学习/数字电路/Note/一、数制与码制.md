# 数字电子技术

# 不同进制（二进制 B、八进制 O、十进制 D、十六进制 H）间的转换

## 二进制与十进制转换

### 二进制转十进制：按权展开法（唯一核心方法）

原理：教材第 1.2 节明确，将二进制数的每一位乘以其对应的权值（权值为\(2^n\)，\(n\)为该位从右往左的序号，起始为 0），再将所有乘积相加，结果即为十进制数。

【图片插入建议】：此处可插入教材图 1-2 类示意图，展示二进制数\((1011.01)_B\)的位权分布（从左到右标注\(2^3\)、\(2^2\)、\(2^1\)、\(2^0\)、\(2^{-1}\)、\(2^{-2}\)），并附带计算过程分步标注，直观呈现 “位权 × 数值位→求和” 的逻辑。

示例：将\((1011.01)_B\)转为十进制

计算过程：\(1\times2^3 + 0\times2^2 + 1\times2^1 + 1\times2^0 + 0\times2^{-1} + 1\times2^{-2} = 8 + 0 + 2 + 1 + 0 + 0.25 = (11.25)_D\)

特点：逻辑唯一、无简化空间，是二进制转十进制的 “标准方法”，教材中所有相关例题均采用此方法，必须掌握。

### 十进制转二进制：短除法（整数部分）+ 乘 2 取整法（小数部分）（最简便方法）

教材第 1.2 节指出，十进制整数与小数的二进制转换需分开处理，该方法是教材重点推荐的工程实用方法。

【图片插入建议】：插入教材图 1-3 类流程图，左侧展示整数部分短除法流程（以\((23)_D\)为例，自上而下标注 “23÷2=11 余 1”“11÷2=5 余 1”…“1÷2=0 余 1”，右侧用箭头标注 “余数倒序→10111”）；右侧展示小数部分乘 2 取整法流程（以\((0.625)_D\)为例，自上而下标注 “0.625×2=1.25 取整 1”“0.25×2=0.5 取整 0”…“0.5×2=1.0 取整 1”，右侧箭头标注 “整数顺序→0.101”），清晰呈现两步转换的差异。

- 整数部分（短除法）：将十进制整数反复除以 2，记录每次的余数（余数为 0 或 1），直到商为 0，最后将余数从后往前排列，即为二进制整数。

示例：将\((23)_D\)转为二进制

计算过程：\(23\div2=11\)余 1，\(11\div2=5\)余 1，\(5\div2=2\)余 1，\(2\div2=1\)余 0，\(1\div2=0\)余 1 → 余数倒序为\((10111)_B\)。

- 小数部分（乘 2 取整法）：将十进制小数反复乘以 2，记录每次整数部分（0 或 1），直到小数部分为 0 或达到精度要求，最后将整数部分从前往后排列，即为二进制小数。

示例：将\((0.625)_D\)转为二进制

计算过程：\(0.625\times2=1.25\)取整 1，\(0.25\times2=0.5\)取整 0，\(0.5\times2=1.0\)取整 1 → 整数顺序为\((0.101)_B\)。

## 二进制与八进制 / 十六进制转换

教材第 1.2 节强调，二进制与八、十六进制的转换基于 “2 的幂次关联”（8=2³，16=2⁴），分组法是最高效的转换方式，无需经过十进制过渡。

### 二进制转八进制：3 位分组法（最简便）

原理：八进制基数为 8（\(2^3\)），因此将二进制数从右往左每 3 位分为一组（整数部分），从左往右每 3 位分为一组（小数部分），不足 3 位补 0，再将每组 3 位二进制数对应转为 1 位八进制数（0-7）。

【图片插入建议】：插入教材表 1-2 衍生示意图，左侧为二进制数\((110101.01)_B\)的分组过程（用竖线分隔 “110 | 101 . 010”，标注 “整数补 0 前导”“小数补 0 末尾”），右侧为 “3 位二进制→八进制” 对应表（如 000=0、001=1…111=7），并在分组下方标注每组对应的八进制数 “6 | 5 . 2”，最终指向结果\((65.2)_O\)。

示例：将\((110101.01)_B\)转为八进制

分组：整数部分\(110\ 101\)，小数部分\(010\)（补 1 个 0）→ 每组对应：\(110=6\)，\(101=5\)，\(010=2\) → 结果为\((65.2)_O\)。

### 二进制转十六进制：4 位分组法（最简便）

原理：十六进制基数为 16（\(2^4\)），因此将二进制数从右往左每 4 位分为一组（整数部分），从左往右每 4 位分为一组（小数部分），不足 4 位补 0，再将每组 4 位二进制数对应转为 1 位十六进制数（0-9，A-F）。

【图片插入建议】：插入与八进制转换对应的对比示意图，左侧为二进制数\((110101.01)_B\)的 4 位分组（“0011 | 0101 . 0100”，标注补 0 位置），右侧为 “4 位二进制→十六进制” 对应表（0000=0…1001=9，1010=A…1111=F），分组下方标注 “3 | 5 . 4”，最终指向\((35.4)_H\)，突出两种分组法的差异与共性。

示例：将\((110101.01)_B\)转为十六进制

分组：整数部分\(0011\ 0101\)（补 2 个 0），小数部分\(0100\)（补 2 个 0）→ 每组对应：\(0011=3\)，\(0101=5\)，\(0100=4\) → 结果为\((35.4)_H\)。

### 八进制 / 十六进制转二进制：按位展开法（最简便）

原理：与二进制转八 / 十六进制相反，将八进制（或十六进制）的每一位，直接对应转为 3 位（或 4 位）二进制数，不足位数补 0，最后去掉整数部分前导 0 和小数部分末尾 0（如需简化）。

【图片插入建议】：插入教材例题式对比图，上半部分为八进制\((65.2)_O\)转二进制（6→110，5→101，2→010，合并为 “110 101 . 010”），下半部分为十六进制\((35.4)_H\)转二进制（3→0011，5→0101，4→0100，合并为 “0011 0101 . 0100”），中间用箭头标注 “去前导 / 末尾 0→110101.01”，呼应前文转换结果，形成闭环。

示例 1：\((65.2)_O\)转二进制 → 6=110，5=101，2=010 → 合并为\((110101.010)_B = (110101.01)_B\)。

示例 2：\((35.4)_H\)转二进制 → 3=0011，5=0101，4=0100 → 合并为\((00110101.0100)_B = (110101.01)_B\)。

## 八进制 / 十六进制与十进制转换

### 八进制 / 十六进制转十进制：按权展开法（核心方法）

原理：教材第 1.2 节明确，类比二进制转十进制，将八进制（或十六进制）每一位乘以权值（八进制权值\(8^n\)，十六进制权值\(16^n\)），再求和，权值的定义与二进制一致（\(n\)为位序号，从右往左起始为 0）。

【图片插入建议】：插入教材图 1-4 类位权示意图，以十六进制\((3A.8)_H\)为例，标注每一位的权值（3 对应\(16^1\)，A 对应\(16^0\)，8 对应\(16^{-1}\)），并分步标注计算过程（\(3×16=48\)，\(10×1=10\)，\(8×0.0625=0.5\)，求和→58.5），直观呈现非二进制数的权值运算逻辑。

示例：\((3A.8)_H\)转十进制 → \(3×16^1 + 10×16^0 + 8×16^{-1} = 48 + 10 + 0.5 = (58.5)_D\)。

### 十进制转八进制 / 十六进制：短除法（整数）+ 乘 R 取整法（小数，R=8/16）（最简便）

原理：教材第 1.2 节指出，该方法是十进制转二进制的延伸，仅将除数 / 乘数改为 8（或 16），余数 / 整数部分对应八进制（0-7）或十六进制（0-9，A-F），需注意十六进制中 10-15 用字母 A-F 表示。

【图片插入建议】：插入十进制转十六进制的短除法流程图（以\((58)_D\)为例），自上而下标注 “58÷16=3 余 10（A）”“3÷16=0 余 3”，右侧用箭头标注 “余数倒序→3A”，并在图下方补充 “十六进制余数对应表”（10=A、11=B…15=F），解决 “余数大于 9” 的表示问题，与十进制转二进制的流程图形成方法迁移。

示例：\((58)_D\)转十六进制 → \(58\div16=3\)余 10（A），\(3\div16=0\)余 3 → 结果为\((3A)_H\)。

# 补码运算的原理、实现与应用

教材第 1.3 节强调，补码是解决带符号数（正、负数）运算的核心机制，可将减法运算转化为加法运算，简化电路设计（仅需加法器即可实现加减运算），是数字系统中带符号数运算的标准方式。

## 补码运算的核心原理

### 模（Modulus）的概念

教材定义 “模” 为计量系统的计数范围，例如 4 位二进制数的模为\(2^4=16\)（计数范围 0-15），n 位二进制数的模为\(2^n\)。补码的本质是利用 “模运算” 实现 “减法→加法” 的转换：

对于模为 M 的系统，若\(a - b = a + (M - b)\)（mod M），则称\((M - b)\)为 b 的 “补码”，即减法运算可转化为 “被减数 + 减数的补码”。

【图片插入建议】：插入教材图 1-6 类 “模运算示意图”，以 4 位二进制数（模 = 16）为例，用圆环表示计数范围（0-15 顺时针排列），标注 “\(5 - 3 = 2\)” 与 “\(5 + 13 = 18 ≡ 2\)（mod 16）”，直观展示 “\(M - b = 16 - 3 = 13\)”，即 “-3 的补码为 13”，验证模运算下减法与加法的等价性。

### 带符号数的补码表示

教材第 1.3 节明确，在 n 位二进制补码系统中，最高位为符号位（0 表示正数，1 表示负数），其余为数值位，补码定义如下：

【图片插入建议】：插入教材表 1-4 “n 位补码表示规则表”，分两列呈现正数与负数的补码规则，左侧列标注 “正数（符号位 0）”，对应 “补码 = 原码（符号位 + 数值位）”，示例 “+3（4 位）：原码 0011→补码 0011”；右侧列标注 “负数（符号位 1）”，对应 “补码 = 符号位 1 +（原码数值位反码 + 1）”，示例 “-3（4 位）：原码 1011→反码 1100→补码 1101”，并用红色字体标注 “反码：数值位按位取反”，明确关键步骤。

- 正数的补码：与原码（符号位 + 数值位）相同。

示例：4 位二进制中，\((+3)_D\)的原码为\(0011\)，补码也为\(0011\)。

- 负数的补码：符号位为 1，数值位为原码数值位的 “反码 + 1”（反码：数值位按位取反）。

示例：4 位二进制中，\((-3)_D\)的原码为\(1011\)，反码为\(1100\)，补码为\(1100 + 1 = 1101\)。

### 补码运算的核心规则

教材第 1.3 节给出补码运算的两大核心规则，是后续运算实现的基础：

【图片插入建议】：插入教材式规则说明图，用蓝色边框框出两条核心规则，第一条 “运算公式：\([X \pm Y]_补 = [X]_补 + [\pm Y]_补\)”，下方标注 “注：减法运算中，\([-Y]_补\)是\([Y]_补\)的‘求补’（符号位和数值位均取反后加 1）”；第二条 “溢出判断：当运算结果的符号位与数值位进位矛盾时，产生溢出”，下方用示例 “4 位补码：\(+7(0111) + +1(0001) = 1000\)（符号位 1，实际为 - 8，溢出）” 辅助说明，并标注 “进位矛盾：数值位向符号位有进位，符号位无进位输出”，明确溢出判断的关键观察点。

- 运算公式：\([X \pm Y]_补 = [X]_补 + [\pm Y]_补\)（减法运算中，\([-Y]_补\)是\([Y]_补\)的 “求补”，即符号位和数值位均取反后加 1）。

- 溢出判断：当运算结果的符号位与数值位进位矛盾时，产生溢出（例如 4 位补码中，\(+7(0111) + +1(0001) = 1000\)，符号位从 0 变 1，实际结果为 - 8，属于溢出）。

## 补码运算的实现步骤

\(Y\)” 运算（转化为\(X + (-Y)\)）为例，实现步骤如下（承接前文）：

### 步骤 1：确定补码位数 n（根据精度需求）

教材第 1.3 节指出，补码位数 n 需根据数字系统的动态范围确定，通常取 8 位、16 位或 32 位（如 8 位补码的表示范围为\(-2^7\)~\(2^7 - 1\)，即 - 128~+127），此处以教材常用的 8 位补码为例展开。

### 步骤 2：求\([X]_补\)和\([-Y]_补\)

教材强调，求补码需先区分正负，再按规则计算，具体如下：

- 若 X 为正数：\([X]_补 = 0 + X\)的 7 位二进制数值（符号位固定为 0，数值位不足 7 位时，高位补 0）。

示例：\(X = +12\)（十进制），7 位二进制数值为\(0001100\)，则\([X]_补 = 00001100\)。

- 若 X 为负数：\([X]_补 = 1 + (|X|\)的 7 位反码 + 1\()\)（符号位固定为 1，先对绝对值的 7 位数值取反，再加 1 得到数值位）。

示例：\(X = -12\)（十进制），\(|X|=12\)的 7 位二进制为\(0001100\)，反码为\(1110011\)，加 1 后为\(1110100\)，则\([X]_补 = 11110100\)。

- 求\([-Y]_补\)：教材明确 “\([-Y]_补\)是\([Y]_补\)的‘对补’”，即对\([Y]_补\)的符号位和 7 位数值位同时按位取反，再整体加 1（区别于负数补码的 “仅数值位取反加 1”）。

示例：若\([Y]_补 = 00001100\)（\(Y=+12\)），则\([-Y]_补\)的计算过程为：取反得\(11110011\)，加 1 得\(11110100\)。

【图片插入建议】：插入教材例题式步骤分解图，以 “求\(X=-12\)的 8 位补码” 和 “由\(Y=+12\)的补码求\([-Y]_补\)” 为两个子图，左侧子图标注 “负数补码计算”，分步展示 “\(|X|=12→0001100\)（7 位数值）→反码\(1110011\)→加 1 得\(1110100\)→符号位 1 + 数值位→\(11110100\)”；右侧子图标注 “对补计算”，分步展示 “\([Y]_补=00001100\)→全位取反\(11110011\)→加 1 得\(11110100\)”，用红色箭头标注两者的差异（“仅数值位取反” vs “全位取反”），避免混淆。

### 步骤 3：执行补码加法运算

教材第 1.3 节强调，补码加法需遵循 “二进制加法规则”，且符号位参与运算，若运算结果超过 8 位（即产生进位），则直接舍弃最高位的进位（因补码运算基于模\(2^8=256\)，进位属于 “模外数值”，不影响结果）。

示例：8 位补码计算\(5 - 3\)（即\(5 + (-3)\)）

- 第一步：确定\([5]_补\)和\([-3]_补\)

\(5\)为正数，7 位数值为\(0000101\)，故\([5]_补 = 00000101\)；

\(3\)的补码为\(00000011\)，对补后得\([-3]_补 = 11111101\)。

- 第二步：加法运算

\(00000101 + 11111101 = 100000010\)（9 位），舍弃最高位进位 “1”，最终结果为\(00000010\)（8 位）。

【图片插入建议】：插入二进制加法竖式图，标注 “补码加法（含符号位）”，竖式中上下两行分别为\([5]_补=00000101\)和\([-3]_补=11111101\)，中间用横线分隔，下方标注计算过程（从最低位开始：\(1+1=10\)写 0 进 1，\(0+0+1=1\)… 最高位\(0+1+1=10\)写 0 进 1），最后用红色方框标注 “舍弃进位 1，结果为\(00000010\)”，直观呈现进位处理规则。

### 步骤 4：将运算结果还原为十进制数

教材指出，需根据结果补码的符号位判断正负，再按规则还原：

- 若符号位为 0（结果为正数）：直接对 7 位数值位按权展开，得到十进制数。

示例：结果补码为\(00000010\)，符号位 0，数值位\(0000010\)，按权展开得\(2\)，即十进制结果为\(+2\)。

- 若符号位为 1（结果为负数）：需对 7 位数值位 “取反加 1”，得到绝对值的二进制，再按权展开后加负号。

示例：若结果补码为\(11110100\)，符号位 1，数值位\(1110100\)，取反得\(0001011\)，加 1 得\(0001100\)（即 12），则十进制结果为\(-12\)。

【图片插入建议】：插入结果还原对比图，左侧为 “正数结果还原”（\(00000010\)→符号位 0→数值位\(0000010\)→\(2\)），右侧为 “负数结果还原”（\(11110100\)→符号位 1→数值位取反加 1→\(0001100\)→\(-12\)），用绿色箭头标注正数的 “直接展开” 路径，红色箭头标注负数的 “取反加 1→展开→加负号” 路径，清晰区分两种还原逻辑。

## 补码运算的典型应用

教材第 1.3 节及后续章节（如第 4 章 “组合逻辑电路”）多次提及补码运算的工程价值，核心应用场景如下：

### 计算机算术逻辑单元（ALU）设计

教材第 4.5 节指出，ALU 是计算机的核心运算部件，补码的核心优势在于 “将减法转化为加法”，使 ALU 仅需集成加法器即可实现 “加、减” 两种运算，无需额外设计减法器（减法器电路复杂且成本高）。例如，8 位 ALU 中，当执行 “\(A - B\)” 时，实际逻辑为 “\([A]_补 + [-B]_补\)”，仅通过加法器和 “对补模块” 即可完成，大幅简化电路结构、降低功耗并提高运算速度。

【图片插入建议】：插入教材图 4-23 类 ALU 简化结构图，左侧标注 “输入”（\(A\)、\(B\)），中间模块标注 “对补电路”（将\(B\)转为\([-B]_补\)）和 “8 位加法器”（接收\([A]_补\)和\([-B]_补\)），右侧标注 “输出”（运算结果），用箭头标注 “\(A - B\)→\([A]_补 + [-B]_补\)” 的逻辑流向，并对比 “无补码时需加法器 + 减法器” 的复杂结构，突出补码的简化作用。

### 嵌入式系统数值处理

教材在 “单片机应用” 相关章节（如附录）中提到，嵌入式系统（如 51 单片机、STM32）的传感器数据（如温度、压力）常以 “带符号二进制数” 形式存储（如温度可能为\(-20℃\)~\(80℃\)），补码是处理这类数据的标准格式：

- 数据存储：8 位单片机中，带符号数默认以补码形式存在（如\(-12℃\)存储为\(11110100\)），避免 “正负零” 问题（原码存在\(+0\)和\(-0\)，补码仅\(00000000\)一种表示）。

- 数据运算：例如 “温度差值计算（当前温度 - 基准温度）”，直接通过补码加法实现，无需额外处理符号位，运算效率高。

### 数字通信系统数据传输

教材第 7 章 “数字通信基础” 指出，数字通信中基带信号常以二进制补码形式编码，原因如下：

- 符号明确：补码的符号位（最高位）可直接表示数据正负，接收端无需额外解码即可判断数据极性（如传输 “-5” 的补码\(11111011\)，接收端见最高位 1 即知为负数）。

- 误码检测：通信中常通过 “补码求和校验” 检测误码，例如发送端将一组数据的补码相加得到 “校验和”，接收端重复计算，若结果不一致则判定误码，补码运算的规律性可提高校验准确性。
