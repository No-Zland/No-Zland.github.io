### 一、C++基础语法与程序结构

#### 知识点总结

1. **C与C++关键字区别**：部分关键字为C++特有（如`inline`、`private`、`public`），部分为两者共通（如`break`）。

2. **输入输出**：`cin >>`读取字符串时以空白字符（空格、Tab、Enter）为分隔符；`cout`可使用`endl`或`'\n'`换行。

3. **程序运行步骤**：编辑（编写代码）→编译（生成目标文件）→连接（合并目标文件与库文件）→运行（执行可执行文件）。

4. **注释**：C++支持`//`（单行注释）和`/*...*/`（多行注释），后者也可在C++中使用。

### 二、指针与数组

#### 知识点总结

1. **指针与数组关系**：数组名隐式转换为指向首元素的指针；`&a`表示整个数组的地址（类型为指向数组的指针），与指向首元素的指针类型不同。

2. **指针操作**：指针可赋值为数组首元素地址（`p = a`或`p = &a[0]`），但不能直接赋值为整个数组的地址（`p = &a`）。

### 三、函数

#### 知识点总结

1. **函数原型**：声明时需包含函数类型、函数名、参数类型，无需返回值表达式；C++要求为每个函数建立原型，C语言仅建议。

2. **函数调用方式**：

- 传值调用：实参将值传递给形参，形参修改不影响实参。

- 引用调用：形参为引用类型（如`int &x`），实参为变量名，形参操作直接作用于实参。

- 指针调用：形参为指针，实参为地址，通过指针间接修改实参。

3. **函数重载**：多个函数同名，通过参数个数、类型区分，与函数返回类型无关，目的是提高可读性和使用方便性。

4. **默认参数**：需从最右侧参数开始定义，调用时缺少参数则使用最右侧默认值。

5. **内联函数**：函数体内不能包含过多或复杂语句（如循环、switch等）。

### 四、变量与常量

#### 知识点总结

1. **变量作用域与存储**：

- 局部变量：若不初始化，其值为随机值；函数调用结束后销毁（静态局部变量除外，其值保留）。

- 全局变量：若不初始化，系统默认值为0；可被多个函数访问，局部变量可隐藏全局变量，通过作用域运算符`::`访问全局变量。

2. **常量**：C++中用`const`声明常量，占用存储单元且不可修改；C语言用`#define`（预处理替换，不占存储）。

题目：

```
编写一个C++程序，使用new运算符动态分配一个整数数组，该程序应该能够让用户通过键盘输入数组的大小，并动态地分配相应大小的数组空间，然后通过键盘输入数组数据，并对该数组排序，最后输出排序后的数组元素。

```

回答：

```

需编写符合要求的C++程序。

```

参考答案：

```cpp

#include <iostream>

using namespace std;

void sortArray(int* arr, int size);

int main() {

int size;

int* arr;

cout << "Enter the size of the array: ";

cin >> size;

// 动态分配内存

arr = new int[size];

if (!arr) {

cerr << "Invalid input. Please enter a valid number." << endl;

return 1;

}

// 填充数组

cout << "Enter " << size << " integers:" << endl;

for (int i = 0; i < size; ++i) {

cin >> arr[i];

}

// 排序数组

sortArray(arr, size);

// 打印数组

cout << "The sorted array contains:" << endl;

for (int i = 0; i < size; ++i) {

cout << arr[i] << " ";

}

cout << endl;

// 释放内存

delete[] arr;

return 0;

}

void sortArray(int* arr, int size) {

for (int i = 0; i < size - 1; ++i) {

for (int j = 0; j < size - i - 1; ++j) {

if (arr[j] > arr[j + 1]) {

int temp = arr[j];

arr[j] = arr[j + 1];

arr[j + 1] = temp;

}

}

}

}

```

答案解析：

```

程序首先让用户输入数组大小，使用new运算符动态分配对应大小的int数组。然后接收用户输入的数组元素，调用sortArray函数（采用冒泡排序算法）对数组排序，排序完成后输出数组元素，最后用delete[]释放动态分配的内存，避免内存泄漏。整个过程实现了动态内存管理、数组输入、排序和输出的功能。

```
