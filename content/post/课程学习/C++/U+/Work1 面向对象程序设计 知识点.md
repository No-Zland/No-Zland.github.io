# 面向对象程序设计核心知识点总结

## 1. 面向对象程序设计基础

- **定义**：面向对象程序设计是一种新的软件系统设计方法，通过类和对象的概念，将数据和操作数据的方法封装在一起，以更好地模拟现实世界的实体及其交互。

- **与面向过程的区别**：C++通过引进类和对象的概念，从面向过程编程转变为面向对象编程，这是对C语言的重要改进。

- **C++语言发展**：起源于C语言，最初被称为“带类的C”，1983年被命名为C++。

- **C++程序执行**：C++程序总是从`main`函数开始执行。

- **C++函数特性**：支持函数重载和默认参数，函数说明必须有原形，有调用关系的函数不一定在同一个程序文件中，函数可以没有返回值（返回类型为`void`）。

- **C++语言特点**：具有简洁、高效和接近汇编语言的特点，不是纯面向对象语言，支持面向对象程序设计，有支持代码重用的语言结构。

## 2. 面向对象的主要特征

- **封装**：将一组数据和与这组数据有关的操作组装在一起形成对象，尽可能隐藏对象的内部细节，通过访问权限修饰符（`public`、`private`、`protected`）控制属性和方法的可见性。`private`属性仅类内部可访问，`public`属性可被外部直接访问，`protected`属性仅类内部和子类可访问。

- **继承**：类之间复用代码、构建层次结构的机制，使子类能共享父类的特征，同时可以有自己的差别或新增部分。类间具有共享特征、差别或新增部分、层次结构等特性。

- **多态**：不同的对象收到相同的消息时产生不同的行为方式。C++支持两种多态性，编译时的多态性通过重载实现，运行时的多态性通过虚函数实现。

## 3. 类与对象

- **类**：是具有相同数据和相同操作的一组对象的集合，是对象的抽象模板，用于描述一组对象的共同属性和行为，是创建对象的样板，是抽象数据类型的实现。

- **对象**：是类的实例，代表系统中的一个实体，是状态（属性）和操作（方法）的封装体，对象有地址，即存储其数据成员单元的首地址。对象之间通过消息通信。

- **类与对象的关系**：类是多个对象的抽象结果，对象是类的具体实例，是抽象和具体的关系。

- **类与结构体的区别**：C++中`class`默认私有（成员/继承），`struct`默认公有；`struct`适合纯数据聚合，`class`适合面向对象设计，手动指定权限后功能可替代，但语义不同。

## 4. 消息与方法

- **消息**：一个对象向另一个对象发出的请求，用于对象之间的通信。发送者只需关注消息接口，无需了解接收者的内部实现。在C++中，消息的发送体现为对接收对象成员函数的调用。

- **方法**：对象所能实现的行为（操作），在C++中通过成员函数实现，当对象接收消息时，调用相应方法执行操作。
