# （选择题）第1题
题目：
```
下列叙述中,不正确的是哪项?()
```
选项：
```
A、this指针是指向当前调用成员函数的对象的指针
B、this指针可用于类中非静态的数据成员和函数成员
C、this指针破坏了类的封装性
D、this指针的类型与所指对象的类型相同
```
参考答案：
```
C
```
答案解析：
```
this指针是C++类成员函数中**隐含的指针参数**，具有以下核心特点：
1. **自动传递**：调用类的非静态成员函数时，编译器会自动将“当前对象的地址”作为this指针传递给函数。
2. **作用范围**：仅在类的非静态成员函数内部可用，指向“当前调用该函数的对象”。
3. **用途**：用于区分成员变量与 局部变量（如`this->num = num`）、在成员函数中返回当前对象（如`return *this`）等。
4. **类型**：其类型为“类类型的指针”（如类`Person`的this指针类型是`Person*`）。
```

# （选择题）第2题
题目：
```
关于this指针的说法正确的是下列哪项?()
```
选项：
```
A、this指针必须显式说明
B、定义一个类后,this指针就指向该类
C、成员函数拥有this指针
D、静态成员函数拥有this指针
```
参考答案：
```
C
```
答案解析：
```
`this`指针是C++类成员函数中的一个**隐式指针**，其核心作用是**指向当前调用成员函数的==对象==**，主要功能包括：
1. **标识当前对象**
   当类的成员函数被调用时，`this`自动指向调用该函数的对象，用于区分“当前对象”的成员（避免与函数参数/局部变量重名）。
   例如：
   ```cpp
   class Person {
   private:
       string name;
   public:
       void setName(string name) {
           this->name = name; // this->name 表示当前对象的name成员
       }
   };
2. **访问类的非静态成员**
   `this`指针只能用于类的**非静态数据成员和成员函数**（静态成员属于类而非对象，无`this`指针），通过`this`可以访问当前对象的所有非静态成员。
3. **返回当前对象自身**
   在成员函数中，可通过`return *this;`返回当前对象的引用（常用于链式调用），例如：
   ```cpp
   class Calc {
   private:
       int val;
   public:
       Calc(int v) : val(v) {}
       Calc& add(int num) {
           val += num;
           return *this; // 返回当前对象，支持链式调用
       }
   };
   // 使用：calc.add(2).add(3);
4. **区分对象的成员与局部变量**
   当成员函数的参数名与类的成员名相同时，`this`是区分两者的关键（如上述`setName`的例子）。
需要注意：
- `this`指针是**隐式存在**的，不需要手动定义，会自动传递给非静态成员函数；
- `this`指针不会破坏类的封装性（它是类内部的机制，仅在成员函数中访问自身成员）；
- `this`的类型是“指向当前类类型的指针”（与所指对象的类型一致）。
   ```

# （选择题）第3题
题目：
```
下列关于对象数组的描述中,错误的是哪项?()
```
选项：
```
A、对象数组的下标是从0开始的
B、对象数组的数组名是一个常量指针
C、对象数组的每一个元素是同一个类的对象
D、对象数组只能被赋值,而不能被取值
```
参考答案：
```

```
答案解析：
```
- **选项A**：C++中数组下标默认从0开始，对象数组也遵循此规则，表述正确。
- **选项B**：数组名本质是指向数组首元素的常量指针（不能修改指向），对象数组的数组名也符合这一特性，表述正确。
- **选项C**：对象数组是“同一类的多个对象组成的数组”，每个元素都是该类的对象，表述正确。
- **选项D**：对象数组的元素是对象，既可以被赋值（如`arr[0] = obj`），也可以被取值（如`obj = arr[0]`），表述错误。
**什么是对象数组？**
对象数组是**由同一类的多个对象组成的数组**，是“数组”与“类对象”的结合体：
1. **本质**：以类的对象为元素的数组，语法格式为`类名 数组名[元素个数]`（如`Person stu[3];`表示创建包含3个`Person`类对象的数组）。
2. **特性**：
   - 每个元素都是该类的对象，==会调用类的构造函数初始化==；
   - 遵循数组的通用规则（下标从0开始、数组名是常量指针等）；
   - 可以通过下标访问单个对象，进而调用其成员函数或访问成员变量（如`stu[0].showInfo();`）。
```

# （选择题）第6题
题目：
```
已知example是已定义的类,则程序结束前,共存在几个对象?()
#include<example.h>
main()
{ example x(5);
  example arr[2]={1,2};
  x.print();
}
```
选项：
```
A、2
B、3
C、4
D、7
```
参考答案：
```
B
```
答案解析：
```
一个是对象，一个是对象数组，
在C++类中，构造函数是用于**对象初始化**的核心方法，除此之外，类还包含多种不同用途的成员方法（函数），按功能可分为以下大类，结合示例帮你清晰理解：
### 一、类的核心方法（除构造函数外）
#### 1. 析构函数 —— 释放对象资源
- **作用**：对象销毁时自动调用，释放对象占用的资源（如动态内存、文件句柄）；
- **语法**：`~类名()`，无返回值、无参数、不能重载；
- **示例**：
  ```cpp
  class Example {
  private:
      int* ptr; // 动态内存指针
  public:
      // 构造函数：分配内存
      Example(int val) { ptr = new int(val); }
      // 析构函数：释放内存
      ~Example() { delete ptr; } 
  };
#### 2. 拷贝构造函数 —— 用已有对象初始化新对象
- **作用**：创建对象时，用同类已有对象“拷贝”初始化新对象（如`Example a = b;`）；
- **语法**：`类名(const 类名 &obj)`，参数必须是类的引用（避免递归调用）；
- **示例**：
  ```cpp
  Example(const Example &other) {
      // 深拷贝：重新分配内存，避免浅拷贝导致的资源重复释放
      ptr = new int(*(other.ptr)); 
  }
  #### 3. 赋值运算符重载 —— 给已有对象赋值
- **作用**：对已存在的对象，用另一个对象的值“赋值”（如`a = b;`，区别于拷贝构造的“初始化”）；
- **语法**：`类名& operator=(const 类名 &obj)`，通常返回自身引用以支持链式赋值；
- **示例**：
  ```cpp
  Example& operator=(const Example &other) {
      if (this == &other) return *this; // 防止自赋值
      delete ptr; // 释放当前对象原有资源
      ptr = new int(*(other.ptr)); // 拷贝新值
      return *this;
  }
  #### 4. 普通成员方法 —— 实现对象的核心功能
- **作用**：操作类的成员变量，实现对象的业务逻辑（如计算、打印、修改属性）；
- **分类**：
  - 非静态成员方法：隐含`this`指针，必须通过对象调用，可访问所有成员（public/protected/private）；
  - 静态成员方法：用`static`修饰，无`this`指针，属于类而非对象，只能访问静态成员；
- **示例**：
  ```cpp
  class Student {
  private:
      string name;
      int score;
      static int total; // 静态成员：所有学生共享
  public:
      // 非静态方法：修改当前对象属性
      void setScore(int s) { score = s; } 
      // 静态方法：统计学生总数（无需对象）
      static void addTotal() { total++; } 
  };
  #### 5. 常成员方法 —— 保证不修改对象状态
- **作用**：声明为`const`的方法，承诺不会修改对象的成员变量（只读操作）；
- **语法**：`返回值 方法名(参数) const;`；
- **示例**：
  ```cpp
  // 常方法：仅读取分数，不修改
  int getScore() const { return score; } 
#### 6. 移动构造/移动赋值 —— 高效转移资源（C++11+）
- **作用**：针对“临时对象”（如函数返回值），直接转移其资源（而非拷贝），提升性能；
- **语法**：
  ```cpp
  // 移动构造
  Example(Example &&other) noexcept {
      ptr = other.ptr; 
      other.ptr = nullptr; // 避免临时对象析构时释放资源
  }
  // 移动赋值
  Example& operator=(Example &&other) noexcept {
      if (this == &other) return *this;
      delete ptr;
      ptr = other.ptr;
      other.ptr = nullptr;
      return *this;
  }
  
### 二、其他特殊方法
#### 1. 友元函数/友元类 —— 突破封装（慎用）
- **作用**：让外部函数/类直接访问类的私有/保护成员；
- **语法**：用`friend`声明，不属于类的成员方法，但能访问类的所有成员；
- **示例**：
  ```cpp
  friend void printScore(const Student &stu) {
      // 直接访问私有成员score
      cout << stu.score << endl; 
  }
#### 2. 虚函数/纯虚函数 —— 实现多态
- **作用**：基类声明虚函数，派生类重写，调用时根据对象实际类型执行对应版本（多态核心）；
- **纯虚函数**：`virtual 返回值 方法名() = 0;`，无实现，包含纯虚函数的类为抽象类，不能实例化；
- **示例**：
  ```cpp
  class Shape {
  public:
      // 纯虚函数：抽象方法，派生类必须实现
      virtual double area() const = 0; 
  };
  class Circle : public Shape {
  private:
      double r;
  public:
      // 重写纯虚函数
      double area() const override { return 3.14 * r * r; } 
  };
### 三、核心方法对比表
| 方法类型       | 核心作用                  | 关键特征                          |
|----------------|---------------------------|-----------------------------------|
| 构造函数       | 初始化对象                | 与类同名、无返回值、可重载        |
| 析构函数       | 释放对象资源              | ~类名、无参数、不能重载           |
| 拷贝构造       | 用已有对象初始化新对象    | 参数为类的const引用               |
| 赋值重载       | 给已有对象赋值            | 返回自身引用、防止自赋值          |
| 普通成员方法   | 实现对象业务逻辑          | 可访问所有成员（静态/非静态）     |
| 常成员方法     | 只读操作，不修改对象      | 末尾加const                       |
| 静态成员方法   | 操作类的静态成员          | static修饰、无this指针            |
| 虚函数         | 实现多态                  | virtual修饰、派生类可重写         |

### 通俗总结
- 构造函数：“创建对象时搭骨架、赋初始值”；
- 析构函数：“销毁对象时清垃圾、释资源”；
- 拷贝/移动构造：“用现成对象快速造新对象”；
- 普通方法：“对象能做的具体事（如查成绩、算面积）”；
- 虚函数：“不同子类对象做同一件事，有不同做法”。

这些方法共同构成类的完整行为，结合数据成员实现面向对象的封装、继承、多态三大特性。

```
下列要以 对象或对象的引用 作为参数的是哪项?()
```
选项：
```
A、析构函数
B、类的友元函数
C、构造函数
D、静态成员函数
```

```

```

```
- **选项A（析构函数）**：析构函数的语法是`~类名()`，**无参数**，因此不可能以对象/对象引用为参数。
- **选项B（类的友元函数）**：友元函数不是类的成员函数，若要访问类的成员（尤其是私有/保护成员），**必须通过“对象或对象引用”作为参数传入**（否则无法关联到具体对象），因此符合要求。
- **选项C（构造函数）**：构造函数是创建对象时调用的，参数是用于初始化对象的“数据值”（如`int`、`string`等），**不是对象/对象引用**（拷贝构造函数是特例，但题目未限定普通构造函数，且选项B更符合）。
- **选项D（静态成员函数）**：静态成员函数属于类，**无`this`指针**，仅能访问静态成员，不需要（也不依赖）对象/对象引用作为参数。
综上，只有类的友元函数需要以对象或对象引用作为参数。
```

#include <iostream>
#include <cmath>
using namespace std;

class Point {
private:
   double x, y;
public:
   // 构造函数
   Point(double x_val, double y_val) : x(x_val), y(y_val) {}
   // 成员函数 display()
   void display() const {
       cout << "(" << x << ", " << y << ")" << endl;
    }
   // 声明友元函数 distance()
   friend double dist(const Point& p1, const Point& p2);
};

// 友元函数 distance() 的定义
double dist(const Point& p1, const Point& p2) {
   double dx = p1.x - p2.x;
   double dy = p1.y - p2.y;
   return sqrt(dx * dx + dy * dy);
}

int main() {
   // 创建两个点对象
   Point p1(3.0, 4.0);
   Point p2(6.0, 8.0);
   // 显示点的坐标
   p1.display();
   p2.display();
   // 计算并显示两点之间的距离
   cout << "Distance between points: " << dist(p1, p2) << endl;
   return 0;
}

#include <iostream>
#include <string>
using namespace std;

class Date {
private:
    int year, month, day;
public:
    // 构造函数
    Date(int y, int m, int d) : year(y), month(m), day(d) {}
    // 成员函数 display()
    void display() {
        cout << year << "-" << month << "-" << day << endl;
    }
};

class Event {
private:
    string name;
    Date date;
public:
    // 构造函数
    Event(string n, Date d) : name(n), date(d) {}
    // 成员函数 display()
    void display() {
        cout << "Event: " << name << "  ";
        date.display();
        cout << endl;
    }
};

int main() {
    // 创建日期对象
    Date date(2024, 10, 27);
    // 创建事件对象
    Event event("做作业", date);
    // 显示事件信息
    event.display();
    return 0;
}
