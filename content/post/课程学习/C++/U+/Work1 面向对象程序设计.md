# （选择题）第5题
题目：
```
下面关于类概念的描述中，哪项是错误的？（）
```
选项：
```
A、类是抽象数据类型的实现
B、类是具有共同行为的若干对象的统一描述体
C、类是创建对象的样板
D、类就是C语言中的结构体类型
```
参考答案：
```
D
```
答案解析：
```
1. **核心差异**：`struct`默认公有（成员 / 继承），`class`默认私有，这是二者最本质的区别；
2. **语义定位**：`struct`适合纯数据聚合（如存储坐标`struct Point {int x,y;}`），`class`适合面向对象设计（封装行为和数据）；
3. **功能等价**：手动指定权限后，二者可以互相替代，但遵循语义约定能让代码更易读。
```

# （选择题）第10题
题目：
```
关于封装，下列说法中不正确的是？（）
```
选项：
```
A、通过封装，对象的全部属性和细节结合在一起，形成一个整体
B、通过封装，一个对象的实现细节被尽可能地隐藏起来（不可见）
C、通过封装，每个对象都成为相对独立的实体
D、通过封装，对象的属性都是不可见的
```
参考答案：
```
D
```
答案解析：
```
在面向对象的封装中，对象的属性（成员变量）可以通过**访问权限修饰符**（`public`、`private`、`protected`）来控制 “是否对外可见”：

- `private`（私有）：属性仅能在类内部访问，外部不可见；
- `public`（公有）：属性可以被类外部直接访问，是**可见的**；
- `protected`（保护）：属性仅能在类内部和子类中访问，外部不可见。
```

```
回答：
```

```
参考答案：
```
在面向对象程序设计中，一个对象向另一个对象发出的请求称为“消息”，消息是一个对象要求另一个对象执行某个操作的规格的说明，通过消息传递才能完成对象之间的相互请求或相互协作。
当对象接收到发向它的消息时，就调用有关的方法，执行相应的操作。
调用对象中的函数就是向该对象传送一个消息，要求该对象实现某一行为（功能、操作）。
对象所能实现的行为（操作），在面向对象程序设计中称为方法，它们是通过调用相应的函数来实现的。
在C++中方法是通过成员函数来实现的。
