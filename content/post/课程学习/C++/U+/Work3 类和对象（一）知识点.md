# 类和对象（一）知识点总结与题目解析

## 一、类的基本结构与访问控制

### 知识点总结

1. **类定义体组成**：类的定义体由数据成员、成员函数以及访问控制信息（`public`/`private`/`protected`）共同构成。其基本语法结构如下：

```cpp

class 类名 {

private: // 私有成员，仅类内可访问

数据成员;

public: // 公有成员，类内和类外可访问

成员函数;

protected: // 保护成员，类内和派生类内可访问

数据成员/成员函数;

};

```

2. **访问权限规则**：

- `private`：私有成员仅能被类的成员函数访问，类外无法通过对象直接访问。

- `public`：公有成员在类内、类外均可通过对象访问，对外完全开放。

- `protected`：保护成员可被类内成员函数及派生类的成员函数访问，但类外无法通过对象访问。

- 默认权限：使用`class`定义的类中，成员的默认访问权限为`private`。

3. **数据成员限制**：

- 数据成员不能是“另一个类”本身（即不能将类作为成员类型），但可以包含其他类的对象作为成员。

- 常量（`const`）和引用（`&`）类型的成员必须通过构造函数初始化表进行赋值，不能在构造函数体内通过赋值语句初始化。

## 二、成员函数特性

### 知识点总结

1. **内联函数（inline）**：

- 类内定义的成员函数默认是内联函数，无需显式添加`inline`关键字。

- 若在类外定义成员函数并希望其为内联函数，需显式添加`inline`关键字，且函数首部需用类名限定（使用作用域限定符`::`）。示例如下：

```cpp

class 类名 {

public:

int getX() { return x; } // 类内定义，默认内联

int getY();

private:

int x, y;

};

inline int 类名::getY() { return y; } // 类外定义为内联

```

2. **类外定义语法**：成员函数在类外定义时，函数首部必须添加`类名::`（作用域限定符），以指定该函数属于哪个类。语法格式为：

```cpp

返回类型 类名::函数名(参数列表) { 函数体 }

```

3. **成员函数特性**：

- 支持重载：即同一个类中可以定义多个同名成员函数，只要它们的参数列表（参数个数、类型或顺序）不同。

- 可设置参数默认值：在函数声明或定义时，可以为参数指定默认值，调用时若未传递对应参数则使用默认值。

- 可声明为静态（`static`）：静态成员函数属于类本身，而非某个对象，可通过类名直接调用。

## 三、构造函数与析构函数

### 知识点总结

1. **构造函数**：

- 形式：构造函数的名字与类名相同，没有返回类型（包括`void`），可以重载（即一个类中可以有多个构造函数，它们的参数列表不同）。

- 调用时机：当创建类的对象时，系统会自动调用构造函数。例如：`Sample s(10);` 会调用带参数的构造函数。

- 特殊类型：

- 默认构造函数：指无参数的构造函数，或所有参数都带有默认值的构造函数。如果用户未定义任何构造函数，编译器会自动生成默认构造函数；若用户定义了其他构造函数，则需手动定义默认构造函数才能无参创建对象。

- 拷贝构造函数：参数为当前类的引用（格式为`类名(类名 &)`），用于对象的复制操作。一个类只能有一个拷贝构造函数。

- 示例：

```cpp

class MyClass {

public:

MyClass() {} // 默认构造函数

MyClass(int val) { x = val; } // 带参构造函数

MyClass(MyClass &other) { x = other.x; } // 拷贝构造函数

private:

int x;

};

```

2. **析构函数**：

- 形式：析构函数的名字为`~类名`，没有返回类型，也没有参数，不能重载（一个类只能有一个析构函数）。

- 调用时机：当对象的生命周期结束时，系统会自动调用析构函数，主要用于释放对象占用的资源（如动态分配的内存）。

- 示例：

```cpp

class MyClass {

private:

int *p;

public:

MyClass() { p = new int; } // 分配动态内存

~MyClass() { delete p; } // 释放动态内存

};

```

3. **初始化表**：

- 用途：用于初始化常量成员（`const`）、引用成员（`&`）以及类类型成员。

- 语法：构造函数名(参数) : 成员1(值1), 成员2(值2) { /* 函数体 */ }

## 四、类与对象的关系

### 知识点总结

- 类是一种用户自定义的数据类型，它描述了具有相同属性（数据成员）和行为（成员函数）的一组对象的抽象。

- 对象是类的实例，是具体存在的实体。一个类可以创建多个对象，这些对象属于该类。

- 同一类的所有对象具有相同的成员（包括数据成员和成员函数），但各个对象的数据成员可以有不同的值。

- 对象的创建和使用遵循“先定义后使用”的原则，如同其他变量一样。

## 五、常见语法细节

### 知识点总结

1. **数据成员赋值限制**：在类的声明中不能直接对数据成员赋值（例如`class A { int x=5; };` 是错误的），必须通过构造函数或类的成员函数在对象创建后进行赋值。

2. **引用参数含义**：在函数参数中，`void func(A &a)` 中的 `A &a` 表示 `a` 是类 `A` 对象的引用（即对象的别名），并非传递对象的地址。使用引用参数可以避免对象的拷贝，提高效率。

3. **作用域与限定符**：类的作用域包含类的所有成员（数据成员和成员函数）的作用域，成员函数可以直接访问类内的成员。当可能出现标识符同名导致歧义时，需要使用作用域限定符 `::` 来指定标识符所属的类（例如 `Sample::x` 表示 `x` 是类 `Sample` 的成员）。
