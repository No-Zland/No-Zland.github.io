# 定义

`main` 函数是 C 程序的**唯一入口点**，由操作系统在程序启动时自动调用，所有用户逻辑均直接或间接在 `main` 中执行；程序执行完 `main` 后，返回值会传递给操作系统，标识程序运行结果。

> 注意：文档中提及的 “函数调用” 均以 `main` 为起点（如 `main` 调用 `sum`、`swap` 等函数），因此 `main` 是实际意义上的 “主调函数” 核心。

# 函数原型（C 标准规定）

C 标准（C89/C99/C11）明确 `main` 函数的两种合法原型，其他形式（如 `void main()`）为编译器扩展，不推荐跨平台使用：

| 原型形式                               | 适用场景     | 说明                                                       |
| ---------------------------------- | -------- | -------------------------------------------------------- |
| `int main(void)`                   | 无命令行参数   | 明确表示 `main` 不接收参数，C 标准推荐写法（空括号 `()` 在 C 中表示 “参数未指定”，不推荐） |
| `int main(int argc, char *argv[])` | 需解析命令行参数 | `argc`：命令行参数个数（含程序名）；`argv`：参数数组（每个元素是字符串指针）             |

**说明：**
- 返回值类型必须是 `int`（C99 后强制要求），早期 `void main()` 仅部分编译器支持（如 Dev-C++），跨平台程序需用 `int main()`；
- 若 `main` 末尾省略 `return 0`（仅 C99 及以后支持），编译器会自动补全 `return 0;`，表示程序正常退出。

# 注意事项

## （1）返回值的意义（操作系统层面）

`main` 的返回值是 “程序运行状态码”，操作系统通过此值判断程序是否正常执行：

- 返回 `0`：程序正常退出（成功）；
- 返回非 `0`（如 `1`、`-1`）：程序异常退出，非 0 值可自定义（如 `1` 表示参数错误，`2` 表示文件不存在）；
- 查看返回值（Linux/macOS）：执行程序后用 `echo $?` 查看上一个程序的返回值。

## （2）`main` 函数不能被其他函数调用

`main` 是操作系统的 “专属调用对象”，用户代码中调用 `main()` 会导致递归死循环（栈溢出），属于非法操作：

运行

```c
#include <stdio.h>
void func() {
    // main(); // 错误：禁止调用main函数，会导致栈溢出
}
int main(void) {
    func();
    return 0;
}
```

## （3）`exit()` 函数与 `return` 的区别（多渠道补充）

```c
#include <stdio.h>
#include <stdlib.h> // exit() 需此头文件

void check_num(int num) {
    if (num < 0) {
        printf("错误：数字不能为负\n");
        exit(1); // 直接终止程序，返回1（无需返回到main）
    }
}

int main(void) {
    int num = -5;
    check_num(num); // 调用后触发exit(1)，程序直接退出
    printf("此句不会执行\n"); // 被exit跳过
    return 0;
}
```


# 实践建议

1. **预处理指令与 `main` 的配合**：
    
    调试时用 `#define DEBUG` 开启 `main` 中的调试日志，发布时关闭；跨平台程序用条件编译适配 `main` 中调用的系统函数（如休眠、文件操作）。
    
2. **宏定义简化 `main` 逻辑**：
    
    用宏定义常用常量（如数组长度、错误码），避免 `main` 中硬编码：

```c
#define ARR_SIZE 10
#define ERR_PARAM 1

int main(void) {
	int arr[ARR_SIZE]; // 宏简化长度定义
	if (/* 参数错误 */) {
		return ERR_PARAM; // 宏简化错误码
	}
	return 0;
}
```
    
3. **头文件保护的必要性**：
    
    若 `main` 所在的 `.c` 文件包含多个自定义头文件，必须在头文件中加 `#ifndef/#define/#endif`，避免函数重复声明导致编译错误（如文档中结构体、函数声明场景）。
