用于解析命令行输入（如 `./program arg1 arg2`），常见于工具类程序（如文件处理、参数配置）：

**参数说明：**

- `argv[0]` 是程序的 “执行路径名”（如 `./program`、`C:\project\program.exe`），不是用户输入的第一个参数；
- `argv` 数组以 `NULL` 结尾（即 `argv[argc] == NULL`），可通过此特性遍历参数（无需依赖 `argc`）：

```c
int i = 0;
while (argv[i] != NULL) {
	printf("argv[%d] = %s\n", i, argv[i]);
	i++;
}
```

```c
#include <stdio.h>

// 带命令行参数的main：解析输入的参数并打印
int main(int argc, char *argv[]) {
    // 1. 打印参数个数（argc至少为1，argv[0]是程序名）
    printf("参数总个数：argc = %d\n", argc);
    
    // 2. 遍历打印所有参数（argv以NULL结尾）
    printf("所有参数：\n");
    for (int i = 0; i < argc; i++) {
        printf("argv[%d] = %s\n", i, argv[i]);
    }

    // 3. 示例：判断是否传入足够参数
    if (argc < 3) {
        printf("用法：%s <参数1> <参数2>\n", argv[0]); // 提示正确用法
        return 1; // 返回非0，告知操作系统程序异常退出
    }

    return 0; // 正常退出
}
```

**运行效果**（Linux/macOS 终端）：

```bash
# 编译：gcc main.c -o program
# 执行：./program hello world
参数总个数：argc = 3
所有参数：
argv[0] = ./program  # 程序名
argv[1] = hello      # 第一个用户参数
argv[2] = world      # 第二个用户参数
```
