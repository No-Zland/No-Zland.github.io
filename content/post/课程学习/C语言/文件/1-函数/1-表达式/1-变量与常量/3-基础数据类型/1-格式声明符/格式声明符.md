%[^\n] 是格式化输入的特殊格式符，专门用于读取含空格的字符串（直到遇到换行符 \n 停止），弥补 % s 遇空格终止的缺陷，是 scanf 读取完整字符串的常用方案。

| 格式符      | 对应数据类型              | 功能说明                       | 适用场景（输入 / 输出） |
| -------- | ------------------- | -------------------------- | ------------- |
| %d       | int（整数）             | 输出 / 输入十进制整数               | 输入 + 输出       |
| %c       | char（字符）            | 输出 / 输入单个字符（注意空格 / 换行的影响）  | 输入 + 输出       |
| %s       | char [] /char*（字符串） | 输出 / 输入字符串（遇空格或 \0 终止）     | 输入 + 输出       |
| `%[^\n]` | char [] /char*（字符串） | 输入字符串（遇换行符 \n 终止，保留空格）     | 仅输入           |
| %f       | float（单精度浮点数）       | 输出 / 输入浮点数（默认保留 6 位小数）     | 输入 + 输出       |
| %lf      | double（双精度浮点数）      | 输入双精度浮点数（输出可用 % f 兼容）      | 仅输入（输出用 % f）  |
| %u       | unsigned int（无符号整数） | 输出 / 输入无符号十进制整数            | 输入 + 输出       |
| %x/%X    | int（整数）             | 输出十六进制整数（小写 / 大写 a-f/A-F）  | 仅输出           |
| %o       | int（整数）             | 输出八进制整数（无前缀 0）             | 仅输出           |
| %p       | void*（指针）           | 输出指针的内存地址（十六进制）            | 仅输出           |
| %e/%E    | float/double（浮点数）   | 科学计数法输出浮点数（小写 / 大写 e）      | 仅输出           |
| %.2f     | float/double（浮点数）   | 自定义保留 n 位小数（如 %.2f 保留 2 位） | 仅输出           |
