# 函数：putchar()

- **定义**：向标准输出设备（屏幕）输出一个字符，是简化版的 fputc(stdout)，无需指定文件指针，直接操作屏幕。

- **函数原型**：

```c
 int putchar(int c);
```

- 参数 c：待输出字符的 ASCII 码（可直接传入字符常量如 'A'，或 int 类型的 ASCII 值）；

- 返回值：成功返回输出的字符（ASCII 码），失败返回 EOF（-1）。

- **典型示例**：

```c
#include <stdio.h>

int main() {

    char ch1 = 'B';   
     
    int ch2 = 67; // 'C'的ASCII码    
    
    putchar('A');   // 输出字符'A'  
      
    putchar(ch1);   // 输出字符'B' 
       
    putchar(ch2);   // 输出字符'C'   
     
    putchar('\n');  // 输出换行符，换行  
      
    return 0;
    
}// 输出结果：ABC（换行）
```

- **特殊操作 / 注意事项**：

- 可直接输出转义字符，如 putchar('\t')（制表符）、putchar('\\')（反斜杠）；

- 虽然参数是 int 类型，但实际仅使用低 8 位（字符的 ASCII 码范围），传入超出范围的值会截断。
