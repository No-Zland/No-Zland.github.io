# 函数：scanf()

- **定义**：按自定义格式从标准输入设备（键盘）读取数据，支持多种类型，需传递变量地址（字符串数组除外）。

- **函数原型**：
```c
int scanf(const char *format, ...);
```

- 参数 format：格式控制字符串，包含格式符和可选分隔符（如空格、逗号）；

- 参数 ...：变量地址列表（普通变量加 &，字符串数组直接写数组名）；

- 返回值：成功返回读取的有效数据个数，失败返回 EOF，读取不匹配返回小于预期的个数。

- **核心格式符（对应数据类型）**：

- 整数类型：%d（int）、%u（unsigned int）、%ld（long）、%lld（long long）；

- 浮点数类型：%f（float）、%lf（double，输入必须用 %lf，输出可用 %f）；

- 字符 / 字符串类型：%c（char）、%s（字符串，遇空格 / 回车停止）、%[^\n]（字符串，遇回车停止，保留空格）。

- **典型示例**：

```c
#include <stdio.h>

int main() {

    int num;   
     
    double score;    
    
    char gender;   
     
    char name[20];  
      
    char addr[50];  
      
    // 1. 读取整数、浮点数、字符  
      
    printf("请输入整数 浮点数 字符（空格分隔）：");    
    
    scanf("%d %lf %c", &num, &score, &gender); // 注意double用%lf，变量加&
        
    // 2. 读取无空格字符串（%s）    
    
    printf("请输入姓名（无空格）：");   
     
    scanf("%s", name); // 字符串数组无需加&    
    
    // 3. 读取含空格字符串（%[^\n]），需先清空缓冲区回车   
     
    getchar(); // 清除上一步scanf残留的回车符  
      
    printf("请输入地址（可含空格）：");   
     
    scanf("%[^\n]", addr);    // 输出读取结果  
      
    printf("\n读取结果：\n");    
    
    printf("整数：%d，浮点数：%.2lf，字符：%c\n", num, score, gender); 
       
    printf("姓名：%s，地址：%s\n", name, addr);   
     
    return 0;
}
```

- **特殊操作 / 注意事项**：

- 普通变量必须加 &（取地址），否则编译报错或内存异常；字符串数组名本身是地址，无需加 &；

- %c 会读取缓冲区的残留字符（如回车、空格），需在读取前用 getchar() 清空；

- %[^\n] 是读取含空格字符串的关键，但其会保留缓冲区的回车，后续若再用 scanf 需先清空；

- 输入数据时，可用空格、回车、制表符作为分隔符，与格式符中的分隔符无关。
