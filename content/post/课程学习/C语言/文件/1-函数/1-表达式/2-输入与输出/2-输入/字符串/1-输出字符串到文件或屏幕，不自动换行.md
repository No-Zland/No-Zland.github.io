# 函数：int fputs(const char *str, FILE *stream);

- **定义**：向指定文件指针指向的设备（屏幕、文件）输出字符串，**不自动添加换行符**，需手动写入 \n。

- **函数原型**：
```c
int fputs(const char *str, FILE *stream);
```

- 参数 str：字符串指针；

- 参数 stream：文件指针（stdout 表示屏幕，或 fopen() 返回的文件指针）；

- 返回值：成功返回非负值，失败返回 EOF。

- **典型示例**：

```c
#include <stdio.h>

int main() {

    char str[] = "Hello File I/O";    
    
    // 1. 输出到屏幕（不自动换行）    
    fputs(str, stdout);    
    
    fputs(" → 无换行\n", stdout); // 手动加\n换行    
    
    // 2. 输出到文件（不自动换行）    
    FILE *fp = fopen("str_output.txt", "w");    
    
    if (fp == NULL) {    
	    
	    perror("fopen error");        
	    
	    return 1;    
	    
	}    
	
	fputs(str, fp);    
	
	fputs("\n第二行字符串", fp); // 手动加\n换行    
	
	fclose(fp);    
	
	return 0;
	
}

// 屏幕输出：Hello File I/O → 无换行（换行）
// 文件str_output.txt内容：
// Hello File I/O
// 第二行字符串
```

- **特殊操作 / 注意事项**：

- 与 puts() 的核心区别：不自动换行，需手动添加 \n；

- 写入文件时，字符串中的 \0 不会被写入，仅写入 \0 前的字符；

- 支持输出空字符串（fputs("", stream)），但无实际意义。
