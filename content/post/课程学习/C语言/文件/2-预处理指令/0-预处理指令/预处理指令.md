预处理指令是 C 语言编译前的 “文本操作指令”，由编译器的**预处理阶段**（编译第一步）执行，核心作用是文本替换、文件引入、代码条件筛选，指令均以 # 开头，无需分号结尾。结合文档提及的 “宏定义、文件包含、条件编译” 三大核心类型，补充多渠道细节如下：

注意事项：
- **文本替换特性**：宏替换仅为 “纯文本替换”，无类型检查，也不执行语法验证（如 ```#define```PI 3.14a 编译时才报错）；

- **括号强制加**：带参数宏的参数和整体表达式必须加括号，否则会因运算符优先级导致逻辑错误（如上文 SQUARE(x+2) 示例）；

- **宏与常量区别**：#define PI 3.14 是文本替换，const float pi = 3.14 是有类型常量（编译时检查类型，占内存），按需选择；

# 头文件保护

必须用 ```#ifndef```/ ```#define``` /```#endif``` 或 ```#pragma once```（部分编译器支持）防止头文件被重复包含（如 A 包含 B，C 包含 A 和 B，会导致 B 的内容**重复嵌入**），如文档中结构体、函数声明场景。
