基本数据类型（int 整数、char 字符、float/double 浮点数）的字节长、取值范围及格式声明符

不同系统 / 编译器下字节长可能有差异（以下为 32 位 / 64 位系统通用值，可通过 sizeof (类型) 验证）：
# C 语言完整数据类型表格

|                     |                       |                                                            |                 |                                                        |
| ------------------- | --------------------- | ---------------------------------------------------------- | --------------- | ------------------------------------------------------ |
| 数据类型                | 字节长（通常）               | 取值范围 / 特性                                                  | 格式声明符（输入 / 输出）  | 说明                                                     |
| **基本整型（有符号）**       |                       |                                                            |                 |                                                        |
| char                | 1 字节                  | -128 ~ 127（signed char）                                    | %c（字符）、%hhd（整数） | 存储单个字符或小整数，默认带符号（部分编译器可配置为无符号）                         |
| short (int)         | 2 字节                  | -32768 ~ 32767                                             | %hd             | 短整型，节省内存                                               |
| int                 | 4 字节                  | -2^31 ~ 2^31-1（-2147483648 ~ 2147483647）                   | %d、%i           | 常用整型，平衡内存和范围                                           |
| long (int)          | 4 字节（32 位）/8 字节（64 位） | -2^31 ~ 2^31-1（32 位）；-2^63 ~ 2^63-1（64 位）                  | %ld             | 长整型，范围更大                                               |
| long long           | 8 字节                  | -2^63 ~ 2^63-1（-9223372036854775808 ~ 9223372036854775807） | %lld            | 长长整型，适用于超大整数                                           |
| **基本整型（无符号）**       |                       |                                                            |                 |                                                        |
| unsigned char       | 1 字节                  | 0 ~ 255                                                    | %hhu（整数）        | 无符号字符，可存储 0~255 的整数或无符号字符                              |
| unsigned short      | 2 字节                  | 0 ~ 65535                                                  | %hu             | 无符号短整型                                                 |
| unsigned int        | 4 字节                  | 0 ~ 4294967295                                             | %u              | 无符号整型                                                  |
| unsigned long       | 4 字节（32 位）/8 字节（64 位） | 0 ~ 2^32-1（32 位）；0 ~ 2^64-1（64 位）                          | %lu             | 无符号长整型                                                 |
| unsigned long long  | 8 字节                  | 0 ~ 2^64-1（0 ~ 18446744073709551615）                       | %llu            | 无符号长长整型                                                |
| **浮点型**             |                       |                                                            |                 |                                                        |
| float               | 4 字节                  | ±3.4e-38 ~ ±3.4e38（约 6-7 位有效数字）                            | %f（输出）、%f（输入）   | 单精度浮点数，精度较低，内存占用小                                      |
| double              | 8 字节                  | ±1.7e-308 ~ ±1.7e308（约 15-17 位有效数字）                        | %f（输出）、%lf（输入）  | 双精度浮点数，精度高，常用默认浮点类型                                    |
| long double         | 8/12/16 字节            | 平台相关（通常范围更大、精度更高）                                          | %Lf（输出）、%Lf（输入） | 长双精度浮点数，跨平台差异大，慎用                                      |
| **枚举类型（**enum**）**  | 由枚举常量最大值决定（通常 4 字节）   | 枚举常量的整数范围（默认从 0 开始递增）                                      | -               | 自定义离散值集合（如星期、状态），本质是整型                                 |
| **数组类型**            | 元素大小 × 元素个数           | 存储同类型元素的连续内存块                                              | -               | 如int arr[5]，字节长为4×5=20字节，无统一格式符，需逐个元素操作                |
| **指针类型**            | 4 字节（32 位）/8 字节（64 位） | 内存地址范围（0 ~ 2^32-1 或 0 ~ 2^64-1）                            | %p              | 存储变量、函数或数据的内存地址，类型如void*、int*等                         |
| **结构体类型（**struct）** | 成员大小之和（含内存对齐）         | 存储不同类型成员的复合数据                                              | -               | 如struct Student{char name[20]; int age;}，字节长由成员和对齐规则决定 |
| **共用体类型（**union）**  | 最大成员的大小               | 成员共用同一块内存（同一时间仅一个成员有效）                                     | -               | 节省内存，如union Data{int i; float f;}，字节长等于最大成员（如 4 字节）    |
