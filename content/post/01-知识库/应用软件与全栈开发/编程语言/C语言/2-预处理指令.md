# 2-预处理指令
## 预处理指令
### 预处理指令
预处理指令是 C 语言编译前的 “文本操作指令”，由编译器的**预处理阶段**（编译第一步）执行，核心作用是文本替换、文件引入、代码条件筛选，指令均以 # 开头，无需分号结尾。结合文档提及的 “宏定义、文件包含、条件编译” 三大核心类型，补充多渠道细节如下：

注意事项：
- **文本替换特性**：宏替换仅为 “纯文本替换”，无类型检查，也不执行语法验证（如 ```#define```PI 3.14a 编译时才报错）；

- **括号强制加**：带参数宏的参数和整体表达式必须加括号，否则会因运算符优先级导致逻辑错误（如上文 SQUARE(x+2) 示例）；

- **宏与常量区别**：#define PI 3.14 是文本替换，const float pi = 3.14 是有类型常量（编译时检查类型，占内存），按需选择；

#### 头文件保护

必须用 ```#ifndef```/ ```#define``` /```#endif``` 或 ```#pragma once```（部分编译器支持）防止头文件被重复包含（如 A 包含 B，C 包含 A 和 B，会导致 B 的内容**重复嵌入**），如文档中结构体、函数声明场景。

## 宏定义
### 宏定义
通过```#define```将标识符（宏名）与文本 / 表达式绑定，预处理阶段会将代码中所有宏名**替换为对应文本**，实现 “一处定义、多处复用”，分为 “无参数宏” 和 “带参数宏” 两类。

#### 无参数宏：#define 宏名 替换文本

```c
#define 宏名 替换文本
```
  
替换文本 可省略，此时宏名仅作为 “标识”，如 ```#define``` DEBUG

示例：

```c
#include <stdio.h>// 无参数宏：定义常量（替换文本为数值/字符串）
#define PI 3.14159
#define MAX_SIZE 100
#define GREET "Hello C Preprocessor"

int main() {    

	// 预处理阶段：PI→3.14159，MAX_SIZE→100，GREET→"Hello C Preprocessor"    
	float radius = 5.0;    
	
	float area = PI * radius * radius; 
	   
	int arr[MAX_SIZE]; // 宏作为数组长度（编译前替换为100）
	        
	printf("圆面积：%.2f\n", area); // 输出：78.54    
	
	printf("%s\n", GREET);         // 输出：Hello C Preprocessor    
	
	return 0;
	
}
```


#### 带参数宏：#define 宏名(参数列表) 替换表达式

```c
#define 宏名(参数列表) 替换表达式
```

参数列表无类型，表达式需加括号避免优先级问题

示例：带参数宏（处理简单逻辑）

```c
#include <stdio.h>
#define MAX(a, b) ((a) > (b) ? (a) : (b)) // 带参数宏：求两数最大值（表达式加括号避免优先级陷阱）
#define SQUARE(x) ((x) * (x)) // 带参数宏：计算平方（参数加括号，避免传入表达式时出错）

int main() {

    int x = 3, y = 5;    // 预处理替换：MAX(3,5)→((3)>(5)?(3):(5))，
    
    SQUARE( x + 2 ) → ( ( 3 + 2 ) * ( 3 + 2 ) )    
    
    printf("最大值：%d\n", MAX(x, y));    
    // 输出：5 
       
    printf("(x+2)的平方：%d\n", SQUARE( x + 2 ) ); 
    // 输出：25（若无括号会变成3+2*3+2=11）    
    
    return 0;
    
}
```

#### 取消宏定义：#undef 宏名 

```c
#undef 宏名
```

取消已定义的宏，后续代码中宏名不再生效：

```c
#define NUM 100

printf("%d\n", NUM); // 输出：100

#undef NUM// printf("%d\n", NUM); // 错误：NUM未定义
```

## 文件包含
### 文件包含
通过  ```#include``` 将指定文件的全部内容 “嵌入” 当前文件，
实现头文件复用（如标准库头文件 <stdio.h>、自定义头文件 myfunc.h）。

注意事项：
- **避免包含源文件**：#include 仅用于包含头文件（.h），不建议包含源文件（.c），否则会导致代码重复编译，生成冗余目标文件。

### 标准库头文件
```c
#include <头文件名>
```

编译器从 “系统头文件路径”查找文件，如 /usr/include、C:\MinGW\include

示例：包含标准库头文件
```c
// 包含标准输入输出库头文件，才能使用printf()、scanf()
#include <stdio.h>

int main() {    

	printf("Hello from stdio.h\n"); // 依赖<stdio.h>中的函数声明   
	 
	return 0;
	
}
```

### 自定义头文件
```c
#include "头文件名"
```

编译器先从 “当前源文件所在路径” 查找，找不到再去系统路径查找，包含自定义头文件（模块化开发）

**示例：**

假设有两个文件：myfunc.h（头文件）和 main.c（源文件）：

- myfunc.h（自定义头文件，声明函数）： 

```c
// 头文件保护（避免重复包含，多渠道核心补充）
#ifndef MYFUNC_H
#define MYFUNC_H // 声明加法函数

int add(int a, int b);

#endif // MYFUNC_H
```

- main.c（包含自定义头文件，调用函数）：

```c
#include <stdio.h> // 包含自定义头文件（当前路径下）
#include "myfunc.h"

int main() {    

	int sum = add(3, 5);   
	 
	printf("3+5=%d\n", sum); // 输出：8  
	  
	return 0;
	
}

// 实现myfunc.h中声明的函数
int add(int a, int b) {

    return a + b;
    
}
```

### 相对路径
```c
#include "./include/myfunc.h" // 从 /include 回溯一级查找 myfunc.h
#include "../../include/myfunc.h" // 从 /include 回溯两级查找 myfunc.h
```

跨平台推荐相对路径

### 绝对路径
```c
#include "C:/project/include/myfunc.h"
```

## 头文件保护
### 基础条件编译
通过条件判断控制 “哪些代码参与编译”，预处理阶段会删除不满足条件的代码，
实现 “跨平台适配、调试开关、代码版本控制”。
常用于嵌入式封装函数芯片型号选择、系统选择。

```c
#if 条件表达式
	
	满足条件的代码
	
#elif 条件表达式
	
	满足此条件的代码
	
#else
	
	所有条件不满足的代码
	
#endif
```

注意： 
**常量表达式**：条件表达式仅支持**常量表达式**（如宏、字面常量），如

```c
#if 1 // 正确
#if MAX_SIZE > 50 // 错误
```

**嵌套条件编译**：支持多层嵌套，需注意#endif 与#if/#ifdef 配对，避免遗漏：

```c
#define OS_WIN 1

#define DEBUG 1

#if OS_WIN 
	   
	#ifdef DEBUG    
	    
	    printf("Windows调试模式\n");    
		
	#else    
	    
	    printf("Windows发布模式\n");    
		
	#endif
	
#endif
```


**示例：** 跨平台适配

不同系统的头文件和函数不同（如 Windows 的 windows.h、Linux 的 unistd.h），用条件编译适配：

```c
#include <stdio.h>

// 判断当前系统宏（由编译器自动定义，如GCC定义__linux__，MSVC定义_WIN32）
#ifdef _WIN32   
 
	#include <windows.h> // Windows系统头文件   
 
	#define SLEEP(x) Sleep(x) // Windows休眠函数（毫秒）

#elif __linux__    

	#include <unistd.h> // Linux系统头文件
    
	#define SLEEP(x) sleep(x/1000) // Linux休眠函数（秒，转换为毫秒）

#else    

	#error "不支持当前操作系统" // 触发编译错误

#endif

int main() {

    printf("休眠3秒...\n");  
      
    SLEEP(3000); // 预处理阶段：Windows→Sleep(3000)，Linux→sleep(3)    
    
    printf("休眠结束\n");   
     
    return 0;
    
}
```

### 宏已定义则编译代码
```c
#ifdef 宏名 // 等价于 #if defined(宏名)

#endif 
```

**示例：** 调试开关，用宏 DEBUG 控制调试日志是否编译，发布版本关闭调试代码：

```c
#include <stdio.h>// 开发阶段定义DEBUG（开启调试），发布阶段注释此句（关闭调试）

#define DEBUG

int main() {

    int num = 10;    // 仅当DEBUG定义时，才编译调试日志代码    
    
    #ifdef DEBUG 
		
        printf("调试：num的初始值为%d\n", num); // 开发时输出，发布时删除    
        
    #endif    
    
    num *= 2;    
    
    printf("最终结果：%d\n", num); // 无论是否调试，都编译    
    
    return 0;
    
}
```

### 宏未定义则编译代码
```c
#ifndef 宏名 // 等价于 #if !defined(宏名)

#define 宏名 // 跟上一个宏名同名，给宏定义

#endif
```

## 编译报错指令
### 编译错误指令
编译错误：#error 指令

在条件不满足时触发编译错误，常用于提示不支持的环境（如上文跨平台示例）；

1. **预处理指令与** **main** **的配合**：

调试时用#define DEBUG 开启 main 中的调试日志，发布时关闭；跨平台程序用条件编译适配 main 中调用的系统函数（如休眠、文件操作）。

2. **宏定义简化** **main** **逻辑**：

用宏定义常用常量（如数组长度、错误码），避免 main 中硬编码：

```c
#define ARR_SIZE 10

#define ERR_PARAM 1

int main(void) {

    int arr[ARR_SIZE]; // 宏简化长度定义    
    
    if (/* 参数错误 */) {    
        
        return ERR_PARAM; // 宏简化错误码    
		
    }    
    
    return 0;
    
}
```
