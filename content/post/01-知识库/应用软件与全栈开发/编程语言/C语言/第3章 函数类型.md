# 1. 主函数（main 函数）—— 程序的入口与控制起点

## 1.1 定义

`main` 函数是 C 程序的**唯一入口点**。程序启动时，通常由 C 运行时启动代码完成必要初始化后调用 `main`，而不是操作系统直接调用 `main`。所有用户逻辑均直接或间接从 `main` 开始执行；`main` 执行结束后，其返回值会传递给宿主环境（通常可理解为操作系统），用于标识程序运行结果。

> 注意：文档中提及的“函数调用”均以 `main` 为起点（如 `main` 调用 `sum`、`swap` 等函数），因此 `main` 是实际意义上的程序入口与控制起点。

## 1.2 函数原型（C 标准规定）

C 标准明确列出了 `main` 的两种常见合法形式，并允许实现定义其他形式。跨平台程序应优先使用下面两种：

| 原型形式 | 适用场景 | 说明 |
| --- | --- | --- |
| `int main(void)` | 无参数形式 | 明确表示 `main` 不接收参数，C 标准推荐用于无参场景。空括号 `int main()` 在 C 中表示“参数未指定”，不推荐 |
| `int main(int argc, char *argv[])` | 需要访问命令行参数 | `argc`：命令行参数个数；`argv`：参数数组，每个元素是字符串指针。`char **argv` 与 `char *argv[]` 等价 |

**说明：**

- C 标准要求 `main` 的返回类型为 `int`。`void main()` 不是标准形式，部分编译器可能接受，但不推荐跨平台使用。
- C99 及以后，若 `main` 执行到末尾 `}` 时没有显式 `return`，等价于执行 `return 0;`，表示程序正常退出。为了清晰，示例中仍建议显式写出 `return 0;`。
- `argc` 为非负数；通常宿主环境会传入至少 1 个参数。若 `argc > 0`，`argv[0]` 表示程序名，但它可能是空字符串，具体值取决于启动方式。
- C 标准保证 `argv[argc]` 是空指针，即 `argv[argc] == NULL`，可据此遍历参数。
- `argv` 及其指向的字符串在程序运行期间通常可由程序修改，但不应依赖修改后的内容具有跨平台一致性。

### 1.2.1 无命令行参数

最常用的基础形式，无命令行参数，仅执行内部逻辑。以下示例按 C99/C11 编写：

```c
#include <stdio.h>

// 函数声明（被 main 调用）
int sum(int a, int b);

int main(void) { // 标准无参数形式
    int a = 3, b = 5;
    int result = sum(a, b); // main 调用 sum 函数

    printf("3 + 5 = %d\n", result); // 输出：8
    return 0; // 程序正常退出，返回 0 给宿主环境
}

// 函数定义（被 main 调用的子函数）
int sum(int a, int b) {
    return a + b;
}
```

### 1.2.2 带命令行参数

用于解析命令行输入（如 `./program arg1 arg2`），常见于工具类程序。`argv[0]` 是程序名或执行路径名，不是用户输入的第一个参数；`argv[1]` 才是第一个用户参数。

```c
#include <stdio.h>
#include <stdlib.h>

int main(int argc, char *argv[]) {
    // 1. 打印参数个数
    printf("参数总个数：argc = %d\n", argc);

    // 2. 遍历打印所有参数
    printf("所有参数：\n");
    for (int i = 0; i < argc; i++) {
        printf("argv[%d] = %s\n", i, argv[i]);
    }

    // 3. 判断是否传入足够参数
    if (argc < 3) {
        printf("用法：%s <参数1> <参数2>\n", argv[0]);
        return EXIT_FAILURE; // 返回非 0，表示程序异常退出
    }

    return EXIT_SUCCESS; // 正常退出
}
```

也可以利用 `argv[argc] == NULL` 遍历参数：

```c
int i = 0;
while (argv[i] != NULL) {
    printf("argv[%d] = %s\n", i, argv[i]);
    i++;
}
```

**运行效果示例**（Linux/macOS 终端）：

```bash
# 编译：gcc -std=c11 -Wall -Wextra -pedantic main.c -o program
# 执行：./program hello world
```

程序输出可能为：

```text
参数总个数：argc = 3
所有参数：
argv[0] = ./program
argv[1] = hello
argv[2] = world
```

说明：`argv[0]` 的具体值取决于启动方式，可能是 `./program`、绝对路径，也可能是空字符串，不应在程序中写死。

## 1.3 注意事项

### 1.3.1 返回值的意义（宿主环境层面）

`main` 的返回值是程序运行状态码，宿主环境可通过此值判断程序是否正常执行：

1. 返回 `0` 或 `EXIT_SUCCESS`：程序正常退出（成功）。
2. 返回非 `0` 或 `EXIT_FAILURE`：程序异常退出。非 0 值可自定义，如 `1` 表示参数错误，`2` 表示文件不存在。

| Linux/macOS   | Windows 命令行  |
| ------------- | ------------ |
| echo $?       | %ERRORLEVEL% |
| 查看上一个程序的退出状态。 | 查看退出码        |

注意 POSIX 环境下通常只能看到状态码的低 8 位，例如 `return -1` 可能显示为 `255`。

更可移植的写法是包含 `<stdlib.h>` 后使用 `EXIT_SUCCESS` 和 `EXIT_FAILURE`。

### 1.3.2 不应在用户代码中调用 `main`

`main` 是程序入口，不应由用户代码主动调用。

C++ 标准明确禁止程序使用 `main`；C 标准没有以同样方式绝对禁止，但在 C 中也不应依赖调用 `main`。

调用 `main` 会导致程序重入或递归调用风险，可能造成栈溢出，也不符合程序入口的设计语义。

```c
#include <stdio.h>

void func(void) {
    // main(); // 不推荐：C++ 禁止；C 中也不应依赖递归调用 main
}

int main(void) {
    func();
    return 0;
}
```

### 1.3.3 `exit()` 函数与 `return` 的区别

```c
#include <stdio.h>
#include <stdlib.h> // exit() 需此头文件

void check_num(int num) {
    if (num < 0) {
        printf("错误：数字不能为负\n");
        exit(EXIT_FAILURE); // 以失败状态码终止整个进程
    }
}

int main(void) {
    int num = -5;
    check_num(num); // 触发 exit，程序直接退出
    printf("此句不会执行\n");
    return 0;
}
```

主要区别可归纳为：

| 写法 | 行为 |
| --- | --- |
| `main` 中 `return n;` | 等价于以状态码 `n` 调用 `exit` |
| 子函数中 `return n;` | 只返回给调用者，不终止整个程序 |
| `exit(n)` | 终止整个进程，刷新 stdio 缓冲区，并调用 `atexit` 注册的函数 |
| `_Exit(n)` | 终止整个进程，但不刷新 stdio 缓冲区，也不调用 `atexit` 注册的函数 |

因此，原文中“`exit(1)` 返回 1”更准确的说法是“以状态码 1 终止进程”。

## 1.4 实践建议

1. **预处理指令与 `main` 的配合**

   调试时可用 `#define DEBUG` 开启 `main` 中的调试日志，发布时关闭：

   ```c
   #ifdef DEBUG
       printf("调试：num = %d\n", num);
   #endif
   ```

   跨平台程序也可用条件编译适配 `main` 中调用的系统相关函数，但应尽量把平台相关代码封装到独立函数中。

2. **用宏或枚举简化 `main` 逻辑**

   可用宏定义常用常量，也可用 `enum` 代替整型宏，减少 `main` 中的硬编码：

   ```c
   enum { ARR_SIZE = 10, ERR_PARAM = 1 };

   int main(void) {
       int arr[ARR_SIZE];
       int failed = 0; // 实际程序中由参数或文件检查结果赋值

       if (failed) {
           return ERR_PARAM;
       }

       (void)arr;
       return 0;
   }
   ```

   宏不是唯一选择；对于整型常量和错误码，`enum` 或 `const` 往往更利于调试和类型检查。

3. **头文件保护**

   如果 `main` 所在项目包含自定义头文件，所有自定义头文件都建议加包含保护，而不仅是包含多个头文件时：

   ```c
   #ifndef MY_HEADER_H
   #define MY_HEADER_H

   /* 函数声明、结构体定义等 */

   #endif
   ```

4. **编译选项建议**

   初学阶段建议开启常见警告，有助于发现 `void main`、未使用参数等问题：

   ```bash
   gcc -std=c11 -Wall -Wextra -pedantic main.c -o program
   ```

   如需更严格检查，可再加 `-Werror` 将警告视为错误。

---

**小结：** `main` 是 C 程序的入口与控制起点，应使用标准形式 `int main(void)` 或 `int main(int argc, char *argv[])`；返回值用于表示程序退出状态；不应在用户代码中调用 `main`；`exit` 与 `return` 的语义不同，应结合场景使用。

# 2. 状态码
## 2.1 从当前函数返回

```c
return 返回值/状态码;
```

从当前函数返回，在 `main` 中使用时，会触发程序退出并返回状态码；

## 2.2 直接终止整个函数

```c
exit(int status);
```

直接终止整个程序（无论在哪个函数中调用），状态码 `status` 与 `main` 返回值意义一致，需包含头文件 `<stdlib.h>`；

# 3. 自定义函数

## 3.1 函数定义

> 
>  返回值类型 函数名(参数列表)
> 

函数的定义由 返回值类型、函数名、参数列表和函数体 组成。

```c
返回值类型 函数名(参数类型1 参数名1, 参数类型2 参数名2, ...) {
    函数体（实现功能的代码）;
    return 返回值; // 若返回值类型为void，可省略return或仅写return;
}
```

> 
> **返回值类型：**
> 表示函数执行后返回的数据类型（如 int、float、void（无返回值）等）。
> 
> **函数名：**
> 自定义的标识符，遵循命名规则。
> 
> **参数列表：**
> 传递给函数的输入数据，可选（无参数时写 void 或空括号）。
> 

示例：定义一个求和函数

```c
int sum(int a, int b) {

    return a + b;
        
}
```

## 3.2 函数声明（函数原型）

函数原型是函数的 “声明式”，用于提前告知编译器函数的存在（当函数定义在调用位置之后时，必须声明）。格式与函数定义的 “头部” 一致，以分号结尾。

示例：为求和函数声明原型

```c
// 函数原型声明
int sum(int, int); 

int main() {
	
    int result = sum(3, 5); // 调用函数
    
    printf("结果：%d\n", result);
    
    return 0;
    
}
// 函数定义（在调用之后）

int sum(int a, int b) {
	
    return a + b;
    
}
```

# 4. 函数调用

## 4.1 传值调用（不影响实参）

将实参的值复制给形参，函数内对形参的修改不影响实参。

示例：传值调用无法修改实参

```c
void change(int x) {

    x = 100; // 仅修改形参x
    
}

int main() {

    int num = 10;
    
    change(num);
    
    printf("num = %d\n", num); // 输出10，实参未被修改
    
    return 0;
}
```

## 4.2 传址调用（可修改实参）

将实参的地址传递给形参（通过指针接收），函数内通过指针修改会影响实参。

示例：传址调用修改实参（交换两个数）

```c
void swap(int *p1, int *p2) {

    int temp = *p1;
    
    *p1 = *p2;
    
    *p2 = temp;
    
}

int main() {

    int a = 5, b = 10;
    
    swap(&a, &b); // 传递实参的地址
    
    printf("a = %d, b = %d\n", a, b); // 输出a=10, b=5
    
    return 0;
}
```

# 5. 函数进阶

## 5.1 递归思维

递归函数是直接或间接调用自身的函数，需满足两个条件：

- 终止条件：递归必须有 “出口”，否则会无限递归导致栈溢出。
- 递归关系：将原问题分解为更小的同类子问题。

示例 1：递归求阶乘（n! = n × (n-1)!，终止条件 n=1 时返回 1）

```c
int factorial(int n) {
	
    if (n == 1) { // 终止条件
	    
        return 1;
        
    }
    
    return n * factorial(n - 1); // 递归关系
    
}

int main() {
	
    printf("5的阶乘：%d\n", factorial(5)); // 输出120
    
    return 0;
    
}
```

示例 2：递归求斐波那契数列（第 n 项 = 第 n-1 项 + 第 n-2 项，终止条件 n=1 或 n=2 时返回 1）

```c
int fibonacci(int n) {
	
    if (n == 1 || n == 2) { // 终止条件
	    
        return 1;
        
    }
    
    return fibonacci(n - 1) + fibonacci(n - 2); // 递归关系
    
}

int main() {
	
    printf("斐波那契第5项：%d\n", fibonacci(5)); // 输出5（序列：1,1,2,3,5）
    
    return 0;
    
}
```

## 5.2 函数指针

**函数原型**：
```c
返回值类型 (* 指针名)(参数类型 1, 参数类型 2, ...);
```

函数指针是指向函数的指针变量，可存储函数的地址，进而通过指针调用函数，常用于实现 “回调函数”（将函数作为参数传递，在特定时机执行）。

**示例：** 用函数指针实现回调逻辑（根据不同函数计算结果）

```c
// 定义两个运算函数
int add(int a, int b) {
    return a + b;
}
int multiply(int a, int b) {
    return a * b;
}
// 回调函数：通过函数指针调用不同运算
int calculate(int (*func)(int, int), int a, int b) {
    return func(a, b);
}
int main() {
    int (*pFunc)(int, int); // 定义函数指针
    pFunc = add; // 指向add函数
    printf("3+5 = %d\n", calculate(pFunc, 3, 5)); // 输出8
    pFunc = multiply; // 指向multiply函数
    printf("3×5 = %d\n", calculate(pFunc, 3, 5)); // 输出15
    return 0;
}
```

函数是 C 语言模块化编程的核心，它将功能封装为可复用的代码块。

# 6. 局部变量与全局变量（详见常量与变量）

变量的作用域是可访问的代码范围，生命周期是变量在内存中存在的时间，两者决定了变量的可见性和存活时间。

## 6.1 局部变量

定义在函数内或代码块（{}）内的变量。

- 作用域：仅限当前函数 / 代码块。
- 生命周期：函数调用开始时创建，调用结束时销毁。

示例：

```c
void func() {
    int local = 10; // 局部变量，仅在func内有效
    printf("local = %d\n", local);
}
int main() {
    func();
    // printf("local = %d\n", local); // 错误：local超出作用域
    return 0;
}
```

## 6.2 全局变量

定义在所有函数外的变量。

- 作用域：整个程序（从定义处到文件结束）。
- 生命周期：程序启动时创建，程序结束时销毁。

示例：

```c
int global = 20; // 全局变量，所有函数可访问
void func() {
    printf("global = %d\n", global); // 正确访问
}
int main() {
    func();
    printf("global = %d\n", global); // 正确访问
    return 0;
}
```

注意：若局部变量与全局变量同名，局部变量会覆盖全局变量（作用域内优先访问局部）。
