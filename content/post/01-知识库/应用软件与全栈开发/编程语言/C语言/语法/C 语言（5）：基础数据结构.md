## 1. 数组

数组是**同类型元素的连续内存块**。定义格式：

```c
数据类型 数组名[元素个数];
```

数组名在大多数表达式中会退化为指向首元素的指针，但数组本身不是指针。`sizeof(数组名)` 得到整个数组的字节数，这一点与指针不同。

### 1.1 一维数组

```c
int arr[5];                    // 仅定义，元素未初始化
int a[5] = {1, 2, 3, 4, 5};    // 完全初始化
int b[5] = {1, 2};             // 部分初始化，其余元素为 0
int c[] = {1, 2, 3};           // 长度由初始化元素个数决定，长度为 3
int d[5] = {0};                // 常用写法：全部元素初始化为 0
```

**要点：**

- 下标从 `0` 开始，合法下标范围是 `0 ~ 长度-1`。
- C 不检查数组越界，越界访问属于未定义行为。
- 局部数组未初始化时，元素值不确定；全局数组和静态数组默认初始化为 0。
- 数组长度必须是编译期常量（C99 起支持变长数组，但实践中应谨慎使用）。

### 1.2 一维数组的输入输出

```c
#include <stdio.h>

int main(void) {
    int arr[5];

    printf("请输入 5 个整数：\n");
    for (int i = 0; i < 5; i++) {
        scanf("%d", &arr[i]);
    }

    printf("数组元素：");
    for (int i = 0; i < 5; i++) {
        printf("%d ", arr[i]);
    }
    printf("\n");

    return 0;
}
```

注意 `scanf("%d", &arr[i])` 中的 `&`：`arr[i]` 是普通 `int` 变量，需要取地址。

### 1.3 二维数组

二维数组可以理解为“多个一维数组的数组”。定义格式：

```c
数据类型 数组名[行数][列数];
```

```c
int matrix[2][3];  // 2 行 3 列，共 6 个 int

int m1[2][3] = {{1, 2, 3}, {4, 5, 6}};  // 按行初始化
int m2[2][3] = {1, 2, 3, 4, 5, 6};      // 按顺序初始化，效果同上
int m3[2][3] = {{1}, {4, 5}};            // 部分初始化，其余为 0
```

访问格式为 `数组名[行下标][列下标]`，行列下标均从 0 开始：

```c
matrix[0][1] = 10;            // 第 1 行第 2 列
printf("%d\n", matrix[1][2]); // 第 2 行第 3 列
```

二维数组的输入输出通常需要双重循环：

```c
#include <stdio.h>

int main(void) {
    int matrix[2][3];

    printf("请输入 2 行 3 列整数：\n");
    for (int i = 0; i < 2; i++) {
        for (int j = 0; j < 3; j++) {
            scanf("%d", &matrix[i][j]);
        }
    }

    printf("二维数组元素：\n");
    for (int i = 0; i < 2; i++) {
        for (int j = 0; j < 3; j++) {
            printf("%d ", matrix[i][j]);
        }
        printf("\n");
    }

    return 0;
}
```

### 1.4 二维数组与一维数组的关系

对于 `int matrix[2][3]`，`matrix[0]` 是第一个包含 3 个 `int` 的一维数组，`matrix[1]` 是第二个。二维数组在内存中按行连续存放。

二维转一维（按行展开）：

```c
int matrix[2][3] = {{1, 2, 3}, {4, 5, 6}};
int arr[6];
int index = 0;

for (int i = 0; i < 2; i++) {
    for (int j = 0; j < 3; j++) {
        arr[index++] = matrix[i][j];
    }
}
// arr = {1, 2, 3, 4, 5, 6}
```

一维转二维：

```c
int arr[6] = {7, 8, 9, 10, 11, 12};
int matrix[2][3];
int index = 0;

for (int i = 0; i < 2; i++) {
    for (int j = 0; j < 3; j++) {
        matrix[i][j] = arr[index++];
    }
}
```

### 1.5 数组作为函数参数

数组作为函数参数时会退化为指向首元素的指针，函数内部无法通过 `sizeof` 得到数组长度，因此通常需要额外传入长度：

```c
#include <stdio.h>

void print_arr(int arr[], int n) {
    for (int i = 0; i < n; i++) {
        printf("%d ", arr[i]);
    }
    printf("\n");
}

int main(void) {
    int a[5] = {1, 2, 3, 4, 5};
    print_arr(a, 5);
    return 0;
}
```

`void print_arr(int arr[], int n)` 与 `void print_arr(int *arr, int n)` 在参数位置上等价。二维数组作为参数时，列数不能省略：

```c
void print_matrix(int matrix[][3], int rows) {
    for (int i = 0; i < rows; i++) {
        for (int j = 0; j < 3; j++) {
            printf("%d ", matrix[i][j]);
        }
        printf("\n");
    }
}
```

## 2. 字符串

C 语言没有独立的字符串类型。字符串本质是**以 `'\0'` 结尾的字符数组**。`'\0'` 是 ASCII 值为 0 的空字符，用作字符串结束标志。

```c
char s1[] = "Hello";  // 等价于 {'H','e','l','l','o','\0'}，长度为 6
char s2[10] = "Hello"; // 数组长度 10，前 6 个元素为 Hello\0，其余为 0
char s3[] = {'H', 'e', 'l', 'l', 'o'}; // 不是字符串，没有 '\0'
```

**区别：**

- `char s1[] = "Hello";` 是字符串，末尾自动补 `'\0'`。
- `char s3[] = {'H', 'e', 'l', 'l', 'o'};` 是字符数组，不是字符串，不能直接传给 `printf("%s")` 或 `strlen`。
- `char *p = "Hello";` 指向字符串字面量，内容通常不可修改，不要通过 `p[0] = 'h'` 修改。

### 2.1 常用字符串函数

需包含 `<string.h>`：

| 函数 | 功能 | 注意事项 |
|---|---|---|
| `strlen(s)` | 求字符串长度，不含 `'\0'` | 返回 `size_t`，输出用 `%zu` |
| `strcpy(dest, src)` | 复制字符串，包含 `'\0'` | `dest` 必须足够大 |
| `strncpy(dest, src, n)` | 最多复制 n 个字符 | 不保证补 `'\0'`，需手动处理 |
| `strcmp(s1, s2)` | 比较字符串 | 相等返回 0；按字典序返回正/负 |
| `strncmp(s1, s2, n)` | 比较前 n 个字符 | 常用于前缀比较 |
| `strcat(dest, src)` | 拼接字符串 | `dest` 必须足够大，且以 `'\0'` 结尾 |
| `strchr(s, c)` | 查找字符 | 返回首次出现位置指针，找不到返回 `NULL` |
| `strstr(s1, s2)` | 查找子串 | 返回首次出现位置指针，找不到返回 `NULL` |

### 2.2 字符串函数示例

```c
#include <stdio.h>
#include <string.h>

int main(void) {
    char s1[20] = "Hello";
    char s2[20] = "World";
    char s3[40];

    printf("strlen(s1) = %zu\n", strlen(s1));  // 5

    strcpy(s3, s1);
    printf("strcpy 后 s3 = %s\n", s3);          // Hello

    strcat(s3, " ");
    strcat(s3, s2);
    printf("strcat 后 s3 = %s\n", s3);          // Hello World

    int cmp = strcmp(s1, s2);
    if (cmp == 0) {
        printf("s1 == s2\n");
    } else if (cmp < 0) {
        printf("s1 < s2\n");                    // 按字典序 Hello < World
    } else {
        printf("s1 > s2\n");
    }

    char *pos = strchr(s3, 'W');
    if (pos != NULL) {
        printf("找到 W，位置偏移 = %ld\n", pos - s3);
    }

    return 0;
}
```

### 2.3 字符串避坑

1. 字符串必须以 `'\0'` 结尾，否则 `strlen`、`printf("%s")`、`strcpy` 等可能越界读取。
2. `strcpy`、`strcat` 不检查目标缓冲区大小，目标空间不足会导致缓冲区溢出。
3. `strncpy(dest, src, n)` 在 `src` 长度大于等于 `n` 时不会自动补 `'\0'`，需要手动设置 `dest[n-1] = '\0'`。
4. `strcmp` 比较的是字典序，不是长度。
5. 字符串字面量通常存放在只读区域，不要通过指针修改。
