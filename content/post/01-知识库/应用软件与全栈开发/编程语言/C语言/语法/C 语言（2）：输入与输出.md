## 1. 标准 I/O 与文件 I/O

C 语言通过 `<stdio.h>` 提供输入输出函数。按操作对象分为：

- **标准 I/O**：键盘（`stdin`）、屏幕（`stdout`、`stderr`）。
- **文件 I/O**：磁盘文件，通过 `FILE *` 文件指针操作。

### 1.1 常用 I/O 函数速查

| 函数 | 方向 | 说明 |
|---|---|---|
| `putchar(c)` | 输出到屏幕 | 输出一个字符，等价于 `fputc(c, stdout)` |
| `fputc(c, stream)` | 输出到文件/屏幕 | 输出一个字符，`stream` 可为 `stdout` |
| `puts(s)` | 输出到屏幕 | 输出字符串并自动换行 |
| `fputs(s, stream)` | 输出到文件/屏幕 | 输出字符串，不自动换行 |
| `printf(fmt, ...)` | 格式化输出到屏幕 | 最常用输出 |
| `fprintf(stream, fmt, ...)` | 格式化输出到文件 | 用法类似 `printf` |
| `getchar()` | 从键盘读字符 | 返回 `int`，便于判断 `EOF` |
| `fgetc(stream)` | 从文件/键盘读字符 | `stream` 可为 `stdin` |
| `fgets(s, n, stream)` | 安全读取字符串 | 最多读 `n-1` 个字符，保留换行符 |
| `scanf(fmt, ...)` | 格式化从键盘读取 | 普通变量需加 `&` |
| `fscanf(stream, fmt, ...)` | 格式化从文件读取 | 格式需与文件内容匹配 |
| `fopen(path, mode)` | 打开文件 | 返回 `FILE *`，失败返回 `NULL` |
| `fclose(fp)` | 关闭文件 | 使用后必须关闭 |

> **不推荐 `gets()`**：无长度限制，存在缓冲区溢出风险，C11 已废弃。  
> **不推荐 `fflush(stdin)`**：该用法非标准，行为未定义。需要清空输入缓冲区时，可循环读取字符直到 `'\n'` 或 `EOF`。

### 1.2 字符输入输出

```c
#include <stdio.h>

int main(void) {
    printf("请输入一个字符：");
    int ch = getchar();  // 用 int 接收，便于判断 EOF

    if (ch != EOF) {
        printf("你输入的是：");
        putchar(ch);
        printf("\nASCII = %d\n", ch);
    }

    return 0;
}
```

`getchar()` 返回 `int`，因为 `EOF` 通常是 `-1`，用 `char` 接收可能无法正确区分普通字符和 `EOF`。

### 1.3 读取含空格的字符串

`scanf("%s", buf)` 遇空白就停止，不能读取含空格的整行。安全读取整行的常用方法是 `fgets`：

```c
#include <stdio.h>
#include <string.h>

int main(void) {
    char buf[50];

    printf("请输入一行文本（可含空格）：");
    if (fgets(buf, sizeof(buf), stdin) != NULL) {
        buf[strcspn(buf, "\n")] = '\0';  // 去掉可能存在的换行符
        printf("你输入的是：%s\n", buf);
    }

    return 0;
}
```

**`fgets` 要点：**

- 最多读取 `n-1` 个字符，最后自动补 `'\0'`。
- 如果读到换行符，会保留在缓冲区中。
- 输入超过 `n-1` 个字符时，只读取前 `n-1` 个，剩余字符留在输入缓冲区。
- 读到文件末尾或出错时返回 `NULL`。

也可以用扫描集 `%[^\n]`，但它不限制宽度时仍有溢出风险，且会留下换行符：

```c
char buf[50];
scanf("%49[^\n]", buf);  // 最多读 49 个字符，遇换行停止
```

### 1.4 格式化输入输出

```c
#include <stdio.h>

int main(void) {
    int num;
    double score;
    char name[20];

    printf("请输入整数和浮点数：");
    if (scanf("%d %lf", &num, &score) != 2) {
        printf("输入格式错误\n");
        return 1;
    }

    printf("请输入姓名（无空格）：");
    scanf("%19s", name);  // 限制宽度，给 '\0' 留位置

    printf("num = %d, score = %.2f, name = %s\n", num, score, name);
    return 0;
}
```

**要点：**

- `scanf` 返回成功读取的数据个数，可用于判断输入是否匹配。
- 读取普通变量必须加 `&`；字符数组名本身是地址，通常不加 `&`。
- `%c` 不跳过空白字符，前面有残留换行时可用 `" %c"`。
- `%s` 遇空白停止，不能读取含空格字符串。
- 用 `%19s` 这类宽度限制防止缓冲区溢出。

### 1.5 文件 I/O 基本流程

文件操作通常遵循：打开 → 检查 → 读写 → 关闭。

```c
#include <stdio.h>

int main(void) {
    // 写入文件
    FILE *fp = fopen("data.txt", "w");
    if (fp == NULL) {
        perror("fopen");
        return 1;
    }

    fprintf(fp, "name: %s, score: %.1f\n", "Tom", 95.5);
    fclose(fp);

    // 读取文件
    fp = fopen("data.txt", "r");
    if (fp == NULL) {
        perror("fopen");
        return 1;
    }

    char name[20];
    float score;
    if (fscanf(fp, "name: %19s, score: %f", name, &score) == 2) {
        printf("读取结果：%s %.1f\n", name, score);
    }

    fclose(fp);
    return 0;
}
```

**常用文件打开模式：**

| 模式 | 含义 | 文件不存在时 |
|---|---|---|
| `"r"` | 只读 | 打开失败，返回 `NULL` |
| `"w"` | 只写，清空或创建 | 创建新文件 |
| `"a"` | 追加写 | 创建新文件 |
| `"r+"` | 读写，从开头开始 | 打开失败 |
| `"w+"` | 读写，清空或创建 | 创建新文件 |
| `"a+"` | 读写，追加 | 创建新文件 |

文本模式下还可加 `b`，如 `"rb"`、`"wb"`，表示二进制模式。跨平台处理二进制文件时应显式使用 `b`。

### 1.6 逐行读取文件

```c
#include <stdio.h>

int main(void) {
    FILE *fp = fopen("data.txt", "r");
    if (fp == NULL) {
        perror("fopen");
        return 1;
    }

    char line[100];
    while (fgets(line, sizeof(line), fp) != NULL) {
        printf("%s", line);  // fgets 保留换行符
    }

    fclose(fp);
    return 0;
}
```

### 1.7 逐字符读取文件

```c
#include <stdio.h>

int main(void) {
    FILE *fp = fopen("data.txt", "r");
    if (fp == NULL) {
        perror("fopen");
        return 1;
    }

    int ch;
    while ((ch = fgetc(fp)) != EOF) {
        putchar(ch);
    }

    fclose(fp);
    return 0;
}
```

`fgetc` 返回 `int`，便于区分普通字符和 `EOF`。

## 2. I/O 避坑清单

1. `scanf` 读取普通变量必须加 `&`；字符数组名通常不加 `&`。
2. `%c` 不跳过空白；前面有残留换行时可用 `" %c"`。
3. `%s` 遇空白停止，不能读取含空格字符串；需要读整行时用 `fgets`。
4. `fgets` 会保留换行符，必要时用 `strcspn(buf, "\n")` 去除。
5. 文件打开后必须检查 `NULL`，使用后必须 `fclose`。
6. 格式说明符必须与数据类型匹配；`scanf` 读 `double` 用 `%lf`，`printf` 输出 `double` 常用 `%f`。
7. 不要使用 `gets()`；不要依赖 `fflush(stdin)`。
8. 字符串必须以 `'\0'` 结尾，否则字符串函数可能越界读取。
9. `strcpy`、`strcat` 不检查目标缓冲区大小，必要时用带长度限制的版本或 `snprintf`。
10. 数组下标从 0 开始，C 不自动检查越界。
11. 数组作为函数参数会退化为指针，函数内无法用 `sizeof` 得到数组长度，需额外传入长度。
12. 二维数组作为函数参数时，列数不能省略。
13. `getchar`、`fgetc` 返回 `int`，不要用 `char` 接收，以免无法正确判断 `EOF`。
14. 文件读写后关闭文件，确保缓冲区数据同步到磁盘。

## 3. 格式说明符

格式说明符用于 `printf`、`scanf`、`fprintf`、`fscanf` 等格式化 I/O 函数。格式符必须与数据类型匹配，否则可能导致乱码、读取错误或未定义行为。

### 3.1 常用格式说明符

| 格式符 | 对应类型 | 说明 |
|---|---|---|
| `%d` | `int` | 十进制整数 |
| `%i` | `int` | 十进制整数，`scanf` 中可自动识别进制 |
| `%u` | `unsigned int` | 无符号十进制 |
| `%x / %X` | 整型 | 十六进制小写/大写 |
| `%o` | 整型 | 八进制 |
| `%c` | `char` | 单个字符；`scanf` 中不跳过空白 |
| `%s` | `char[] / char*` | 字符串；遇空白停止 |
| `%[^\n]` | `char[] / char*` | 扫描集，读取到换行符为止，保留空格；仅用于输入 |
| `%f` | `float` / `double` 输出 | 默认保留 6 位小数 |
| `%.2f` | 浮点 | 保留 2 位小数 |
| `%e / %E` | 浮点 | 科学计数法 |
| `%lf` | `double` 输入 | `scanf` 读取 `double` 必须用 `%lf` |
| `%Lf` | `long double` | 长双精度 |
| `%p` | 指针 | 输出地址 |
| `%%` | 无 | 输出百分号 |

### 3.2 `printf` 与 `scanf` 的差异

`printf` 和 `scanf` 的格式符并不完全对称，最容易出错的是浮点数：

```c
double d = 3.14;

printf("%f\n", d);    // 输出 double 可以用 %f
scanf("%lf", &d);     // 输入 double 必须用 %lf
```

`float` 输入用 `%f`，`double` 输入用 `%lf`；输出时 `float` 和 `double` 都可以用 `%f`。`long double` 输入输出都用 `%Lf`。

### 3.3 宽度、精度与对齐

```c
printf("%5d\n", 42);      // 右对齐，占 5 位：   42
printf("%-5d|\n", 42);    // 左对齐，占 5 位：42   |
printf("%.2f\n", 3.14159); // 保留 2 位小数：3.14
printf("%8.2f\n", 3.14159); // 总宽 8，保留 2 位：    3.14
```

`scanf` 中也可以限制读取宽度，例如 `%19s` 最多读取 19 个字符，给 `'\0'` 留位置：

```c
char name[20];
scanf("%19s", name);
```

### 6.4 格式说明符避坑

1. 格式符必须与类型匹配，`%d` 不要对应 `double`。
2. `scanf` 读取普通变量必须加 `&`；字符数组名本身是地址，通常不加 `&`。
3. `%c` 不跳过空白字符；前面有残留换行时，可用 `" %c"` 跳过空白。
4. `%s` 遇空白停止，不能读取含空格的字符串；需要读整行时用 `fgets` 或扫描集。
5. `size_t` 用 `%zu`，不要用 `%d`。
6. 指针用 `%p`，不要用 `%d` 或 `%x` 强行输出。
