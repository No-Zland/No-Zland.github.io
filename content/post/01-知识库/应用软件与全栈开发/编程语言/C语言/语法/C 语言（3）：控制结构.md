## 1. 分支结构

分支结构根据条件选择执行路径。C 语言中主要有 `if` 语句和 `switch` 语句。

### 1.1 `if` 单分支

条件表达式为真（非 0）时执行语句块，否则跳过：

```c
if (条件表达式) {
    语句块;
}
```

```c
#include <stdio.h>

int main(void) {
    int num = 10;

    if (num > 0) {
        printf("%d 是正数\n", num);
    }

    return 0;
}
```

### 1.2 `if-else` 双分支

条件为真执行语句块 1，否则执行语句块 2：

```c
if (条件表达式) {
    语句块1;
} else {
    语句块2;
}
```

```c
#include <stdio.h>

int main(void) {
    int num = 7;

    if (num % 2 == 0) {
        printf("%d 是偶数\n", num);
    } else {
        printf("%d 是奇数\n", num);
    }

    return 0;
}
```

### 1.3 `if-else if-else` 多分支

依次判断条件，执行第一个为真的分支；所有条件都不满足时执行 `else`：

```c
if (条件表达式1) {
    语句块1;
} else if (条件表达式2) {
    语句块2;
} else {
    语句块n;
}
```

```c
#include <stdio.h>

int main(void) {
    int score = 85;

    if (score >= 90) {
        printf("等级：A\n");
    } else if (score >= 80) {
        printf("等级：B\n");
    } else if (score >= 60) {
        printf("等级：C\n");
    } else {
        printf("等级：D\n");
    }

    return 0;
}
```

**注意：**

- 条件按从上到下的顺序判断，第一个为真的分支执行后，后续分支不再判断。
- 多分支条件的顺序很重要。上例中 `score >= 90` 必须放在 `score >= 80` 之前，否则 95 分也会先命中 `>= 80`。
- `else` 总是与最近的未匹配 `if` 配对，写嵌套 `if` 时建议加花括号避免歧义。

### 1.4 `switch` 多条件匹配

`switch` 根据表达式的值匹配 `case` 常量，适合离散整型或枚举值：

```c
switch (表达式) {
    case 常量1:
        语句块1;
        break;
    case 常量2:
        语句块2;
        break;
    default:
        语句块n;
}
```

```c
#include <stdio.h>

int main(void) {
    int day = 3;

    switch (day) {
        case 1: printf("星期一\n"); break;
        case 2: printf("星期二\n"); break;
        case 3: printf("星期三\n"); break;
        case 4: printf("星期四\n"); break;
        case 5: printf("星期五\n"); break;
        case 6: printf("星期六\n"); break;
        case 7: printf("星期日\n"); break;
        default: printf("输入无效\n");
    }

    return 0;
}
```

**`switch` 要点：**

- `switch` 表达式必须是整型或枚举类型，不能是浮点数、字符串。
- `case` 后必须是编译期整型常量表达式，不能是变量。
- `break` 用于跳出 `switch`；缺少 `break` 会发生“贯穿”，继续执行下一个 `case`。
- `default` 可选，处理所有未匹配情况。
- 多个 `case` 可以共享同一段代码：

```c
switch (ch) {
    case 'a':
    case 'e':
    case 'i':
    case 'o':
    case 'u':
        printf("元音\n");
        break;
    default:
        printf("辅音或其他\n");
}
```

### 1.5 三元条件运算符

简单二选一可以用 `?:` 简化：

```c
int max = (a > b) ? a : b;
```

等价于：

```c
int max;
if (a > b) {
    max = a;
} else {
    max = b;
}
```

三元运算符适合简单赋值，嵌套过多会降低可读性，复杂逻辑仍应使用 `if-else`。

## 2. 循环结构

循环用于重复执行代码块。C 语言提供 `for`、`while`、`do-while` 三种循环。

### 2.1 `for` 循环：固定次数循环

```c
for (初始化表达式; 条件表达式; 更新表达式) {
    循环体;
}
```

执行流程：

1. 执行初始化表达式（只执行一次）。
2. 判断条件表达式，为真则执行循环体，为假则退出。
3. 执行更新表达式。
4. 重复步骤 2-3。

```c
#include <stdio.h>

int main(void) {
    for (int i = 1; i <= 10; i++) {
        printf("%d ", i);
    }
    printf("\n");
    return 0;
}
```

`for` 适合循环次数已知的场景。`for` 的初始化、条件、更新三部分都可以省略，但省略条件时等价于永真，需要配合 `break` 退出：

```c
for (;;) {
    // 无限循环，需要 break 退出
}
```

### 2.2 `while` 循环：先判断后执行

```c
while (条件表达式) {
    循环体;
}
```

先判断条件，**为真则执行**循环体，重复此过程；条件一开始为假时，循环体一次都不执行。

```c
#include <stdio.h>

int main(void) {
    int i = 1;
    int sum = 0;

    while (i <= 100) {
        sum += i;
        i++;
    }

    printf("1 到 100 的和为：%d\n", sum);
    return 0;
}
```

`while` 适合循环次数未知、依赖条件退出的场景。循环体内必须有改变条件的语句，否则可能死循环。

### 2.3 `do-while` 循环：先执行后判断

```c
do {
    循环体;
} while (条件表达式);
```

先执行循环体，再判断条件；条件为真则继续循环，否则退出。循环体至少执行一次。

```c
#include <stdio.h>

int main(void) {
    int num;

    do {
        printf("请输入一个正整数：");
        scanf("%d", &num);
    } while (num <= 0);

    printf("你输入的正整数是：%d\n", num);
    return 0;
}
```

`do-while` 适合 **“至少执行一次”** 的场景，例如输入校验。

### 2.4 三种循环的选择

| 循环 | 特点 | 适用场景 |
|---|---|---|
| `for` | 初始化、条件、更新集中在一行 | 循环次数已知或可计算 |
| `while` | 先判断后执行 | 循环次数未知，依赖条件退出 |
| `do-while` | 先执行后判断，至少执行一次 | 输入校验、菜单循环 |

三种循环可以互相转换，选择可读性最好的即可。

## 3. 循环控制

### 3.1 `break`：跳出当前循环或 `switch`

`break` 立即跳出当前所在的循环或 `switch`，执行后续代码：

```c
#include <stdio.h>

int main(void) {
    int arr[] = {2, 4, 6, 8, 10};
    int target = 6;
    int found = -1;

    for (int i = 0; i < 5; i++) {
        if (arr[i] == target) {
            found = i;
            break;
        }
    }

    if (found != -1) {
        printf("找到目标值，索引为：%d\n", found);
    } else {
        printf("未找到\n");
    }

    return 0;
}
```

`break` 只跳出**最内层**循环或 `switch`，不会跳出多层嵌套。

### 3.2 `continue`：跳过本次循环剩余部分

`continue` 跳过本次循环的剩余代码，直接进入下一次循环的条件判断：

```c
#include <stdio.h>

int main(void) {
    for (int i = 1; i <= 10; i++) {
        if (i % 2 == 0) {
            continue;  // 偶数跳过，不执行 printf
        }
        printf("%d ", i);
    }
    printf("\n");
    return 0;
}
```

**注意：**

- `continue` 不会跳出循环，只是跳过当前这一轮。
- `for` 循环中 **`continue` 会执行更新表达式**；`while` 循环中如果更新语句在 `continue` 之后，可能造成死循环。
- `break` 和 `continue` 都只作用于最内层循环。

### 3.3 多层循环的退出

常用两种方式：

1. `break` 只能跳出最内层循环。

2. `goto` 通常不推荐，但 **“从多层嵌套中统一跳转到清理代码”** 是其少数合理用法之一。

```c
// 方式一：使用标志变量
int found = 0;
for (int i = 0; i < 3 && !found; i++) {
    for (int j = 0; j < 3; j++) {
        if (matrix[i][j] == target) {
            found = 1;
            break;
        }
    }
}

// 方式二：使用 goto（谨慎使用，但跳出多层循环是合理场景）
for (int i = 0; i < 3; i++) {
    for (int j = 0; j < 3; j++) {
        if (matrix[i][j] == target) {
            goto found_label;
        }
    }
}
found_label:
printf("找到目标\n");
```
