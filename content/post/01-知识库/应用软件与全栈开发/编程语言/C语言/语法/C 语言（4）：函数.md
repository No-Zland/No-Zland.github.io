## 1. `main` 函数：程序入口

### 1.1 标准形式

`main` 函数是 C 程序的唯一入口。标准形式优先使用：

| 形式 | 适用场景 |
|---|---|
| `int main(void)` | 无命令行参数 |
| `int main(int argc, char *argv[])` | 需要访问命令行参数 |

`void main()` 不是标准形式，部分编译器可能接受，但不推荐跨平台使用。

```c
#include <stdio.h>

int main(void) {
    printf("Hello, C\n");
    return 0;
}
```

### 1.2 命令行参数

`argc` 是参数个数；`argv[0]` 通常是程序名或执行路径，`argv[1]` 才是第一个用户参数；标准保证 `argv[argc] == NULL`。

```c
#include <stdio.h>

int main(int argc, char *argv[]) {
    printf("argc = %d\n", argc);

    for (int i = 0; i < argc; i++) {
        printf("argv[%d] = %s\n", i, argv[i]);
    }

    return 0;
}
```

假设编译为 `program`，执行 `./program hello world`，输出类似：

```text
argc = 3
argv[0] = ./program
argv[1] = hello
argv[2] = world
```

`argv[0]` 的具体值取决于启动方式，可能是 `./program`、绝对路径或空字符串，不应写死。

### 1.3 返回值与退出状态

`main` 的返回值表示程序退出状态：

- 返回 `0` 或 `EXIT_SUCCESS`：程序正常退出。
- 返回非 0 或 `EXIT_FAILURE`：程序异常退出。

```c
#include <stdio.h>
#include <stdlib.h>

int main(void) {
    FILE *fp = fopen("data.txt", "r");
    if (fp == NULL) {
        perror("fopen");
        return EXIT_FAILURE;
    }

    fclose(fp);
    return EXIT_SUCCESS;
}
```

在 Linux/macOS 中可用 `echo $?` 查看上一个程序的退出状态；Windows 命令行用 `%ERRORLEVEL%`。注意 POSIX 环境通常只能看到状态码的低 8 位。

### 1.4 不应在用户代码中调用 `main`

`main` 是程序入口，不应由用户代码主动调用。C++ 标准明确禁止；C 标准虽未以同样方式绝对禁止，但也不应依赖调用 `main`，否则可能导致重入或递归调用风险。

### 1.5 `return` 与 `exit`

| 写法                   | 行为                                   |
| -------------------- | ------------------------------------ |
| `main` 中 `return n;` | 以状态码 `n` 结束程序                        |
| 子函数中 `return n;`     | 仅返回给调用者，不终止程序                        |
| `exit(n)`            | 终止整个进程，刷新 stdio 缓冲区，调用 `atexit` 注册函数 |
| `_Exit(n)`           | 终止进程，但不刷新 stdio 缓冲区，不调用 `atexit` 函数  |

`exit` 需要包含 `<stdlib.h>`：

```c
#include <stdio.h>
#include <stdlib.h>

void check_num(int num) {
    if (num < 0) {
        printf("错误：数字不能为负\n");
        exit(EXIT_FAILURE);
    }
}

int main(void) {
    check_num(-5);
    printf("这行不会执行\n");
    return 0;
}
```

## 2. 函数定义、声明与调用

### 2.1 函数定义

函数定义由返回值类型、函数名、参数列表和函数体组成：

```c
返回值类型 函数名(参数类型1 参数名1, 参数类型2 参数名2, ...) {
    函数体;
    return 返回值;
}
```

```c
int sum(int a, int b) {
    return a + b;
}
```

- 返回值类型为 `void` 时，函数不返回值，可省略 `return` 或只写 `return;`。
- 无参数时参数列表写 `void`，例如 `int func(void)`。
- 函数名遵循标识符命名规则。

### 2.2 函数声明

函数声明用于提前告知编译器函数的存在。函数定义在调用位置之后时，必须先声明：

```c
#include <stdio.h>

int sum(int a, int b);  // 函数声明，以分号结尾

int main(void) {
    printf("%d\n", sum(3, 5));
    return 0;
}

int sum(int a, int b) {  // 函数定义
    return a + b;
}
```

声明中的参数名可以省略，例如 `int sum(int, int);`。

### 2.3 函数调用

函数调用格式为 `函数名(实参列表)`：

```c
int result = sum(3, 5);
```

调用时，实参的值或地址传递给形参。C 语言参数传递只有一种方式：**传值**。所谓“传址调用”本质是把地址值传给指针形参。

### 5.4 传值调用

形参是实参的副本，函数内修改形参不影响实参：

```c
#include <stdio.h>

void change(int x) {
    x = 100;  // 只修改形参 x
}

int main(void) {
    int num = 10;
    change(num);
    printf("num = %d\n", num);  // 仍为 10
    return 0;
}
```

### 2.5 传址调用

传入实参的地址，函数通过指针修改实参指向的数据：

```c
#include <stdio.h>

void swap(int *p1, int *p2) {
    int temp = *p1;
    *p1 = *p2;
    *p2 = temp;
}

int main(void) {
    int a = 5, b = 10;
    swap(&a, &b);
    printf("a = %d, b = %d\n", a, b);  // a = 10, b = 5
    return 0;
}
```

**要点：**

- 传值调用适合只读参数或不需要修改实参的场景。
- 传址调用适合需要修改实参、传递大结构体避免复制、或需要返回多个值的场景。
- 传入指针后，函数内要先检查指针是否为 `NULL`，再解引用。

### 2.6 数组作为函数参数

数组作为参数时退化为指向首元素的指针，函数内无法通过 `sizeof` 得到数组长度，需额外传入长度：

```c
#include <stdio.h>

void print_arr(int arr[], int n) {
    for (int i = 0; i < n; i++) {
        printf("%d ", arr[i]);
    }
    printf("\n");
}

int main(void) {
    int a[5] = {1, 2, 3, 4, 5};
    print_arr(a, 5);
    return 0;
}
```

`int arr[]` 与 `int *arr` 在参数位置上等价。数组参数本质是传址，函数内修改 `arr[i]` 会影响原数组。

## 63 递归

递归函数是直接或间接调用自身的函数。递归必须满足两个条件：

- **终止条件**：递归必须有出口，否则会无限递归导致栈溢出。
- **递归关系**：将原问题分解为更小的同类子问题。

### 3.1 阶乘

```c
#include <stdio.h>

int factorial(int n) {
    if (n <= 1) {          // 终止条件
        return 1;
    }
    return n * factorial(n - 1);  // 递归关系
}

int main(void) {
    printf("5! = %d\n", factorial(5));  // 120
    return 0;
}
```

### 3.2 斐波那契数列

```c
int fibonacci(int n) {
    if (n == 1 || n == 2) {  // 终止条件
        return 1;
    }
    return fibonacci(n - 1) + fibonacci(n - 2);  // 递归关系
}
```

递归写法直观，但斐波那契的朴素递归会重复计算大量子问题，`n` 较大时效率极低。实际可用迭代或记忆化：

```c
int fibonacci_iter(int n) {
    if (n == 1 || n == 2) {
        return 1;
    }

    int a = 1, b = 1, c = 0;
    for (int i = 3; i <= n; i++) {
        c = a + b;
        a = b;
        b = c;
    }
    return c;
}
```

### 3.3 递归避坑

1. 必须有终止条件，且终止条件必须能在有限步内到达。
2. 递归深度过大会导致栈溢出，深度较大时应改用迭代。
3. 递归可能有大量重复计算，必要时用记忆化或迭代优化。
4. 递归函数的参数应逐步向终止条件靠近，否则可能无限递归。

## 4. 函数指针

函数指针是保存函数地址的指针变量，可用于实现回调。

### 4.1 定义与调用

```c
返回值类型 (*指针名)(参数类型1, 参数类型2, ...);
```

```c
#include <stdio.h>

int add(int a, int b) {
    return a + b;
}

int main(void) {
    int (*p)(int, int) = add;  // p 指向 add 函数
    printf("%d\n", p(3, 5));   // 通过函数指针调用，输出 8
    printf("%d\n", (*p)(3, 5)); // 等价写法
    return 0;
}
```

### 4.2 回调函数

函数指针常用于把函数作为参数传递，实现回调：

```c
#include <stdio.h>

int add(int a, int b) { return a + b; }
int mul(int a, int b) { return a * b; }

int calculate(int (*func)(int, int), int a, int b) {
    return func(a, b);
}

int main(void) {
    int (*p)(int, int) = add;
    printf("3 + 5 = %d\n", calculate(p, 3, 5));  // 8

    p = mul;
    printf("3 * 5 = %d\n", calculate(p, 3, 5));  // 15

    return 0;
}
```

### 4.3 函数指针避坑

1. 函数指针的类型必须与目标函数匹配：返回值类型和参数类型都要一致。
2. `int (*p)(int, int)` 中括号不能省，`int *p(int, int)` 是返回指针的函数声明。
3. 函数名在表达式中通常退化为函数指针，`p = add` 和 `p = &add` 等价。
4. 调用函数指针前应确保它已指向有效函数，未初始化的函数指针解引用属于未定义行为。

## 5. 综合示例：菜单循环 + 函数回调

下面把循环、`switch`、函数和函数指针串在一起：

```c
#include <stdio.h>

int add(int a, int b) { return a + b; }
int sub(int a, int b) { return a - b; }
int mul(int a, int b) { return a * b; }

int main(void) {
    int choice;
    int a, b;

    do {
        printf("\n1. 加法  2. 减法  3. 乘法  0. 退出\n");
        printf("请选择：");
        scanf("%d", &choice);

        if (choice == 0) {
            break;
        }

        printf("请输入两个整数：");
        scanf("%d %d", &a, &b);

        switch (choice) {
            case 1: printf("结果：%d\n", add(a, b)); break;
            case 2: printf("结果：%d\n", sub(a, b)); break;
            case 3: printf("结果：%d\n", mul(a, b)); break;
            default: printf("无效选择\n");
        }
    } while (1);

    return 0;
}
```

这个例子中：

- `do-while` 保证菜单至少显示一次。
- `switch` 根据选择分派到不同函数。
- `break` 用于跳出 `switch` 和退出菜单循环。
- 三个运算函数通过函数名直接调用；如果需要运行时切换算法，可改成函数指针数组。
