## 1. 表达式定义

表达式由 **操作数** 和 **运算符** 组成。C 语言中每个表达式**都有值，也有类型**。

### 1.1 优先级与结合性总表

**数字越小，优先级越高**；同优先级按结合性决定执行顺序。

![[C语言优先级与结合性总表.jpg]]

**几个容易出错的点：**

- `*` 在优先级 2 是 **解引用**，在优先级 3 是 **乘法**，二者不是同一个用法。
- `&` 在优先级 2 是 **取地址**，在优先级 8 是 **按位与**。
- `+ -` 在优先级 2 是 **一元正负号**，在优先级 4 是 **二元加减**。
- 赋值运算符优先级很低，且是右结合，所以 `a = b = 0` 等价于 `a = (b = 0)`。
- 逗号运算符优先级最低，`a = 1, b = 2` 先执行 `a = 1`，再执行 `b = 2`，整个表达式结果为 `2`。

### 1.2 短路求值

**`&&` 和 `||`** 具有 **短路求值** 特性。

**本质：** 左侧结果已能决定整体结果时，右侧不再计算。

```c
int a = 0;
int b = 10;

if (a != 0 && b / a > 1) {  // a != 0 为假，右侧 b / a 不会执行
    printf("不会到这里\n");
}

if (a == 0 || b / a > 1) {  // a == 0 为真，右侧 b / a 不会执行
    printf("会到这里\n");
}
```

这个特性常用于 **“先判空、再使用”** 的场景，例如 `if (p != NULL && p->value > 0)`。

**注意：** 短路 **只保证右侧不被求值**，不改变运算符优先级；复杂条件仍建议加括号。

## 2. 类型转换

C 语言中不同类型混合运算时会发生转换。转换分为 **隐式转换** 和 **强制转换** 。

### 2.1 隐式转换

编译器自动完成，通常遵循 **“低精度→高精度”** 的方向，尽量避免数据丢失：

```c
int a = 10;
float b = 3.14f;
float c = a + b;  // a 先隐式转为 float，再与 b 相加
```

常见提升顺序（粗略理解）：

$$
char / short → int → long → long long → float → double
$$


### 2.2 强制转换

由程序员**显式指定**目标类型，格式为 `(目标类型)表达式`：

```c
double d = 5.99;
int e = (int)d;              // e = 5
float f = 10.5f;
int g = (int)(f + 2.5);      // 先算 f + 2.5 = 13.0，再转为 int，g = 13
```

不会改变原变量的值，只影响表达式的值或赋值结果。

强制转换要谨慎使用，尤其是指针类型之间的转换。

### 2.3 注意

1. **对齐兼容：** 强制转换指针类型时，要确保对齐和实际对象类型兼容。

2. **精度丢失：** 

高精度转低精度可能丢失数据，例如 `double` 转 `int` 会截断小数。

浮点数转整数是**截断**，**不是四舍五入**。

3. **未知性：** 

赋值时的隐式转换**不一定报错**，编译器可能只给警告，需要自己检查。

**有符号和无符号混合运算**（如比较）时，有符号数可能被转换为无符号数，导致意外结果。

```c
double d = 3.99;
int n = d;        // n = 3，小数被截断
unsigned int u = 10;
int i = -1;
if (i < u) {      // i 可能被转换为无符号数，比较结果与直觉不同
    printf("可能出乎意料\n");
}
```

## 3. 变量：定义、初始化与赋值

**变量** 是程序中用于存储数据的内存空间。

1. **定义**：申请空间，例如 `int age;`
2. **初始化**：定义时赋初值，例如 `int age = 18;`
3. **赋值**：定义后修改值，例如 `age = 20;`

```c
int age;              // 定义，未初始化
float score = 95.5f;  // 定义并初始化
char gender = 'M';

age = 18;             // 赋值
age = 20;             // 重新赋值，覆盖旧值
```

**未定义行为：** 局部变量未初始化时，值是不确定的，不要假设局部变量默认是 0。

### 3.1 作用域与生命周期

| 类别     | 定义位置                  | 作用域       | 生命周期           |
| ------ | --------------------- | --------- | -------------- |
| 局部变量   | 函数或代码块内               | 当前函数/代码块  | 进入块创建，离开块销毁    |
| 全局变量   | 所有函数外                 | 从定义处到文件结束 | 程序启动到程序结束      |
| 静态局部变量 | 函数/代码块内，用 `static` 修饰 | 当前函数/代码块  | 整个程序运行期，仅初始化一次 |

```c
#include <stdio.h>

int global = 100;  // 全局变量

void count(void) {
    static int cnt = 0;  // 静态局部变量，仅初始化一次
    cnt++;
    printf("cnt = %d\n", cnt);
}

int main(void) {
    count();  // cnt = 1
    count();  // cnt = 2
    printf("global = %d\n", global);
    return 0;
}
```

**静态局部变量** 的作用域仍在函数内，但生命周期是整个程序：**函数多次调用时，它保留上一次的值**。

### 3.2 同名变量

若局部变量与全局变量 **同名**，作用域内 **优先访问局部变量**：

```c
#include <stdio.h>

int x = 10;

void func(void) {
    int x = 20;
    printf("func: x = %d\n", x);  // 20，访问局部变量
}

int main(void) {
    func();
    printf("main: x = %d\n", x);  // 10，访问全局变量
    return 0;
}
```

**注意：** 同名变量容易造成阅读混淆，实际项目中应尽量避免。

## 4. 常量

常量是值不可修改的量。C 语言中常见形式有四种：

| 形式 | 写法 | 特点 |
|---|---|---|
| 字面常量 | `123`、`3.14f`、`'A'`、`"hello"` | 直接写出的值 |
| `const` 常量 | `const int MAX = 100;` | 编译期检查，不可修改 |
| 宏常量 | `#define PI 3.14159` | 预处理文本替换，无类型检查 |
| 枚举常量 | `enum Week { MON, TUE, WED };` | 本质为整型，默认从 0 递增 |

```c
#define PI 3.14159
const int MAX = 100;
enum Week { MON, TUE, WED };  // MON=0, TUE=1, WED=2
```

### 4.1 宏常量与 `const` 常量的区别

1. **宏**

是 **预处理阶段** 的 **文本替换**，不参与类型检查，也没有作用域概念：

```c
#define SQUARE(x) ((x) * (x))

int a = SQUARE(1 + 2);  // 展开为 ((1 + 2) * (1 + 2))，结果为 9
```

**注意：** 如果宏参数不加括号，很容易出错：

```c
#define BAD_SQUARE(x) x * x

int b = BAD_SQUARE(1 + 2);  // 展开为 1 + 2 * 1 + 2，结果为 5
```

2. **`const` 常量** 

有类型、有作用域，**调试时也能看到符号**，通常更安全。对于整型常量和错误码，`enum` 或 `const` 往往比宏更 **利于调试和类型检查**。

### 4.2 枚举常量

```c
enum Week {
    MON,  // 0
    TUE,  // 1
    WED   // 2
};

enum Status {
    OK = 0,
    ERR_PARAM = 1,
    ERR_FILE = 2
};
```

**本质：** 是**整型**，适合表示离散状态集合。相比直接写 `0`、`1`、`2`，枚举能 **提高可读性**。

## 5. 基本数据类型

**注意：** 不同平台字节长度可能不同，可用  ** `sizeof` **  验证。

下表为常见值，不应视为跨平台绝对保证。

| 类型                   |      常见字节 | 常见格式说明符          | 说明          |
| -------------------- | --------: | ---------------- | ----------- |
| `char`               |         1 | `%c` / `%hhd`    | 字符或小整数      |
| `short`              |         2 | `%hd`            | 短整型         |
| `int`                |         4 | `%d` / `%i`      | 常用整型        |
| `long`               |     4 或 8 | `%ld`            | 平台相关        |
| `long long`          |         8 | `%lld`           | 大整数         |
| `unsigned char`      |         1 | `%hhu`           | 无符号字符       |
| `unsigned short`     |         2 | `%hu`            | 无符号短整型      |
| `unsigned int`       |         4 | `%u`             | 无符号整型       |
| `unsigned long`      |     4 或 8 | `%lu`            | 无符号长整型      |
| `unsigned long long` |         8 | `%llu`           | 无符号大整数      |
| `float`              |         4 | 输出 `%f`，输入 `%f`  | 单精度浮点       |
| `double`             |         8 | 输出 `%f`，输入 `%lf` | 双精度浮点       |
| `long double`        |      平台相关 | `%Lf`            | 长双精度，跨平台差异大 |
| 指针                   |     4 或 8 | `%p`             | 输出地址        |
| 数组                   | 元素大小 × 个数 | 无统一格式符           | 连续内存块       |
| 结构体                  |   成员大小加对齐 | 无统一格式符           | 复合类型        |

### 5.1 用 `sizeof` 验证类型长度

```c
#include <stdio.h>

int main(void) {
    printf("char: %zu\n", sizeof(char));
    printf("int: %zu\n", sizeof(int));
    printf("long: %zu\n", sizeof(long));
    printf("long long: %zu\n", sizeof(long long));
    printf("float: %zu\n", sizeof(float));
    printf("double: %zu\n", sizeof(double));
    printf("pointer: %zu\n", sizeof(void *));
    return 0;
}
```

`sizeof` 返回 `size_t` 类型，输出用 `%zu`。不要假设 `int` 一定是 4 字节，也不要假设指针一定是 8 字节。

### 5.2 有符号与无符号

`char`、`short`、`int`、`long` 默认是否带符号由实现决定，但通常 `char` 是否有符号取决于平台。需要明确时，使用 `signed char` 或 `unsigned char`。

无符号类型不表示负数，混合比较时容易出问题：

```c
unsigned int u = 1;
int i = -1;

if (i < u) {
    printf("直觉上 i 更小\n");
} else {
    printf("实际可能走到这里\n");
}
```

不要把有符号和无符号混在一起比较，必要时先统一类型。
