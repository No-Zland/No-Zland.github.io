实验一：汇编语言运行环境及方法

1.实验目的：

（1）熟悉汇编语言运行环境和方法。

（2）了解如何使用汇编语言编制程序。

2.实验内容：

（1）学习输入、编辑汇编语言程序。

（2）学习对汇编语言程序进行汇编、连接和运行。

3.实验步骤：

（1）在DOS提示符下，进入MASM5.0目录。具体操作：用鼠标依次点击“开始-程序-附件-命令提示符”，或者“开始-运行”输入“cmd”进入DOS模拟环境。

常用基本DOS命令：

|                                                                                                                                                                                                                                                                                                                                                  |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 格式：      说明：<br><br>D:              去往D盘<br><br>cd..            返回上一级目录<br><br>cd  文件夹名    目录切换到该文件名（子目录）下<br><br>cd\             直接回根目录<br><br>dir             显示当前根目录下的文件目录<br><br>dir/s           显示所有目录<br><br>dir/p           目录多的时候，p用来分屏，显示完一屏后停下来<br><br>help            指令帮助<br><br>cls             清除屏幕<br><br>notepad         打开记事本程序 |

（2）在MASM5.0目录下启动EDIT编辑程序，也可以用其它任何一个文本编辑器编辑。输入、编辑源程序并保存在指定的目录中。源程序要以“.asm”为扩展名。例如：edit  abc.asm

（3）用汇编程序masm对源程序汇编，如果出现“error”或者“warning”请仔细检查源程序，不断修改错误，直至汇编通过为止。汇编结束会产生相应的.obj目标文件。

例如：masm  abc.asm

（4）用连接程序link产生相应的.exe可执行文件。例如：link  abc.obj

（5）执行程序。可直接从DOS执行程序，即在DOS环境中，输入文件名回车即可。
