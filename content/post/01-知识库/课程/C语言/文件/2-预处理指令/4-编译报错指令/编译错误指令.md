编译错误：#error 指令

在条件不满足时触发编译错误，常用于提示不支持的环境（如上文跨平台示例）；

1. **预处理指令与** **main** **的配合**：

调试时用#define DEBUG 开启 main 中的调试日志，发布时关闭；跨平台程序用条件编译适配 main 中调用的系统函数（如休眠、文件操作）。

2. **宏定义简化** **main** **逻辑**：

用宏定义常用常量（如数组长度、错误码），避免 main 中硬编码：

```c
#define ARR_SIZE 10

#define ERR_PARAM 1

int main(void) {

    int arr[ARR_SIZE]; // 宏简化长度定义    
    
    if (/* 参数错误 */) {    
        
        return ERR_PARAM; // 宏简化错误码    
		
    }    
    
    return 0;
    
}
```
