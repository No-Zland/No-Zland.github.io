控制程序的执行顺序，是实现逻辑的核心，分支结构用于根据条件选择不同的执行路径，C 语言中主要有 if 语句和 switch 语句。

# 1. if语句
## 1.1 单分支：if(条件表达式) 语句块

当条件表达式为真（非 0）时，执行语句块；否则跳过。

```c
if (条件表达式) {
    语句块;
}
````

示例：判断一个数是否为正数

```c
#include <stdio.h>

int main() {

    int num = 10;
    
    if (num > 0) {
	    
        printf("%d是正数\n", num);
        
    }
    
    return 0;
    
}
```

## 1.2 双分支：if (条件表达式) {语句块1;} else {语句块2;}

条件表达式为真执行语句块 1，否则执行语句块 2。

```c
if (条件表达式) {

    语句块1;
    
} else {
	
    语句块2;
    
}
```

示例：判断一个数是奇数还是偶数

```c
#include <stdio.h>

int main() {
	
    int num = 7;
    
    if (num % 2 == 0) {
	    
        printf("%d是偶数\n", num);
        
    } else {
	    
        printf("%d是奇数\n", num);
        
    }
    
    return 0;
    
}
```

## 1.3  多分支：if (条件表达式1) {语句块1;} else if (条件表达式2){语句块2;}...else {语句块n;}

依次判断条件，执行第一个为真的语句块；若所有条件都不满足，执行 else 后的语句块 n。

```c
if (条件表达式1) {

    语句块1;
    
} else if (条件表达式2) {

    语句块2;
    
}
...
else {

    语句块n;
    
}
```

示例：根据分数判断等级（A:≥90，B:80-89，C:60-79，D:＜60）

```c
#include <stdio.h>
int main() {

    int score = 85;
    
    if (score >= 90) {
    
        printf("等级：A\n");
        
    } else if (score >= 80) {
    
        printf("等级：B\n");
        
    } else if (score >= 60) {
    
        printf("等级：C\n");
        
    } else {
    
        printf("等级：D\n");
        
    }
    return 0;
}
```

# 2. 多条件匹配：switch (条件表达式)

根据表达式的值，匹配对应的 case 常量，执行其后的语句块；break （见循环结构）用于跳出 switch 结构，否则会”贯穿“；default 处理所有未匹配的情况（可选）。

```c
switch (表达式) {
	
    case 常量1:
	    
        语句块1;
        
        break;
        
    case 常量2:
	    
        语句块2;
        
        break;
    ...
    default:
	    
        语句块n;
        
}
```

示例：根据数字输出对应星期

```c
#include <stdio.h>

int main() {

    int day = 3;
    
    switch (day) {
    
        case 1:printf("星期一\n");break;
        
        case 2:printf("星期二\n");break;
        
        case 3:printf("星期三\n");break;
        
        case 4:printf("星期四\n");break;
        
        case 5:printf("星期五\n");break;
        
        case 6:printf("星期六\n");break;
        
        case 7:printf("星期日\n");break;
        
        default: printf("输入无效\n");
        
    }
    
    return 0;
}
```
