# 运算符重载

## 知识点详细总结

- **基本概念**：运算符重载是对已有的运算符赋予多重含义，使得同一运算符作用于不同类型的数据时，能够产生不同的行为。

- **限制**：

- 不能改变运算符的操作个数、优先级和结合性。

- 可以改变运算符的原有功能（即重载后功能可与原功能不同）。

- 并非所有运算符都可重载，不能重载的运算符包括==“.”、“.* ”、“::”、“sizeof”和“?:”==。

- **重载函数类型**：

- 成员函数、普通函数、友元函数可以重载运算符。

- ==构造函数、析构函数==不能直接重载运算符。

- **参数规则**：

- ==友元函数重载运算符==时，==参数至少需要1个；若为无参则重载错误==。

- ==成员函数重载运算符==时，==第一个操作数是对象本身（或this指针）==。

- **具体运算符重载**：

- 双目运算符“>”重载为友元函数时，表达式`obj1>obj2`会被解释为==`operator>(obj1,obj2)`==。

- 单目运算符“++”重载为友元函数时，表达式`++obj`会被解释为==`operator++(obj)`==；重载为成员函数时，原型通常为`T& operator++()`。

- ==“=”必须用成员函数重载==。

- ==“<<”要求用友元函数重载==。

- **函数名**：重载运算符的==函数名由`operator`加运算符==组成。

# 函数模板与类模板

## 知识点详细总结

- **功能**：模板的主要作用是提高代码的可重用性，用于解决函数体相同但参数类型不同的问题，避免代码冗余。

- **函数模板**：

- 定义格式需要==正确声明类型参数==，可包含多个类型参数（并非只能有一个）。

- 类型参数不仅可以出现在形参表中，还可以在==函数体等其他位置==使用。

- 模板形参是定义中使用的`T`等标识符，用于表示通用类型。

- 实例化过程由编译器在编译时自动完成，根据实际调用的参数类型生成具体的函数版本。

- 允许与同名的非模板函数重载，编译器会根据调用情况选择合适的函数。

- **类模板**：

- 类属类被称为==模板类==。

- 定义时类型参数的大小写必须保持一致，否则会导致错误。

- 实例化需要在定义对象时指定类型参数，生成的具体模板类如==`tanytemp<int>`==（其中`tanytemp`是类模板名，`int`是指定的类型参数）。

# C++的输入和输出

## 知识点详细总结

- **流对象**：

- ==`cin`==是==`istream`类==的==对象==，用于标准输入。

- ==`cout`==是==预定义的输出流对象==，用于标准输出。

- `cerr`和`clog`用于输出错误信息，其中==`cerr`不缓冲，`clog`有缓冲==。

- **格式控制**：

- 十六进制输出可使用==`cout.setf(ios::hex)`==成员函数或`hex`操作符。

- ==`setbase`操作符==既可以用于输入，也可以用于输出，用于==设置进制==。

- ==`setw`操作符==用于设置输出宽度，使用时需包含`<iomanip>`头文件。

- ==`setfill`操作符==用于设置填充字符，对应的成员函数是`fill`。

- ==`oct`操作符==用于八进制的输入输出。

- **输入输出函数**：

- ==`getline`==函数用于从输入流中读取一行字符。

- ==`read`函数==从输入流中提取指定长度的字节序列。

- ==`write`函数==将指定长度的字节序列插入到输出流中。

- `cin>>`可读取多种C++标准类型的数据，而`cin.getline()`仅用于输入字符型数据。

- **文件处理**：

- ==`fstream`类==用于处理文件的输入输出操作。

- 使用==`fstream`流类==定义对象并打开磁盘文件时，默认的打开方式不是`ios::out`。

- **状态标志操作**：

- ==`setf`成员函数==用于==设置==状态标志。

- ==`unsetf`成员函数==用于==清除==状态标志。

- ==`rdstate`成员函数==用于==获取==状态标志。
