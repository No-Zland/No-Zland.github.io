# 小红走网格
## 题目描述
在二维平面坐标系中，小红初始位置为 (0,0)。她可以向四个方向移动，移动的步数由四个正整数 \(a\)、\(b\)、\(c\)、\(d\) 定义，分别表示小红向上、向下、向左和向右移动一次的步数。
* 向上移动一次，走 \(a\) 步：(0,0) \(\rightarrow\) (0,\(a\))；
* 向下移动一次，走 \(b\) 步：(0,0) \(\rightarrow\) (0,\(-b\))；
* 向左移动一次，走 \(c\) 步：(0,0) \(\rightarrow\) (\(-c\),0)；
* 向右移动一次，走 \(d\) 步：(0,0) \(\rightarrow\) (\(d\),0)。
小红最终想要到达的目标位置为 \((x,y)\)。请判断小红是否可以通过上述步数到达目标位置。
## 输入描述：
每个测试文件均包含多组测试数据。第一行输入一个整数 \(T (1 \le T \le 10^4)\) 代表数据组数，每组测试数据描述如下：
在一行上输入六个整数 $x, y, a, b, c, d (1 \le x, y, a, b, c, d \le 10^9)$代表目标位置所在坐标、向上下左右四个方向单次移动的步数。
## 输出描述：
对于每一组测试数据，新起一行。如果小红可以到达目标位置，输出 YES；否则，直接输出 NO。
## 示例1
### 输入
```text
3
1 1 1 1 1 1
3 3 6 6 6 6
5 1 1 1 1 3
```
### 输出
```text
YES
NO
YES
```
### 说明
对于第一组测试数据，其中一种可行的方案是，向上移动 1 步到达 (0,1)，然后向右移动 1 步到达 (1,1)。
对于第二组测试数据，我们可以证明，小红无法通过给定的步数到达 (3,3)。
对于第三组测试数据，其中一种可行的方案是，向右移动 3 步到达 (3,0)、向左移动 1 步到达 (2,0)、向右移动 3 步到达 (5,0)、最后向上移动 1 步到达 (5,1)。

---
```cpp
#include <bits/stdc++.h>
using namespace std;
using ll = long long;
ll gcd(ll a, ll b) {
    return b == 0 ? a : gcd(b, a % b);
}
int main() {
    int T;
    cin >> T;
    while (T--) {
        ll x, y, a, b, c, d;
        cin >> x >> y >> a >> b >> c >> d;
        // 裴蜀定理
        bool y_possible = (y % gcd(a, b) == 0);
        bool x_possible = (x % gcd(c, d) == 0);
        cout << (x_possible && y_possible ? "YES" : "NO") << endl;
    }
    return 0;
}
```
这道题属于**数论**中的**线性丢番图方程**问题，具体涉及：
1. **裴蜀定理（Bézout's identity）**
2. **最大公约数（GCD）的应用**
3. **线性不定方程的非负整数解存在性判断**
## 详细的解题思维过程
### 1. 问题转化
首先，我们需要把移动过程抽象成数学方程。
设：
- 向上移动 pp 次，向下移动 qq 次
- 向右移动 rr 次，向左移动 ss 次
那么最终位置坐标满足：
- 纵坐标：$p×a−q×b=y$
- 横坐标：$r×d−s×c=x$
其中 p,q,r,sp,q,r,s 都是**非负整数**。
### 2. 分治思想
观察发现，**x 方向和 y 方向是独立的**！小红可以在 y 方向上下移动的同时，在 x 方向左右移动，两者互不影响。所以我们可以把问题拆分成两个独立的子问题：
- **子问题1**：是否存在非负整数 p,qp,q 使得 p⋅a−q⋅b=yp⋅a−q⋅b=y
- **子问题2**：是否存在非负整数 r,sr,s 使得 r⋅d−s⋅c=xr⋅d−s⋅c=x
只有两个子问题同时有解，答案才是 YES。
### 3. 数学本质
对于方程 $p⋅a−q⋅b=y$：
#### 第一步：整数解的存在性（裴蜀定理）
根据数论中的**裴蜀定理**：方程 $p⋅a−q⋅b=y$ 有**整数解**（p, q 可以是负整数）的**充要条件**是：
$gcd⁡(a,b)∣y$
即 y 必须是 a 和 b 的最大公约数的倍数。
这是因为 p⋅a−q⋅b 能表示的所有整数，恰好是 gcd(a,b) 的所有倍数。
#### 第二步：非负解的存在性
但是，我们不仅需要整数解，还需要**非负整数解**（p ≥ 0, q ≥ 0）。
这时候需要思考：如果存在一组整数解 $(p_0,q_0)$，那么通解形式是：
$p=p_0​+k⋅g_b​,q=q_0​+k⋅g_a​$
其中 g=gcd(a,b)，k 是任意整数。
**关键洞察**：通过选择合适的 k，我们总能让 p 和 q 都变成非负数吗？
- 如果 $p_0$​ 是负数，我们可以增加 k（加上 $b/g$）让 p 变大
- 如果$q_0​$ 是负数，我们可以减少 k（减去 $a/g$）让 q 变大
但要注意：p 和 q 的变化是联动的。增加 k 会让 p 变大，同时让 q 也变大（因为 q 的系数是 $a/g>0$）。这意味着我们不能独立调整 p 和 q。
**深入分析**：
实际上，只要存在整数解，我们总可以通过调整 k 得到非负解，除非遇到特殊情况。为什么？
假设我们有一组整数解 (p0,q0)。考虑 k 从负无穷到正无穷变化时，p 和 q 的变化轨迹是一条直线。这条直线一定会穿过第一象限（p ≥ 0, q ≥ 0），因为：
- 当 k → +∞ 时，p 和 q 都 → +∞
- 当 k → -∞ 时，p 和 q 都 → -∞
所以直线一定会穿过第一象限！这意味着总存在某个 k 使得 p ≥ 0 且 q ≥ 0。
**例外情况**：当 a 和 b 都是正数时，确实总是成立。唯一的陷阱是当目标值 y 非常大或非常小的时候，我们需要确保调整后的 p, q 是整数（这已经由通解保证了）。
### 4. 严谨证明
更严谨的数学证明：
对于方程 $p⋅a−q⋅b=y$，令 $g=gcd⁡(a,b)$，$a=g⋅A$，$b=g⋅B$，则方程化为：
$p⋅A−q⋅B=yg$
其中 gcd⁡(A,B)=1。
根据扩展欧几里得算法，存在一组特解 (p0,q0) 满足：
p0⋅A−q0⋅B=yg
通解为：
p=p0+B⋅t,q=q0+A⋅t
其中 t 是任意整数。
我们需要存在整数 t 使得：
p0+B⋅t≥0且q0+A⋅t≥0p0​+B⋅t≥0且q0​+A⋅t≥0
即：
$t≥⌈−p0B⌉$且$t≥⌈−q0A⌉t≥⌈−Bp0​​⌉$且$t≥⌈−Aq0​​⌉$
由于 A, B 都是正整数，只要取 t 足够大（大于这两个下界的最大值），就能满足条件。所以**非负解总是存在的**！
### 5. 最终结论
因此，问题的答案简化为：
- **纵坐标可达** ⇔ y 是 gcd⁡(a,b) 的倍数
- **横坐标可达** ⇔ x 是 gcd⁡(c,d) 的倍数
