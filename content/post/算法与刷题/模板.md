## 6. 字符串

### 6.1 字符串哈希（双哈希防冲突）

**原理**：把字符串当作 `P` 进制数，用「前缀哈希」快速得到任意子串的哈希值。双哈希用两个不同的基数 `P1、P2` 分别计算，只有两个值都相等才判为相等，冲突概率降到几乎为 0。

**前缀哈希递推式**（`h[i]` 表示 `s[0..i-1]` 的哈希值）：

```
h[i] = h[i-1] * P + s[i-1]
```

等价于 `s[0]*P^(i-1) + s[1]*P^(i-2) + ... + s[i-1]`（高位在前）。

```cpp
using ull = unsigned long long;
const ull P1 = 131, P2 = 13331;   // 经验素数，冲突少

struct Hash {
    vector<ull> h1, h2;   // 前缀哈希（1-based，h[0]=0）
    vector<ull> p1, p2;   // p[i] = P^i，预处理好避免每次重算
    int n;

    void init(const string& s) {
        n = s.size();
        h1.assign(n + 1, 0); h2.assign(n + 1, 0);
        p1.assign(n + 1, 1); p2.assign(n + 1, 1);
        for (int i = 1; i <= n; ++i) {
            h1[i] = h1[i-1] * P1 + s[i-1];   // 前缀哈希递推
            h2[i] = h2[i-1] * P2 + s[i-1];
            p1[i] = p1[i-1] * P1;            // P 的 i 次幂
            p2[i] = p2[i-1] * P2;
        }
    }

    // 返回 [l, r] 0-based 闭区间的哈希值（打包成 pair）
    pair<ull, ull> get(int l, int r) {
        // 子串长度 = r - l + 1
        // h[r+1] 与 h[l] 都是 1-based，对应 s[0..r] 与 s[0..l-1]
        ull a = h1[r+1] - h1[l] * p1[r-l+1];
        ull b = h2[r+1] - h2[l] * p2[r-l+1];
        return {a, b};
    }
};
```

**子串提取的数学推导**：

```
h[r+1] = s[0]*P^r + s[1]*P^(r-1) + ... + s[r]
h[l]   = s[0]*P^(l-1) + ... + s[l-1]

h[r+1] - h[l] * P^(r-l+1)
  = s[l]*P^(r-l) + s[l+1]*P^(r-l-1) + ... + s[r]   // 即子串 s[l..r] 的哈希
```

其中 `r-l+1` 是子串长度，`P^(r-l+1)` 用于把 `h[l]` “左移”到与 `h[r+1]` 高位对齐再相减。

**为什么用 `unsigned long long` 自然溢出**：

- `ull` 溢出会自动对 `2^64` 取模（无符号溢出是定义良好行为），**无需手动取模**，速度最快。
- 模数 `2^64` 是合数，理论上可能被构造数据卡掉；若追求绝对稳妥可改用大素数取模（如 `1e9+7` / `1e9+9`），但会略慢。双哈希已能覆盖绝大多数场景。

**易错点**：

1. `h` 数组是 **1-based**（`h[1..n]`），而 `get(l, r)` 的 `l, r` 是 **0-based**，所以取子串用 `h[r+1]` 与 `h[l]`，长度用 `r-l+1`。
2. `p[i]` 幂次必须**预处理好**，否则每次取子串临时算 `P^len` 会退化成 O(len)。
3. 判等必须 `h1` 与 `h2` **同时**相等（即比较 `pair`），不能只看其中一个。

### 6.2 KMP

**核心概念——前缀函数 `pi[i]`**：表示模式串 `p` 的前缀 `p[0..i]` 中，**最长的「既是真前缀又是真后缀」的长度**。它等价于「在 `i+1` 处失配时，模式串下一个应比对的位置」。

例如 `p = "ababa"`：

| i | p[0..i] | 最长公共真前后缀 | pi[i] |
|---|---------|------------------|-------|
| 0 | `a`     | 无               | 0     |
| 1 | `ab`    | 无               | 0     |
| 2 | `aba`   | `a`              | 1     |
| 3 | `abab`  | `ab`             | 2     |
| 4 | `ababa` | `aba`            | 3     |

```cpp
// 求模式串 p 的前缀函数数组
vector<int> kmp_pre(const string& p) {
    int m = p.size();
    vector<int> pi(m);            // pi[0] 恒为 0
    for (int i = 1; i < m; ++i) {
        int j = pi[i - 1];        // 候选：尝试把上一个前后缀延长一位
        while (j > 0 && p[i] != p[j]) j = pi[j - 1];  // 失配则回退到次长前后缀
        if (p[i] == p[j]) ++j;    // 匹配成功则延长
        pi[i] = j;
    }
    return pi;
}
```

**`kmp_pre` 关键点**：

- `j = pi[i-1]`：前 `i` 个字符已有长度为 `j` 的公共真前后缀，尝试比较 `p[i]` 与 `p[j]` 延长一位。
- `while (j > 0 && p[i] != p[j]) j = pi[j-1]`：失配时不是 `j--`，而是直接跳到 `pi[j-1]`，跳过大量无效尝试，这是 KMP 不回退、均摊 O(m) 的关键。
- 退出循环后若 `p[i] == p[j]` 则 `++j`，否则 `j` 已经是 0。

```cpp
// 在 s 中匹配 p，返回所有匹配起点（0-based）
vector<int> kmp_match(const string& s, const string& p) {
    vector<int> pi = kmp_pre(p), res;
    int j = 0;                     // 已匹配的模式串长度
    for (int i = 0; i < (int)s.size(); ++i) {
        while (j > 0 && s[i] != p[j]) j = pi[j - 1];  // 失配回退
        if (s[i] == p[j]) ++j;                        // 匹配则延长
        if (j == (int)p.size()) {                     // 找到一个完整匹配
            res.push_back(i - j + 1);                 // 起点 = i - 长度 + 1
            j = pi[j - 1];                            // 回退，允许重叠匹配
        }
    }
    return res;
}
```

**`kmp_match` 关键点**：

- 主串指针 `i` 只前进**从不回退**，模式串靠 `j = pi[j-1]` 回退，保留「主串后缀能匹配上模式串前缀」的信息。
- 找到完整匹配后 `j = pi[j-1]`（而不是 `j = 0`），用于处理**重叠匹配**，例如 `s = "aaa"`, `p = "aa"` 会得到两个匹配。
- 起点公式 `i - j + 1`：`i` 是当前主串下标，`j` 是匹配长度，起点为 `i - j + 1`（0-based）。

**复杂度与易错点**：

- 时间复杂度 O(n + m)：`j` 每次最多 +1，`while` 中回退总次数不超过前进总次数，均摊线性。
- 空模式串需特判，否则 `pi[j-1]` 会越界（竞赛题通常保证非空）。

## 7. 数学

### 7.1 快速幂

```cpp
ll qpow(ll a, ll b, ll mod = MOD) {
    ll res = 1 % mod;
    a %= mod;
    while (b) {
        if (b & 1) res = res * a % mod;
        a = a * a % mod;
        b >>= 1;
    }
    return res;
}
```

### 7.2 快速乘（防 `a*b` 溢出，用于 a、b 接近 1e18）

```cpp
ll qmul(ll a, ll b, ll mod) {
    ll res = 0;
    a %= mod;
    while (b) {
        if (b & 1) res = (res + a) % mod;
        a = (a + a) % mod;
        b >>= 1;
    }
    return res;
}
```

### 7.3 gcd / lcm / 扩展欧几里得

```cpp
ll gcd(ll a, ll b) { return b ? gcd(b, a % b) : a; }
ll lcm(ll a, ll b) { return a / gcd(a, b) * b; }

// 扩展欧几里得：ax + by = gcd(a, b)
ll exgcd(ll a, ll b, ll& x, ll& y) {
    if (!b) { x = 1; y = 0; return a; }
    ll d = exgcd(b, a % b, y, x);
    y -= a / b * x;
    return d;
}

// 求 a 关于 mod 的逆元（要求 gcd(a, mod) = 1）
ll inv(ll a, ll mod) {
    ll x, y;
    exgcd(a, mod, x, y);
    return (x % mod + mod) % mod;
}
```

### 7.4 欧拉筛（线性筛素数）

```cpp
vector<int> primes;
vector<bool> is_prime(1e6 + 5, true);
void sieve(int n) {
    is_prime[0] = is_prime[1] = false;
    for (int i = 2; i <= n; ++i) {
        if (is_prime[i]) primes.push_back(i);
        for (int p : primes) {
```

### 7.5 组合数（预处理阶乘 + 逆元）

```cpp
const int MAXN = 1e6 + 5;
ll fact[MAXN], inv_fact[MAXN];

void init_comb(int n = MAXN - 1) {
    fact[0] = 1;
    for (int i = 1; i <= n; ++i) fact[i] = fact[i-1] * i % MOD;
    inv_fact[n] = qpow(fact[n], MOD - 2, MOD);
    for (int i = n - 1; i >= 0; --i) inv_fact[i] = inv_fact[i+1] * (i+1) % MOD;
}

ll C(int n, int m) {
    if (m < 0 || m > n) return 0;
    return fact[n] * inv_fact[m] % MOD * inv_fact[n-m] % MOD;
}
```

## 8. 数据结构

### 8.1 并查集（DSU）

```cpp
struct DSU {
    vector<int> fa, sz;
    DSU(int n) : fa(n + 1), sz(n + 1, 1) {
        iota(all(fa), 0);
    }
    int find(int x) {
        return fa[x] == x ? x : fa[x] = find(fa[x]);  // 路径压缩
    }
    bool unite(int a, int b) {                        // 按大小合并
        a = find(a), b = find(b);
        if (a == b) return false;
        if (sz[a] < sz[b]) swap(a, b);
        fa[b] = a; sz[a] += sz[b];
        return true;
    }
    bool same(int a, int b) { return find(a) == find(b); }
};
```

### 8.3 线段树（区间加 + 区间求和）

```cpp
struct SegTree {
    int n;
    vector<ll> sum, lazy;
    SegTree(int n) : n(n), sum(n << 2), lazy(n << 2) {}

    void pushup(int rt) { sum[rt] = sum[rt << 1] + sum[rt << 1 | 1]; }

    void pushdown(int rt, int l, int r) {
        if (lazy[rt]) {
            int mid = (l + r) >> 1;
            sum[rt << 1] += lazy[rt] * (mid - l + 1);
            sum[rt << 1 | 1] += lazy[rt] * (r - mid);
            lazy[rt << 1] += lazy[rt];
            lazy[rt << 1 | 1] += lazy[rt];
            lazy[rt] = 0;
        }
    }

    void build(int rt, int l, int r, vector<ll>& a) {
        if (l == r) { sum[rt] = a[l]; return; }
        int mid = (l + r) >> 1;
        build(rt << 1, l, mid, a);
        build(rt << 1 | 1, mid + 1, r, a);
        pushup(rt);
    }

    void update(int rt, int l, int r, int L, int R, ll val) {
        if (L <= l && r <= R) {
            sum[rt] += val * (r - l + 1);
            lazy[rt] += val;
            return;
        }
        pushdown(rt, l, r);
        int mid = (l + r) >> 1;
        if (L <= mid) update(rt << 1, l, mid, L, R, val);
        if (R > mid) update(rt << 1 | 1, mid + 1, r, L, R, val);
        pushup(rt);
    }

    ll query(int rt, int l, int r, int L, int R) {
        if (L <= l && r <= R) return sum[rt];
        pushdown(rt, l, r);
        int mid = (l + r) >> 1;
        ll ans = 0;
        if (L <= mid) ans += query(rt << 1, l, mid, L, R);
        if (R > mid) ans += query(rt << 1 | 1, mid + 1, r, L, R);
        return ans;
    }
};
```

### 8.6 稀疏表（ST 表，静态 RMQ）

```cpp
struct SparseTable {
    vector<vector<int>> st;
    vector<int> lg;
    SparseTable(const vector<int>& a) {
        int n = a.size();
        lg.resize(n + 1);
        for (int i = 2; i <= n; ++i) lg[i] = lg[i >> 1] + 1;
        int K = lg[n] + 1;
        st.assign(n, vector<int>(K));
        for (int i = 0; i < n; ++i) st[i][0] = a[i];
        for (int j = 1; j < K; ++j)
            for (int i = 0; i + (1 << j) <= n; ++i)
                st[i][j] = max(st[i][j-1], st[i + (1 << (j-1))][j-1]);
    }
    int query(int l, int r) {  // 0-based，闭区间
        int j = lg[r - l + 1];
        return max(st[l][j], st[r - (1 << j) + 1][j]);
    }
};
```

### 9.2 Dijkstra 最短路（堆优化）

```cpp
vector<ll> dijkstra(int s, const vector<vector<pii>>& g) {
    int n = g.size() - 1;
    vector<ll> dist(n + 1, LINF);
    dist[s] = 0;
    priority_queue<pll, vector<pll>, greater<pll>> pq;  // (dist, v)
    pq.push({0, s});
    while (!pq.empty()) {
        auto [d, u] = pq.top(); pq.pop();
        if (d > dist[u]) continue;
        for (auto [v, w] : g[u]) {
            if (dist[u] + w < dist[v]) {
                dist[v] = dist[u] + w;
                pq.push({dist[v], v});
            }
        }
    }
    return dist;
}
```

### 9.3 SPFA / Bellman-Ford（含负权，可判负环）

```cpp
bool spfa(int s, const vector<vector<pii>>& g, vector<ll>& dist) {
    int n = g.size() - 1;
    dist.assign(n + 1, LINF); dist[s] = 0;
    vector<int> cnt(n + 1), inq(n + 1);
    queue<int> q; q.push(s); inq[s] = 1;
    while (!q.empty()) {
        int u = q.front(); q.pop(); inq[u] = 0;
        for (auto [v, w] : g[u]) {
            if (dist[u] + w < dist[v]) {
                dist[v] = dist[u] + w;
                cnt[v] = cnt[u] + 1;
                if (cnt[v] >= n) return false;  // 存在负环
                if (!inq[v]) { q.push(v); inq[v] = 1; }
            }
        }
    }
    return true;
}
```

### 9.7 最近公共祖先（LCA，倍增）

```cpp
int LOG;
vector<vector<int>> up;
vector<int> depth;

void dfs(int u, int p, const vector<vector<int>>& g) {
    up[u][0] = p;
    for (int j = 1; j < LOG; ++j)
        up[u][j] = up[up[u][j-1]][j-1];
    for (int v : g[u]) if (v != p) {
        depth[v] = depth[u] + 1;
        dfs(v, u, g);
    }
}

int lca(int a, int b) {
    if (depth[a] < depth[b]) swap(a, b);
    int diff = depth[a] - depth[b];
    for (int j = 0; j < LOG; ++j) if (diff >> j & 1) a = up[a][j];
    if (a == b) return a;
    for (int j = LOG - 1; j >= 0; --j)
        if (up[a][j] != up[b][j]) a = up[a][j], b = up[b][j];
    return up[a][0];
}
// 初始化：LOG = ceil(log2(n)) + 1; up.assign(n+1, vector<int>(LOG));
```

#### 12.3.1 强连通分量（Tarjan）

用于求有向图的强连通分量，典型真题《高速公路》(2015-09 T4)。

```cpp
struct SCC {
    int n, tot = 0, scc_cnt = 0;
    vector<vector<int>> g;
    vector<int> dfn, low, belong, in_stk;
    vector<int> stk;

    SCC(int n) : n(n), g(n + 1), dfn(n + 1), low(n + 1), belong(n + 1), in_stk(n + 1) {}

    void add_edge(int u, int v) { g[u].push_back(v); }

    void dfs(int u) {
        dfn[u] = low[u] = ++tot;
        stk.push_back(u); in_stk[u] = 1;
        for (int v : g[u]) {
            if (!dfn[v]) {            // 树边
                dfs(v);
                low[u] = min(low[u], low[v]);
            } else if (in_stk[v]) {   // 回边 / 横叉边（在栈中）
                low[u] = min(low[u], dfn[v]);
            }
        }
        if (dfn[u] == low[u]) {       // u 是 SCC 的根
            ++scc_cnt;
            int x;
            do {
                x = stk.back(); stk.pop_back();
                in_stk[x] = 0; belong[x] = scc_cnt;
            } while (x != u);
        }
    }

    void solve() {
        for (int i = 1; i <= n; ++i)
            if (!dfn[i]) dfs(i);
    }
};
```

#### 12.3.2 树的直径（两次 DFS）

典型真题《网络延时》(2015-03 T4)：求树的最长路径。任取一点找最远点 `a`，再从 `a` 找最远点 `b`，`a-b` 即直径。

```cpp
vector<vector<int>> g(n + 1);
vector<int> dist(n + 1);

function<void(int, int)> dfs = [&](int u, int p) {
    for (int v : g[u]) if (v != p) {
        dist[v] = dist[u] + 1;
        dfs(v, u);
    }
};

dist[1] = 0; dfs(1, 0);            // 任取起点 1
int a = 1;
for (int i = 1; i <= n; ++i) if (dist[i] > dist[a]) a = i;

dist[a] = 0; dfs(a, 0);            // 从最远点再 DFS
int diameter = 0;
for (int i = 1; i <= n; ++i) diameter = max(diameter, dist[i]);
```

#### 12.3.3 欧拉路径 / 回路

典型真题《送货》(2015-12 T4)：判断是否存在欧拉路径/回路，并输出字典序最小的路径。

**存在性判定**：

- 无向图欧拉回路：所有点度数为偶数；欧拉路径：恰有 0 或 2 个奇度点。
- 有向图欧拉回路：所有点入度 == 出度；欧拉路径：恰一个「出度 - 入度 = 1」和一个「入度 - 出度 = 1」，其余相等。

**Hierholzer 求路径**（有向图，需先保证存在）：

```cpp
vector<int> path;
void hierholzer(int u, vector<multiset<int>>& g) {
    while (!g[u].empty()) {
        int v = *g[u].begin();
        g[u].erase(g[u].begin());   // 删边
        hierholzer(v, g);
    }
    path.push_back(u);              // 回溯时记录
}
// 调用后 reverse(path.begin(), path.end()) 即欧拉回路/路径
```

> 无向图需成对删边（删 `u->v` 同时删 `v->u`），可用 `vector<set<int>>` 或链式前向星标记已删边。要求字典序最小则用有序结构（`set`）保证每次取最小邻点。

#### 12.3.4 区间 DP 框架

典型真题《压缩编码》(2016-12 T4)：本质是「石子合并」问题（每次只能合并相邻的），用区间 DP 求最小合并代价。

```cpp
// dp[l][r] 表示合并区间 [l, r] 的最小代价
// sum[l][r] 为区间和（前缀和预处理）
for (int len = 2; len <= n; ++len) {              // 枚举区间长度
    for (int l = 1; l + len - 1 <= n; ++l) {      // 枚举左端点
        int r = l + len - 1;
        dp[l][r] = LINF;
        for (int k = l; k < r; ++k)               // 枚举分割点
            dp[l][r] = min(dp[l][r],
                           dp[l][k] + dp[k + 1][r] + sum[r] - sum[l - 1]);
    }
}
// 答案：dp[1][n]
```

#### 12.3.5 数位 DP 框架

典型真题《有趣的数》(2013-12 T4)。用于统计 `[1, n]` 内满足某种数位性质的数的个数，用记忆化搜索实现最通用。

```cpp
ll memo[20][2][2];  // 维度按题目状态扩展；tight 一般用 !tight 才记忆化
bool vis[20][2][2];

// 例：统计 [1, n] 中不含数字 4 的数的个数
ll dfs(const string& s, int pos, bool tight, bool lead) {
    if (pos == (int)s.size()) return 1;          // 走到末尾，得到一个合法数
    if (!tight && !lead && vis[pos][tight][lead]) return memo[pos][tight][lead];

    int limit = tight ? s[pos] - '0' : 9;
    ll res = 0;
    for (int d = 0; d <= limit; ++d) {
        if (d == 4) continue;                    // 题目条件：数位不含 4
        res += dfs(s, pos + 1, tight && (d == limit), lead && (d == 0));
    }

    if (!tight && !lead) { vis[pos][tight][lead] = true; memo[pos][tight][lead] = res; }
    return res;
}
ll count(ll n) { return dfs(to_string(n), 0, true, true); }
```

> `tight` 表示当前是否紧贴上限，`lead` 表示是否仍处于前导零。不同题目只需改「跳过/计数」的条件，状态维度按需增减。

### 12.4 经典真题解析

#### 12.4.1 最大的矩形（2013-12 T3）—— 单调栈

**题意**：给一排柱高，求能构成的最大矩形面积。

**思路**：对每根柱子，其能向左右扩展的边界是「左右第一个比它矮的柱子」。用单调栈求出左右第一个更矮柱，面积 = 高 ×（右边界 - 左边界 - 1）。

```cpp
ll largestRectangle(vector<int>& h) {        // h[1..n] 为柱高
    int n = h.size() - 1;
    vector<int> L(n + 1), R(n + 1, n + 1);
    stack<int> st;
    for (int i = 1; i <= n; ++i) {           // 左边界
        while (!st.empty() && h[st.top()] >= h[i]) st.pop();
        L[i] = st.empty() ? 0 : st.top();
        st.push(i);
    }
    while (!st.empty()) st.pop();
    for (int i = n; i >= 1; --i) {           // 右边界
        while (!st.empty() && h[st.top()] >= h[i]) st.pop();
        R[i] = st.empty() ? n + 1 : st.top();
        st.push(i);
    }
    ll ans = 0;
    for (int i = 1; i <= n; ++i)
        ans = max(ans, 1LL * h[i] * (R[i] - L[i] - 1));
    return ans;
}
```

#### 12.4.2 最优灌溉（2014-12 T4）—— 最小生成树

**题意**：n 个田块、m 条可选沟渠（带费用），求连通所有田块的最小费用。

**思路**：直接最小生成树，用 Kruskal（见 9.5），边权为费用。

```cpp
struct Edge { int u, v; ll w; };
sort(all(edges), [](const Edge& a, const Edge& b) { return a.w < b.w; });
DSU dsu(n);
ll ans = 0;
for (auto& e : edges)
    if (dsu.unite(e.u, e.v)) ans += e.w;   // 全部连通后即为最小费用
```

#### 12.4.3 数据中心（2018-12 T4）—— 最小生成树（瓶颈）

**题意**：求一棵生成树，使**最大边权最小**，输出该最大边权。

**思路**：最小生成树（Kruskal）恰好满足「最大边权最小」，只需在 Kruskal 过程中记录最后一条加入的边权。

```cpp

```

#### 12.4.4 网络延时（2015-03 T4）—— 树的直径

**题意**：求无根树的最长路径（交换机网络的最大转发次数）。

#### 12.4.5 高速公路（2015-09 T4）—— 强连通分量

**题意**：求有向图中「可以互相到达的城市对」数量。

**思路**：用 Tarjan（12.3.1）缩点后，每个强连通分量大小为 `sz`，则贡献 `C(sz, 2)` 对，累加。

```cpp
SCC scc(n);
// 读入边 scc.add_edge(u, v);
scc.solve();
vector<int> sz(scc.scc_cnt + 1);
for (int i = 1; i <= n; ++i) sz[scc.belong[i]]++;
ll ans = 0;
for (int i = 1; i <= scc.scc_cnt; ++i)
    ans += 1LL * sz[i] * (sz[i] - 1) / 2;
```

#### 12.4.6 送货（2015-12 T4）—— 欧拉路径

#### 12.4.7 交通规划（2016-04 T4）—— 最短路

**题意**：新增若干边使所有点到 1 号点最短路不变，求新增边的最小总长度。

**思路**：跑 Dijkstra（见 9.2）得到 `dist[]`，对每个点 `v`，在所有满足 `dist[u] + w == dist[v]` 的入边中选最小 `w` 累加（即最短路 DAG 上的最小生成树）。

```cpp
vector<ll> dist = dijkstra(1, g);
ll ans = 0;
for (int v = 2; v <= n; ++v) {
    ll best = LINF;
    for (auto [u, w] : g[v])            // 遍历所有入边
        if (dist[u] + w == dist[v]) best = min(best, (ll)w);
    ans += best;
}
```

### 12.5 前两题（T1 / T2）满分策略

**定位**：T1、T2 几乎不考复杂算法，考的是**基本功 + 细节**。满分的关键不是会多少算法，而是**不丢细节分**。

**失分三大来源**：读题不清、边界/溢出、输出格式错误。拿下前两题的公式 =「算法范围全覆盖」+「细节零失误」。

#### 12.5.1 高频算法范围（按出现频率排序）

#### 12.5.2 各题型模板与思路

**① 模拟题（最高频）**

模拟题没有固定模板，但有统一的「三步法」：

```
1. 读清题意：明确输入顺序、数据范围、输出要求
2. 确定状态：找出题目的核心状态变量，及每次操作的状态转移
3. 推进过程：按时间步 / 事件顺序循环，注意终止条件与边界
```

遇到「时间推进」类（如碰撞的小球、公共钥匙盒），用 `while` 或 `for` 按秒推进，每步先更新再检查。

**② 数组计数 / 哈希**

```cpp
// 值域较小（≤ 1e6）时用数组当哈希，比 map 快且稳
const int MAXV = 10005;        // 按题目值域定
int cnt[MAXV] = {0};
for (int x : a) cnt[x]++;      // 计数

// 值域很大或下标为字符串/负数时用 map
unordered_map<int, int> mp;
for (int x : a) mp[x]++;
```

**③ 排序 + 结构体（多关键字）**

```cpp
struct Node { int id, val; };
sort(all(v), [](const Node& a, const Node& b) {
    if (a.val != b.val) return a.val > b.val;  // 第一关键字：val 降序
    return a.id < b.id;                        // 第二关键字：id 升序
});
```

**④ 简单数学**

```cpp
// 数位拆分 / 求数位和
int digitSum(int n) { int s = 0; while (n) { s += n % 10; n /= 10; } return s; }

// 判断是否包含某数字 d
bool hasDigit(int n, int d) {
    while (n) { if (n % 10 == d) return true; n /= 10; }
    return false;
}

// 闰年判断 + 每月天数
int days[] = {0,31,28,31,30,31,30,31,31,30,31,30,31};
bool leap(int y) { return (y % 4 == 0 && y % 100 != 0) || y % 400 == 0; }

// 环形 / 循环用取模（注意负数取模要 + n）
int idx = (i + 1) % n;

// 中位数（注意用 long long，避免求和溢出）
```

**⑤ 前缀和 / 差分**

```cpp
// 一维前缀和：pre[i] = 前 i 个元素和
vector<ll> pre(n + 1);
for (int i = 1; i <= n; ++i) pre[i] = pre[i-1] + a[i];
// 区间 [l, r] 和 = pre[r] - pre[l-1]

// 二维前缀和（矩阵）
// s[i][j] = s[i-1][j] + s[i][j-1] - s[i-1][j-1] + a[i][j]
// 子矩阵 (x1,y1)~(x2,y2) 和：
//   = s[x2][y2] - s[x1-1][y2] - s[x2][y1-1] + s[x1-1][y1-1]

// 差分：区间 [l, r] 同时加 x
b[l] += x; b[r+1] -= x;      // 最后对 b 求前缀和还原
```

**⑥ 双指针（有序列表合并，如稀疏向量）**

```cpp
// 两个按 index 升序的列表，求相同 index 的乘积和
int i = 0, j = 0;
ll ans = 0;
while (i < n && j < m) {
    if (a[i].idx == b[j].idx) { ans += 1LL * a[i].val * b[j].val; ++i; ++j; }
    else if (a[i].idx < b[j].idx) ++i;
    else ++j;
}
```

**⑦ 表达式求值（栈，处理中缀含括号）**

```cpp
int eval(const string& s) {
    stack<int> num;
    stack<char> op;
    unordered_map<char,int> pri{{'+',1},{'-',1},{'*',2},{'/',2}};
    auto calc = [&]() {
        int b = num.top(); num.pop();
        int a = num.top(); num.pop();
        char c = op.top(); op.pop();
        if (c=='+') num.push(a+b);
        else if (c=='-') num.push(a-b);
        else if (c=='*') num.push(a*b);
        else num.push(a/b);
    };
    for (int i = 0; i < (int)s.size(); ++i) {
        if (isdigit(s[i])) {
            int x = 0;
            while (i < (int)s.size() && isdigit(s[i])) x = x*10 + (s[i++]-'0');
            --i; num.push(x);
        } else if (s[i]=='(') op.push('(');
        else if (s[i]==')') { while (op.top()!='(') calc(); op.pop(); }
        else { while (!op.empty() && pri[op.top()] >= pri[s[i]]) calc(); op.push(s[i]); }
    }
    while (!op.empty()) calc();
    return num.top();
}
```

**⑧ 简单贪心**

思路：每次取当前最优选择，能证明局部最优构成全局最优（如「打酱油」每次优先买 5 瓶装，因为单价最低）。

#### 12.5.3 满分细节清单（必背，决定是否拿满）

1. **数据范围 → 类型**：累加、乘法、面积、数量都可能超 `int`，默认用 `long long`，读入输出用 `%lld` 或 `cout`。
2. **下标起点**：数组从 0 还是 1 开始要统一，注意 `n-1`、`n+1` 的越界。
3. **输出格式**：
   - 每个答案一行，多个数用空格分隔（末尾**不要**多余空格）。
   - 保留小数：`cout << fixed << setprecision(2) << x;`。
4. **多组测试 / 多行输入**：注意是否先读 `T`；计数数组、布尔标记在每组前要**清零**。
5. **读整行残留换行**：`cin >> x` 后用 `getline` 前，先 `cin.ignore();` 吃掉换行符。
6. **环形取模负下标**：用 `((i - 1) % n + n) % n` 处理 `i-1` 可能为负的情况。
7. **排序去重顺序**：`unique` 前必须先 `sort`。
8. **字符串比较 / 计数**：注意大小写、空白字符、`string::npos`。
9. **浮点精度**：浮点数判等用 `fabs(a-b) < 1e-9`，输出时按要求四舍五入。
10. **边界值**：n=1、空输入、恰好整除等边界情况单独测一下。

**考场建议**：T1 目标 10 分钟内拿满；T2 目标 30 分钟内拿满。做完立即用题目给的样例 + 自己构造的边界样例（n=1、全 0、最大值）验证，而不是直接交。

## 附：常用数学常量与常见陷阱

- `INF = 0x3f3f3f3f` 配合 `memset(a, 0x3f, sizeof a)` 可快速初始化为大数（每个 int 约为 1061109567）。
- 取模时先加 MOD 再取模，避免负数：`(a - b + MOD) % MOD`。
- `a / b % MOD` 要用逆元：`a * inv(b) % MOD`，不能直接除法取模。
- 浮点数比较用 `fabs(a - b) < 1e-9`，不用 `==`。
- 排序前若元素可能重复，注意 `unique` 前必须先 `sort`。
- 大数乘法溢出时用 `__int128` 或快速乘。

```cpp
// __int128 用法（输出需手写）
using i128 = __int128_t;
i128 x = (i128)a * b % MOD;
```
