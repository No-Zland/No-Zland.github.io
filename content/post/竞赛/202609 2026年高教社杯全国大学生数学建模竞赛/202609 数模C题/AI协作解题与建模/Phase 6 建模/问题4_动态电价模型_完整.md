# 问题4：波动电价下的动态风险调度模型

## 一、问题4的建模定位

问题4不重新建立一套新的微网模型，而是在已经完成的问题2、问题3基础上，仅把原来确定的固定日内电价扩展为随日期、时段变化且未来可能未知的实时电价过程。

因此问题4分为：

\[
\boxed{
Q4\text{-}2
=
\text{波动电价下的问题2}
}
\]

以及：

\[
\boxed{
Q4\text{-}3
=
\text{波动电价下的问题3}.
}
\]

其中：

- Q4-2继承问题2的“0:00日前计划购电 + 日内多阶段非预见实时补救”；
- Q4-3继承问题3的“0:00初始计划 + 6:00/12:00/18:00滚动调整 + 最终偏差一次性结算”。

问题4新增的核心并不是新的物理约束，而是：

\[
\boxed{
\text{未来电价本身也成为不确定信息}.
}
\]

本文采用已经确定的严格因果解释：

> 附件4中的2025全年价格视为实际运行过程中逐步实现的真实交易价格。任一决策时刻，只允许使用该时刻以前已经实现的历史价格以及基于历史信息形成的未来价格预测；附件4中当前时刻以后的真实价格不能直接用于当前决策。

由此，问题4仍然遵循：

\[
\boxed{
\text{当前决策只能依赖当前信息集，未来实际负荷、未来实际光伏和未来实际电价均不得提前进入模型}.
}
\]

# 五、Q4-2联合价格—负荷—光伏场景

## 5.1 残差定义

继续使用问题2负荷、光伏预测残差：

\[
\epsilon^L_{s,k}
=
L^{act}_{s,k}
-
\widehat L_{s,k\mid0},
\]

\[
\epsilon^G_{s,k}
=
G^{act}_{s,k}
-
\widehat G_{s,k\mid0}.
\]

价格预测残差定义为：

\[
\boxed{
\epsilon^p_{s,k}
=
p^{act}_{s,k}
-
\widehat p_{s,k\mid0}.
}
\]

必须使用历史日期 \(s\) 当时真实可获得信息生成的样本外预测值计算残差，不能用全年的事后拟合残差。

---

## 5.2 是否需要联合考虑光伏误差和价格误差

推荐：

\[
\boxed{
\text{需要保留联合关系，但不需要使用复杂Copula或DRO}.
}
\]

原因是：

- 电价可能与系统负荷水平相关；
- 光伏高低可能通过外部电力供需间接影响价格；
- 如果价格残差、负荷残差和光伏残差完全独立抽样，会产生历史上从未出现过的组合；
- 若采用三组场景笛卡尔积，场景规模会迅速爆炸。

因此主方案采用：

\[
\boxed{
\text{历史日联合残差轨迹Bootstrap}.
}
\]

对历史日期 \(s\)，构造联合残差轨迹：

\[
\boxed{
\boldsymbol e_s
=
\left(
\boldsymbol\epsilon^L_s,
\boldsymbol\epsilon^G_s,
\boldsymbol\epsilon^p_s
\right).
}
\]

每次抽样时始终从**同一个历史日期**同时抽取：

\[
\epsilon^L,
\qquad
\epsilon^G,
\qquad
\epsilon^p.
\]

从而在不引入额外复杂统计模型的情况下，自然保留历史上的联合相关结构。

---

## 5.3 联合场景生成

在日期 \(d\) 的0:00，从此前历史残差日期中抽取：

\[
s_\omega<d.
\]

构造：

\[
\boxed{
L^{(\omega)}_{d,k}
=
\max
\left\{
0,\,
\widehat L_{d,k\mid0}
+
\epsilon^L_{s_\omega,k}
\right\},
}
\]

\[
\boxed{
G^{(\omega)}_{d,k}
=
\max
\left\{
0,\,
\widehat G_{d,k\mid0}
+
\epsilon^G_{s_\omega,k}
\right\},
}
\]

\[
\boxed{
p^{(\omega)}_{d,k}
=
\max
\left\{
0,\,
\widehat p_{d,k\mid0}
+
\epsilon^p_{s_\omega,k}
\right\}.
}
\]

这些初始完整轨迹不能直接当作“0:00已经知道的未来场景标签”来配置全天独立储能动作，而必须进一步转化为具有共同前缀的非预见场景树，或通过条件滚动补救实现等价的信息约束。

# 六、Q4-2风险中性非预见随机优化模型

设场景树节点集合为：

\[
\mathcal N_d.
\]

节点 \(n\) 所属物理时段为：

\[
\kappa(n),
\]

节点到达概率为：

\[
\rho_n,
\]

当前节点价格为：

\[
p_{d,n}.
\]

## 6.1 计划购电费用

由于全天计划购电量：

\[
q^{buy}_{d,k\mid0}
\]

在0:00固定，但实际交割价格未来未知，因此其期望正常购电费用不能再写成固定：

\[
\sum_kp_k^{fix}q^{buy}_{d,k\mid0}.
\]

应写成：

\[
\boxed{
\mathbb E(C^{plan}_d)
=
\sum_{n\in\mathcal N_d}
\rho_n
p_{d,n}
q^{buy}_{d,\kappa(n)\mid0}.
}
\]

由于同一阶段所有节点概率之和为1，上式等价于：

\[
\boxed{
\mathbb E(C^{plan}_d)
=
\sum_{k=0}^{143}
\bar p_{d,k\mid0}
q^{buy}_{d,k\mid0},
}
\]

其中：

\[
\boxed{
\bar p_{d,k\mid0}
=
\mathbb E
\left[
p_{d,k}\mid\mathcal I_{d,0}
\right].
}
\]

若Bootstrap场景等概率，则：

\[
\bar p_{d,k\mid0}
=
\frac1S
\sum_{\omega=1}^{S}
p^{(\omega)}_{d,k}.
\]

---

## 6.2 紧急购电期望费用

因此：

\[

=
5
\sum_{n\in\mathcal N_d}
\rho_n
p_{d,n}
q^{emg}_{d,n}.
}
\]

---

# 九、Q4-3联合条件场景

在更新时刻 \(r\)，已经观察到当天联合残差前缀。

定义：

\[
\boldsymbol e^{obs}_{d,0:r-1}
=
\left(
\epsilon^{L,obs}_{d,0:r-1},
\epsilon^{G,obs}_{d,0:r-1},
\epsilon^{p,obs}_{d,0:r-1}
\right).
\]

对历史日期 \(s\)，计算前缀距离：

\[
\boxed{
D_s(r)
=
w_LD^L_s(r)
+
w_GD^G_s(r)
+
w_pD^p_s(r).
}
\]

为避免单位量纲影响，实际计算时应先分别将三类残差标准化。

例如：

\[
D^p_s(r)
=
\sqrt{
\frac1r
\sum_{j=0}^{r-1}
\left(
\widetilde\epsilon^p_{s,j}
-
\widetilde\epsilon^{p,obs}_{d,j}
\right)^2
}.
\]

负荷、光伏同理。

推荐简单取：

\[
\boxed{
w_L=w_G=w_p=\frac13.
}
\]

然后选取距离最近的若干历史日形成条件残差库，从这些日期中联合抽取：

\[
\boxed{
(\epsilon^L_{s,k},
\epsilon^G_{s,k},
\epsilon^p_{s,k}),
\qquad
k\ge r.
}
\]

从而得到当前时刻的联合条件未来场景。

这种方法的优点是：

\[
\boxed{
\text{不用Copula，不需要估计复杂联合分布，同时保留历史联合相关性}.
}
\]

## 12.2 非预见随机价格版本

若使用当前条件联合场景树，则购电调整计划：

仍然是更新时刻 \(r\) 的共同决策，不能按未来叶场景分别设置。

\boxed{

\left[

\bar p_{d,k\mid r}
\left[
q^{buy}_{d,k\mid r}
+
\frac12
\left(

+
a^-_{d,k\mid r}
\right)
\right].

因为：

均在当前更新时刻已经确定，与当前场景树未来分支无关，所以可以直接使用条件期望价格。

\bar p_{d,k\mid r}
\mathbb E(q^{emg}_{d,k}),

因为价格与紧急缺口可能相关。

# 十六、怎样控制联合随机场景规模

如果分别生成：

\[
S_L
\]

个负荷场景、

\[
S_G
\]

个光伏场景、

\[
S_p
\]

个价格场景，再做笛卡尔积，会得到：

\[
S_LS_GS_p
\]

条场景。

例如：

\[
10\times10\times10=1000
\]

条完整路径，进一步转化成多阶段场景树后规模更大，不适合全年滚动求解。

因此必须避免笛卡尔积。

---

## 16.1 主方案：联合历史日Bootstrap

每次直接抽取历史日期 \(s\) 的三类残差：

\[
\boxed{
(
\boldsymbol\epsilon^L_s,
\boldsymbol\epsilon^G_s,
\boldsymbol\epsilon^p_s
).
}
\]

先生成：

\[
\boxed{
S_0=30\sim50
}
\]

条联合完整轨迹。

---

## 16.2 场景削减

对联合轨迹计算标准化后的距离：

\[
D(\omega_i,\omega_j)
=
w_LD_L
+
w_GD_G
+
w_pD_p.
\]

推荐：

\[
w_L=w_G=w_p=\frac13.
\]

使用：

- k-medoids；
- 层次聚类；
- 前向场景削减；

任一简单方法压缩到：

\[
\boxed{
S=8\sim15
}
\]

条代表性联合轨迹。

代表场景概率按原始聚类成员数确定：

\[
\boxed{
\pi_s
=
\frac{N_s}{S_0}.
}
\]

---

## 16.3 不直接建立144阶段完全分支树

理论上每天144个10 min时段都可以形成新的随机分支，但完整树会指数爆炸。

因此推荐：

\[
\boxed{
\text{10 min物理状态更新}
+
\text{稀疏随机分支}
+
\text{实时条件滚动补救}.
}
\]

具体实现可采用：

- 物理SOC仍每10 min更新；
- 不确定性树每1 h或关键时刻重新分支；
- Q4-3在0/6/12/18时重新生成条件场景；
- 实际执行层每10 min只执行当前第一步，再根据已经实现信息更新。

这样不会改变10 min物理模型，只减少随机树组合规模。

---

## 16.4 推荐计算规模

对于本科国赛和全年滚动计算，建议：

### Q4-2

- 初始Bootstrap：30—50条联合轨迹；
- 场景削减：8—12条代表轨迹；
- 场景树随机分支：1 h或2 h级；
- 物理储能状态：10 min级；
- 真实运行时采用条件滚动补救。

### Q4-3

- 每个0/6/12/18更新时刻重新筛选条件历史日；
- 保留8—12条代表未来联合轨迹；
- 当天只执行到下一次更新；
- 次日预览只用于SOC未来价值，不锁定次日正式购电计划。

# 十七、三种方法比较

## 17.1 方法一：确定性预测价格LP

用：

\[
\widehat L,
\qquad
\widehat G,
\qquad
\widehat p
\]

直接代替未来不确定量。

Q4-2目标近似为：

\[
\boxed{
\min
\sum_k
\widehat p_{d,k\mid0}
q^{buy}_{d,k\mid0}
}
\]

并在实际运行时通过储能和紧急购电处理偏差。

Q4-3每次MPC更新时使用：

\[
\widehat p_{d,k\mid r}.
\]

### 优点

- 结构最简单；
- 仍为标准LP；
- 全年运行速度快；
- 很适合作为baseline；
- 容易验证动态价格模块是否正确。

### 缺点

只考虑：

\[
\boxed{
\text{一个未来价格轨迹}
}
\]

无法体现价格预测误差、负荷误差和光伏误差共同作用下的尾部紧急购电风险。

---

## 17.2 方法二：非预见联合场景随机优化

联合建模：

\[
\boxed{
(L,G,p)
}
\]

的不确定性。

当前节点动作只取决于已经实现的联合历史。

### 优点

- 与问题2已经确定的非预见性框架完全一致；
- 能考虑价格和净负荷不确定性的相关性；
- 直接最小化期望真实经济成本；
- 紧急购电5倍价格机制自然进入目标；
- 不需要引入过多主观不确定集合参数；
- 若不强制二进制互斥，仍然保持线性规划结构。

### 缺点

- 计算量高于确定性LP；
- 场景数量和场景削减方法会影响计算结果；
- 必须严格控制非预见性，不能使用平铺完整场景。

---

## 17.3 方法三：鲁棒优化

可以为未来量建立不确定集合：

\[
L_{d,k}
\in
[\widehat L_{d,k}-\Delta^L_{d,k},
 \widehat L_{d,k}+\Delta^L_{d,k}],
\]

\[
G_{d,k}
\in
[\widehat G_{d,k}-\Delta^G_{d,k},
 \widehat G_{d,k}+\Delta^G_{d,k}],
\]

\[
p_{d,k}
\in
[\widehat p_{d,k}-\Delta^p_{d,k},
 \widehat p_{d,k}+\Delta^p_{d,k}].
\]

然后优化最坏情形成本：

\[
\boxed{
\min_x
\max_{\xi\in\mathcal U}
C(x,\xi).
}
\]

为了避免逐点最坏情况过度保守，还可以设置预算不确定集：

\[
\sum_kz_k\le\Gamma.
\]

### 优点

- 不依赖精确概率分布；
- 对极端价格和供电缺口有较强保护；
- 理论上安全性强。

### 缺点

- 如果同时对负荷、光伏、价格取最坏情形，很容易形成“高负荷 + 低光伏 + 高电价”同时发生的极端组合；
- 结果可能明显过度保守；
- 不确定集合宽度和预算参数 \(\Gamma\) 具有较强人为性；
- 多阶段自适应鲁棒模型实现难度明显高于当前题目所需；
- 不如历史联合Bootstrap直观地利用附件2、附件4实际数据。

因此不建议将鲁棒优化作为问题4主模型。

# 二十、推荐改进方案：CVaR联合尾部风险模型

\text{负荷和光伏偏差}

\text{5倍紧急购电}
}
\]

共同造成的高额尾部成本。

对场景树叶路径：

\[
\ell\in\mathcal L_d,
\]

定义总运行损失：

### Q4-2

\[
\boxed{
Z^{4-2}_\ell
=

# 二十一、为什么不把鲁棒优化作为正式改进方案

鲁棒优化可以作为论文中的方法比较或扩展方向，但不建议作为主改进模型。

原因是附件2、附件4已经提供了丰富历史数据，完全可以构造经验残差分布。

在这种情况下舍弃历史概率信息，改成：

\[
\boxed{
\text{所有变量都按最坏情形}
}
\]

会损失已有数据价值。

尤其是如果模型同时取：

\[
\text{高负荷}
+
\text{低光伏}
+
\text{高电价},
\]

容易得到非常保守的全天计划购电和高SOC保有策略。

所以建议定位：

\[
\boxed{
\text{鲁棒优化 = 备选方法/进一步研究}
}
\]

而不是主模型。

# 二十五、可直接写入论文的模型说明

> **问题4动态电价下的风险调度模型。**  
> 问题4在问题2和问题3模型基础上进一步考虑外部电网实时电价的不确定性。本文不重新构造微网物理模型，而完整继承前述能量平衡、储能状态转移、容量与功率约束、跨日储能连续、非预见性以及问题3的滚动调整结算结构，仅将原固定日内电价扩展为随日期和时段变化的随机价格过程。
>
> 由于题目未说明每天0:00能够提前获得当天完整实时电价，本文将附件4价格数据视为实际运行过程中逐步实现的交易价格。在任一决策时刻，仅允许使用此前已经实现的历史价格，并基于历史信息形成未来价格预测。附件4中当前时刻以后的真实价格仅用于后续时刻的信息更新和事后费用结算，不参与此前决策。
>
> 在价格预测方面，采用最近4个相同星期属性日期对应10 min时段价格的均值构造日前基准预测，并在6:00、12:00和18:00利用当天已经实现的价格偏差修正剩余时段预测。为同时描述负荷、光伏和价格预测误差，本文采用历史日联合残差轨迹Bootstrap，即从同一历史日期同时抽取负荷、光伏和价格残差，并经场景削减构造非预见联合场景树，从而在不引入复杂联合分布假设的前提下保留三类误差的历史相关关系。
>
> 对Q4-2，每天0:00确定全天计划购电量，日内储能、弃光、计划富余和紧急购电仅根据已经实现的负荷、光伏、价格和储能状态进行多阶段非预见补救。对Q4-3，在此基础上进一步于0:00、6:00、12:00和18:00同步更新光伏与价格预测，仅对尚未执行的购电计划进行MPC滚动调整。调整结算仍以0:00初始计划为唯一基准，各交割时段只按执行前最终有效购电量与原计划的偏差结算一次，实际费用统一采用该交割10 min时段实际实现的实时电价。
>
> 在模型选择方面，确定性价格预测LP作为基准模型；联合价格—负荷—光伏场景下的多阶段非预见随机LP作为正式主模型；进一步在叶路径总运行费用上加入CVaR以控制高价与供电缺口同时出现时的尾部风险。相比完全鲁棒优化，该方案能够充分利用附件2和附件4提供的历史概率信息，并在经济性、风险性、可解释性和全年滚动计算规模之间取得较好的平衡。
