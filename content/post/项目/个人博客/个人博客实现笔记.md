# 个人博客实现笔记

本文记录这个三级递进个人博客各功能的实现方式，作为后续维护与二次开发的参考。核心代码在仓库根目录的 `build_blog.py`，日历与任务在 `calendar.js` / `calendar.css`，Hugo 集成在 `hugo.toml` / `layouts/index.html`。

## 一、总体架构

数据流：

```
content/post（Obsidian 笔记库）
        │  os.walk 扫描
        ▼
build_blog.py（解析 + 渲染 + 组装）
        │
        ▼
site/（纯静态站点：HTML + CSS + JS + 图片）
        │  hugo server 当作 staticDir 服务
        ▼
http://localhost:1313/
```

关键决策：笔记里大量使用了 Obsidian 专属语法（`==高亮==`、`^上标^`、`~下标~`、`[[wiki 链接]]`、`![[图片]]`、空行分隔的表格、`$公式$`），Hugo 自带的 Goldmark 渲染器原生不支持这些，因此**保留 Python 渲染器**，Hugo 只负责把 `site/` 当静态站点服务。

## 二、三级递进导航

由三个函数生成三类页面：

| 函数 | 生成内容 | 触发条件 |
| --- | --- | --- |
| `build_home` | 首页：单列展示一级分类 | 站点根 |
| `build_folder_page` | 列表页：展示二级分类 | 目录下还有子目录 |
| `build_reading_page` | 阅读页：连续展示所有 md | 目录下没有子目录（或“散篇”） |

目录树构建：

- `scan()`：用 `os.walk` 递归扫描 `content/post`，收集所有 `.md`（排除 `_index.md`、`个人简历.md`）、图片，以及每个目录最早的 `mtime`（作为创立时间）。
- `build_tree()`：生成 `dir_docs`（目录 → 直属文档）和 `child_dirs`（父目录 → 子目录列表）。
- `docs_under()`：按前缀递归收集某目录下所有文档，用于阅读页的“连续阅读”。
- 主流程 `main()`：遍历一级目录，有子目录则生成列表页（含“散篇”入口 `direct.html`），无子目录直接生成阅读页。

连续阅读的“分界线”：

```python
divider = '<div class="doc-divider"><span>分隔线</span></div>'
content = divider.join(articles)
```

## 三、目录简介与创立时间

- `folder_intro()`：有子目录则列出子目录名，否则列出前几篇文章标题，最多 6 项加“等”。
- `folder_created()`：取目录下最早文件修改时间，格式化为 `YYYY-MM-DD`。
- `scan()` 中的 `touch()` 会把这个 `mtime` 向上冒泡到所有祖先目录，保证“创立时间”是整棵子树最早的时间。

## 四、左侧抽屉个人主页

`build_drawer()` 生成抽屉 HTML，包含：

- 头像区：`copy_avatar()` 把根目录 `头像.jpg`（或 jpeg/png/webp/avatar.*）复制为 `assets/avatar.*`；没有头像时 `avatar_name=None`，只渲染默认人形 SVG（`.avatar-default`）。
- 姓名与副标题：梁双宇 / 个人博客 · 记录学习与成长（中英切换）。
- 简介段落。
- 联系方式：GitHub、哔哩哔哩、电子邮箱，每个都内嵌对应品牌 SVG 图标（`.contact-icon`）。
- 更新日历与任务：`<section id="calendar">`，由 `calendar.js` 填充。

开合逻辑在 `JS` 里：`openD` / `closeD`，支持 `Esc` 关闭、点击遮罩关闭、焦点管理，以及 `#profile` / `#contact` 锚点直接打开。

def copy_avatar():

    ...
    return None  # 没有头像 → 页面显示默认人形图标

## 六、主题切换（浅色 / 暗色）

CSS 用自定义属性 + `data-theme` 属性切换：

- `:root` 定义浅色：白底，紫 `--brand`、青、绿、蓝为辅助色。
- `[data-theme="dark"]` 定义暗色：藏蓝底，黑金 `--brand`、墨绿、暗紫为辅助色。
- 渐变背景：`--drawer-grad`（紫青蓝渐变）、`--drawer-bg`。
- 辅助色透明化用 `color-mix(...)` 实现，同时保留 `--bg` 作为回退。

JS 的 `applyTheme(t)` 写入 `data-theme`、切换图标，并用 `localStorage` 记忆；首次加载读取 `localStorage`，否则跟随系统 `prefers-color-scheme`。

## 七、中英切换（梁双宇 / Shine Leong）

JS 里 `I18N.zh` / `I18N.en` 字典 + `applyLang(lang)`：

- 遍历 `[data-i18n]` 更新文本、`[data-i18n-title]` 更新 title、`[data-i18n-aria-label]` 更新 aria 标签。
- 切换按钮文字（`EN` / `中`），记忆到 `localStorage`。
- 派发 `langchange` 自定义事件，让 `calendar.js` 同步刷新日历文案。

## 八、Obsidian 风格 Markdown 渲染

`convert_md()` 使用 `python-markdown` + `pymdownx`：

```python
extensions=[
    "tables",               # 表格
    "fenced_code",          # 代码块
    "sane_lists",           # 列表
    "pymdownx.mark",        # ==高亮==
    "pymdownx.tilde",       # ~~删除~~ 与 ~下标~
    "pymdownx.caret",       # ^上标^
    "pymdownx.tasklist",    # - [ ] 任务列表
    "pymdownx.arithmatex",  # $...$ / $$...$$ 公式
]
```

配套处理：

- `fix_tables()`：合并被空行打断的表格行（Obsidian 导出常见），让表格扩展正确识别。
- `preprocess()`：重写标准图片链接与 `![[...]]` 图片嵌入、`[[...]]` wiki 链接。
- 公式用 MathJax 3 的 `tex-svg.js` 渲染，阅读页在 `<head>` 注入脚本（`with_math=True`）。

## 九、图片资源与 wiki 链接

- `copy_asset()`：把笔记内引用的图片复制到 `site/assets/files/`，返回相对链接。
- `resolve_wikilink_asset()`：按文件名（忽略大小写）在扫描结果里查找图片，优先同目录、再匹配 `<标题>_assets` 子目录，最后取第一个匹配。
- 缺失图片输出 `<p class="missing-img">[图片缺失: xxx]</p>`。

## 十、动画效果

CSS 关键帧与类：

- `card-in`：分类卡片 / 文章入场（配合 `--i` 变量做逐项延迟）。
- `topbar-in` / `fade-in`：顶栏与面包屑淡入。
- `avatar-pop` / `slide-up` / `contact-in`：抽屉打开时头像弹入、文字上滑、联系方式依次滑入。
- `gradient-pan`：抽屉头部渐变背景缓慢流动。
- `blob-float`：抽屉头部的柔光圆斑漂浮。
- `icon-spin`：主题按钮切换时旋转。
- 卡片 hover 的“扫光”效果由 `.cat-item::after` 渐变位移实现。
- 全站尊重 `prefers-reduced-motion`，用户偏好减少动效时自动降级。

## 十一、更新日历与任务提醒

由 `calendar.js` + `calendar.css` 实现：

- 数据来源：`build_blog.py` 的 `collect_updates()` 按文章 `mtime` 统计每天更新篇数，注入 `window.BLOG_UPDATES`。
- 日历渲染：月视图、周末/今天/选中高亮、更新热力（绿色深浅按篇数分级）。
- 任务：新增 / 删除 / 勾选完成，`localStorage` 持久化，跨标签页用 `storage` 事件同步。
- 提醒：每秒检查到点任务，页面内 `toast` 提示 + 系统 `Notification` 通知。

## 十二、Hugo 集成

- `hugo.toml`：`staticDir = ['site']` 服务生成产物，`contentDir = 'hugo_src'` 指向空目录避免二次渲染，`disableKinds` 关闭除 home 外的渲染。
- `layouts/index.html`：`{{ readFile "site/index.html" | safeHTML }}` 让 Hugo 首页直接输出生成好的内容。
- 之所以不关闭 `home`：该 Hugo 版本对 `disableKinds = ['home']` 会 panic，故保留 home 并用模板读取静态首页。

## 十三、无障碍与细节

- 隐藏标题 `sr-only`、按钮 `aria-label`、可见焦点 `:focus-visible`。
- 抽屉关闭时归还焦点，`Esc` 可关闭。
- 窄屏响应式：`< 760px` 隐藏副标题，`< 640px` 收紧内边距与顶栏间距。
