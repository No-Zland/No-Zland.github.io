### 知识点：

标准约瑟夫环，结论是递推：f(1)=0，f(i)=(f(i-1)+m) mod i，答案取 f(n)。含义：f(i) 表示 i 个人编号 0..i-1、从 0 号开始报数、报到 m 出队时最后剩下的人的编号。推导：第一轮出局的是 (m-1) mod i 号，把他删掉后剩 i-1 人，从出局者的下一位开始重新编号为 0，就变成规模 i-1 的同一个子问题；子问题答案 f(i-1) 是子环里的编号，映射回原环只需整体平移 m 位再对 i 取模，即 (f(i-1)+m) mod i。本题起点是 k 而不是 0，因为整个圈只是被旋转了 k 个位置，所以答案是 (f(n)+k) mod n。n ≤ 100，O(n) 递推一步到位；也可以开数组模拟，但下标处理更啰嗦、更容易错。

---

### 题目描述

> 有  $n$  个人（编号  $0\sim n-1$ ）围成一圈，从编号为  $k$  的人开始报数，报数依次为  $1,2,\dots,m$ ，报到  $m$  的人出队。下次从出队者的下一个人开始重新报数，循环往复，直到队伍中只剩最后一个人，该人即"大王"。
>
> 给定三个正整数  $n,k,m$ ，请输出最后剩下的"大王"编号。

**输入描述**

> 在一行中输入三个整数  $n\left(2 \leqq n \leqq 100 \right),k\left(0 \leqq k \leqq n-1\right),m\left(1 \leqq m \leqq 100\right)$ ，用空格隔开。

**输出描述**

> 输出一个整数，表示最后剩下的"大王"编号。

#### 示例

**输入**

```text
5 1 2
```

**输出**

```text
3
```

---

### 最终代码：

```cpp
#include <iostream>
using namespace std;

int main() {
    int n, k, m;
    if (!(cin >> n >> k >> m)) return 0;
    // 以「起点为 0 号」的标准约瑟夫问题求解
    int f = 0;  // f(1) = 0
    for (int i = 2; i <= n; ++i) f = (f + m) % i;
    // 把编号平移回真实的起点 k
    cout << (f + k) % n << "\n";
    return 0;
}
```

### 解题思路

这题我第一反应是开数组模拟报数，n 只有 100，模拟完全过得去。但我更想练手推递推，于是先从小规模验证：一个人时答案必是 0；两个人时谁留下只取决于 m 的奇偶，用 (0+m)%2 试了一下，结果吻合。接着想一般情形：把 i 个人里的第一个出局者删掉，剩下的 i-1 人围成的圈和原问题结构完全一样，只是起点换成了出局者的下一位、编号整体错开了 m 位，于是有 f(i)=(f(i-1)+m)%i。代码就从 i=2 递推到 n，初值 f=0。最后一处细节是起点 k：从编号 k 的人开始报 1，等于给整个圈的编号统一加上 k，所以把递推结果再平移 k 并对 n 取模。用样例 n=5,k=1,m=2 验算，f 依次是 0,0,2,0,2，(2+1)%5=3，与输出一致。

#### 卡点与关键一步

- 起点是 k 不是 0，最后必须 (f(n)+k)%n 平移回去，直接输出 f(n) 会整体偏 k 位
- 递推初值 f(1)=0，循环从 i=2 开始，写成 i=1 或从 n 往下推都会对不上
- 数组模拟时删除元素后计数起点要落在被删位置（即下一个元素）上，这里极易下标越界或错位

#### 复杂度

| 项 | 值 |
|---|---|
| 时间复杂度 | O(n) |
| 空间复杂度 | O(1) |
