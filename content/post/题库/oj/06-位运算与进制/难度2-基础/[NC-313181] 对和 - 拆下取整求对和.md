### 知识点：

结论：H = ((n-1)·S - P)/2，其中 S=Σa_i，P 是奇偶性不同的下标对数，等于 odd·(n-odd)。推导：对单个数对拆下取整，⌊(a+b)/2⌋ = (a+b)/2 - [(a+b) 为奇数]/2，而 a+b 为奇数当且仅当 a、b 一奇一偶。把 n(n-1)/2 个数对求和：第一项里每个 a_i 出现在其余 n-1 个对中，合计 (n-1)S/2；第二项是异奇偶对数的一半，即 P/2。合并得 H=((n-1)S-P)/2。整数性也有保证：每个数对贡献的 (a_i+a_j)-[异奇偶] 必为偶数，求和后自然被 2 整除。

### 题目描述

> 小苯有一个长度为  $n$  的数组  $a_1, a_2, \dots, a_n$ 。他定义数组的“和谐值”为：
>
>
>
>  $\displaystyle H(a) = \sum_{i=1}^{n} \sum_{j=i+1}^{n} \left\lfloor \frac{a_i + a_j}{2} \right\rfloor$ 
>
> 你的任务是求出“和谐值”  $H(a)$ 。
>
> 【名词解释】
>
>  $\lfloor x \rfloor$ ：代表对  $x$  进行下取整操作，得到不超过  $x$  的最大整数。

**输入描述**

> 每个测试文件均包含多组测试数据。第一行输入一个整数  $T\left(1 \leqq T \leqq 10^5\right)$  代表数据组数，每组测试数据描述如下：
>  $\hspace{23pt}\bullet\,$ 第一行输入一个整数  $n\left(1 \leqq n \leqq 2 \times 10^5\right)$ ，表示数组的长度。
>  $\hspace{23pt}\bullet\,$ 第二行输入  $n$  个整数  $a_1, a_2, \dots, a_n\left(1 \leqq a_i \leqq 10^6\right)$ ，表示数组的元素。
> 除此之外，保证单个测试文件的  $n$  之和不超过  $2 \times 10^5$ 。

**输出描述**

> 对于每一组测试数据，新起一行输出一个整数，表示该数组的“和谐值”。

#### 示例

**输入**

```text
3
3
1 2 3
4
5 5 5 5
2
100000 1
```

**输出**

```text
5
30
50000
```

### 最终代码：

```cpp
#include <cstdio>
using namespace std;
typedef long long ll;

// 对和：floor((a+b)/2) = (a+b)/2 - [a,b 奇偶不同]/2。
// 求和项里每个 a_i 出现 (n-1) 次，得到 H = ((n-1)*S - P)/2，P 是异奇偶的对数。
int main() {
    int T;
    if (scanf("%d", &T) != 1) return 0;
    while (T--) {
        int n;
        scanf("%d", &n);
        ll s = 0, odd = 0;
        for (int i = 0; i < n; i++) {
            ll x;
            scanf("%lld", &x);
            s += x;
            if (x & 1) odd++;
        }
        ll p = odd * (n - odd); // 异奇偶对
        printf("%lld\n", ((ll)(n - 1) * s - p) / 2);
    }
    return 0;
}
```

### 解题思路

按定义直接算是 O(n²)，n 到 2e5 肯定不行，所以第一反应就是把这个二重求和拆开。拆法来自对单个 pair 的观察：下取整只差一个 0 或 1/2，而差多少完全由两个数的奇偶性决定，于是每一项都能写成线性的 (a_i+a_j) 再减一个修正项。线性那部分可以直接按出现次数汇总——每个元素出现 n-1 次，得到 (n-1)S；修正项只需要数一数异奇偶的对数，等于奇数个数乘偶数个数。手算 1 2 3：S=6，异奇偶对是 (1,2)、(2,3) 共 2 对，(2·6-2)/2=5，和样例一致；100000 和 1 那组 (100001-1)/2=50000 也吻合。整个过程没有用到排序或前缀和，纯粹是把 floor 展开后按次数汇总。

#### 卡点与关键一步

- 不能两重循环枚举数对，n=2e5 会超时。
- 修正项是异奇偶对数 P=odd·(n-odd)，减的时候别弄反成同奇偶。
- (n-1)·S 最大到约 4e16，必须用 long long，除 2 放在最后做。

#### 复杂度

| 项 | 值 |
|---|---|
| 时间复杂度 | O(n) |
| 空间复杂度 | O(1) |
