### 知识点：

结论先行：按这种反射法编号，第 k 个 n 位格雷码就是 g = k ^ (k >> 1)，直接按位输出即可。推导：设 G(n) = 0·G(n−1) 接 1·reverse(G(n−1))。若 k < 2^(n−1)，最高位为 0，低 n−1 位就是 G(n−1) 的第 k 个；否则令 r = k − 2^(n−1)，它落在逆序段，对应 G(n−1) 的下标 2^(n−1) − 1 − r，最高位为 1。把「是否在下半段、下标要不要翻转」一层层展开，恰好等于相邻二进制位异或：g_i = k_i ^ k_{i+1}，也就是 g = k ^ (k>>1)。这也正好解释了「相邻只差一位、首尾也相邻」两条性质，所以完全不用真的递归生成 2^n 个串。

### 题目描述

> 已替换官方数据
>
>
>
>    通常，人们习惯将所有 n位二进制串按照字典序排列，例如所有2位二进制串按字典序从小到大排列为： 00， 01， 10， 11。 
>    格雷码（Gray Code）是一种特殊的 n位二进制串排列法，它要求相邻的两个二进制串间恰好有一位不同，特别地，第一个串与最后一个串也算作相邻。
>  所有 2位二进制串按格雷码排列的一个例子为： 00， 01， 11， 10。
>  n 位格雷码不止一种，下面给出其中一种格雷码的生成算法：
>           1位格雷码由两个1 位二进制串组成，顺序为：0， 1。          n+1位格雷码的前 $2^n$  个二进制串，可以由依此算法生成的 n 位格雷码（总共 $2^n$  个 n 位二进制串）按顺序排列，再在每个串前加一个前缀 0 构成。          n + 1 位格雷码的后  $2^n$  个二进制串，可以由依此算法生成的 n 位格雷码（总共 $2^n$  个 n 位二进制串）按逆序排列，再在每个串前加一个前缀 1 构成。      综上， n + 1 位格雷码，由 n 位格雷码的  $2^n$  个二进制串按顺序排列再加前缀 0，和按逆序排列再加前缀 1 构成，共 $2^{n+1}$  个二进制串。另外，对于 n 位格雷码中的 $2^n$  个二进制串，我们按上述算法得到的排列顺序将它们从 $0 ∼ 2^{n − 1}$  编号。
>  按该算法， 2 位格雷码可以这样推出：
>          已知 1 位格雷码为 0， 1。           前两个格雷码为 0 1， 0 1。后两个格雷码为 1 1， 1 0。合并得到 00， 01， 11， 10，编号依次为 0 ∼ 3。      同理， 3 位格雷码可以这样推出：
>          已知 2 位格雷码为： 00， 01， 11， 10。          前四个格雷码为：0 00， 0 01， 0 11， 0 10。后四个格雷码为：1 10， 1 11， 1 01，1 00。合并得到： 000， 001， 011， 010， 110， 111， 101， 100，编号依次为 0 ∼ 7。      
>    现在给出 n, k，请你求出按上述算法生成的 n 位格雷码中的 k 号二进制串。

**输入描述**

> 仅一行两个整数 n,k，意义见题目描述。

**输出描述**

> 仅一行一个 n 位二进制串表示答案。

#### 示例 1

**输入**

```text
2 3
```

**输出**

```text
10
```

#### 示例 2

**输入**

```text
3 5
```

**输出**

```text
111
```

### 最终代码：

```cpp
// 格雷码：按「前一半加前缀 0、后一半逆序加前缀 1」的反射构造，
// 编号为 k 的 n 位格雷码正是 g = k ^ (k >> 1)。
#include <cstdio>

int main() {
    int n;
    unsigned long long k;
    if (scanf("%d %llu", &n, &k) != 2) return 0;
    unsigned long long g = k ^ (k >> 1);
    for (int i = n - 1; i >= 0; --i) putchar(((g >> i) & 1ULL) ? '1' : '0');
    putchar('\n');
    return 0;
}
```

### 解题思路

第一反应是照题面递归生成，但 n 一大就是 2^n 个串，肯定不行，于是想「能不能只跟 k 的二进制有关」。先手推：n=2 时编号 0..3 是 00,01,11,10，恰好是 k^(k>>1)；n=3 时 k=5 得 111 也吻合。为了确认不是巧合，我又按定义写了递归：k 在上半段就输出 0 并递归 (n−1, k)，在下半段就输出 1 且把下标翻成 2^(n−1) − 1 − (k − 2^(n−1))，发现每一步做的正是「高位取反、低位下标翻转」，展开后就是相邻位异或。最终核心只有一行：g = k ^ (k >> 1)，然后从高到低输出 n 位，前导 0 必须补齐。

#### 卡点与关键一步

- 必须输出恰好 n 位，前导 0 不能省略（n=3,k=0 要输出 000）
- n 可能到 64，k 要用 unsigned long long 读，int 会溢出
- 别真去生成 2^n 个串；递归版翻转下标是 2^(n−1) − 1 − r，少减 1 就全错

#### 复杂度

| 项 | 值 |
|---|---|
| 时间复杂度 | O(n) |
| 空间复杂度 | O(1) |
