### 知识点：

考的是环上的 01 约束传播，模型是「一个局部等式 + 枚举起点」。设 x_i ∈ {0,1} 表示 i 是否说真话，s_i 表示 i 的声称。结论：x_{i-1} = s_i ⊕ (1 − x_i)，即由「我是否说真」唯一确定「左边的人是否说真」，所以合法局面数只可能是 0、1、2。推导：若 x_i = 1，其声称正确，左边真假就等于 s_i；若 x_i = 0，其声称错误，左边真假就是 1 − s_i，两种情况合并正是上面的异或式。于是枚举 x_1 的两种取值，沿 i = 1, n, n−1, …, 2 倒推一圈，最后用 i = 1 的等式回头校验假设是否自洽。复杂度 O(n)，n 之和 ≤ 2×10^6，足够。答案为 0/1/2，取模只是通用要求。

### 题目描述

> 小苯正在和小朋友们玩游戏，他让所有的小朋友围成一圈， $i$  号小朋友左侧的是  $i-1$  号小朋友，特别的： $1$  号小朋友的左侧是  $n$  号小朋友。
>
> 现在，已知每个小朋友要么说真话，要么说假话；且每个小朋友都声称自己左侧的小朋友说了：真话（ $\texttt{`1'}$ ）或假话（ $\texttt{`0'}$ ），显然这些 "声称" 里有真有假，因为有些小朋友会说假话。
>
> 你的任务就是求出，在所有可能的不同的局面（即每个小朋友都要么说真话、要么说假话，显然一共有  $2^n$  个）中，有多少个局面满足：所有小朋友声称的真假性都和他自己说话的真假性一致。
>
> （即：如果其说真话，则其 "声称" 必然是正确的；如果说假话，则其 "声称" 也必然是不正确的。）

**输入描述**

> 每个测试文件均包含多组测试数据。第一行输入一个整数  $T\ (1\leqq T\leqq 10^5)$  代表数据组数，每组测试数据描述如下：
>
> 第一行一个正整数  $n\ (1 \leqq n \leqq 10^6)$ ，表示小朋友的个数。
>
> 第二行一个长度为  $n$  的  $\texttt{01}$  串  $s$ ，表示每一位小朋友都声称自己左侧的人说的话的真假。（如果是  $\texttt{'1'}$  就代表他声称左边的人说的是真话；反正则是假话。）
>
> 除此之外，保证单个测试文件的  $n$  之和不超过  $2 \times 10^6$ ，保证  $s$  仅由  $\texttt{`0'}$  和  $\texttt{`1'}$  两种字符构成。

**输出描述**

> 对于每组测试数据：
> 在单独的一行输出一个整数，表示在所有可能的不同局面中，合法局面的个数。（即每个人说话的真假都和自己声称的真假性一致。）（由于结果可能很大，因此输出结果对  $998244353$  取模的值。）

#### 示例

**输入**

```text
2
5
11111
3
101
```

**输出**

```text
2
0
```

### 最终代码：

```cpp
// NC304877 小苯的真假游戏
// 题目：n 个人围成一圈，i 声称左边 i-1（特别的 1 的左边是 n）说真话(1)/假话(0)，
//       求使人说的话真假与其声称一致的赋值方案数（每个 2^n 种局面中）。
//
// 记 x_i in {0,1} 为 i 是否说真，s_i 为 i 的声称。
// 若 x_i = 1，则 "左边的人说真" 成立 <=> x_{i-1} = s_i；
// 若 x_i = 0，则该声称是假的 <=> x_{i-1} = 1 - s_i。
// 合起来 x_{i-1} = s_i XOR (1 - x_i)：由 x_i 唯一确定 x_{i-1}。
// 于是只要枚举 x_1 的 2 种取值，绕环倒推一圈回来看是否自洽，方案数只可能是 0/1/2。
#include <cstdio>

using namespace std;
typedef long long ll;

int main() {
    int T;
    if (scanf("%d", &T) != 1) return 0;
    while (T--) {
        int n;
        scanf("%d", &n);
        static char buf[1000005];
        scanf("%s", buf);
        ll cnt = 0;
        for (int start = 0; start < 2; ++start) {
            int cur = start;  // 当前已知的 x_i
            bool ok = true;
            for (int step = 0; step < n; ++step) {
                int i = ((-step) % n + n) % n;  // step 0 -> 0, step 1 -> n-1, ...
                int left = (i - 1 + n) % n;
                int val = (buf[i] - '0') ^ (1 - cur);
                if (step == n - 1) {  // 回到起点，做自洽校验
                    if (val != start) ok = false;
                } else {
                    cur = val;
                }
            }
            if (ok) ++cnt;
        }
        printf("%lld\n", cnt % 998244353LL);
    }
    return 0;
}
```

### 解题思路

看到 2^n 个局面、答案还要对 998244353 取模，第一反应是「是不是要计数 DP 或者矩阵快速幂」，但读完规则发现约束非常局部：每个人只谈论左边一个人的真假，而「我说真还是说假」本身又把左边那个人的真假钉死了，所以整条链一旦定了起点就再没有自由度。于是我把条件写成等式：x_i 为真时 x_{i-1} = s_i，x_i 为假时 x_{i-1} = 1 − s_i，合起来是一个异或式。接下来只要枚举 1 号的真假两种可能，按 i = 1 → n → n−1 → … → 2 的顺序绕环推回去，最后检查推出来的 x_1 与假设是否一致，一致就给答案加一。n = 1 时自己就是自己的左邻居，同一套取模下标的写法能自动覆盖这种退化情形。写完用 2^n 暴力枚举对拍了 n ≤ 7 的全部 01 串，结果完全一致，也解释了样例 11111 → 2、101 → 0。

#### 卡点与关键一步

- 递推方向是「由 i 推 i−1」，环上要倒着绕，别把 s_i 与它左边那位的关系写反
- 合法方案数最多只有 2，看到取模不要误以为要算组合数或 DP 计数
- n = 1 时自己声称自己，要用统一的取模下标写法覆盖退化情况

#### 复杂度

| 项 | 值 |
|---|---|
| 时间复杂度 | O(Σn) |
| 空间复杂度 | O(n) |
