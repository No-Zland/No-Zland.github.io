### 知识点：

考点是字符串层面的循环位移加二进制转十进制。模型：把串看成一个环，右移 k 位后第 i 个位置来自原串下标 (i−k) mod n，所以结果串直接拼成 s[n−k:] + s[:n−k]，其中 k 先对 n 取模，不必真的移 k 次。二进制转十进制用 Horner 递推：v = v*2 + (c−'0')，从高位扫到低位，等价于按权展开 Σb_t·2^t，一次遍历即可。这题真正的坑在输入：题面给的是函数调用式的 "10110",2，不是一个串加一个整数两行，所以要先把引号内的二进制串抠出来，再取它后面的第一个数字串当 k。位数题面没有上限，因此累加用一个 128 位整数兜底，输出时手写除十取余。

---

### 题目描述

> 有一个二进制数的字符串，想把字符串循环右移k位，然后得到一个新的二进制数，求这个数的十进制值是多少。给定一个二进制字符串str和循环位移位数k，返回循环后的二进制数的十进制值。

**输入描述**

> 

**输出描述**

> 

#### 示例

**输入**

```text
"10110",2
```

**输出**

```text
21
```

### 最终代码：

```cpp
#include <iostream>
#include <string>
#include <vector>
#include <algorithm>
#include <cctype>
using namespace std;

// 用 128 位兜底：二进制串可能比 long long 长
static string i128_to_string(__int128 x) {
    if (x == 0) return "0";
    bool neg = x < 0;
    unsigned __int128 u = neg ? (unsigned __int128)(-(x + 1)) + 1 : (unsigned __int128)x;
    string s;
    while (u) { s.push_back(char('0' + (int)(u % 10))); u /= 10; }
    if (neg) s.push_back('-');
    reverse(s.begin(), s.end());
    return s;
}

int main() {
    string all, line;
    while (getline(cin, line)) { all += line; all += '\n'; }

    string s;
    long long k = 0;

    size_t q1 = all.find('"');
    size_t q2 = (q1 == string::npos) ? string::npos : all.find('"', q1 + 1);

    if (q1 != string::npos && q2 != string::npos) {
        // 输入形如 "10110",2
        s = all.substr(q1 + 1, q2 - q1 - 1);
        size_t i = q2 + 1;
        while (i < all.size() && !isdigit((unsigned char)all[i])) i++;
        long long v = 0;
        while (i < all.size() && isdigit((unsigned char)all[i])) { v = v * 10 + (all[i] - '0'); i++; }
        k = v;
    } else {
        // 没有引号的退化情况：第一个数字串当二进制串，第二个当 k
        vector<string> tok;
        string cur;
        for (size_t i = 0; i < all.size(); i++) {
            char ch = all[i];
            if (isdigit((unsigned char)ch)) cur.push_back(ch);
            else { if (!cur.empty()) { tok.push_back(cur); cur.clear(); } }
        }
        if (!cur.empty()) tok.push_back(cur);
        if (tok.empty()) return 0;
        s = tok[0];
        if (tok.size() > 1) k = stoll(tok[1]);
    }

    if (s.empty()) { cout << 0 << "\n"; return 0; }

    int n = (int)s.size();
    k %= n;  // 右移超过一圈等价于取模
    string rot = s.substr(n - (int)k) + s.substr(0, n - (int)k);

    __int128 val = 0;
    for (size_t i = 0; i < rot.size(); i++) val = val * 2 + (rot[i] - '0');
    cout << i128_to_string(val) << "\n";
    return 0;
}
```

### 解题思路

第一反应是把串真的移 k 次再求值，但看到样例输入是 "10110",2 这种带引号和逗号的形式，就先决定把输入解析单独拎出来做：整块读入，找第一对双引号取中间的串，再从右引号之后找第一段连续数字当 k，这样无论题面把两者排成一行还是两行都不会崩。解析解决后就是去掉重复劳动：右移 k 位只是下标的循环重排，k 对 n 取模就够，结果串是 s[n−k:] + s[:n−k]，长度不变。最后按 Horner 法从高位到低位累加 v = v*2 + (c−'0')，一遍扫完 O(n)。求和时我特意用了 128 位整数：题面没给位数上限，用 long long 在 64 位串上会溢出成负数，手写一个除十取余的打印函数比引高精度库更省事。

#### 卡点与关键一步

- 输入是 "10110",2 这种函数式写法，不能只写 cin >> s >> k，要按引号取串、再取逗号后的数字
- k 必须先对 len 取模；k 恰好等于 len 的整数倍时结果就是原串，别拼出空串或越界
- 位数偏长时 int/long long 会溢出，二进制累加要留够宽度（__int128 或手写高精度）

#### 复杂度

| 项 | 值 |
|---|---|
| 时间复杂度 | O(n) |
| 空间复杂度 | O(n) |
