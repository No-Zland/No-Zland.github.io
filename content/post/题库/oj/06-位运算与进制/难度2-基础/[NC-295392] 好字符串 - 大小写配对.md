### 知识点：

好字符的定义是逐字母独立的：字母 x 是好字符，当且仅当「小写 x 出现过」与「大写 X 出现过」同真同假。所以整串是好字符串 ⟺ 26 个字母的这两个布尔值全部相等。实现上只需两个 26 位掩码，扫一遍字符串：小写字母置 maskLow 的第 i 位，大写字母置 maskUp 的第 i 位，最后判断两个掩码是否相等。这一步等价于逐字母检查，但把 26 次判断压成一次整数比较。注意「同时不出现」也算合法，也就是说字符串里可以出现任意多的未配对字母，只要它们的大小写都没出现。

---

### 题目描述

> 给你一个长度为  $n$  的字符串  $s$ ，如果一个小写字母为好字符，当且仅当该小写字母对应的大写字母和它同时在字符串  $s$  中出现 或者 同时不在字符串  $s$  中出现；而如果一个字符串为好字符串，当且仅当  $26$  个小写字母  $\texttt{`a'} \sim \texttt{`z'}$  都是好字符。 
>
> 现在想知道字符串  $s$  是否为好字符串。

**输入描述**

> 第一行输入一个整数  $n$   $\left ( 1\leqq n\leqq 100 \right )$ ，表示字符串  $s$  的长度。 
> 第二行输入一个长度为  $n$  的字符串  $s$ ，仅由大小写字母组成。

**输出描述**

> 如果字符串  $s$  为好字符串，输出  $\text{YES}$ ，否则输出  $\text{NO}$ 。注意输出均为大写字母。

#### 示例 1

**输入**

```text
5
AaBBb
```

**输出**

```text
YES
```

#### 示例 2

**输入**

```text
4
abAA
```

**输出**

```text
NO
```

### 最终代码：

```cpp
#include <cstdio>

int main() {
    int n;
    if (scanf("%d", &n) != 1) return 0;
    static char s[105];
    scanf("%s", s);
    int low[26] = {0}, up[26] = {0};
    for (int i = 0; i < n; i++) {
        if (s[i] >= 'a' && s[i] <= 'z') low[s[i] - 'a'] = 1;
        else up[s[i] - 'A'] = 1;
    }
    bool ok = true;
    for (int i = 0; i < 26; i++)
        if (low[i] != up[i]) ok = false;
    puts(ok ? "YES" : "NO");
    return 0;
}
```

### 解题思路

这题读完我第一反应就是「给 26 个字母各记两个标记」。题意里有个容易看漏的点：好字符允许「大小写都不出现」，所以不能用「每个出现的字母都必须有配对」来判断，必须让 26 个字母全部参与比较。于是开两个 26 位整型掩码，扫一遍分别按大小写置位，最后比 maskLow==maskUp 即可。写完拿样例验证：AaBBb 里 a、b 大小写齐全，其余字母都不出现 → YES；abAA 里 a 齐了但 b 缺大写 B → NO。为保险又手推了 n=1、s=A 的情况，应该是 NO，程序也确实是 NO。

#### 卡点与关键一步

- 「同时不出现」也是好字符，不能只检查出现过的字母，否则会漏判
- 只出现大写（如 A）时必须输出 NO，大小写要成对出现或成对缺席
- 输出是大写 YES/NO，注意别写成 Yes

#### 复杂度

| 项 | 值 |
|---|---|
| 时间复杂度 | O(n) |
| 空间复杂度 | O(1) |
