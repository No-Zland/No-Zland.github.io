### 知识点：

考的是折叠纸条时「层的上下顺序」，本质是找规律加 64 位位移。结论：设折叠后长度 L = 2^(n-m)，在折叠后最上层距左端 x 处染色，答案是 2L+1-x，即 2^(n-m+1)+1-x。推导：每次折叠只是把后半截整摞翻过来压到前半截上，前半截各摞的位置与层序都不动，所以任一摞的最底层永远是原纸条的同一格本身（对折叠次数归纳可证）。最后一次折叠把第 q 格那摞翻过来盖到第 2L+1-q 格上，翻转会颠倒层序，原来的最底层变成最顶层；要染的是最上层，于是取 x 的镜像位置 2L+1-x 的最底层，也就是原纸条的第 2L+1-x 格。所以只有最后一次折叠影响最上层，n、m 只通过 n-m 起作用，n 可达 1e9 也完全不需要模拟。

---

### 题目描述

> 给你条宽度为  $1$ ，长度为  $2^n$  个单位长度的纸条。进行  $m$  次如下的对半折叠操作：
>
>  $\hspace{23pt}\bullet\,$ 每次都将当前纸条的后半截翻折到前半截之上。
>
> 完成  $m$  次折叠后，在折叠后的纸条正面距离左侧  $x$  个单位长度的位置进行染色，求染色的部分在折叠前、距离原纸条左侧的单位长度。
>
> 下图为  $n=3,m=2$  的折叠过程：
>
>
> ![](https://uploadfiles.nowcoder.com/images/20250513/0_1747128132199/D3FAC90B0F8994BE1DAE0203983107CB)

**输入描述**

> 在一行上输入三个正整数  $n,m,x \left(0\le n-m\le 40;\ 1\le n,m\le 10^9;\ 1\le x\le 2^{n-m} \right)$ 。

**输出描述**

> 输出一个正整数，表示染色的部分在折叠前距离原纸条左侧的单位长度。

#### 示例

**输入**

```text
3 2 1
```

**输出**

```text
4
```

### 最终代码：

```cpp
// NC294005 露西的蛋糕
// 题意：长度 2^n 的纸条，做 m 次「后半截翻折到前半截之上」，折叠后长度 L = 2^(n-m)。
//       在折叠后最上层、距左端 x 处染色，问该处原本距原纸条左端的长度。
// 结论：answer = 2 * L + 1 - x = 2^(n-m+1) + 1 - x。
// 推导：
//   1) 每摞纸的最底层永远是原位置 p 本身——前半截从不被搬动，只往上压新层；
//   2) 最后一次折叠把后半截第 q 格整摞翻过来盖到第 2L+1-q 格上，翻转会把这一摞
//      上下颠倒，于是「翻转前的最底层」变成「翻转后的最顶层」；
//   3) 最顶层 = 翻转前位置 2L+1-x 的最底层 = 原纸条位置 2L+1-x。
//   只有最后一次折叠决定最上层，所以答案只与 n-m 和 x 有关。
#include <cstdio>
int main() {
    long long n, m, x;
    if (scanf("%lld %lld %lld", &n, &m, &x) != 3) return 0;
    long long L = 1LL << (n - m);        // 折叠后长度，保证 0 <= n-m <= 40
    printf("%lld\n", 2LL * L + 1 - x);   // 最顶层来自原纸条的镜像位置
    return 0;
}
```

### 解题思路

这题我卡了好几轮。一开始想逐次模拟整条纸带的折叠，但 2^n 随 n 爆炸，根本存不下；又想只追踪被染的那一格，可折叠方向每层都在变，递归写出来对不上样例。真正的转折是我把 n=3、m=2 的折叠用纸和笔一格一格画出来：第一折后折叠位置 1 那摞是 {1,8}，第二折把右半两摞翻过来盖到左边，位置 1 就变成 {1,8} 加上翻转后的 {4,5}，最顶上正好是样例要的 4。这让我意识到「最上层」只由最后一次折叠决定，而每次折叠都只是把后半截翻过来压上去，所以每摞的最底层恒等于它原来的位置。于是答案就是 x 关于最后一条折线的镜像 2L+1-x，n 和 m 只通过 n-m 进入公式。为保险我写了全量模拟，对 n ≤ 7 的所有 m、x 比对公式，确认处处一致后才改成交付版本。

#### 卡点与关键一步

- 「正面」是折叠后朝上的最上层，不要去还原最底层那一格，否则样例会算成 1 而不是 4。
- 答案可到 2^41，必须用 `long long` 和 `1LL << k`，`int` 与 `1 << k` 都会溢出。
- 折叠后的长度是 2^(n-m)（n-m ≤ 40），x 的相对位置也基于它，别把镜像轴当成 2^n。
