### 知识点：

结论：n 为奇数无解，n 为偶数时答案就是 n 的二进制分解。理由两条：一、2 的正整数次幂（2,4,8,…）都是偶数，若干个偶数之和仍是偶数，所以奇数不可能拆出来，直接输出 −1；二、偶数的二进制表示里 2^0 位本来就是 0，按位权展开天然满足「互不相同」和「和为 n」，方案唯一。因此实现只有两步：判奇偶，然后从高位到低位把为 1 的位权输出。所谓「2 的正整数次幂」不含 2^0=1，这正是奇数无解的根源，也是本题唯一的坑。

>  对于正整数  $𝑛&preview=true$  的一种特定拆分，我们称它为“优秀的”，当且仅当在这种拆分下， $𝑛&preview=true$  被分解为了若干个不同的  $2&preview=true$  的正整数次幂。注意，一个数  $𝑥&preview=true$  能被表示成  $2&preview=true$  的正整数次幂，当且仅当  $𝑥&preview=true$  能通过正整数个  $2&preview=true$  相乘在一起得到。

### 最终代码：

```cpp
// 优秀的拆分：拆成若干个互不相同的 2 的正整数次幂。
// 2 的正整数次幂都是偶数，故奇数无解；偶数按二进制位从高到低输出即可（2^0 位天然为 0）。
#include <cstdio>

int main() {
    unsigned long long n;
    if (scanf("%llu", &n) != 1) return 0;
    if (n & 1ULL) { puts("-1"); return 0; }

    bool first = true;
    for (int i = 63; i >= 0; --i) {
        if ((n >> i) & 1ULL) {
            if (!first) putchar(' ');
            printf("%llu", (unsigned long long)(1ULL << i));
            first = false;
        }
    }
    putchar('\n');
    return 0;
}
```

### 解题思路

看到「若干个不同的 2 的正整数次幂之和」，第一反应就是二进制：任何数的二进制位权展开本身就是互不相同的 2 的幂之和，唯一性也自动满足。唯一的坑是 2^0=1 不算正整数次幂，所以 n 为奇数时最低位为 1，无论怎么拆都要用到 1，无解，输出 −1；偶数最低位是 0，直接高位到低位输出。n=6 是 110 → 4 2，n=7 最低位是 1 → −1，两个样例都符合。输出按题意从大到小、空格分隔，我用 first 标记控制空格，避免行尾多一个空格。

#### 卡点与关键一步

- 1 = 2^0 不算「2 的正整数次幂」，所以奇数一律无解，别把 1 当合法项
- 输出要求从大到小、相邻两数一个空格，行尾不要多余空格
- n 可能到 2^63 量级，要用 unsigned long long 读，位权写 1ULL << i

#### 复杂度

| 项 | 值 |
|---|---|
| 时间复杂度 | O(log n) |
| 空间复杂度 | O(1) |
