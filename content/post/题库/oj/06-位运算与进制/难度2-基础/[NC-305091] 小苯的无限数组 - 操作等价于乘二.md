### 知识点：

考的是找出一次删除操作之后下标与值的映射关系，模型是「操作叠加」。结论：k 次操作后 a_n = n × 2^k。推导：原数组是 1, 2, 3, …，删掉奇数下标（值为 1, 3, 5, …）后剩下 2, 4, 6, …，左移补位后新数组第 i 项恰好是 2i，也就是整体值翻倍；再做一次操作，仍然是对当前数组取偶数位再左移，同样等于再乘 2。每一步都是独立的「乘 2」，可以直接叠加，所以 k 次就是乘 2^k。数据范围 n ≤ 1e5、k ≤ 10，n·2^k ≤ 1e8 在 int 内，但用 long long 更稳，写 n << k 或循环乘 2 都可以。

### 题目描述

> 小苯有一个无限长的升序数组  $a=\{1,2,3,...\}$ ，即  $a_i=i$ ，现在小红对  $a$  执行了  $k$  次操作，具体来说：
>
>
>
>  $\hspace{23pt}\bullet$  每次操作，小红都会将数组的奇数下标的元素全部删除，只保留偶数下标的元素，同时剩余的元素如果左侧有空位就会左移，直到补满所有空位。
>
>  $\hspace{23pt}$  例如第一次操作后， $a$  数组会从  $\{1,2,3...\}$  变为  $\{2,4,6...\}$ 。
>
> 在所有操作执行完后，小苯想知道  $a_n$  的值是多少，你的任务就是帮他求出所有  $k$  次操作执行完后  $a_n$  的值。

**输入描述**

> 每个测试文件均包含多组测试数据。第一行输入一个整数  $T\ (1\leqq T\leqq 100)$  代表数据组数，每组测试数据描述如下：
>
> 第一行两个整数  $n, k\ (1 \leqq n \leqq 10^5, 0 \leqq k \leqq 10)$ ，分别表示询问的下标和操作的次数。

**输出描述**

> 对于每组测试数据：
> 在单独的一行输出一个整数表示所有操作执行完后  $a_n$  的值。

#### 示例

**输入**

```text
2
4 1
3 0
```

**输出**

```text
8
3
```

### 最终代码：

```cpp
// NC305091 小苯的无限数组
// 题目：a = {1,2,3,...}，每次删掉奇数下标元素、剩下的左移，问 k 次操作后 a_n。
// 结论：每操作一次等价于把所有值乘 2（保留下标 2,4,6,... 即原值 2,4,6,...），
//       所以 a_n = n * 2^k。
#include <cstdio>

using namespace std;

int main() {
    int T;
    if (scanf("%d", &T) != 1) return 0;
    while (T--) {
        long long n, k;
        scanf("%lld %lld", &n, &k);
        long long ans = n;
        for (long long i = 0; i < k; ++i) ans <<= 1;
        printf("%lld\n", ans);
    }
    return 0;
}
```

### 解题思路

第一反应是「k 只有 10，暴力模拟几步不就好了」，但数组是无限长的，真去模拟既不现实也没必要，所以必须先找规律。我手推了前几步：原数组 1, 2, 3, 4, 5…；一次操作后 2, 4, 6, 8…，正好是每项都乘 2；再操作一次得到 4, 8, 12…，还是乘 2。于是猜想每次操作等价于整体乘 2，用归纳一看也成立——当前数组第 i 项是 i·2^j，删掉奇数下标后第 i 项变成 (2i)·2^j = i·2^{j+1}。既然 k ≤ 10，答案就是 n 左移 k 位。为了不「想当然」，我又写了个暴力：真开一个够长的数组，每次取下标为奇数的部分丢掉、剩下的前移，对 n ≤ 60、k ≤ 4 全部对拍，结果完全一致。样例 4 1 → 8 和 3 0 → 3 也都对得上。

#### 卡点与关键一步

- 操作删的是「奇数下标」而不是「奇数元素」，本题两者恰好等价，但别把这个巧合当一般结论
- k = 0 时答案就是 n，左移 0 位虽然自然正确，但别漏掉这个分支的验证
- 多组数据，每组单独输出一行，别漏行或多输出

#### 复杂度

| 项 | 值 |
|---|---|
| 时间复杂度 | O(T·k) |
| 空间复杂度 | O(1) |
