### 知识点：

考的是「换根」公式的反向使用：已知每个点到全树点权的距离加权和 t_i，反求点权。结论：设 W 为总点权和，对父 p 与子 v 有 t_v - t_p = (W - S_v) - S_v = W - 2S_v，故 S_v = (W - (t_v - t_p)) / 2；再用 Σ_{v≠root} S_v = Σ_x val_x·depth(x) = t_root，得 (n-1)W - Σ(t_v - t_p) = 2t_root，W 唯一确定。推导核心是换根时 v 子树内的点距离减 1、子树外的点加 1，相减正好剩 (W-S_v)-S_v。拿到 W 后所有 S_v 可算，而 val_v = S_v - Σ_child S_c（根用 W 代替），自顶向下作差即可。

### 题目描述

> “或停留在金色枝头声声歌唱”。
>
> 给定一棵边权为  $1$ ，由  $n$  个节点构成的树，第  $i$  个点的点权为  ${\rm val}_i$  ，设  ${\rm dis}(i,j)$  表示点  $i$  到点  $j$  的最短距离（特别地， ${\rm dis}(i,i)=0$  ），记  $t_i=\sum\limits_{j=1}^n {\rm val}_j\times {\rm dis}(i,j)$ 。
>
> 现在给定树的结构和  $t$  数组，要求求出  ${\rm val}$  数组（数据保证  ${\rm val}_i$  均为正整数）。

**输入描述**

> 第一行输入一个整数  $n \left(2\le n\le 6\times 10^5\right)$ 
> 此后  $n-1$  行，第  $i$  行输入两个整数  $u_i,v_i \left(1\le u_i,v_i\le n\right)$  表示第  $i$  条树边连接节点  $u_i$  和节点  $v_i$ 。
> 第  $n+1$  行输入  $n$  个整数  $t_1, t_2, \dots, t_n \left(1\le t_i\le 10^9\right)$  代表给定的数组。
>
>  $n\\
> u_1\ v_1\\
> u_2\ v_2\\
> \vdots\\
> u_{n-1}\ v_{n-1}\\
> t_1\ t_2\ t_3\dots\ t_n$

**输出描述**

> 在一行上输出  $n$  个正整数  $val_1, val_2, \dots, val_n$ ，第  $i$  个整数表示节点  $i$  的点权。

#### 示例 1

**输入**

```text
2
1 2
1 3
```

**输出**

```text
3 1
```

#### 示例 2

**输入**

```text
5
1 2
1 3
1 4
1 5
18 40 40 24 28
```

**输出**

```text
6 1 1 9 7
```

#### 示例 3

**输入**

```text
5
1 2
1 3
3 4
4 5
34 40 34 40 56
```

**输出**

```text
3 9 3 5 4
```

### 最终代码：

```cpp
// NC293975 树到云端
// 题意：树上边权为 1，t_i = sum_j val_j * dis(i,j)，已知整棵树与 t，反求正整数 val。
// 关键关系（换根）：设 W = sum val，边 (p -> v)（p 为父）对应的子树权和为 S_v，则
//   t_v - t_p = (W - S_v) - S_v = W - 2 S_v   =>   S_v = (W - (t_v - t_p)) / 2
// 又因为 sum_{v != root} S_v = sum_x val_x * depth(x) = t_root，于是
//   (n-1) W - sum_{v != root} (t_v - t_p) = 2 t_root  =>  W 唯一确定。
// 得到 W 后可算出所有 S_v，再自上而下作差：val_v = S_v - sum_{child} S_c（根用 W 代替 S_root）。
#include <algorithm>
#include <climits>
#include <cstdio>
#include <cstring>
#include <string>
#include <vector>
using namespace std;

namespace io {
const int SZ = 1 << 16;
char buf[SZ];
int len = 0, pos = 0;
inline int gc() {
    if (pos == len) {
        len = (int)fread(buf, 1, SZ, stdin);
        pos = 0;
        if (len <= 0) return -1;
    }
    return (unsigned char)buf[pos++];
}
inline long long readInt() {
    int c = gc();
    long long x = 0;
    int sgn = 1;
    while (c != -1 && (c < '0' || c > '9') && c != '-') c = gc();
    if (c == '-') { sgn = -1; c = gc(); }
    while (c >= '0' && c <= '9') { x = x * 10 + (c - '0'); c = gc(); }
    return x * sgn;
}
} // namespace io

int main() {
    int n = (int)io::readInt();
    size_t E = 2 * (size_t)(n - 1) + 2;
    vector<int> head(n + 1, -1), to(E), nxt(E);
    int ec = 0;
    for (int i = 1; i < n; ++i) {
        int u = (int)io::readInt(), v = (int)io::readInt();
        to[ec] = v; nxt[ec] = head[u]; head[u] = ec++;
        to[ec] = u; nxt[ec] = head[v]; head[v] = ec++;
    }
    vector<long long> t(n + 1);
    for (int i = 1; i <= n; ++i) t[i] = io::readInt();

    // 迭代 BFS 定根为 1，n 可达 6e5，不能递归
    vector<int> par(n + 1, 0), order;
    order.reserve(n);
    order.push_back(1);
    par[1] = 0;
    for (size_t k = 0; k < order.size(); ++k) {
        int u = order[k];
        for (int e = head[u]; e != -1; e = nxt[e]) {
            int v = to[e];
            if (v == par[u]) continue;
            par[v] = u;
            order.push_back(v);
        }
    }

    long long K = 0;                               // sum_{v != root} (t_v - t_par(v))
    for (int i = 1; i < n; ++i) K += t[order[i]] - t[par[order[i]]];
    long long W = (2 * t[1] + K) / (n - 1);        // 总点权和

    vector<long long> S(n + 1, 0), ans(n + 1, 0);
    for (int i = 1; i < n; ++i) {
        int v = order[i];
        S[v] = (W - (t[v] - t[par[v]])) / 2;       // 子树权和
    }
    for (int v = 1; v <= n; ++v) ans[v] = (v == 1 ? W : S[v]);
    for (int i = 1; i < n; ++i) {                  // 减去每个孩子的整棵子树
        int v = order[i];
        ans[par[v]] -= S[v];
    }

    string out;
    out.reserve((size_t)n * 8);
    char tmp[32];
    for (int i = 1; i <= n; ++i) {
        int ln = snprintf(tmp, sizeof(tmp), "%lld", ans[i]);
        if (i > 1) out.push_back(' ');
        out.append(tmp, ln);
    }
    out.push_back('\n');
    fwrite(out.data(), 1, out.size(), stdout);
    return 0;
}
```

### 解题思路

看到「给 t 求 val」，我第一反应是用换根公式：从父挪到子时，子树内的点都近了一格、子树外的都远了一格，差值只和总权 W 与子树权和 S_v 有关。可这个式子同时含 W 和 S_v，看上去是 n 个方程、n+1 个未知量，缺一个条件。盯着 t 的结构想了很久，我注意到 Σ_{v≠root} S_v 恰好就是 t_root——每个点会被它到根路径上除根以外的每个祖先各统计一次，这一步是全题的题眼，它把 W 解了出来。有了 W，S_v 一算就有，val_v 只是「自己的子树和减去所有孩子的子树和」。实现上我全部用迭代 BFS，n=6e5 的链不能递归；读入换成了自己写的缓冲读。写完后用随机小树反推对拍，第三组样例还帮我逮到「减子树和写成减孩子点权」的 bug。

#### 卡点与关键一步

- 不能用递归 DFS：n 可到 6e5，一条链会直接爆栈。
- val_v 要减的是孩子的子树权和 S_c，不是孩子的点权 val_c，这层差别在样例 3 会立刻暴露。
- Σ(t_v - t_p) 可达 6e14，全部用 `long long`；根节点要拿 W 当「子树和」，不能直接用 S_root。

|---|---|
| 时间复杂度 | O(n) |
| 空间复杂度 | O(n) |
