### 知识点：

结论：答案等于「gcd(a_i,a_{i+1})=1 的相邻边」这张图的最小点覆盖，而它的边只连在原序列相邻位置之间，是路径的子图，从左往右贪心、每条尚未被覆盖的坏边都选右端点即为最优。关键推导：被修改的元素可以取任意正整数，取左邻居的一个质因子乘右邻居的一个质因子，就能同时和两侧不互质（两个邻居都被修改时取同一个常数即可），所以「能不能修好」只取决于那些两端都未修改的相邻对；每个坏边至少要有一个端点被修改，这正是点覆盖。路径上的最小点覆盖贪心正确性用交换论证：坏边 (i,i+1) 选右端点 i+1 能覆盖到 (i+1,i+2)，比选 i 覆盖得更靠右，不会更差。

### 题目描述

> 小苯有一个长度为  $n$  的序列  $a_1, a_2, \dots, a_n$ ，每个元素都是正整数。
>
> 小苯每次操作可以选择序列中的一个元素  $a_i$ ，将其替换为任意正整数。
>
> 小苯想知道，最少需要修改多少个元素（可以不修改），才能使得序列  $a$  满足：任意相邻的元素都不是互质的。
>
> 你的任务就是求出这个最小修改次数。
>
> 【名词解释】
>
> 互质：多个整数的最大的共有约数（简称最大公约数，gcd）如果恰好为  $1$ ，被称它们为互质的。例如， $12$  和  $30$  的公约数有  $1,2,3,6$ ，其中最大的约数是  $6$ ，所以它们不是互质的； $5$  和  $7$  的公约数仅有  $1$ ，所以它们是互质的。

**输入描述**

> 每个测试文件均包含多组测试数据。第一行输入一个整数  $T\left(1 \leqq T \leqq 10^4\right)$  代表数据组数，每组测试数据描述如下：
>  $\hspace{23pt}\bullet\,$ 第一行输入一个整数  $n\left(2 \leqq n \leqq 2 \times 10^5\right)$ ，表示序列的长度。
>  $\hspace{23pt}\bullet\,$ 第二行输入  $n$  个正整数  $a_1, a_2, \dots, a_n\left(1 \leqq a_i \leqq 10^6\right)$ ，表示序列的元素。
> 除此之外，保证单个测试文件的  $n$  之和不超过  $2 \times 10^5$ 。

**输出描述**

> 对于每一组测试数据，新起一行输出一个整数，表示最小修改次数。

#### 示例

**输入**

```text
3
5
2 3 6 1 10
4
2 2 2 2
6
6 1 5 6 2 15
```

**输出**

```text
2
0
3
```

### 最终代码：

```cpp
#include <cstdio>
#include <vector>
#include <numeric>
using namespace std;

// 邻合：被修改的位置取值可任意，总能同时和左右邻接，
// 于是问题等价于「选最少的点覆盖所有 gcd=1 的相邻边」，即路径子图的最小点覆盖。
// 从左往右贪心：边坏且左端点没被选，就选右端点。
int main() {
    int T;
    if (scanf("%d", &T) != 1) return 0;
    while (T--) {
        int n;
        scanf("%d", &n);
        vector<int> a(n);
        for (int i = 0; i < n; i++) scanf("%d", &a[i]);
        int cnt = 0;
        bool selPrev = false; // 上一个位置是否已被修改
        for (int i = 0; i + 1 < n; i++) {
            bool bad = std::gcd(a[i], a[i + 1]) == 1;
            if (bad && !selPrev) {
                cnt++;
                selPrev = true;
            } else {
                selPrev = false;
            }
        }
        printf("%d\n", cnt);
    }
    return 0;
}
```

### 解题思路

一上来我想到的是 DP：每个位置考虑改或不改，但「改成什么」这个维度看起来会爆炸，卡了一下。真正的转折是意识到修改后的值完全自由：只要取左右邻各一个质因子的乘积，就能保证和两边都不互质，所以改过的位置一定是安全的。这样问题只剩「哪些位置必须改」，也就是让所有 gcd=1 的相邻边都被至少一个端点覆盖——路径子图上的最小点覆盖。路径上的最小点覆盖有很干脆的贪心：从左往右看边，遇到坏边且左端点没被选，就选右端点，并记下这个位置已被选，下一条边就能直接跳过。手推样例 2 3 6 1 10 得 2，2 2 2 2 得 0，6 1 5 6 2 15 得 3，和输出一致。

#### 卡点与关键一步

- 别去 DP「改成什么数」，改过的元素可以配任意邻居，这是把问题化成点覆盖的关键。
- 贪心要记住左端点是否已被选，否则同一条坏边会被重复计数。
- 1 与任何正整数都互质，a_i=1 相关的相邻对全部是坏边，别漏判。

#### 复杂度

| 项 | 值 |
|---|---|
| 时间复杂度 | O(n log A) |
| 空间复杂度 | O(n) |
