### 知识点：

关键化简：记 A=ww'（长度 2k 的偶回文），则 t=A A。反过来，t 回文且前一半 A 回文时必有 t=A A。故「廻文串」= 以 c 为偶中心半径 2k 的回文，且半段以 c−k 为偶中心半径 k 也回文。用偶回文 Manacher 的 d2[i]（以 i−1,i 为偶中心的最长半径），条件即 d2[c]≥2k 且 d2[c−k]≥k；令 j=c−k，得 j∈[c−⌊d2[c]/2⌋, c−1] 且 j+d2[j]≥c，是二维偏序，离线按 c 降序扫、树状数组数点即得总数。覆盖是区间覆盖最少条数：每个中心取最大可行 k（线段树二分找最左满足 j+d2[j]≥c 的 j）得区间 [c−2k,c+2k−1]，对左端点做前缀最大得 reach[p]，从 −1 起反复跳即最小覆盖数。

### 题目描述

> 信条-TeneT
>
> 定义一个字符串  $t$  是「廻文串」，当且仅当其满足以下条件之一：
>
>  $\hspace{23pt}\bullet\,$  $|t| = 1$ ，即  $t$  是一个单字符；
>
>  $\hspace{23pt}\bullet\,$  $t$  由非空字符串  $w$  和其反转  $w'$  拼接两遍构成，即  $t = ww'ww'$ ，更具体地说，记  $w$  的长度为  $k$ ，则： $t = \underbrace{w_1 w_2 \cdots w_k}_{w} \underbrace{w_k \cdots w_2 w_1}_{w'} \underbrace{w_1 w_2 \cdots w_k}_{w} \underbrace{w_k \cdots w_2 w_1}_{w'}$ ，长度为  $4 \times k$ 。
>
> 定义一个字符串的连续子串是「廻文子串」，当且仅当其是「廻文串」。 
>
> 现在，给定一个字符串  $s$ ，下标从  $1$  开始，请你求解：
>
>  $\hspace{23pt}\bullet\,$  $s$  一共有多少个「廻文子串」；
>
>  $\hspace{23pt}\bullet\,$ 最少需要多少个「廻文子串」才能够覆盖这个字符串（不要求恰好覆盖，即可以存在选中的廻文子串之间存在重叠），更具体地——对于字符串  $s$  的  $k$  个 廻文子串  $\{s[l_i..r_i]\}_{i=1}^k$ ，若对于任意  $p \in [1, |s|]$ ，存在  $i \in [1, k]$  使得  $l_i \leq p \leq r_i$ ，则称这  $k$  个子串覆盖了  $s$ ；能取到的最小的  $k$  即为答案，也可以称为最小覆盖数。

**输入描述**

> 输入一个长度为  $4 \leqq {\rm length}(s) \leqq 5\times 10^5$ ，由小写字母构成的字符串  $s$ 。

**输出描述**

> 在一行上输出两个整数，分别表示  $s$  一共有多少个「廻文子串」、 $s$  的最小覆盖数。

#### 示例 1

**输入**

```text
abbaccabbabbbbabb
```

**输出**

```text
18 14
```

#### 示例 2

**输入**

```text
aaaaa
```

**输出**

```text
7 2
```

#### 示例 3

**输入**

```text
aabbbbbbba
```

**输出**

```text
14 5
```

#### 示例 4

**输入**

```text
hhiihhhhhh
```

**输出**

```text
13 6
```

### 最终代码：

```cpp
#include <cstdio>
#include <cstring>
#include <vector>
#include <algorithm>

// 廻文串 = w w' w w'（|w| = k >= 1），长度为 4k。
// 记 A = w w'，则 A 是长度 2k 的偶回文，t = A A。
// 反过来：t 是回文且 t 的前一半 A 是回文 <=> t = A A，A 回文。

static const int MAXN = 500005;
static char s[MAXN];
static int d2[MAXN];   // d2[i]：以 (i-1,i) 之间为偶中心的最长偶回文半径
static int vv[MAXN];   // vv[j] = j + d2[j]
static int n;

// ---------- 偶回文 Manacher ----------
static void manacher() {
    for (int i = 0, l = 0, r = -1; i < n; i++) {
        int k = (i > r) ? 0 : std::min(d2[l + r - i + 1], r - i + 1);
        while (i + k < n && i - k - 1 >= 0 && s[i + k] == s[i - k - 1]) k++;
        d2[i] = k;
        if (i + k - 1 > r) { l = i - k; r = i + k - 1; }
    }
}

// ---------- 线段树：区间内最左的 vv[j] >= 阈值 的位置 ----------
static int seg[4 * MAXN];
static void build(int node, int l, int r) {
    if (l == r) { seg[node] = vv[l]; return; }
    int mid = (l + r) >> 1;
    build(node << 1, l, mid);
    build(node << 1 | 1, mid + 1, r);
    seg[node] = std::max(seg[node << 1], seg[node << 1 | 1]);
}
// 返回 [ql,qr] 中最小的下标 j 满足 vv[j] >= th，没有返回 -1
static int findFirst(int node, int l, int r, int ql, int qr, int th) {
    if (r < ql || l > qr || seg[node] < th) return -1;
    if (l == r) return l;
    int mid = (l + r) >> 1;
    int res = findFirst(node << 1, l, mid, ql, qr, th);
    if (res != -1) return res;
    return findFirst(node << 1 | 1, mid + 1, r, ql, qr, th);
}

// ---------- 树状数组：离线数点 ----------
static int bit[MAXN];
static void bitAdd(int i, int val) {
    for (i++; i <= n; i += i & (-i)) bit[i] += val;
}
static int bitSum(int i) {  // [0..i]
    int r = 0;
    for (i++; i > 0; i -= i & (-i)) r += bit[i];
    return r;
}

int main() {
    if (scanf("%s", s) != 1) return 0;
    n = (int)strlen(s);
    manacher();
    for (int j = 0; j < n; j++) vv[j] = j + d2[j];

    // 计数：对偶中心 c（1..n-1）与半径 2k，
    // 条件 d2[c] >= 2k 且 d2[c-k] >= k，令 j = c-k，则 j in [c-D, c-1] 且 j+d2[j] >= c
    struct Query { int c, L, R; };
    std::vector<Query> qs;
    qs.reserve(n);
    for (int c = 1; c < n; c++) {
        int D = d2[c] / 2;
        if (D > 0) qs.push_back({c, c - D, c - 1});
    }
    std::sort(qs.begin(), qs.end(), [](const Query &a, const Query &b) { return a.c > b.c; });
    std::vector<int> ids(n);
    for (int i = 0; i < n; i++) ids[i] = i;
    std::sort(ids.begin(), ids.end(), [](int a, int b) { return vv[a] > vv[b]; });

    long long cnt = 0;
    int ptr = 0;
    for (size_t qi = 0; qi < qs.size(); qi++) {
        Query &q = qs[qi];
        while (ptr < n && vv[ids[ptr]] >= q.c) { bitAdd(ids[ptr], 1); ptr++; }
        cnt += bitSum(q.R) - bitSum(q.L - 1);
    }

    // 覆盖：对每个中心 c 取最大可行 k，得到区间 [c-2k, c+2k-1]
    build(1, 0, n - 1);
    std::vector<int> best(n + 1, -1);
    for (int c = 1; c < n; c++) {
        int D = d2[c] / 2;
        if (D <= 0) continue;
        int jmin = findFirst(1, 0, n - 1, c - D, c - 1, c);
        if (jmin == -1) continue;
        int k = c - jmin;
        int L = c - 2 * k, R = c + 2 * k - 1;
        if (R > best[L]) best[L] = R;
    }
    for (int p = 0; p < n; p++) if (best[p] < p) best[p] = p;  // 单字符一定可行
    int reach = -1;
    for (int p = 0; p < n; p++) {
        if (best[p] > reach) reach = best[p];
        best[p] = reach;   // best[p] = max{ maxEnd[l] : l <= p }
    }
    int steps = 0, covered = -1;
    while (covered < n - 1) {
        covered = best[covered + 1];
        steps++;
    }

    printf("%lld %d\n", cnt + n, steps);
    return 0;
}
```

### 解题思路

第一反应是这串东西看着唬人，但 ww'ww' 明显是 (ww')²，先把它化简成 A A，再问「A 回文」这个条件能不能由 t 回文自动得到——推了一下发现不行，必须两条都留，不过两条都能落在 Manacher 的半径上，心里就踏实了。于是把「长度为 4k 的 t」编码成偶中心 c 和半长 k：d2[c]≥2k 管大回文，d2[c−k]≥k 管小回文。第二个条件写成 j=c−k 后变成 j+d2[j]≥c，正好是「下标区间 + 阈值」的二维偏序，直接离线加 BIT 统计，避免 O(n²) 枚举。覆盖这块先想清楚这是区间覆盖而不是划分：把每个中心的看成一个区间，左端点做前缀最大得到「覆盖到 p 之后最远能到哪」，再贪心跳。写完后用随机小串对拍暴力（枚举所有 ww'ww' 并贪心），确认计数和覆盖数都对。

#### 卡点与关键一步

- 计数要加上 n 个单字符子串，题面里 |t|=1 也算廻文串
- 覆盖是区间覆盖：左端点 ≤ 已覆盖右端 +1 的区间都能选，只从「当前位置」起跳会算多
- Manacher 偶半径中心 c 从 1 开始，d2[c]/2 才是 k 的上界，长度 0 的中心不要计入答案

#### 复杂度

| 项 | 值 |
|---|---|
| 时间复杂度 | O(n log n) |
| 空间复杂度 | O(n) |
