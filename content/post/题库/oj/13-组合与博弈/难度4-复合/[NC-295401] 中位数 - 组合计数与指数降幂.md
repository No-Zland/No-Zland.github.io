### 知识点：

mid(l,r) 是区间第 ⌈len/2⌉ 大，换成升序下标就是 ⌊len/2⌋+1（长度偶数时取偏大的那个）。中位数位置只由区间长度决定，所以按长度 L 分类：固定一个值 v，它成为长度 L 区间中位数的方案数是 C(v−1,k−1)·C(n−v,L−k)·L!·(n−L)!，其中 k=⌊L/2⌋+1；同长度区间共 n−L+1 个且对称同分布，故 ans=∏_L(∏_v v^{cnt})^{n−L+1}。指数对 MOD−1 取模（MOD=1610612741 是素数，费马小定理），组合数用 Pascal 加法递推，规避 MOD−1 非素数不能求逆的问题。

### 题目描述

> 给定一个整数  $n$ ，现在对于一个长度为  $n$  的排列  $p_1,p_2,\dots,p_n$ ，其价值  $\operatorname{v}(p)$  定义为： 
>
>
>
>  $\operatorname{v}(p)=\textstyle\prod\limits_{l=1}^{n}\textstyle\prod\limits_{r=l}^{n}\operatorname{mid}(l,r)$ 
>
> 现在，需要你求出所有  $n!$  种不同排列的价值的总乘积。由于答案可能很大，请将答案对  $1\,610\,612\,741$ （TXT文本复制：1610612741）取模后输出。
>
> 【名词解释】
>
>  $\operatorname{mid}(l,r)$  指的是区间  $[l,r]$  内第  $\left \lceil \tfrac{r-l+1}{2} \right \rceil$  大的数值，例如：数组  $\{1,2,3,4\}$  中第  $1$  大是  $4$ ，第  $2$  大是  $3$ ，第  $3$  大是  $2$ ，第四大是  $1$ ，所以，这个数组的中位数是第  $2$  大的数，是  $3$ 。
>
> 长度为  $n$  的排列是由  $1,2,\dots,n$  这  $n$  个整数、按任意顺序组成的数组（每个整数均恰好出现一次）。例如， $\{2,3,1,5,4\}$  是一个长度为  $5$  的排列，而  $\{1,2,2\}$  和  $\{1,3,4\}$  都不是排列，因为前者存在重复元素，后者包含了超出范围的数。

**输入描述**

> 第一行输入一个整数  $n$   $\left ( 1\leqq n\leqq 6\times 10^3 \right )$ ，表示排列  $p$  的长度。

**输出描述**

> 输出一个整数，代表所有  $n!$  种不同排列的价值的总乘积。由于答案可能很大，请将答案对  $1\,610\,612\,741$  取模后输出。

#### 示例 1

**输入**

```text
2
```

**输出**

```text
16
```

#### 示例 2

**输入**

```text
1000
```

**输出**

```text
1294676896
```

### 最终代码：

```cpp
#include <cstdio>
#include <vector>
using namespace std;

// ans = 所有长度 L 的区间、所有排列中，该区间第 (floor(L/2)+1) 小元素的连乘积。
// 同长度的区间对称同分布，共 n-L+1 个，于是
//   ans = prod_{L=1..n} ( prod_{v=1..n} v^{C(v-1,k-1)*C(n-v,L-k)*L!*(n-L)!} )^{n-L+1}
// 其中 k = floor(L/2)+1。指数对 MOD-1 取模（MOD 是素数）；
// 组合数用 Pascal 加法递推算 mod (MOD-1)，全程只用加法。
static const long long MOD = 1610612741LL;
static const long long P2 = MOD - 1;

int main() {
    int n;
    if (scanf("%d", &n) != 1) return 0;
    int K = n / 2 + 1;                 // 需要的最大列号
    size_t W = (size_t)K + 1;
    // C[i][j] mod (MOD-1)，一维展开
    vector<unsigned int> C((size_t)(n + 1) * W, 0);
    for (int i = 0; i <= n; i++) {
        C[(size_t)i * W] = 1;
        int up = i < K ? i : K;
        for (int j = 1; j <= up; j++) {
            unsigned long long v = 0;
            if (j <= i - 1) v += C[(size_t)(i - 1) * W + j];
            if (j - 1 <= i - 1) v += C[(size_t)(i - 1) * W + (j - 1)];
            C[(size_t)i * W + j] = (unsigned int)(v % (unsigned long long)P2);
        }
    }
    vector<long long> fact(n + 1);
    fact[0] = 1;
    for (int i = 1; i <= n; i++) fact[i] = fact[i - 1] * i % P2;

    vector<long long> ex(n + 1, 0);
    for (int L = 1; L <= n; L++) {
        int k = L / 2 + 1;
        int a = k - 1, b = L - k;
        long long mult = fact[L] * fact[n - L] % P2;
        mult = mult * (n - L + 1) % P2;
        for (int v = 1; v <= n; v++) {
            long long A = C[(size_t)(v - 1) * W + a];   // 比 v 小的 v-1 个数中选 a 个进区间
            long long B = C[(size_t)(n - v) * W + b];   // 比 v 大的 n-v 个数中选 b 个进区间
            long long e = A * B % P2 * mult % P2;
            ex[v] += e;
            if (ex[v] >= P2) ex[v] -= P2;
        }
    }
    long long ans = 1;
    for (int v = 1; v <= n; v++) {
        if (!ex[v]) continue;
        long long t = 1, base = v % MOD, e = ex[v];
        while (e) {
            if (e & 1) t = t * base % MOD;
            base = base * base % MOD;
            e >>= 1;
        }
        ans = ans * t % MOD;
    }
    printf("%lld\n", ans);
    return 0;
}
```

### 解题思路

面对「所有排列的价值总乘积」，我先想把排列维度和区间维度拆开：每个排列里每个区间贡献一个中位数。关键观察是中位数的位置只由区间长度决定，与具体元素无关，所以同长度的区间在全体排列上完全对称、同分布，只要算一个代表再乘 n−L+1。接着是「某个值 v 当选中位数多少次」的计数：比 v 小的 v−1 个数里挑 k−1 个、比 v 大的 n−v 个数里挑 L−k 个进区间，区间内 L! 种、区间外 (n−L)! 种排法，纯组合。指数是天文数字，必须降幂，而 MOD 是素数，指数对 MOD−1 取模；坑在于 MOD−1 不是素数、不能求逆元，所以组合数走 Pascal 加法递推。写完先用 n=2 手算得 16、n=1000 的样例对齐，才敢提交。

#### 卡点与关键一步

- MOD−1 不是素数，组合数只能加法递推，不能用「阶乘+逆元」
- 中位数是第 ⌈len/2⌉ 大，即升序第 ⌊len/2⌋+1 个；长度偶数时取偏大的一侧，抄错会系统性偏移
- 指数和最终答案是两个不同的模（MOD−1 与 MOD），快速幂里外不能混用

#### 复杂度

| 项 | 值 |
|---|---|
| 时间复杂度 | O(n^2 + n log MOD) |
| 空间复杂度 | O(n^2) |
