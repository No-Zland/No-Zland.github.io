### 知识点：

这题是不定方程非负整数解计数，模型是隔板法（插板法）。要求 a+b+c=d 的有序非负解个数：把 d 个 1 和 2 块隔板排成一行，共 d+2 个位置，从中选 2 个位置放隔板，隔板把 1 分成三段，段长依次就是 a、b、c；反过来任意一组解也唯一确定两个隔板的位置，所以答案是 C(d+2,2)=(d+1)(d+2)/2。手算前几项 d=0,1,2,3 得 1,3,6,10，正是三角数，与样例 d=2→6、d=0→1 对得上。答案要对 998244353 取模，除法在模意义下不成立，必须换成乘 2 的逆元 (p+1)/2=499122177。题面没有给出 d 的范围，稳妥做法是把 d 当字符串读入、边读边取模，这样 d 再大也不会溢出。

---

### 题目描述

> 给出 $d_{}$ 的值，问有多少个 $(a_{}, b, c)$ 序列使得 $a_{}+b+c=d$ 。 $(a_1,b_1,c_1)$ 序列与 $(a_2,b_2,c_2)$ 序列不同当且仅当 $a_1 \neq a_2$  或  $b_1 \neq b_2$  或  $c_1 \neq c_2$ 。

**输入描述**

> 输入一个整数d。

**输出描述**

> 输出一个数字代表序列的个数，因数据过大，请对答案模998244353。

#### 示例 1

**输入**

```text
2
```

**输出**

```text
6
```

#### 示例 2

**输入**

```text
0
```

**输出**

```text
1
```

### 最终代码：

```cpp
#include <iostream>
#include <string>
using namespace std;

const long long MOD = 998244353;

int main() {
    // 读成字符串：题面没给 d 的范围，按任意长度的非负整数处理
    string s;
    if (!(cin >> s)) return 0;
    long long dm = 0;
    for (char c : s) {
        if (c < '0' || c > '9') continue;
        dm = (dm * 10 + (c - '0')) % MOD;
    }
    const long long INV2 = (MOD + 1) / 2;  // 2 在 mod 998244353 下的逆元
    long long a = (dm + 1) % MOD;
    long long b = (dm + 2) % MOD;
    long long ans = a * b % MOD * INV2 % MOD;  // C(d+2, 2) = (d+1)(d+2)/2
    cout << ans << "\n";
    return 0;
}
```

*代码为参考实现（按题意重写并用样例验证），非本人原始提交。*

### 解题思路

第一反应是枚举 a 和 b，c=d-a-b 就唯一确定了，复杂度 O(d^2)，但 d 根本没说多大，这条路不敢走。于是改成找通项：这其实就是把 d 个相同的球放进 3 个不同的盒子里，允许空盒，是隔板法最基础的模型。我把 d=0,1,2,3 手算了一遍得到 1,3,6,10，确认通项是 (d+1)(d+2)/2。接着处理取模：如果直接写 (d+1)*(d+2)/2%MOD，一是乘法可能溢出，二是整数除法在模意义下根本不成立，所以改成先取模、再乘逆元 499122177。最后是输入规模，题目没给 d 的范围，我干脆用 string 读入、逐位推进 dm=(dm*10+digit)%MOD，把大数问题一次性消灭。整道题关键是先想清楚'为什么不枚举'，再确认计数模型和取模细节。

#### 卡点与关键一步

- 模意义下不能直接除以 2，要么乘逆元 499122177，要么先算出 (d+1)(d+2)/2 再取模（后者 d 大时会溢出）
- 题目问的是有序三元组，不能去重；且 d=0 时答案就是 1，循环从 1 开始数会漏
- 题面未给 d 的范围，用 int 甚至 long long 读入都可能溢出，按字符串边读边取模最稳

#### 复杂度

| 项 | 值 |
|---|---|
| 时间复杂度 | O(|d|)，|d| 为输入数字的位数 |
| 空间复杂度 | O(1) |
