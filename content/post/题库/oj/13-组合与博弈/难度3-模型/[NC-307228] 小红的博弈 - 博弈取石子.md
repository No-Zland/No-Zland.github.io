### 知识点：

结论：n≤2 输出 red，n≥3 输出 purple。理由是小紫每次可以拿任意个，只要轮到她时还有石子，她就能一次拿光，把空堆留给小红，使小红无子可取。因此小红唯一的胜机是先手第一回合直接拿完；她的单次上限是 2，只有 n=1、2 能做到。n≥3 时小红无论拿 1 个还是 2 个，都至少剩 1 个，后手小紫立刻清空。这个博弈双方行动集合不对称，不能套普通 Nim 的异或结论，只需分析先手能否一击结束。

---

### 题目描述

> 小红正在和小紫玩游戏。
>
> 	现在有  $n$  个石子，小红每次可以拿  $1$  或  $2$  个，小紫每次可以拿任意个，由小红先手，轮流行动。若轮到某人时无石子可取，则输掉游戏。
>
> 我们认为小红和小紫都会以最优策略进行游戏，请问谁会赢？

**输入描述**

> 第一行输入一个整数  $n \left(1 \leqq n \leqq10\right)$ 。

**输出描述**

> 如果小红会赢，请输出  $\texttt{red}$ ，否则输出  $\texttt{purple}$ 。

#### 示例 1

**输入**

```text
1
```

**输出**

```text
red
```

#### 示例 2

**输入**

```text
3
```

**输出**

```text
purple
```

### 最终代码：

```cpp
#include <cstdio>

// 小紫每次可以拿任意个，所以只要轮到她且还有石子，
// 她就能一次拿光、让小红面对空堆而输。
// 因此小红想赢，只能在自己第一个回合就把 n 个石子全部拿完，
// 也就是 n <= 2（一次拿 1 或 2 个）。n >= 3 时小紫必胜。
int main() {
    int n;
    if (scanf("%d", &n) != 1) return 0;
    printf("%s\n", n <= 2 ? "red" : "purple");
    return 0;
}
```

### 解题思路

第一反应是 n 只有 1 到 10，可以先手推再写。把 n=1、2、3 摆出来：n=1 小红拿 1 个直接赢；n=2 她一次拿 2 个也赢；n=3 时她拿 1 剩 2，或拿 2 剩 1，小紫都能一次拿光，于是小红下一轮面对空堆输。由此发现关键不是怎么分配，而是小紫的能力太强：只要她获得一次行动机会且场上还有石子，比赛必然在她手里结束。所以小红必须在自己第一次行动就清空，n≤2 是唯一可能。想通后代码只剩一个三目表达式，连循环都不用写。

#### 卡点与关键一步

- 不要套普通取石子/Nim 的结论，这里两人的可拿数量不同
- n=2 时小红能一次拿 2 个，属于 red，边界不要写成 n<2
- 小紫是后手，n≥3 时她必定能拿到第一次行动机会
