### 知识点：

这是“删除合法连续段后左右拼接”的公平组合游戏，标准模型是 Sprague-Grundy：一次删除会把局面拆成左右两个互不影响的子局面，所以 SG(区间)=mex{SG(左) xor SG(右)}。整理后结论很简洁：先手必败当且仅当数组里恰好只有一个 -1，且它左侧与右侧的 +1 个数相等（形如 "+"*m + "-" + "+"*m）。理由分四种情况：-1 的个数为偶数时整个数组乘积为 1，可一步删光；个数为 0 时全是 +1，长度 n 的纯 +1 段 SG 恰为 n；个数为 1 时这个 -1 把数组切成两个独立的 +1 堆，SG=L xor R，只有 L=R 才为 0；个数为奇数且 >=3 时，删掉中间连续的 k-1 个 -1 并吃掉两侧适量 +1，总能构造出上面的必败形态。

### 题目描述

> 对于给定的由  $n$  个整数构成、且整数仅为  $1$  或  $-1$  的数组  $\{a_1, a_2, \dots, a_n\}$ ，Alice 和 Bob 借助于此玩游戏。
>
> 双方轮流操作，每一次操作可以任选一个非空连续子数组，该子数组满足其中的所有元素的乘积恰好为  $1$ ，随后将其删除。删除后，左右剩余元素将直接拼接形成新的连续数组，下一步的操作基于新数组进行。
>
> 若轮到某位玩家操作时无法找到这样的子数组删除，则该玩家输掉游戏，对方获胜。现在，Alice 作为先手，且两人都采取最优策略，游戏最后的胜者会是谁？
>
> 非空连续子数组为从原数组中，连续的选择一段元素（可以全选，但不可以不选）得到的新数组。

**输入描述**

> 每个测试文件均包含多组测试数据。第一行输入一个整数  $T\left(1\leq T\leq 2 \times 10^5\right)$  代表数据组数，每组测试数据描述如下：
> 第一行输入一个正整数  $n \left(1\leq n\leq 2\times 10^5\right)$  代表数组中的元素个数。
> 第二行输入  $n$  个整数  $a_1, a_2, \dots, a_n \left(a_i\in \{ -1,1\}\right)$  代表数组中的元素。
>
> 除此之外，保证单个测试文件的  $n$  之和不超过  $2 \times 10^5$ 。

**输出描述**

> 对于每一组测试数据，新起一行。如果最后获胜的是 Alice，输出  $\rm Alice$ ，否则输出  $\rm Bob$ 。

#### 示例

**输入**

```text
5
5
1 1 1 1 1
5
-1 -1 -1 -1 -1
5
1 1 1 1 -1
5
1 1 -1 1 1
5
1 1 -1 -1 1
```

**输出**

```text
Alice
Alice
Alice
Bob
Alice
```

### 最终代码：

```cpp
// NC288078 数组数组
// 题意：数组元素为 ±1，每步删除一个乘积恰为 1 的非空连续子数组（即含偶数个 -1），
//       删完后左右拼接，不能操作者败，问先手 Alice 是否必胜。
// 结论（枚举 SG 验证过 n<=20 的全部数组，见复盘）：
//       先手必败 <=> 数组中恰好只有一个 -1，且它左右两侧的 +1 个数相等。
// 其余情况先手必胜：-1 个数为偶数可一次删光；-1 个数为 0 时全是 +1（SG=n）；
//       -1 个数为奇数且 >=3 时，删掉中间 k-1 个 -1 并微调两侧 +1 的个数就能走到必败态。
#include <cstdio>

int main() {
    int T;
    if (scanf("%d", &T) != 1) return 0;
    while (T--) {
        int n;
        scanf("%d", &n);
        int neg = 0, first = -1;
        for (int i = 0; i < n; ++i) {
            int x;
            scanf("%d", &x);
            if (x == -1) {
                ++neg;
                if (first < 0) first = i;
            }
        }
        bool bob = false;
        if (neg == 1) {
            int left = first;           // 左侧 +1 的个数
            int right = n - 1 - first;  // 右侧 +1 的个数
            if (left == right) bob = true;
        }
        printf(bob ? "Bob\n" : "Alice\n");
    }
    return 0;
}
```

### 解题思路

第一反应是上 SG，但状态是指数级的，只能先打表找规律。我写了个暴力：枚举长度 <= 20 的所有 ±1 串，用 sg(区间)=mex(sg(左) xor sg(右)) 递推。结果很反直觉——必败态只有 "-"、"+-+"、"++-++" 这类“恰好一个 -1 且两边 +1 数量相等”的串，5 个 -1、2 个 -1 这些情况清一色先手必胜。于是我回头补证明：偶数个 -1 一步删光；1 个 -1 时它像一堵墙，局面退化成两堆 +1 的异或；奇数个且 >=3 时，删掉中间 k-1 个 -1、再把多余的 +1 从两侧吃掉，就能走到“左 m 个 +1、一个 -1、右 m 个 +1”。代码最后只有 O(n) 扫描：统计 -1 的个数与第一个 -1 的位置。

#### 卡点与关键一步

- 删除后数组是拆成左右两个独立子游戏，求 SG 要用异或，不能对拼接后的串直接求 SG。
- n=1 且元素为 -1 是必败态（左右各 0 个 +1），容易漏判。
- 条件是“恰好一个 -1 且左右 +1 数量相等”，不是“-1 在正中间”（中间位置还要看 n 的奇偶）。

#### 复杂度

| 项 | 值 |
|---|---|
| 时间复杂度 | O(n) |
| 空间复杂度 | O(1) |
