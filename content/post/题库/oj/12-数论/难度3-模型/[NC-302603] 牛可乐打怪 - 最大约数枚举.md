### 知识点：

考的是把战斗过程抽象成「每击伤害 x 与出手次数 k」两个量，再归约成约数问题。结论：答案 d = a − x，其中 x 是「不超过 a 的最大 n 的约数」。推导：防御力 d 等价于把每击伤害定为 x = a − d，x 只能取 1..a（x = 0 时每击 0 伤害，永远打不死怪）。打死怪要 k = ⌈n/x⌉ 次出手；怪物先手，玩家第 k 次出手消灭怪物时，怪物正好已经打了 k 次，所以总受伤 D = k·x = ⌈n/x⌉·x，它正是 ≥ n 的最小 x 倍数。x = 1 时 D 就是 n，所以最小总伤害恒等于 n，第一目标不需要搜索；再看第二目标「攻击序列最短」即 k 最小，也就是 x 最大，并且要 D = n 就必须 x | n。综上 x 取 n 的不超过 a 的最大约数。

### 题目描述

> 牛可乐在玩一款回合制游戏，每次攻击造成的伤害为  $\max(攻击力-防御力,0)$  。当前他的攻击力固定为  $a$  ，防御力可以在战斗开始前调整为任一非负整数，战斗开始后保持不变。
>
>
>
> 	他遇到了一种特殊怪物，该怪物具有以下核心属性与机制：
>
>
>
> 			初始血量为  $n$  ，当怪物的血量小于等于  $0$  时，怪物被消灭
>
>
> 			战斗开始后，怪物拥有优先攻击权，即攻击序列为「怪物、玩家、怪物、玩家……」
>
>
> 			怪物会完全复制玩家的攻击力与防御力
>
>
>
>
>
>
> 	牛可乐想知道：如何调整自己的防御力，可以在自身受到总伤害最小的前提下，用最短攻击序列消灭怪物。

**输入描述**

> 输入两个正整数  $a,n(1 \le a,n \le 10^9)$  ，分别代表牛可乐的攻击力、怪物的初始血量。

**输出描述**

> 输出一个整数，代表牛可乐的防御力。

#### 示例 1

**输入**

```text
1 1
```

**输出**

```text
0
```

#### 示例 2

**输入**

```text
2 4
```

**输出**

```text
0
```

### 最终代码：

```cpp
// NC302603 牛可乐打怪
// 题目：攻击力 a，防御力 d 可任意取非负整数；怪物完全复制玩家属性、血量 n、先手。
//       求使"自身受到总伤害最小"且在此前提下"攻击序列最短"的防御力 d。
//
// 记 x = a - d 为每一击的真实伤害，d>=0 => 1 <= x <= a（x=0 永远打不死）。
// 打死怪物需要 k = ceil(n/x) 次玩家出手；怪物先手，玩家第 k 次出手前怪物已出手 k 次
// （回合 1,3,5,...），所以总受伤 D = k*x = ceil(n/x)*x，它是 >= n 的、x 的最小倍数。
// 于是 D 的最小值恒为 n（x=1 必是 n 的约数），代价是出手最多；要在总伤害同为 n 的
// 方案里让攻击序列最短，就要 k 最小，即 x 取"不超过 a 的最大 n 的约数"。
// 答案 d = a - x。
#include <cstdio>
#include <vector>
#include <algorithm>

using namespace std;
typedef long long ll;

int main() {
    ll a, n;
    if (scanf("%lld %lld", &a, &n) != 2) return 0;
    // 枚举 n 的全部约数，取 <= a 的最大者
    vector<ll> divs;
    for (ll i = 1; i * i <= n; ++i) {
        if (n % i == 0) {
            divs.push_back(i);
            if (i != n / i) divs.push_back(n / i);
        }
    }
    ll x = 1;
    for (ll v : divs)
        if (v <= a) x = max(x, v);
    printf("%lld\n", a - x);
    return 0;
}
```

### 解题思路

第一反应是「总伤害 = 出手次数 × 每击伤害」，于是把未知量从防御力换成每击伤害 x = a − d，取值范围 1..a。接着数怪物出手次数：怪物先手，回合是怪、人、怪、人……玩家第 k 次出手打死怪时，怪物恰好出手 k 次（第 k+1 次没轮到），所以总受伤就是 ⌈n/x⌉·x。这个式子的含义一眼能看穿——它是 ≥ n 的最小 x 倍数，因此只要 x | n，伤害就能压到理论下界 n；而 x = 1 一定是 n 的约数，说明最小伤害必然可取到 n，第一目标根本不用搜索。第二目标「攻击序列最短」等价于出手次数最少，也就是 x 尽量大，配合 x | n，就是「n 的不超过 a 的最大约数」。实现上试除到 √n 收集全部约数，取 ≤ a 的最大值，答案是 a − x。为了保险，我把 a ≤ 20、n ≤ 30 的全组合用暴力枚举 d、按 (总伤害, 出手次数) 双关键字取最优对拍过，结论一致。

#### 卡点与关键一步

- 防御力不能取到让每击伤害为 0（d = a），那会永远打不死怪，x 必须 ≥ 1
- 两个目标有优先级：先最小化总伤害，再最小化攻击次数，不能直接贪心让 x 最大
- 输出的是防御力 a − x，不是每击伤害 x，也不是出手次数

| 项 | 值 |
|---|---|
| 时间复杂度 | O(√n) |
| 空间复杂度 | O(√n) |
