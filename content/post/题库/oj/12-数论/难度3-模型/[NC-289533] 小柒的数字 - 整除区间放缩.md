### 知识点：

记 q=⌊z/y⌋，则 z 落在 [qy, qy+y-1]。要让 ⌊z/x⌋ 也等于 q，需要 qx≤z≤qx+x-1。由题设 2x≤y 得 z≥qy≥2qx，而 qx+x-1<2qx 对 q≥1、x≥1 恒成立，故 q≥1 时无解。于是只剩 q=0：此时要求 z<y 且 ⌊z/x⌋=0 即 z<x，z 取 1..min(n,x-1)，答案是 min(n,x-1)。核心是用 2x≤y 这个条件把「商相同」直接放缩成不可能，属于整除区间与不等式放缩结合的结论题，每组 O(1)。

---

### 题目描述

> 小柒现在有两个数字  $x,y$  满足  $2 \times x\leq y$ 。小柒想知道，在  $[1,n]$  的范围内，有多少个整数  $z$  满足  $\big\lfloor \tfrac{z}{x} \big\rfloor = \big\lfloor \tfrac{z}{y} \big\rfloor$ 。
>
> 在这里， $\lfloor x \rfloor$  代表对  $x$  进行下取整操作。

**输入描述**

> 每个测试文件均包含多组测试数据。第一行输入一个整数  $T\left(1\leq T\leq 10^5\right)$  代表数据组数，每组测试数据描述如下：
> 在一行上输入三个整数  $x,y,n\left(1\leq 2 \times x\leq y\leq 10^9;\ 1\leq n\leq 10^9\right)$ 。

**输出描述**

> 对于每一组测试数据，新起一行输出一个整数，代表满足条件的数字  $z$  的个数。

#### 示例

**输入**

```text
3
2 4 3
1 3 1000
1000 10000 100
```

**输出**

```text
1
0
100
```

---

### 最终代码：

```cpp
#include <cstdio>
#include <algorithm>
using namespace std;

int main() {
    int T;
    if (scanf("%d", &T) != 1) return 0;
    while (T--) {
        long long x, y, n;
        scanf("%lld %lld %lld", &x, &y, &n);
        // 由 2x <= y 可证只有 floor(z/x)=floor(z/y)=0 时才可能相等
        long long ans = min(n, x - 1);
        printf("%lld\n", ans);
    }
    return 0;
}
```

### 解题思路

第一反应是整除分块：把 z 按 ⌊z/y⌋ 的商分段，每段里再去数 ⌊z/x⌋ 相等的部分。动手前先看条件 2x≤y，立刻发现它很强——z 一旦到达 y，⌊z/x⌋ 至少是 2q，而这一段 ⌊z/y⌋ 只有 q，两者永远对不上。于是只需要考虑 q=0 的那一段，即 z<y，此时要求 ⌊z/x⌋=0，即 z<x。答案就是 [1,n] 与 [1,x-1] 的交集长度 min(n,x-1)。三个样例分别给出 1、0、100，正好对应「n 截断」「x=1」「x-1 截断」三种形态。我又用 x≤14、y 到 3x+11、n 取若干值的近千组数据暴力枚举验证，全部一致。

#### 卡点与关键一步

- 只数到 x-1 而不是 x：z=x 时 ⌊z/x⌋=1≠0，x=1 时答案恒为 0。
- 忘记与 n 取 min，n<x 时会把区间外的数算进来。
- 商的区间是 [qy, qy+y-1]，别写成 [qy, qy+y] 或 z≤qy+y 这类边界错位。

#### 复杂度

| 项 | 值 |
|---|---|
| 时间复杂度 | O(T)，每组 O(1) |
| 空间复杂度 | O(1) |
