### 题目描述

> 本题与《A. 小红的数组查询（一）》共享部分题目背景，但是所求内容不同，我们建议您重新阅读题面。
>
> 小红拿到了一个长度为  $10^{100}$  的数组，其构成如下：
>
>  $\hspace{23pt}\bullet\,$ 数组的第一个元素  $a_1=1$ ；
>
>  $\hspace{23pt}\bullet\,$ 对于  $2 \leqq i \leqq 10^{100}$ ， $a_i=(a_{i-1}+d) \bmod p$ 。
>
> 现在小红想知道， $l$  到  $r$  之间有多少种不同元素。共有  $q$  次询问。

**输入描述**

> 第一行输入两个整数  $d,p \left(1\leqq d,p \leqq 10^9\right)$ ，表示数组公差、模数。
> 第二行输入一个整数  $q \left(1\leqq q \leqq 10^5\right)$ ，表示询问次数。
> 此后  $q$  行，第  $i$  行输入两个整数  $l_i,r_i \left(1\leqq l_i \leqq r_i \leqq 10^{18}\right)$ ，表示第  $i$  次询问的区间。

**输出描述**

> 对于每一次询问，新起一行，输出一个整数，代表区间内元素的种类数。

#### 示例

**输入**

```text
3 4
2
1 2
1 100000000000
```

**输出**

```text
2
4
```

---

### 最终代码：

```cpp
#include <bits/stdc++.h>
using namespace std;
using ull = unsigned long long;

int main(){
    ull d, p;
    cin >> d >> p;
    
    ull n = lcm(d, p) / d;
    
    int q;
    cin >> q;
    while(q --){
        ull l, r;
        cin >> l >> r;
        if(p == 1 && l == 1 && r > l){
            cout << 2 << '\n';
        }
        else cout << min(r - l + 1, n) << '\n';
    }
}
```

---

### 解题思路

由题可知，这是一个等差数列，数值很大要取模。

等差数列是一元函数，有单调性，而取模，只是把下面给截掉，所以可以得到新的函数具有周期性，因此需要找到这个周期性的关键因素。

凭借感觉，估计是个定理。只有他们等长的时候，即最小公倍数，得到开启新一轮循环的最大值。最大值除去它本身，可以得到需要进行的次数（周期长度）。

又因为周期性，所以可以得到 l - r + 1 < n 的时候，没有完成一个周期，即出现的数字之和也不超过 n，由此可以得出答案。

需要注意的是，数列是第二个项才开始取模，（这也是我没有AC的主要原因，我其实是考虑到了p == 1 && l == 1 的情景，但是那两个样例点少考虑的l == r的情况，这时候 n == 1，因此总的条件为p == 1 && l == 1 && r > l），
