### 知识点：

时钟同余模型：一天 1440 分钟，把时刻化成“当天第几分钟”后做模运算。结论：t=(h·60+m+k) mod 1440，答案就是 t/60 与 t%60，用 %02d 补零成 hh:mm。推导：时和分是两种进制的位置，分别进位就得处理 k 跨多少小时、跨多少天；统一成分钟后只剩一个加法加一次取模，跨天由 mod 1440 自动完成。数据范围 k≤1e9，虽然 h·60+m+k 在 int 上勉强不溢出，但这种量级直接开 long long 更稳妥。本题按“每组输入”描述，多组数据读到 EOF。

---

### 题目描述

> 小乐乐比较懒惰，他现在想睡觉，然后再去学习。他知道现在的时刻，以及自己要睡的时长，想设定一个闹钟叫他起床学习，但是他太笨了，不知道应该把闹钟设定在哪个时刻，请你帮助他。(只考虑时和分，不考虑日期)

**输入描述**

> 输入现在的时刻以及要睡的时长k（单位：minute），中间用空格分开。
>
> 输入格式：hour:minute k(如hour或minute的值为1，输入为1，而不是01)
>
> (0 ≤ hour ≤ 23，0 ≤ minute ≤ 59，1 ≤ k ≤ 109)

**输出描述**

> 对于每组输入，输出闹钟应该设定的时刻，输出格式为标准时刻表示法（即时和分都是由两位表示，位数不够用前导0补齐）。

#### 示例 1

**输入**

```text
0:0 100
```

**输出**

```text
01:40
```

#### 示例 2

**输入**

```text
1:0 200
```

**输出**

```text
04:20
```

### 最终代码：

```cpp
#include <cstdio>

// 定闹钟：总分钟数对 1440 取模，再拆回时和分，均补足两位。
int main() {
    long long h, m, k;
    while (scanf("%lld:%lld %lld", &h, &m, &k) == 3) {
        long long t = ((h * 60 + m + k) % 1440 + 1440) % 1440;
        printf("%02lld:%02lld\n", t / 60, t % 60);
    }
    return 0;
}
```

### 解题思路

第一反应是最朴素的进位：k 加到分钟上，满 60 进小时，小时再对 24 取模。写到一半发现 k 可以到 1e9，意味着要循环上百万次进位，虽然也能过但很难看。于是换成“分钟制”：把当前时刻压成 h*60+m，加上 k，整体对 1440 取模，再除 60、模 60 还原成时和分，跨天、跨多天都是一个公式解决。样例验证：0:0 加 100 分钟是 1:40，1:0 加 200 分钟是 4:20，都能对上；又用 23:59 加 1 分钟测了跨天，得到 00:00。题面写“对于每组输入”，所以加了 while(scanf(...)==3) 循环，输出用 %02lld 补零。

#### 卡点与关键一步

- k 是 1e9 量级，累加变量用 long long
- 输出必须补前导 0：01:40 不能写成 1:40
- 别用逐步进位模拟跨天，直接对 1440 取模

| 项 | 值 |
|---|---|
| 时间复杂度 | O(1) |
| 空间复杂度 | O(1) |
