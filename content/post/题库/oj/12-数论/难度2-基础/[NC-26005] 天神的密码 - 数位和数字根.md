### 知识点：

反复把一个数换成它各位数字之和，直到只剩一位，得到的值叫数字根。结论：对任意正整数 x，dr(x)=(x-1) mod 9 + 1，等价地 x%9 为 0 时答案是 9，否则就是 x%9。原因很简单：10 ≡ 1 (mod 9)，所以 x 与它的数位和模 9 同余；每做一次数位和，模 9 的余数不变，迭代到一位数之后，1..9 中与 x 同余的数只有一个（余数 0 对应 9），所以终值被唯一确定。本题 N ≤ 1e9、K ≤ 2，所以 N^K 最大 1e18，long long 装得下，直接算出 X 再反复求数位和即可，不需要高精度，也不必依赖公式。多组数据每组独立计算，把 X 限制在装得下的范围内就不会出问题。

### 题目描述

> 2018年，icebound打开了神殿。而在2019年，icebound正在试图破解天神的密码，以期获得天神的力量。
>
>  icebound发现，想要得到神的密码，必须先要完成一个祭祀仪式。在这个祭祀仪式上，我们首先会追随神的指引，得到两个正整数 N和 K。随后，我们令  $X=N^K$ ，得到天神喜欢的数字X。
>
>  利用 X，我们进行以下方式得到天神最后的密码：
>
>  步骤 1 将 X每个数位上的数字相加得到 Y。
>
>  步骤 2 令 X=Y
>
>  步骤 3 反复执行 步骤 1，直到 X只有一个数位时停止，即  $1 \leq X \leq 9$ 。此时的 X 即为天神的密码。
>
>  比如：当 N=11,K=2 时，首先我们得到  $X=N^{K}=11^{2}=121$ 。然后我们把 X 的各个数位上的数相加，即 Y=1+2+1=4。此时 X=Y=4，X 仅有一个数位了，所以我们停止操作，得到天神的密码为4。
>
>  icebound许诺，如果他获得了天神的力量，一定保你荣华富贵，全家幸福，还会另外送你一块金牌。所以，请你帮助他计算天神的密码。

**输入描述**

> 首先第一行一个整数 T ，代表数据组数。
> 随后 T 行，每行两个数 N,K ，用空格隔开。
>  $1 \leq T \leq 20$ ， $1 \leq N \leq 10^9$ ， $1 \leq K \leq 2$

**输出描述**

> 一行一个整数 X，表示天神的密码。

#### 示例

**输入**

```text
2
11 2
100 1
```

**输出**

```text
4
1
```

### 最终代码：

```cpp
#include <iostream>
using namespace std;

int main() {
    int T;
    if (!(cin >> T)) return 0;
    while (T--) {
        long long N, K;
        cin >> N >> K;
        // K 只有 1 或 2，N <= 1e9，N^2 <= 1e18 用 long long 装得下
        long long x = 1;
        for (int i = 0; i < K; ++i) x *= N;
        // 反复求数位和，直到只剩一位
        while (x >= 10) {
            long long y = 0;
            while (x > 0) { y += x % 10; x /= 10; }
            x = y;
        }
        cout << x << "\n";
    }
    return 0;
}
```

### 解题思路

看到 N^K 我第一反应是要不要写高精度，读完数据范围发现 K 只有 1 和 2、N ≤ 1e9，N^2 最多 1e18，long long 就够了，于是决定直接算幂。接下来是怎么求数位和：题目要求反复执行直到只剩一位，最直白的写法就是 while(x>=10) 里求一遍各位和，一位数时循环自然终止。我也想过用数字根公式 (x-1)%9+1 一步到位，但它依赖 x>0，余数 0 时还容易写成输出 0，既然直接迭代最多十几轮，那就选更不容易出错的模拟。实现时把求和放进内层 while(x>0)，用临时变量 y 存和，别在原地把 x 改掉又拿去做循环条件。样例 11^2=121，一次数位和就得到 4；100^1=100 也立刻收敛到 1。

#### 卡点与关键一步

- 别被'幂'吓到去写高精度：K ≤ 2、N ≤ 1e9，N^K 最大 1e18，long long 足够
- 如果改用数字根公式，余数为 0 时必须输出 9，写成 x%9 会输出 0
- 多组数据要每组重新算幂，不能把上一组的 X 接着累乘下去

#### 复杂度

| 项 | 值 |
|---|---|
| 时间复杂度 | O(T·log10(N^K))，数位和最多迭代十来次 |
| 空间复杂度 | O(1) |
