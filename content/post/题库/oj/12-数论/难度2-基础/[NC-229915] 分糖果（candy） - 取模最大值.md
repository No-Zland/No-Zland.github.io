### 知识点：

结论：奖励就是 K mod n。若 ⌊L/n⌋ = ⌊R/n⌋（区间落在同一个长度为 n 的块里），答案是 R mod n；否则答案是 n-1。推导：把数轴按 n 切成 [qn, qn+n-1] 的块，块内 K mod n = K-qn，关于 K 严格递增，所以只在单块内时取最大的 K=R 最优。若跨块，设 q=⌊L/n⌋，由 R ≥ (q+1)n 可知 (q+1)n-1 这个数落在 [L,R] 内（它不小于 L，也不大于 R），此时余数取到 n-1；而余数上界本身就是 n-1，所以这是最优值。模型是「分段讨论余数极值」，按模数分块讨论是这类题的标准切法，比枚举或二分都短。

### 题目描述

> 红太阳幼儿园有 $n$ 个小朋友，你是其中之一。保证 $n \geq 2$ 。
>  有一天你在幼儿园的后花园里发现无穷多颗糖果，你打算拿一些糖果回去分给幼儿园的小朋友们。
>  由于你只是个平平无奇的幼儿园小朋友，所以你的体力有限，至多只能拿  $R$  块糖回去。
>  但是拿的太少不够分的，所以你至少要拿L 块糖回去。保证 $n \leq L \leq R$ 。
>  也就是说，如果你拿了 $K$  块糖，那么你需要保证 $L \leq K \leq R$ 。
>  如果你拿了 $K$  块糖，你将把这k 块糖放到篮子里，并要求大家按照如下方案分糖果：只要篮子里有不少于  $n$ 块糖果，幼儿园的所有  $n$  个小朋友（包括你自己）都从篮子中拿走恰. 好. 一块糖，直到篮子里的糖数量少于  $n$  块。此时篮子里剩余的糖果均归你所有——这些糖果是作为你搬糖果的奖励。
>  作为幼儿园高质量小朋友，你希望让作为你搬糖果的奖励的糖果数量（而不是你最后获得的总糖果数量.！）尽可能多；因此你需要写一个程序，依次输入  $n,L,R$ ，并输出出你最多能获得多少作为你搬糖果的奖励的糖果数量。

**输入描述**

> 输入一行，包含三个正整数 $n,L,R$ ，分别表示小朋友的个数、糖果数量的下界和上界。

**输出描述**

> 输出一行一个整数，表示你最多能获得的作为你搬糖果的奖励的糖果数量。

#### 示例 1

**输入**

```text
7 16 23
```

**输出**

```text
6
```

#### 示例 2

**输入**

```text
10 14 18
```

**输出**

```text
8
```

### 最终代码：

```cpp
// NC229915 分糖果（candy）
// 拿 K 颗，奖励 = K mod n，求 K 属于 [L,R] 时 K mod n 的最大值。
// 若 L、R 落在同一个 n 的倍数区间内，余数随 K 单调增，取 R%n；
// 否则区间里必然跨过一个 n 的倍数，可以取到 n-1。
#include <cstdio>

int main() {
    long long n, L, R;
    if (scanf("%lld %lld %lld", &n, &L, &R) != 3) return 0;
    if (L / n != R / n)
        printf("%lld\n", n - 1);
    else
        printf("%lld\n", R % n);
    return 0;
}
```

### 解题思路

看到「拿 K 块糖、奖励 K mod n、K 在 [L,R]」，我先想的是要让余数最大就该尽量贴着 n 的倍数，但 L、R 可能很大，不可能枚举。于是分两类讨论：如果 L 和 R 落在同一块里（L/n == R/n），余数随 K 单调增，直接取 R%n；如果跨了块，区间里一定包含某个 n 的倍数减一，余数能顶到 n-1。判跨块我一开始想写 L%n > R%n，想了一下发现当 L 恰好是 n 的倍数时会漏判，改成比较 L/n 与 R/n 就干净了。样例验证：7 与 16..23 中 16/7=2、23/7=3 跨块，输出 6 ✓；10 与 14..18 都在第 1 块里，18%10=8 ✓。

#### 卡点与关键一步

- 跨块时答案是 n-1，不是 R%n 也不是 L%n
- 判跨块用 L/n != R/n 最稳；用 L%n > R%n 这类写法在 L 是 n 的倍数时会漏判
- 题面没有给 n、L、R 的上界，用 long long 读入更保险
