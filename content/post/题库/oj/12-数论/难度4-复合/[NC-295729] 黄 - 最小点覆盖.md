### 知识点：

结论：把 gcd(a_i,a_{i+1})>1 的相邻对看成一条边，答案就是这些「坏边」在链上的最小点覆盖数，可用从左到右的贪心求出。关键观察两点：一是改一个数最多能同时消掉左右两条坏边，等价于选中一个顶点覆盖它的所有关联边；二是修改不会制造新坏边——把该位置改成任意一个大于 10^18 的质数 p，因为所有 a_i ≤ 10^18 < p，p 不可能整除任何 a_i，于是两部分 gcd 必为 1。合起来，问题从「改数」严格退化成「链上选最少的点覆盖所有坏边」。链是路径图，最小点覆盖的经典贪心是：从左往右扫边，若这条边坏且左端点还没被选，就选右端点（选右端点还能顺带覆盖下一条边），得到的点数即最优。

### 题目描述

> 在神秘的魔法学院中，学员小黄偶然间获得了一串蕴含魔力的整数序列。这些整数各自拥有独特的魔力属性，然而，若相邻两个整数的魔力属性不能相互兼容（即不互质），就会引发魔力冲突，可能导致严重的魔法事故。 
>
> 为了避免魔力冲突，小黄可以施展魔法，选择序列中的一个整数，将其转化为任意一个大于  $1$  的整数，以此改变它的魔力属性。现在，小黄迫切想知道，最少需要施展多少次这样的魔法，才能让这串整数序列中的相邻元素魔力属性都相互兼容（即相邻元素都互质）。 
>
> 【名词解释】
>
> 互质：如果两个整数  $a$  和  $b$  的最大公约数为  $1$  那么就称  $a$  和  $b$  互质。最大公约数指的是能够同时整除这几个整数的最大正整数。例如  $8,10$  的最大公因数是  $2$ ，不是  $1$ ，因此不是互质。 $7, 13$  的最大公因数是  $1$ ，因此这是互质。

**输入描述**

> 每个测试文件均包含多组测试数据。第一行输入一个整数  $T\left(1\leq T\leq 10^5\right)$  代表数据组数，每组测试数据描述如下： 
> 第一行输入一个整数  $n\left(2 \leq n \leq 10^5\right)$ ，表示序列的长度。 
> 第二行输入  $n$  个整数  $a_1,a_2,\dots,a_n\left(1 \leq a_i \leq 10^{18}\right)$ ，表示给定的整数序列。 
>
> 除此之外，保证单个测试文件的  $n$  之和不超过  $2\times10^5$ 。

**输出描述**

> 对于每个查询，新起一行输出一个整数，表示使得序列中相邻元素互质所需的最小操作次数。如果无论如何修改都无法满足条件，输出  $-1$ 。

#### 示例

**输入**

```text
4
5
2 4 6 9 12
2
2 2
4
2 3 5 7
5
1000000000000000000 2 7 3 12
```

**输出**

```text
2
1
0
2
```

### 最终代码：

```cpp
// NC295729 黄
// 相邻不互质的位置对构成路径上的"坏边"。改一个数可以同时消掉它左右两条坏边，
// 而且改成大于 1e18 的质数后不与任何相邻数冲突。
// 于是答案 = 坏边组成的路径图的最小点覆盖，按链从左到右贪心即可。
#include <cstdio>
#include <vector>
#include <numeric>

typedef unsigned long long ull;

static const int BUFSZ = 1 << 24;
static char ibuf[BUFSZ];
static int ilen = 0, ipos = 0;

static inline int gc() {
    if (ipos == ilen) {
        ilen = (int)fread(ibuf, 1, BUFSZ, stdin);
        ipos = 0;
        if (ilen <= 0) return -1;
    }
    return ibuf[ipos++];
}

static inline ull readU() {
    int c = gc();
    while (c != -1 && (c < '0' || c > '9')) c = gc();
    ull x = 0;
    while (c >= '0' && c <= '9') {
        x = x * 10 + (ull)(c - '0');
        c = gc();
    }
    return x;
}

int main() {
    int T = (int)readU();
    std::vector<ull> a;
    while (T--) {
        int n = (int)readU();
        a.resize(n);
        for (int i = 0; i < n; ++i) a[i] = readU();
        long long ans = 0;
        bool chosen = false;   // 上一个位置是否已被"改过"
        for (int i = 0; i + 1 < n; ++i) {
            if (!chosen && std::gcd(a[i], a[i + 1]) > 1) {
                ++ans;         // 贪心：改右端点 i+1，顺带覆盖下一条边
                chosen = true;
            } else {
                chosen = false;
            }
        }
        printf("%lld\n", ans);
    }
    return 0;
}
```

*代码为参考实现（按题意重写并用样例验证），非本人原始提交。*

### 解题思路

我第一反应是 DP：f[i][0/1] 表示考虑前 i 个位置、第 i 个位置改没改。写着写着卡在转移条件上——改过的数要和左右都互质，可「改成什么」是自由变量，状态里表达不了。于是换角度想：既然可以随便改，能不能一次改就保证两边都干净？想到用远大于 10^18 的质数，它比所有 a_i 都大，gcd 必然是 1，卡点就通了，而且两次修改之间不再互相影响。于是问题变成纯覆盖：只关心每条坏边是否至少有一个端点是「改过的」。链上的最小点覆盖我按老套路贪心——从左往右扫，边坏且左端点没被选就选右端点。样例 4 里 10^18 与 2 冲突、3 与 12 冲突，两条坏边不相邻，答案 2，和贪心结果一致。

#### 卡点与关键一步

- a_i 到 10^18，必须用 unsigned long long / long long 读入，int 直接爆
- 只有「左端点没被选中」的坏边才 +1，每条坏边都加会算多
- 题面提到无法满足时输出 -1，但总能把某个数改成大于 10^18 的质数，这个分支实际不可达，别真去判 -1

|---|---|
| 时间复杂度 | O(Σn · log A) |
| 空间复杂度 | O(n) |
