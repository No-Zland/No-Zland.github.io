### 知识点：

按 x 分三种情况直接输出 10^1+y、10^9+y、10^18+y，本质是纯分支输出，真正的考点是数据范围与溢出判断：y≤10^18，x=3 时答案最大到 2×10^18，超过 32 位 int（约 2.1×10^9）但仍在 signed 64 位的 9.22×10^18 之内，所以 long long / unsigned long long 足够，不需要高精度。另外 10^18 必须写成整型字面量，写成 1e18 这种 double 字面量后加整数会有精度风险。

---

### 题目描述

> 对于给定的  $x$  和  $y$ ：
>
>  $\hspace{23pt}\bullet\,$  若  $x=1$  ：直接输出  $10^1+y$  ；
>
>  $\hspace{23pt}\bullet\,$  若  $x=2$  ：直接输出  $10^{9}+y$  ；
>
>  $\hspace{23pt}\bullet\,$  若  $x=3$  ：直接输出  $10^{18}+y$  。

**输入描述**

> 在一行上输入两个整数  $x,y \left(1 \leq x \leq 3;\ 0 \leq y \leq 10^{18}\right)$  。

**输出描述**

> 输出一个整数，代表答案。

#### 示例 1

**输入**

```text
1 3
```

**输出**

```text
13
```

#### 示例 2

**输入**

```text
2 9
```

**输出**

```text
1000000009
```

#### 示例 3

**输入**

```text
3 1000000000000000000
```

**输出**

```text
2000000000000000000
```

---

### 最终代码：

```cpp
#include <cstdio>
using namespace std;

int main() {
    long long x, y;
    if (scanf("%lld %lld", &x, &y) != 2) return 0;
    unsigned long long base;
    if (x == 1) base = 10ULL;                 // 10^1
    else if (x == 2) base = 1000000000ULL;    // 10^9
    else base = 1000000000000000000ULL;       // 10^18
    printf("%llu\n", base + (unsigned long long)y);
    return 0;
}
```

### 解题思路

看到题面就是三个分支，我第一反应是 printf 三个常数加 y。动笔时停顿了两处：一是 10^18 怎么写，我用了整型字面量 1000000000000000000ULL，而不是 1e18，避免 double 的精度隐患；二是要不要上高精度，估算最大值是 1e18+1e18=2e18，signed 64 位能装下，就没必要开 __int128 或大整数。读入用 %lld 读进 long long，输出用无符号格式化。三个样例恰好覆盖 x=1、x=2、x=3，其中第三个样例 y 取到 10^18，正好验证了上界处不溢出，输出 2000000000000000000。

#### 卡点与关键一步

- 1e18 作为 double 字面量不精确，应写成整型 1000000000000000000。
- 答案可达 2×10^18，用 int 会直接溢出。
- y 必须用 %lld 读入，%d 会截断成 32 位。
