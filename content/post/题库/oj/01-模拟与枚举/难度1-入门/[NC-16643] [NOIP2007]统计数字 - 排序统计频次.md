### 知识点：

本质是「按值分组计数」：把 n 个数排序后，相等的数必然相邻，于是顺序扫一遍，遇到值变化就结算上一组的 (值, 次数)，输出顺序天然满足“从小到大”。时间 O(n log n)，空间 O(n)。等价做法是用哈希表统计再对键排序，或者直接用有序的 map，复杂度同为 O(n log n)；题目额外保证「不相同的数不超过 10000 个」，说明重复非常多，排序后线性扫描能把大批重复一次吃掉，常数比每个数都插一次 map 小。数值不超过 1.5×10⁹，int 装得下，但用 long long 更省心。

---

### 题目描述

> 某次科研调查时得到了n个自然数，每个数均不超过1500000000（1.5*109）。已知不相同的数不超过10000个，现在需要统计这些自然数各自出现的次数，并按照自然数从小到大的顺序输出统计结果。

**输入描述**

> 第1行是整数n，表示自然数的个数。
> 第2~n+1行每行一个自然数。

**输出描述**

> 输出m行（m为n个自然数中不相同数的个数），按照自然数从小到大的顺序输出。每行输出两个整数，分别是自然数和该数出现的次数，其间用一个空格隔开。

#### 示例

**输入**

```text
8
2
4
2
4
5
100
2
100
```

**输出**

```text
2 3
4 2
5 1
100 2
```

### 最终代码：

```cpp
#include <cstdio>
#include <algorithm>
#include <vector>

// 排序后相同的数聚在一起，扫一遍输出「数值 次数」。
int main() {
    int n;
    if (scanf("%d", &n) != 1) return 0;
    std::vector<long long> a(n);
    for (int i = 0; i < n; ++i) scanf("%lld", &a[i]);
    std::sort(a.begin(), a.end());
    for (int i = 0; i < n;) {
        int j = i;
        while (j < n && a[j] == a[i]) ++j;
        printf("%lld %d\n", a[i], j - i);
        i = j;
    }
    return 0;
}
```

### 解题思路

读完第一句就定了方向：要按数值从小到大输出每个数的出现次数，那先排序，让相同的数挤到一起，再一次扫描分组。中途也想过 map<long long,int> 统计，代码更短，但每个数都要一次 log 级插入，常数更大；而题面说不同的数不超过一万个，重复很多，正好是“排序 + 线性扫描”最占便宜的场景。实现用双指针：i 指向组首，j 一直走到值变化，输出 a[i] 和 j−i，然后让 i=j。边界上把循环条件统一写成 j<n，这样所有数相同、只有 1 个数的情况都不会越界。输出用 printf，避免大量行时的流刷新开销；读入同理用 scanf。样例里 2 出现 3 次、4 两次、5 一次、100 两次，跑出来完全一致。

#### 卡点与关键一步

- 输出格式是「数值 次数」，中间恰好一个空格、每组一行，顺序必须从小到大
- 双指针分组时 while 条件要写 j<n，防止越界
- 读入量大时用 scanf 或关掉同步的 cin，否则容易慢在 IO 上

#### 复杂度

| 项 | 值 |
|---|---|
| 时间复杂度 | O(n log n) |
| 空间复杂度 | O(n) |
