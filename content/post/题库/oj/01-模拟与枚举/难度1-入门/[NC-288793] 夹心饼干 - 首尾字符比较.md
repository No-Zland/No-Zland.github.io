### 知识点：

这题考字符串首尾字符的直接比较，本质是回文判定的特例：长度为 3 时只需看首尾，中间字符完全不参与判断。结论是 s[0] == s[2] 时输出 YES，否则 NO。关键在于题面强调“大小写字母混合构成”，比较做的是字符本身而非折叠大小写后的结果，所以 "Ioi" 的首字母 'I' 与末字母 'i' 并不相等，答案是 NO，样例 2 正是用来卡这一点的。长度由题面保证为 3，因此下标 0 与 2 一定存在，无需判越界；读入用 cin >> s 或 scanf("%s") 即可自动跳过空白。

---

### 题目描述

> 您将得到一个由三个字母组成的字符串  $s$ ，我们定义这个字符串是“夹心饼干”，当且仅当  $s$  的第一个字母与最后一个字母完全相同。
>
> 请你判定  $s$  是否是“夹心饼干”。

**输入描述**

> 在一行上输入一个长度为  $3$ 、由大小写字母混合构成的字符串  $s$ 。

**输出描述**

> 如果字符串  $s$  是“夹心饼干”，直接输出  $\rm YES$ ，否则输出  $\rm NO$ 。

#### 示例 1

**输入**

```text
ioi
```

**输出**

```text
YES
```

#### 示例 2

**输入**

```text
Ioi
```

**输出**

```text
NO
```

### 最终代码：

```cpp
// NC288793 夹心饼干
// 题意：给一个长度为 3 的字符串，判定首字母与末字母是否完全相同（区分大小写）。
// 做法：直接比较 s[0] 与 s[2]，相同输出 YES，否则输出 NO。
#include <iostream>
#include <string>

int main() {
    std::string s;
    if (!(std::cin >> s)) return 0;
    if (s.front() == s.back()) {
        std::cout << "YES" << "\n";
    } else {
        std::cout << "NO" << "\n";
    }
    return 0;
}
```

### 解题思路

第一反应是“回文串判定”，但读题后发现题目只要求首字母与末字母相同，中间那个字母是陪衬，于是问题被压缩成一次字符比较。写代码时我提醒自己两点：一是别顺手写成 s[0]==s[1]，二是别加 tolower，因为样例 "Ioi" 明确要求 NO，说明判定必须区分大小写。剩下的就是读入、比较、按样例的大写形式输出 YES / NO。这题没有算法难度，练的是“把自然语言条件精确翻译成一行判定”，以及严格对齐样例输出的大小写，因为它不是 Special Judge，写错大小写会直接 WA。

#### 卡点与关键一步

- 大小写敏感："Ioi" 的首字母 'I' 与末字母 'i' 不同，答案是 NO，不要调用 tolower 统一大小写。
- 本题不是 Special Judge，输出必须是全大写 YES / NO，写成 Yes / No 会 WA。
- 判的是首尾两个字符，不是相邻字符，也不是三个字符全相同（如 ioi 中间的 o 与两侧不同仍是 YES）。

| 项 | 值 |
|---|---|
| 时间复杂度 | O(1) |
| 空间复杂度 | O(1) |
