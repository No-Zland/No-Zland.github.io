### 知识点：

这题考“垂直”这一几何关系在四方向字符上的离散化：U 与 D 同处竖直轴且互为反向，L 与 R 同处水平轴且互为反向；与竖直方向垂直的是水平方向，与水平方向垂直的是竖直方向。结论：把 U、D 映射成 R，把 L、R 映射成 D，就是一组合法答案。因为题目是 Special Judge，任何垂直方向都被接受，所以不需要考虑“往哪边躲更安全”这类题面没有的附加条件。实现上读一个字符、做一次分支、输出一个字符即可，注意读字符前跳过空白，避免读到行末换行。

### 题目描述

> 你和Askalana撸猫正欢之时，一名强盗闯了进来，对你和Askalana开始了魔法加特林连射。
>
> 强盗射出了  $1$  发魔法，魔法会从上下左右四个方向之一（对应使用  $\texttt{`U'}$ 、 $\texttt{`D'}$ 、 $\texttt{`L'}$ 、 $\texttt{`R'}$  表示）来袭，你不会护盾法术，所以你需要向垂直于魔法来袭的方向的方向躲避魔法。
>
> 请直接输出你将要躲避的方向。

**输入描述**

> 在一行上输入一个字符，代表魔法袭来的方向。我们保证这个字符为  $\texttt{`U'}$ 、 $\texttt{`D'}$ 、 $\texttt{`L'}$ 、 $\texttt{`R'}$  中的一个。

**输出描述**

> 输出  $\texttt{`U'}$ 、 $\texttt{`D'}$ 、 $\texttt{`L'}$ 、 $\texttt{`R'}$  中的一个，代表你将要躲避的方向。
>
> 你可以以任何大小写形式输出答案。
> 如果存在多个解决方案，您可以输出任意一个，系统会自动判定是否正确。注意，自测运行功能可能因此返回错误结果，请自行检查答案正确性。

#### 示例 1

**输入**

```text
U
```

**输出**

```text
R
```

#### 示例 2

**输入**

```text
L
```

**输出**

```text
D
```

### 最终代码：

```cpp
// NC289264 和猫猫一起起舞！
// 题意：魔法从 U/D/L/R 某个方向射来，输出一个与它垂直的方向。
// 做法：上下方向来袭就向左右躲（统一输出 R），左右方向来袭就向上下躲（统一输出 D）。
#include <cstdio>

int main() {
    char c;
    if (scanf(" %c", &c) != 1) return 0;
    char ans;
    if (c == 'U' || c == 'D') ans = 'R';   // 竖直方向 -> 水平躲避
    else ans = 'D';                        // 水平方向 -> 竖直躲避
    printf("%c\n", ans);
    return 0;
}
```

### 解题思路

读题后我先确认这题在练什么：四个方向两两配对，答案只能落在与来袭方向垂直的那条轴上，所以本质上是一个四分支映射。为了让样例对得上，我选 U/D -> R、L/R -> D：样例给 U 输出 R，给 L 输出 D，正好吻合。题面明确说多解可任意输出（SPJ），因此不必纠结“左躲还是右躲”。代码只有读入、判断、输出三行，唯一要小心的是读单个字符时用 cin 或 scanf(" %c") 跳过空白，否则若是数据带多余换行就会读到空白字符。这题的价值在于“看清题目允许多解”这件事本身。

#### 卡点与关键一步

- 垂直不等于相反：U 的相反方向是 D（同一条轴），垂直应当是 L 或 R。
- 本题是 SPJ，多解均正确，但自测工具可能拿固定答案比对而报错，应以逻辑正确为准。
- 读单个字符要跳过空白（cin 或 scanf(" %c")），否则可能读到换行。
