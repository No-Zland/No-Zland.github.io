### 知识点：

考点是忽略大小写的字符串相等判断。题面说'可以通过大小写转换变成 Yes'，等价于两个条件：长度必须为 3，且第 i 个字符在忽略大小写后与目标串 "Yes" 的第 i 个字符相同。做法是先判长度，再逐位把字符统一转成大写（或小写）后比较，全等输出 accept，否则输出 wrong answer。要特别注意目标串本身大小写是混着的（Y 大写、e 和 s 小写），所以归一化必须对两边同时做，只转输入是不行的。C++ 里可以用 toupper/tolower，也可以判断是否小写后减 32；输入长度 ≤ 3，任何写法都是 O(1)。这题练的是把自然语言条件翻译成可判定的逻辑，以及输出串要一字不差。

---

### 题目描述

> 小红在判题的时候，经常发现选手把"Yes"输出成"YES"或者"yes"，她希望写一个spj（special judge）来判断选手是否输出了"Yes"。你能帮帮她吗？

**输入描述**

> 一个长度不超过3的、仅由小写字母或者大写字母组成。

**输出描述**

> 若字符串可以通过大小写转换变成"Yes"，则输出"accept"。否则输出"wrong answer"。

#### 示例 1

**输入**

```text
yEs
```

**输出**

```text
accept
```

#### 示例 2

**输入**

```text
No
```

**输出**

```text
wrong answer
```

### 最终代码：

```cpp
#include <iostream>
#include <string>
using namespace std;

int main() {
    string s;
    if (!(cin >> s)) return 0;
    string target = "Yes";
    bool ok = (s.size() == 3);
    if (ok) {
        for (int i = 0; i < 3; ++i) {
            char a = s[i], b = target[i];
            if (a >= 'a' && a <= 'z') a = char(a - 'a' + 'A');
            if (b >= 'a' && b <= 'z') b = char(b - 'a' + 'A');
            if (a != b) { ok = false; break; }
        }
    }
    cout << (ok ? "accept" : "wrong answer") << "\n";
    return 0;
}
```

### 解题思路

题面讲的是 spj 场景，实际就是要我实现一个忽略大小写的比较器。我先圈出两个约束：长度不超过 3，而目标串正好 3 个字符，所以长度不足时一定不匹配；目标是 "Yes" 而不是 "yes"，大小写是混着的。如果偷懒把输入整体转小写再和 "yes" 比，逻辑上也能对，但要求我记得目标串转小写后长什么样，容易记错；更稳的写法是把输入和目标串都归一化成大写，再逐位比较，语义更直接。代码里我写了一个小循环，遇到第一处不同就 break，最后按布尔值输出。样例 yEs 通过；No 长度不对，直接判错，输出 wrong answer。顺带注意输出是 'wrong answer' 两个单词，中间有空格。

#### 卡点与关键一步

- 输出必须是 accept 和 wrong answer（中间一个空格、全小写），拼错一个字符就 WA
- 目标串是 "Yes"，只把第一个字符 Y 判对、后面两位不管会漏判
- 题目只保证长度不超过 3，长度不足 3 的输入也要判错，别默认长度一定是 3

#### 复杂度

| 项 | 值 |
|---|---|
| 时间复杂度 | O(1)（字符串长度 ≤ 3） |
| 空间复杂度 | O(1) |
