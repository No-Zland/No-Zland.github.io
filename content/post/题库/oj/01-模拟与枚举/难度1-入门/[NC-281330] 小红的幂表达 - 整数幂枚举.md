### 知识点：

要把 x 写成所有 a^b（a、b 为正整数）的形式，按指数 b 从小到大输出。关键结论：固定指数 b 时，满足 a^b=x 的正整数 a 至多一个，因为 a^b 关于 a 严格单调递增，所以只需枚举 b，再验证 x 是不是完全 b 次方。b 的上界由底数下界决定：底数至少为 2，一旦 2^b>x 就再不可能有解，x ≤ 1e5 时 b ≤ 16。验证时从 a=2 开始做 b 次整数乘法，乘法前用 p > x/a 判断是否越界，一旦超过 x 立刻 break，因为 a 再变大只会更大。b=1 时 a=x 恒成立，所以第一条输出一定是 =x^1。输出格式是另一半分：第一行单独输出 x 本身，之后每行是 "=a^b" 这种带等号的形式，顺序按指数升序。

---

### 题目描述

> 小红拿到了一个正整数，请你帮小红将其表示为幂（ $a^b$ ）的形式。

**输入描述**

> 一个正整数 $x$ 
>  $2\leq x \leq 10^5$

**输出描述**

> 第一行输出 $x$ 。
> 接下来每一行输出一个幂的表达式。
> 请按指数从小到大的顺序输出。

#### 示例

**输入**

```text
16
```

**输出**

```text
16
=16^1
=4^2
=2^4
```

---

### 最终代码：

```cpp
#include <iostream>
using namespace std;

int main() {
    long long x;
    if (!(cin >> x)) return 0;
    cout << x << "\n";
    // 按指数 b 从小到大枚举所有 a^b = x（a,b 都是正整数）
    for (long long b = 1;; ++b) {
        // 底数至少为 2；若 2^b 都超过 x，后面更大的 b 更不可能，直接结束
        long long t = 1;
        bool over2 = false;
        for (long long i = 0; i < b; ++i) {
            t *= 2;
            if (t > x) { over2 = true; break; }
        }
        if (over2) break;

        for (long long a = 2;; ++a) {
            long long p = 1;
            bool bigger = false;
            for (long long i = 0; i < b; ++i) {
                if (p > x / a) { bigger = true; break; }  // a^(i+1) 已超过 x
                p *= a;
            }
            if (bigger) break;  // a 再变大只会更大
            if (p == x) { cout << "=" << a << "^" << b << "\n"; break; }
        }
    }
    return 0;
}
```

### 解题思路

读完题我先确认三件事：a 和 b 是不是都取正整数（是，所以 x^1 这条要输出）、输出是否按指数升序（是）、每行带不带等号（样例带）。想清楚这三点，剩下就是枚举。第一版我想枚举 a 从 2 到 sqrt(x) 再反复开方，但开方有精度风险，不如直接枚举指数 b：固定 b 后 a 是唯一的，用一个自己写的循环乘法判断 a^b 是否等于 x，完全避开浮点。b 的上界我一开始顺手写了个 100，跑样例没问题但心里没底，改成 2^b>x 就 break，既正确又省事。内层枚举 a 时也加了提前退出：某个 a 的 b 次幂已经超过 x 就停。最后对着样例 16 检验，输出 =16^1、=4^2、=2^4，b=3 无解被跳过，顺序和题面一致。

#### 卡点与关键一步

- 第一行要先单独输出 x，之后每行必须以等号开头（=a^b），漏掉任一处都会 WA
- 别只找质数底数，4^2、16^4 这种复合底数的表示同样要输出
- 用浮点 pow 判断完全幂会在 1e5 附近出现精度误差，应改成整数乘法逐次判断

#### 复杂度

| 项 | 值 |
|---|---|
| 时间复杂度 | O(x)，b=1 那层需要枚举到 a=x，其余指数层规模按平方根级迅速衰减 |
| 空间复杂度 | O(1) |
