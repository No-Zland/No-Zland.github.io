### 知识点：

这题考把自然语言里的两种合法形态翻译成布尔表达式，属于最基础的分类讨论。结论：合法当且仅当 (a==b && b==c) || (b==a+1 && c==b+1)。因为输入已保证 a<=b<=c，刻子不需要写成三者两两相等，顺子也不需要先排序，直接判相邻差 1 即可。顺子不要求从 1 开始，题面只关心 1 到 9 的数字，所以 123 和 789 都合法；而 891、912 这类看起来“首尾相接”的组合在数字轴上并不连续，本就不满足 a<=b<=c 的输入约定，不会出现在数据里。整个判定只有一次常数级比较。

### 题目描述

> 大家都说养一只猫可以有效缓解压力，于是，鸭梨山大的 Askalana 养了一只猫娘。
>
> Askalana 想教她的猫打麻将。但是，猫猫小姐还不会认花色，所以，在本题中我们只关心数字。
>
> 麻将中，同类牌中三个一样的或连续的数字被称为一副牌，有四副牌再加上一对作为将就能构成最基础的和牌。
>
> 但灵智初开的猫娘小姐还不识数，请你帮帮她，看看她的牌能否构成一副牌吧！
>
> 对于 Askalana 挑选出的三张牌，我们只关心其上面的数字。Askalana 保证数字仅为  $1$  到  $9$  之间的整数。你需要判定这三张牌是否构成一副牌。
>
> 更具体地，记给定的三张牌分别为  $a,b,c$ ，保证  $a \leqq b \leqq c$ 。它们被称作一副牌，当且仅当满足以下条件之一：
>
>  $\hspace{23pt}\bullet\,$ 三张牌相同，此时构成一副刻子，即  $a=b=c$ ；
>
>  $\hspace{23pt}\bullet\,$ 三张牌连续，此时构成一副顺子，即  $b=a+1$  且  $c=b+1$ 。

**输入描述**

> 在一行上输入三个正整数  $a,b,c \left(1 \leqq a \leqq b \leqq c \leqq 9\right)$ ，表示猫娘小姐拿到的牌。

**输出描述**

> 如果猫娘小姐拿到的三张麻将能构成刻子或顺子，输出  $\rm Yes$ ，否则输出  $\rm No$ 。您可以以任何大小写形式输出答案，例如， $\rm yEs$ 、 $\rm yes$  和  $\rm YeS$  都将被视为肯定的回答。

#### 示例 1

**输入**

```text
1 2 3
```

**输出**

```text
Yes
```

#### 示例 2

**输入**

```text
8 8 8
```

**输出**

```text
Yes
```

#### 示例 3

**输入**

```text
2 3 3
```

**输出**

```text
No
```

### 最终代码：

```cpp
// NC288220 麻将入门
// 题意：给定 1..9 的三张牌 a<=b<=c，判断是否构成刻子（三张相同）或顺子（连续三张）。
// 做法：两个条件各自判定一次，命中任一即输出 Yes，否则 No。
#include <cstdio>

int main() {
    int a, b, c;
    if (scanf("%d%d%d", &a, &b, &c) != 3) return 0;
    bool kezi = (a == b && b == c);              // 刻子
    bool shunzi = (b == a + 1 && c == b + 1);    // 顺子
    if (kezi || shunzi) printf("Yes\n");
    else printf("No\n");
    return 0;
}
```

*代码为参考实现（按题意重写并用样例验证），非本人原始提交。*

### 解题思路

第一反应是排序后判 a+1==b && b+1==c，但题面已经把输入约束成 a<=b<=c，排序纯属多余，于是直接列两个条件用 || 连接：刻子 a==b==c、顺子 b==a+1 且 c==b+1。写的时候我特意把顺子写成“相邻两步都差 1”，而不是只判 a+2==c，这样更贴近定义、可读性也更好。之后按样例输出 Yes/No（题面说大小写任意，但和样例一致最保险）。三个样例正好覆盖顺子 1 2 3、刻子 8 8 8、以及“两张相同但不连续”的 2 3 3，写完自测一遍就能确认没有漏掉分支。

#### 卡点与关键一步

- 顺子要相邻两步都差 1，只判 a+2==c 容易在放宽约束时出错，按定义写更稳。
- 输入已保证 a<=b<=c，不要额外排序，也不要臆造“可能乱序”的分支。
- 2 3 3 这类两张相同却不相邻的情形必须判 No，刻子要三张全等。

| 项 | 值 |
|---|---|
| 时间复杂度 | O(1) |
| 空间复杂度 | O(1) |
