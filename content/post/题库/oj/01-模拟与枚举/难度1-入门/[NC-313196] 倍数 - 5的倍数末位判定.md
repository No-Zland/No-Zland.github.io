### 知识点：

结论：存在合法重排使结果为 5 的倍数，当且仅当 n 的十进制表示中含有数字 0 或 5。推导：5 的倍数末位只能是 0 或 5，所以不含 0/5 时怎么排都不行，必要性成立。充分性分两种：若含 0，就把一个 0 放末位，其余数字顺序不动，此时 n≥1 保证剩下的高位里有非零数字，不会出现前导零；若不含 0 但含 5，就把 5 放末位，剩下的位全是 1~9 的数字，更没有前导零。所以只需扫一遍数位判断是否存在 0 或 5，不需要真的枚举排列（9 位全排列对 1e4 组数据完全不可行）。

---

### 题目描述

> 小苯有一个正整数  $n$ 。
>
> 小苯可以将  $n$  的十进制表示中的数位任意重新排列，得到一个新的正整数（不能有前导零）。
>
> 你的任务就是判断：是否存在一种重新排列方式，使得得到的数字是  $5$  的倍数。

**输入描述**

> 每个测试文件包含多组测试数据。第一行输入一个整数  $T\left(1 \leqq T \leqq 10^4\right)$  代表数据组数，每组测试数据描述如下：
>  $\hspace{23pt}\bullet\,$ 输入一个整数  $n\left(1 \leqq n \leqq 10^9\right)$ ，表示给定的正整数。

**输出描述**

> 对于每一组测试数据，新起一行，如果存在满足条件的排列方式，输出  $\texttt{YES}$ ，否则输出  $\texttt{NO}$ 。

#### 示例

**输入**

```text
3
5
51
123
```

**输出**

```text
YES
YES
NO
```

---

### 最终代码：

```cpp
#include <cstdio>
using namespace std;
typedef long long ll;

// 倍数：5 的倍数末位只能是 0 或 5，所以只要十进制里出现过 0 或 5，
// 就把它挪到最后一位（其余高位不会出现前导零问题，因为 n >= 1 至少有一个非零位）。
int main() {
    int T;
    if (scanf("%d", &T) != 1) return 0;
    while (T--) {
        ll n;
        scanf("%lld", &n);
        bool ok = false;
        while (n > 0) {
            int d = (int)(n % 10);
            if (d == 0 || d == 5) { ok = true; break; }
            n /= 10;
        }
        printf("%s\n", ok ? "YES" : "NO");
    }
    return 0;
}
```

*代码为参考实现（按题意重写并用样例验证），非本人原始提交。*

### 解题思路

第一反应是「重排」听起来像搜索，但 n 最多 9 位、T 又有 1e4，全排列显然不行。于是问自己：一个数能不能被 5 整除到底取决于什么？答案只取决于末位，末位只可能是 0 或 5。这样整个重排问题就塌缩成「数位里有没有 0 或 5」。我把两种情况都过了一遍：有 0 就把 0 挪到最后，有 5 就把 5 挪到最后，都能保证最高位不为 0。写完扫数位：n=5 有 5 输 YES；51 含 5，排成 15 是 5 的倍数输 YES；123 没有 0/5 输 NO，和样例一致。这题在练的是「整除判定只和末位有关」这种把构造问题降维成判定问题的思路。

#### 卡点与关键一步

- 只要数位里出现 0 或 5 就是 YES，不需要真的构造排列，更不要写全排列搜索。
- 记得处理前导零：本题含有 0/5 时总能排成不以 0 开头的形式，别因此误判成 NO。
- n 可能只有一位，例如 n=5 应当 YES。

#### 复杂度

| 项 | 值 |
|---|---|
| 时间复杂度 | O(log n) |
| 空间复杂度 | O(1) |
