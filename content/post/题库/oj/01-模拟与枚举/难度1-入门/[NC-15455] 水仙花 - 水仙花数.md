### 题目描述

> 数学上水仙花数是这样定义的： “水仙花数”是指一个三位数，它的各位数字的立方和等于其本身，比如：153=1^3+5^3+3^3。 现在要求输出所有在m和n范围内的水仙花数。  
>    (要求使用C语言）

**输入描述**

> 两行行，分别为m和n

**输出描述**

> 所有水仙花数，升序排列，一行一个数
> 范围内不存在不用输出

#### 示例

**输入**

```text
100
500
```

**输出**

```text
153
370
371
407
```

### 最终代码：

2024-10-17 16:36:20

```cpp
#include <cstdio>

// 三位水仙花数：各位立方和等于自身，枚举 [m,n] 内所有数判断。
int main() {
    int m, n;
    if (scanf("%d %d", &m, &n) != 2) return 0;
    for (int x = m; x <= n; ++x) {
        if (x < 100 || x > 999) continue;
        int a = x / 100, b = x / 10 % 10, c = x % 10;
        if (a * a * a + b * b * b + c * c * c == x) printf("%d\n", x);
    }
    return 0;
}
```

### 解题思路

看到“三位数 + 立方和”我第一反应就是按位拆开暴力判断，区间最多 900 个数，完全够。中途想过直接把四个答案打表，但输入是 m 和 n 两个界，打完表还得筛区间，没有更简单，索性老老实实循环。拆位用整除和取模，个位 x%10、十位 x/10%10、百位 x/100。写的时候特意加了 x<100||x>999 的过滤，因为题面只保证给 m、n，没保证区间落在三位数里，而像 1=1³ 这种会被误判。输出用 printf("%d\n")，没有额外空行，这样区间为空时自然什么都不打印。

#### 卡点与关键一步

- 拆中间位要 /10%10，直接 %10 是错的
- 区间不一定在三位数内，需要过滤
- 区间为空时不要输出空行

#### 复杂度

| 项 | 值 |
|---|---|
| 时间复杂度 | O(min(n,999)-max(m,100)+1)，至多 O(900) |
| 空间复杂度 | O(1) |
