### 知识点：

结论：比较两张券的实付金额即可——八折券实付 0.8x=4x/5，无门槛券实付 x-5。把两者比大小，两边同乘 5 得到 4x 与 5x-25，即比较 x 与 25：x>25 用八折更便宜，x<25 用 5 元券更便宜，x=25 时两种都是 20 元，输出 0。属于最基础的「按公式算两种方案再比大小」模型：把「哪张券划算」翻译成两个关于 x 的一次函数比大小，解出分界点 0.8x < x-5 ⟺ 0.2x > 5 ⟺ x > 25。注意输出的是券的面值 8/5/0 而不是金额，所以判定仍然落在「谁让实付更小」上，只是答案载体换了。

### 题目描述

> 小歪正在点外卖，他有一张仅可单独使用的八折优惠券和一张仅可单独使用无门槛  $5$  元优惠券，他想知道，如果要购买  $x$  元的外卖，使用哪一张券会使得最终支付的金额最小。

**输入描述**

> 在一行上输入一个整数  $x\left(5\leqq x\leqq 10^9\right)$ ，表示外卖的价格。

**输出描述**

> 如果使用八折优惠券更划算，输出  $8$ ；如果使用无门槛  $5$  元优惠券更划算，输出  $5$ ；如果两种优惠券都一样划算，输出  $0$ 。

#### 示例 1

**输入**

```text
5
```

**输出**

```text
5
```

#### 示例 2

**输入**

```text
500
```

**输出**

```text
8
```

### 最终代码：

```cpp
// NC296097 外卖券
// 八折券实付 4x/5，无门槛 5 元券实付 x-5，
// 比较 4x/5 与 x-5 等价于比较 4x 与 5x-25，即比较 x 与 25。
#include <cstdio>

int main() {
    long long x;
    if (scanf("%lld", &x) != 1) return 0;
    // 两边同乘 5 做整数比较，避开浮点误差
    long long payDiscount = 4 * x;        // 八折：0.8x = 4x/5
    long long payCoupon = 5 * (x - 5);    // 5 元券：x-5
    if (payDiscount < payCoupon)
        printf("8\n");
    else if (payDiscount > payCoupon)
        printf("5\n");
    else
        printf("0\n");
    return 0;
}
```

### 解题思路

看到「哪种券让支付金额更小」，我第一反应就是各算一遍再比，因为只有两种方案、只有一个变量 x。真正动手时注意到一个坑：0.8x 可能带小数（比如 x=7 是 5.6 元），用 double 在本题范围其实够，但整数比较更干净——两边同乘 5，比较 4x 与 5x-25，等价且没有精度问题。代入样例验证：x=5 时 4x=20、5(x-5)=0，后者更小，输出 5 ✓；x=500 时 2000 < 2475，八折赢，输出 8 ✓。顺手解出分界点 x=25，理论上代码可以只写一个与 25 的比较，但我保留了直接比较两个实付的写法，因为它不需要额外推导，也不容易在等号归属上出错。

#### 卡点与关键一步

- 输出的是券的面值 8/5/0，不是算出来的支付金额，别把钱数打出去
- 相等（x=25，两张券都付 20）要输出 0，不能顺手输出 8 或 5
- 用浮点算 0.8x 有精度隐患，两边同乘 5 转成整数比较最稳
