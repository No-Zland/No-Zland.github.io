### 知识点：

结论：把三种魔法看成 0、1、2 的循环，小红赢当且仅当 y=(x+1) mod 3。推导：水(0) 克火(1)、火(1) 克冰(2)、冰(2) 克水(0)，三个「克制」关系恰好都是「对手编号 = 自己编号加一再对 3 取模」，于是不必写三条 if，一个取模就能覆盖全部三种胜利情况。平局是 x==y，其余情况（即 y=(x+2) mod 3）都是小橙赢，因为三种魔法两两之间必有一方克制另一方，不存在第四种关系。这题属于最基础的循环判定模拟：把散在文字描述里的关系表压缩成代数形式，能明显降低写错分支的概率，也是「石头剪刀布型」状态机的最小写法。

### 题目描述

> 在魔法学院的竞技场上，小红和小橙正在进行一场别开生面的魔法对决。在这个魔法对决里，不同的魔法有着相互克制的关系。水魔法克制火魔法，火魔法克制冰魔法，冰魔法克制水魔法。每种魔法用一个数字表示： $0$  代表水魔法， $1$  代表火魔法， $2$  代表冰魔法。 
>
> 	请你判断并输出最终谁赢得了这一轮魔法对决。如果两人使用的魔法相同，则判定为平局。

**输入描述**

> 在一行上输入两个整数  $x,y \left(0 \leq x,y \leq 2\right)$ ，分别表示小红和小橙所使用的魔法类型。

**输出描述**

> 如果小红赢了，输出  $\text{Hongwins}$ （TXT文本复制：Hongwins）；如果小橙赢了，输出  $\text{chengwins}$ （TXT文本复制：chengwins）；如果两人平局，输出  $\text{Draw}$ （TXT文本复制：Draw）。

#### 示例 1

**输入**

```text
1 2
```

**输出**

```text
Hongwins
```

#### 示例 2

**输入**

```text
2 1
```

**输出**

```text
chengwins
```

#### 示例 3

**输入**

```text
0 0
```

**输出**

```text
Draw
```

### 最终代码：

```cpp
// NC295727 红橙
// 0 水、1 火、2 冰；水克火、火克冰、冰克水，
// 即小红赢当且仅当 y = (x+1) mod 3。
#include <cstdio>

int main() {
    int x, y;
    if (scanf("%d %d", &x, &y) != 2) return 0;
    if (x == y)
        printf("Draw\n");
    else if ((x + 1) % 3 == y)   // 水(0)->火(1)、火(1)->冰(2)、冰(2)->水(0)
        printf("Hongwins\n");
    else
        printf("chengwins\n");
    return 0;
}
```

### 解题思路

看到「水克火、火克冰、冰克水」我立刻联想到石头剪刀布，心想用 if-else 列三种胜利也行，但要写三个条件、还容易漏。于是试着把编号代进去：水=0 克火=1，火=1 克冰=2，冰=2 克水=0，三组刚好都满足「对手 = 我加一，再 mod 3」，一个 (x+1)%3==y 就判完了。剩下 x==y 是平局，其他情况是小橙赢。样例核对：1 2 时 (1+1)%3=2，Hongwins ✓；2 1 时 (2+1)%3=0≠1 且不相等，chengwins ✓；0 0 平局 ✓。最后提醒自己输出串的写法：Hongwins、chengwins（首字母小写 c）、Draw，三个都不是常规拼法，抄题面最稳。

#### 卡点与关键一步

- 三个输出串是 Hongwins / chengwins / Draw，小橙那个首字母是小写 c，容易顺手写成 Chengwins
- 必须先判 x==y 平局，否则相等的情况会掉进某个胜负分支
- 克制方向别写反：水(0) 打火(1)、火(1) 打冰(2)、冰(2) 打水(0)
