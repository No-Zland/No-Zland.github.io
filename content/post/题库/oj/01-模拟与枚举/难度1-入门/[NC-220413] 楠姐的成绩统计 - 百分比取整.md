### 知识点：

统计模型：一遍扫描计数，再换算成百分比。结论：及格率 = round(100·cnt_p/n)，优秀率 = round(100·cnt_g/n)，四舍五入用纯整数写成 (200·cnt+n)/(2n) 向下取整。推导：round(x)=⌊x+1/2⌋，把 x=100cnt/n 通分后得 ⌊(200cnt+n)/(2n)⌋，分子分母全为整数，C 的整除天然向下取整，正好实现“五入”。反例是用 printf("%.0f")：它走默认舍入模式（四舍六入五成双），42.5 会输出 42，而且浮点本身有误差，临界值不可靠。输出里的字面百分号要写成 %%。

### 题目描述

> 09级的楠姐是学霸中的战斗机，本科期间专业课拿过n个满分（n≥4），后来去了中科院读博士，现在某东，已经开始指导后辈发论文了。 
>    楠姐给419的渣渣们组织了一场考试，卷面总分为100分，每个学生的得分都是一个0到100的整数。     如果得分至少是60分，则称为及格。如果得分至少为85分，则称为优秀。  
>
>      请计算及格率和优秀率，用百分数表示，百分号前的部分四舍五入保留整数。

**输入描述**

> 输入的第一行包含一个整数n，表示考试人数。
>
> 接下来n行，每行包含一个0 至100 的整数，表示一个419er的得分。

**输出描述**

> 输出两行，每行一个百分数，分别表示及格率和优秀率。百分号前的部分四舍五入保留整数。

#### 示例

**输入**

```text
7
80
92
56
74
88
100
0
```

**输出**

```text
71%
43%
```

### 最终代码：

```cpp
#include <cstdio>

// 及格率/优秀率：百分号前四舍五入（.5 进位），用整数运算避免浮点误差。
// round(100*cnt/n) = floor((200*cnt+n)/(2n))
int main() {
    int n;
    if (scanf("%d", &n) != 1) return 0;
    int pass = 0, good = 0;
    for (int i = 0; i < n; ++i) {
        int s;
        if (scanf("%d", &s) != 1) return 0;
        if (s >= 60) ++pass;
        if (s >= 85) ++good;
    }
    printf("%d%%\n", (int)((2LL * 100 * pass + n) / (2LL * n)));
    printf("%d%%\n", (int)((2LL * 100 * good + n) / (2LL * n)));
    return 0;
}
```

### 解题思路

这题读起来很轻，但我第一遍就栽在取整上。第一反应是 double p = cnt*100.0/n 然后 printf("%.0f%%", p)，结果 42.5 被舍成 42，样例立刻对不上。改成手动 +0.5 再转 int 能过，可边界值还是心虚；最后换成 (200*cnt+n)/(2*n) 的整数写法，逻辑上完全等价于四舍五入，且没有任何精度问题。第二个点是统计口径：及格是 ≥60，优秀是 ≥85，是两个独立条件，不能写成 else if。整体流程就是读 n、扫一遍分数、维护两个计数器，最后两行输出。样例 7 个人里 5 个及格、3 个优秀，42.857 进位成 43，正好验证了取整逻辑。

#### 卡点与关键一步

- round 用整数式 (200cnt+n)/(2n)，别依赖 %.0f 的默认舍入
- 及格与优秀是两个独立条件，都要判
- 输出里的 % 要转义成 %%

#### 复杂度

| 项 | 值 |
|---|---|
| 时间复杂度 | O(n) |
| 空间复杂度 | O(1) |
