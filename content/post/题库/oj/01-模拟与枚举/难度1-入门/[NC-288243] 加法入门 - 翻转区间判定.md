### 知识点：

把塔展平成 1..N 的数组后，位置 p（1-indexed）所在层号 i 是最小的满足 i(i+1)/2≥p 的整数，它的两个孩子位于 p+i 与 p+i+1。原始值等于下标、严格递增，所以塔天然平衡。翻转 [l,r] 后，区间内第 p 位的值变成 l+r-p，随 p 递减：只要区间内存在一条完整的父子边，父值必然大于子值，平衡立刻被破坏；而跨边界的两类边都自动满足（父在区间外时 p<l≤l+r-c，子在区间外时新父值≤r<c）。于是判定退化为「[l,r] 内是否存在完整父子边」。对 p≥l 求最小可能右端点：孩子为 p+row(p)，而 p 与 row(p) 都单调不减，最小值在 p=l 处取到，故 r≥l+row(l) 即为 No。

### 题目描述

> 教会了猫猫数数，Askalana决定教她一些更进一步的东西。
>
> 本题与《B. 数数入门》共享部分题目背景，这一部分我们使用特殊的格式标注。
>
> 〖引用开始〗 
>
> 	Askalana 搭建了一个  $n$  层的麻将塔。从上往下数，第  $i$  层由  $i$  块麻将组成。每一块麻将上面都刻了一个整数，记第  $i$  层从左往右数第  $j$  块麻将上的数字为  $a_{i,j}$ 。如下所示：
>
> 		 $\begin{array}{c}
> a_{1,1}\\ 
> a_{2,1} \hspace{20pt} a_{2,2} \\ 
> a_{3,1} \hspace{20pt} a_{3,2} \hspace{20pt} a_{3,3} \\
> \vdots \hspace{35pt} \vdots \hspace{35pt} \vdots \hspace{35pt} \vdots \\ 
> a_{n,1} \hspace{23pt} a_{n,2} \hspace{23pt} \cdots \hspace{23pt} a_{n,n} 
> \end{array}$ 
>
>
> 除最下层外，每块麻将的左、右两角分别由其两块麻将支撑；如果一座麻将塔中，每一块麻将左下、右下支撑它的麻将上的整数均不小于它自身，那么称这座麻将塔是“平衡的”。更具体地，对于任意的  $a_{i,j} \left(1 \leqq i \lt n;\ 1 \leqq j \leqq i\right)$ ，若都有  $a_{i, j} \leqq a_{i+1, j}$  且  $a_{i, j} \leqq a_{i+1, j+1}$ ，那么这座麻将塔是“平衡的”。
>
> 〖引用结束〗 
>
>
> 在本题中，每一块麻将上的整数都各不相同，且为  $1$  到  $\tfrac{n \times (n+1)}{2}$  中的一个。Askalana 按整数从小到大的顺序，自上而下、自左而右的搭出了一座麻将塔。如下所示：
>
>
>
> 			 $\begin{array}{c} 
> 1 \\ 
> 2 \hspace{40pt} 3 \\ 
> 4 \hspace{40pt} 5 \hspace{40pt} 6 \\ 
> \vdots \hspace{47pt} \vdots \hspace{47pt} \vdots \hspace{47pt} \vdots \\ 
> {\tfrac{n \times (n-1)}{2} + 1} \quad {\tfrac{n \times (n-1)}{2} + 2} \qquad \cdots \qquad {\tfrac{n \times (n-1)}{2}+n}
> \end{array}$

**输入描述**

> 每个测试文件均包含多组测试数据。第一行输入一个整数  $T\left(1\leqq T\leqq 10^5\right)$  代表数据组数，每组测试数据描述如下：
> 在一行上输入三个整数  $n, l, r\left(2\leqq n\leqq 10^9;\ 1\leqq l \lt r\leqq \tfrac{n \times (n+1)}{2}\right)$  代表麻将塔的层数、翻转的区间。

**输出描述**

> 对于每一组测试数据，新起一行。如果反转后的数组搭出的麻将塔是“平衡的”，输出  $\rm{Yes}$ ，否则  $\rm{No}$ 。您可以以任何大小写形式输出答案，例如， $\rm yEs$ 、 $\rm yes$  和  $\rm YeS$  都将被视为肯定的回答。

#### 示例

**输入**

```text
3
5 1 15
5 2 3
5 2 4
```

**输出**

```text
No
Yes
No
```

### 最终代码：

```cpp
#include <cstdio>
#include <cmath>
using namespace std;

// 第 p 个位置（从 1 开始）位于第几层：最小的 i 使 i(i+1)/2 >= p
long long row_of(long long p) {
    long double t = (long double)p;
    long long i = (long long)((sqrtl(8.0L * t + 1.0L) - 1.0L) / 2.0L);
    while (i > 0 && i * (i - 1) / 2 >= p) i--;
    while (i * (i + 1) / 2 < p) i++;
    return i;
}

int main() {
    int T;
    if (scanf("%d", &T) != 1) return 0;
    while (T--) {
        long long n, l, r;
        scanf("%lld %lld %lld", &n, &l, &r);
        // 翻转区间内部任意一对父子边都会使大盘压小盘 -> No
        // 唯一可能破坏平衡的是「完全落在 [l,r] 内的一条边」，
        // 其最小可能右端点出现在父节点 p = l 上，为 l + row(l)
        long long p = l + row_of(l);
        puts(r < p ? "Yes" : "No");
    }
    return 0;
}
```

### 解题思路

先想模拟：N 最大约 5×10^17，T 又有 10^5，逐元素翻转再检查绝无可能，必须 O(1) 判定。于是拿 n=5 手推：翻转 [2,3] 为什么是 Yes？因为 2、3 是同一层的相邻元素，之间没有父子边；翻成 3、2 后，2 的孩子是 4、5，3 的孩子是 5、6，父子仍然递增。反过来 [2,4] 里 2→4 是一条边，翻完 4 跑到 2 上面，直接违规。由此提出猜想：只有区间内包含完整父子边时才 No。接着把跨边界的两种边代入新值 l+r-p 逐条验证，发现都恒成立，猜想得到证明。最后把「存在内部边」化成一维单调最值，最小右端点出现在 p=l，即 l+row(l)。我用 n≤8 的全部 (l,r) 暴力建塔对拍了 1386 组，全部一致。

#### 卡点与关键一步

- 新值是 l+r-p（因为原数组值等于下标），写成 r-l+p 或 l+r+p 会全盘错。
- 层号要用 1-indexed 的 i(i+1)/2≥p，且 n 最大 1e9、l 可达 5×10^17，开方后必须微调（floor(sqrt) 常差一），计算全程 long long。
- 别漏掉 l 落在最后一层的情况：那里没有子节点，但 r<l+row(l) 自动成立，不需要额外特判。

#### 复杂度

| 项 | 值 |
|---|---|
| 时间复杂度 | O(T)，每组 O(1) |
| 空间复杂度 | O(1) |
