### 知识点：

单表替换（凯撒）密码模型：把 0-9、A-Z、a-z 依次首尾相连，得到一条长度 62 的字符环，加密是整体后移 d 位，解密是整体前移 d 位。结论：先建常量表 table[62]，对密文每个字符求出下标 i，明文就是 table[(i−d) mod 62]，C 里负数要写 (i−d%62+62)%62。关键推导在“跨段”：如果把数字、大写、小写分三段各自取模，那么 '1' 回退 3 位会算成 '8'，而样例要求 'y'，说明三段必须连成一条整环。d 先对 62 取模，可处理任意大的偏移量。

### 题目描述

> 一段由凯撒密码加密过的密文，凯撒密码指的是将字符偏移一定的单位，例如若偏移量为2，则a替换为c，b替换为d，c替换为e，...，z替换为b。若加密nowcoder，则密文为pqyeqfgt。现在发现加密包括数字、大写字母、小写字母，即0-9、A-Z、a-z的排列顺序进行偏移，现在截获了对方的一段密文以及偏移量，给定一段密文str和偏移量d，求对应的明文。

**输出描述**

### 最终代码：

```cpp
#include <cstdio>
#include <cctype>
#include <cstdlib>
#include <iostream>
#include <string>
using namespace std;

// 凯撒密码：0-9、A-Z、a-z 连成一条 62 长度环，解密时整体回退 d 位。
static const char *TAB = "0123456789ABCDEFGHIJKLMNOPQRSTUVWXYZabcdefghijklmnopqrstuvwxyz";

int main() {
    string line;
    if (!getline(cin, line)) return 0;
    // 取出被引号包住的那一段作为密文，引号后面（或逗号后）的整数是偏移量
    string cipher;
    size_t l = line.find('"'), r = (l == string::npos ? string::npos : line.find('"', l + 1));
    size_t p;
    if (l != string::npos && r != string::npos) {
        cipher = line.substr(l + 1, r - l - 1);
        p = r + 1;
    } else {
        size_t c = line.find(',');
        cipher = line.substr(0, c);
        p = (c == string::npos ? line.size() : c + 1);
    }
    int d = 0;
    while (p < line.size() && !(isdigit((unsigned char)line[p]) || line[p] == '-')) ++p;
    int sign = 1;
    if (p < line.size() && line[p] == '-') { sign = -1; ++p; }
    for (; p < line.size() && isdigit((unsigned char)line[p]); ++p) d = d * 10 + (line[p] - '0');
    d = (sign * d) % 62;
    if (d < 0) d += 62;

    string plain;
    for (char ch : cipher) {
        int idx = -1;
        for (int i = 0; i < 62; ++i)
            if (TAB[i] == ch) { idx = i; break; }
        if (idx < 0) { plain += ch; continue; }          // 环外字符原样保留
        plain += TAB[(idx - d + 62) % 62];
    }
    printf("\"%s\"\n", plain.c_str());
    return 0;
}
```

### 解题思路

第一反应是分段处理：数字在数字里转、字母在字母里转，这也是最常见的凯撒写法。拿样例二 "123ABCabc",3 一试就不对了，输出是 yz0789XYZ——'1' 往回走三位掉进了小写区，说明出题人把 62 个字符连成了一条环。于是改成先拼表再查表：对每个字符线性找下标（只有 62 个，代价可忽略），减 d 后加 62 再模 62。输入格式也是坑，题面没给输入说明，只能从样例看出是 "密文",偏移量，所以先按引号截出密文，再从引号后面读整数，输出句末同样补上引号。

#### 卡点与关键一步

- 62 个字符是一条整环，不能分三段各自取模
- 输入带引号和逗号，密文不能把引号算进去
- (i-d) 为负时要 +62 再取模

#### 复杂度

| 项 | 值 |
|---|---|
| 时间复杂度 | O(|s|) |
| 空间复杂度 | O(1) |
