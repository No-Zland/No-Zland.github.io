### 知识点：

关键是把「拍照时刻」算明白：你排到第 i 个窗口队尾时前面有 a_i 个人，而所有窗口每单位时间同时走一个人，所以不管你什么时候加入，你都会在第 a_i 时刻站到队首（加入时刻被抵消掉了）。于是每访问一个窗口就消耗一个时刻 a_i，且下一次加入要求那个窗口还没关，即必须 a_j>a_i，访问顺序被强制成 a 的严格递增序。结论：可行 ⇔ 所有 a_i 两两不同；排序后检查相邻是否相等即可。

### 题目描述

> 本题与《C. 食堂大作战2.0》共享题目背景，但是所求内容与范围均不同，我们建议您重新阅读题面。
>
> 你来到食堂吃完了饭，并决定给在寝室沉迷游戏没吃饭的室友一个惊喜——向 Ta 展示今天食堂每一个窗口的饭菜。所以，你要去每个窗口排队拍照，并且发给室友。
>
> 食堂目前一共有  $n$  个窗口，第  $i$  个窗口目前排了  $a_i$  个人。假设目前所有窗口排队的人不会再多加，并且每隔相同的时间，所有窗口的第一个人都会同时打完饭离开，如果有第二个人，那么第二个人将会成为新的第一个人，并且开始买饭；如果没有第二个人（队伍没人了），这个窗口将会瞬间关闭。
>
> 你将排在队伍的末尾，并且你每次只能选择一个窗口排队。当你位于队列最前面的时候，你可以进行拍照操作。拍照和切换队伍的时间忽略不计（即，排到你的时候，你可以瞬间拍照并切换到另一个队伍末尾排队）。你想要知道，是否存在一个合理的排队顺序，使得你能够在每一个窗口关闭前都拍到一张照片。

**输入描述**

> 第一行输入一个正整数  $n \left(1 \leqq n \leqq {\color{black}{\pmb{10^3}}}\right)$  代表食堂窗口总数。
> 第二行输入  $n$  个正整数  $a_1, a_2, \dots, a_n \left(1 \leqq a_i \leqq 10^9\right)$  代表每个窗口的排队人数。

**输出描述**

> 如果存在一个合理的排队顺序，使得你能够在每一个窗口关闭前都拍到一张照片，直接输出  $\rm YES$ ，否则输出  $\rm NO$ 。

#### 示例 1

**输入**

```text
3
1 2 3
```

**输出**

```text
YES
```

#### 示例 2

**输入**

```text
3
1 1 1
```

**输出**

```text
NO
```

#### 示例 3

**输入**

```text
5
1 14 5 11 4
```

**输出**

```text
YES
```

### 最终代码：

```cpp
#include <cstdio>
#include <vector>
#include <algorithm>
using namespace std;
int main() {
    int n;
    if (scanf("%d", &n) != 1) return 0;
    vector<long long> a(n);
    for (auto &v : a) scanf("%lld", &v);
    sort(a.begin(), a.end());
    bool ok = true;
    for (int i = 1; i < n; i++)
        if (a[i] == a[i - 1]) { ok = false; break; }
    puts(ok ? "YES" : "NO");
    return 0;
}
```

### 解题思路

第一反应是模拟+贪心，但很快发现根本不用模拟：设当前时刻为 t，加入窗口 i 后前面还剩 a_i−t 人，再过 a_i−t 步就到队首，所以拍照时刻恰好是 t+(a_i−t)=a_i，和 t 无关。这一步把「排队顺序」问题变成了「给 a_i 排一个严格递增的访问序」，也就是所有 a_i 必须互不相同。样例 1 2 3 的答案 YES 还帮我确认了边界：恰好在窗口关闭那一刻拍照是允许的，所以判据是严格大于、但等号只出现在同一窗口自身，去重判据成立。实现只需排序后看相邻是否有相等，n 只有 10^3，代价可以忽略。

#### 卡点与关键一步

- 判据是「严格递增」，不是「非降」：两个窗口 a 相同会在同一时刻同时到队首，做不到
- 切换时目标窗口必须还没关，即要求 a_j>当前时刻，不能把等号算成可行
- n=1 时任何 a_1 都可行，不要漏掉这种只有单个窗口的情况

#### 复杂度

| 项 | 值 |
|---|---|
| 时间复杂度 | O(n log n) |
| 空间复杂度 | O(n) |
