### 知识点：

考点：把「任意 k 个不同行不同列元素和相等」翻译成代数结构。结论：k≥2 时等价于 A[i][j]=r[i]+c[j]（用差两格的两种排列取等即得），k=1 时任意 1×1 都合法。表示不唯一：r 加 t、c 减 t 矩阵不变，取 min(c)=0 归一化后 r[i] 恰是第 i 行最小值，于是「所有元素≥m」等价于「所有 r[i]≥m」。计数变为数 r[i]≥m、c[j]≥0、min(c)=0、Σr+Σc≤n：用「c 全非负」减「c 全≥1」（各减 1，上限变 n−k）容斥，每次是 2k 个非负整数和≤S 的方案数 C(S+2k,2k)。最终 ans=(n−m+1)+Σ_{k≥2,km≤n}[C(n−(m−2)k,2k)−C(n−(m−1)k,2k)]。

### 题目描述

> “以我残躯化烈火”。
>
> 给定两个整数  $n,m$ ，你需要构建一个方阵，满足：
>
>  $\hspace{23pt}\bullet\,$ 方阵的每一个元素均为整数，且大于等于  $m$ ；
>
>  $\hspace{23pt}\bullet\,$ 矩阵的主对角线（即全部  $y=x$  的格子）上的数值和不超过  $n$ ；
>
>  $\hspace{23pt}\bullet\,$ 记矩阵的大小为  $k\times k$ ，从矩阵中取出任意  $k$  个不在同一行同一列的整数，每一种取法的  $k$  个数值之和均相等。
>
> 输出满足条件的不同的方阵数量。由于答案可能很大，请将答案对  $(10^9+7)$  取模后输出。

**输入描述**

> 每个测试文件均包含多组测试数据。第一行输入一个整数  $T\left(1\leq T\leq 100\right)$  代表数据组数，每组测试数据描述如下：
> 在一行上输入两个整数  $n,m\left(1\leq n,m\leq 6\times 10^5\right)$ ，表示矩阵的两个构造限制。
>
>  $T\\
> n_1\ m_1\\
> n_2\ m_2\\
> \vdots\\
> n_t\ m_t$

**输出描述**

> 对于每组测试数据，新起一行输出一个整数表示答案。

### 最终代码：

```cpp
#include <cstdio>

typedef long long ll;
const int MOD = 1000000007;
const int MAXF = 1300000;  // 2*6e5 足够：n - (m-2)k <= n + 2k <= 2n

static ll fact[MAXF], inv_fact[MAXF];

ll qpow(ll a, ll e) {
    ll r = 1 % MOD;
    a %= MOD;
    while (e > 0) {
        if (e & 1) r = r * a % MOD;
        a = a * a % MOD;
        e >>= 1;
    }
    return r;
}

void init() {
    fact[0] = 1;
    for (int i = 1; i < MAXF; i++) fact[i] = fact[i - 1] * i % MOD;
    inv_fact[MAXF - 1] = qpow(fact[MAXF - 1], MOD - 2);
    for (int i = MAXF - 1; i > 0; i--) inv_fact[i - 1] = inv_fact[i] * i % MOD;
}

inline ll C(ll N, ll K) {
    if (K < 0 || N < 0 || K > N) return 0;
    if (N >= MAXF) return 0;
    return fact[N] * inv_fact[K] % MOD * inv_fact[N - K] % MOD;
}

int main() {
    init();
    int T;
    if (scanf("%d", &T) != 1) return 0;
    while (T--) {
        ll n, m;
        scanf("%lld %lld", &n, &m);
        ll ans = (n >= m) ? ((n - m + 1) % MOD) : 0;  // k = 1
        for (ll k = 2; k * m <= n; k++) {
            ll two_k = 2 * k;
            ll a1 = n - (m - 2) * k;  // n - k*m + 2k
            ll a2 = n - (m - 1) * k;  // n - k*m + k
            ans += C(a1, two_k) - C(a2, two_k);
            ans %= MOD;
        }
        ans = ((ans % MOD) + MOD) % MOD;
        printf("%lld\n", ans);
    }
    return 0;
}
```

### 解题思路

读完题我第一件事是把「任意取法求和相等」翻译成方程：取两种只差两格的排列，得到 A11+A22=A12+A21，再多取几组就能确认整个矩阵必须是「行加列」的形式，只有 2k−1 个自由参数。接着卡在去重：a[i]+b[j] 的表示可以整体平移，于是规定列的最小值为 0，这样 r[i] 正好是每行最小值，矩阵与参数一一对应。再代回去发现「所有元素≥m」在归一化后只剩「每行最小值≥m」，约束一下子干净了。剩下就是数格子：Σr+Σc≤n 的方案，用「全非负」减「全≥1」做容斥，每次套隔板法 C(S+2k,2k)。k=1 要单独算 n−m+1，因为那时没有任何限制。最后按 k 从 2 枚举到 n/m，用预处理的阶乘算组合数；先用 n=9,m=2 手算出 191 对上了，再交样例会更有底。

#### 卡点与关键一步

- k=1 必须单独加 n−m+1，直接套 k≥2 的容斥式会算错
- n−(m−2)k 这类上标可能为负，二项式要判 N<K 直接返回 0，否则会越界
- 忘了 min(c)=0 的归一化会导致同一个矩阵被重复计数

#### 复杂度

| 项 | 值 |
|---|---|
| 时间复杂度 | O(n/m) 每组，阶乘预处理 O(N) |
| 空间复杂度 | O(N) |
