### 知识点：

递推式是 a_i = a_{i−2}，说明每项只依赖隔一项的前驱，下标按奇偶分成两条互不干扰的链：奇数位全部继承 a_1 = 1，偶数位全部继承 a_2 = 0。所以长度 100 的数组其实就是 1,0,1,0,…，不同元素只有 {0,1} 两种，问题从「区间去重」退化成「区间里出现了几种下标奇偶性」。结论：长度 1 的区间只含一种奇偶性，答案是 1；长度 ≥ 2 的区间必然一奇一偶相邻，答案恒为 2。也就是 (l==r ? 1 : 2)，一次询问 O(1)，连数组都不用建。这题练的是「先看清序列结构，再决定要不要模拟」的观察习惯。

### 题目描述

> 本题与《C.小红的数组查询（二）》共享部分题目背景，但是所求内容不同，我们建议您重新阅读题面。
>
> 小红拿到了一个长度为  $100$  的数组，其构成如下：
>
>  $\hspace{23pt}\bullet\,$ 数组的第一个元素  $a_1=1$ ；
>
>  $\hspace{23pt}\bullet\,$ 数组的第二个元素  $a_2=0$ ；
>
>  $\hspace{23pt}\bullet\,$ 对于  $3 \leqq i \leqq 100$ ， $a_i=a_{i-2}$ 。
>
> 现在小红想知道， $l$  到  $r$  之间有多少种不同元素。

**输入描述**

> 在一行上输入两个整数  $l,r \left(1\leqq l \leqq r \leqq 100\right)$ ，表示查询的区间。

**输出描述**

> 输出一个整数，表示  $l$  到  $r$  之间的不同元素个数。

#### 示例

**输入**

```text
1 2
```

**输出**

```text
2
```

---

### 最终代码：

```cpp
#include <iostream>
using namespace std;

int main() {
    int l, r;
    if (!(cin >> l >> r)) return 0;
    // 奇数下标恒为 1，偶数下标恒为 0，整个数组只有 1 和 0 两个值
    // 区间长度 1 时只出现一种下标奇偶性；长度 >= 2 时必同时含奇、偶下标
    cout << (l == r ? 1 : 2) << "\n";
    return 0;
}
```

### 解题思路

这题数据规模小到可以无脑建数组再去重，但我第一反应还是先看递推式长什么样：a_i 只依赖 a_{i−2}，等于把数组拆成奇数下标和偶数下标两条链，每条链内部都是常数。代入前两项就知道奇数链全是 1、偶数链全是 0，整个数组只有两个值。到这一步问题就变了性质：不再问「有多少个不同的数」，而是问「区间里有没有同时出现奇偶两种下标」。区间长度为 1 时只看到一个下标，答案 1；长度大于 1 时相邻两个下标一定一奇一偶，答案必然是 2。所以最后代码只有一行输出。复盘时我把这种题归为观察题：先分析结构往往能让 O(n) 掉到 O(1)，盲目开数组虽然能过，但没练到东西；另外这里 a 的下标从 1 开始，别顺手按 0-based 去想。

#### 卡点与关键一步

- 数组下标从 1 开始，a_1=1、a_2=0，别把递推写成从 i=2 起算出 a_2=1
- 答案只有 1 和 2 两种，l==r 时是 1，别看到样例 1 2 输出 2 就以为恒为 2
- 长度 ≥ 2 时一定同时含奇、偶下标（相邻即可），不需要真的去数元素

#### 复杂度

| 项 | 值 |
|---|---|
| 时间复杂度 | O(1) |
| 空间复杂度 | O(1) |
