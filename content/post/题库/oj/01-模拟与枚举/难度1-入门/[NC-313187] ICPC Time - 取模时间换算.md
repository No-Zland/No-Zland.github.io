### 知识点：

考的是 24 小时制下的时间加法。结论：结束小时数 =(n+5) mod 24。推导很简单：开始时刻是 n 时 0 分 0 秒，赛程 5 小时整，分钟与秒都不进位，所以只需要把小时数加 5；一天 24 小时循环，超过 23 就回到 0，因此对 24 取模。由于 n∈[0,23]，n+5∈[5,28]，最多减一次 24，写成 (n+5)%24 与写 if(n+5>=24) n+5-24 完全等价，前者更不容易漏分支。这题本质是在练「把一天当循环节、用取模做周期换算」这个最基础的模型，后面所有日期、时钟类模拟都从这里长出来。

---

### 题目描述

> 众所周知，一场 ICPC 区域赛的时长是  $5$  小时。
>
> 现在给定一个整数  $n\left(0 \leqq n \leqq 23\right)$ ，表示区域赛的开始时间（ $n$  时  $0$  分  $0$  秒）。
>
> 你的任务就是求出：本场区域赛结束时的小时数（注意：按  $24$  小时制计时，即从  $0$  点开始到  $23$  点为一天，答案可能到第二天）。

**输入描述**

> 输入一个整数  $n\left(0 \leqq n \leqq 23\right)$ ，表示区域赛的开始时间。

**输出描述**

> 输出一个整数，表示结束时刻的小时数（ $0 \leqq$  答案  $\leqq 23$ ）。

#### 示例 1

**输入**

```text
9
```

**输出**

```text
14
```

#### 示例 2

**输入**

```text
23
```

**输出**

```text
4
```

---

### 最终代码：

```cpp
#include <cstdio>
using namespace std;

// ICPC Time：比赛从 n 点开始，持续 5 小时，24 小时制取模。
int main() {
    int n;
    if (scanf("%d", &n) != 1) return 0;
    printf("%d\n", (n + 5) % 24);
    return 0;
}
```

*代码为参考实现（按题意重写并用样例验证），非本人原始提交。*

### 解题思路

第一反应是「加 5 再判断越界」，条件写出来是 n+5≥24 就减 24，两种写法都能过。但既然整场只有一次跨天，我直接写成 (n+5)%24，省掉分支也避免把大于和大于等于写错。写之前还确认了一下不需要处理分钟：题目说的是 5 小时整，开始也是整点，分钟和秒都是 0，所以只要动小时这一位。用样例验：n=9 时 14，n=23 时 28%24=4，都对得上；再想一下边界，n=19 时正好 24 取模回 0，说明取模把「恰好跨到 0 点」也覆盖了。这题在练的是把「跨天」抽象成循环节、用取模统一处理，而不是真的去模拟 5 个小时的时间流逝。

#### 卡点与关键一步

- 必须对 24 取模，n+5 可能到 28，直接输出会超过 23。
- 本题较直接，除取模外无明显卡点。
