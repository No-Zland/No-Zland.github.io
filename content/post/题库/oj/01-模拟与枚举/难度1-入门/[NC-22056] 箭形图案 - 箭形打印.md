### 知识点：

图形打印模型：菱形/箭形都能参数化为“行号 i →（缩进, 字符数）”。结论：共 2n+1 行，令 d=|i−n|，则每行 * 的个数为 n+1−d，左侧缩进为 2d（按样例第一行顶格）。推导：i=n 是中间最长的一行，有 n+1 个 *；每远离中轴一行，d 加 1，* 少一个、缩进多两个空格，直到 d=n 时只剩 1 个 *，正好收在顶点。因为上下关于 i=n 对称，一个距离变量就能同时描述上下两半，代码只有一层行循环。本题为多组输入，每组独立输出，读到 EOF 结束。

### 题目描述

> KiKi学习了循环，BoBo老师给他出了一系列打印图案的练习，该任务是打印用“*”组成的箭形图案。

**输入描述**

> 本题多组输入，每行一个整数（2~20）。

**输出描述**

> 针对每行输入，输出用“*”组成的箭形。

#### 示例 1

**输入**

```text
2
```

**输出**

```text
*
  **
***
  **
    *
```

#### 示例 2

**输入**

```text
3
```

**输出**

```text
*
    **
  ***
****
  ***
    **
      *
```

#### 示例 3

**输入**

```text
4
```

**输出**

```text
*
      **
    ***
  ****
*****
  ****
    ***
      **
        *
```

### 最终代码：

```cpp
#include <cstdio>
#include <cstdlib>

// 箭形/菱形图案：共 2n+1 行，第 i 行与中轴距离 d = |i-n|，
// 星号数 = n+1-d，缩进 = 2d；按样例第一行顶格输出。
int main() {
    int n;
    while (scanf("%d", &n) == 1) {
        for (int i = 0; i < 2 * n + 1; ++i) {
            int d = abs(i - n);
            int cnt = n + 1 - d;
            int lead = (i == 0 ? 0 : 2 * d);
            for (int k = 0; k < lead; ++k) putchar(' ');
            for (int k = 0; k < cnt; ++k) putchar('*');
            putchar('\n');
        }
    }
    return 0;
}
```

### 解题思路

我先在纸上把 n=2、3、4 的样例逐行数了一遍：行数分别是 5、7、9，正好是 2n+1；星号数从 1 递增到 n+1 再对称回落；缩进每远离中轴一行加两个空格。于是把“第几行”换成“离中轴多远”的 d，上下两半共用一个公式，不用写两段循环。第一行按样例是顶格的，其余行缩进 2d，这一点我对着三组样例的每一行都核过。多组输入用 while(scanf("%d",&n)==1) 读到 EOF，每组之间不加空行。写完先只跑出 3 行，检查发现循环上界写成了 2n−1，改成 2n+1 才和样例对上。

#### 卡点与关键一步

- 行数是 2n+1，写成 2n−1 会少最后几行
- 缩进每层 2 个空格，不是 1 个
- 多组输入要读到 EOF，别只读一组

#### 复杂度

| 项 | 值 |
|---|---|
| 时间复杂度 | O(n^2) |
| 空间复杂度 | O(1) |
