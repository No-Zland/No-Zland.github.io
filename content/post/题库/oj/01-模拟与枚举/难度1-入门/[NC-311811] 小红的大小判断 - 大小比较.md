### 知识点：

在正整数范围内，x 与 x² 的大小关系可以一次分类说完：x=1 时两者相等；x≥2 时 x²−x=x(x−1)>0，所以 x² 严格更大。也就是说「left」这一支对合法输入永远不会输出，但题面要求三路比较，代码仍按三种情况写全。真正要注意的是数据类型：x≤10^5 时 x²≤10^10，已经超出 32 位 int，必须用 64 位整数比较，否则会溢出成负数而判反。

---

### 题目描述

> 小红拿到了一个正整数  $x$ ，她希望你帮她判断  $x$  和  $x^2$  哪个更大。请你帮帮她。

**输入描述**

> 输入一个正整数  $x \left(1 \leqq x \leqq 10^5\right)$ 。

**输出描述**

> 如果  $x$  更大，输出  $\texttt{left}$ ；如果  $x^2$  更大，输出  $\texttt{right}$ ；如果两数相等，输出  $\texttt{equal}$ 。

#### 示例

**输入**

```text
3
```

**输出**

```text
right
```

---

### 最终代码：

```cpp
#include <cstdio>
using namespace std;
int main() {
    long long x;
    if (scanf("%lld", &x) != 1) return 0;
    long long sq = x * x;
    if (x > sq) puts("left");
    else if (x < sq) puts("right");
    else puts("equal");
    return 0;
}
```

### 解题思路

读完题我先把 x²−x 提出来看，它就是 x(x−1)，一眼能看出在 x≥1 时非负、只有 x=1 取 0，于是「相等」只对应 x=1，「right」对应 x≥2，「left」是理论上的死分支。第一版差点直接用 int 存平方，写到一半想到 10^5 的平方是 10^10，立刻换成 long long，避免溢出后符号翻转把答案判反。实现就是读入、求平方、三路比较、按样例输出小写单词，没有任何多余分支。

#### 卡点与关键一步

- x=1 要输出 equal，漏掉这个分支会把 1 判成 left
- x*x 必须用 64 位整数，int 在 x=10^5 时会溢出
- 输出是小写 left / right / equal，大小写必须与样例一致

#### 复杂度

| 项 | 值 |
|---|---|
| 时间复杂度 | O(1) |
| 空间复杂度 | O(1) |
