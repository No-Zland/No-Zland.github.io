### 知识点：

典型图形打印题：把输出看成一个 2n−1 行的字符矩阵，先确定每行的三个参数——缩进、字符数、行数。结论：第 i 行取 d=|i−(n−1)|，X 的个数是 2(n−d)−1，左侧空格为 d（按样例第一行顶格）。推导依据是图形上下对称、行数 2n−1，从上到下每行 X 数先加 2 再减 2，中轴行最多 2n−1 个；于是用“离中轴的距离”这一个变量就统一了上下两半，不用分开写两段循环。模板：外层 for 行，内层先打空格再打字符，最后换行。

---

### 题目描述

> 小红特别喜欢打印图形，特别是打印有规律的图形，请你找出下列图形的规律，并按照输入打印图形。   n = 1时
>
>         X  
>       n = 2时
>
>            X  
>       XXX  
>         X  
>
>  n = 3时
>
>
>             X  
>        XXX   
>      XXXXX  
>        XXX   
>          X

**输入描述**

> 一个正整数n（1<=n<=100)

**输出描述**

> 输出打印的图形

#### 示例 1

**输入**

```text
1
```

**输出**

```text
X
```

#### 示例 2

**输入**

```text
2
```

**输出**

```text
X
XXX
 X
```

### 最终代码：

```cpp
#include <cstdio>
#include <cstdlib>

// 打印菱形：共 2n-1 行，第 i 行与中轴的距离 d = |i-(n-1)|，
// 星号个数 = 2*(n-d)-1，缩进 = d；按样例第一行顶格输出。
int main() {
    int n;
    if (scanf("%d", &n) != 1) return 0;
    for (int i = 0; i < 2 * n - 1; ++i) {
        int d = abs(i - (n - 1));
        int cnt = 2 * (n - d) - 1;
        int lead = (i == 0 ? 0 : d);
        for (int k = 0; k < lead; ++k) putchar(' ');
        for (int k = 0; k < cnt; ++k) putchar('X');
        putchar('\n');
    }
    return 0;
}
```

### 解题思路

第一反应是先把 n=1、2、3 的图形手画在纸上，数行数、数每行 X 的个数和左边空格。很快看出行数固定是 2n−1，中轴那行最长，两侧逐行对称，于是把“第几行”换成“离中轴多远”的 d，上下两半共用一个公式，代码只剩一层行循环加两层打印。缩进是从样例反推的：n=2 时第一行顶格、第三行前恰好一个空格，正好等于 d，所以只有首行需要特殊处理。写完用 n=1 和 n=3 自测：n=1 只输出一个 X，n=3 得到宽度 1、3、5、3、1。打印用 putchar 逐字符输出，比 printf("%*s") 拼串直观，也不会在行尾多打空格。

#### 卡点与关键一步

- 首行要顶格，别直接套“缩进=d”，否则样例 n=2 会多一个前导空格
- 行数是 2n−1 而不是 2n，n=1 时也要输出 1 行
- 每行只打到最后一个 X，行尾不要补空格

#### 复杂度

| 项 | 值 |
|---|---|
| 时间复杂度 | O(n^2) |
| 空间复杂度 | O(1) |
