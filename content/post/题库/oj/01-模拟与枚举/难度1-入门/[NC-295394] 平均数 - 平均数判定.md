### 知识点：

结论只有三条：同时存在「严格大于平均数」和「严格小于平均数」的人时一定可行——取大于者等于 μ+1、小于者等于 μ−1、等于者等于 μ，均值恰好是 μ；只存在单侧偏离（有人严格大于却没人严格小于，或反之）时一定不可行——所有数都 ≥μ 且至少一个 >μ，均值必 >μ，与假设矛盾；全是 0（所有人等于平均数）时取所有数相同即可。所以答案只由三个计数 lt、eq、gt 是否「双侧齐全」决定，和具体数值无关，也不需要真的解方程。这类题的关键是把「存在性」转成「能否构造」，构造一旦给出就同时完成了充分性证明。

### 题目描述

> 班上有  $n$  名同学，其中每位同学都有一个数值，但是每位同学并不会告诉你这个数值为多少，他们只会告诉你这个数值是否大于 / 等于 / 小于这  $n$  个数值的平均数，具体地：
>
>  $\hspace{23pt}\bullet\,$ 若  $a_i=-1$ ，表示第  $i$  名同学的数值小于平均数；
>
>  $\hspace{23pt}\bullet\,$ 若  $a_i=0$ ，表示第  $i$  名同学的数值等于平均数；
>
>  $\hspace{23pt}\bullet\,$ 若  $a_i=1$ ，表示第  $i$  名同学的数值大于平均数。
>
> 其中平均数指的是这  $n$  个数值的平均数值（保留小数点，不四舍五入），如  $\{3,4,5,6\}$  的平均数为  $\tfrac{3+4+5+6}{4}=4.5$ 。 
>
> 但是，它们其中，有些人可能会说谎，请你检查并判断：若给定的这  $n$  个数  $a_i$  满足平均数的情况，则输出  $\text{YES}$ ，否则输出  $\text{NO}$ 。

**输入描述**

> 第一行输入一个整数  $n$   $\left ( 1\leqq n\leqq 10^5 \right )$ ，表示数组  $a$  的长度。 
> 第二行输入  $n$  个整数  $a_1,a_2,\dots,a_n$   $\left ( -1\leqq a_i\leqq 1 \right )$ ，表示每一个同学的数字与平均数的关系。

**输出描述**

> 如果给定的这  $n$  个数  $a_i$  满足平均数的情况，则输出  $\text{YES}$ ，否则输出  $\text{NO}$ 。注意输出均为大写字母。

#### 示例 1

**输入**

```text
4
0 0 0 0
```

**输出**

```text
YES
```

#### 示例 2

**输入**

```text
5
1 1 1 1 1
```

**输出**

```text
NO
```

### 最终代码：

```cpp
#include <cstdio>

int main() {
    int n;
    if (scanf("%d", &n) != 1) return 0;
    int lt = 0, eq = 0, gt = 0;
    for (int i = 0; i < n; i++) {
        int x;
        scanf("%d", &x);
        if (x < 0) lt++;
        else if (x == 0) eq++;
        else gt++;
    }
    // 有严格大于也有严格小于 -> 可构造：大的取 mu+1、小的取 mu-1、等于的取 mu
    // 只有单侧偏离（全大于或全小于）-> 平均值必然被拉偏，不可能；全等于 -> 可以
    bool ok;
    if (lt && gt) ok = true;
    else if (lt || gt) ok = false;
    else ok = true;
    puts(ok ? "YES" : "NO");
    return 0;
}
```

### 解题思路

第一反应是想设平均数为 μ，然后给每个人一个区间（比如大于者 ∈(μ,+∞)），但这看起来像线性规划，没必要。转而想「平均值一定夹在最小值和最大值之间」这个基本事实：只要有人严格在上面、有人严格在下面，均值就能落在 μ，几乎不用算。于是先试双边都存在的情况，构造出 μ+1、μ−1、μ 这组数，均值就是 μ，可行。再检查只有单边的情况：所有数都 ≥μ 且有一个严格大于，均值一定 >μ，自相矛盾，必 NO。最后补上「全是 0」这个边界，取所有数相等即可，输出 YES。写代码时只统计三个计数，不读入具体值。

#### 卡点与关键一步

- 全是 0 是 YES，别把「没有任何 -1/1」误判成 NO
- 只有 1 和 0、没有 -1 时是 NO：严格大于平均数的人存在，却没有严格小于的，均值必被拉高
- 只有 -1 和 1 而中间没人等于平均数也照样 YES，不要额外要求 0 出现

#### 复杂度

| 项 | 值 |
|---|---|
| 时间复杂度 | O(n) |
| 空间复杂度 | O(1) |
