### 知识点：

最基础的字符串遍历题：给定长度固定为 8 的 01 串，统计字符 '1' 的个数。模型就是线性扫描加一个计数器，读入、遍历、输出三步走。最需要小心的是字符与整数的区别：字符 '1' 的 ASCII 是 49，比较时必须写 s[i]=='1'，写成 s[i]==1 会永假；如果要把字符转成数值，应当写 s[i]-'0'。这类题练的是「读入 → 遍历 → 按格式输出」的完整流程和对字符类型的敏感度，而不是算法本身；因为串里没有空格，scanf("%s") 或 cin >> s 都能一次读完整个串。

---

### 题目描述

> 小 K 同学向小 P 同学发送了一个长度为 8 的 01 字符串来玩数字游戏，小 P 同学想 要知道字符串中究竟有多少个 1。 
>
> 	 注意：01 字符串为每一个字符是 0 或者 1 的字符串，如“101”（不含双引号）为一 个长度为 3 的 01 字符串。

**输入描述**

> 输入文件只有一行，一个长度为 8 的 01 字符串 s。

**输出描述**

> 输出文件只有一行，包含一个整数，即 01 字符串中字符 1 的个数。

#### 示例 1

**输入**

```text
00010100
```

**输出**

```text
2
```

#### 示例 2

**输入**

```text
11111111
```

**输出**

```text
8
```

#### 示例 3

**输入**

```text
01010101
```

**输出**

```text
4
```

---

### 最终代码：

```cpp
#include <cstdio>

// 长度为 8 的 01 串，数其中字符 '1' 的个数。
int main() {
    char s[16];
    if (scanf("%s", s) != 1) return 0;
    int cnt = 0;
    for (int i = 0; i < 8; ++i)
        if (s[i] == '1') ++cnt;
    printf("%d\n", cnt);
    return 0;
}
```

*代码为参考实现（按题意重写并用样例验证），非本人原始提交。*

### 解题思路

题目一眼看完：长度固定为 8 的 01 串，数里面有几个 1。我没用任何技巧，直接读入字符串，循环 8 次，遇到字符 '1' 计数器加一，最后输出。写的时候提醒自己两个小地方：一是比较对象必须是字符常量 '1' 而不是数字 1，否则永远不成立；二是串中没有空格，可以整体读入，不用逐字符读。三个样例正好覆盖了零散、全 1、交替三种情况，跑出来是 2、8、4，与期望一致。这题本身没什么可优化的，真正值得记的是这个「固定长度 + 逐字符统计」的模板，后面很多统计类题目都是它的放大版，只要把长度换成 |s| 即可。

#### 卡点与关键一步

- 比较要用字符 '1'，别写成数字 1（ASCII 49，条件会恒假）
- 循环边界按题目给定的 8 走，别用 sizeof(s) 之类
- 输出只有一行一个整数，不要多打印提示语或空行

#### 复杂度

| 项 | 值 |
|---|---|
| 时间复杂度 | O(1) |
| 空间复杂度 | O(1) |
