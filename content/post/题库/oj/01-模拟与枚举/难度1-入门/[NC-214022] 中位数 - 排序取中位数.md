### 知识点：

中位数的定义：把 n 个数升序排序后，n 为奇数取正中间那个（0 基下标 n/2），n 为偶数取中间两个数的算术平均。所以这题的算法部分只有一次 sort，真正的考点是把定义与输出格式写对。输出要求是：结果是整数就直接输出整数，是小数才保留两位小数。因此既不能无脑 printf 两位小数（会把 3 打成 3.00，与样例 3 不符），也不能无脑取整。稳妥做法是排序后算出中位数（偶数时可能是 .5），用 llround 取最近整数，若与它相差小于 1e-9 说明是整数，按整数输出，否则按两位小数输出。题面只说'数字'没限定整数，用 double 存可以同时兼容小数输入；n ≤ 100，规模上怎么写都行。

### 题目描述

> 今天又是开心的一天，WYJ决定吃一顿好的（划掉）和LK一起van游戏
>  游戏规则如下：
>  WYJ给出N个数字，LK要找出N个数字的中位数。
>  要是能找出中位数，WYJ就请LK吃饭，否则LK就要请WYJ吃饭，但是LK从小不好好学习，不知道中位数是什么，并且LK很小气，一听到要请吃饭，立马抓住在一旁吃瓜的你。
>  现在请你来和WYJ一起van游戏

**输入描述**

> 第一行输入一个数N用来表示数组的长度（N<=100）
> 第二行输入N个数字，并以一个空格隔开

**输出描述**

> 输出N个数字的中位数，若为小数则保留两位小数，若为整数则直接输出

#### 示例 1

**输入**

```text
5

```

**输出**

```text
3
```

#### 示例 2

**输入**

```text
8
1 6 4 7 8 2 3 5
```

**输出**

```text
4.50
```

#### 示例 3

**输入**

```text
8
4 1 6 5 8 9 16 10
```

**输出**

```text
7
```

### 最终代码：

```cpp
#include <iostream>
#include <vector>
#include <algorithm>
#include <cmath>
#include <cstdio>
using namespace std;

int main() {
    int n;
    if (!(cin >> n)) return 0;
    vector<double> a(n);
    for (int i = 0; i < n; ++i) cin >> a[i];
    sort(a.begin(), a.end());

    double mid;
    if (n % 2 == 1) mid = a[n / 2];
    else mid = (a[n / 2 - 1] + a[n / 2]) / 2.0;

    long long r = llround(mid);
    if (fabs(mid - (double)r) < 1e-9) printf("%lld\n", r);  // 整数直接输出
    else printf("%.2f\n", mid);                             // 小数保留两位
    return 0;
}
```

### 解题思路

这题读完就知道主体是排序，五分钟能写完，真正让我停顿的是输出格式。样例里 1..8 的中位数 4.5 输出 4.50，而 6 和 8 的平均 7 却输出 7 而不是 7.00——也就是说题目要求'整数原样输出、小数保留两位'，这必须显式判断。我的做法是排序后按奇偶取出中位数，偶数情况求和后除以 2.0，然后看它离最近整数是否足够近：差小于 1e-9 就按整数打印，否则打印两位小数。数组用 double 而不是 int，是因为题面只写了'数字'，万一出现小数也不会读崩。样例逐个手验：5 个数排序后下标 2 是 3，输出 3；8 个数中间是 4 和 5，平均 4.5，输出 4.50；第三组中间是 6 和 8，平均 7，判成整数输出 7。三组全对。

#### 卡点与关键一步

- 偶数个元素时要取中间两个的平均值，只取其中一个会 WA
- 输出要分两种情况：整数不能打成 7.00，小数必须两位（4.5 → 4.50）
- 必须先排序再取中间，按输入顺序直接取下标是错的

#### 复杂度

| 项 | 值 |
|---|---|
| 时间复杂度 | O(n log n) |
| 空间复杂度 | O(n) |
