### 知识点：

考的是把 ICPC 的罚时规则原文翻译成一个公式，属于规则模拟题。结论：本题最终状态为 Accepted 时罚时 = t + (n − 1) × 20；为 Rejected 时罚时 = 0。推导：题面保证不会在通过之后再次提交，所以最后一次提交就是首次通过，第 n 次之前的 n − 1 次提交必然全部是错误提交，按规则每次计 20 分钟；首次通过的分钟数恰好是最后那次提交的时刻 t，两项相加即为本题罚时。Rejected 时规则写明该题罚时记 0，前面错多少次都不计，也不能把 t 算进去。实现上只需判断读入的字符串是否等于 Accepted，再套对应公式。

### 题目描述

> 在  $\rm ICPC$  国际大学生程序设计竞赛的规则中，队伍的排名是以：题目的通过数量、队伍的总罚时来计算得到的。首先通过题目数量多的队伍靠前，如果题数一样，则总罚时少的队伍更靠前。（罚时的单位为分钟。） 
>
> 在本题中我们只考虑罚时。
>
> 而总罚时等于所有题目的罚时之和，每道题的罚时则为：
>
>  $\hspace{23pt}1.$  如果这道题最终通过了，首次通过该题时的分钟数 + 首次通过本题之前的错误提交数  $\times 20$ 。
>
>  $\hspace{23pt}2.$  否则这道题最终也没有通过，则本题的罚时为  $0$ 。
>
> 例如小红的队伍在某场比赛的第  $276$  分钟首次通过了一道题，在此之前这道题已经尝试了  $8$  次均未通过，本次（也就是第  $9$  次提交）通过了此题，则此题的罚时为： $276+8\times 20=436$ 。
>
> 现在已知在一场区域赛的  $\rm A$  题中，小苯的队伍提交了  $n$  次，并且最后一次提交的时刻为  $t$  分钟，并且本题最终的状态为  $\texttt{Accepted}$ （通过） 或  $\texttt{Rejected}$ （未通过），且小苯的队伍如果通过了  $\rm A$  题，则必然是最后一次提交通过的此题，也就是说小苯的队伍不会在通过此题后再次提交。
>
> 你的任务就是确定小苯队伍的  $\rm A$  题产生的罚时。

**输入描述**

> 第一行输入一个字符串  $s$ ，表示小苯队伍  $\rm A$  题最终的结果。（保证  $s=\texttt{"Accepted"}$  或  $s=\texttt{"Rejected"}$ ）
>
> 第二行两个整数  $n, t\ (1 \leqq n \leqq 100, 1 \leqq t \leqq 300)$ ，分别表示小苯队伍在  $\rm A$  题的提交数量和最后一次提交的时刻（单位：分钟）。

**输出描述**

> 在单独的一行输出一个整数，表示本场比赛中，小苯的队伍里  $\rm A$  题产生的罚时。

#### 示例 1

**输入**

```text
Accepted
9 276
```

**输出**

```text
436
```

#### 示例 2

**输入**

```text
Rejected
9 276
```

**输出**

```text
0
```

### 最终代码：

```cpp
// NC305093 ICPC Penalty
// 题目：n 次提交，最后一次在 t 分钟，最终状态 Accepted / Rejected，求本题罚时。
// 结论：Accepted => t + (n-1)*20；Rejected => 0。
#include <iostream>
#include <string>

using namespace std;

int main() {
    string s;
    long long n, t;
    cin >> s;
    cin >> n >> t;
    if (s == "Accepted")
        cout << t + (n - 1) * 20 << '\n';
    else
        cout << 0 << '\n';
    return 0;
}
```

### 解题思路

这是纯规则翻译的签到题，读完就知道不要想算法，重点是别把定义读错。我的第一反应是先把「错误提交次数」这个量钉死：题面说通过一定是最后一次、且通过后不再提交，那么前 n − 1 次提交全部是未通过的，错误次数就是 n − 1，不需要任何额外统计。再确认「分钟数」取哪个：规则说用首次通过该题时的分钟数，而首次通过就是最后一次，直接取 t。代进样例 276 + 8 × 20 = 436，正好对上，说明这两个量的取法没理解偏。第二组是 Rejected 分支，规则明确该题罚时记 0，所以直接输出 0，绝不能顺手把 t 也加上去。字符串比较我用整串 ==，注意 Accepted / Rejected 的拼写和大小写都照抄题面，不要自己缩写成 AC。

#### 卡点与关键一步

- 别把「提交次数 n」当成错误次数，错误次数是 n − 1
- Rejected 时输出 0，不能把最后提交时刻 t 也计入
- 字符串要和 Accepted / Rejected 严格匹配，大小写、拼写错一个字符就走错分支
