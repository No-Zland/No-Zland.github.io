### 知识点：

字符串去前导零的标准模型：找到第一个不是 '0' 的位置 p，从 p 开始输出到结尾。因为题意保证 s 表示的数值是正整数，所以 p 一定存在（除非 s 形如 "000"，这在题面数据里不会出现，但作为防御性分支补一个输出 "0" 更稳）。全程按字符处理，不做数值转换：即使本题 value≤10^9 可以塞进 int，字符串做法也才是这类题的通解，且天然不受长度影响。

---

### 题目描述

> 红美铃负责红魔馆的门卫工作。为了向大小姐汇报，她每天都会记录来访者的总数。
>
> 由于美铃在登记簿上预留了固定的格子，当访客数量较少时，她会在数字前面填充若干个  $\texttt{0}$  来补齐位数。例如，如果访客只有  $9$  人，她可能会记录为  $\texttt{009}$ 。现在，美铃需要将这些记录整理成标准的正整数格式，即去掉所有无意义的前导零（leading zeros）。
>
> 给定一个表示正整数的字符串  $s$ ，请你帮美铃输出其去掉前导零后的结果。

**输入描述**

> 在一行上输入一个长度为  $\textrm{length}(s)$ 、仅由数字字符组成的字符串  $s \left(1 \leqq \textrm{length}(s) \leqq 100\right)$ 。保证字符串  $s$  所代表的数值  $\textrm{value}(s)$  为正整数，且满足  $1 \leqq \textrm{value}(s) \leqq 10^9$ 。

**输出描述**

> 输出一个整数，表示去掉前导零后的整数形式。

#### 示例 1

**输入**

```text
009
```

**输出**

```text
9
```

#### 示例 2

**输入**

```text
20260208
```

**输出**

```text
20260208
```

### 最终代码：

```cpp
#include <iostream>
#include <string>
using namespace std;
int main() {
    string s;
    if (!(cin >> s)) return 0;
    size_t p = s.find_first_not_of('0');
    // 棰樼洰淇濊瘉鏁板€间负姝ｆ暣鏁帮紝鏁?p 涓€瀹氬瓨鍦紱淇濋櫓璧疯澶勭悊鍏ㄩ浂
    if (p == string::npos) cout << 0 << '\n';
    else cout << s.substr(p) << '\n';
    return 0;
}
```

### 解题思路

我第一反应是不能先 stoi 再输出——那样遇到长度 100 的串题面虽说不出现，但思路就错了；正确做法是纯粹按字符扫描。于是直接用 string 的 find_first_not_of('0') 拿到第一个非零字符的下标 p，再输出 s.substr(p)。顺手补了 p==npos 时输出 0 的分支，因为题目只说保证是正整数，把边界写死一点不亏。第二组样例 20260208 正好验证了「中间和末尾的 0 都要保留」这一点。

#### 卡点与关键一步

- 只删开头的 0，串中间和末尾的 0 必须原样保留
- 全为 0 时要输出单个 0，不能输出空串（本题保证正整数，仍建议留这个分支）
- 不要用整数读入再打印，问题要求的是字符串整理

#### 复杂度

| 项 | 值 |
|---|---|
| 时间复杂度 | O(|s|) |
| 空间复杂度 | O(|s|) |
