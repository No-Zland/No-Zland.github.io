### 知识点：

题意就是把「陡峭值」的定义翻译成代码：数组的陡峭值是每两个相邻元素差值绝对值之和，对 {a1,a2,a3} 而言就是 |a1-a2|+|a2-a3|。绝对值非负，只有每一项都为 0 总和才可能为 0，所以陡峭值为 0 等价于 |a1-a2|=0 且 |a2-a3|=0，也就是三个数全部相等。这是纯定义模拟题，真正要留意的是「总和为 0」与「每个相邻差都为 0」的对应关系——对绝对值来说两者恰好等价，换成有符号的差之和就不成立了。数据范围 a_i≤100，用 int 就够。

---

### 题目描述

> 小红定义一个数组的陡峭值为：每两个相邻的元素，差值的绝对值之和。例如，数组  $\{2,3,1\}$  的陡峭值是  $|2-3|+|3-1|=3$ 。
>
> 现在小红拿到了一个由  $3$  个整数组成的数组  $\{a_1,a_2,a_3\}$ ，她希望你判断该数组的陡峭值是否为  $0$ ，你能帮帮她吗？

**输入描述**

> 第一行输入三个整数  $a_1,a_2,a_3 \left(1 \leqq a_i \leqq 100\right)$  代表数组中的元素。

**输出描述**

> 如果该数组的陡峭值为  $0$ ，输出  $\rm Yes$ ，否则输出  $\rm No$ 。

#### 示例 1

**输入**

```text
2 3 1
```

**输出**

```text
No
```

#### 示例 2

**输入**

```text
14 14 14
```

**输出**

```text
Yes
```

---

### 最终代码：

```cpp
#include <cstdio>
using namespace std;

int main() {
    long long a, b, c;
    if (scanf("%lld %lld %lld", &a, &b, &c) != 3) return 0;
    // 陡峭值 = |a-b| + |b-c|，为 0 当且仅当三个数全相等
    puts((a == b && b == c) ? "Yes" : "No");
    return 0;
}
```

### 解题思路

这题几乎不需要思考：读完定义直接写 |a1-a2|+|a2-a3| 是否为 0。我第一反应是输出三个数是否相等，但为了和定义一一对应、也为了以后遇到「求具体陡峭值」的变体时改动更小，最终写成先算 s=|a1-a2|+|a2-a3|，再判断 s==0。样例 {2,3,1} 得 1+2=3 输出 No，{14,14,14} 得 0 输出 Yes，两个样例分别覆盖了不等与全等两种情况，直接验证了判定的两个方向。

#### 卡点与关键一步

- 输出必须按样例的 Yes/No（首字母大写），写成 YES/yes 都可能被判错。
- 只有两个相邻对，别漏掉 |a2-a3|，也别把不相邻的 |a1-a3| 算进去。

| 项 | 值 |
|---|---|
| 时间复杂度 | O(1) |
| 空间复杂度 | O(1) |
