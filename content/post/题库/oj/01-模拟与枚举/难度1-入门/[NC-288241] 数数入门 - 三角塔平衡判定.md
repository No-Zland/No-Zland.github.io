### 知识点：

这题考三角形二维数组上的相邻约束校验，模型是“每个元素都不大于它下方两个支撑位”，逐个元素做 O(1) 校验即可。结论：塔平衡当且仅当对所有 1<=i<n、1<=j<=i 都有 a[i][j] <= a[i+1][j] 且 a[i][j] <= a[i+1][j+1]。实现上不必存下整座塔，只需滚动保留上一层：读第 i 层时，用上一层的第 j 个元素去和本层第 j、j+1 个元素比较，边界是 j 从 1 到 i-1。数据范围上单个文件 n 之和不超过 1e3，总元素数最多约 5×10^5，逐元素比较完全够用。

### 题目描述

> 好吧，麻将这些东西对于还不认识数字的小猫咪有些太难了，Askalana 决定从一些简单易懂的方面开始教她。
>
> Askalana 搭建了一个  $n$  层的麻将塔。从上往下数，第  $i$  层由  $i$  块麻将组成。每一块麻将上面都刻了一个整数，记第  $i$  层从左往右数第  $j$  块麻将上的数字为  $a_{i,j}$ 。如下所示：
>
> 	 $\begin{array}{c}
> a_{1,1}\\ 
> a_{2,1} \hspace{20pt} a_{2,2} \\ 
> a_{3,1} \hspace{20pt} a_{3,2} \hspace{20pt} a_{3,3} \\
> \vdots \hspace{35pt} \vdots \hspace{35pt} \vdots \hspace{35pt} \vdots \\ 
> a_{n,1} \hspace{23pt} a_{n,2} \hspace{23pt} \cdots \hspace{23pt} a_{n,n} 
> \end{array}$ 
>
> 除最下层外，每块麻将的左、右两角分别由其两块麻将支撑；如果一座麻将塔中，每一块麻将左下、右下支撑它的麻将上的整数均不小于它自身，那么称这座麻将塔是“平衡的”。更具体地，对于任意的  $a_{i,j} \left(1 \leqq i \lt n;\ 1 \leqq j \leqq i\right)$ ，若都有  $a_{i, j} \leqq a_{i+1, j}$  且  $a_{i, j} \leqq a_{i+1, j+1}$ ，那么这座麻将塔是“平衡的”。否则该麻将塔就会倒塌，而猫猫小姐因为没学会也没有她的小鱼干吃。
>
> 作为来 Askalana 家撸猫的你当然不想看到可爱的猫猫因为吃不到小鱼干哭啦，请帮帮她判断一下麻将塔是否是“平衡的”吧~

**输入描述**

> 每个测试文件均包含多组测试数据。第一行输入一个整数  $T\left(1\leqq T\leqq 10^3\right)$  代表数据组数，每组测试数据描述如下：
> 第一行输入一个正整数  $n \left(1\leqq n \leqq 10^3\right)$  代表麻将塔的层数。
> 此后  $n$  行，第  $i$  行输入  $i$  个正整数  $a_{i,1}, a_{i,2}, \dots, a_{i,i} \left(1\leqq a_{i,j} \leqq 9\right)$  表示麻将塔第  $i$  层从左到右的麻将数值。
>
> 除此之外，保证单个测试文件的  $n$  之和不超过  $10^3$ 。

**输出描述**

> 对于每一组测试数据，新起一行。如果麻将塔平衡，输出  $\rm Yes$ ，否则输出  $\rm No$ 。您可以以任何大小写形式输出答案，例如， $\rm yEs$ 、 $\rm yes$  和  $\rm YeS$  都将被视为肯定的回答。

#### 示例

**输入**

```text
2
4
1
2 3
4 5 6
7 8 9 9
4
9
9 8
7 6 5
4 3 2 1
```

**输出**

```text
Yes
No
```

### 最终代码：

```cpp
// NC288241 数数入门
// 题意：n 层三角塔，第 i 层有 i 个数。平衡要求每个 a[i][j] <= a[i+1][j] 且 <= a[i+1][j+1]。
// 做法：逐层读入，读第 i 层时用上一层（i-1 个数）校验所有支撑关系，任一处不满足即标记 No。
#include <cstdio>

const int MAXN = 1005;
int prevRow[MAXN], curRow[MAXN];

int main() {
    int T;
    if (scanf("%d", &T) != 1) return 0;
    while (T--) {
        int n;
        scanf("%d", &n);
        bool ok = true;
        for (int i = 1; i <= n; ++i) {
            for (int j = 1; j <= i; ++j) scanf("%d", &curRow[j]);
            // 上一层第 j 块必须被本层的 j、j+1 两块托住，且都不小于它
            if (i > 1) {
                for (int j = 1; j <= i - 1; ++j) {
                    if (prevRow[j] > curRow[j] || prevRow[j] > curRow[j + 1]) ok = false;
                }
            }
            for (int j = 1; j <= i; ++j) prevRow[j] = curRow[j];
        }
        printf(ok ? "Yes\n" : "No\n");
    }
    return 0;
}
```

### 解题思路

一眼看出这是行与行之间的比较：每个数不能大于它下面托着它的两个数。于是我的思路是滚动两行——读入当前层后立刻拿上一层做判断，判完再把当前层覆盖成上一层，空间只有 O(n)。第一版我把下标写错了，拿本层相邻元素去比较（同层比较），和题目要求的层间约束对不上；改成 prev[j] 与 cur[j]、cur[j+1] 比较、j 取 1 到 i-1 之后才对上样例。另一个细节是：即使已经判出不平衡，也必须把这一组数据全部读完，否则下一组会读错位，所以我是用 bool 标记而不是提前 break。样例第一组递增塔输出 Yes、第二组倒塔输出 No，正好验证了这两个方向。

#### 卡点与关键一步

- 约束是“上一层元素 <= 下一层两个支撑位”，不要写成同层相邻元素的比较。
- 判出 No 之后仍要把当前测试数据读完，否则残留输入会让后续用例错位。
- 第 1 层只有一个数，没有支撑关系，循环要从 i==2 开始判。

#### 复杂度

| 项 | 值 |
|---|---|
| 时间复杂度 | O(Σ n_i^2) |
| 空间复杂度 | O(n) |
