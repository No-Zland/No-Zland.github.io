### 知识点：

结论：只有四种候选值 A+B、A−B、A×B、A/B，逐一和 C 比较，任意一种相等就输出 YES。唯一有前提的是除法：题目要求 A 能被 B 整除且结果为整数，所以必须先判 A%B==0，再比较 A/B==C，不能直接用整数除法。B≥1 保证了不会除零；A−B 可能为 0 或负数，而 C 是正整数，直接比较不会误判。数据范围只有 10，四种运算全枚举即可，不需要任何优化。

---

### 题目描述

> 小白月赛起步早但频率低
>
> 牛客周赛起步晚但频率高
>
> 终于，在  $2026$  年  $1$  月中下旬的周末，两者产生了交集， $\rm Round127$  真是个神秘的场次呢...
>
>
>
> 	小苯有三个正整数  $A,B,C$ ，他可以使用恰好一次四则运算（加法、减法、乘法、除法）将  $A$  和  $B$  组合起来，得到一个新的整数。
>
> 具体来说，四种操作如下：
>
>  $\hspace{23pt}1.\ A + B$ 
>
>  $\hspace{23pt}2.\ A - B$ 
>
>  $\hspace{23pt}3.\ A \times B$ 
>
>  $\hspace{23pt}4.\ A \div B$ （仅当  $A$  能被  $B$  整除时，注意：除法必须保证能整除，且结果仍为整数。）
>
> 你的任务就是判断  $C$  是否等于上面四个算式之一的结果。

**输入描述**

> $\hspace{23pt}$ 一行三个正整数  $A,B,C\ (1 \leq A,B,C \leq 10)$ 。

**输出描述**

> 如果  $C$  可以通过一次四则运算得到，输出一行  $\texttt{"YES"}$ ，否则输出一行  $\texttt{"NO"}$ 。

#### 示例 1

**输入**

```text
3 5 8
```

**输出**

```text
YES
```

#### 示例 2

**输入**

```text
10 2 5
```

**输出**

```text
YES
```

#### 示例 3

**输入**

```text
10 2 6
```

**输出**

```text
NO
```

### 最终代码：

```cpp
#include <cstdio>

// 枚举四种运算，判断是否恰好有一种结果等于 C。
// 注意除法要求 A % B == 0，且 B 至少为 1，不会出现除零。
int main() {
    long long A, B, C;
    if (scanf("%lld %lld %lld", &A, &B, &C) != 3) return 0;
    bool ok = (A + B == C) || (A - B == C) || (A * B == C) ||
              (A % B == 0 && A / B == C);
    printf("%s\n", ok ? "YES" : "NO");
    return 0;
}
```

*代码为参考实现（按题意重写并用样例验证），非本人原始提交。*

### 解题思路

第一反应是这题范围极小，四个 if 直接枚举最稳。真正需要小心的是除法：题面明确说只有整除时除法才算一种操作，如果写成 A/B==C，像 7/2 会被截断成 3，可能误判成 YES。所以除法条件写成 A%B==0 && A/B==C，其余三种照抄。另一个细节是 A−B 在 A<B 时为负，但 C≥1，比较自然为假，不用额外特判。四个条件用 || 连接，命中任意一个就输出 YES。最后用样例 10 2 5 验证除法分支、10 2 6 验证全不满足的分支，都能对上。

#### 卡点与关键一步

- 除法必须先判整除，不能直接做整数除法
- A−B 可能为负，别用无符号类型存储
- 输出是全部大写的 YES / NO

| 项 | 值 |
|---|---|
| 时间复杂度 | O(1) |
| 空间复杂度 | O(1) |
