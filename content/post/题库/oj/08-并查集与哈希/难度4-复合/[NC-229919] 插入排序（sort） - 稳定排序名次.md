### 知识点：

结论：题面给出的插入排序只在 a[j] < a[j-1] 时交换相邻两项，相等不换，所以它是稳定排序；因此 a_x 排序后的位置 = 1 + 满足 (a_y,y) 字典序小于 (a_x,x) 的 y 的个数，也就是「比它小的个数」加「值相等但下标更小的个数」。这就是稳定排序下的名次公式：小于它的元素全排在它前面，等于它的元素按原下标定先后。实现上把所有 (值,下标) 二元组放进一棵支持 order_of_key 的有序集合（pbds 的 tree），查询时数比 (a_x,x) 小的二元组个数，O(log n)；修改时删旧二元组、插新二元组，同样 O(log n)。等价写法是树状数组统计严格小于，再为每个值维护一个下标有序表。

### 题目描述

> 插入排序是一种非常常见且简单的排序算法。小 $Z$ 是一名大一的新生，今天 $H$ 老师刚刚在上课的时候讲了插入排序算法。
>  假设比较两个元素的时间为 $O(1)$ ，则插入排序可以以 $O(n^2)$ 的时间复杂度完成长度为n 的数组的排序。不妨假设这 $n$ 个数字分别存储在 $a_1, a_2, · · · , a_n$ 之中，则如下伪代码给出了插入排序算法的一种最简单的实现方式：
>    这下面是C/C++ 的示范代码 
>
> ```
> for (int i = 1; i <= n; i++)
>   for (int j = i; j>=2; j‐‐)
>    if ( a[j] < a[j‐1] ){
>        int t = a[j‐1];
>        a[j‐1] = a[j];
>        a[j] = t;
>    }
> ```
>  这下面是Pascal 的示范代码 
>
> ```
> for i:=1 to n do
>    for j:=i downto 2 do
>     if a[j]<a[j‐1] then
>      begin
>       t:=a[i];
>       a[i]:=a[j];
>       a[j]:=t;
>     end;
> ```
>          为了帮助小  $Z$  更好的理解插入排序，小  $Z$ 的老师  $H$ 老师留下了这么一道家庭作业：    
>
>         $H$ 老师给了一个长度为 $n$ 的数组 $a$ ，数组下标从 $1$ 开始，并且数组中的所有元素均为非负整数。小  $Z$  需要支持在数组 $a$ 上的 $Q$ 次操作，操作共两种，参数分别如下：   
>
>
>
>         $1$   $x v$ : 这是第一种操作，会将 $a$ 的第 $x$ 个元素，也就是 $a_x$ 的值，修改为 $v$ 。保证 $1≤x≤n,1≤v≤10^9$ 。 注意这种操作会改变数组的元素， 修改得到的数组会被保留， 也会影响后续的操作。   
>
>         $2$   $x$ : 这是第二种操作，假设 H 老师按照上面的伪代码对 $a$ 数组进行排序，你需要告诉  $H$ 老师原来 $a$ 的第 $x$ 个元素，也就是 $a_x$ ，在排序后的新数组所处的位置。保证 $1≤x≤n$ 。 注意这种操作不会改变数组的元素， 排序后的数组不会被保留， 也不会影响后续的操作 。   
>
>
>
>
>
>
>
>       $H$ 老师不喜欢过多的修改，所以他保证类型 $1$ 的操作次数不超过 $5000$ 。   
>
>      小 $Z$ 没有学过计算机竞赛，因此小  $Z$  并不会做这道题。他找到了你来帮助他解决这个问题。  
>
>
>  sort.zip

**输入描述**

> 输入的第一行包含两个正整数 $n, Q$ ，表示数组长度和操作次数。保证 $1≤n≤8,000,1≤Q≤2×10^5$ 。
>
> 输入的第二行包含 $n$ 个空格分隔的非负整数，其中第 $i$ 个非负整数表示 $a_i$ 。保证 $1≤a_i≤10^9$ 。
>
> 接下来 $Q$ 行，每行 $2∼3$ 个正整数，表示一次操作，操作格式见题目描述。

**输出描述**

> 对于每一次类型为 $2$ 的询问，输出一行一个正整数表示答案。

#### 示例

**输入**

```text
3 4
3 2 1
2 3
1 3 2
2 2
2 3
```

**输出**

```text
1
1
2
```

### 最终代码：

```cpp
// NC229919 插入排序（sort）
// 题面给出的插入排序只在 a[j] < a[j-1] 时交换相邻两项，是稳定排序。
// 所以 a_x 排序后的位置 = 1 + 满足 (a_y, y) 字典序小于 (a_x, x) 的 y 的个数。
// 用 pbds 有序集合维护全部 (值, 下标) 二元组，order_of_key 直接给出该计数。
#include <cstdio>
#include <vector>
#include <utility>
#include <ext/pb_ds/assoc_container.hpp>
#include <ext/pb_ds/tree_policy.hpp>

typedef std::pair<long long, int> PII;
typedef __gnu_pbds::tree<PII, __gnu_pbds::null_type, std::less<PII>,
                         __gnu_pbds::rb_tree_tag,
                         __gnu_pbds::tree_order_statistics_node_update> ordered_set;

int main() {
    int n, Q;
    if (scanf("%d %d", &n, &Q) != 2) return 0;
    std::vector<long long> a(n + 1);
    ordered_set st;
    for (int i = 1; i <= n; ++i) {
        scanf("%lld", &a[i]);
        st.insert(PII(a[i], i));
    }
    while (Q--) {
        int op;
        scanf("%d", &op);
        if (op == 1) {
            int x;
            long long v;
            scanf("%d %lld", &x, &v);
            st.erase(PII(a[x], x));
            a[x] = v;
            st.insert(PII(v, x));
        } else {
            int x;
            scanf("%d", &x);
            printf("%d\n", (int)st.order_of_key(PII(a[x], x)) + 1);
        }
    }
    return 0;
}
```

### 解题思路

最直接的做法是每次询问都跑一遍插入排序，n≤8000、Q≤2×10^5，O(n²Q) 必爆，所以得先搞清「位置由什么决定」。我盯着伪代码看：只有 a[j] < a[j-1] 才交换，相等时两个元素永远不动——这一条就是整个解法的钥匙，说明它是稳定排序。于是 a_x 的位置 = 比它小的元素个数 + 和它相等但排在它前面的元素个数 + 1。这两个条件能合并成一个字典序比较：把每个元素写成 (值, 下标)，比 (a_x,x) 小的个数就是答案减一。我用 pbds 的有序集合维护全部二元组，order_of_key 直接给出计数，改点就是删旧插新。样例 3 2 1 里询问下标 3（值 1）时计数为 0，答案 1 ✓；改成 3 2 2 后问下标 2 得 1、问下标 3 得 2 ✓，正好验证了稳定性。

#### 卡点与关键一步

- 漏掉稳定性：值相等时按原下标排，只数「严格小于」会少算前面相等的元素
- 有序集合的键必须带下标，只用 multiset<值> 区分不了同值元素的名次
- 修改时要先 erase 旧的 (a[x],x) 再 insert 新值；也别每次询问重新排序，n≤8000、Q≤2×10^5 时单次 O(n log n) 就会超时

#### 复杂度

| 项 | 值 |
|---|---|
| 时间复杂度 | O((n+Q) log n) |
| 空间复杂度 | O(n) |
