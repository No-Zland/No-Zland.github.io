### 知识点：

把邻居距离按位拆开：设第 j 列有 c_j 个 1，则第 i 串在第 j 位的贡献是「自己是 1 时 n−c_j，自己是 0 时 c_j」。翻转区间 [l,r] 等价于在增量数组 δ 上取一个子段和，问题化成「最小子段和」，用 Kadane 一遍扫完，并且要把空段（不操作）也算进去。注意 δ 要减掉自己这一串：s_i 为 1 时翻转后该位贡献是 c_j−1，为 0 时是 n−c_j−1。预处理列计数是 O(nm)，之后每串 O(m)。

### 题目描述

> 小苯有  $n$  个长度为  $m$ ，仅由字符  $\texttt{0}$  和  $\texttt{1}$  组成的字符串  $s_1, s_2, \dots, s_n$ 。全部下标均从  $1$  开始。
>
> 定义两个字符串  $u$  和  $v$  的差异度为它们对应位置字符不同的数量，即：
>
>
>
>  $\displaystyle\text{diff}(u, v) = \Big\lvert\{k : u_k \neq v_k\}\Big\rvert = \sum_{k=1}^m [u_k \neq v_k]$ 
>
> 对于第  $i$  个字符串  $s_i$ ，小苯定义其邻居距离为  $s_i$  与所有其他字符串的差异度之和：
>
>
>
>  $\displaystyle D_i = \sum_{j=1, j \neq i}^n \text{diff}(s_i, s_j)$ 
>
> 现在，小苯每一次在求  $D_i$  之前，都可以独立地对  $s_i$  进行一次操作（当然也可以不操作）：选择当前字符串的一个区间  $[l_i, r_i]\ (1 \leqq l_i \leqq r_i \leqq m)$ ，然后将  $s_i$  的第  $l_i$  到第  $r_i$  个字符进行 01 反置。
>
> 你的任务就是对于每个  $i\left(1 \leqq i \leqq n\right)$ 求出：对  $s_i$  进行最优操作后，能得到的最小邻居距离。
>
> 【名词解释】
>
> 本题公式中的大括号代表艾弗森括号，具体地， $[P] = \begin{cases} 1 & \text{如果 } P \text{ 为真} \\ 0 & \text{如果 } P \text{ 为假} \end{cases}$ 。
>
> 01 反置：同时将字符串中的  $\texttt{0}$  变成  $\texttt{1}$ ， $\texttt{1}$  变成  $\texttt{0}$ 。

**输入描述**

> 每个测试文件包含多组测试数据。第一行输入一个整数  $T\left(1 \leqq T \leqq 100\right)$  代表数据组数，每组测试数据描述如下：
>  $\hspace{23pt}\bullet\,$ 第一行输入两个整数  $n, m\left(2 \leqq n \leqq 2 \times 10^3;\, 1 \leqq m \leqq 2 \times 10^3\right)$ ，表示字符串的数量、字符串长度。
>  $\hspace{23pt}\bullet\,$ 此后  $n$  行，第  $i$  行输入一个长度为  $m$ ，仅由  $\texttt{0}$  和  $\texttt{1}$  组成的字符串  $s_i$ ，表示第  $i$  个字符串。
> 除此之外，保证单个测试文件的  $n \times m$  之和不超过  $4 \times 10^6$ 。

**输出描述**

> 对于每一组测试数据，一共  $n$  行，第  $i$  行输出一个整数，表示字符串  $s_i$  操作后的最小邻居距离。

#### 示例

**输入**

```text
1
3 4
0000
1111
0101
```

**输出**

```text
2
2
4
```

### 最终代码：

```cpp
#include <cstdio>
#include <vector>
#include <string>
#include <algorithm>
using namespace std;

int main() {
    int T;
    if (scanf("%d", &T) != 1) return 0;
    while (T--) {
        int n, m;
        scanf("%d %d", &n, &m);
        vector<string> s(n);
        for (int i = 0; i < n; i++) {
            static char buf[2005];
            scanf("%s", buf);
            s[i] = buf;
        }
        vector<int> c(m, 0);                    // 每一列 1 的个数
        for (int i = 0; i < n; i++)
            for (int j = 0; j < m; j++)
                if (s[i][j] == '1') c[j]++;

        for (int i = 0; i < n; i++) {
            long long base = 0;
            for (int j = 0; j < m; j++)        // 原串的邻居距离
                base += (s[i][j] == '1') ? (n - c[j]) : c[j];
            // 翻转第 j 位的增量 delta_j：
            // s=1: 该位贡献 n-c_j 变成 c_j-1   -> 2c_j-n-1
            // s=0: 该位贡献 c_j   变成 n-c_j-1 -> n-2c_j-1
            long long best = 0, cur = 0;        // 允许不操作（空区间）
            for (int j = 0; j < m; j++) {
                long long d = (s[i][j] == '1') ? (2LL * c[j] - n - 1)
                                               : (n - 2LL * c[j] - 1);
                cur = min(d, cur + d);          // 最小子段和（Kadane）
                best = min(best, cur);
            }
            printf("%lld\n", base + best);
        }
    }
    return 0;
}
```

### 解题思路

我第一反应是枚举区间再重算差异，但 m 到 2000，区间 O(m²)、每次重算 O(nm)，必然超时。于是想能不能把「差异度之和」拆成按位独立求和——固定第 j 列，全体的 1 的个数 c_j 是公共信息，s_i 在这一位的贡献只取决于自己是不是 1，这就是能预处理的量，也是这题的关键观察。按位拆完后，翻转一个区间对总和的改变就是一段连续增量之和，于是对每个 i 只需在 δ 上求最小子段和，Kadane 一次扫描即可，还要与 0 取 min 表示「可以不操作」。推到公式时我在 s_i=1 的分支漏减了自己，导致样例偏大，回头用暴力对拍才把 −1 补上。

#### 卡点与关键一步

- 增量公式要减掉自身：s_i 为 1 时该位翻转后贡献是 c_j−1 而不是 c_j，少这一项整体会偏大
- 允许不操作，所以答案取 min(0, 最小子段和)，否则全正增量的串会被迫翻转
- 多组数据，列计数数组要按每组新的 m 重新清零，且总和用 long long

#### 复杂度

| 项 | 值 |
|---|---|
| 时间复杂度 | O(nm) |
| 空间复杂度 | O(nm) |
