### 知识点：

考最基本的线性递推：f(1)=f(2)=1，f(i)=f(i−1)+f(i−2)。结论是只需要两个变量滚动，第 i 项只依赖前两项，不必开数组，空间 O(1)。这题真正的考点不是递推本身，而是数据范围：k ≤ 50 时 f(50) = 12586269025，已经超过 int 上限（约 2.1×10^9），必须用 64 位整数 long long 存，否则在第 47 项附近就会溢出成负数。另外 k = 1、2 都等于 1，循环从第 3 项开始推，边界不单独处理就会多推一项。

---

### 题目描述

> 小蒜蒜最近学习了斐波那契数列。 斐波那契数列是指这样的数列：数列的第一个和第二个数都为 1，接下来每个数都等于前面 2 个数之和。

**输入描述**

> 输入一行，包含一个正整数 k。（1 ≤ k ≤ 50）

**输出描述**

> 输出一行，包含一个正整数，表示斐波那契数列中的第 k 个数

#### 示例

**输入**

```text
19
```

**输出**

```text
4181
```

---

### 最终代码：

```cpp
// 斐波那契：f(1)=f(2)=1，f(i)=f(i-1)+f(i-2)，顺推即可。
// k ≤ 50，f(50)=12586269025 超过 32 位，所以用 long long。
#include <cstdio>

int main() {
    int k;
    if (scanf("%d", &k) != 1) return 0;
    if (k <= 2) { puts("1"); return 0; }
    long long a = 1, b = 1;
    for (int i = 3; i <= k; ++i) {
        long long c = a + b;
        a = b;
        b = c;
    }
    printf("%lld\n", b);
    return 0;
}
```

### 解题思路

这题看着是入门题，第一反应是开个 f[55] 数组递推，但马上意识到两件事：一是只需要前两项，用 a、b 两个变量滚动就够，没必要开数组；二是 k=50 时 f(50)=12586269025 早已超出 int，必须用 long long。于是写成 a=b=1 代表 f(1)、f(2)，从 i=3 推到 k，每次 c=a+b 后把 a、b 往后挪一格，最后输出 b；k≤2 直接输出 1。样例 k=19 得到 4181，和手算的斐波那契一致，再用 k=1、2、50 自测边界和溢出。这题在练的是「看到递推先估最大值、再决定用不用 64 位」的习惯，以及滚动变量的写法。

#### 卡点与关键一步

- 必须用 long long：f(50)=12586269025 超出 int，用 int 会在第 47 项左右溢出成负数
- k=1 和 k=2 都输出 1，循环要从 i=3 开始，否则会多推一项
- 不必开数组也不必写递归，两个滚动变量最稳

#### 复杂度

| 项 | 值 |
|---|---|
| 时间复杂度 | O(k) |
| 空间复杂度 | O(1) |
