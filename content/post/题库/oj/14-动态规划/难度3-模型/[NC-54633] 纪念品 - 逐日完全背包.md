### 知识点：

模型是「逐日完全背包」。结论：把第 d 天到第 d+1 天看成一次交易，物品 j 的代价是 P[d][j]，收益是 P[d+1][j] − P[d][j]（只买正收益的），容量是当前金币 M；因为同一种纪念品当天可以买任意多个，这是完全背包，容量维度要正序枚举。算完一天把 M 更新为 M + dp[M]，再滚到下一天。为什么能一天一天独立算：买卖同价、没有手续费，任何跨多天的持有都能拆成「每天按当日价卖出、次日按当日价买回」的等价链，收益完全不变，所以最优解一定可以写成逐日交易；而金币越多可选方案只增不减，因此每天把金币做到最大是安全的贪心。

### 题目描述

> 小伟突然获得一种超能力，他知道未来 T 天 N 种纪念品每天的价格。某个纪念品 的价格是指购买一个该纪念品所需的金币数量，以及卖出一个该纪念品换回的金币数量。
>
> 	 每天，小伟可以进行以下两种交易无限次： 
>
>
>
> 			任选一个纪念品，若手上有足够金币，以当日价格购买该纪念品；
>
>
> 			卖出持有的任意一个纪念品，以当日价格换回金币。
>
>
>  每天卖出纪念品换回的金币可以立即用于购买纪念品，当日购买的纪念品也可以当日卖出换回金币。当然，一直持有纪念品也是可以的。 
>
> 	T 天之后，小伟的超能力消失。因此他一定会在第 T 天卖出所有纪念品换回金币。 
>
> 	小伟现在有 M 枚金币，他想要在超能力消失后拥有尽可能多的金币。

**输入描述**

> 第一行包含三个正整数 T,N,M，相邻两数之间以一个空格分开，分别代表未来天数 T，纪念品数量 N，小伟现在拥有的金币数量 M。 
> 接下来 T 行，每行包含 N 个正整数，相邻两数之间以一个空格分隔。第 𝑖 行的 N 个正整数分别为  $P_{𝑖,1}$ ,  $P_{𝑖,2}$ , $\dots\dots$  , $P_{𝑖,𝑁}$ ，其中  $P_{𝑖,𝑗}$ 表示第 𝑖 天第 𝑗 种纪念品的价格。

**输出描述**

> 输出仅一行，包含一个正整数，表示小伟在超能力消失后最多能拥有的金币数量

#### 示例 1

**输入**

```text
6 1 100 
50 
20 
25 
20 
25 
50
```

**输出**

```text
305
```

#### 示例 2

**输入**

```text
3 3 100 
10 20 15 
15 17 13 
15 25 16
```

**输出**

```text
217
```

### 最终代码：

```cpp
// 纪念品：每天可无限次买卖，且当日回款当日可用。
// 把第 d 天到第 d+1 天看成一次完全背包：买价 p[d][j]，收益 p[d+1][j]-p[d][j]，
// 容量是当前金币数；逐日把金币滚动放大。
#include <cstdio>
#include <vector>

int main() {
    int T, N;
    long long M;
    if (scanf("%d %d %lld", &T, &N, &M) != 3) return 0;

    std::vector<std::vector<long long>> p(T, std::vector<long long>(N));
    for (int i = 0; i < T; ++i)
        for (int j = 0; j < N; ++j) scanf("%lld", &p[i][j]);

    std::vector<long long> dp;
    for (int d = 0; d + 1 < T; ++d) {
        if (M <= 0) break;
        dp.assign((size_t)M + 1, 0);
        for (int j = 0; j < N; ++j) {
            long long cost = p[d][j];
            long long gain = p[d + 1][j] - p[d][j];
            if (gain <= 0 || cost > M) continue;
            for (long long c = cost; c <= M; ++c) {
                long long cand = dp[(size_t)(c - cost)] + gain;
                if (cand > dp[(size_t)c]) dp[(size_t)c] = cand;
            }
        }
        M += dp[(size_t)M];
    }
    printf("%lld\n", M);
    return 0;
}
```

### 解题思路

第一反应是「在 T 天上做状态压缩 DP」，但每天持有的品种和件数都是天文数字，状态存不下。换个角度：我只要回答「今天这笔钱怎么花最划算」，而买卖同价、可以当日来回、没有手续费，于是把一次跨天持有拆成逐日结算不会亏，问题就解耦成 T−1 个独立小问题。每个小问题就是：容量 M，物品代价 P[d][j]，收益 P[d+1][j] − P[d][j]，每种无限件——标准完全背包，一维数组正序推。实现时每天 dp.assign(M+1, 0) 重开，负收益品种直接跳过，最后 M += dp[M]。样例 2 正好验证了「容量会被用剩」：150 金币先买 8 个 17 元的赚 64，剩 14 再买一个 13 元的赚 3，共 67，得到 217，和 dp[M] 一致。

#### 卡点与关键一步

- 这是完全背包不是 01 背包，容量必须正序枚举；写成倒序会变成每种最多买一个
- 只统计 gain > 0 的品种，亏钱的品种不买
- dp 的容量是当天金币数，金币逐日变大，dp 数组必须每天按当前 M 重开

#### 复杂度

| 项 | 值 |
|---|---|
| 时间复杂度 | O(T·N·M) |
| 空间复杂度 | O(T·N + M) |
