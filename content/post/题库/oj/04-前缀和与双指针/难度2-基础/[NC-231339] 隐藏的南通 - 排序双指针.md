### 知识点：

这题是「极值窗口」模型：每个位置二选一，最小化 max−min。先证一个结论——答案区间的左、右端点一定等于某个 b_i 或 c_i，因为把区间端点往里收不会破坏可行性。于是把 2n 个候选值摊平成 (值, 下标) 排序，在有序表上滑窗：窗口 [l,r] 合法当且仅当每个下标 i 的 b_i、c_i 至少有一个落在窗口里，此时窗口内每个位置都能取到窗口内的值，max−min 就是 v[r]−v[l]。合法性对 r 单调、对 l 单调，所以右指针一直右移、左指针只进不退，用 covered 记当前覆盖了多少个不同下标，covered==n 时收缩左边界。总复杂度 O(n log n)，n ≤ 1e5 完全够。

### 题目描述

> 众所周知，ACM 是南通人的天堂，但 ACM 中占大多数的还是正常人，因此大多数南通人要学着隐藏自己。刚进 ACM 第一天，作为南通人的小 A 就知道了集训队里不成文的规矩（代价是被另一个南通人瓜瓜学长好好的教训了一番）。小 A 知道，作为一个人，总是有正反两面的，在南通人眼里，这代表两个属性：攻击力  $b_i$  和守气值  $c_i$ ，这两个属性可以用同一个系统计算。一个人会不自觉地表现出其中一面。现在，南通学长瓜瓜酱给出了一个难题，你要帮助小 A 想想办法，好让一群南通人（编号从  $1$  到  $n$ ）出门时尽量保持一致，不会出现两个人角色属性差异过大的情况。（即保证所有人表现出的攻或守数值的差值尽可能小，这里的差值是指最大值和最小值的差值。） 
>
>  形式化的讲，有一个长度为  $n$  的序列  $\{a_i\}$ ，每个元素  $a_i$  有  $b_i$ ， $c_i$  两个值可选，确定  $a$  的每一项使得
>   $\displaystyle \max_{1\leqslant i \leqslant n}\{a_i\} - \min_{1\leqslant i \leqslant n}\{a_i\}$ 
>  最小。

**输入描述**

> 第一行一个整数  $n(n \leqslant 10^5)$ ，表示数组  $a$  的长度。
>
> 第二行  $n$  个整数  $b_1,b_2,...,b_n(1 \leqslant b_i\leqslant  n)$ 分别表示  $a_1,a_2,\cdots,a_n$  的第一种取值。 
>
> 第三行  $n$  个整数  $c_1,c_2,...,c_n(1 \leqslant c_i\leqslant n)$ 分别表示  $a_1,a_2,\cdots,a_n$  的第二种取值。

**输出描述**

> 一个整数  $n$ ，表示答案。

#### 示例

**输入**

```text
5
1 2 3 4 5
3 4 2 1 4
```

**输出**

```text
1
```

### 最终代码：

```cpp
#include <iostream>
#include <vector>
#include <algorithm>
#include <climits>
using namespace std;

int main() {
    int n;
    if (!(cin >> n)) return 0;
    vector<int> b(n), c(n);
    for (int i = 0; i < n; i++) cin >> b[i];
    for (int i = 0; i < n; i++) cin >> c[i];

    // 2n 个候选值摊平排序，窗口内要求每个下标至少出现一次
    vector<pair<int, int>> v;
    v.reserve(2 * n);
    for (int i = 0; i < n; i++) {
        v.push_back(make_pair(b[i], i));
        v.push_back(make_pair(c[i], i));
    }
    sort(v.begin(), v.end());

    int m = 2 * n, l = 0, covered = 0, ans = INT_MAX;
    vector<int> cnt(n, 0);
    for (int r = 0; r < m; r++) {
        if (cnt[v[r].second]++ == 0) covered++;
        while (covered == n) {
            ans = min(ans, v[r].first - v[l].first);
            if (--cnt[v[l].second] == 0) covered--;
            l++;
        }
    }
    cout << ans << "\n";
    return 0;
}
```

### 解题思路

读题后先把「每个位置二选一、最小化最大值减最小值」翻译成图形语言：在数轴上放 2n 个点，要求选一个区间，使每个位置的两个点至少有一个落在里面，并让区间尽量短。这个描述直接指向排序加双指针——固定右端点后，左端点越靠右越好。于是把 2n 个 (value, index) 排序，右指针右移时给对应下标的计数加一，第一次出现时 covered 加一；一旦 covered==n，就先用当前 v[r]−v[l] 更新答案，再试着右移左指针，把计数减回去，计数归零时 covered 减一。这里想通的关键一点是：不需要真的枚举 2^n 种选择，窗口保证了每个下标至少有一个候选值可用，就一定能同时给所有位置选出值来。写完用 2^n 全枚举的暴力随机对拍了几百组，全部一致。

#### 卡点与关键一步

- 合法性判定是「每个下标至少一个候选值在窗口内」，不是「窗口里候选值个数等于 n」
- 移动左指针时计数要先减、归零才让 covered 减一，否则覆盖数会算少
- n=1 时答案是 0，ans 初值别用 INT_MAX 直接输出

#### 复杂度

| 项 | 值 |
|---|---|
| 时间复杂度 | O(n log n) |
| 空间复杂度 | O(n) |
