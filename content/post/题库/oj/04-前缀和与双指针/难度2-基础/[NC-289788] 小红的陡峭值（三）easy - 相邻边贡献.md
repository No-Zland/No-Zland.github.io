### 知识点：

窗口的陡峭值对「相邻边」是可加的：长度为 k 的窗口的陡峭值等于窗口内 k-1 条相邻边的权值之和。于是把「枚举窗口」换成「枚举边」：第 i 条边连接 s[i] 与 s[i+1]，权值 w_i=|s[i+1]-s[i]|，它被窗口 [st, st+k-1] 覆盖当且仅当 st≤i 且 st+k-1≥i+1，即 i-k+2≤st≤i，同时 st 本身要落在 0..n-k 内。所以该边贡献 w_i×(min(i,n-k)-max(0,i-k+2)+1)，区间为空则贡献 0。这是典型的贡献法（交换求和顺序），把 O(nk) 降到 O(n)，也是 easy→hard 只改数据范围时的正解思路。

### 题目描述

> 本题为《D. 小红的陡峭值（三）hard》的简单版本，两题的唯一区别在于本题的数据范围更小。
>
> 小红定义一个字符串的陡峭值为：每两个相邻字符，Ascii 码差值的绝对值之和。例如， $\texttt{"bca"}$  的陡峭值是  $|\texttt{`c'}-\texttt{`b'}|+|\texttt{`a'}-\texttt{`c'}|=1 + 2 = 3$ 。 
>
> 现在小红拿到了一个长度为  $n$ ，仅由小写字母构成的字符串  $s$ 。她希望你求出这个字符串所有长度为  $k$  的连续子串的陡峭值之和，你能帮帮她吗？
>
> 连续子串为从原字符串中，连续的选择一段字符（可以全选、可以不选）得到的新字符串。

**输入描述**

> 第一行输入两个正整数  $n,k \left(2\leqq k\leqq n \leqq \pmb{10^3}\right)$  代表字符串的长度、子串的长度。
> 第二行输入一个长度为  $n$ ，仅由小写字母组成的字符串  $s$ 。

**输出描述**

> 输出一个整数，代表所有长度为  $k$  的连续子串的陡峭值之和。

#### 示例

**输入**

```text
3 2
bca
```

**输出**

```text
3
```

### 最终代码：

```cpp
#include <cstdio>
#include <cstdlib>
#include <algorithm>
using namespace std;

int main() {
    int n, k;
    if (scanf("%d %d", &n, &k) != 2) return 0;
    char buf[100005];
    scanf("%s", buf);
    long long ans = 0;
    // 相邻对 (i,i+1) 被多少长度为 k 的窗口覆盖
    for (int i = 0; i + 1 < n; i++) {
        long long d = llabs((long long)buf[i + 1] - (long long)buf[i]);
        long long lo = max(0, i - k + 2);   // 窗口起点 st 满足 st+k-1 >= i+1
        long long hi = min(i, n - k);       // 且 st <= i
        if (hi >= lo) ans += d * (hi - lo + 1);
    }
    printf("%lld\n", ans);
    return 0;
}
```

### 解题思路

第一反应是老老实实枚举 n-k+1 个窗口、每个窗口扫 k 个字符，复杂度 O(nk)。n≤10^3 的 easy 版这样确实能过，但 hard 版 n 是 10^5，所以我直接按贡献法写。关键想法：陡峭值是边权之和，每条边的贡献只看它被多少个窗口覆盖，而覆盖它的窗口起点是一段连续区间，端点能 O(1) 算出。具体地，起点 st 要 ≤i（否则窗口右端还没到 i+1），且 st≥i-k+2（否则窗口右端已经越过 i+1），再与 0、n-k 取交，就得到覆盖数。答案对每条边累加 w_i×覆盖数。写完后我先把 n≤7 的所有小写串与 O(nk) 暴力和公式三方对拍，又抽了 300 组随机大串验证可执行文件，全部一致。

#### 卡点与关键一步

- 起点下界的 +2 容易写成 +1：条件是 st+k-1≥i+1，移项得 st≥i-k+2。
- 窗口起点范围是 0..n-k，忘记与 n-k 取 min 会在靠近末尾的边上多算。
- k=n 时只有 1 个窗口，所有边的覆盖数都应为 1，是很好的快速自检。

#### 复杂度

| 项 | 值 |
|---|---|
| 时间复杂度 | O(n) |
| 空间复杂度 | O(n) |
