### 知识点：

考的是前缀和与差分互逆。条件「b 的前缀和数组恰是 a 的 [l,r] 段」写成式子就是：b 的前 t 项和等于 a_{l+t−1}。把 t 与 t−1 两式相减，得 b_t = a_{l+t−1} − a_{l+t−2}；t=1 时前缀和就是 b_1 本身，所以 b_1 = a_l。结论：所谓构造，就是把区间 a[l..r] 做一次差分，首项取 a_l，之后的项都是相邻差。因为任何数列的差分必然能积回原序列，所以答案存在且唯一，这也解释了题面那句「可以证明」。实现上每组询问 O(r−l+1) 输出，用有符号类型保存（相邻差可能为负）。模板记忆：前缀和 ↔ 差分是一对逆运算，前缀和的逆就是「首项 + 相邻差」。

### 题目描述

> 小红拿到了一个长度为  $n$  的数组  $a_1,a_2,\dots,a_n$ 。她会进行  $q$  次查询，每次输入两个正整数  $l,r$ ，她希望你构造一个长度为  $r-l+1$  的数组，满足该数组的前缀和数组恰好是原数组  $a$  的  $[l,r]$  区间对应的连续子数组。换句话说，记新数组为  $b_1,b_2,\dots,b_{r-l+1}$ ，则有
>
>
>
>  $\begin{cases}
>     a_1=b_l \\ 
>     a_2=b_l+b_{l+1} \\ 
>     \dots \\ 
>     a_{r-l+1}=b_l+b_{l+1}+\dots+b_{r-l+1}
> \end{cases}$ 
>
> 我们可以证明，答案一定存在且唯一。你能帮帮她吗？ 
>
> 【名词解释】
>
> 我们定义，前缀和数组为数组的“前  $i$  项和”构成的数组。例如  $\{1,2,2,1\}$  的前缀和数组是  $\{1,1+2=3,3+2=5,5+1=6\}$  即  $\{1,3,5,6\}$ 。

**输入描述**

> 第一行输入一个整数  $n \left(1\leqq n \leqq 100\right)$ ，代表数组长度。
> 第二行输入  $n$  个整数  $a_1,a_2,\dots,a_n \left(1\leqq a_i \leqq 10^9\right)$ ，代表小红拿到的的数组。
> 第三行输入一个整数  $q \left(1\leqq q \leqq 100\right)$ ，代表询问次数。
> 此后  $q$  行，第  $i$  行输入两个正整数  $l_i,r_i \left(1\leqq l_i \leqq r_i \leqq n\right)$ ，代表第  $i$  次询问。

**输出描述**

> 对于第  $i$  次询问，新起一行，在同一行上输出  $r_i-l_i+1$  个整数，代表小红构造的数组。
> 我们可以证明，该数组一定存在且唯一。

#### 示例

**输入**

```text
5
1 3 5 2 1
2
1 3
3 4
```

**输出**

```text
1 2 2
5 -3
```

### 最终代码：

```cpp
#include <iostream>
#include <vector>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n;
    if (!(cin >> n)) return 0;
    vector<long long> a(n + 1);
    for (int i = 1; i <= n; i++) cin >> a[i];

    int q;
    cin >> q;
    while (q--) {
        int l, r;
        cin >> l >> r;
        // 要求 b 的前缀和恰好是 a[l..r]：b_1 = a_l，b_i = a_i - a_{i-1}
        for (int i = l; i <= r; i++) {
            long long val = (i == l) ? a[l] : a[i] - a[i - 1];
            cout << val << (i == r ? '\n' : ' ');
        }
    }
    return 0;
}
```

### 解题思路

题面里那串符号写得比较绕（a_1=b_l、a_2=b_l+b_{l+1} 混着下标），我干脆不看符号，抓住一句硬话：新数组 b 的前缀和数组恰好是 a 的 [l,r] 这一段。把它写成 b 的前 t 项和 = a_{l+t−1}，再写出 t−1 的版本，两式相减立刻得到 b_t = a_{l+t−1} − a_{l+t−2}，首项 b_1 = a_l。也就是 b 就是 a 在 [l,r] 上的一次差分，构造题变成了照公式输出。拿样例验：a=[1,3,5,2,1]，查询 [3,4] 得到 5 和 2−5=−3，正是样例的 5 −3，顺便确认了答案可以为负，不能假设 a 单调。代码就是读入、每组询问一层循环。写完我按前缀和回代验证了随机数据，前缀和确实等于 a[l..r]。

#### 卡点与关键一步

- 答案可以是负数（样例第二组就是 −3），别用无符号类型或默认递增
- 首项是 a_l 本身，从第二项才开始做相邻差，下标别整体错一位
- 每组询问单独占一行，组内用空格分隔，行末不要多输出空格

#### 复杂度

| 项 | 值 |
|---|---|
| 时间复杂度 | O(nq) |
| 空间复杂度 | O(n) |
