### 知识点：

结论：s 与 reverse(s) 的字典序由第一对不相等的首尾字符决定。设 n=|s|，反转串第 i 位等于 s[n−1−i]，所以从两端向中间扫，找到第一个 s[i]≠s[n−1−i]：前者大就输出 left，后者大就输出 right；若一直相等，说明 s 是回文，两串完全相同，输出 equal。依据是字典序比较遇到第一个不同字符就定胜负，后面的字符不再影响结果。这样把“构造反转串”改写成双指针，额外空间从 O(n) 降到 O(1)，时间仍是 O(n)。

### 题目描述

> 小红拿到了一个字符串，她希望你判断该字符串反转 $^\texttt{[1]}$ 后的字典序 $^\texttt{[2]}$ 和原串哪个更大。你能帮帮她吗？
>
> 【名词解释】
>
> 反转 $^\texttt{[1]}$ ：将字符串从右往左重新书写，例如  $s_1s_2\dots s_n$  反转后得到  $s_n s_{n-1} \dots s_1$ 。
>
> 字符串的字典序 $^\texttt{[2]}$ 比较：从左到右逐个比较两个字符串的字符。如果在某个位置上字符不同，比较这两个字符的字母表顺序，字母序大的字符串字典序也大。

**输入描述**

> 在一行上输入一个长度为  ${\rm length}(s)$ ，仅由英文小写字母构成的字符串  $s\left(1 \leqq {\rm length}(s) \leqq 10^5\right)$ 。

**输出描述**

> 如果原串字典序更大，输出  $\texttt{left}$ ；如果反转后的字典序更大，输出  $\texttt{right}$ ；如果原串和反转后的字符串字典序相同，则输出  $\texttt{equal}$ 。

#### 示例 1

**输入**

```text
abc
```

**输出**

```text
right
```

#### 示例 2

**输入**

```text
now
```

**输出**

```text
right
```

#### 示例 3

**输入**

```text
a
```

**输出**

```text
equal
```

### 最终代码：

```cpp
#include <iostream>
#include <string>

using namespace std;

// 比较 s 与 reverse(s)。设 n = |s|，反转串第 i 位就是 s[n-1-i]，
// 因此只需从两端向中间找第一对不相等的字符：
//   s[i] > s[n-1-i]  -> 原串更大，输出 left
//   s[i] < s[n-1-i]  -> 反转串更大，输出 right
// 全部配对相等（回文）时输出 equal。
int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    string s;
    if (!(cin >> s)) return 0;
    int n = (int)s.size();
    for (int i = 0; i < n / 2; ++i) {
        char l = s[i], r = s[n - 1 - i];
        if (l == r) continue;
        cout << (l > r ? "left" : "right") << '\n';
        return 0;
    }
    cout << "equal\n";
    return 0;
}
```

### 解题思路

第一反应是直接复制一份串 reverse 过来，再用 string 的比较运算符，两行就能写完。这样当然正确，但会多开一个长度 1e5 的字符串。仔细想，反转串只是下标映射 i→n−1−i，没必要真的构造，于是改成从两端向中间走：每次比较 s[i] 和 s[n−1−i]，相等就继续，不等就当场定胜负。因为字典序在第一个不同字符处已经决定，不需要看后面。循环只走到 n/2，中间的字符自己和自己相等，可以跳过。写完手推 abc 得 a<c 输出 right，now 得 n<w 输出 right，单字符 a 不进入循环输出 equal，三组样例全部对上。

#### 卡点与关键一步

- 扫完没有不同要输出 equal，不能默认成 left
- 循环上界取 n/2 即可，别把中间位置重复比较
- 输出是 left/right/equal 三个小写单词，注意拼写和大小写

#### 复杂度

| 项 | 值 |
|---|---|
| 时间复杂度 | O(n) |
| 空间复杂度 | O(n) |
