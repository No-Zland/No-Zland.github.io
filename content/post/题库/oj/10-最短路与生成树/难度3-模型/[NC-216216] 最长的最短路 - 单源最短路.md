### 知识点：

模板题：以邮局 0 为源点跑一次 Dijkstra，再在 1..N 的 dist 里取最大值。题名「最长的最短路」容易误导——「最长」是对最短路结果取最大，不是求最长路（一般图上最长路是 NP 难的），所以仍是标准最短路。要点有三：一是松弛用优先队列加懒惰删除，弹出的点若已确定就跳过；二是数据范围，w ≤ 1e9、M < 1e5，最短路可能到 1e14，dist 与松弛必须是 long long，INF 取 LLONG_MAX 且只在可达点弹出的分支里做加法；三是统计，按编号 1..N 升序扫描、只有 dist 严格大于当前最优才更新，天然满足「并列取编号最小」。复杂度 O((N+M) log N)。

### 题目描述

> 小张是个邮递员，一直以来他都骑着他的小电驴送邮件。今天小张终于攒够了钱去买一辆新车！可是今天仍然是工作日，因此小张只能在完成了今天的邮件投递任务之后才能去买车。因为想要早点下班去买车，小张决定研究一下每个要前往的投递点与邮局所在的点最短路是多远。因此小张将每个投递点重新编号为1~N，邮局所在地点编号为0。并且直接画出了有些投递点之间的M条单行路，最终得到了一张新的地图，小张想知道距离邮局最远的投递点是哪个（如果某个投递点不可达则不用考虑该距离）。

**输入描述**

> 输入N（N< 1e4）代表有N个投递点（编号为1~N），与M(M<1e5)条路。
> 接下来M行，每行含三个值：u，v，w，代表u，v之间有一条单行路，从u可以到达v。投递点这两个投递点，路的长度为w（w <= 1e9）。

**输出描述**

> 输出投递点中到邮局的最短路径最长的一个，并且输出这个投递点的编号。如果有多个答案，输出编号最小的投递点。

#### 示例

**输入**

```text
4 4
0 1 4
0 2 3 
0 3 2
0 4 1
```

**输出**

```text
4 1
```

### 最终代码：

```cpp
#include <iostream>
#include <vector>
#include <queue>
#include <utility>
#include <climits>
using namespace std;

typedef long long ll;
typedef pair<ll, int> pli;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int N, M;
    if (!(cin >> N >> M)) return 0;

    vector<vector<pli>> g(N + 1);  // 点编号 0~N
    for (int i = 0; i < M; i++) {
        int u, v;
        ll w;
        if (!(cin >> u >> v >> w)) break;
        if (u < 0 || u > N || v < 0 || v > N) continue;
        g[u].push_back(make_pair(w, v));
    }

    const ll INF = LLONG_MAX;
    vector<ll> dist(N + 1, INF);
    vector<char> done(N + 1, 0);
    priority_queue<pli, vector<pli>, greater<pli>> pq;

    dist[0] = 0;
    pq.push(make_pair(0LL, 0));
    while (!pq.empty()) {
        pli top = pq.top();
        pq.pop();
        ll d = top.first;
        int u = top.second;
        if (done[u]) continue;
        done[u] = 1;
        for (size_t j = 0; j < g[u].size(); j++) {
            ll w = g[u][j].first;
            int v = g[u][j].second;
            if (d + w < dist[v]) {
                dist[v] = d + w;
                pq.push(make_pair(dist[v], v));
            }
        }
    }

    ll best = -1;
    int bidx = -1;
    for (int i = 1; i <= N; i++) {
        if (dist[i] == INF) continue;  // 不可达的点不考虑
        if (dist[i] > best) { best = dist[i]; bidx = i; }  // 严格大于 => 并列取小编号
    }
    if (bidx != -1) cout << best << " " << bidx << "\n";
    return 0;
}
```

### 解题思路

先把题目拆成两个独立问题：每个投递点到邮局的最短路，以及在这些最短路里挑最长的一条。第一个是 Dijkstra 模板，第二个只是一次线性扫描，所以核心代码没什么可犹豫的。我特意停下来想了一遍为什么不能「求最长路」：无向图的边权取反后负环、一般图最长路 NP 难，而这里问的是最短路的长度最大值，完全可以在最短路结果上做 max，不要被标题带跑。第二个决策是输出顺序，样例给的是 4 1，即先距离后编号，这一点必须按样例来。第三个是规模估算：单条边最大 1e9，一条路径最多约 1e4 条边，长度能到 1e13 量级，int 必爆，所以 dist、优先队列的元素都用 long long。最后统计时先判 dist 是否为 INF（不可达按题面跳过），并列用严格大于保小编号。

#### 卡点与关键一步

- 输出是先距离后编号（样例 4 1），顺序写反会 WA 得很隐蔽
- 路径长度能达到 1e13 以上，dist 必须用 long long，INF 不能取 0x3f3f3f3f
- 不可达点若参与取最大值会得到 INF 或极大值，比较前要先筛掉，同理不要对 INF 做加法

#### 复杂度

| 项 | 值 |
|---|---|
| 时间复杂度 | O((N+M) log N) |
| 空间复杂度 | O(N+M) |
