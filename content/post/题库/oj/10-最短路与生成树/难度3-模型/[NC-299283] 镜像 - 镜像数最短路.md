### 知识点：

在数值上建隐式图：结点是正整数，边是 x→x+k 与 x→reverse(x)（个位非 0 时可用）。两条边代价都是 1，所以最少操作数就是无权图 BFS 最短路。核心是搜索上界：镜像不改变位数，+k 只会让数变大，因此位数单调不减，一旦位数超过 digits(b) 就永远回不到 b，只需在 [1,10^d) 内搜索（d=digits(b)≤7，节点 ≤10^7）。若 a 的位数已大于 b，除 a=b 外直接 −1。

---

### 题目描述

> 对于一个正整数  $x$ ，小苯定义它的“镜像数”为将其十进制表示反转后得到的数（例如  $123$  的镜像数是  $321$ ）。更具体地，若  $x$  的十进制表示为  $x_1x_2\dots x_n$ ，则其镜像数为  $x_nx_{n-1}\dots x_1$ 。
>
> 现在给定两个正整数  $a$  和  $b$ ，小苯可以进行任意次操作（也可以不操作），每次操作从以下两种中任选一种执行：
>
>  $\hspace{23pt}\bullet\,$ 如果  $a$  的个位数字不为  $0$ ，则将  $a$  替换为它的镜像数；
>
>  $\hspace{23pt}\bullet\,$ 将  $a$  加上  $k$ 。
>
> 小苯想知道最少需要多少次操作，才能将  $a$  变成  $b$ 。如果无法实现，输出  $-1$ 。

**输入描述**

> 每个测试文件均包含多组测试数据。第一行输入一个整数  $T\left(1 \leqq T \leqq 100\right)$  代表数据组数，每组测试数据描述如下：
>  $\hspace{23pt}\bullet\,$ 输入三个正整数  $a, b, k\left(1 \leqq a, b, k \leqq 10^6\right)$ ，表示给定的两个正整数以及操作的常数。
> 除此之外，保证单个测试文件的  $a$  之和、 $b$  之和均不超过  $2 \times10^7$ 。

**输出描述**

> 对于每一组测试数据，新起一行输出一个整数，表示最少操作次数，若无法实现则输出  $-1$ 。

#### 示例

**输入**

```text
3
123 321 2
123 444 123
123 123 114514
```

**输出**

```text
1
2
0
```

### 最终代码：

```cpp
#include <cstdio>
#include <vector>
using namespace std;

// 思路：BFS。结点是数值，边是 +k 和镜像（个位非 0 时）。
// 关键边界：镜像不改变位数，+k 只会变大，
// 所以一旦位数超过 digits(b) 就再也回不到 b —— 搜索范围限制在 [1, 10^d)。
int main() {
    int T;
    if (scanf("%d", &T) != 1) return 0;
    vector<int> dist;
    vector<int> q;
    while (T--) {
        long long a, b, k;
        scanf("%lld %lld %lld", &a, &b, &k);
        if (a == b) { puts("0"); continue; }
        int d = 0;
        for (long long t = b; t > 0; t /= 10) d++;
        long long lim = 1;
        for (int i = 0; i < d; i++) lim *= 10;   // 10^d
        if (a >= lim) { puts("-1"); continue; }  // 位数多于 b，只增不减

        dist.assign((size_t)lim, -1);
        q.clear();
        q.reserve(1 << 16);
        dist[(size_t)a] = 0;
        q.push_back((int)a);
        long long ans = -1;
        for (size_t h = 0; h < q.size() && ans < 0; h++) {
            int x = q[h];
            int dd = dist[(size_t)x];
            // 操作一：镜像
            if (x % 10 != 0) {
                long long m = 0;
                for (int y = x; y > 0; y /= 10) m = m * 10 + y % 10;
                if (m < lim && dist[(size_t)m] < 0) {
                    dist[(size_t)m] = dd + 1;
                    if (m == b) { ans = dd + 1; break; }
                    q.push_back((int)m);
                }
            }
            // 操作二：+k
            long long nx = (long long)x + k;
            if (nx < lim && dist[(size_t)nx] < 0) {
                dist[(size_t)nx] = dd + 1;
                if (nx == b) { ans = dd + 1; break; }
                q.push_back((int)nx);
            }
        }
        printf("%lld\n", ans);
    }
    return 0;
}
```

### 解题思路

看到「最少操作次数」且两种操作都是一次一步，第一反应是 BFS；但状态是无限多的正整数，必须先找封闭搜索域。我盯着两条操作的性质：+k 单调增，镜像是位数不变的双射（个位为 0 时不可用），所以数字的位数只会不减——一旦比 b 多一位，之后无论怎么加、怎么反都回不来，这直接给出上界 [1,10^d)，d 最多 7。另一个边界是 a 的位数比 b 多时无解（位数不能减少），除非一开始 a=b。BFS 里镜像只在 x%10≠0 时入队，+k 只保留小于 lim 的转移；dist 用 int 数组并在多组数据间复用，20 组满规模实测 0.3 秒左右。

#### 卡点与关键一步

- 镜像只在个位不为 0 时合法：对末尾是 0 的数做反转会丢掉前导零，等于换成了另一个数
- 必须按位数剪枝，否则 BFS 会一直向上加 k，永不终止
- a 的位数大于 b 时只有 a=b 可行，其余输出 −1；a=b 的特判也要放在最前面

#### 复杂度

| 项 | 值 |
|---|---|
| 时间复杂度 | O(10^d)，d=digits(b)≤7 |
| 空间复杂度 | O(10^d) |
