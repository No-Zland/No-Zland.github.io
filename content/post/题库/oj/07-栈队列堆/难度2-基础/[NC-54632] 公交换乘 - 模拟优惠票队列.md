### 知识点：

考的是「带时间窗口和优先级的资源匹配」，模型是按获得顺序维护一个优惠票队列。结论：由于所有记录按时间递增且同一分钟不会出现两条记录，45 分钟窗口内最多只有 46 张票，于是每条公交只需在这一小段里找票，整体线性。三个判定要点：一、只有地铁产生票，公交不产生；二、票可用当且仅当 t_bus − t_subway ≤ 45 且 subway_price ≥ bus_price；三、同时有多张可用时必须取最早获得的那张，所以从队头往后扫，第一张满足条件的即答案。已用或已过期的票可以永久跳过，用一个 head 指针把它们剪掉，避免重复扫描退化成 O(n²)。

### 题目描述

> 著名旅游城市 B 市为了鼓励大家采用公共交通方式出行，推出了一种地铁换乘公交 车的优惠方案：
>
>
>
> 			在搭乘一次地铁后可以获得一张优惠票，有效期为 45 分钟，在有效期内可以 消耗这张优惠票，免费搭乘一次票价不超过地铁票价的公交车。在有效期内指 开始乘公交车的时间与开始乘地铁的时间之差小于等于 45 分钟，即： $𝑡_{𝑏𝑢𝑠} −𝑡_{𝑠𝑢𝑏𝑤𝑎𝑦} ≤ 45$  
>
>
> 			搭乘地铁获得的优惠票可以累积，即可以连续搭乘若干次地铁后再连续使用优 惠票搭乘公交车。
>
>
> 			搭乘公交车时，如果可以使用优惠票一定会使用优惠票；如果有多张优惠票满 足条件，则优先消耗获得最早的优惠票。
>
>
> 现在你得到了小轩最近的公共交通出行记录，你能帮他算算他的花费吗？

**输入描述**

> 输入文件的第一行包含一个正整数 𝑛，代表乘车记录的数量。
> 接下来的 𝑛 行，每行包含 3 个整数，相邻两数之间以一个空格分隔。第 𝑖 行的 第 1 个整数代表第 𝑖 条记录乘坐的交通工具，0 代表地铁，1 代表公交车；第 2 个 整数代表第 𝑖 条记录乘车的票价  $𝑝𝑟𝑖𝑐𝑒_𝑖$  ；第三个整数代表第 𝑖 条记录开始乘车的时 间  $𝑡_𝑖$  （距 0 时刻的分钟数）。
> 我们保证出行记录是按照开始乘车的时间顺序给出的，且不会有两次乘车记录出现 在同一分钟。

**输出描述**

> 输出文件有一行，包含一个正整数，代表小轩出行的总花费

#### 示例 1

**输入**

```text
6 
0 10 3 
1 5 46 
0 12 50 
1 3 96 
0 5 110 
1 6 135
```

**输出**

```text
36
```

#### 示例 2

**输入**

```text
6 
0 5 1 
0 20 16 
0 7 23 
1 18 31 
1 4 38 
1 7 68
```

**输出**

```text
32
```

### 最终代码：

```cpp
// 公交换乘：地铁产生优惠票（有效期 45 分钟、可抵不超过地铁票价的公交），
// 公交能用票一定用，且优先用最早获得的那张。
#include <cstdio>
#include <vector>

int main() {
    int n;
    if (scanf("%d", &n) != 1) return 0;

    long long total = 0;
    std::vector<int> ct, cp;      // 优惠票的产生时间、可抵票价
    std::vector<char> used;
    size_t head = 0;              // 已永久失效（过期或已用）的票的前缀

    for (int i = 0; i < n; ++i) {
        int type, t;
        long long price;
        scanf("%d %lld %d", &type, &price, &t);
        if (type == 0) {          // 地铁：付费并得到一张票
            total += price;
            ct.push_back(t);
            cp.push_back((int)price);
            used.push_back(0);
        } else {                  // 公交：在 45 分钟窗口内找最早可用的票
            while (head < ct.size() && (used[head] || t - ct[head] > 45)) ++head;
            int pick = -1;
            for (size_t j = head; j < ct.size(); ++j) {
                if (used[j] || t - ct[j] > 45) continue;
                if (cp[j] >= price) { pick = (int)j; break; }
            }
            if (pick >= 0) used[pick] = 1;
            else total += price;
        }
    }
    printf("%lld\n", total);
    return 0;
}
```

### 解题思路

第一反应是「每条公交都扫一遍前面所有地铁票」，担心 O(n²)，但读题时注意到「不会有两次乘车记录出现在同一分钟」，说明有效窗口内票数不超过 46，被反复扫到的只有已用或已过期的票，于是加一个 head 指针把它们永久剪掉，复杂度就降到线性。写法上：地铁直接加钱并压入一张 (time, price)，公交先把 head 推过所有 used 或 t − ticket > 45 的票，再从 head 往后找第一张 price 够的，命中就标记 used（不真删，省掉 vector 搬移），没命中才付钱。样例 2 帮我确认了两个细节：地铁票价 5 抵不了公交 6，会跳到后面那张 20 的票，说明「优先最早」是硬规则而不是找最便宜的；38 分那次差 15 分钟仍在窗口内，说明边界是 ≤ 45。

#### 卡点与关键一步

- 有效期是 t_bus − t_subway ≤ 45，等号也算有效，写成 < 45 会挂边界
- 票的额度是「地铁票价」，比较的是 cp ≥ bus_price，不是余额或差价
- 命中票后要标记已用；已用和已过期的票都应被 head 永久跳过，否则退化成 O(n²)

#### 复杂度

| 项 | 值 |
|---|---|
| 时间复杂度 | O(n) |
| 空间复杂度 | O(n) |
