### 知识点：

把「插入 ab」倒过来看就是「删除相邻的 ab」，所以 s 是好串 ⇔ s 能被反复删掉相邻 ab 变空。把 a 记作左括号、b 记作右括号，结论是：s 是好串 ⇔ s 只含 a、b，任意前缀中 a 的个数不少于 b 的个数，并且 a 与 b 总数相等，也就是标准合法括号序列。必要性：空串合法，在合法串任意位置插入 "ab" 后，各前缀计数仍非负、总数也不变。充分性：任意非空的合法括号序列一定含有相邻的 "ab"（取最左边的 b，它前一位必是 a），删掉之后仍然合法，归纳即得。实现只要一个计数器 bal：遇 a 加一、遇 b 减一，中途为负或结尾非零就是 Bad。

### 题目描述

> 牛牛喜欢跟字符串玩耍，他学会了一种新操作：在当前字符串中任意位置（包括开头和结尾）插入子串  $\texttt{ab}$ 。
>
> 牛牛称一个字符串为 好串，当且仅当它可以通过若干次上述操作从 空串 生成。
>
> 例如， $\texttt{ab}$ 、 $\texttt{aabb}$ 、 $\texttt{aababb}$  都是好串，而  $\texttt{aab}$ 、 $\texttt{ba}$ 、 $\texttt{abbb}$  不是好串。
>
> 现给定一个字符串  $s$ ，请判断字符串  $s$  是否是好串。

**输入描述**

> 在一行中输入一个仅由小写字母组成字符串  $s$ （ $1 \leqq |s| \leqq 10^5$ ）。

**输出描述**

> 如果字符串  $s$  是好串，输出  $\texttt{Good}$ ；否则输出  $\texttt{Bad}$ 。

#### 示例 1

**输入**

```text
ab
```

**输出**

```text
Good
```

#### 示例 2

**输入**

```text
aab
```

**输出**

```text
Bad
```

#### 示例 3

**输入**

```text
abaababababbaabbaaaabaababaabbabaaabbbbbbbb
```

**输出**

```text
Bad
```

### 最终代码：

```cpp
#include <cstdio>

// 插入 "ab" 的逆操作是删掉相邻的 "ab"。把 a 看成左括号、b 看成右括号，
// 则 s 是好串 ⇔ s 是合法的括号序列（任意前缀 a 的个数不少于 b 的个数，且总数相等）。
int main() {
    static char s[100005];
    if (scanf("%s", s) != 1) return 0;
    int bal = 0;
    bool ok = true;
    for (int i = 0; s[i]; ++i) {
        if (s[i] == 'a') {
            ++bal;
        } else if (s[i] == 'b') {
            if (--bal < 0) { ok = false; break; }  // 出现了无法匹配的 b
        } else {
            ok = false;  // 混入其它字符，一定不是好串
            break;
        }
    }
    if (bal != 0) ok = false;  // a、b 数量不等
    puts(ok ? "Good" : "Bad");
    return 0;
}
```

### 解题思路

看到“任意位置插入 ab”，我先做逆向思考：若 s 是好串，则一定能删掉某个相邻的 ab 回到一个好串，于是判题变成“能不能反复删 ab 删空”。这一步直接让我想到括号匹配——ab 就是一对配好的括号。接着把充要条件两头都验一遍：插入 ab 会让某个位置之后的前缀 a、b 计数同时加一，非负性和总量都不受影响；反过来，任何非空的合法括号序列，取最左边的 b，它前一位必然是 a，因此一定存在可删的相邻 ab，删完仍然合法，归纳下去必然删空。两条都成立，判据就只是前缀非负 + 总数相等。实现用一个 bal 扫一遍，O(|s|)。样例第三个串我数了下 a 比 b 多，果然是 Bad。为了保险，我又枚举了长度 ≤9 的全部 a/b 串，用“从空串出发插入 ab 能到达哪些串”的 BFS 结果和判据逐串比对，完全一致。

#### 卡点与关键一步

- 只判 a、b 数量相等不够，前缀里一旦 b 多于 a 就不是好串（如 ba）
- 输出是首字母大写的 Good / Bad，别写成 good / bad
- 题面说只含小写字母，但仍要处理混入其它字符的情况，直接判 Bad

#### 复杂度

| 项 | 值 |
|---|---|
| 时间复杂度 | O(|s|) |
| 空间复杂度 | O(1) |
