### 知识点：

这题考带约束的构造：构造 n 个正整数，相邻两项差的绝对值为 1，且总和不超过 3n（石子可以不用完）。结论是按周期 6 循环取值 1,2,3,4,3,2 即可。验证三件事：其一，相邻差恒为 1（周期内 1->2->3->4->3->2，跨周期 2->1 也差 1）；其二，每项都不小于 1；其三，每个完整周期的和为 15，小于预算 18=3×6，任意前缀和也不超过 3 倍前缀长度，所以总和严格小于 3n。可以把它理解成“爬四格、退两格”的锯齿，平均每格 2.5 颗石子；而 n=3、n=4 时它恰好退化成样例的 1 2 3 和 1 2 3 4。

### 题目描述

> Askalana因刚教完猫猫认字识数魔力大伤而不敌，打开传送门逃往了异世界，Askalana魔力耗尽，卒。 
>
> 这人太坏，折磨你不说还折磨这么可爱的猫猫，你想。于是你想丢下Askalana离开自己找回去的路。一天后，你发现这个世界竟不知空间魔法为何物，何况回家。于是你又去给她从小土包里挖了出来。 
>
> 你们找到了城里的冒险家协会，准备给Askalana补充魔力，助力她打赢复活赛。
>
> 从冒险家协会购买到的情报显示，城外的一座遗迹里有一眼魔泉，正是补魔的好地方，你和猫猫决定就带Askalana去这里了！
>
> 要打开遗迹，需要解开遗迹门口的石子谜题。一共有  $n$  个空格子和  $3 \times n$  颗石子，你需要构造一个方案，向每一个空格子中放入石子，使得相邻格子中的石子数之差的绝对值恰好为  $1$ 。更具体地，对于第  $i \left( 1 \lt i \lt n \right)$  个格子，记你在其中放入了  $a_i$  颗石子，则需要满足  $\left| a_{i - 1} - a_{i} \right| = 1$ 、且  $\left| a_{i} - a_{i + 1} \right| = 1$ 。
>
> 石子可以不用完，但是每一个格子都不能为空。可以证明的是，这样的构造方案一定存在，输出任意一种即可。

**输入描述**

> 每个测试文件均包含多组测试数据。第一行输入一个整数  $T\left(1\leqq T\leqq 10^3\right)$  代表数据组数，每组测试数据描述如下：
> 在一行上输入一个整数  $n\left(1\leqq n\leqq 2\times 10^5\right)$  代表空格子数量。
>
> 除此之外，保证单个测试文件的  $n$  之和不超过  $2 \times 10^5$ 。

**输出描述**

> 对于每一组测试数据，新起一行。输出  $n$  个整数，代表你构造的方案。
> 如果存在多个解决方案，您可以输出任意一个，系统会自动判定是否正确。注意，自测运行功能可能因此返回错误结果，请自行检查答案正确性。

#### 示例

**输入**

```text
2
3
4
```

**输出**

```text
1 2 3
1 2 3 4
```

### 最终代码：

```cpp
// NC289268 冒险猫猫参上！！
// 题意：构造 n 个正整数 a[1..n]，满足 |a[i]-a[i+1]|=1，且总石子数 sum a[i] <= 3n（可不全用完）。
// 做法：按周期 6 循环取值 1 2 3 4 3 2（爬坡再下坡），每 6 个格子的和为 15 < 18 = 3*6，
//       任意前缀和都不超过 3*格子数；相邻差恒为 1，且都 >= 1，满足全部约束。
#include <cstdio>

int main() {
    int T;
    if (scanf("%d", &T) != 1) return 0;
    const int cyc[6] = {1, 2, 3, 4, 3, 2};
    while (T--) {
        int n;
        scanf("%d", &n);
        for (int i = 0; i < n; ++i) {
            printf("%d", cyc[i % 6]);
            putchar(i + 1 < n ? ' ' : '\n');
        }
    }
    return 0;
}
```

### 解题思路

先看约束：总和不超过 3n，即平均每格至多 3 颗，而每格至少 1 颗、相邻差 1，所以数值不能一直往上爬。最朴素的想法是 1,2,1,2 交替，和只有 1.5n，一定合法；但 n=3 时会输出 1 2 1，与样例 1 2 3 不一致。虽然本题是 SPJ、两种都算对，我还是希望和样例对齐以便自测，于是改成 1,2,3,4,3,2 的六周期锯齿：n=3 得 1 2 3、n=4 得 1 2 3 4，和样例完全一致，同时每周期只花 15 颗、预算有 18 颗，前缀也不会超标。写完后我另写脚本把 n 从 1 跑到 200000，逐组检查非空、相邻差 1、总和不超过 3n，全部通过，最大比值约为 0.87。

#### 卡点与关键一步

- 不能用 1..n 递增：总和 n(n+1)/2 在 n>=6 时就超过 3n，必须来回折返。
- 周期接缝也要满足相邻差 1：周期必须以 1 开头、以 2 结尾，别改成以 1 结尾的周期。
- n=1、n=2 是边界，构造要能自动退化（本方案输出 "1"、"1 2"，均合法）。

| 项 | 值 |
|---|---|
| 时间复杂度 | O(n) |
| 空间复杂度 | O(1) |
