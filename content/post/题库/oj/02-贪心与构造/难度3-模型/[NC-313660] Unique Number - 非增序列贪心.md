### 知识点：

前缀加一的直接结论：位置 i 被所有前缀 [1,j] (j≥i) 覆盖，所以最终序列必有 c1≥c2≥…≥cn；反过来任意非增非负序列都能实现——对前缀 [1,i] 做 c_i−c_{i+1} 次（令 c_{n+1}=0）即可，故操作顺序无关，过程被彻底消掉。于是问题等价于：在 c_i≤d_i 且非增的前提下最大化不同数值个数。又因为只增不减，中间时刻的值永远不超过终值，约束只需在终点检查。非增还意味着 c_j≤c_i≤d_i (i<j)，每个位置的真实上界是前缀最小值 m_i=min(d_1..d_i)，且 m 本身非增。在非增上界下从右往左贪心：c_n=0，c_i=min(m_i,c_{i+1}+1)，能抬一格就抬一格，答案=1+成功抬升次数。

### 题目描述

> 小苯给定你一个长度为  $n$  的序列  $c_1, c_2, \dots, c_n$ ，初始时所有  $c_i = 0$ 。
>
> 你可以进行如下操作任意次（可以不执行）：
>
>  $\hspace{23pt}\bullet\,$ 选择一个前缀  $[1, i] \left(1 \leqq i \leqq n \right)$ ，并将前缀中所有元素的值增加  $1$ 。
>
> 同时，你还会得到一个长度为  $n$  的“限制序列”  $d_1, d_2, \dots, d_n$ 。
>
> 你的任务就是求出：在保证操作过程中任意时刻，所有位置  $i$  均满足  $c_i \leqq d_i$  的前提下，最终能使得序列  $c$  中不同数值的种类数最多是多少？

**输入描述**

> 每个测试文件均包含多组测试数据。第一行输入一个整数  $T\left(1 \leqq T \leqq 10^5 \right)$  代表数据组数，每组测试数据描述如下：
>
> 第一行输入一个整数  $n\left(1 \leqq n \leqq 2 \times 10^5 \right)$ 。
> 第二行输入  $n$  个整数  $d_1, d_2, \dots, d_n\left(0 \leqq d_i \leqq 10^9 \right)$ 。
>
> 除此之外，保证单个测试文件的  $n$  之和不超过  $2 \times 10^5$ 。

**输出描述**

> 对于每一组测试数据，新起一行输出一个整数，表示在操作过程中不违反限制的情况下，序列  $c$  最终能包含的不同数值的种类数的最大值。

#### 示例

**输入**

```text
2
4
2 2 1 0
3
0 0 0
```

**输出**

```text
3
1
```

### 最终代码：

```cpp
#include <cstdio>
#include <algorithm>
#include <vector>
#include <climits>

// 前缀加一 ⇒ 最终序列必然非增 c1>=c2>=...>=cn，且任意非增序列都可由前缀操作得到
// （对前缀 [1,i] 操作 c_i-c_{i+1} 次），过程中只增不减，故约束只需在终点满足。
// 又因非增，c_j <= c_i <= d_i (i<j)，于是每个位置的实际上界是前缀最小值 m_i。
// 在非增上界 m 下从右往左贪心：c_n=0，c_i=min(m_i, c_{i+1}+1)，能抬就抬一格。
int main() {
    int T;
    if (scanf("%d", &T) != 1) return 0;
    while (T--) {
        int n;
        scanf("%d", &n);
        std::vector<long long> m(n);
        long long cur = LLONG_MAX;
        for (int i = 0; i < n; ++i) {
            long long x;
            scanf("%lld", &x);
            cur = std::min(cur, x);
            m[i] = cur;
        }
        long long v = 0;  // 当前右侧已确定的 c 值（从 c_n=0 开始）
        int cnt = 1;      // 值 0 一定出现
        for (int i = n - 2; i >= 0; --i) {
            if (m[i] > v) {  // min(m_i, v+1) = v+1，产生一个新数值
                ++v;
                ++cnt;
            }
            // 否则 m_i == v，只能保持不变（m 非增保证 m_i >= v）
        }
        printf("%d\n", cnt);
    }
    return 0;
}
```

### 解题思路

读完题我先盯住“前缀加一”：位置越靠左被覆盖的机会越多，所以终值必然非增。接着反问反过来成不成立——把对前缀 [1,i] 的操作次数记成 x_i，则 c_i=x_i+x_{i+1}+…+x_n，只要 x_i=c_i−c_{i+1}≥0 就能构造出来，说明所有非增序列都可达。这一下动态过程就被彻底丢掉了，只剩静态问题：找非增的 c，每项不超过 d_i，让不同数值尽量多。第二步处理 d 的坑：d 在中间骤降会把右边全部压住，所以先把 d 改写成前缀最小值 m，这样每个位置的上界才真实。第三步定贪心方向：不同值最多就是从 0 一格一格往上爬，于是从最右端令 c_n=0（取最小最安全），往左每次尝试 min(m_i,c_{i+1}+1)，比右侧大 1 就多一个新数值，否则只能复制右侧的值；因为 m 非增，这个转移不会破坏单调性。为了确认没漏构造，我又写了一份枚举全部非增序列的暴力，n≤6、d_i≤5 随机对拍几千组，结果完全一致。

#### 卡点与关键一步

- 必须在前缀最小值 m 上贪心；直接用原始 d 会出错，例如 d=[10,0,10] 时右侧被 0 压住
- c_n 取 0 而不是 d_n，取大只会让可用的数值区间变窄
- 初始的 0 本身就算一种数值，计数从 1 开始，别漏掉也别重复加
