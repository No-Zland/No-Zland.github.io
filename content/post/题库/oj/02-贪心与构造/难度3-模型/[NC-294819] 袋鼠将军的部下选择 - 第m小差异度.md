### 知识点：

结论：答案就是 n 个差异度 d_i=|a_i-k| 中的第 m 小值。推导：设答案为 D，则「能选出恰好 m 人使最大差异度 ≤ D」等价于「d_i ≤ D 的人数至少 m」——只要能挑出至少 m 个差异度不超过 D 的人，从中任取 m 个，最大差异度都不会超过 D；反过来若人数不足 m 则无解。这个判定关于 D 单调（D 变大，达标人数只增不减），所以最小的可行 D 恰好是第 m 小的 d_i。属于「最大值最小化」模型，常用两种写法：二分答案 + 计数 O(n log V)，或直接排序/选择第 m 小 O(n log n) 甚至期望 O(n)。本题选人没有任何额外约束（不要求连续、不要求分组），所以比分组型问题简单，直接取第 m 小即可。

### 题目描述

> 在迎战坎格鲁斯普雷之前，袋鼠将军需要从  $n$  名可选部下中选出  $m$  名组成精锐小队。袋鼠将军的战斗力为  $k$ ，第  $i$  名部下的战斗力为  $a_i$ ，定义该部下的差异度为  $|a_i - k|$ ，即部下战斗力与将军战斗力之差的绝对值。
>
> 请你选出恰好  $m$  名部下，使得被选中部下的最大差异度最小化。

**输入描述**

> 每个测试文件均包含多组测试数据。第一行输入一个整数  $T\left(1\leqq T\leqq 10^4\right)$  代表数据组数，每组测试数据描述如下：
> 第一行输入三个整数  $n,m,k\left(1\leqq m\leqq n\leqq 10^5;\ -10^9\leqq k\leqq 10^9\right)$ ，表示部下人数、选出人数、将军战斗力。
> 第二行输入  $n$  个整数  $a_1,a_2,\dots,a_n\left(-10^9\leqq a_i\leqq 10^9\right)$ ，表示部下的战斗力。
>
> 除此之外，保证单个测试文件的  $n$  之和不超过  $10^5$ 。

**输出描述**

> 对于每组测试数据，新起一行输出一个整数，表示选择  $m$  名部下后最大差异度的最小值。

#### 示例

**输入**

```text
3
3 1 5
4 3 6
4 2 7
8 6 3 10
5 5 2
3 4 5 6 7
```

**输出**

```text
1
1
5
```

### 最终代码：

```cpp
// NC294819 袋鼠将军的部下选择
// 差异度 d_i = |a_i - k|，要求选恰好 m 个使最大差异度最小。
// 把 d_i 升序排序，答案就是第 m 小的 d_i：取差异度最小的 m 个人最稳。
#include <cstdio>
#include <cstdlib>
#include <vector>
#include <algorithm>

int main() {
    int T;
    if (scanf("%d", &T) != 1) return 0;
    std::vector<long long> d;
    while (T--) {
        int n, m;
        long long k;
        scanf("%d %d %lld", &n, &m, &k);
        d.resize(n);
        for (int i = 0; i < n; ++i) {
            long long a;
            scanf("%lld", &a);
            d[i] = a > k ? a - k : k - a;
        }
        // 只需要第 m 小的元素，nth_element 平均 O(n)
        std::nth_element(d.begin(), d.begin() + (m - 1), d.end());
        printf("%lld\n", d[m - 1]);
    }
    return 0;
}
```

### 解题思路

「让最大差异度最小」这个措辞让我第一反应是二分答案：二分 D，统计 |a_i-k| ≤ D 的人数是否 ≥ m。但马上意识到这里没有分组、也没有连续性约束，选谁完全自由，于是问题退化成一个纯粹的「取最小的 m 个」——达标人数随 D 单调，第 m 小的差异度就是临界值。为了保险我用交换论证又想了一遍：如果最优方案选了一个差异度较大的而漏掉更小的，把它换掉后最大值不会变大，矛盾，所以排序取第 m 小是对的。实现上我用 nth_element 只找第 m 小，避免整段排序；多组数据共用一个 vector 反复 resize，注意下标是 m-1。

#### 卡点与关键一步

- 差异度要取绝对值，最大可达 2×10⁹，接近 int 上限，用 long long 存更稳
- 第 m 小对应排序后的下标 m-1，不是 m
- T 可达 10⁴，多组数据别每组都重新申请大 vector

#### 复杂度

| 项 | 值 |
|---|---|
| 时间复杂度 | O(Σn)（nth_element 均摊） |
| 空间复杂度 | O(n) |
