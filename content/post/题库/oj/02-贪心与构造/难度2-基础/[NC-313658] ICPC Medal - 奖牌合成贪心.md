### 知识点：

结论：按轮贪心，每轮把铜牌尽量换成银牌，再把银牌尽量换成金牌，金牌返还的铜牌投入下一轮，直到换不出金牌为止。正确性：铜牌只有换银牌一种用途，银牌只有换金牌一种用途，能换就换不会损失机会；每枚金牌净消耗 x*y−1 个铜牌（合成时返还 1 个），资源单调减少，过程必然停止。按批计算时本轮银牌为 b+c/x，金牌数为 (b+c/x)/y，铜牌余 c%x 再加金牌数，规模每轮至少缩小到约 1/(xy)，轮数 O(log c)，用 long long 防止溢出。

### 题目描述

> 小苯在梦里梦到了 ICPC 奖牌是可以合成的。
>
> 具体来说，合成规则如下：
>
>  $\hspace{23pt}\bullet\,$  $x$  个铜牌可以合成  $1$  个银牌；
>
>  $\hspace{23pt}\bullet\,$  $y$  个银牌可以合成  $1$  个金牌。
>
> 特别地，每次合成一个金牌时，会额外掉落  $1$  个铜牌作为副产品。
>
> 现在小苯初始拥有  $a$  个金牌、 $b$  个银牌、 $c$  个铜牌。
>
> 他可以通过不断合成，将低级奖牌逐步升级为高级奖牌。银牌可以继续合成金牌，铜牌也可以先合成银牌再合成金牌。每次合成金牌后掉落的铜牌可以继续参与后续的合成。
>
> 你的任务就是求出最终小苯最多能拥有多少个金牌。

**输入描述**

> 在一行上输入五个整数  $a, b, c, x, y\left(0 \leqq a, b, c \leqq 10^9;\ 2 \leqq x, y \leqq 10^9 \right)$ ，分别表示初始金牌数、银牌数、铜牌数，以及合成银牌所需的铜牌数、合成金牌所需的银牌数。

**输出描述**

> 输出一个整数，表示最多能获得的金牌数量。

#### 示例 1

**输入**

```text
0 2 10 3 2
```

**输出**

```text
3
```

#### 示例 2

**输入**

```text
1 3 8 4 3
```

**输出**

```text
2
```

### 最终代码：

```cpp
#include <cstdio>

// 贪心：铜牌除了合成银牌没有别的用途，银牌除了合成金牌也没有别的用途，
// 所以每一轮都把能换的铜牌全部换成银牌，再把能换的银牌全部换成金牌。
// 合成金牌会返还 1 个铜牌，返还的铜牌进入下一轮继续参与合成。
// 每轮铜牌数会变成 c % x + 新增金牌数，规模至少缩小到 1/(x*y) 量级，
// 因此循环轮数是 O(log c) 级别，不会超时。
int main() {
    long long a, b, c, x, y;
    if (scanf("%lld %lld %lld %lld %lld", &a, &b, &c, &x, &y) != 5) return 0;

    while (true) {
        long long s = c / x;   // 本轮铜牌能合成的银牌
        b += s;
        c %= x;
        long long g = b / y;   // 本轮银牌能合成的金牌
        if (g == 0) break;
        b %= y;
        a += g;
        c += g;                // 每合成 1 个金牌返还 1 个铜牌
    }
    printf("%lld\n", a);
    return 0;
}
```

*代码为参考实现（按题意重写并用样例验证），非本人原始提交。*

### 解题思路

第一反应是模拟：铜牌够 x 就换银牌，银牌够 y 就换金牌。但一次只换一个会退化，比如 x=y=2、c=1e9 时要循环上亿次。于是把单个兑换改成按批兑换：本轮银牌总数为 b+c/x，能换出的金牌为 (b+c/x)/y，一次全部换掉；铜牌剩下 c%x，再加上每枚金牌返还的 1 个。这样每轮资源至少缩小 xy 倍，循环很快结束。用样例 1 手推：0 2 10 3 2，先 10 铜换 3 银，银共 5 换 2 金，余 1 银 1 铜；再 1 铜换 1 银，银 2 换 1 金，共 3 金。样例 2 同样得 2。为确认贪心最优，我还用小范围暴力枚举所有兑换顺序对拍，结果一致。

#### 卡点与关键一步

- 每合成 1 个金牌返还 1 个铜牌，漏掉返还答案会偏小
- 不能一次只换一个地模拟，c 到 1e9 会超时，要按批换
- 银牌余数 b%y 要留到下一轮，不能直接清零

#### 复杂度

| 项 | 值 |
|---|---|
| 时间复杂度 | O(log c) |
| 空间复杂度 | O(1) |
