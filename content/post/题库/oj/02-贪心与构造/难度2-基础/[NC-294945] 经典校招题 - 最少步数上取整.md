### 知识点：

考的是「每步代价相同、单步步长有上限」时的最少步数，本质是最朴素的贪心加向上取整。结论：最少步数 = ceil(n/2) = (n+1)/2。推导分两步：下界看单步能力，走 k 步最多跨 2k 阶，要 2k ≥ n，所以 k ≥ ceil(n/2)；上界给构造，先走 floor(n/2) 次 2 阶，再按 n 的奇偶补一次 1 阶（偶数次就不补），恰好 ceil(n/2) 步走完且不会越过第 n 阶。上下界相等，答案即 ceil(n/2)。这题不是「有多少种走法」的斐波那契模型，不要条件反射写 DP——虽然 n ≤ 1e5 时 DP 也能过，但正确解法是 O(1) 的一句取整，抓住「尽量迈 2 阶」这一个贪心选择即可。

### 题目描述

> 有这样一个经典的题目：一共有  $n$  阶台阶，现在你位于第  $0$  阶，每次可以向上走  $1$  阶或  $2$  阶。
>
> 现在，我们想要知道，最少需要走几次才能到达第  $n$  阶。

**输入描述**

> 输入一个整数  $n \left(1 \leqq n \leqq 10^5\right)$  代表台阶数。

**输出描述**

> 输出一个整数，表示最少需要走几次。

#### 示例 1

**输入**

```text
5
```

**输出**

```text
3
```

#### 示例 2

**输入**

```text
6
```

**输出**

```text
3
```

### 最终代码：

```cpp
// NC294945 经典校招题
// 题意：从第 0 阶走到第 n 阶，每步可上 1 阶或 2 阶，求最少步数。
// 结论：步数 = ceil(n/2) = (n+1)/2。
//   下界：k 步最多上 2k 阶，2k >= n => k >= ceil(n/2)。
//   构造：floor(n/2) 次 2 阶 + (n mod 2) 次 1 阶，恰好 ceil(n/2) 步。
#include <cstdio>
int main() {
    long long n;
    while (scanf("%lld", &n) == 1) printf("%lld\n", (n + 1) / 2);
    return 0;
}
```

### 解题思路

看到「每次走 1 阶或 2 阶、求最少次数」，我第一反应是那个爬楼梯的方案数 DP，随即反应过来这里问的是最少步数而不是方案数，递推完全没有必要。既然每步都只算一次，最优策略一定是能迈 2 阶就迈 2 阶，只在剩下 1 阶时补一步，所以答案就是把 n 除以 2 向上取整。我在纸上验证过 n=5 是 3 步（2+2+1）、n=6 是 3 步（2+2+2），和样例吻合；再想反例：为了「刚好踩到 n」而改用 1 阶替换某个 2 阶，步数只会变多，不可能更优，所以贪心是安全的。最后落成一行 (n+1)/2 输出。

#### 卡点与关键一步

- 不要写成方案数 DP（那是「有几种走法」的题），本题只需要最少步数。
- 奇数必须向上取整，`(n+1)/2` 比先除再判断更不容易漏。
- 输入虽然只有 1e5 级别，仍建议用 `long long` 读，避免以后换数据范围时踩坑。

#### 复杂度

| 项 | 值 |
|---|---|
| 时间复杂度 | O(1) |
| 空间复杂度 | O(1) |
