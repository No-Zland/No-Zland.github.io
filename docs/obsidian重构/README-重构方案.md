## 3. 两条刻意的例外

1. **课程保留教材章节**：`01-知识库/课程/C语言/文件/1-函数/1-表达式/…` 原样保留。章节是「书」的骨架，压平成一堆 `1-无命令行参数.md` 只会更难找；MOC 也替代不了目录。这条分支是唯一没压平的地方。
2. **竞赛 / 项目保留"一次事件一个文件夹"**：`02-实战库/竞赛/202609 高教社杯…/` 里同时有题面、思路、代码、数据、论文，拆开就废了。它们不是知识，是案卷。

其余全部按「形态」重排。判断标准只有一句：**这个文件夹是"一次事件"还是"一个知识点"？** 前者留目录，后者进标签。
