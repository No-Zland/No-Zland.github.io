# 设计规范（配色 / 排版 / 组件）

> 适用范围：`build_blog.py` 内联的 `CSS`、`src/*.css`、`src/*.js` 里用到的颜色与尺寸。
> 原则：**颜色只走 CSS 变量**，不写死在组件里；canvas（知识图谱）从 `--sat-*` 变量读色。
> 改配色时：先改变量 → 同步本文件 → `python build_blog.py` 重新生成。

---

## 2. 标题层级配色

| 层级 | 亮色 | 暗色 | 说明 |
| --- | --- | --- | --- |
| `h1` | `#5340c9` | `#b9a6ff` | 文章大标题，保留下边框（同色 35% 混边线） |
| `h2` | `#1f6fe0` | `#8ab4ff` | 一级小节 |
| `h3` | `#0f8fa3` | `#63d3c6` | 二级小节 |
| `h4`–`h6` | `#a2560a` | `#e6bd7a` | 更深层级、卡片小标题 |

对应变量：`--h1` / `--h2` / `--h3` / `--h4`，只作用于 `.doc-body` 内的文章标题，
站点其他卡片标题仍用 `--text`，避免满屏彩色。

## 3. 代码与高亮

- 代码块底色：`#12182a`（亮/暗一致），文字 `#e6e9f0`，圆角 10px，内边距 16/18px。
- 行内代码：底 `--code-bg`，字 `--code-color`；亮色 `#f1f2f7` / `#c0392b`，暗色 `#20304a` / `#ffb3a0`。
- 高亮由 Pygments 在构建时生成（`build_blog.py` 的 `BlogCodeStyle`），未标注语言的代码块保持纯文本。

| Token | 色值 | 示意 |
| --- | --- | --- |
| Keyword | `#c792ea` | `if` `for` `return` `using` |
| Keyword.Type / Builtin | `#ffcb6b` | `int` `ll` `cin` `cout` |
| String | `#a5e075` | `"hello"` |
| Number | `#f78c6c` | `194` `1000000000` |
| Comment | `#6b7a99`（斜体） | `// 当前苹果数` |
| Function | `#82aaff` | `check()` |
| Operator | `#89ddff` | `+` `<<` `*` |
| Punctuation | `#a6accd` | `()` `{}` `;` |
| Error | `#ff5370` | 词法错误 |

## 4. 内容元素

| 元素 | 规范 |
| --- | --- |
| 正文 | 15.5px / 行高 1.7，段落间距 12px，长段落首行缩进 2em（`.p-indent`） |
| 链接 | 正文下划线 + 2px offset，色 `--brand` |
| 引用块 | 左侧 3px 品牌色，底 `--accent-bg`，圆角右侧 8px |
| 表格 | **默认居中**：`width: fit-content; margin: 16px auto; max-width: 100%;` 超宽横向滚动 |
| 图片 | **默认居中**：`display: block; margin: 14px auto;` 圆角 8px，点击放大 |
| 分隔线 | 1px `--border`，上下 22px |
| 徽章 / 标签 | 圆角 999px，底 `--bg-soft`，字 `--text-soft`，字号 9–11px |

## 5. 知识图谱（canvas）

星图台的颜色全部来自 `--sat-*`，亮/暗各一套：

| 变量 | 亮色 | 暗色 | 用途 |
| --- | --- | --- | --- |
| 底板 | 淡蓝白渐变 | 深藏蓝渐变 | `.satellite` 背景 |
| `--sat-ink` | `#232a3d` | `#e9eefb` | tooltip 主文字 |
| `--sat-soft` | `#5f6b85` | `#9db0cc` | 图例、提示 |
| `--sat-halo` | `rgba(250,251,255,.95)` | `rgba(9,14,26,.88)` | 节点标签描边（保证压在任何背景上都读得清） |
| `--sat-star` | `rgba(70,84,120,.38)` | `rgba(255,255,255,.8)` | 星点 |
| `--sat-chip` | `rgba(255,255,255,.9)` | `rgba(8,13,24,.74)` | 旧版胶囊底（保留变量） |
| `--sat-tip-bg` | `rgba(255,255,255,.97)` | `rgba(9,15,28,.94)` | tooltip 底 |
| `--sat-kicker` | `#5f4fd6` | `#c7b8ff` | 「知识图谱」小标 |
| `--sat-btn-*` | 白底深字 | 深底浅字 | 缩放按钮 |

节点配色规则：板块色 → 子级 `+16%` 提亮 → 文章 `+30%` 提亮；暗色下整体再提亮 22%。

## 6. 组件与排版

- **圆角**：卡片 12–16px，按钮 8–10px，徽章 999px。
- **阴影**：`--shadow`（常态）/ `--shadow-hover`（悬停上浮 3–4px）。
- **动效**：统一 `--ease: cubic-bezier(.22,.61,.36,1)`；`prefers-reduced-motion` 下全部关闭。
- **聚焦环**：`outline: 2px solid var(--accent-cyan); outline-offset: 3px`。
- **字号阶梯**：26（页面标题）/ 23（文内 h1）/ 20（h2）/ 17（h3）/ 15.5（正文）/ 13（表格与注释）/ 11–12（元信息）。

---

## 7. 对比度与可访问性

- 正文与底色对比度 ≥ 7:1（亮色 `#1f2430` on `#ffffff`，暗色 `#e6edf7` on `#0e1a2b`）。
- 次要文字 ≥ 4.5:1；标签描边（`--sat-halo`）保证图谱文字在任何节点上都可读。
- 颜色不单独承载信息：板块、状态同时用文字 / 形状区分。

---

## 8. 变更流程

1. 改 `build_blog.py` 的 `:root` / `[data-theme="dark"]` 变量，或 `src/search.css` 的 `--sat-*`。
2. 同步更新本文件的表格。
3. `python build_blog.py --clean`，本地对照亮/暗两套主题检查。
4. 提交时在 commit message 里写明改了哪一类颜色。
